# 标准研究问题集

## 三个核心问题（必问）

### 问题1：核心算法流程

**问题模板**：
```
这篇文章的核心算法流程是怎样的？
```

**预期答案要点**：
- 主要的阶段和步骤
- 输入和输出
- 关键组件和模块
- 整体架构

**适用于**：
- 任何需要理解算法流程的论文
- 方法论型论文
- 系统架构类工作

---

### 问题2：改进和创新

**问题模板**：
```
这篇文章相比其他工作或者它的baseline有什么改进和创新？
```

**预期答案要点**：
- 与现有工作的区别
- 主要的创新点
- 克服的挑战
- 性能提升（定量）
- 方法论上的改进

**适用于**：
- 所有研究论文
- 需要理解贡献的论文
- 对比实验类论文

---

### 问题3：实验部署和运行效率

**问题模板**：
```
这个工作的实验在什么环境部署的，部署时运行效率如何？
```

**预期答案要点**：
- 实验环境（硬件、软件）
- 部署场景（室内/室外）
- 运行效率指标（延迟、吞吐量）
- 计算资源消耗
- 可扩展性分析

**适用于**：
- 系统实现类论文
- 机器人/自动驾驶论文
- 实际部署相关的工作

## 问题设计原则

### 好的问题特征

1. **具体明确** - 不模糊，目标清晰
2. **针对核心** - 针对论文的主要内容
3. **可验证** - 答案可以在论文中找到
4. **有价值** - 有助于理解论文的核心贡献
5. **简洁** - 避免过长或过于复杂

### 差的问题示例

- ❌ "这篇论文怎么样？"（太模糊）
- ❌ "详细解释所有内容"（范围太大）
- ❌ "作者是什么人？"（与论文内容无关）
- ❌ "你觉得这个论文好还是不好？"（需要主观判断，不适合从论文中提取）

### 好的问题示例

- ✅ "这篇文章的核心算法流程是怎样的？"
- ✅ "相比其他工作，主要的改进和创新是什么？"
- ✅ "实验在什么环境下进行，运行效率如何？"
- ✅ "使用了哪些技术框架和方法？"
- ✅ "主要实验结果和性能指标是什么？"

## 自定义问题模板

根据不同领域，可以创建特定的问题模板：

### 计算机视觉领域

- 使用了什么网络架构？
- 数据增强策略是什么？
- 损失函数是如何设计的？
- 推理速度和精度如何平衡？

### 机器人/自动驾驶领域

- 传感器配置是怎样的？
- 控制算法使用了什么方法？
- 安全性如何保证？
- 实时性如何实现？

### 自然语言处理领域

- 使用了什么预训练模型？
- 微调策略是什么？
- 评估指标有哪些？
- 多语言/多模态能力如何？

### 深度学习理论领域

- 理论基础是什么？
- 收敛性如何证明？
- 泛化误差界是多少？
- 与现有理论的关系如何？

## 使用建议

### 选择问题数量

- **最少**：3个核心问题（必问）
- **推荐**：3-5个问题（包括扩展问题）
- **最多**：7个问题（避免信息过载）

### 问题顺序建议

1. 先问核心问题（流程、创新、实验）
2. 再问具体细节（实现、参数、结果）
3. 最后问扩展问题（应用、未来工作）

### 批量询问策略

如果需要问多个问题，可以考虑：

```bash
# 方式1：逐个询问
notebooklm ask "问题1"
notebooklm ask "问题2"
notebooklm ask "问题3"

# 方式2：合并询问（注意长度）
notebooklm ask "问题1？问题2？问题3？"
```
