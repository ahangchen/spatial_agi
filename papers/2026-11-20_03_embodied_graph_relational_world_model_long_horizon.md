# Embodied Graph: A Relational World Model for Long-Horizon Tasks

## 一句话总结

Embodied Graph（EG）是一个把环境状态抽象为稀疏关系图的形式化框架（节点=智能体+实体，边=交互效应传播路径，交互=作用于目标节点的动作），其上的 Relational World Model（RWM）用 Task-Aware Graph Constructor 维护有界图记忆、用图版 RSSM 学习节点级潜在动力学，**直接在图状态上做长时程想象**——在 Minecraft 里是给定预算内唯一拿到钻石的方法，开环预测误差增长远慢于 DreamerV3。

## 核心问题

### Q1: 核心算法原理是什么？

**问题**: 这篇文章的核心算法原理是什么？请详细描述：1) 核心思想和动机，2) 主要技术方法，3) 算法流程和关键步骤，4) 输入输出。

**分析**:

1. **核心思想和动机**

   长时程具身任务（Minecraft 挖钻石、Crafter、网页多步操作）的特点是决策序列长、反馈延迟，世界模型的"想象式规划"是对症的药。但现有世界模型有两个结构性病灶：

   - **稠密像素监督注入冗余**: 视觉变化量 ≠ 决策重要性。风吹草动改变大量像素但物体状态没变；捡起关键道具可能只改变几个像素。像素重建目标把模型容量花在外观上，漏掉决定后续动作的状态转移；
   - **误差累积 → 想象漂移（imagination drift）**: 小误差在长 rollout 中复利放大。论文的经典插图：早期预测把沙洲磨平了一点，几十步后滚出一片幻觉绿洲，策略被引向真实环境永远不会提供的状态。

   解决思路：**在稀疏关系图上想象**。图天然过滤无关细节、聚焦实体与关系；结构化表示让动力学只在"任务相关的东西"上学习，复利误差的基数被砍掉，有效想象时域（effective imagination horizon）被拉长。

   两个核心挑战：
   1. 开放动态环境中物体/关系会生灭变化，如何在线蒸馏并维持一致的图（状态抽象的构建问题）；
   2. 如何学习 rollout 复合误差更小的图动力学（可靠长时程预测问题）。

2. **主要技术方法**

   **Embodied Graph 形式化**: G^t = (V^t, E^t, I^t)。
   - 节点：异构，V = {V_a（智能体）, V_e（环境实体）}；
   - 边：有向、异构三类（entity-entity / entity-agent / agent-agent），(u,v) 表示 u 的状态会影响 v 的变化；
   - 交互：A = (i, v)，交互类型 i + 目标节点 v，这就是"动作"的图语义。

   **RWM 两大组件**：
   - **TA-EGC（Task-Aware Embodied Graph Constructor）**: 实现 G^t = C_φ(G^{t-1}, o_t)，把观测转成候选节点，经任务感知过滤与动态融合，维护一个至多 N 个节点的**有界全局图记忆**；
   - **EG-RSSM（Embodied Graph Recurrent State Space Model）**: 实现 p_Θ(G^{t+1} | G^{≤t}, A^{≤t})，为每个节点维护 {h（确定性潜在态）, z（随机潜在态）}，通过消息传递聚合邻居上下文，学习节点级、关系感知的动力学。

3. **算法流程和关键步骤**

   **TA-EGC 的图维护循环**：
   1. 前端把观测 o_t 转成 M 个候选节点（带属性向量）；
   2. **任务感知节点过滤**: 三个打分器 S_θk 给每个候选拍 s_task / s_novel / s_cover，加权合成总分 s_i = α_t·s_task + α_n·s_novel + α_c·s_cover，Top-P 进入插入集；
      - 任务相关性标签（hindsight 定义）：候选在接下来 W 步内成为交互目标；
      - 新颖性：语义类别在当前候选中的稀缺度；
      - 覆盖度：偏好分散插入而非扎堆一处；
      - 任务项的损失权重再按策略优势 Adv 重加权，强调关键步骤；
   3. **动态图融合**: 每个已存在节点经身份测试匹配至多一个候选（匹配则更新属性和 last-seen 步数 l_j），未匹配的候选作为新节点插入；图满时驱逐最久未见（LRU）节点；
   4. 边集由关系函数重建 E^t = R(V^t)，边上传递的消息由 EG-RSSM 学习。

   **EG-RSSM 的节点级动力学**：
   1. 节点编码 x_j = f_enc(o_j)；
   2. 消息聚合 c_j = AGG({φ(x_j, x_k) | k ∈ N(j)})——关系信息进上下文；
   3. 确定性转移 h_j^t = f_dyn(h_j^{t-1}, z_j^{t-1}, c_j^{t-1}, A^{t-1})；
   4. 双 KL 正则（DreamerV3 式）：
      - L_dyn：KL[sg(q posterior) ‖ p prior]，训练先验追后验；
      - L_rep：KL[q ‖ sg(p)]，约束后验不偏离预测动力学；
   5. **拓扑辅助目标 L_topo**: 预测每次交互的结构性结果 b^t（具身域=节点诞生；Web=交互后到达的页面），弥补 KL 正则不约束结构变化（边的生灭）的缺口；
   6. **双预测损失（dual prediction）**: 从潜在态解码环境节点属性 + 智能体属性，保证潜在变量保留任务相关语义、想象 rollout 可解码回紧凑图状态。

   **决策使用**: 想象的图状态提供"动作后果预测"，指导具身控制（Minecraft/Crafter）与网页智能体（交互后页面状态预测）的决策。

4. **输入输出**

   - **输入**: 部分可观测环境的观测流 o_t（像素/页面）+ 动作流（图交互 A_t）；
   - **输出**: 图状态的预测 G^{t+1}（节点属性 + 结构结果）、可解码的紧凑图想象轨迹；下游输出决策/策略；
   - **训练目标**: 最大化观测下一图的似然（式 2）+ 打分损失 + KL 双正则 + 拓扑损失 + 双预测解码损失。

**关键结果**: Minecraft 给定预算内唯一拿到钻石的方法；Crafter 长时程目标增益最大；开环预测误差增长显著慢于 DreamerV3；WebAgents 任务验证关系状态预测对网页决策的适用性。

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**问题**: 这篇文章与通用空间智能（Spatial AGI）有什么关系？请分析：1) 如何理解和表示空间，2) 如何处理空间关系，3) 对Spatial AGI有什么启发，4) 可以应用到哪些Spatial AGI场景。

**分析**:

1. **如何理解和空间表示**

   Embodied Graph 对空间的理解是**关系优先**的：
   - 空间被抽象为"实体 + 关系 + 交互"的三元结构，几何坐标退居其次（节点属性可以含位置，但框架核心是拓扑）；
   - 边的方向性编码了因果传播路径——"什么东西的变化会影响什么"，这是对空间的功能性理解而非几何性理解；
   - 有界图记忆（≤N 节点 + LRU 驱逐）意味着空间记忆是**有预算的、按任务相关性取舍的**——这与 Spatial AGI 需要的"选择性空间记忆"高度相关：不是记住一切，而是记住对任务重要的空间结构。

2. **如何处理空间关系**

   - **显式关系建模**: 不同于把所有东西混进一个纠缠的潜在向量（entangled latent state），RWM 的节点级状态分解让"每个物体的动力学"独立可学习，物体间依赖通过消息传递显式流动；
   - **交互的局部性**: 交互作用于目标节点，效应沿边传播——这为空间因果推理提供了结构化骨架（"我砍这棵树，掉落物进入背包，背包状态变化影响后续合成"）；
   - **结构变化单独监督**: L_topo 专门预测节点诞生等结构性事件，承认"关系结构的改变"与"属性的改变"是两类不同的空间事件。

3. **对Spatial AGI的启发**

   - **抽象层级的选择决定想象时域**: 本文证明稀疏图抽象能把有效想象时域拉长（误差增长慢于 DreamerV3）。Spatial AGI 同样面临"想象多远"的问题——像素级想象漂移（幻觉绿洲）在空间预测中同样致命；图/关系抽象是抗漂移的一剂药方；
   - **任务感知的记忆管理**: s_task/s_novel/s_cover 三重打分 + 优势加权的 hindsight 标签，给出了"空间记忆该记什么"的可学习答案。Spatial AGI 的空间记忆系统可以从这里借"按未来交互有用性来筛选记忆"的原则；
   - **关系世界模型 vs 像素世界模型 vs 潜在原生空间**: 三天读的三篇论文正好构成表示光谱（外置像素 → 关系图 → 原生潜在），Embodied Graph 证明了结构化抽象在长时程上的独特价值——Spatial AGI 可能需要分层想象：图层管长时程因果，像素/潜在层管短时程外观；
   - **跨域抽象的普适性**: 同一框架覆盖 Minecraft、Crafter 和网页交互，说明"实体-关系-交互"抽象跨越具身与数字环境——这是 Spatial AGI（广义的空间不止物理3D）需要的抽象普适性。

4. **可以应用的Spatial AGI场景**

   - **机器人长时程任务规划**: 把操作场景抽象为物体图，想象多步操作后的物体状态图（含物体诞生/消失），用于任务级规划；
   - **空间记忆系统**: 有界图记忆 + LRU + 任务相关打分，可直接作为导航/操作 agent 的空间记忆模块设计；
   - **家庭/仓库级场景图动力学**: 现有 3D scene graph 是静态的，EG 补上了"交互驱动的动态演化"；
   - **GUI/数字空间智能体**: 论文已验证网页智能体应用——数字空间（页面、应用）的空间智能；
   - **多智能体空间协调**: 框架预留了 agent-agent 边与交互，可扩展到多机器人空间协作。

### Q3: 主要创新点和局限性是什么？

**问题**: 基于前面的分析，这个方法的主要创新点和局限性是什么？与其他相关工作相比有什么优势和劣势？

**分析**:

1. **主要创新点**

   - **Embodied Graph 形式化**: 把"环境动力学建模"重新定义为"图上的预测任务"（式 1-2），统一具身与 Web 两个领域，是对世界模型输入表示的范式级重定义；
   - **TA-EGC：任务感知的有界图记忆**: 三重打分（任务/新颖/覆盖）+ hindsight 标签 + 优势加权的在线节点过滤，加上身份测试 + LRU 驱逐的动态融合——解决了"开放环境中在线维持一致性图"的难题；
   - **EG-RSSM：节点级 RSSM + 关系传播**: 把 DreamerV3 式 RSSM 分解到节点级，消息传递进确定性转移，结构结果（节点诞生/页面到达）单独监督——图动力学学习的完整配方；
   - **想象漂移的定量改善**: 开环预测误差增长显著慢于 DreamerV3，Minecraft 钻石是"唯一成功"的硬指标。

2. **主要局限性**

   - **前端依赖**: 候选节点来自前端的实体提取（Minecraft 有物体分割，网页有 DOM），开放无结构场景（真实世界杂乱厨房）的候选提取质量决定上限；
   - **几何信息薄弱**: 图抽象天然丢弃精确几何，想象"物体状态图"而非"物体在3D空间中的位姿"——真正的空间操作（抓取、避障）仍需几何层；
   - **离散交互假设**: 交互 A=(i,v) 是离散作用于目标节点的动作，连续控制（推、擦、倒）的图语义表达困难；
   - **N 节点预算的取舍风险**: LRU + 任务相关性打分可能驱逐"当前不相关但之后关键"的实体（比如过早丢弃的钥匙）；
   - **评测域偏游戏/网页**: Minecraft/Crafter/Web 的实体边界清晰，真实世界的模糊实体（一堆纸、半杯水）是未验证的硬骨头。

3. **与其他相关工作的对比**

   - **vs DreamerV3**: 同为 RSSM 血统，RWM 把纠缠潜在态换成节点级分解+关系传播，长时程误差增长更慢、长时程任务收益最大；DreamerV3 胜在通用性（无需实体前端）；
   - **vs 3D Scene Graph 方法**: scene graph 是静态重建产物，EG 是交互驱动的动态演化形式化——补上了"图如何随动作变化"这一环；
   - **vs 像素级视频世界模型**: 反其道而行——不预测像素，预测结构化状态；牺牲外观保真度换取因果清晰度与想象时域；
   - **vs 昨日粒子世界模型 GPWM**: 粒子是几何化的实体（带3D位置），EG 的节点是语义化实体（带属性与关系）；GPWM 侧重动态场景重建，EG 侧重任务级想象规划；
   - **vs WebAgent 世界模型研究**: EG 把网页交互纳入同一形式化，是"具身=数字空间"统一叙事的有力注脚。

## 核心技术发现

- 发现1: **视觉变化量与决策重要性解耦**——像素监督把容量浪费在外观变化上，任务相关的状态转移反而欠监督；稀疏图抽象从源头修正监督信号的错配；
- 发现2: **结构化抽象拉长有效想象时域**——图状态的 rollout 复合误差增长显著慢于纠缠潜在态，"想象多远"取决于表示多稀疏、多结构化；
- 发现3: **任务相关性是可以被 hindsight 监督的**——"接下来 W 步内是否成为交互目标"这样的后验标签让记忆筛选变成了可学习问题。

## 与Spatial AGI的关系

### 直接贡献

提供了一个"空间 = 实体关系图 + 交互动力学"的可训练实现：图记忆（TA-EGC）+ 图想象（EG-RSSM）+ 图决策的完整闭环，并在具身游戏与网页两个域验证。

### 技术启发

- Spatial AGI 的空间记忆应当有预算、按任务相关性筛选、可在线融合与驱逐；
- 长时程空间想象需要抽象层级（图/符号），短时程保真需要感知层级（像素/潜在）——分层想象架构呼之欲出；
- 结构性事件（实体生灭）需要独立的监督通道（L_topo），不能指望属性预测顺带学会。

### 应用场景

机器人任务级规划、空间记忆模块、动态场景图、GUI 智能体、多智能体协调。

## 个人思考

### 最令人兴奋的发现

Minecraft "唯一拿到钻石"这个结果比任何平均分都有力：长时程任务的成败是悬崖式的，结构化想象带来的不只是分数提升，而是质变。幻觉绿洲的插图也极有说服力——它把"像素世界模型的误差累积"变成了一个视觉上人人都懂的故事。

### 潜在局限

图抽象是一把锋利的双刃剑：它假设"任务相关的世界 = 实体与关系"，但空间智能的大量任务恰恰生活在图表示的盲区——连续几何、物理接触、流体。N 节点预算下"暂时不相关"实体的驱逐也是隐患。理想的 Spatial AGI 架构可能是：图层做长时程任务推理，几何/像素层做短时程执行，两层互相校准。

### 与昨日研究的关联

昨天第 4 篇 cosphere（多智能体全景高斯 SLAM）负责"精确空间重建"，今天 EG 负责"任务级空间想象"——一个在几何底座，一个在语义顶层。再加上昨天 gpwm 的粒子（几何实体化），"空间智能的表示金字塔"正在浮现：像素 → 几何（点/粒子/高斯）→ 语义实体图 → 任务/符号。

## 关键数据

- **Minecraft**: 给定预算内唯一获得钻石的方法（长时程硬指标）
- **Crafter**: 超越 SOTA 基线，长时程目标增益最大
- **开环预测**: 误差增长速度显著慢于 DreamerV3（有效想象时域更长）
- **Web agents**: 关系状态预测有效提升网页决策（Zhou et al., 2024 基准）
- **图记忆**: 有界 ≤N 节点，LRU 驱逐，Top-P 任务感知插入
- **损失体系**: L（图似然）+ L_score + L_dyn + L_rep + L_topo + 双预测解码

## 总结

### 核心发现总结

Embodied Graph 把长时程世界建模从像素空间搬到稀疏关系图上：TA-EGC 解决"在线维持任务感知的有界图记忆"，EG-RSSM 解决"图上的低漂移动力学学习"。结果是长时程任务的质变（Minecraft 钻石）与想象时域的显著拉长。

### 对Spatial AGI的意义

它确立了"空间想象需要分层抽象"的论点：关系图层负责长时程、任务级的空间因果推演，与像素/几何/潜在表示互补。空间记忆的任务感知管理（记什么、忘什么）由此成为可学习问题。

## 扩展分析

### Embodied Graph 与经典场景图的对比表

| 维度 | 3D Scene Graph | Embodied Graph |
|------|---------------|----------------|
| 来源 | 静态重建/感知 | 在线交互维护 |
| 节点 | 物体/房间等实体 | 智能体 + 实体（异构） |
| 边 | 空间/语义关系（如在之上、包含） | 因果影响关系（谁的状态影响谁） |
| 动态 | 静态快照 | 随交互演化（含节点生灭） |
| 用途 | 场景理解/查询 | 动力学预测/想象规划 |
| 更新 | 重新重建 | 身份测试 + 增量融合 + LRU |

EG 本质上是给 scene graph 加了"时间轴 + 因果边 + 交互语义"，从"空间是什么"进化到"空间如何变化"。

### TA-EGC 三重打分的设计智慧

- **task**（未来 W 步内成为交互目标）: 后验、任务条件化、优势加权——直接对齐决策价值；
- **novel**（语义类别稀缺度）: 保多样性，防止图被大量同类物体塞满（Minecraft 里满屏石头）；
- **cover**（空间分散度）: 防止扎堆单区域，保证图对观测的全局覆盖。

三者合成的隐含哲学：好的空间记忆 = 对任务有用 + 有信息量 + 覆盖全面。这个组合可以原封不动搬进任何 Spatial AGI 记忆系统。

### 图 RSSM 与 DreamerV3 RSSM 的对照

- DreamerV3：单一纠缠潜在态 {h, z}，重建像素监督；
- EG-RSSM：N 个节点各自的 {h_j, z_j}，消息聚合进 f_dyn，解码图属性 + 结构事件；
- 关键差异在**误差的隔离性**：纠缠态里一个分量出错污染整个状态；节点级分解把误差局部化在单个节点，配合稀疏图的小基数，rollout 漂移自然放缓。

### L_topo 的必要性论证

KL 双正则只约束 z 的分布对齐，不约束"结构事件"（新节点出现、页面跳转）。如果放任不管，模型会把结构变化当成属性变化硬塞进节点属性里，图拓扑失真。L_topo 把"交互 → 结构结果"作为显式分类/预测问题，等于告诉模型：**世界中有些变化是拓扑性的，请单独学会预测它**。对空间智能的启示：实体生灭（物体出现/消失/被吃掉）在空间推理中是高价值事件，值得独立预测通道。

### Minecraft 钻石任务的意义

"获取钻石"需要：砍树 → 合成工作台 → 木镐 → 挖石头 → 石镐 → 挖铁 → 铁镐 → 下矿 → 找钻石。链条约 20+ 步，任何一步想象漂移都会导致策略走进死路。像素世界模型在几十步的 rollout 后早已漂出有效状态空间。RWM 是预算内唯一成功者，说明图抽象把这条链上"真正重要的状态"（拥有什么工具、在什么层）保真地传到了链条末端。

### Web 域迁移的深层含义

网页交互的"图"（DOM 元素 + 跳转关系）与 Minecraft 的图（实体 + 交互）共享同一形式化，说明 EG 抓住的是**交互式环境的通用语法**：实体、关系、离散交互、可预测的状态转移。Spatial AGI 若以"一切可交互空间"为研究对象（物理空间、数字空间、混合空间），EG 提供的统一形式化是宝贵的理论起点。

### 分层想象架构设想（个人推演）

结合近三天论文，设想一个四层想象系统：
1. **像素层**（短时程，<1s）：视频/图像生成器，管外观保真；
2. **几何层**（中时程）：高斯/粒子/网格动力学，管物理与位姿；
3. **图层级**（长时程）：EG 式实体关系图，管任务因果与状态；
4. **符号层**（超长时程）：任务图/目标树，管规划。

层间接口：下层向上层提供实体化输入（前端提取），上层向下层提供约束（想象的目标状态）。每层用适配的抽象控制各自的误差增长速率——这正是 EG "稀疏抽象拉长想象时域"思想的多层推广。

### 开放问题

1. 前端实体提取在无结构真实世界的鲁棒性——开放词汇分割/跟踪的进展是 EG 落地的关键依赖；
2. 连续动作的图语义化：参数化交互（力度、轨迹）如何进入 A=(i,v) 形式化；
3. 多智能体 EG 的博弈动力学：agent-agent 边上的消息传递如何建模竞争/合作；
4. 图记忆预算 N 与任务复杂度的标度关系；
5. 图想象与几何想象的接口：节点状态如何实例化成位姿/形状约束。

## 问答式深度复习（自测）

### 问：为什么像素级世界模型会有想象漂移？
答：像素监督让模型对一切视觉变化均摊容量，任务相关的小变化（捡起道具）欠拟合、无关的大变化（光影）过拟合；长 rollout 中小误差复利放大（沙洲→绿洲），rollout 偏离真实状态分布，策略被误导。

### 问：TA-EGC 如何防止图被冗余碎片填满？
答：三道闸门：三重打分只放行 Top-P 任务相关候选；身份测试把候选融合进已有节点而非新建；容量满时 LRU 驱逐最久未见节点。图始终 ≤N 节点。

### 问：EG-RSSM 与 DreamerV3 的 RSSM 差在哪？
答：状态分解到节点级（每个实体一套 {h,z}）；确定性转移接收消息聚合的邻居上下文 c_j（关系建模）；监督从像素重建换成图属性解码 + 结构事件预测（L_topo）。

### 问：L_dyn 和 L_rep 的方向差异？
答：L_dyn = KL[sg(q)‖p]，梯度只进 prior（先验学后验）；L_rep = KL[q‖sg(p)]，梯度只进 posterior（后验贴先验）。双向 stop-gradient 避免 KL 坍缩，是 Dreamer 血统的标准配方，EG 把它逐节点应用。

### 问：Web 任务里"结构结果"是什么？
答：交互后到达的页面（page reached）。与 Minecraft 的"节点诞生"同构：都是交互引发的离散结构跳变。

### 问：本文最大的弱点？
答：对前端实体提取的依赖。游戏和网页的实体边界天然清晰，真实世界（模糊物体、连续物质）会让候选节点质量崩塌——图抽象的上限由感知前端决定。

## 名词表

- **Embodied Graph (EG)**: (V, E, I) 三元组的状态抽象：节点、异构有向边、交互。
- **Interaction**: A=(i, v)，交互类型 + 目标节点，动作的图语义。
- **TA-EGC**: 任务感知图构造器：候选过滤（task/novel/cover 打分）+ 动态融合（身份测试/LRU）。
- **EG-RSSM**: 节点级循环状态空间模型：消息聚合 + 双 KL + 拓扑损失 + 双预测。
- **Imagination drift**: 长想象 rollout 中误差累积导致的预测腐化。
- **Effective imagination horizon**: 模型 rollout 多远后误差显著增长的度量。
- **Hindsight labels**: 用未来轨迹回填的训练标签（如"未来 W 步成为交互目标"）。
- **Identity test**: 图融合中新观测与已有节点的匹配过程。
- **Structural outcome (b^t)**: 交互的拓扑结果（节点诞生/页面到达）。

## 补充精读：损失体系的整体审视

RWM 的六个损失组件及分工：

| 损失 | 监督什么 | 防止什么失败 |

| L（图似然，式2） | 整体动力学 | — 总目标 |
| L_score（式3） | 节点过滤打分器 | 图被冗余碎片淹没 |

设计要点：没有任何一个损失是"像素重建"——所有监督都在图/属性/结构层面，这是与 DreamerV3 最根本的分野。

## 补充精读：Minecraft 案例的想象链分析

以钻石链为例试推 RWM 的想象过程：
1. 状态图节点：{agent, 树×n, 原木×k, 工作台?, 木镐?, ...}；
2. 交互"砍树@tree_3"→ L_topo 预测原木节点诞生 → 双预测更新背包属性；
3. 长链 rollout：每个中间工件（工作台→木镐→石镐→铁镐）都是图中的显式节点，其存在性被 L_topo/属性解码持续跟踪；

## 补充精读：与空间记忆研究的对接

近期空间智能领域的记忆系统（EmbodiedLGR 图记忆、Reasmory 重建即记忆、HoloAgent-0 结构化3D记忆）都在回答"空间记忆的载体是什么"。EG 的独特贡献是加上了**动力学**：不只是"存空间的图"，而是"图会随交互演化且可预测"。这把空间记忆从静态检索库升级为可模拟的环境副本——记忆即世界模型。

## 补充精读：可学习记忆管理的意义再强调

传统记忆管理是手工规则（相似度阈值、时间衰减、容量 FIFO）。TA-EGC 的三重打分是**从轨迹数据中学习**的：hindsight 标签（未来 W 步成为交互目标）不需要人工标注——回放轨迹时自动可得；优势加权把"关键决策时刻"的样本放大。任何 Spatial AGI 记忆系统都可以复制这套"用后验有用性监督前置筛选"的配方，把记忆管理变成无监督可学习问题。

## 补充精读：误差增长曲线的意义

开环预测误差 vs rollout 步数的曲线是本文最有信息量的图之一：
- DreamerV3：早期误差低但增长快（纠缠态误差复利）；
- RWM：误差增长近似线性且斜率小（节点误差隔离 + 稀疏基数）；
- 交叉点即"有效想象时域"的分界——RWM 在 Minecraft 钻石需要的 ~20+ 步尺度上仍保持可用预测，DreamerV3 早已漂出。

这张图给出的可操作指标是：**用误差增长斜率而非单点误差来评世界模型**，对 Spatial AGI 评测体系是直接的贡献。

## 补充精读：潜在扩展——把几何塞回图节点

EG 节点属性当前是语义特征。一个显然的增强：节点属性挂载局部几何（点云/高斯/包围盒+位姿），动力学分两层——图级（EG-RSSM 管属性与拓扑）+ 几何级（节点内部管形状形变与位姿变化）。这样：
- 长时程任务推理走图层（低漂移）；
- 抓取/避障等几何推理走节点内几何层；
- L_topo 管实体生灭，几何层管连续变化。
这与"分层想象架构"设想一致，是 EG 走向真实机器人场景的最短路径。

## 补充精读：与 LLM Agent 的关系

EG 的图抽象天然适配 LLM 的符号推理：图可以序列化为文本（节点列表+边列表），LLM 可以读图、提议交互、校验想象结果。一个自然的系统组合：LLM 做任务分解与图级规划 → RWM 做图级想象验证 → 底层策略执行。EG 在这里扮演"LLM 可读的世界模拟器"角色，这是它在 agentic 时代的独特生态位。
