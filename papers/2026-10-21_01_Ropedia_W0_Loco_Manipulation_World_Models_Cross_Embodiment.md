## 一句话总结

Ropedia W0 是首个跨具身（人类/夹爪机器人/灵巧人形机器人）的自我中心 Loco-Manipulation 世界基础模型，用统一显式运动学表征（相机位姿 + 投影骨架）作为动作接口，基于 10k 小时人类自我中心视频 + 3k 小时机器人数据训练，在五个跨具身基准上取得 SOTA，并证明人类视频预训练数据规模可以单调提升人类与机器人双方的预测性能。

## 核心问题

### Q1: 这篇文章的核心算法原理是什么？

#### 1. 核心思想和动机

- **问题背景**：世界模型让具身智能体能够预判动作后果、支持"想象未来"式决策，但现有机器人世界模型几乎都聚焦在**固定底座、夹爪操作**上，存在两大盲区：
  1. **Locomotion 引起的视角变化**：机器人/人在移动时相机视角持续改变，现有世界模型很少建模这种"移动中操作"（loco-manipulation）。
  2. **灵巧手-物体交互**：多数模型只处理平行夹爪，缺少灵巧手的精细建模。
- **跨具身泛化困境**：
  - DreamDojo 在后训练阶段用机器人特定动作替换 latent-action 条件；
  - Cosmos3 虽共享 backbone 但依赖 domain-specific 动作投影；
  - 数值 action token 需要具身特定的编码器。
  - 结论：**每个新具身都需要专用控制接口或额外适配**，无法做到"一个模型走天下"。
- **数据困境**：学习可泛化的世界模型需要大规模、高质量、带丰富多模态标注（相机轨迹、手部动作、任务描述）的自我中心视频。公共自我中心数据集普遍存在：缺公制相机轨迹、手部姿态噪声/缺失、格式异构、规模不足。
- **核心洞察**：人类自我中心视频是廉价且海量的"如何在世界中移动和交互"的经验来源。如果找到一个**对人类和机器人都一致的显式运动学接口**，就能把人类视频当作世界模型的预训练燃料，再迁移到机器人上。

#### 2. 主要技术方法

**(a) 统一显式运动学表征（核心创新）**

- **Locomotion → 公制相机位姿**：用相机 6DoF 位姿序列编码移动引发的视角变化。位姿来自 SLAM 或 DA3 估计，是**公制尺度**的，保证跨数据集一致。
- **Manipulation → 投影骨架（projected skeletons）**：
  - 人类：WiLoR 重建 MANO 手部关键点，投影到图像平面。
  - 机器人：URDF 前向运动学（FK）计算关键点位置，再投影到图像；对 FK 投影不准的公开数据，进行**大量人工关键点标注与修正**。
  - 骨架保留具身特定结构，但以**图像对齐（image-aligned）**的格式呈现，与人类骨架处于同一表示空间。
- **关键性质**：这一接口在人类预训练、人-机器人 mid-training、可选后训练三个阶段**保持完全一致**，不需要为每个具身换接口。

**(b) Xp-Data 数据引擎（human-in-the-loop 流水线）**

五阶段流水线：
1. **数据来源**：14 个公共人类自我中心数据集 + 6,000 小时自采四鱼眼相机数据 + 13 个公共机器人数据集（平行夹爪与灵巧手）。
2. **视频过滤**：VLM 筛除严重模糊、光照不均、过曝/欠曝、抖动过大的片段；丢弃既无相机运动也无手部的片段。
3. **多模态标注**：
   - 几何：相机内参 + 公制轨迹（标定/自研 SLAM/DA3）；Grounding DINO 检测动态区域（手、人）以从轨迹一致性检查中排除。
   - 运动学：人类手部 WiLoR+MANO 投影；机器人关键点 URDF FK + 人工标注/修正。
   - 语义：任务/子任务/原子动作三层级联描述（Gemini 标注、Qwen 校验、人工复核）。
4. **质量检查**：相机轨迹做深度重投影一致性与时序平滑检查；人类手部标注对照 MediaPipe 与微调 MMPose 双检测器交叉验证；机器人关键点由两个在人工标注数据上微调的检测器交叉校验；语义字幕由 Qwen 验证 Gemini 输出。
5. **训练片段构建**：统一切分为 81 帧、640×480、16 fps 的多模态片段。

最终：**~10k 小时人类数据 + ~3k 小时机器人数据**，共享同一 schema；另有 Xp-Teleop 基准（约 1 小时 held-out 长时程灵巧人形 loco-manipulation 遥操作数据）。

**(c) 世界模型本体**

- 视频生成式世界模型（DiT 类 backbone），条件输入为：自我中心视频历史 + 相机位姿序列 + 投影骨架序列 + 语言描述。
- 两阶段训练：
  - **Pretrain**：仅人类自我中心视频。
  - **Mid-train**：人类 + 机器人混合数据。
  - **可选 Post-train**：目标具身/基准的少量或全量数据适配。
- 参数规模：5B 与 A14B 两档。

**(d) 蒸馏与实时交互**

- 蒸馏后支持**实时、分钟级 rollout**，实现跨具身的 **live VR 交互**（人在 VR 中操控机器人身体，模型实时预测未来画面）。

#### 3. 算法流程和关键步骤

```
原始人类/机器人视频
   → VLM 质量过滤
   → 几何标注（SLAM/DA3 公制相机位姿）
   → 运动学标注（MANO 手部骨架 / URDF-FK + 人工修正的机器人骨架，投影到图像）
   → 语义标注（三级任务描述，Gemini+Qwen+人工）
   → 质量检查（重投影一致性、双检测器交叉、人工复核）
   → 统一切片（81帧, 640×480, 16fps）
   → [Pretrain: 人类数据] → [Mid-train: +机器人数据] → [可选 Post-train]
   → [蒸馏] → 实时分钟级 rollout / VR 交互
   → 下游: 策略评估 / 基于模型的规划 / World-Action 建模
```

- World-Action 建模应用：将 W0 预训练的视频 backbone 直接初始化 world-action 模型（而非另加 action head），学习到的动作更鲁棒。

#### 4. 输入输出

- **输入**：自我中心视频历史帧、公制相机位姿序列、投影骨架序列（人类 MANO 或机器人 FK 关键点）、层级任务语言描述。
- **输出**：未来自我中心视频预测（动作条件下的环境演化），蒸馏后可实时生成分钟级长时程 rollout。
- **模型规模**：5B / A14B（激活约 14B）。

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

#### 1. 如何理解和表示空间

- **空间 = 视角 + 身体几何的组合**：Ropedia W0 把空间理解拆成两个正交成分——
  - 相机位姿序列表达"我在空间中如何移动"（自运动 / ego-motion）；
  - 投影骨架表达"我的操作器如何在空间中伸展与作用"（操纵几何）。
- 这是一种**显式、图像对齐、具身无关**的空间-动作中间表示：不同具身（人、夹爪臂、灵巧人形）在同一图像坐标系统中表达运动，模型学到的不再是某个机器人的动作空间，而是"身体在空间中的投影几何如何改变世界"这一普适规律。
- 数据上强调**公制尺度**（metric camera trajectories），说明作者认为空间智能需要绝对尺度而非纯相对几何——这对导航、操作的可执行性至关重要。

#### 2. 如何处理空间关系

- **手-眼-世界三方对齐**：骨架投影天然把操作器关键点锚定在图像坐标系中，与物体、场景在同一像素空间里交互，模型可以直接学习"手移动到画面某处时物体会如何变化"的空间因果。
- **Locomotion 与 manipulation 的耦合建模**：移动改变视角、操作改变物体，二者在长时程中交织。W0 是首批在自回归 rollout 中同时维持两者一致性的工作（30 秒级长时程 rollout）。
- **跨具身空间关系迁移**：人类学会的"伸手-抓握-移动"空间模式可以零样本迁移到机器人骨架上，说明模型学到的是**与具体身体解耦的空间交互结构**。

#### 3. 对 Spatial AGI 的启发

1. **统一动作接口是空间智能规模化的前提**：类似语言模型需要统一 token 空间，空间智能需要统一的"身体-空间"接口。W0 的"位姿+投影骨架"证明了一个显式几何接口可以承载 27+ 种具身。
2. **人类视频是空间智能的最大数据源**：10k 小时人类数据的 scaling 曲线单调上升且**同时改善人类与机器人评估**，印证"人类经验 → 空间智能基础模型"路线的可行性。
3. **Mid-training 的关键作用**：人类预训练 → 人机混合 mid-train 的课程设计让零样本跨具身迁移超过基线全量后训练，提示空间智能训练应刻意设计"数据金字塔"。
4. **显式几何条件优于纯 latent action**：消融显示去掉骨架条件 PSNR 掉 3.8 dB（A14B），去掉相机条件在移动视角具身上掉 1.3 dB——空间条件是预测保真度的根基，latent action 容易把动作与视觉变化纠缠。
5. **世界模型 → 决策的完整闭环**：策略排序、基于模型的规划、world-action 联合训练三个下游应用给出了空间智能落地机器人决策的模板。

#### 4. 可以应用的 Spatial AGI 场景

- **人形机器人训练仿真器**：实时分钟级 rollout + VR 交互 = 可交互的神经世界模拟器，用于遥操作数据采集与策略评估。
- **机器人策略评估器**：用世界模型 rollout 排序策略，替代昂贵的真机评估。
- **长时程操作规划**：想象 30 秒级未来以做 model-based planning。
- **家庭服务机器人**：loco-manipulation 覆盖"走到冰箱前→开门→拿东西"的完整家庭任务链。
- **空间智能预训练基础设施**：Xp-Data 的 schema 可作为社区统一数据格式。

### Q3: 基于前面的分析，这个方法的主要创新点和局限性是什么？

#### 1. 主要创新点

1. **首个跨具身 loco-manipulation 世界基础模型**：首次同时覆盖 locomotion（视角变化）+ manipulation（含灵巧手）+ 跨具身（人类/夹爪/灵巧人形）三个维度。
2. **统一显式运动学接口**：相机位姿 + 投影骨架的图像对齐表示，一个接口通吃人类预训练/人机 mid-train/机器人后训练，无需具身特定 action head。
3. **Xp-Data 大规模统一数据引擎**：10k+3k 小时、含大量人工机器人关键点标注修正的 human-in-the-loop 流水线，是本领域迄今最大的统一标注自我中心-机器人语料。
4. **Xp-Teleop 基准**：首个针对长时程灵巧人形 loco-manipulation 预测的 held-out 基准。
5. **人类数据 scaling 定律**：系统证明人类预训练小时数与人类/机器人预测性能的对数-线性单调关系；人类预训练初始化让 1% 后训练数据超过官方 base 100% 数据的效果。
6. **实时长时程交互**：蒸馏后分钟级实时 rollout + VR 直播交互，把世界模型从"离线评估"推向"在线交互媒介"。

#### 2. 主要局限性

1. **骨架投影依赖人工标注**：机器人关键点的人工标注与修正是重人力环节，扩展到新具身仍有边际成本，与"全自动规模化"愿景有张力。
2. **公制位姿估计的误差传播**：SLAM/DA3 在退化场景（弱纹理、动态遮挡）下的位姿误差会直接进入训练信号。
3. **评估以视频预测为主**：虽有策略排序与规划实验，但"更好的视频预测 = 更好的决策"这一因果链仍未完全闭合，缺乏端到端任务成功率的大规模真机验证。
4. **2D 图像对齐表示的局限**：投影骨架丢失深度信息，遮挡区域的操作几何需要模型自行推断；相比 3D 场景表示（如 3DGS）缺少显式三维结构。
5. **计算成本**：A14B 的训练与（蒸馏前的）推理成本高；实时性依赖蒸馏，蒸馏可能损失长时程一致性。
6. **数据偏差**：人类日常活动视频的任务分布与机器人任务分布存在 gap，mid-train 混合比例是手工设定的超参。

#### 3. 与其他相关工作的对比

| 维度 | DreamDojo | Cosmos3 | AnyWorld | **Ropedia W0** |
|------|-----------|---------|----------|----------------|
| 跨具身 | 后训练换接口 | 共享backbone+专用投影 | 人→机器人重组合 | **统一接口全程一致** |
| Locomotion | 弱 | 弱 | 仅操作 | **原生建模视角变化** |
| 灵巧手 | 部分 | 部分 | 未测 | **原生支持** |
| 人类数据利用 | 部分 | 部分 | 源域 | **10k小时核心燃料** |
| 长时程 rollout | 短 | 短 | 未测 | **~30秒自回归 + 分钟级蒸馏** |
| 实时交互 | 无 | 无 | 无 | **VR live** |

- **优势**：唯一同时解决"移动+操作+跨具身+人类数据规模化"的工作；5B 打赢 14B 基线，数据效率与参数效率俱佳。
- **劣势**：相比 latent-action 方法（如 DreamDojo 的初始版本），显式骨架接口需要更多标注工程；相比 3D 结构化世界模型，空间表示仍是 2.5D 图像平面。

## 核心技术发现

- **发现 1**：去掉骨架条件，A14B/5B PSNR 分别下降 3.8/1.8 dB——操作骨架是预测保真度的最大贡献者。
- **发现 2**：去掉相机条件平均只掉 0.3/0.1 dB，但在有移动视角的具身上掉 1.3 dB 且生成运动减少——相机条件是 loco-manipulation 的关键。
- **发现 3**：单 mid-train checkpoint 零样本预测全部 8 种具身，A14B 达 21.98 PSNR，比同数据微调的 Cosmos3 高约 3 dB。
- **发现 4**：1% 后训练数据下，W0 预训练初始化比官方视频 base 初始化高 4.8-7.1 dB，且超过后者 100% 数据的效果。
- **发现 5**：模型从 5B → A14B，跨具身集合 +2.2 dB、AgiBot +2.3 dB、零样本三基准 +1.4~2.1 dB——数据与模型双 scaling 均有效。

## 与Spatial AGI的关系

### 直接贡献
- 提供了"空间智能 = 视角智能 + 身体几何智能"的可操作分解，并证明该分解可以跨具身共享。
- Xp-Data + Xp-Teleop 为空间智能社区提供了带公制几何与运动学标注的大规模基础设施。

### 技术启发
- 空间智能基础模型应优先设计**显式、图像对齐、具身无关**的空间-动作接口，而非依赖 latent action。
- "人类数据预训练 → 人机 mid-train → 具身后训练"的课程范式可推广到更广的空间任务。

### 应用场景
- 人形机器人神经仿真器、策略评估器、长时程规划器、VR 遥操作界面。

## 个人思考

### 最令人兴奋的发现
- 人类视频 scaling 对机器人迁移的单调增益曲线（Fig. 7）是"人类经验可以蒸馏为机器人空间智能"这一命题迄今最直接的实验证据之一。如果该曲线继续延伸，未来机器人的空间智能上限将由互联网级人类视频决定，而非昂贵的机器人遥操作数据——这将根本性改变具身智能的经济学。
- VR 实时交互展示了世界模型的新角色：它不只是预测器，而是**人机共享的想象空间**——人在其中"住进"机器人的未来。

### 潜在局限
- 2D 投影骨架接口虽然优雅，但可能是一个"局部最优"：它把 3D 结构推断全部推给了模型内部。与 3DGS/占据网格等显式 3D 条件的融合可能是下一代版本。
- 人工标注瓶颈值得警惕：如果每加一个新具身都要几周人工标注，"任意具身即插即用"就有折扣。自动化的具身 FK-视觉对齐（如可微标定）是必要的后续工作。

### 与昨日研究的关联
- 昨天（2026-10-20）精读的 ORD-WM 主张物体中心的刚性动力学 3D 世界建模，T2-z 强调测试时优化环境 latent——三者共同指向一个趋势：世界模型正从"端到端黑箱视频预测"走向"显式结构化条件"（W0 的骨架、ORD-WM 的物体动力学、T2-z 的环境 latent）。显式结构是当前世界模型提升空间一致性与跨域泛化的共同答案。
- 与 LAW（语言-动作-世界统一）呼应：W0 提供了世界侧的统一基础，LAW 式的 agentic 框架可以架在其上。

## 关键数据

- **数据规模**：人类 ~10,000 小时（14 公共数据集 + 6,000h 自采四目鱼眼）；机器人 ~3,000 小时（13 公共数据集）；训练片段 81 帧 / 640×480 / 16 fps。
- **模型规模**：5B 与 A14B 两档。
- **基准**：DreamDojo、Ψ0、ω-HOME、Xp-Teleop、AgiBot 五个跨具身基准 + held-out 人类视频。
- **代表成绩**：
  - Xp-Teleop 零样本 A14B midtrain 16.42 PSNR > 所有基线 full-data 结果（最高 14.98）。
  - ω-HOME 零样本 19.55 PSNR（基线最好 16.24）。
  - 长时程自回归 rollout：ω-HOME ~32s，Xp-Teleop ~30s。
  - AgiBot：A14B 20.88 PSNR（最强基线 18.56）。
  - 蒸馏后实时分钟级 rollout。

## 总结

### 核心发现总结
Ropedia W0 用"相机位姿 + 投影骨架"的统一显式运动学接口，把 10k 小时人类自我中心经验和 3k 小时机器人数据融进单一世界基础模型，首次实现跨具身 loco-manipulation 预测的 SOTA，并通过系统性 scaling 实验证明人类视频是机器人空间智能的可迁移燃料。

### 对Spatial AGI的意义
- 它为 Spatial AGI 提供了一个可复制的配方：**统一空间-动作接口 + 人类视频规模化 + 分阶段课程训练**。
- 长时程实时 rollout + VR 交互预示了空间智能的交互形态：不是被动看视频，而是"进入"模型想象的世界中行动。
- 局限（2D 表示、人工标注、决策闭环）恰好勾勒出下一阶段 Spatial AGI 研究的三条主线：3D 显式条件、自动化具身对齐、世界模型驱动的真机任务成功。

## 附录 A：逐节深度精读

### A.1 摘要精读

摘要的五层信息结构：

1. **问题定义**：世界模型让具身智能体预判动作后果，但"联合建模 locomotion 与 manipulation"跨多样具身仍然困难，原因有二——异构动作空间（heterogeneous action spaces）与多模态监督有限。
2. **方案声明**：Ropedia W0 是**首个**覆盖人类与机器人的自我中心 loco-manipulation 世界基础模型。
3. **数据贡献**：Xp-Data = 10k 小时人类自我中心数据 + 3k 小时机器人数据，带统一多模态标注与系统性质量控制。
4. **接口贡献**：统一运动学表征——locomotion 用相机位姿编码、manipulation 用投影骨架编码；机器人骨架 = 具身特定 FK + 大量人工关键点标注修正。
5. **验证与价值**：五个跨具身基准（DreamDojo、Ψ0、ω-HOME、Xp-Teleop、AgiBot）+ held-out 人类视频上从零样本到少样本到全量后训练均 SOTA；人类预训练数据 scaling 同时改善人类与机器人评估；蒸馏后实时分钟级 rollout 支持 live VR 交互；下游应用覆盖策略评估、model-based 规划、world-action 建模。

### A.2 引言精读：三大矛盾的精确刻画

**矛盾一：固定底座假设 vs 真实具身任务。**
现有模型 [119, 122, 4] 聚焦固定底座夹爪操作。但家庭、仓库等真实场景中，机器人必须先"走到"才能"操作到"。移动引发的视角变化（ego-motion）会让纯操作世界模型的外推完全失效——相机轨迹是操作任务中最大的"协变量"。

**矛盾二：具身异构 vs 单一模型。**
- DreamDojo：post-train 时把 latent action 换成机器人特定动作 → 每个具身后训练一次。
- Cosmos3：共享 backbone 但 domain-specific action projection → 接口不统一。
- 数值 action token：维度/语义因具身而异 → 编码器不可复用。
W0 的回答：把动作翻译成一种"所有身体共有的语言"——图像平面上的几何投影。

**矛盾三：数据稀缺 vs 规模需求。**
公共自我中心数据集的问题清单：
- 缺公制相机轨迹（无法学 ego-motion）
- 手部姿态噪声/缺失（无法学操作）
- 格式异构（无法联合训练）
- 规模不足（无法支撑泛化）

### A.4 数据流水线精读（第3节）

**统计口径定义**（论文脚注，体现工程严谨性）：
- episode（机器人）/ clip（人类）= 连续源录像
- window = 从源录像切出的 81 帧训练样本
- source = 一条 (dataset, end-effector) 流（如 AgiBot World Beta 贡献平行夹爪流 + 灵巧手头相机流两条 source）

**过滤细节**：VLM 检查严重模糊、光照差/不均、过曝欠曝、过度抖动；"既无相机运动也无可见手部"的片段直接丢弃——保证每条数据都同时服务 locomotion 或 manipulation 学习。

**几何标注细节**：
- 优先级：可用标定 > 自研 SLAM > DA3
- Grounding DINO 检测手/人等动态区域，**从相机轨迹一致性检查中排除**——避免动态物体污染静态场景假设。

**人类运动学**：WiLoR → MANO 关键点 → 投影到图像平面。

**机器人关键点人工工程**（论文坦承的核心人力投入）：
- 公开机器人录像的 FK 投影常与画面中夹爪/手错位，很多发布甚至缺可靠相机标定
- 流程：FK 给初始估计（有 joint states + 标定时）→ 人工标注或精修图像对齐骨架

**质量检查四道关**：
1. 相机轨迹：深度重投影一致性 + 时序平滑 [110]
2. 人类手部：几何 + 语义双查（3D 投影 vs MediaPipe 与微调 MMPose 的独立 2D 检测；VLM 排除他人之手）
3. 机器人关键点：两个在人工标注数据上微调的检测器交叉恢复/去重
4. 语义：Gemini 生成 → Qwen 校验 → 人工仲裁

## 附录 B：方法论批判性评估

### B.1 实验设计的强点

1. **评估矩阵完整**：5 基准 × 3 后训练预算（0/few/full）× 2 规模 × 2 训练阶段 = 系统性覆盖，避免了"只报最好配置"的 cherry-picking。
2. **匹配比较公平**：与 Cosmos3 在相同机器人混合数据上微调后比较，排除"基线没喂够数据"的质疑。
3. **seen/unseen 拆解**：Xp-Teleop 拆 seen/unseen 场景，后训练同步提升两者 → 证明是适配而非记忆。
4. **消融定位明确**：两个条件各自的贡献分别量化，且区分"平均效应"与"移动视角子集效应"。

### B.2 潜在实验弱点

1. **PSNR 导向**：视频世界模型评估以 PSNR/SSIM/LPIPS/FVD 为主，这些指标对物理合理性（穿模、力反馈）不敏感；PVBench 类物理测量指标未使用。
2. **Xp-Teleop 规模小**：仅约 1 小时 held-out 数据，长时程评估的统计功效有限。
3. **真机决策验证薄**：策略排序、规划实验在仿真/离线为主，端到端真机任务成功率未系统报告。
4. **midtrain 混合比例未消融**：人:机数据比例是关键超参但未见系统扫描。
5. **A14B "A" 含义**（推测为激活参数）：与稠密基线的参数公平性对比需谨慎解读。

### B.3 对领域的战略含义

1. **接口之争的阶段性答案**：latent action（便宜但纠缠）vs 数值 token（精确但异构）vs 显式几何投影（本文，折中：精确、统一，但要标注）。W0 的胜出说明当前阶段"标注换性能"是划算的。
2. **人类数据飞轮确立**：一旦"人类视频 → 机器人能力"的 scaling 被确立，数据竞争将转向自我中心视频的采集与标注基础设施。
3. **VR 交互作为新数据引擎**：live VR rollout 本身可以产生新的遥操作数据，形成"世界模型 ⇄ 数据"正循环。

## 附录 G：Spatial AGI 视角的延伸推演

### G.1 从 W0 反推空间智能的分层架构

```
L4 决策层    策略评估 / 规划 / world-action 联合训练      ← W0 下游应用
L3 预测层    动作条件世界模型（视频 rollout）              ← W0 本体
L2 接口层    统一空间-动作表示（位姿+骨架投影）            ← W0 核心创新
L1 数据层    公制几何 + 运动学 + 语义统一标注              ← Xp-Data
L0 感知层    SLAM / 手部重建 / 检测（DA3, WiLoR, DINO）    ← 现成工具栈
```

**洞察**：W0 的贡献集中在 L1-L2。这印证当前 Spatial AGI 的瓶颈不在模型结构（L3 以上日趋同质化：都是 DiT 视频骨干），而在**统一表示与数据基础设施**。

### G.2 空间智能的"token 时刻"何时到来？

NLP 的爆发依赖统一 token 化。W0 的投影骨架像是空间智能的"前-token"尝试：
- 优点：图像对齐、具身无关、可视化调试
- 缺点：2D、丢深度、需人工标注
- 可能的"真 token"：以 3D 关键点序列 / 3DGS 增量 / 场景图操作为原子单元的离散化空间-动作语言。W0 的 scaling 成功会加速这一方向的探索。

### G.3 对"世界模型评估"的思考

W0 的下游实验实际在回答一个问题：世界模型的预测质量能否代理真机表现？其策略排序实验是积极信号，但从"排序正确"到"成功率预测"还有距离。Spatial AGI 社区需要的是一个"世界模型 → 决策成功率"的校准基准——谁能建立它，谁就掌握下一代具身评估话语权。

### G.4 风险与伦理速记

- 大规模自我中心视频涉及隐私（路人面孔、私人空间），论文未讨论数据合规细节。
- 实时 VR rollout 若用于遥操作，预测与真实的偏差可能带来操作安全风险（模型"脑补"的物体状态 ≠ 真实）。
- 人类数据 scaling 若延续，少数机构的数据护城河会加深，值得社区关注开源替代。
