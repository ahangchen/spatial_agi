# SkillMemo: Expert-guided Skill Memory Framework for Compositional Embodied Manipulation

**arXiv**: 2026-08-06 | **Subjects**: cs.RO, cs.AI

**Authors**: Changyuan Wang, Chubin Zhang, Zhenyu Wu, Runhao Li, Angyuan Ma, Ke Chao, Yinan Liang, Xiuwei Xu, Ziwei Wang, Yansong Tang, Jiwen Lu

---

## 论文概述

Embodied visuomotor models, including Diffusion Policy (DP) and Vision-Language-Action (VLA) models, have demonstrated promising performance on robotic manipulation benchmarks. However, their potential remains fundamentally constrained by the scarcity of large-scale expert demonstration data. SkillMemo提出了一种**专家引导的技能记忆框架**，通过将专家技能分解、存储为可组合的技能原语，实现 compositional embodied manipulation。

---

## Q1: 核心算法原理

### 1.1 核心思想和动机

**核心问题**: 
- VLA/DP模型需要大量专家演示数据
- 长horizon复合任务难以端到端学习
- 已学技能在新任务中难以迁移复用

**核心思想**: 
- 将复杂操作任务分解为可复用的技能原语（skill primitives）
- 使用记忆机制存储和检索技能
- 通过组合技能原语完成新的复合任务

**关键洞察**: 专家演示中包含大量可复用的子技能模式。通过显式提取和存储这些模式，可以大幅减少新任务所需的训练数据。

### 1.2 主要技术方法

**SkillMemo框架包含三个核心组件**：

1. **技能提取模块（Skill Extraction）**:
   - 从专家演示中自动发现和提取技能原语
   - 使用时序分割将长轨迹分解为短技能片段
   - 每个技能原语包含：视觉观测、动作序列、前件/后件条件

2. **技能记忆库（Skill Memory Bank）**:
   - 结构化存储技能原语
   - 基于语义和空间特征的索引
   - 支持高效检索和匹配

3. **技能组合执行器（Compositional Executor）**:
   - 根据任务描述检索相关技能
   - 规划技能执行顺序
   - 处理技能间的过渡和参数传递

### 1.3 算法流程

```
输入: 任务描述T + 环境观测O
输出: 动作序列A

训练阶段:
1. 从专家演示D中提取技能:
   For each trajectory τ in D:
     - 时序分割：{s₁, s₂, ..., sₖ} = Segment(τ)
     - 技能编码：eᵢ = Encode(sᵢ)
     - 前件/后件提取：(preᵢ, postᵢ) = ExtractConditions(sᵢ)
   存储到技能记忆库M

推理阶段:
1. 技能检索: {m₁, ..., mₙ} = Retrieve(M, T, O)
2. 技能规划: plan = Plan(T, {m₁, ..., mₙ}, O)
3. 技能执行:
   For each step in plan:
     - 加载技能参数
     - 条件检查
     - 执行动作
     - 更新状态
```

### 1.4 输入输出

- **训练输入**: 专家演示轨迹（视觉观测+动作序列）
- **推理输入**: 任务描述（自然语言）+ 实时环境观测
- **输出**: 连续动作序列

## Q2: 与Spatial AGI的关系

### 2.1 空间理解与表示

SkillMemo在多个层面处理空间信息：

1. **技能空间表示**: 每个技能原语包含空间上下文（物体位置、机械臂构型）
2. **空间条件**: 技能的前件和后件包含空间约束（如"物体在桌面上"→"物体在手中"）
3. **空间索引**: 技能记忆库使用空间特征进行检索
4. **空间泛化**: 学到的技能可以在不同空间配置下复用

### 2.2 空间关系处理

- **物体-物体关系**: 技能可以编码物体间的空间操作（如堆叠、排列）
- **物体-机器人关系**: 技能包含机器人与物体的空间交互模式
- **空间坐标变换**: 技能在不同空间坐标下的适应性

### 2.3 对Spatial AGI的启发

1. **技能库作为空间知识库**: 技能记忆库本质上是一种程序性空间知识库
2. **组合性**: 复杂空间任务可以通过组合简单空间技能完成
3. **记忆架构**: 为Spatial AGI提供了可复用的技能存储和检索机制
4. **专家引导**: 从专家演示中学习是获取高质量空间技能的有效途径

### 2.4 可应用的Spatial AGI场景

1. **通用机器人操作**: 家庭服务机器人的日常操作技能
2. **工业自动化**: 复杂装配任务中的技能复用
3. **多步骤实验**: 生物/化学实验室自动化
4. **空间规划**: 长horizon空间任务规划

## Q3: 创新点与局限性

### 3.1 主要创新点

1. **显式技能记忆**: 将隐式的技能学习转化为显式的技能存储和检索，大幅提高技能复用效率
2. **专家引导分解**: 从专家演示中自动发现技能边界，不需要人工标注
3. **组合执行**: 支持将多个技能原语组合为复杂操作流程
4. **前件/后件条件**: 使用前置和后置条件实现技能的可靠链接
5. **空间泛化**: 技能不绑定到特定空间位置，可在新环境中复用

### 3.2 局限性

1. **依赖专家演示**: 需要高质量的专家演示数据来初始化技能库
2. **技能分割质量**: 自动时序分割可能在错误边界导致技能质量下降
3. **检索精度**: 复杂场景下的技能检索可能不准确
4. **过渡处理**: 技能间的平滑过渡仍具挑战性
5. **规模限制**: 随技能库增长，检索效率可能下降
6. **动态环境**: 未充分验证动态变化环境下的表现

### 3.3 与相关工作的比较

| 方法 | 技能表示 | 复用方式 | 组合能力 |
|------|---------|---------|---------|
| 端到端VLA | 隐式 | 不可 | 无 |
| DP + 技能库 | 显式技能 | 检索 | 有限 |
| 期权学习 | 期权策略 | 层次 | 中等 |
| **SkillMemo** | **记忆+条件** | **检索+泛化** | **强** |

## Spatial AGI视角的深度思考

### 1. 程序性空间记忆

SkillMemo的技能记忆库可以看作是Spatial AGI的**程序性空间记忆**——存储"如何做"的空间知识，与陈述性空间记忆（"是什么"的空间知识）互补。

### 2. 技能层次化

未来可以构建层次化的技能库：
- 原子技能：抓取、放置、推动
- 复合技能：倒水、开抽屉
- 任务级技能：做三明治、整理桌面

### 3. 与world model的结合

技能记忆可以与world model结合：
- World model预测技能执行后的世界状态
- 基于预测选择最优技能
- 形成model-based的技能规划

### 4. 跨具身迁移

技能的抽象表示（前件/后件+空间约束）为跨具身迁移提供了可能——不同机器人可以使用相同的技能描述。

---

## 总结

SkillMemo通过专家引导的技能记忆框架，为embodied manipulation提供了可组合、可复用的技能管理方案。其对Spatial AGI的核心贡献在于展示了如何将复杂空间操作分解为可管理的技能原语，并通过记忆机制实现高效复用。这种程序性空间记忆的概念对构建通用Spatial AGI系统具有重要意义。
