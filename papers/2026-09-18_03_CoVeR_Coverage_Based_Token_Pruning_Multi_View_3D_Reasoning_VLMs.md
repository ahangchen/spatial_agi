## 一句话总结

把 3D 场景表示为多视角图像喂给 2D VLM 时，视觉 token 数随视角线性爆炸。已有剪枝方法两大家族都有硬伤：学习型重要性打分（attention/特征）会留下近重复 token、场景大部分区域无人代表；体素化方法改善覆盖但无法保证精确的每场景 token 预算，且在多视角重叠下饱和（只能降到约 69%）。CoVeR 用一个确定性、training-free、只用几何坐标的两阶段选择器（自适应体素初始化 + FPS 覆盖扩展）解决两者：保证精确每场景预算、突破饱和上限、避免重复选择——仅约 8% 的 token 保留 93.5% 的全 token 性能，三个 3D 推理基准（ScanQA/SQA3D/OpenEQA）平均超 SOTA 3.9 个百分点，跨 4 个 VLM 即插即用。

## 核心问题

### Q1: 这篇文章的核心算法原理是什么？

**问题**：这篇文章的核心算法原理是什么？请详细描述：1) 核心思想和动机，2) 主要技术方法，3) 算法流程和关键步骤，4) 输入输出。

**分析**：

#### 1. 核心思想和动机

3D-语言数据比互联网级图文数据少几个数量级，直接大规模训练 3D 表示受数据限制。实用替代：把 3D 场景渲染成多视角图像，让预训练 2D VLM 直接推理，继承其视觉-语言先验。代价是**视觉 token 线性爆炸**：12 视角在 LLaVA-OneVision-7B 产生 8,748 个视觉 token，LLM 推理成本剧增。剪 token 成为多视角 3D 推理的刚需。

**对已有方法的批判性分析**（本文的问题学贡献）：

- **学习型重要性剪枝**（attention 排序、视觉特征排序、辅助编码器）：冗余在多视角 3D 中本质是**几何的**——不同相机拍到同一物理区域。与几何无关的重要性分数会把预算花在近重复 token 上，而场景其他位置的独特物体/边界欠代表。且信号是模型特定的，跨架构不迁移。
- **体素化剪枝**（VTC/DTC）：把 token 反投影到 3D 体素、同体素合并。覆盖改善了，但两个致命问题：
  1. **无法精确控制输出数量**：token 数 = 占据体素数 G(v_s)，由场景几何决定而非预算决定。固定 v_s=0.2m、目标 B=1342 时，56% 场景低于预算、44% 超出——单场景可能超出内存/延迟上限，即使数据集平均达标；
  2. **体素占据饱和**：约 31% 的 token 是跨视角对同一表面的近重复观测，把 v_s 降到 0.02m 也没法再分离，保留率卡在约 69% 平台；高冗余场景饱和在 46-57%。

**核心洞察**：空间覆盖与 3D 推理性能相关。最优形式化是**离散欧氏 k-center 问题**：在恰好 B 个保留 token 的约束下，最小化有向 Hausdorff 距离 d_H(X,C) = max_t min_{j∈C} ||t−t_j||——即"被代表得最差的 token 离任何保留 token 有多远"。小 d_H 认证"没有区域被整体丢弃"，这正是学习型方法给不了的保证。

#### 2. 主要技术方法

CoVeR = 确定性、training-free、纯几何（只用 token 的 3D 反投影坐标，无 attention、无特征、无学习信号）的两阶段选择器：

**Stage 1 覆盖初始化（自适应体素化）**：
- 超参 α∈(0,1) 定 stage 1 目标 B_init = max(1, ⌊αB⌋)；
- 对体素尺寸 v_s 做**逐场景二分搜索**（区间 [0.02, 5.0] m，最多 T=16 次，容差 τ=0.05），使占据体素数 G(v_s) 落入 (1±τ)B_init；
- 每个占据体素保留一个代表 token：取体素内"离其他 token 均值最近"的 token（几何中心代理，避免边界 token 破坏均匀性）；
- 安全阀：若 |C_init|>B，保留 B 个人口最多体素的代表（实际实验中该分支从未触发）。

**Stage 2 覆盖扩展（体素初始化的 FPS）**：
- 剩余预算 B_expan = B − |C_init|；
- 从 C_init 出发做最远点采样（Farthest Point Sampling）：每轮加入"离当前已选集合最远"的 token——即把 token 放到当前覆盖最弱的地方；
- FPS 天然是覆盖导向的，与体素化互补：体素化便宜、一步铺开全场但数量受分辨率封顶；FPS 可变数量但冷启动慢。体素初始化让 FPS 第一跳就测"到已覆盖区的距离"，只去未覆盖区。

**与 VLM 集成**：即插即用模块，紧跟视觉编码器之后选 token 索引 C；所有 token 仍过 projector，投影后仅 C 索引的特征进入 LLM，保持原始序列顺序。不改动 token 布局，兼容任何 projector 保持逐 token 对应的 VLM（实验测了 4 个）。

**精确预算的三情况保证**：(1) |C_init|<B → stage 2 补足（全部实测场景处于此 regime）；(2) 相等 → stage 2 为空；(3) 超出 → 安全阀。无论如何，输出恰好 B 个。

#### 3. 算法流程和关键步骤

```
输入: 带位姿 RGB-D 多视角 + 冻结视觉编码器产生的 M 个 patch token
      （每个已反投影到世界坐标 t_i）+ 预算 B
Step 1  B_init ← max(1, ⌊αB⌋)
Step 2  Stage 1: 二分搜索逐场景体素尺寸 v_s（T≤16 次）
        → 每占据体素选中心代表 token → C_init（粗覆盖）
Step 3  安全阀: 若超预算，取人口最多体素的代表
Step 4  Stage 2: 从 C_init 出发 FPS 迭代 B_expan 次
        → 每次加入离已选集最远的 token（补覆盖盲区）
Step 5  输出 C（|C|=B，保持原序列顺序），投影后送入 LLM
```

#### 4. 输入输出

- **输入**：多视角 RGB-D 图像、相机位姿、冻结 VLM 视觉编码器输出的 token 坐标、目标预算 B、比例 α。
- **输出**：恰好 B 个 token 索引（确定性、与模型无关），其 3D 位置 collectively 覆盖整个场景。
- **收益**：ScanQA 14% 保留率下 LLM TFLOPs 降 8.6×、KV cache 降 7×、GPU 显存降 1.4×、推理加速 2.5×，相对精度仅降 1.1%。

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**问题**：这篇文章与通用空间智能（Spatial AGI）有什么关系？请分析：1) 如何理解和表示空间，2) 如何处理空间关系，3) 对Spatial AGI有什么启发，4) 可以应用到哪些Spatial AGI场景。

**分析**：

#### 1. 如何理解和表示空间

CoVeR 处理的是"**token 的空间化**"问题：2D VLM 的 patch token 本身没有空间含义，但借助深度与相机位姿反投影，每个 token 获得 3D 世界坐标——场景从"图像集合"变成"带语义的 3D 点云"。CoVeR 的贡献是指出：这个点云上的信息选择问题应该用**空间覆盖几何**（k-center/Hausdorff）来定义，而不是用数据驱动的显著性来定义。

这隐含着一个关于空间理解的主张：**对 3D 推理而言，"每个地方都被看到"比"重要地方被反复看到"更重要**。空间问题的答案常常藏在任意角落（"沙发后面的地上有什么"），空间智能的注意力预算应该均匀铺开再按需加密，这与单图理解的显著性驱动注意力根本不同。

#### 2. 如何处理空间关系

- **跨视角对齐**：token 坐标统一到世界系后，近重复观测（同区域多视角）被自动识别并在 stage 1 去重——空间关系（视角间对应）被用于消除信息冗余；
- **覆盖度量**：有向 Hausdorff 距离把"表征完整性"变成可优化的几何量——空间关系的处理从隐式（attention 学出来）变为显式（几何计算出来）；
- **覆盖与重要性的兼容**：统计显示 CoVeR 的保留集也覆盖了学习型方法偏好的区域（有向距离分析），说明空间覆盖是比 saliency 更基础的量——重要区域自然有独特几何位置，覆盖优化会自动留住它们。

#### 3. 对 Spatial AGI 的启发

1. **几何先验优于学习信号的选择场景**：在冗余本质是几何的任务里，确定性几何算法（二分体素 + FPS）打败了端到端学习的打分器——简单、可证明、跨模型零成本迁移。Spatial AGI 的很多"中间件"问题（token 选择、视角选择、关键帧选择）可能都属此类。
2. **预算工程是空间智能的硬约束**：LLM 的上下文窗口、KV cache、延迟都是有限资源，"每场景精确预算"比"平均预算"重要得多——具身 agent 单次任务的资源超支即失败。CoVeR 的精确预算保证是系统工程级的贡献。
3. **覆盖指标作为评估工具**：d_H 可以反向用作诊断——衡量一个多视角观测集、一个 token 化方案、甚至一个 agent 的探索路径对场景的覆盖质量。
4. **Scaling 的乘法门**：8% token 保留 93.5% 性能，意味着多视角 3D 推理的视角数上限可以再翻数倍——空间智能系统可以同时用更多视角（更好的覆盖）与更低成本（剪枝），覆盖与规模不再互斥。

#### 4. 可以应用的 Spatial AGI 场景

- **具身问答/场景理解**：ScanQA、SQA3D、OpenEQA 直接受益，机器人边走边问；
- **多视角 VLM 的所有下游**：空间规划、导航指令理解、场景描述、变化检测；
- **长视频/大规模视角流**：视角数不受 token 预算限制后，可处理数十上百视角的场景文档化；
- **边缘部署**：KV cache 降 7× 使多视角 3D 推理上手机/机器人端侧成为可能；
- **与 SLAM 结合**：SLAM 关键帧的 token 选择（与 SCOUT/PanoGS 类系统的组合）。

### Q3: 基于前面的分析，这个方法的主要创新点和局限性是什么？与其他相关工作相比有什么优势和劣势？

**分析**：

#### 1. 主要创新点

1. **问题形式化**：首次把多视角 3D token 剪枝明确形式化为精确预算约束下的 k-center 覆盖问题，并用有向 Hausdorff 距离给出可优化的目标；
2. **双家族缺陷的系统诊断**：体素化（无精确预算 + 饱和平台 69%）vs 学习型重要性（近重复 + 模型特定），量化证据充分（31% 重叠率、44% 场景超预算等）；
3. **两阶段互补算法**：自适应体素初始化（便宜的全局粗覆盖）+ 体素初始化 FPS（精确补盲区），确定性、training-free、纯几何；
4. **精确每场景预算保证**：三情况覆盖 + 安全阀，工程级严谨；
5. **强实证**：8% token → 93.5% 性能，三基准平均 +3.9pp，跨 4 VLM 泛化，8.6× TFLOPs / 7× KV cache 节省。

#### 2. 主要局限性

1. **依赖 RGB-D 与位姿**：token 反投影需要深度和相机位姿；纯 RGB 多视角（无深度）场景需要额外深度估计，误差会传播到坐标进而破坏覆盖假设；
2. **均匀覆盖未必最优**：k-center 均匀覆盖假设"每个区域同等重要"，但问题相关时（如"桌上是什么"）注意力本该集中；CoVeR 不利用语言条件做非均匀分配（这正是它模型无关的代价）；
3. **静态场景假设**：token 坐标是静态世界系；动态物体/多时刻观测的处理未涉及；
4. **剪枝只省 LLM 侧**：视觉编码器仍要处理全部视角图像，编码端成本不变；
5. **k-center 的近似性**：FPS 是 k-center 的贪心近似（2-近似界），非全局最优。

#### 3. 与其他相关工作的对比

| 维度 | CoVeR | VTC/DTC（体素化） | SeGPruner/VisPruner（attention） | Geo3DPruner（VGGT 编码器） |
|---|---|---|---|---|
| 使用学习信号 | 无 | 无（VTC 特征平均） | attention + 特征 | attention + 重训 VGGT |
| 确定性 | ✓ | ✓ | 部分 | ✓ |
| 精确每场景预算 | ✓ | ✗ | ✓ | ✓ |
| 覆盖保证（d_H 有界） | ✓（目标即此） | 隐式 | 无 | 无 |
| 跨模型迁移 | 即插即用 | ✓ | 需 attention 访问 | 需重训 |
| 预算下限 | 任意（突破饱和） | ~69% 平台 | 任意 | 任意 |
| 计算开销 | 二分 16 次 + FPS，极轻 | 轻 | 中 | 重（大编码器） |

**优势**：唯一同时做到"精确预算 + 覆盖保证 + 零学习信号 + 跨模型迁移"的方案；性能与效率双 SOTA。
**劣势**：无语义/任务自适应性（对特定问题的信息集中不如 attention 方法）；依赖深度位姿输入质量。

## 个人思考

### 最令人兴奋的发现

"31% 的 token 是跨视角近重复"这个数字值得所有做多视角/VLA 系统的人记住——不剪枝的话，接近三分之一的算力在重复计算同一物理表面。更妙的是这个问题用 1970 年代的 k-center 贪心（FPS）加二分体素就能解决到 SOTA：**空间智能的很多瓶颈不在模型容量，而在经典几何算法的缺席**。

另一个深刻的信号是"纯几何打败学习打分器"。这暗示 attention 在多视角 3D 设定下并没有学到真正的空间显著性——它学的是单图统计先验。在空间任务上，显式几何先验可能比隐式学习先验更接近正确的归纳偏置。

### 潜在局限

均匀覆盖是双刃剑：它给了"没有区域被丢弃"的保证，但也放弃了任务自适应。真正的空间智能系统最终需要"覆盖保底 + 任务聚焦"的两层预算：先用 CoVeR 保证场景完整表征，再按问题用轻量语义加权微调——但要小心别退回模型特定老路。另外 RGB-D 依赖在真机上是现实约束，单目深度的尺度漂移会直接扭曲覆盖度量。

### 与今日其他论文的关联

- **NormLift**（今日 01）与 CoVeR 是同一栈上的互补两层：NormLift 决定"token 的语义如何提升到 3D 基元"，CoVeR 决定"哪些 token 值得进入 LLM"。两者都强调与下游消费几何一致（球面余弦 vs k-center 覆盖），可以视作"空间中间件理论化"趋势的两个实例；
- **SoftNav**（今日 04）把 3D 场景 token 注入 VLM 隐层做导航；CoVeR 的选择器可以直接套在 SoftNav 的实体 token 上——1,200 样本训练出的 projector 之前先做几何剪枝；
- **PanoGS-SLAM**（今日 02）提供在线几何底座，其关键帧的高斯/像素坐标正是 CoVeR 式选择的天然输入。

## 总结

### 核心发现总结

CoVeR 把多视角 3D token 剪枝形式化为精确预算下的 k-center 覆盖问题，用"自适应体素初始化 + 体素初始化 FPS"的确定性两阶段纯几何方案，同时解决学习型方法的近重复缺陷与体素化方法的预算失控/饱和缺陷，以 8% 的 token 保留 93.5% 的推理性能并全面超越 SOTA。

### 对Spatial AGI的意义

它证明了空间智能系统中"几何驱动的确定性中间件"是一条可行且常常优于学习信号的路线，并把"空间覆盖"确立为可优化、可认证的表征质量指标。对于需要把 VLM 推向多视角、实时、端侧的 Spatial AGI 系统而言，这是一个立即可用的效率杠杆。

## 扩展分析：方法细节深挖

### A. k-center 问题的近似保证

有向 Hausdorff 距离最小化等价于离散欧氏 k-center：选 B 个中心使最大覆盖半径最小。FPS 是经典的 2-近似贪心：记 OPT 为最优半径，则 FPS 的最终半径 ≤ 2·OPT。虽然论文未强调这个理论界，但它给 CoVeR 的覆盖质量提供了隐式保证：任何场景中最差被代表的 token 距离最近保留 token 不超过最优值的两倍。

### B. 二分搜索的合理性辩护

占据体素数 G(v_s) 理论上对 v_s 不单调（不同尺度体素网格不嵌套），二分搜索因此是启发式而非精确求根。但论文观察到实证单调趋势（v_s 越小 G 越大，直至饱和），加上：

- 固定区间 [0.02, 5.0] m 由室内场景尺度一次性确定；
- T=16 次迭代足以跨整个区间；
- 三情况预算保证使搜索终点误差不影响输出数量；

工程上稳健。这是"理论不完美 + 工程保底"的务实设计范例。

### C. 代表 token 选择的细节

每体素选"离其他 token 均值最近的 token"而非随机或第一个：均值中心代理避免选到体素边界的 token——边界 token 可能与相邻体素的代表靠得很近，破坏选择的均匀性，恶化 d_H。这个细节体现了覆盖目标贯穿到每个微观决策。

### D. 体素初始化 FPS 的关键性

冷启动 FPS 从随机单点开始，前几步选择近乎任意，收敛到均匀分布慢。体素初始化让 FPS 的第一步就拥有全局粗覆盖，后续每步的"最远点"计算都是相对整个已覆盖集的——等效于把 FPS 的探索阶段外包给便宜的体素化。两阶段的耦合不是简单拼接而是互补加速。

### E. 与 VLM 集成的兼容性设计

保留"所有 token 过 projector、投影后再选"的做法有两个好处：

1. projector 的逐 token 对应性假设最小化（多数 VLM 满足）；
2. 不触碰视觉编码器的 batch 维信息流，剪枝完全在 LLM 入口处发生。

代价是 projector 的计算没有节省——但 projector 相对 LLM 是小头，这个取舍合理。

## 扩展分析：实验结果的深层解读

### F. 三个基准代表三种能力

- **ScanQA**：空间场景理解（基于 ScanNet 的自然语言问答）——测 3D 常识与定位；
- **SQA3D**：situated reasoning（给定情境描述的 3D 问答）——测视角化情境推理；
- **OpenEQA**：具身问答（来自真实视频流的问题）——测开放世界场景记忆。

CoVeR 在三者上同时领先，说明覆盖假设不挑任务类型：不管问题问的是物体、关系还是情境，"全场都有代表"都是正确的先验。

### G. 激烈预算下的表现

性能差距在温和预算（50%+）下各方法接近，在激进预算（<15%）下 CoVeR 优势拉大——这正是两大家族失效模式被放大的区间：体素化撞上饱和平台无法继续下降，学习型方法的重要 token 重复浪费预算。工程上最重要的恰恰是激进区间：端侧部署需要 8-15% 保留率。

### H. 跨 VLM 泛化的含义

在 4 个架构各异的 VLM 上零调参迁移，证明选择器捕捉的是**数据的性质**（空间冗余结构）而非**模型的性质**（attention 分布）。这与学习型剪枝形成根本对照：后者的每次模型更换都要重新校准。

### I. 阶段消融的启示

论文的阶段分析显示：真实 token 优于合并特征（VTC 的合成 token 会丢失高频细节），纯空间距离优于学习信号。两条证据共同支持"保留原始 token + 几何选择"的设计。

## 扩展分析：对 Spatial AGI 研究路线的启示

### J. 空间中间件的"确定性优先"原则

CoVeR 与 NormLift（今日 01）共同指向一个设计准则：当问题的冗余/一致性结构本质是几何的，优先用确定性几何算法，把学习信号留给真正需要语义的地方。空间智能系统栈可以画一条分界线：

- **几何层**（坐标、覆盖、一致性、可见性）→ 确定性算法（FPS、k-center、Hausdorff、二分）
- **语义层**（物体识别、关系推理、语言对齐）→ 学习模型（VLM、3D-LLM）

跨界是允许的（语义引导非均匀覆盖），但默认应该从确定性侧开始，只在证明必要时才引入学习。

### K. 预算作为一等公民

具身系统的资源预算（token、延迟、显存、能耗）必须在每场景粒度上被保证，而非数据集平均。CoVeR 的"精确预算三情况"模式可以复制到：视角数量预算、SLAM 关键帧预算、语义查询预算、世界模型 rollout 步数预算。任何"平均达标"的系统设计都藏着单场景超支的尾部风险。

### L. 覆盖度量的泛化

有向 Hausdorff 距离可以泛化为空间智能的通用表征质量指标：

- 评估多视角采集路径的完整性；
- 评估 token 化/关键帧/地图稀疏化的信息损失上界；
- 评估 agent 探索行为的场景覆盖率（与主动探索结合）。

它便宜、可微变体可推导、有 2-近似理论支撑，具备成为"空间 FID"的潜质。

## 常见问题（FAQ）

**Q1: CoVeR 需要深度精确吗？**
覆盖度量对深度尺度误差敏感但宽容：k-center 只关心相对距离结构，小尺度误差对覆盖排序影响有限。大幅深度误差（单目深度的尺度漂移）会扭曲体素划分，建议配合 SLAM/深度一致性检查。

**Q2: 与 text 条件剪枝（按问题选 token）冲突吗？**
不冲突而是分层：CoVeR 保证场景级覆盖基线，text 条件可以在预算内做局部加密。但要注意引入 text 条件就重新引入了模型相关性。

**Q3: 编码器开销怎么算？**
视觉编码器仍处理全部视角。若编码器本身成为瓶颈，可与帧级预筛（如模糊/重复帧丢弃）串联——CoVeR 解决的是 LLM 侧的 token 冗余。

**Q4: FPS 计算复杂度？**
朴梦 O(B·M)，带 KD-tree/网格加速可大幅降低；相对一次 LLM 前向可忽略。

**Q5: 动态场景怎么办？**
当前静态世界系。动态场景需要时间维扩展：token 坐标加时间戳，覆盖目标在时空体素上定义——概念上直接，工程上待做。

## 对后续研究的具体建议

1. **语义自适应覆盖**：在保底均匀覆盖之上加轻量语言条件加权，量化"任务聚焦 vs 模型无关"的 trade-off；
2. **时空扩展**：token 坐标加时间维，处理动态场景与长视频；
3. **与 Soft projector 联动**：与 SoftNav 类 3D token 注入方法组合，在更少 token 下验证导航性能；
4. **覆盖引导的主动探索**：把 d_H 作为探索价值函数，让 agent 主动补覆盖盲区；
5. **理论深化**：把 FPS 2-近似界与 3D 推理性能损失联系起来，建立覆盖半径-精度损失的理论曲线。

## 风险与反思

- **RGB-D/位姿依赖**：无深度场景需额外深度估计，引入新的误差源；
- **静态假设**：真实具身环境的动态性未覆盖；
- **编码端未省**：端到端效率收益受视觉编码器成本拖底；
- **均匀覆盖的语义盲区**：极端语言条件下的任务相关区域可能被稀释。

## 深度问答与批判性检验

### Q: 为什么学习型重要性方法在多视角场景失效得这么彻底？
因为它们的评分函数在单图内是合理的（显著性、注意力集中处重要），但多视角下同一物理区域被反复高分打标——评分函数缺乏跨视角去重机制。本质是把单图先验错误外推到多图设定。这提示：任何 token 级打分器迁移到新设定时，都要先问"冗余结构变了吗"。

### Q: 8% 保留 93.5% 性能，剩下的 6.5% 损失是什么类型的？
推测主要是细粒度与计数类问题：覆盖剪枝保留的是空间骨架，丢失的是重复纹理细节与微小物体的完整证据。任务侧证据：涉及空间布局与物体定位的问题几乎无损，细节描述类问题有更大下降。这也指明了语义自适应第二阶段的用武之地。

### Q: 体素饱和的 69% 平台是普适常数吗？
不是。它取决于视角重叠度：房间级 ScanQA 数据约 31% token 重复；视角更密（视频流、环绕拍摄）重叠率更高、平台更低；视角稀疏则平台更高。平台值是数据采集几何的函数——这个依赖性本身就值得在论文中更显式地建模。

### Q: 二分搜索 16 次迭代会不会成为延迟瓶颈？
每次迭代是一次体素计数（哈希/排序，M 个 token，毫秒级），16 次总计仍在几毫秒量级，相对 LLM 前向（百毫秒-秒级）可忽略。且 v_s 搜索可按场景缓存，同场景多查询复用。

### Q: 与简单的"每 N 个 token 抽 1 个"均匀子采样相比优势在哪？
均匀子采样在图像网格上均匀，但 token 的 3D 分布不均匀（多视角重叠区 token 密度高），网格均匀 = 空间不均匀。CoVeR 在 3D 空间中均匀，这才是推理需要的均匀。论文的基线对比应该包含这一项——它是 spatial pruning 价值的最直接证明。

## 给工程师的实施要点

1. α 的选择权衡：α 大则体素化承担更多（快但受饱和限制），α 小则 FPS 主导（覆盖更精但稍慢）；典型 α≈0.5-0.7；  
2. token 坐标反投影只需一次，多轮对话缓存复用；  
3. 部署前先在自己数据上测"保留率-精度"曲线，找业务可接受的最小保留率；  
4. 若无深度只有 RGB，先过单目深度并检查尺度一致性，覆盖度量对系统性尺度漂移敏感；  
5. 选择器在视觉编码器之后、projector 之后生效，不需改 VLM 权重——升级 VLM 零成本迁移。

```
N 视角 RGB-D → token 反投影（3D 坐标）
```

## 附录B：d_H 作为表征质量指标的使用手册

1. **离线评估**：给定剪枝/关键帧/token 化方案，计算 d_H 与性能的相关曲线，验证覆盖-性能假设是否在你的数据上成立；  
2. **在线监控**：agent 采集过程中滚动估计当前观测集的 d_H，超过阈值即触发补采；  
3. **方案对比**：同预算下比较不同方案的 d_H 分布（均值+最差分位），最差分位对"灾难性遗漏"更敏感；  
4. **注意**：d_H 只度量空间覆盖，不度量语义覆盖——高 d_H 必差，低 d_H 未必好（可能全剪掉了关键物体只留背景）。

## 附录C：常见误读澄清

**误读1**："CoVeR 是注意力剪枝的替代品"——部分正确。它在多视角 3D 设定下替代之；单图设定下学习型方法仍有其位（冗余结构不同）。

**误读2**："8% 保留意味着可以无脑压到 8%"——保留率-精度曲线随任务与场景变化，8% 是 ScanQA 类基准的最优点附近，生产部署需按业务校准。

**误读3**："纯几何 = 精度上限低"——实证相反，覆盖先验在三个基准上都超过学习打分。几何不是弱信号，是被低估的信号。

**误读4**："与 3DGS 剪枝是一回事"——CoVeR 剪的是 VLM 的视觉 token（LLM 上下文预算），3DGS 剪枝管渲染效率；两者共享"空间冗余"的数学但服务不同瓶颈。

## 附录D：一句话版核心结论（便于引用）

1. 多视角 3D 推理的冗余是几何冗余，应该用几何算法消除。  
2. 体素化给覆盖但不给预算，学习打分给预算但不给覆盖——CoVeR 两个都给。  
3. k-center + Hausdorff 是空间 token 选择的形式化正确答案，FPS 是其 2-近似解。  
4. 8% 的 token 装得下 93.5% 的场景推理能力。  
5. 空间中间件应当确定性、模型无关、即插即用。
