## 论文摘要

在Embodied视觉-语言决策任务（如机器人操作和导航）中，VLM和VLA各有优势：VLM擅长长期规划，VLA擅长反应式控制。但它们都面临同一个感知瓶颈——视觉幻觉（visual hallucinations），即模型无法区分任务相关物体和干扰物。本文提出**SceneDiver**，一种利用VLM长期规划能力的粗到细（coarse-to-fine）焦点计划生成方法：首先构建整体场景图（scene graph）建立初始理解，然后通过识别-理解-分析的迭代循环逐步将任务分解为更简单的子问题。为支持反应式控制，还设计了轻量级适配器将审慎式焦点能力蒸馏到VLA中。

## Q1: 核心算法原理

### 1. 核心思想和动机

**问题定义**: VLM/VLA在复杂视觉场景中产生视觉幻觉——物体幻觉（预测不存在的物体）和感知错误（物体遗漏、属性绑定错误、实例计数不准）。这是因为模型无法在杂乱背景中区分任务相关物体和干扰物。

**核心洞察**: 
- 直接一步聚焦（one-step focus）无效，因为有效的聚焦本质上需要对场景的深度理解
- VLM已经具备长期规划能力，应该利用这一能力来引导感知聚焦
- 从粗到细的策略符合人类视觉认知：先理解全局，再聚焦局部

**动机来源**: 人类在执行视觉任务时，并不会一次性处理所有视觉信息。我们先快速浏览全局建立场景理解，然后根据任务目标聚焦到特定区域。SceneDiver将这一认知过程形式化为两阶段计算流程。

### 2. 主要技术方法

#### Stage 1: 粗粒度阶段 — 场景图推理（Graph Reasoning）

- **场景图构建**: 使用OvSGTR（开放词汇场景图检测器）从原始图像生成场景图
  - 节点（Nodes）= 物体
  - 边（Edges）= 空间关系
  - 物体用 `<ref>` 标注，关系用 `<pred>` 指定，位置用 `<box>` 编码

- **图推理**: VLM基于场景图执行高级推理
  - 将复杂全局场景分解为一系列对应图中节点的简单局部子场景
  - VLM作为唯一真相来源，场景图作为推理引导
  - 当不一致出现时，VLM可以选择空间邻近的邻居、丢弃无关目标、或保留模糊子场景作为候选

#### Stage 2: 细粒度阶段 — 验证与探索（Verification and Exploration）

- **顺序处理**: VLM按顺序对每个子场景进行"放大"处理
- **智能体行为**: 模型主动验证信息是否与当前任务相关
  - 如果局部窗口内的物体与计划匹配 → 确认为有效候选
  - 如果视觉证据模糊 → 触发"语义缩放"（semantic zoom），缩小视野解决细粒度细节
  - 如果预期目标缺失 → 启动局部空间搜索，扫描邻近区域重新获取目标
- **自主搜索**: 模型自主选择、丢弃或搜索附近区域，以Agent方式构建最终验证物体集合 C

#### 焦点调制（Focus Modulation）

- 将候选物体边界框栅格化为像素级**焦点分数图** s ∈ [0,1]^{H×W}
- 设计软调制策略：
  - 亮度衰减：I_dim = I ⊙ (β + (1-β)s)，β为可见性下限
  - 高频抑制：I_out = s ⊙ I_dim + (1-s) ⊙ B_σ(I_dim)
  - 目标物体保持清晰明亮，干扰物被柔和暗化

#### SceneDiver 适配器（Adapter）

- 将显式推理蒸馏到端到端VLA中
- 位置：在projector之后的跨模态对齐空间
- **Slot Attention**: 提取任务条件化的结构化表示
  - 将视觉特征 F ∈ R^{L×D} 投影到以物体为中心的slots S ∈ R^{K×Ds}
  - 任务token通过学习注意力池化为全局向量 v_task
  - 初始化：S_init ~ N(μ(v_task) + δ, σ_global)
  - 任务引导的slot初始化确保slot捕获任务相关实体
- **Mask预测模块**: 生成精细注意力mask
- **知识转移目标**:
  - Structure Loss: 监督Slot Attention学习结构化推理相关表示
  - Mask Loss: 监督mask预测模块提高空间定位精度

### 3. 算法流程和关键步骤

```
输入: 图像 I, 任务指令 T
输出: 决策动作 A

1. 场景图构建
   G = OvSGTR(I)  // 生成场景图
   
2. 粗粒度图推理（Stage 1）
   SubScenes = VLM.graph_reason(G, T)
   // VLM基于场景图分解全局场景为局部子场景
   
3. 细粒度验证与探索（Stage 2）
   C = {}  // 候选物体集合
   for each sub_scene in SubScenes:
       if VLM.verify(sub_scene, T):
           C.add(sub_scene.objects)
       elif ambiguous:
           zoomed = semantic_zoom(sub_scene)
           if VLM.verify(zoomed, T):
               C.add(zoomed.objects)
       elif missing:
           nearby = local_search(sub_scene)
           if VLM.verify(nearby, T):
               C.add(nearby.objects)
   
4. 焦点调制
   s = rasterize(C.bounding_boxes)  // 生成焦点分数图
   I_out = soft_modulate(I, s)  // 亮度衰减 + 高频抑制
   
5. 最终决策
   A = VLM.decide(I_out, T)  // 或 A = VLA_with_adapter(I_out, T)
   
输出: A
```

### 4. 输入输出

- **输入**: RGB图像 + 自然语言任务指令
- **输出**: 
  - VLM模式：高级决策（如导航方向、操作步骤）
  - VLA模式：端到端动作（7-DoF机械臂控制）
- **中间表示**: 场景图、子场景描述、焦点分数图、调制图像

## Q2: 与Spatial AGI的关系

### 1. 如何理解和表示空间

**场景图作为空间表示**:
- SceneDiver使用场景图（scene graph）作为核心空间表示
- 场景图以物体为节点、空间关系为边，提供了结构化的空间表示
- 每个物体带有边界框 `<box>` 编码空间位置
- 空间关系通过 `<pred>` 谓词显式表示（如"on", "next to", "inside"）

**空间层次化理解**:
- 全局场景 → 局部子场景 → 个体物体
- 这种层次化分解直接对应空间理解的层次：全局空间认知 → 区域空间理解 → 物体级空间定位
- 与Spatial AGI的多尺度空间理解需求高度一致

**焦点分数图作为空间注意力**:
- 像素级的空间注意力分配
- 将"在哪里看"（where to look）问题转化为可计算的spatial map
- 本质上是一种自顶向下的空间注意力机制

### 2. 如何处理空间关系

**显式空间关系推理**:
- 通过场景图中的谓词关系（on/next to/inside等）显式编码空间关系
- VLM在图推理阶段利用这些关系来推断任务相关区域
- 例如："拿起桌上的红色杯子" → 场景图中"红色杯子"节点通过"on"关系连接到"桌子"节点

**空间搜索行为**:
- 当目标物体在预期位置缺失时，模型执行局部空间搜索
- 这模拟了人类在空间中寻找物体时的行为：先看预期位置，找不到就搜索附近区域
- "语义缩放"本质上是在空间尺度上的调整——从宏观到微观

**空间上下文推理**:
- 场景图不仅编码物体本身，还编码物体间的空间布局
- VLM的推理过程考虑了空间上下文：一个子场景的空间位置影响对其他子场景的理解

### 3. 对Spatial AGI的启发

**结构化空间表示的重要性**:
- SceneDiver证明了非结构化的像素输入容易导致幻觉
- 通过场景图这种结构化表示，可以显著改善空间推理质量
- 启发Spatial AGI：需要中间的结构化空间表示层，而非纯端到端

**粗到细的空间推理范式**:
- 从全局空间理解到局部空间聚焦的两阶段范式
- 这与Spatial AGI的"先理解空间结构，再执行空间操作"理念一致
- 可推广到任何需要精确空间定位的AGI任务

**Agent式空间探索**:
- SceneDiver让VLM以Agent方式探索视觉场景
- 模型自主决定"看哪里"、"放大哪里"、"搜索哪里"
- 这种自主空间探索能力是Spatial AGI的核心需求

**蒸馏从推理到反应**:
- 将显式的迭代推理蒸馏为隐式的端到端反应
- 这对Spatial AGI很重要：AGI需要在推理深度和执行效率之间取得平衡

### 4. 可以应用的Spatial AGI场景

- **机器人操作**: 在杂乱环境中精确识别操作目标（已验证）
- **自主导航**: 在复杂场景中识别导航路标和障碍物（已验证）
- **场景理解**: 从RGB图像构建结构化空间表示
- **空间问答**: 回答关于复杂场景的空间问题
- **多物体交互**: 理解多个物体间的空间关系并做出决策
- **空间规划**: 基于场景图的空间路径规划

## Q3: 创新点和局限性

### 1. 主要创新点

**创新1: 焦点计划生成（Focus Plan Generation）**
- 不是简单的一次性注意力聚焦，而是生成一个计划来逐步聚焦
- 将"看什么"本身作为一个需要规划的任务
- 这是一个新颖的视角：将注意力控制转化为规划问题

**创新2: 场景图引导的粗到细推理**
- 场景图不是最终输出，而是作为推理引导的中间表示
- VLM作为推理者，场景图作为工具——这种分工利用了各自优势
- 粗到细的分解策略使复杂场景变得可处理

**创新3: Agent式视觉探索**
- 模型不是被动处理图像，而是主动"探索"视觉场景
- 语义缩放和局部搜索行为赋予了模型主动感知能力
- 这将主动感知（active perception）的理念融入了VLM

**创新4: 推理到反应的蒸馏**
- Slot Attention作为结构化表示的桥梁
- 将迭代推理的成果蒸馏为轻量级适配器
- 保持了VLA的推理效率，同时获得了推理深度

**创新5: 软调制策略**
- 不是hard mask（完全移除背景），而是soft modulation（暗化+模糊化）
- 保留了环境上下文，同时突出任务相关物体
- 这种设计更符合人类视觉认知（周边视觉仍然存在但弱化）

### 2. 主要局限性

**局限1: 对场景图检测器的依赖**
- 方法依赖OvSGTR生成高质量场景图
- 场景图检测器的错误会传播到后续推理
- 在场景图检测器表现差的场景（如遮挡严重、罕见物体）下效果会受限

**局限2: 多轮推理的延迟**
- 尽管设计了适配器来加速，VLM模式仍需要多轮迭代
- 在需要快速反应的场景（如动态环境）中可能受限
- 论文报告仅2.64%计算开销，但这是适配器模式而非完整VLM模式

**局限3: 场景图的表达能力限制**
- 场景图主要编码物体级的空间关系
- 难以表示更复杂的空间结构（如物体内部结构、非刚性物体、动态场景）
- 对于需要细粒度几何理解的任务可能不足

**局限4: 视觉调制的不可逆性**
- 软调制后的图像丢失了部分背景信息
- 如果后续任务需要背景信息（如利用环境线索），调制可能有害
- 可见性下限β需要手工调整

**局限5: 适配器的泛化能力**
- 适配器通过蒸馏学习，可能在训练域外表现下降
- Slot Attention的slot数量K需要预设，可能不适配所有场景复杂度
- 蒸馏质量的上线受限于教师模型（完整SceneDiver）

### 3. 与其他相关工作的对比

| 维度 | SceneDiver | 直接注意力 | 物体检测器辅助 | 视觉grounding微调 |
|------|-----------|-----------|--------------|----------------|
| 方法 | 场景图+粗到细推理 | 一次性注意力mask | 外部检测器+VLM | 微调VLM增强grounding |
| 推理深度 | 深（多轮迭代） | 浅（一次计算） | 中（依赖检测器） | 中（通过训练） |
| 效率 | 慢（VLM）/快（适配器） | 快 | 中 | 快 |
| 可解释性 | 高（场景图+推理过程） | 低 | 中 | 低 |
| 泛化性 | 高（利用VLM通用能力） | 中 | 低（依赖检测器类别） | 中 |

与SpatialStack（层次几何-语言融合）对比：
- SpatialStack直接在特征层面融合几何信息
- SceneDiver在感知层面通过场景图引导注意力
- 两者互补：SpatialStack改进空间表示，SceneDiver改进空间注意力

与Reasmory（3D重建作为显式记忆）对比：
- Reasmory使用3DGS作为空间记忆
- SceneDiver使用场景图作为空间推理引导
- Reasmory更适合需要精确3D理解的任务，SceneDiver更适合需要物体级推理的任务

## 核心技术发现

### 发现1: 视觉幻觉的根源是感知过载
- VLM产生幻觉不是因为"不知道"，而是因为"看到了太多"
- 杂乱背景中的干扰物消耗了模型的注意力资源
- 通过焦点调制减少干扰，可以显著改善决策质量

### 发现2: 场景图作为VLM的"思维脚手架"
- 场景图不是最终输出，而是VLM推理过程中的中间表示
- 类比人类思维：场景图起到了"工作记忆"的作用
- 将非结构化的像素信息转化为结构化的图表示，降低了推理难度

### 发现3: Agent式视觉探索的可行性
- VLM可以像Agent一样自主探索视觉场景
- "决定看哪里"、"决定放大哪里"、"决定搜索哪里"——这些行为可以涌现自VLM本身的能力
- 不需要硬编码的规则

### 发现4: 推理-反应的蒸馏是可行的
- 复杂的迭代推理可以蒸馏为轻量级适配器
- Slot Attention是有效的结构化表示桥梁
- 这为"训练时深度推理、推理时快速反应"提供了可行路径

### 发现5: 软调制优于硬mask
- 完全移除背景信息会损失上下文
- 软调制（暗化+模糊化）在突出目标的同时保留了环境线索
- 这更符合生物视觉系统的运作方式

## 与Spatial AGI的关系

### 直接贡献

1. **空间注意力机制**: SceneDiver的焦点分数图为Spatial AGI提供了一种自顶向下的空间注意力机制，可以集成到任何视觉感知pipeline中

2. **结构化空间表示**: 场景图作为空间表示的中间层，架起了像素级感知和符号级推理之间的桥梁

3. **空间搜索策略**: 当目标在预期位置缺失时的局部空间搜索策略，可以直接应用于Spatial AGI的空间探索任务

### 技术启发

1. **多尺度空间理解**: 粗到细的两阶段范式启发Spatial AGI在设计空间理解模块时采用多尺度策略

2. **推理-反应分离架构**: VLM负责深度推理、VLA负责快速反应的架构设计，启发Spatial AGI在系统中分离"思考"和"行动"

3. **Agent式感知**: 将VLM视为视觉探索Agent的设计理念，启发Spatial AGI赋予感知模块更多自主性

### 应用场景

- **Embodied AI系统**: 机器人在杂乱环境中操作时的目标识别和聚焦
- **自动驾驶**: 在复杂交通场景中聚焦关键车辆和行人
- **AR/VR**: 在增强现实中根据用户任务突出相关物体
- **空间问答系统**: 对复杂空间关系问题的精确回答

## 个人思考

### 最令人兴奋的发现

**"注意力即规划"的思想**。SceneDiver将注意力控制转化为规划问题——不是直接"看"目标，而是规划"如何看"目标。这是一个深层洞察：在复杂空间中，"在哪里看"本身就是需要智能规划的任务。这与Spatial AGI的核心挑战高度一致——空间智能不仅仅是理解空间，还包括决定如何分配空间注意力资源。

**Agent式视觉探索**的范式也令人兴奋。将VLM从被动的图像处理器转变为主动的场景探索者，这更接近人类视觉系统的工作方式。人类不是被动地看到所有东西然后筛选——我们的眼睛不断移动，根据任务目标主动探索视觉场景。

### 潜在局限

**场景图的表达能力边界**。场景图擅长编码物体级的空间关系，但难以表示：
- 物体内部的结构信息（如一个机器人的关节）
- 连续的空间场（如地形、植被分布）
- 动态空间关系（随时间变化的空间布局）
- 非几何的空间属性（材质、重量、温度）

这意味着SceneDiver在物体级任务（操作、导航）中表现好，但在需要更精细空间理解的任务中可能受限。

**从2D到3D的鸿沟**。SceneDiver基于2D图像和2D边界框，空间推理主要在2D空间进行。对于需要3D空间理解的任务（如深度估计、6-DoF位姿估计），可能需要将场景图扩展到3D。

### 与昨日研究的关联

昨天（2026-07-01）分析的论文中：
- **CRISP** 诊断VLM空间推理的语言先验vs真实推理——SceneDiver通过场景图引导，减少了语言先验的干扰
- **CubifyGS** 的对象中心3DGS——可以与SceneDiver的场景图结合，3DGS提供几何基础，场景图提供语义结构
- **Dense Embodied CoT VLA** 的密集思维链——SceneDiver的粗到细推理也是一种思维链，但专门针对感知瓶颈

### 方法组件

## 技术细节补充

### 焦点分数图的数学定义

焦点分数图 s ∈ [0,1]^{H×W} 定义为：
```
s_{u,v} = I[∃k ∈ C: (u,v) ∈ b_k]
```
即像素(u,v)在某个候选物体k的边界框b_k内时为1，否则为0。

### 软调制的数学公式

亮度衰减：
```
I_dim = I ⊙ (β + (1-β)s)
```
其中 β ∈ (0,1) 是可见性下限，防止背景完全变黑。

高频抑制：
```
I_out = s ⊙ I_dim + (1-s) ⊙ B_σ(I_dim)
```
其中 B_σ 是高斯模糊算子。目标区域保持锐利，背景被模糊化。

### Slot Attention的任务引导初始化

```
S_init ~ N(μ(v_task) + δ, σ_global)
```
其中：
- v_task: 任务token通过学习注意力池化得到的全局向量
- δ: 学习到的偏移
- σ_global: 全局可学习方差

这种初始化确保slot以任务为导向，而非随机初始化。

### 蒸馏损失

- **Structure Loss**: 监督Slot Attention的输出对齐教师模型的结构化推理中间表示
- **Mask Loss**: 监督mask预测模块的输出对齐教师模型的焦点分数图

## 总结

### 核心发现总结

SceneDiver提出了一种新颖的"焦点计划生成"方法来解决VLM/VLA的视觉幻觉问题。核心创新在于：
1. 将注意力控制转化为规划问题——不是直接聚焦，而是规划如何聚焦
2. 使用场景图作为推理脚手架，通过粗到细的两阶段分解降低复杂度
3. 赋予VLM Agent式的视觉探索能力——自主决定看哪里、放大哪里、搜索哪里
4. 通过轻量级适配器将深度推理蒸馏为快速反应

### 对Spatial AGI的意义

1. **空间注意力是核心能力**: Spatial AGI不仅需要理解空间，还需要知道在哪里分配注意力资源
2. **结构化中间表示**: 场景图作为像素到符号的桥梁，对Spatial AGI的空间理解模块设计有启发
3. **推理-反应分离**: 深度推理用于训练/慢思考，快速反应用于部署/快反应——这是Spatial AGI系统的重要架构模式
4. **Agent式感知**: 将感知模块设计为自主探索Agent，而非被动处理器
