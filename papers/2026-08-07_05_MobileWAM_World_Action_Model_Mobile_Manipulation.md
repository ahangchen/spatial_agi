## 论文摘要翻译

基于视频生成骨干网络的世界动作模型（WAM）是机器人学习的新兴范式，但仍局限于桌面操作。移动操作需要在场景级动态中同时进行移动和全身操作，而现有方法仍被缺乏动态感知的视觉编码器和手工设计的协调所主导。我们用MobileWAM弥合这一差距——一种混合Transformer架构，通过层级联合注意力将预训练视频扩散Transformer与轻量动作专家融合，将互联网级运动先验转化为全身控制。为协调移动和操作的异构动态，动作专家的每个前馈层成为三专家混合（共享、移动、操作），由动作token中的运动意图软路由。为进一步密集化监督，我们提出Chain-of-Foresight（CoF）：中间表示序列预测未来潜变量的链条，每步以前驱为条件。在部署时，WAM作为纯当前帧编码器； foresight仅通过梯度作用，推理时foresight链和视频生成都被丢弃。MobileWAM在ManiSkill-HAB上超越SOTA移动操作策略，并成功迁移到真实ARX Lift2移动操作平台。

## Q1: 核心算法原理

### 1. 核心思想和动机

MobileWAM 回答了一个根本问题：**移动操作不仅仅是"桌面操作+移动底座"**。

**三大差距**：
1. **视角差距**：桌面相机固定，移动机器人相机随移动持续变化
2. **多模态性**：底座自由导致底座-臂路径组合爆炸，动作分布远更多模态
3. **因果性**：早期导航错误会默默导致后续抓取失败——因果深度和空间变化使任务成为长时序问题

**核心思想**：
- 将视频生成WAM从桌面扩展到移动操作
- 关键洞察：移动操作中移动和操作是"乘法"关系而非"加法"关系
- 用Chain-of-Foresight将视频预测的"单步预测"变成"链式推理"

### 2. 主要技术方法

#### 2.1 World Expert（世界专家）
- 预训练视频扩散Transformer（L=30层，宽度3072）
- 冻结3D VAE：16×空间压缩，4×时间压缩
- 一个潜变量tick = 一个动作块（H=4），对齐视觉和运动时钟
- 头部+腕部相机合成side-by-side，通过空间注意力强制跨视角一致性
- 当前帧作为干净潜变量（timestep 0），后续帧携带噪声
- T5语言编码器注入指令

#### 2.2 Action Expert + Mobile MoE

**轻量动作去噪Transformer（宽度1024）**：
- 30层与骨干锁步运行
- 动作token通过层级联合注意力加入视觉token
- 非对称注意力掩码：动作读视觉，视觉不读动作

**Mobile MoE（核心创新）**：
- 动作专家的每个前馈层替换为三专家混合：
  - **共享专家**：处理通用运动结构
  - **移动专家**：专注于底座导航命令
  - **操作专家**：专注于臂/夹爪精细控制
- 路由器读取平均池化的噪声动作嵌入，温度缩放softmax软路由
- 专家从密集层克隆初始化，路由器零初始化 → 专业化仅在数据需要时涌现
- 不需要负载均衡损失
- 13维动作：臂(7关节) + 夹爪 + 头部pan/tilt + 躯干升降 + 底座线/角速度

#### 2.3 Chain-of-Foresight (CoF)

**动机**：单步预测只问"接下来发生什么"，移动操作需要"然后呢？然后呢？"

**架构**：
- 从骨干的4个均匀间隔层{4,12,20,30}提取隐状态
- 融合MLP g生成初始信念h₀
  - h₀ = g([H⁽⁴⁾; H⁽¹²⁾; H⁽²⁰⁾; H⁽³⁰⁾])
- 深度特定模块F₁,...,F_K链式展开
- 每步k：Fₖ输入信念h_{k-1}和噪声目标z_k^{τ_k}，输出速度估计和信念hₖ
- 信念是步骤间的唯一通道 → 强制hₖ总结演化中的世界

**关键特性**：
- 训练时提供密集的时序监督
- 推理时完全丢弃 → 零推理成本
- 权重折扣 w₁ > w₂ > ... > wₖ（远期未来权重更低）

#### 2.4 解耦视频-动作去噪
- 视频和动作使用相同的flow matching形式
- 独立的偏移倾斜时间采样 → 任一分支可独立去噪
- 部署时：骨干对当前帧做一次编码 → 缓存KV → 动作迭代去噪
- 视频分支和CoF完全丢弃

#### 2.5 非对称注意力掩码
- 当前token：仅自注意
- 未来视频token：注意所有视觉token
- 动作token：仅注意当前token
- 视频token不看动作token → 确保训练和部署的当前帧表示一致

### 3. 算法流程

```
训练:
输入: o_t (头+腕相机), s_t (本体感受), ℓ (指令), 未来视频V_{t:t+T}
1. 视频编码：3D VAE压缩 → 潜变量序列
2. 动作编码：噪声动作块 → 动作token
3. 层级联合注意力(30层):
   视觉token ← 视觉token (自注意)
   动作token ← 视觉token + 动作token (交叉注意)
   每层FFN → Mobile MoE三专家路由
4. CoF分支: 从层{4,12,20,30}提取 → 链式预测
5. 输出: 视频速度估计 + 动作速度估计 + CoF速度估计
Loss: L_vid + L_act + L_CoF (深度衰减)

部署:
1. 骨干编码当前帧(1次) → 缓存KV
2. CoF和视频分支丢弃
3. 动作token迭代去噪 → 输出全身动作块
4. 推理时间: 938ms (比generate-then-act WAM快5-8×)
```

### 4. 输入输出
**输入**: 头部+腕部RGB图像, 13维本体感受, 语言指令  
**输出**: 13维全身动作块（臂7 + 夹爪1 + 头部2 + 躯干1 + 底座2）

## Q2: 与Spatial AGI的关系

### 1. 空间理解和表示
- **视频先验作为空间知识**：互联网视频蕴含丰富的物理世界运动先验，MobileWAM通过视频预训练将这些先验转化为机器人控制
- **信念状态作为空间记忆**：CoF的信念hₖ本质是空间世界的压缩表示，编码了"世界如何随时间演化"
- **多视角空间一致性**：头部+腕部相机side-by-side合成，通过空间注意力强制一致

### 2. 空间关系处理
- **移动-操作耦合**：底座移动改变相机视角→影响操作精度；操作动作影响物体位置→影响后续导航
- **运动意图驱动的路由**：MoE路由器根据动作token的运动意图自动决定使用移动还是操作专家
- **长时序空间推理**：CoF的链式预测让模型理解"移动到某处→然后操作→然后移动到下一处"的长时序空间序列

### 3. 对Spatial AGI的启发
- **视频是世界模型的训练数据**：互联网视频包含丰富的空间-时间-因果模式，是Spatial AGI世界模型的理想训练源
- **专家混合处理多模态**：移动和操作是不同运动regime，需要不同的专家——这种"分而治之"策略可推广到Spatial AGI的其他多模态任务
- **训练时辅助推理时丢弃**：CoF的"训练时提供密集监督，推理时零成本"设计模式可广泛应用于Spatial AGI
- **信念链作为世界模型**：CoF的RNN式信念传递是构建Spatial AGI世界模型的有效范式

### 4. 应用场景
- 家庭服务机器人（移动+操作）
- 仓库物流（移动抓取放置）
- 厨房助手（取物+操作电器）
- 医院/护理机器人
- 户外巡检机器人

## Q3: 创新点和局限性

### 创新点
1. **首个将WAM从桌面扩展到移动操作**：系统性地解决了视角、多模态性、因果性三大差距
2. **Mobile MoE**：三专家（共享/移动/操作）由运动意图软路由，自然处理异构动态
3. **Chain-of-Foresight**：链式未来潜变量预测，训练时密集监督，推理时零成本
4. **解耦视频-动作去噪**：部署时视频分支完全丢弃，5-8×加速
5. **零初始化路由器**：专业化仅在数据需要时涌现，不需要负载均衡损失

### 局限性
1. **计算需求**：30层视频扩散Transformer作为骨干，训练资源需求高
2. **数据需求**：需要配对的视频-动作数据，移动操作数据采集成本高
3. **视角数量有限**：仅头部+腕部两个视角，可能在某些任务中不足
4. **动作空间连续性假设**：13维连续动作空间，不适合需要离散决策的任务
5. **CoF链长度选择**：K个foresight步是一个超参数，最优值可能因任务复杂度而异
6. **真实世界迁移**：仅在ARX Lift2上验证，更多平台验证需要

### 对比
| 方法 | 移动操作 | 世界模型 | MoE | Foresight | 推理效率 |
|------|---------|---------|-----|-----------|---------|
| **MobileWAM** | ✅ | ✅视频WAM | ✅三专家 | ✅CoF链 | 938ms |
| Fast-WAM | ❌桌面 | ✅ | ❌ | ❌ | 快 |
| AC-DiT | ✅ | ❌ | ❌ | ❌ | 需3D点云 |
| SG-VLA | ✅ | ❌ | ❌ | ❌ | 需GT分割 |
| π₀.₅ | ✅ | ❌ | ❌ | ❌ | 基线 |

## 核心技术发现

1. **移动操作≠桌面操作+导航**：移动和操作是乘法关系，底座移动的微小误差会传播放大到操作精度
2. **视频先验可迁移到全身控制**：互联网视频中的运动模式可以通过层级联合注意力有效迁移到机器人
3. **信念链是世界模型的有效表示**：CoF的RNN式信念传递让模型学会了"世界状态如何演化"的隐式模型
4. **MoE自然处理异构动态**：不同运动regime（导航vs操作）需要不同的计算路径，MoE让模型自动学习这种分化
5. **训练辅助可推理时丢弃**：深度学习中"训练时复杂，推理时简洁"是一个强大的设计模式

## 与Spatial AGI的关系

### 直接贡献
- 为移动操作Spatial AGI提供世界模型基础
- CoF信念链可作为Spatial AGI的时空记忆模块
- 视频先验迁移降低Spatial AGI的数据需求

### 技术启发
- **乘法耦合处理**：多个能力（移动+操作）的组合不是简单叠加，需要专门的架构设计
- **训练-推理解耦**：辅助任务（视频预测、CoF）在训练时提供信号但推理时无成本
- **专家混合作为能力分配器**：不同子任务由不同专家处理，路由器自动学习分配

## 个人思考

### 最令人兴奋的发现
CoF的"信念链"设计——每步预测将信念传递给下一步，信念是步骤间唯一通道——本质上是在构建一个序列化的世界模型。这个设计简单而优雅，类似于RNN/LSTM的隐状态传递，但用于未来潜变量预测。更令人兴奋的是，这一切在推理时完全丢弃，只留下策略级的动作输出。

### 潜在局限
- 视频扩散Transformer作为骨干的计算成本极高（30层，宽度3072）
- CoF链长度K是一个关键超参数，太短无法建模长时序，太长训练困难
- Mobile MoE的路由器零初始化虽然优雅，但在极端不平衡数据上可能退化
- 仅在ManiSkill-HAB和ARX Lift2上验证，更多场景需要验证

### 与昨日研究的关联
- **SelfWAM**（自引导世界动作模型）：MobileWAM扩展了WAM到移动操作，SelfWAM关注WAM的自引导
- **Faster-WAM**（深层动作模块质疑）：MobileWAM用MoE回答了"如何设计动作模块"的问题
- **WAP**（世界动作规划器）：两者都关注世界模型+动作，但MobileWAM更关注移动操作的特殊挑战
- **BWM**（低成本世界模拟器）：MobileWAM的视频扩散骨干是BWM类型方法的高级版本

## 关键数据

### ManiSkill-HAB（仿真）
- MobileWAM: 73.0% 平均成功率（SOTA）
- 输入: 仅RGB（无需点云或GT分割）
- 训练: 一阶段端到端

### 真实世界（ARX Lift2）
- 5个家庭任务（Ta-Te），时序递增
- 对比π₀.₅：MobileWAM优势随任务时序增长而增大
- 推理时间: 938ms/步（比generate-then-act WAM快5-8×）

### 架构参数
- 骨干: L=30层，宽度3072（视频扩散Transformer）
- 动作专家: 宽度1024，30层
- Mobile MoE: 3专家/层（共享+移动+操作）
- CoF: K步链，4层tap {4,12,20,30}
- 动作空间: 13维（臂7+夹爪1+头2+躯干1+底座2）

## 总结

### 核心发现
MobileWAM系统性地将世界动作模型从桌面扩展到移动操作，核心创新包括：
1. Mobile MoE处理移动/操作的异构动态
2. Chain-of-Foresight提供零推理成本的时序密集监督
3. 解耦视频-动作去噪实现高效部署

### 对Spatial AGI的意义
1. **世界模型实用化**：视频生成WAM首次在移动操作上达到SOTA
2. **多能力融合范式**：MoE作为能力分配器处理多模态空间任务
3. **训练-推理解耦设计**：辅助任务丰富训练信号但不增加推理成本
4. **移动操作作为Spatial AGI核心能力**：从固定操作到移动操作是Spatial AGI的关键跃迁

### 未来方向
- 更高效的骨干（减少30层Transformer的开销）
- 自适应CoF链长度
- 多机器人协作场景
- 更多真实平台验证
- 与3DGS场景表示的结合
