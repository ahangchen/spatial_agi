## 一句话总结

Stateful Harness 提出把世界演化与视频渲染解耦：由符号化世界状态+显式规则
维护隐藏状态的演化并编译成指令，冻结的视频生成模型只负责"把事件画出来"，
可编辑 3D 场景的预览片段提供空间与相机引导；配套 WorldState-Bench
（50 对反事实孪生场景）证明纯视频模型在隐藏状态规则遵循上只有 32% 的
双案例成功率，而完整 harness 用同一冻结模型达到 92%。

## 核心问题

### Q1: 核心算法原理是什么？

**问题**: 这篇文章的核心算法原理是什么？请详细描述核心思想、方法、流程与输入输出。

**分析**:

1. **核心思想和动机**

   当前视频世界模型（如各类 interactive video generation）可以
   从单图生成动作条件视频，用户能"漫游"生成的场景。
   但有一个根本缺陷：**当动作结果取决于当前帧中不可见的隐藏状态时，
   纯视频模型无法遵循持久规则**。
   例如：抽屉里有没有东西（关着看不见）、开关是开是关、
   门锁了没有——视频模型只从像素推断，而像素不包含这些信息。

   核心洞察：**规则执行与像素生成是两种不同的计算**。
   规则执行是离散、符号、确定性的（"如果锁着，开门失败"）；
   像素生成是连续、感知、生成性的（"开门失败看起来什么样"）。
   把两者塞进同一个神经网络（用视频隐式学规则）既低效又不可靠。

2. **主要技术方法**

   **Stateful Harness 三件套**：

   - **演化世界状态（evolving world state）**：
     以显式符号结构维护世界（对象、属性、关系、隐藏状态如开关/锁/内容物），
     并按用户指定的规则（rules）确定性地演化。
   - **冻结视频模型渲染**：
     每一轮，harness 解析用户动作 → 在符号世界里计算事件结果 →
     把结果编译成自然语言指令，交给一个**冻结的**视频生成模型渲染。
     规则改了，模型不用重训。
   - **可编辑 3D 场景预览**：
     一个轻量可编辑 3D 场景生成 preview clip，
     为视频模型提供空间布局与相机轨迹引导，
     确保生成的像素与符号世界的几何一致。
   - **状态回写闭环**：
     渲染出的片段反过来更新世界状态，进入下一轮——
     形成状态→事件→像素→状态 的循环。

3. **算法流程和关键步骤**

   ```
   输入: 初始帧 + 规则描述 + 用户逐轮动作
   1. 动作解析: harness 在符号世界状态下解析动作合法性
   2. 规则执行: 按显式规则计算事件结果（含隐藏状态）
   3. 指令编译: 事件 → 文本指令
   4. 3D 预览: 可编辑场景生成空间/相机引导的 preview clip
   5. 视频渲染: 冻结的视频模型生成事件片段
   6. 状态回写: 片段确认/更新世界状态
   7. 下一轮循环
   输出: 逐轮动作条件视频流（规则一致）
   ```

4. **输入输出**

   - 输入：单张初始图、自然语言规则、逐轮用户动作。
   - 输出：每一轮符合隐藏状态与规则的视频片段（可交互序列）。

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**分析**:

1. **如何理解和表示空间**

   这篇文章对空间智能的最大贡献是区分了**空间的外观**
   （视频像素）与**空间的状态**（符号结构）。
   一个房间不等于它的当前视角图像：抽屉的内容、锁的状态、
   物体的支撑关系都是不依赖于视角的持久空间事实。
   Spatial AGI 必须维护这种**视角不变的状态层**，
   而不能把"理解空间"等同于"记住像素"。

2. **如何处理空间关系**

   - 隐藏状态本质是空间关系（物体在抽屉里、门与门框的锁定关系）；
   - 反事实孪生（同初始帧+同动作、不同隐藏状态、不同结果）
     是检验空间关系是否被真正表征的锐利工具——
     如果模型只看像素，两个案例的输出必然相同；
   - 可编辑 3D 场景作为像素与符号之间的几何桥梁，
     说明**显式 3D 中间表征**是连接符号推理与神经渲染的实用解。

3. **对 Spatial AGI 的启发**

   - **系统1/系统2 的空间版**：像素生成是系统1（快速直觉），
     规则执行是系统2（慢速符号推理）。Spaceful Harness 是
     空间领域双过程架构的干净实现；
   - **冻结模型的模块化红利**：规则可编程、可验证、可解释，
     视觉模型可随时升级——这是 Spatial AGI 系统设计的重要范式；
   - **隐藏状态是空间记忆的下界**：任何只依赖当前观测的空间系统
     都会在 occluded state 上翻车，这印证了空间记忆/状态跟踪
     是 Spatial AGI 的核心组件。

4. **可以应用的 Spatial AGI 场景**

   - 交互式世界模拟器（游戏、机器人仿真前端）；
   - 具身规划器的事实验证层：计划先在符号世界推演，再渲染预览；
   - 视频世界模型的规则一致性外挂（不改模型架构）；
   - 反事实空间推理数据生成：孪生场景天然是高质量训练信号。

### Q3: 主要创新点和局限性是什么？

**分析**:

1. **主要创新点**

   - **架构主张**：把"Execute the Rules"与"Generate the Pixels"
     解耦——这可能是交互式世界建模的正确抽象分层；
   - **Stateful Harness**：符号状态机 + 冻结视频渲染器 + 3D 预览
     引导的完整可运行系统；
   - **WorldState-Bench**：50 对反事实孪生（同帧同动作、异状态异结果）
     的精巧评测设计，直击"像素即理解"的幻觉；
   - **量化证据**：11 个视频后端最好只有 32% 双案例成功率；
     同一模型加 harness 后 32%→64%（仅指定结局）→92%（完整 harness）。

2. **主要局限性**

   - 规则需要显式给定——现实世界的规则是隐式、凌乱、可学习的，
     "规则从哪来"本文未解决；
   - 符号状态的表达能力有限（离散属性、关系），连续物理
     （流体、形变）难以纳入；
   - 指令编译是 bottleneck：符号→文本→视频的信息损失可能
     导致渲染与状态不一致；
   - 50 对孪生的基准规模较小；
   - 多轮交互中状态回写的错误可能累积。

3. **与其他相关工作的对比**

   - vs **端到端交互视频世界模型（Genie 系、Matrix-Game 等）**：
     它们把规则隐式学进网络，游戏性强但规则一致性无保证；
     Stateful Harness 用外挂符号层换确定性；
   - vs **程序化世界模型 / OOWM（面向对象程序化 WM）**：思想相近
     （显式结构与规则），本文增加神经渲染前端与反事实评测；
   - vs **Hybrid 神经符号规划（PDDL+LLM）**：传统工作止于符号层，
     本文打通到像素级可视化；
   - vs **视频模型物理一致性研究（PhysVid 等）**：那些工作在
     模型内部修物理，本文在模型外部执行规则。

## 核心技术发现

- 发现1：视频模型作为规则执行器在隐藏状态任务上系统性失败
  （最好 32%），因为规则不在像素里；
- 发现2：同一冻结模型 + 符号 harness 可以达到 92% 规则遵循——
  问题在架构不在模型容量；
- 发现3：可编辑 3D 场景 preview 是连接符号状态与视频渲染的
  有效几何桥梁；
- 发现4：反事实孪生对是检验"空间状态表征"的锐利评测工具。

## 与 Spatial AGI 的关系

### 直接贡献

确立了空间智能架构中"状态层"与"外观层"分离的原则，
并提供了检验隐藏状态理解的基准。

### 技术启发

- Spatial AGI 需要**视角不变的持久状态表征**，不能只靠像素记忆；
- 神经渲染 + 符号推理的分层组合可各自发挥确定性/生成性优势；
- 规则可编程意味着世界模型可验证、可编辑、可审计。

### 应用场景

交互式模拟器、规划验证层、世界模型规则外挂、
反事实空间推理数据引擎。

## 个人思考

### 最令人兴奋的发现

32%→92% 这个跃升（模型完全没动）是对"把一切塞进大模型"
思路的有力反驳。世界模型也许不是一个更大的视频模型，
而是一个视频模型加上一台干净的状态机。

### 潜在局限

规则人工给定的假设在开放世界不成立。真正的 Spatial AGI
需要**规则归纳**能力：从观察中学习"这个世界的物理和社会规则"，
再交给符号层执行。规则学习+规则执行的双层架构是下一步。

### 与近期研究的关联

与 CoAWM（连续动作世界模型）、E0.5（未来预测 3D 基础模型）
形成谱系：都在回答"世界模型该把什么显式化"。
Stateful Harness 的答案是：状态与规则显式化，像素留给渲染器。
这与 GOFusion 的"几何+外观+信息分层"共同勾勒出
Spatial AGI 表征栈的分层哲学。

## 关键数据

- WorldState-Bench：50 对反事实孪生场景；
- 11 个视频后端评测；规则提示下最好 32% 双案例正确；
- MiniMax-H3：指定结局 32%→64%；完整 harness 92%（同一冻结模型）。

## 总结

### 核心发现总结

规则执行与像素生成应当解耦：符号状态机负责"世界如何演化"，
冻结视频模型负责"演化看起来什么样"，可编辑 3D 场景做几何桥梁。
反事实孪生评测证明该架构将规则遵循从 32% 提升到 92%。

### 对 Spatial AGI 的意义

空间智能不等于空间外观的生成能力。真正的空间理解包括
视角不变的状态维护与规则推理——这部分应该显式化、
可验证化，而不是指望视频模型的隐式拟合。
