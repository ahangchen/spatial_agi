## 核心问题

### Q1: 核心算法原理

**问题**: 这篇文章的核心算法原理是什么？

**分析**:

这篇论文是一篇综述论文，系统性地梳理了 World Action Models (WAMs) 这一新兴范式。其核心不是提出单个算法，而是建立了一个完整的分类框架来理解如何将世界模型与动作生成统一到一个模型中。

#### 1. 核心思想和动机

**问题背景**: 当前的 Vision-Language-Action (VLA) 模型（如 RT-2, OpenVLA, π₀）学习的是从观察到动作的直接映射 `p(a|o,l)`，**不显式建模物理世界的动态演化**。这导致：

- 缺乏物理推理能力，无法预测动作的后果
- 泛化能力受限，在需要预测未来状态的新场景中表现不佳
- 无法利用大量无动作标注的人类视频数据

**核心主张**: WAMs 将世界模型（预测环境动态）与动作生成（机器人控制）统一到一个框架中，目标是学习联合分布：

```
p(o', a | o, l)
```

即给定当前观察 o 和语言指令 l，同时预测未来状态 o' 和动作 a。

**两大核心准则**:
1. **前向预测建模**: 模型必须预测环境的物理演化（显式视觉预测或隐式物理表示）
2. **耦合动作生成**: 模型必须将动作推导与预测的未来状态严格对齐

#### 2. 主要技术方法 — 分类体系

论文将现有 WAM 方法分为两大架构类别：

**A. 级联式 WAM (Cascaded WAM)**

将目标分解为 `p(o',a|o,l) = p(a|o',o,l) × p(o'|o,l)`，先预测未来状态，再从中推导动作。

根据中间表示类型进一步分为：

**A1. 显式规划（像素空间表示）**

- **学习式动作提取**: 
  - UniPi: 开山之作，视频扩散生成 → 逆动力学模型(IDM)提取动作
  - VLP: 加入VLM进行语义层级干预和树搜索评分
  - RoboEnvision: 非自回归策略，VLM分解子任务 → 生成关键帧 → 插值
  - This&That: 使用指示性表达("this"/"that")+手势坐标消除歧义
  - TesserAct: 加入深度+法线通道引入几何约束
  - MVISTA-4D: 轨迹级潜空间优化 + 残差IDM
  - Vidar: 人类视频→机器人视频转换，支持双手操作
  - Gen2Act: 零样本调用VideoPoet生成人类视频
  - Veo-Act: 门控机制，粗导航用视频IDM，精细接触切换到反应式VLA
  - π₀.7: 用预训练VLA替代IDM，世界模型生成子目标图像注入VLA上下文窗口
  - VAG: 1D U-Net作为动作解码器，视频扩散特征条件化动作生成

- **几何式动作提取**:
  - AVDC: 视频生成 → 密集光流 → SE(3)变换，无需动作标注
  - Im2Flow2Act: 在潜空间估计光流，绕过像素级视频合成
  - 3DFlowAction: 三维光流场，捕获旋转和深度位移
  - NovaFlow/Dream2Flow: 零训练操作，直接使用预训练视频模型
  - Dreamitate: 立体视频扩散 → MegaPose追踪工具6-DoF姿态
  - 4DGen: 多视角一致生成，联合预测RGB视频和3D点图序列
  - RIGVid: FoundationPose追踪被操作物体 + VLM质量控制

**A2. 隐式规划（潜空间表示）**

- VPP: VAE编码观察帧 → 扩散模型预测未来潜序列 → 轻量策略网络，首次实现实时控制
- VILP: 多视角潜规划
- S-VAM: 自蒸馏桥接效率与质量差距
- Video Policy: 冻结视频U-Net，训练独立动作U-Net利用中间特征
- ARDuP: Co-Tracker密集运动追踪 + SAM交互区域掩码
- mimic-video: Flow matching替代DDPM + 部分去噪策略
- MWM: 语义掩码潜变量替代RGB预测，过滤光度干扰
- OmniVTA: 扩展到视觉-触觉域
- LAPA: 无监督潜动作预训练，VQ-VAE从无标签视频学习潜动作
- villa-X: 本体感受前向动力学模型 + 联合扩散框架

**B. 联合式 WAM (Joint WAM)**

直接建模联合分布 `p(o',a|o,l)`，世界预测和动作生成在共享表示空间内共同优化。

**B1. 自回归生成**

将未来世界变量和动作变量序列化为token，通过因果左到右解码建模。

- **显式解耦表示**: 
  - GR-1: 视频预训练Transformer → 双分支头解码未来视觉块和连续动作
  - GR-MG: 宏观/微观步骤层级，扩散生成视觉目标
  - GR-2: VQGAN离散化视觉，CVAE参数化连续动作块

- **统一离散表示**: 
  - CoT-VLA: 因果注意力生成视觉思维链 → 全注意力预测动作token
  - WorldVLA: 模态特定因果掩码，禁止同块动作token相互注意
  - RynnVLA-002: 离散MLLM骨干 + 连续Action Transformer头
  - ℱ1: Mixture-of-Transformer(MoT)，Generation专家 + Action专家

- **预测潜表示**: 
  - VLA-JEPA: 在抽象连续潜嵌入空间进行联合序列建模，无需像素重建

**B2. 扩散式生成**

通过扩散或flow matching并行生成未来状态和动作，克服自回归的顺序瓶颈。

- **统一流架构**（单DiT骨干）:
  - **显式未来预测**:
    - PAD: 联合去噪未来图像潜变量和动作token，支持无动作互联网视频
    - VideoVLA: 复用CogVideoX-5B骨干
    - UWM: 世界/动作变量独立噪声调度，单模型多模式运行
    - Cosmos Policy: 潜帧注入，单检查点同时作为策略/世界模型/价值函数
    - DreamZero: 基于Wan2.1，KV-cache观察替换 + 系统级优化实现实时控制
    - GigaWorld-Policy: 动作注意力仅关注历史观察，推理时无需生成未来视频
    - X-WAM: 交错深度分支实现RGB-D联合建模
  
  - **隐式未来预测**:
    - FLARE: 可学习未来token，内部激活与冻结教师编码器的未来观察嵌入对齐
    - FRAPPE: 后训练方案，多对齐专家 + MoT路由

- **多流架构**（多分支/专家）:
  - **交叉注意力耦合**:
    - CoVAR: Bridge Attention模块联合视频-动作注意力
    - LDA-1B: MM-DiT共享注意力层 + DINO潜空间预测
    - DUST: 世界/动作独立噪声时间步 + 异步采样
    - LingBot-VA: MoT + KV-cache累积完整交错历史
    - DexWorldModel: 双状态TTT记忆替代增长KV-cache
    - AIM: 意图-因果注意力掩码，价值图局部化任务相关区域
    - Motus: 三模态联合注意力（世界+动作+语义理解）
    - MotuBrain: H-bridge结构，全联合注意力仅在中间层
    - AdaWorldPolicy: 力预测器作为第三专家
  
  - **隐藏状态耦合**:
    - DiT4DiT: 视频DiT中间隐藏状态 → Action DiT交叉注意力
    - Fast-WAM: 训练时保留视频分支，推理时移除，仅用编码器潜特征
    - WAV: 视频模块 → 价值模块评估 → 动作解码器
    - Act2Goal: 目标导向，多尺度时间哈希组织近距离/远距离帧和动作
  
  - **共享表示**:
    - UVA: 共享Transformer统一编码 → 轻量视频/动作扩散头分别解码
    - PhysGen: 连续自回归框架，物理token统一建模 → 分离解码路径

#### 3. 算法流程和关键步骤

**WAMs 的通用训练流程**:

```
输入: 当前观察 o_t, 语言指令 l
输出: 未来状态预测 o_{t+1}, 动作序列 a_t

1. 编码阶段:
   - 视觉编码器处理观察 o_t → 视觉token
   - 语言编码器处理指令 l → 语言token
   - (可选) 本体感受编码器处理关节状态

2. 世界预测阶段:
   - Cascaded: 先生成未来状态表示（像素/潜空间/光流）
   - Joint: 在统一框架中并行处理

3. 动作生成阶段:
   - Cascaded: 从预测的未来状态提取动作（IDM/几何计算）
   - Joint: 与世界预测联合解码

4. 联合训练目标:
   L_WAM = E[-log p(o', a | o, l)]
   + 可能包含辅助损失（对齐损失、重建损失等）

5. 推理:
   - 实时控制需要优化推理延迟（KV-cache、异步执行、量化等）
   - 闭环执行：每步接收真实观察替代想象帧
```

#### 4. 输入输出

**输入**:
- 多模态观察 o ∈ O: RGB图像、深度图、本体感受、触觉等
- 语言指令 l ∈ L: 自然语言任务描述
- (可选) 目标图像、动作历史

**输出**:
- 未来状态预测 o': 视频帧、潜表示、光流、语义掩码等
- 动作序列 a: 连续关节角度、末端执行器位姿、离散动作token等

### Q2: 与Spatial AGI的关系

**问题**: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

#### 1. 如何理解和表示空间

WAMs 通过多种途径理解物理空间：

- **像素级视觉预测**: 直接生成未来RGB视频帧，隐式编码空间布局和物体位置变化
- **3D几何表示**: 
  - TesserAct引入深度+法线通道
  - 4DGen联合预测3D点图序列
  - 3DFlowAction生成三维光流场捕获旋转和深度位移
  - PointWorld在3D点流表示下统一状态和动作
- **潜空间表示**: 
  - DINOv3语义特征替代RGB（DexWorldModel）
  - 语义掩码潜变量（MWM）
  - JEPA风格的抽象潜嵌入（VLA-JEPA）
- **多视角一致性**: Ctrl-World, MiLA等实现多相机联合预测
- **触觉空间**: OmniVTA将触觉模态纳入世界建模

**关键洞察**: WAMs的空间理解不是静态的——它必须预测空间在动作干预下的动态演化。这种时空预测能力是Spatial AGI的核心需求。

#### 2. 如何处理空间关系

- **物体间空间关系**: 通过视频预测隐式学习物体间的空间关系变化（碰撞、支撑、包含等）
- **机器人-环境空间关系**: 动作条件化的世界模型显式建模机器人操作如何改变环境的空间配置
- **跨视角空间一致性**: 多视角预测和3D表示确保空间理解的一致性
- **层级空间推理**: 
  - VLP使用VLM进行语义级空间规划
  - GR-MG的宏观/微观层级将空间推理分解
  - Act2Goal的多尺度时间哈希组织近距离和远距离的空间规划

#### 3. 对Spatial AGI的启发

**最核心的启发**: WAMs提出了一种**预测性空间智能**的范式——真正的空间理解不仅意味着感知当前的空间配置，更意味着能够预测空间在交互下的演化。

具体启发：

1. **世界模型作为空间智能的基础设施**: WAMs表明，将世界动态内化到模型中是构建空间智能agent的关键步骤。Spatial AGI需要一个内部的世界模拟器。

2. **多模态空间感知**: 从纯RGB到RGB-D、光流、语义掩码、触觉，WAMs展示了多模态融合对于完整空间理解的重要性。Spatial AGI也需要超越纯视觉的空间感知。

3. **从数据中学习物理规律**: WAMs通过大规模视频数据学习物理先验（重力、碰撞、变形），这为Spatial AGI提供了一条从数据而非手工规则学习物理的路径。

4. **联合训练策略**: WAMs展示了如何利用异构数据源（机器人遥操作、人类视频、仿真、UMI）进行联合训练，这对Spatial AGI的数据策略至关重要。

5. **实时推理的工程实践**: DreamZero等工作的系统级优化（异步执行、DiT缓存、量化）为Spatial AGI的实时部署提供了工程参考。

#### 4. 可以应用的Spatial AGI场景

1. **家庭服务机器人**: 需要预测操作后果（打开柜门后的空间变化、放置物体的稳定性）
2. **自动驾驶**: 预测交通参与者的未来行为和环境演化
3. **工业装配**: 预测零件装配过程中的空间关系变化
4. **人形机器人操控**: 双手协调操作中的空间推理和预测
5. **导航与探索**: 在未知环境中预测路径可行性和空间布局
6. **柔性物体操作**: 预测变形物体的空间状态变化（布料折叠、线缆整理）

### Q3: 创新点和局限性

#### 1. 主要创新点

**作为综述论文的创新**:

1. **首次系统定义WAMs**: 提供了严格的概率框架定义 `p(o',a|o,l)`，清晰区分了WAMs与VLA、世界模型、视频策略等相关概念

2. **完整的分类体系**: 
   - Cascaded vs. Joint的二分法
   - 按中间表示（像素/潜空间/光流）、生成方式（自回归/扩散）、耦合机制（交叉注意力/隐藏状态/共享表示）的细粒度分类
   - 涵盖80+篇论文的全面覆盖

3. **数据生态系统的系统分析**: 四大数据范式的梳理（遥操作、UMI、仿真、人类视频），以及它们之间的trade-off分析（图7的Transfer Difficulty vs. Scaling Difficulty）

4. **评估协议的综合**: 从视觉保真度、物理常识、动作合理性三个维度组织评估

5. **丰富的表格和图表**: 
   - Table 1-3的详细方法对比（参数量、骨干网络、评估场景）
   - Figure 1的时间演化图
   - Figure 5-6的架构示意图

**WAMs作为一个领域的创新**:

1. **从反应式到预测式的范式转变**: VLA只做反应式映射，WAMs引入了物理预测能力

2. **统一数据消化能力**: 可以同时利用 (o_t, a_t) 对、(o_t, o_{t+1}) 序列、和完整 (o_t, a_t, o_{t+1}) 三元组

3. **多样化的架构探索**: 从简单的两阶段级联到复杂的多专家MoT，展示了丰富的设计空间

4. **实时控制的工程突破**: DreamZero等展示了WAMs可以实际部署到实时机器人控制中

#### 2. 主要局限性

**综述本身的局限**:

1. **缺乏定量对比**: 作为综述，没有在统一基准上对比不同方法的性能，各论文报告的指标不具可比性

2. **覆盖面广但深度有限**: 80+篇论文的覆盖意味着每篇只能点到为止，缺乏对单个方法的深入批判性分析

3. **开源复现性**: 综述本身不提供可复现的实验

**WAMs作为领域的局限**:

1. **计算成本**: 
   - 扩散式WAMs的推理延迟仍然是实际部署的主要瓶颈
   - 联合生成（视频+动作）的计算开销远大于纯VLA

2. **误差累积**: 
   - 自回归方法的长程预测存在严重的误差累积问题
   - 级联式方法中世界模型的预测误差会传播到动作生成

3. **物理准确性**: 
   - 基于视频生成的世界模型可能生成视觉合理但物理不正确的预测
   - 对精细物理交互（接触力、摩擦、变形）的建模仍然不足

4. **评估鸿沟**: 
   - 大多数评估在仿真环境中进行，真实世界部署验证有限
   - 缺乏统一的评估基准来同时评估世界模型质量和动作策略性能

5. **数据需求**: 
   - 高质量的 (o_t, a_t, o_{t+1}) 三元组数据仍然稀缺
   - 如何有效融合异构数据源仍是一个开放问题

6. **泛化能力**: 
   - 跨具身形态的泛化仍然有限
   - 对训练分布之外的场景和物体类型的泛化能力未充分验证

7. **安全性和可靠性**: 
   - 世界模型的"幻觉"可能导致危险的机器人动作
   - 缺乏对预测不确定性的显式建模

#### 3. 与其他相关工作的对比

| 维度 | 标准VLA | 世界模型(独立) | WAMs |
|------|---------|---------------|------|
| 目标 | p(a\|o,l) | p(o'\|o,a) | p(o',a\|o,l) |
| 物理推理 | 无 | 有 | 有 |
| 动作生成 | 直接映射 | 需外接策略 | 内置 |
| 数据需求 | (o,a)对 | (o,a,o')三元组 | 可融合多种数据 |
| 推理速度 | 快 | 中等 | 慢（当前） |
| 泛化能力 | 中等 | 强 | 最强（潜力） |

## 核心技术发现

### 发现1: 级联vs联合的根本trade-off

- **级联式**: 解耦设计，世界模型和动作模型可独立优化，但存在级联误差和信息瓶颈
- **联合式**: 紧耦合设计，世界-动作交互更深，但训练复杂且计算开销大
- **趋势**: 联合式方法正在成为主流，特别是扩散式联合WAMs

### 发现2: 扩散模型主导但自回归在追赶

- 扩散式方法在生成质量和多模态分布建模上占优
- 自回归方法在序列一致性和与LLM架构兼容性上有优势
- ℱ1和VLA-JEPA展示了自回归方法的潜力

### 发现3: 从像素到潜空间的演化趋势

- 早期工作依赖像素级视频预测（UniPi）
- 中期探索光流、语义掩码等中间表示
- 近期主流转向潜空间预测（VPP, FLARE, VLA-JEPA），兼顾效率和表示质量
- 关键洞察：像素重建是不必要的计算浪费，抽象的物理状态表示才是核心

### 发现4: 预训练视频基础模型的价值

- Wan2.1, Cosmos-Predict2, CogVideoX等预训练视频模型成为WAMs的核心骨干
- 这些模型携带了互联网规模的世界知识，为机器人策略提供了丰富的物理先验
- 微调而非从零训练已成为主流范式

### 发现5: 实时控制的系统级优化

- DreamZero展示了异步执行、DiT缓存、量化、CUDA-graph等工程优化
- Fast-WAM展示了训练时保留世界分支、推理时移除的策略
- GigaWorld-Policy让动作注意力仅关注历史观察，推理时无需生成未来视频
- 这些工程实践对WAMs的实际部署至关重要

### 发现6: 数据混合训练策略

- UWM的独立噪声调度允许优雅处理无动作视频数据
- PAD的注意力掩码策略支持动作标注和纯视频数据的混合训练
- LAPA/villa-X的潜动作学习从无标签视频提取动作信息
- 这种数据灵活性是WAMs相对于纯VLA的核心优势

## 与Spatial AGI的关系

### 直接贡献

1. **预测性空间推理框架**: WAMs提供了一个将空间感知和空间预测统一到策略学习中的完整框架。Spatial AGI的核心——理解和预测物理世界的空间演化——正是WAMs的设计目标。

2. **从数据学习物理**: WAMs展示了如何从大规模视频数据中学习物理规律（重力、碰撞、接触、变形），为Spatial AGI提供了一条数据驱动的物理理解路径。

3. **3D空间表示**: TesserAct, 4DGen, PointWorld等工作将WAMs扩展到3D几何表示，直接服务于Spatial AGI的3D空间理解需求。

### 技术启发

1. **世界模型作为空间智能的核心组件**: WAMs的架构设计（级联/联合、显式/隐式）为Spatial AGI的架构选择提供了丰富的参考。

2. **多模态空间感知**: 触觉、深度、力反馈等多模态信息的融合对于完整的Spatial AGI至关重要。

3. **大规模预训练 → 下游微调的范式**: 视频基础模型预训练 → 机器人任务微调的范式可以迁移到更广泛的Spatial AGI场景。

4. **评估体系**: 视觉保真度、物理常识、动作合理性三个维度的评估框架可以直接应用于Spatial AGI的评估。

### 应用场景

1. **通用机器人操控**: 预测操作后果，处理未见物体和环境
2. **自主导航与探索**: 在未知环境中预测空间布局变化
3. **人机协作**: 预测人类动作和环境演化，实现安全协作
4. **数字孪生**: 精确的物理世界模拟和预测
5. **具身智能体**: 在虚拟环境中进行物理合理的交互

## 个人思考

### 最令人兴奋的发现

1. **WAMs统一了两个长期分离的研究方向**: 世界模型（强化学习中的环境建模）和VLA（机器人策略学习）的统一是一个深刻的架构决策，它不仅解决了技术问题，更提供了正确的概念框架。

2. **潜空间预测的优雅性**: FLARE和VLA-JEPA展示了不需要像素级重建就能实现物理预测的路径。这与人类认知的"内部模拟"更加一致——我们不会在脑中渲染高清视频，而是在抽象表示层面进行推理。

3. **数据灵活性的战略意义**: WAMs能利用无动作标注的互联网视频是关键突破。机器人数据的获取成本极高，而人类操作视频几乎无限。LAPA的潜动作预训练和UWM的噪声调度是特别优雅的解决方案。

4. **单检查点多模式的愿景**: UWM和Cosmos Policy展示了一个模型同时作为策略、世界模型、价值函数的潜力——这是通向通用空间智能agent的重要一步。

### 潜在局限

1. **评估的真实世界差距**: 绝大多数方法只在LIBERO、CALVIN、MetaWorld等仿真基准上评估。从仿真到真实世界的迁移仍然是一个巨大挑战。论文中对Real列标记为"-"的方法占比很高。

2. **长程推理的缺失**: 几乎所有方法的评估都是短horizon任务（单步或少数几步操作）。真正的Spatial AGI需要长程的规划和推理能力。

3. **物理准确性的验证不足**: "视觉上合理"不等于"物理上正确"。视频生成模型的已知问题（物体变形、违反物理规律的生成）在WAMs中可能被继承。

4. **可解释性**: 联合WAMs的内部工作机制（特别是扩散式方法）仍然是黑箱。模型预测的未来状态是否真正编码了物理规律，还是只是统计模式的记忆？

5. **安全性考量不足**: 论文几乎没有讨论WAMs的安全性问题。当世界模型"幻觉"时，机器人可能执行危险动作。需要更多的不确定性量化和安全约束机制。

### 与空间智能研究的关联

1. **从2D到3D的扩展**: 当前大多数WAMs工作在2D视觉空间。与3D Gaussian Splatting、NeRF、3D重建等空间智能技术的结合是一个重要的未来方向。PointWorld是一个初步尝试。

2. **与空间推理的结合**: WAMs目前主要关注低级操控任务的动态预测。将高级空间推理（空间关系理解、场景图、导航规划）与WAMs结合，可以构建更完整的Spatial AGI系统。

3. **物理模拟的融合**: 当前WAMs从数据中隐式学习物理。与显式物理模拟器（MuJoCo, IsaacGym）的融合，或者利用物理先验约束WAMs的预测，可能提高物理准确性。

## 训练数据生态系统

论文系统分析了四大类训练数据源及其对WAMs的独特价值：

### 1. 机器人遥操作数据

- **优势**: 最高质量的动作标注，精确的运动学grounding
- **劣势**: 收集成本高，环境多样性受限，规模化困难
- **趋势**: 从单实验室 → 多机器人聚合(OXE, ARIO) → 自动化生成(Grasp-Anything, Interleave-VLA)
- **对WAMs价值**: 提供高质量的 (o_t, a_t, o_{t+1}) 三元组

### 2. UMI风格人类示范数据

- **优势**: 便携低成本，真实环境多样性高
- **劣势**: 人-机器人形态差距，需要动作重定向
- **趋势**: 从简单夹爪 → 灵巧手 + 触觉 + 多视角 → 百万级规模(RealOmin)
- **对WAMs价值**: 桥接高质量动作标注和环境多样性的trade-off

### 3. 仿真数据

- **优势**: 无限可扩展，完美ground truth，安全
- **劣势**: 仿真到真实的domain gap
- **对WAMs价值**: 物理引擎本质上是精确计算世界模型，提供无限的三元组数据

### 4. 人类/自我中心视频

- **优势**: 近乎无限规模，极端环境多样性
- **劣势**: 无动作标注，人-机器人差距大
- **对WAMs价值**: WAMs的独特优势——通过世界建模目标利用无动作视频学习物理先验

### 数据混合策略

论文展示了WAMs如何灵活利用不同数据源：
- **有动作数据**: 完整的 WAM 训练损失
- **无动作视频**: 仅世界建模损失（UWM的完全噪声化动作侧、PAD的注意力掩码）
- **低质量数据**: 仅动力学预测（LDA-1B的分层监督）
- **潜在动作**: 从视频中自监督提取（LAPA, villa-X）

## 评估协议

### 世界模型质量评估

1. **视觉保真度** (Visual Fidelity):
   - PSNR/SSIM: 像素级重建质量
   - LPIPS/DreamSim: 感知相似度
   - FVD: 视频整体质量

2. **物理常识** (Physical Commonsense):
   - VideoPhy, PhyGenBench: 物理合理性评估
   - Physics-IQ: 物理智能测试
   - WorldScore: 综合世界模型评分

3. **动作合理性** (Action Plausibility):
   - WorldSimBench: 世界模拟合理性
   - WoW, wo, val!: 交互性评估

### 策略质量评估

覆盖从仿真到真实部署的完整评估链：
- 仿真基准: MetaWorld, RLBench, CALVIN, LIBERO系列
- 泛化测试: COLOSSEUM, AGNOSTOS, SimplerEnv
- 真实设备: RoboArena, RoboChallenge

### 评估gap分析

- **缺乏WAM专用基准**: 当前评估要么只评世界模型质量，要么只评策略性能
- **需要联合评估**: 同时评估预测准确性和控制性能
- **物理准确性评估不足**: 视觉合理 ≠ 物理正确

## 开放挑战与未来方向

### 1. 长程时空一致性
- 当前方法主要处理短horizon（1-5秒）
- 长程任务需要层级规划和错误恢复机制
- GR-MG的宏观/微观分解是一个初步尝试

### 2. 物理准确性
- 视频生成模型的"幻觉"问题
- 需要物理约束或物理感知的评估
- 与显式物理模拟器的融合

### 3. 计算效率
- 扩散式WAMs的推理延迟
- 需要更高效的架构设计（如Fast-WAM的策略）
- 边缘设备部署的可能性

### 4. 3D空间理解
- 当前大多数方法基于2D视觉
- 与3D重建、NeRF、Gaussian Splatting的结合
- PointWorld的3D点流表示是一个方向

### 5. 多具身泛化
- 跨机器人形态的策略迁移
- 统一的动作空间表示
- 人类→机器人的动作迁移

### 6. 安全性和可靠性
- 预测不确定性量化
- 安全约束下的动作生成
- 人在环路的验证机制

### 7. 开放世界泛化
- 从封闭实验室到开放世界的迁移
- 未见物体、未见环境的处理
- 持续学习和在线适应

## 总结

### 核心发现总结

本综述是World Action Models领域的**奠基性工作**，系统性地：

1. **定义了WAMs**: 从概率框架出发，严格定义了 `p(o',a|o,l)` 的联合建模目标
2. **建立了分类体系**: Cascaded vs. Joint，显式 vs. 隐式，自回归 vs. 扩散的完整分类
3. **覆盖了80+方法**: 涵盖了2024-2026年的几乎所有重要工作
4. **分析了数据生态**: 四大数据源的全面梳理和trade-off分析
5. **综合了评估协议**: 视觉保真度 + 物理常识 + 动作合理性的三维评估

### 对Spatial AGI的意义

WAMs代表了从**反应式空间智能**到**预测式空间智能**的关键转变：

- **反应式** (VLA): 看到什么 → 做什么
- **预测式** (WAM): 看到什么 → 预测未来 → 做什么

这种预测能力是Spatial AGI的核心——真正理解空间意味着不仅能感知当前的空间配置，还能预测空间在交互下的演化。WAMs提供了实现这一目标的具体技术路径。

**最重要的takeaway**: 将世界模型嵌入到策略架构中，而不是作为外部工具，是构建Spatial AGI的正确方向。这不是一个工程优化，而是架构层面的必要设计——只有当策略"看到"自己动作的后果时，它才能做出真正智能的决策。
