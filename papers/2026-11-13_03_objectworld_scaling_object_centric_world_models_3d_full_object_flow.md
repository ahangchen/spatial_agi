## 核心问题

### Q1: 核心算法原理

**问题**: 这篇文章的核心算法原理是什么？

**分析**:

#### 1. 核心思想和动机

机器人操作的数据瓶颈是具身智能最深的痛点：动作标注的真机数据采集昂贵、绑定本体、远比视觉数据稀缺。生成式世界模型提供了一条绕开"直接动作监督"的路线——从大规模视觉经验中学习"物体和场景如何演化"。但这条路线需要一个**中间表示**，它必须同时满足两个苛刻条件：

1. **可大规模监督（scalable to supervise）**：能从海量视频中自动恢复；
2. **对下游控制可执行（actionable for control）**：能被机器人控制器消费。

现有表示的权衡：

| 表示 | 优点 | 缺点 |
|------|------|------|
| 像素空间（目标图像/视频） | 视觉信息丰富 | 对控制间接，需额外 grounding |
| 稀疏关键点/可供性点 | 接口简洁 | 丢失完整物体运动 |
| 6-DoF 物体位姿 | 有度量结构 | 刚体假设，无法表达形变 |
| 物体流（partial object flow） | 物体中心、可跨本体 | 只覆盖**可见表面**，遮挡区域无运动定义 |

ObjectWorld 的核心提案：**3D full-object flow（3D 全物体流）**——把稠密3D轨迹分配到目标物体**完整表面**的所有点上，包括被遮挡区域。通过在重建的完整几何上铺开运动场，这个表示：

- 使**完整物体运动显式化**（可见+不可见表面统一描述）；
- **统一覆盖刚体与可变形物体**（稠密对应场天然兼容非刚性形变）；
- **本体无关**（基于物体运动学而非机器人特定动作）；
- **可直接优化**（下游控制器可针对物体级运动目标做优化）。

#### 2. 主要技术方法

**（a）问题形式化**

给定初始 RGBD 观测 ℐ 和语言指令 ℒ，世界模型预测：

P̂^obj_{1:T} = {p̂_{i,t} ∈ R³}，其中 N^obj=512 个物体点，T=48 步预测时域。

每个 p̂_{i,t} 是物体点 i 在时刻 t 的预测3D位置。这个"期望物体运动"作为高层任务预测与底层机器人执行的接口。

下游执行是流条件动作优化：

τ* = argmin_τ D(Φ(ℐ,τ), P̂^obj_{1:T}) + λR(τ)

其中 τ 是末端执行器轨迹，Φ(ℐ,τ) 是执行 τ 引起的物体运动，D 度量与预测流的差异，R 正则化平滑性/可行性。**关键结构**：机器人的动作不是被直接预测，而是通过"优化使物体运动逼近世界模型想象的目标运动"来求解——解耦了想象与执行。

**（b）1210 小时数据集与自动标注管线**

数据集构成（统一 16 FPS 计时）：

- **仿真子集 454.5 小时**：198,947 条轨迹，251 个任务，聚合 ManiSkill 3、MetaFold（可形变物体）、Meta-World、MIKASA、RLBench、RoboCasa、RoboTwin 2.0 七个数据源；
- **真实世界子集 755.6 小时**：289,976 个片段，来源包括 AgiBot World（机器人演示）、Something-Something V2（第三人称人类演示）、EPIC-KITCHENS（第一人称人类演示）。

**真实世界自动标注管线**（无需机器人动作、深度、标定相机、预扫描网格）：

1. **VLM 预处理**：Gemini 2.5 Pro 识别目标物体、生成任务描述、把原始视频切分为原子操作片段（每次"接触-分离"交互一段）；
2. **相机位姿+点云**：Track4World（Depth Anything 3 主干）估计相机位姿并重建每帧点云（统一到首帧相机坐标系）；
3. **目标分割**：VLM 提案 + SeC 传播目标 mask；
4. **几何重建与跟踪**：SAM 3D 重建完整物体 mesh → Any6D 估计初始位姿 → FoundationPose 全程跟踪位姿；
5. **流生成**：在 canonical 物体坐标系均匀采样 mesh 表面点，每步用"跟踪位姿 × 相机到参考系变换"变换，得到稠密轨迹。

**质量过滤**：每帧将重建物体按估计位姿投影回图像，与传播 mask 算 IoU；在专家标注校准集上定阈值后全库过滤——空间-时间一致性双指标系统化质控。

**（c）世界模型架构（全物体流预测）**

输入：首帧 RGB-D + 任务指令。

1. **初始3D观测构建**：SAM2 得目标 mask → SAM3D 重建完整几何 → Any6D 初始位姿把 mesh 放入场景 → mesh 表面采样得完整物体点集 P^o（512点）；深度反投影得场景点云 P^s；
2. **多模态编码**：
   - 视觉-语言通路：Qwen2.5-VL 编码 RGB+指令，物体点3D坐标投影到图像采样逐点语义特征；
   - 3D通路：Point Transformer V3（PTv3）联合编码物体+场景点云（物体表征融入场景几何上下文）；
3. **融合与解码**：两路特征融合为 object tokens → 自注意力精炼 → cross-attention decoder（object queries 读取场景与语言上下文，条件于噪声流和时间 t）→ flow head 输出稠密位移轨迹 F = {ΔP^o_t}，t=1..48。

预测的是相对初始表面的**位移场**，天然兼容非刚性形变（不同点不同位移）。

**（d）下游执行**

轻量优化模块把预测流转为末端执行器轨迹：最小化"执行后物体运动"与"预测物体运动"的差异 + 平滑正则。无需重新训练策略网络，跨本体只需换 Φ 的实现。

#### 3. 算法流程和关键步骤

1. 离线：视频 → VLM 切分 → 重建+跟踪 → 全物体流标注 → IoU 质量过滤 → 1210h 数据集；
2. 在线感知：RGB-D 首帧 → SAM2/SAM3D/Any6D → 完整物体几何+场景点云；
3. 预测：Qwen2.5-VL 语义特征 + PTv3 几何特征 → 融合 → 条件生成 512点×48步位移场；
4. 执行：优化末端轨迹使物体运动逼近预测流 → 执行。

#### 4. 输入输出

- **输入**：初始 RGB-D 图像 + 自然语言任务描述。
- **输出**：目标物体完整表面的稠密3D轨迹（512点 × 48步），再优化为机器人末端执行器轨迹。

### Q2: 与Spatial AGI的关系

**问题**: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**分析**:

#### 1. 如何理解和表示空间

ObjectWorld 的空间表示是一个**物体中心的显式运动场**：

- 空间被分解为"物体几何（mesh表面点）+ 物体运动（每个点的3D轨迹）+ 场景上下文（场景点云）"三层；
- 与视频 latent（SWAM）或语义地图（Compass 1）不同，这是**几何显式**的表示——每个点的位置有明确3D坐标；
- "完整表面（含遮挡区）"是关键：空间智能不应只理解看得见的部分，真正的空间理解包含对不可见几何的想象与推理。全物体流把"看不见但会动"的部分显式纳入预测。

#### 2. 如何处理空间关系

- **物体-环境关系**：PTv3 联合编码物体与场景点云，运动预测天然条件于空间上下文（推桌子要考虑地板、拉抽屉要考虑柜体）；
- **物体-物体/物体-手关系**：原子操作片段的切分（接触-分离交互）把操作中的接触关系结构化；
- **时间维度上的空间演化**：48步位移场是"空间关系的时序推演"——从静态关系预测未来关系。

#### 3. 对Spatial AGI的启发

1. **中间表示是规模化与可执行性的枢纽**：Spatial AGI 的各能力（感知/想象/行动）需要统一的中间表示来衔接。ObjectWorld 证明"稠密3D运动场"是这样一个枢纽——既可从视频大规模自动恢复，又可被控制器直接消费。这个"两可性"标准（scalable + actionable）应成为空间表示设计的普适判据。
2. **显式几何与生成模型的结合范式**：预测不发生在像素空间而在 mesh 表面点上——生成模型（flow head）负责"想象运动"，显式几何负责"承载运动"。这避免了视频生成路线的几何模糊问题。
3. **自动标注管线 = 数据引擎**：1210小时数据中 62% 来自野外视频的自动标注，VLM+重建+跟踪的组合管线证明了"无动作标注的视频 → 几何监督"的转化是可规模化的。这直接回应了空间智能最大的数据瓶颈。
4. **遮挡推理的操作化**：全物体流要求模型想象遮挡区域的运动，这是空间智能中"amodal completion"（不可见完成）能力的操作化训练信号。

#### 4. 可以应用的Spatial AGI场景

- 跨本体操作基座（想象物体运动 → 本体无关执行）；
- 可形变物体操作（折叠衣物、绑绳、处理食物）——6-DoF 位姿路线做不到的；
- 世界模型与机器人控制的接口标准化；
- 从互联网视频挖掘操作监督的数据引擎。

### Q3: 创新点和局限性

**问题**: 基于前面的分析，这个方法的主要创新点和局限性是什么？

**分析**:

#### 1. 主要创新点

1. **表示创新：3D full-object flow**：把物体流从可见表面扩展到完整几何（含遮挡），统一刚体/可形变物体，兼顾可大规模监督与可执行性——补上了表示谱系的关键空位。
2. **1210小时数据集 + 可扩展标注管线**：首个大规模"完整3D物体运动"监督数据集；管线无需深度/标定/网格先验，IoU 一致性质控 + 专家校准，工程质量高。
3. **数据来源的多样性**：7个仿真数据源 + 3类真实视频（机器人/第三人称/第一人称），证明管线对异构来源的通用性。
4. **架构组合务实**：Qwen2.5-VL（语义）+ PTv3（几何）+ SAM系（感知）+ FoundationPose（跟踪），每个组件用当前最强开源件，系统级创新而非单点架构 novelty。
5. **验证闭环完整**：标注质量 → 数据 scaling 增益 → 预测质量 → 跨场景/跨本体操作成功，四层实验覆盖全链路。

#### 2. 主要局限性

1. **重建-跟踪误差传导**：整条管线依赖 SAM3D 重建质量和 FoundationPose 跟踪精度；遮挡严重、透明/反光物体、快速运动场景中误差会放大，IoU 过滤只能剔除最差的。
2. **物体中心视角的局限**：只预测目标物体的运动，不建模场景中其他物体的响应（推倒多米诺、倒水弄湿桌面）——操作的真实世界后果不止目标物体。
3. **接触建模缺失**：位移场描述"物体如何动"，但不描述"手如何接触"——抓取点的选择仍需外部模块，接触密集任务（穿针、打结）可能吃力。
4. **512点/48步的分辨率**：对精细操作（亚厘米对准）和大时程任务可能不够。
5. **单物体假设**：原子片段定义为单目标物体交互，多物体协作任务（双手操作两物体）超出表示范围。

#### 3. 与其他相关工作的对比

- **vs Im2Flow2Act**：2D图像点跟踪流 vs ObjectWorld 的3D完整表面流——维度（2D→3D）和覆盖（可见→完整）双重升级。
- **vs Dream2Flow / NovaFlow**：从生成视频的 masked 跟踪点导出物体中心3D流——仍是可见区域；ObjectWorld 直接在重建完整几何上定义运动目标。
- **vs PointWorld**：预测动作条件的**全场景**3D点流（RGB-D+动作输入）vs ObjectWorld 预测**单目标物体**完整表面流（图像+语言输入，动作由优化求解）。前者场景全面但输入依赖机器人动作，后者物体深入且本体无关。
- **vs 6-DoF 位姿方法**：位姿有度量但刚体假设；全物体流兼容形变，代价是放弃了位姿的参数化简洁性。
- **优势**：表示的表达力与通用性、数据规模、跨本体能力。
- **劣势**：管线复杂度、误差传导链长、场景级理解弱于 PointWorld。

## 核心技术发现

- **发现1**：全物体流使刚体与可形变物体在单一表示下统一——位移场不需要刚体假设，形变就是"不同点不同位移"。
- **发现2**：真实世界62%（755.6/1210小时）的监督来自野外视频自动标注，"视频→几何监督"的转化管线可行且质量可控（IoU 过滤+专家校准）。
- **发现3**：流预测随数据量 scaling 提升——物体运动预测是一种可规模化学习的能力，不是只能靠仿真穷举的任务。
- **发现4**：优化式执行（物体运动匹配）实现跨场景/跨本体迁移，无需为每个机器人重训策略。

## 与Spatial AGI的关系

### 直接贡献

ObjectWorld 构造了 Spatial AGI 技术栈中**物体级空间动力学想象**层：给定"世界此刻的样子+想达成什么"，显式想象"物体未来如何运动"。它同时贡献了该层最大规模的训练数据。

### 技术启发

- **两可性判据**：空间中间表示必须"可大规模监督 + 可下游执行"，这是评估一切空间表示候选（视频latent、点云流、场景图、占用场）的统一标尺；
- **显式几何承载生成式想象**：几何与动力学的分工（mesh 承载、flow head 想象）比纯视频生成更可控制；
- **数据引擎思维**：标注管线是资产，数据集只是管线的输出。

### 应用场景

跨本体操作基座、可形变物体操作、互联网操作视频挖掘、世界模型评估（物体流是可度量的预测目标）、操作任务的视觉规划。

## 个人思考

### 最令人兴奋的发现

最有意思的是"全物体流"对**遮挡**的处理。可见表面流是"所见即所测"，而全物体流要求模型知道"抽屉背面、杯子把手内侧此刻在哪、将去哪"——这本质上是把 amodal 空间推理（对不可见的推理）变成了操作的必要组件。监督信号来自"重建几何×跟踪位姿"，而预测时模型必须从单帧可见观测想象出完整几何再预测其运动。这是一条把"空间想象力"显式注入操作系统的路线。

其次是 62% 监督来自野外视频这个数字。操作学习的"数据天花板"一直被认为是真机数据的采集速度，ObjectWorld 说明物体运动监督可以从人类视频海量提取——瓶颈从"采集"转移到"管线精度"。

### 潜在局限

物体中心的视角有深刻的边界：真实操作是"手-物体-环境"的三体问题。ObjectWorld 把"手"抽象为优化变量、把"环境"冻结为上下文点云，只想象"物体"。对环境会响应的任务（叠被子压到枕头的形变传播），预测会失真。此外整条管线是"重建+跟踪+生成"的串联，每一环的失败模式不同，系统的端到端可靠性上限受最短板制约。

### 与今日研究的关联

今天五篇论文形成了一个漂亮的互补结构：SWAM 用视频 latent 做隐式想象（想象先于行动），ObjectWorld 用全物体流做显式想象（几何承载的想象先于行动）——同一个"想象→行动"原则的隐式/显式两个版本。ObjectWorld 的 1210h 数据集与 SWAM 的 47k h 数据池、Compass 1 的 2500h 标注数据一起，勾勒出空间智能数据建设的三条战线：视频先验、物体动力学、空间记忆。

## 关键数据

- 数据集：1210.1 小时（16 FPS 标准化）
  - 仿真 454.5h：198,947 轨迹 / 251 任务 / 7 个数据源（含 MetaFold 可形变物体数据）
  - 真实 755.6h：289,976 片段 / 3 类来源（AgiBot World、Something-Something V2、EPIC-KITCHENS）
- 预测规格：512 物体表面点 × 48 步位移
- 标注管线：Gemini 2.5 Pro（切分）→ Track4World/DA3（位姿+点云）→ SeC（mask传播）→ SAM 3D（mesh重建）→ Any6D（初始位姿）→ FoundationPose（跟踪）→ IoU 一致性过滤（专家校准阈值）
- 模型：Qwen2.5-VL（视觉语言编码）+ PTv3（点云编码）+ cross-attention decoder + flow head

## 总结

### 核心发现总结

ObjectWorld 提出 3D full-object flow 作为生成式世界模型与机器人执行之间的物体中心接口：在重建的完整物体几何（含遮挡区域）上定义稠密3D轨迹，统一刚体与可形变物体。配套 1210 小时数据集（62%来自野外视频自动标注管线）与图像+语言→全物体流的世界模型（Qwen2.5-VL + PTv3 + flow head），下游通过流条件优化求解末端轨迹。实验验证标注质量、数据 scaling 增益与跨场景/跨本体操作泛化。

### 对Spatial AGI的意义

它给出了空间中间表示的"两可性"设计判据（可大规模监督+可执行），示范了显式几何与生成式想象结合的范式，并证明物体动力学监督可以从互联网视频规模化提取。物体级显式运动想象是连接"视频生成式世界模型"与"度量级操作执行"的关键桥梁——空间智能从"看得懂"到"动得了"的那一步。

## 深度补充分析

### A. 表示谱系与 ObjectWorld 的定位

把操作任务的中间表示按"几何显式度"与"覆盖完整度"两个轴排列：

```
覆盖完整度 →
几何显式度 ↓
          │ 像素/视频        │ 目标图像
          │ (SWAM类)         │
          ├─────────────────┼──────────────────
          │ 部分物体流        │ 全物体流
          │ (Im2Flow2Act)    │ (ObjectWorld) ← 本文
          ├─────────────────┼──────────────────
          │ 6-DoF位姿        │ (位姿+形变参数, 尚无)
          │ (位姿类方法)      │
```

ObjectWorld 占据右上象限：几何显式（每点3D坐标）+ 覆盖完整（含遮挡表面）。它放弃的是像素外观（颜色、纹理、光影）——对操作而言，"物体去哪"比"看起来什么样"更本质，这个取舍是合理的。

### B. 标注管线的误差分析

管线每一环的典型失败模式与系统性影响：

| 环节 | 失败模式 | 后果 | 缓解 |
|------|---------|------|------|
| VLM 切分 | 原子操作边界错误 | 片段内运动不完整 | Gemini 2.5 Pro 语义理解 |
| Track4World 位姿 | 纹理弱/快速运动漂移 | 全局坐标系错位 | DA3 深度主干 |
| SeC mask 传播 | 遮挡后丢失/漂移 | IoU 过滤剔除 | IoU 一致性检查 |
| SAM3D 重建 | 对称/遮挡区域几何错误 | "完整表面"本身有误 | ——（最薄弱环节） |
| FoundationPose | 长时程跟踪漂移 | 流轨迹弯曲失真 | IoU 过滤 |
| Any6D 初始位姿 | 初始对齐错误 | 整段流系统性偏移 | —— |

关键洞察：**IoU 过滤只能捕捉"重建与观测不一致"的错误，无法捕捉"重建本身错误但自洽"的错误**——例如 SAM3D 把杯子把手重建错了形状，跟踪自洽，IoU 正常，但把手区域的流是错的。数据集的精度上限由重建质量决定，这可能是 512 点流中"遮挡区域精度低于可见区域"的系统性来源。

### C. 数据 scaling 的实证意义

论文报告流预测随数据量提升（data-scalable flow prediction）。这个结论值得放大解读：

1. **物体运动预测是"可学习统计规律"而非"需求解的物理问题"**：杯子被推会滑动、抽屉被拉会平移、衣物被抖会展开——物体动力学有大量可从数据学习的先验，不需要精确物理仿真即可预测"大致正确"的运动，而"大致正确"足以指导操作优化。
2. **数据来源多样性可能是 scaling 的关键而非总量**：454h 仿真（物理精确但分布窄）+ 755h 真实视频（分布广但精度低）的混合是否优于同总量单一来源？论文未做该消融——这是数据配方维度的开放问题（可对照 SWAM 的配方研究）。
3. **scaling 上限未知**：1210h 之后的增益曲线如何？物体运动的 long-tail（罕见形变模式）可能需要更多数据或物理先验注入。

### D. 执行模块的深入解读

流条件动作优化 τ* = argmin D(Φ(ℐ,τ), P̂^obj) + λR(τ) 的几个要点：

- **Φ 是正向模型**：给定初始观测与候选动作，预测物体运动。这可以是一个简化动力学模型（如刚体+接触近似）或学习到的正向模型。执行质量的上限由 Φ 的保真度决定——世界模型想象得再好，正向模型不准就执行不出。
- **本体无关的代价**：换本体只需换 Φ（不同臂的运动学/动力学），但 Φ 的精度随本体复杂度下降——末端执行器（夹爪）比灵巧手难建 Φ，所以论文的跨本体验证大概率集中在夹爪类。
- **无重策略训练**：与传统模仿学习（每个本体重训策略）相比，优化式执行是"一次想象、处处执行"。代价是推理时优化计算（采样/梯度迭代）与对 Φ 的依赖。
- **闭环问题**：48步开环想象+优化执行是准开环的。执行偏差累积后需要重新感知-想象循环，论文未详述闭环频率。

### E. 与操作学习三大流派的对照

| 流派 | 代表 | 监督 | 泛化来源 | 弱点 |
|------|------|------|---------|------|
| 模仿学习/VLA | OpenVLA, π系列 | 动作标注 | 数据规模 | 真机数据瓶颈 |
| 世界模型+中间表示 | ObjectWorld, VPP | 视频/几何标注 | 视频规模+表示设计 | 接口精度 |
| 优化/模型预测控制 | 采样式MPC | 物理模型 | 模型保真度 | 建模成本 |

ObjectWorld 是第二流派的深化：它不与模仿学习竞争"谁的动作更准"，而是重新分配监督负担——用"物体运动监督"（可从视频自动获得）替代"动作监督"（必须真机采集）。如果物体流监督精度继续提升，第二流派可能吞并第一流派的数据优势。

### F. 对 Spatial AGI 的战略意义再思考

**物体级 vs 场景级 vs 任务级的世界模型分层**：

- 场景级：SWAM / PointWorld（全场景视频或点云流）——覆盖广但单物体深度浅；
- 物体级：ObjectWorld（单目标物体完整表面流）——深度深但覆盖窄；
- 任务级：价值对齐/奖励世界模型（ViVa 类）——直接优化任务成功。

三层最终需要融合：场景模型负责"背景会怎样"、物体模型负责"目标怎么动"、任务模型负责"怎样算成功"。ObjectWorld 证明了物体层可以独立规模化——这暗示未来的空间智能世界模型可能是**分层的模型组合**而非单体巨模型。

### G. 关键术语表

- **Full-Object Flow**：物体完整表面（含遮挡区）所有点的稠密3D轨迹场。
- **Partial Object Flow**：仅可见/被跟踪区域的物体流（先前工作的局限）。
- **Atomic Manipulation Clip**：一次"接触-分离"交互对应的视频片段，标注的基本单位。
- **Canonical Object Frame**：物体自身坐标系，mesh 采样点的参考系。
- **Flow-Conditioned Action Optimization**：以匹配预测物体流为目标优化机器人动作。
- **Amodal Completion**：推断被遮挡区域几何/状态的能力。

### H. 三个核心问题的回答摘要

**Q1 核心算法**：提出 3D 全物体流表示（512点×48步完整表面轨迹）；VLM+重建+跟踪的自动标注管线从野外视频生成监督（1210h 数据集，IoU 质控）；Qwen2.5-VL+PTv3 双通路编码、flow head 条件生成位移场；下游流条件优化求解末端轨迹，实现本体无关执行。

**Q2 Spatial AGI 关系**：物体级显式动力学想象层；"可大规模监督+可执行"的表示设计判据；遮挡推理（amodal）的操作化训练；互联网视频→几何监督的数据引擎范式。

**Q3 创新与局限**：创新在于表示谱系补全、数据管线、跨本体优化执行、全链路验证；局限在于重建误差传导、单物体/单目标假设、接触建模缺失、开环执行的闭环频率未明。

### I. 扩展问答（FAQ）

**Q: 为什么选 512 点而不是更密的采样？**

A: 512 点在"流场表达力"与"预测/优化计算量"之间取平衡。每步每点3维位移，48步×512点≈7.9万维预测输出；更密的采样（如4096点）会使 flow head 与下游优化的计算量线性膨胀。且执行只需要物体级运动趋势足够准确，逐点超精度意义有限。

**Q: 可形变物体（衣物、绳索）的流预测与刚体有何本质不同？**

A: 刚体运动有6个自由度（512点位移强相关，可由单一变换解释）；形变物体的512点位移近乎独立（每个点有自己的运动），预测难度实质上是"预测一个512×3维的时变场"。MetaFold 仿真数据的加入正是为这个。模型能否真正学到衣物褶皱的动力学，是表示能力的试金石。

**Q: 该方法与模仿学习能结合吗？**

A: 可以且互补：全物体流可作模仿学习的辅助监督（预测头+动作头多任务），或作为模仿数据的中间标注（给无动作标注视频赋予运动语义）。也可以想象两级策略：世界模型给物体级目标，低层模仿策略学"怎么抓才能引起这种运动"。

**Q: 对操作失败如何归因？**

A: 三段式归因：想象错了（预测流与真实物体的差异）、执行错了（优化后的动作与预测流的差异）、感知错了（重建/分割错误）。流表示的可度量性让这种归因成为可能——这是相对端到端 VLA 的诊断优势。

**Q: 最大的单点风险是什么？**

A: SAM3D 单目重建的完整几何质量。整条管线的"全物体"承诺建立在重建之上——若重建的遮挡区域不可靠，"全物体流"就退化为"部分流的精修版"。未来方向是用多视角视频或生成先验增强单目重建。

**Q: 该表示能否扩展到导航场景？**

A: 原则上可以——预测"场景中可动物体的未来流"就是导航的前瞻预测（行人会走向哪）。但物体分割/重建在导航距离与遮挡下更难，且导航需要更大空间范围。ObjectWorld 与 Compass 1 的中间地带（室内移动操作）是自然的扩展方向。
