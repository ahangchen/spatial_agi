## 论文概览

SMA（Spatial Memory Agent）回答了一个被两条主流路线（后训练/工具调用）忽视的问题：**冻结的 VLM 能否通过无参数更新的自演化提升空间推理能力？** 答案是肯定的——通过把验证器打分的空间推理经验蒸馏为"可迁移教训"（transferable lessons），存入外部记忆库，部署时用"语义过滤 + 可迁移可靠性分数（TRS）联合排序"检索教训指导推理。

### 一句话总结

> 不改权重、不调工具，让冻结 VLM 在可验证空间环境中"刷题→反思→提炼教训"，再用证据校准的可靠性分数检索教训指导新题——参数更新之外的自演化第三路线。

### 核心结果速览

| 基础模型 | No Memory | SMA | 提升 |
|---------|----------|-----|------|
| Qwen3.5-122B-A10B | 65.3 | **68.8** | +3.5 |
| Qwen3.6-35B-A3B | 61.6 | **66.7** | +5.1 |
| Qwen3.6-27B | 63.3 | **69.8** | +6.5 |
| Qwen3.5-9B | 60.6 | **63.5** | +2.9 |

四个规模上 macro average 全部第一，20 组评估中大多数最佳。

## 核心问题

### Q1: 核心算法原理

**问题**: 这篇文章的核心算法原理是什么？

**分析**:

1. **核心思想和动机**

   现有 VLM 空间推理提升的两条路线各有代价：
   - **后训练路线**（SFT/RL）：需要训练基础设施，改权重导致遗忘风险，泛化受训练分布限制（SpatialVLM、RoboSpatial 等）
   - **Agentic 工具路线**（S-Agent、SpaceTools）：推理时依赖外部专家工具（深度估计、3D 重建），增加延迟与系统复杂度
   
   SMA 探索第三条路线的动机：
   - 冻结模型 = 可复用、无灾难性遗忘、随基础模型升级即插即用
   - 无工具依赖 = 部署简单，无工具链失败模式
   - 核心赌注：**空间推理的失败模式是重复的、可抽象为程序性知识的**——"左/右判断要先统一朝向"、"遮挡推理先找支撑面"这类教训可跨题迁移
   
   灵感来源是文本 Agent 的记忆自演化（A-Mem、MemGPT 等经验记忆系统），但现有方法有两个缺陷：仅面向文本 Agent、检索只看语义相似度而不区分"表面相关"与"程序可靠迁移"。

2. **主要技术方法**

   **(1) 记忆卡结构**：每条记忆 m_i = (t_i, s_i, l_i, n_i, c_i, v_i)
   - t_i: 源任务描述
   - s_i: rollout 简短摘要（任务形状 + 成功/失败模式诊断）
   - l_i: **可迁移教训**——紧凑可复用原则，包含"模式识别、要避开的陷阱、要执行的检查"
   - n_i: 后续被检索使用的次数
   - c_i: 这些访问累积的奖励
   - v_i: TRS（可迁移可靠性分数）
   - **防泄漏设计**：检索时只暴露 t/s/l 三字段，不暴露先前的预测或验证答案

   **(2) 经验获取与单遍记忆写作**：
   - 可验证空间环境：每题 ξ_i = (视觉输入 V_i, 任务 t_i, 已验证目标 y_i*)
   - 检索增强解题：o_i = F(V_i, t_i, G_i)，解析出预测 ŷ_i，验证器返回标量奖励 r_i = Eval(ŷ_i, y_i*)
   - 反思模型生成记忆：(s_i, l_i) = R_φ(o_i, t_i, y_i*, r_i)——**给反思模型看验证答案**以精准定位失败原因，但反泄漏规则禁止在教训中复述答案
   - **One-Pass Memory Writing**：只在第一遍写记忆卡；实验发现持续重写（Continual）产生大量重复卡。后续 pass 复用固定记忆库，仅更新可靠性状态

   **(3) 两阶段检索**：
   - 阶段1 语义过滤：任务嵌入余弦相似度 rel_ij = cos(ψ(t_i), ψ(t_j))，低于阈值 δ 的丢弃 → 候选集 C_i
   - 阶段2 联合排序：S_ij = (1-η)·z(rel_ij) + η·z(v_j)，z 为裁剪 z-score 归一化，η 控制 TRS 权重，Top-k 组成指导集 G_i 前置于用户 prompt
   - 设计动机：语义相似度只能提出候选，但"表面相似的题"不一定适用"同一推理程序"——TRS 用证据区分

   **(4) 访问证据校准（Visit-Evidence Calibration）**：
   - 初始化：n_i=0, c_i=0, v_i=v_0（**均匀初始值**——记忆的初始 TRS 不因创建它的 rollout 对错而偏高/偏低）
   - 更新：每当记忆卡被检索用于新题且该题得奖励 r_i ∈ [0,1]，则 n_j+1, c_j+r_i, v_j = (λv_0 + c_j)/(λ + n_j)
   - λ 是均匀先验强度——低访问记忆向公共初始值收缩（贝叶斯收缩估计），高访问记忆收敛到经验迁移成功率
   - **关键分离**：TRS 估计"程序被检索后有多大帮助"，与"创建该记忆的 rollout 是否答对"解耦——答错题目的失败教训同样可能有高 TRS

   **(5) 只读部署**：经验获取完成后记忆库完全固定（记忆、访问数、奖励、TRS 均冻结），部署时只检索不写回

3. **算法流程和关键步骤**

   ```
   Phase 1: 经验获取（环境分割 X）
   for 每个空间问题 ξ_i in X:
     1. 语义过滤 + TRS排序 → 检索指导集 G_i
     2. 冻结VLM推理: o_i = F(V_i, t_i, G_i)
     3. 验证: r_i = Eval(Parse(o_i), y_i*)
     4. [仅第一遍] 反思蒸馏: (s_i,l_i) = R_φ(o_i, t_i, y_i*, r_i) → 写入记忆卡
     5. TRS校准: 对 G_i 中每张卡 n+=1, c+=r_i, v=(λv_0+c)/(λ+n)
   
   Phase 2: 只读部署（部署分割 D）
   for 每个新空间问题:
     1. 语义过滤 + TRS排序 → 指导集 G（同Phase 1检索）
     2. 冻结VLM推理（记忆卡 t/s/l 前置于 prompt）
     3. 不写回、不更新记忆
   ```

4. **输入输出**

   - **输入**: 冻结 VLM F + 反思模型 R_φ + 可验证空间环境（视觉输入 + 任务 + 可验证答案）+ 部署期新题
   - **输出**: 外部记忆库（程序性教训卡）+ 部署期提升的推理准确率
   - **评估**: 5 个空间基准（RoboSpatial、ERQA、Omni3D、SAT、EmbSpatial）+ 4 个基础模型（Qwen3.5-122B-A10B、Qwen3.6-35B-A3B、Qwen3.6-27B、Qwen3.5-9B），另含 SITE-image、ViewSpatial 共 7 基准雷达图

### Q2: 与Spatial AGI的关系

**问题**: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**分析**:

1. **如何理解和表示空间**

   SMA 的空间表示是**程序性知识（procedural knowledge）而非陈述性知识（declarative knowledge）**：
   - 不构建显式几何（无点云/网格/高斯），而是把空间推理模式编码为语言化的"教训"
   - 教训的三元结构：模式（什么题型）+ 陷阱（常见错误）+ 检查（正确推理步骤）
   - 这对应认知科学中的程序性记忆（怎么做事）vs 情景记忆（发生过什么）——SMA 明确选择前者，因为目标迁移而非记题
   
   与几何表示路线（AlayaWorld 点缓存、Reasmory 3D 重建记忆）形成互补：
   - 几何记忆：回答"空间里有什么、在哪里"（陈述性）
   - 程序记忆：回答"如何推理空间关系"（程序性）
   - 完整的 Spatial AGI 需要两者

2. **如何处理空间关系**

   - 空间关系的处理被隐式编码在教训中——例如（推测的教训形态）"图中人的左右以人物朝向为准而非相机视角"、"遮挡判断需先确认支撑接触面"
   - **原子能力分析**（Figure 7）显示最大增益在 correspondence 风格的空间检查——对应、匹配类空间关系推理
   - 记忆组合分析（Table 5）揭示了空间推理的"指导传染"：检索到 3 张全成功源记忆 → 93.0% 准确率；全失败源 → 39.0%。**指导质量直接决定推理质量**

3. **对Spatial AGI的启发**

   - **启发1: 自演化的三路线框架**。后训练（改权重）、工具增强（加感知）、记忆演化（攒经验）——SMA 补全了第三象限。Spatial AGI 系统设计应把三条路线视为正交可组合轴
   - **启发2: TRS 式证据校准检索**。"语义相似 ≠ 程序可迁移"的洞察对所有 Spatial AGI 记忆系统成立：3D 场景记忆、技能库、地图库的检索都应引入"该记忆实际帮助过多少次"的证据项，而非只看表面相似度
   - **启发3: 失败经验的正面价值**。TRS 与源对错解耦（失败源教训 TRS 0.452 仍贡献 61.4% 准确率）——失败教训是空间推理改进的富矿，只从成功经验学习会浪费一半数据
   - **启发4: 只读部署的工程价值**。记忆冻结使部署可复现、可审计、无记忆投毒风险（部署期不被污染）——对安全敏感的 Spatial AGI 应用（机器人、驾驶）重要
   - **启发5: 跨模型迁移**。122B 写的记忆给 27B 用仍 +9.4（RoboSpatial）——空间程序性知识具有跨模型通用性，暗示可以构建"共享空间教训库"作为 Spatial AGI 基础设施

4. **可以应用的Spatial AGI场景**

   - **具身 Agent 的经验积累**：导航失败模式（死角、遮挡、动态障碍）可蒸馏为程序教训，跨任务复用
   - **机器人操作的技能记忆**：抓取失败的几何诊断（"细颈容器需侧向接近"）作为教训卡积累
   - **VLM 空间推理增强服务**：作为中间件给任何冻结 VLM 提供空间推理 boost，无重训成本
   - **持续学习替代方案**：模型频繁升级的场景（基础模型季度更新），记忆库即插即用
   - **多智能体共享教训库**：不同机器人/Agent 的空间经验汇聚为公共教训库（论文已验证跨模型迁移可行性）

### Q3: 创新点和局限性

**问题**: 基于前面的分析，这个方法的主要创新点和局限性是什么？

**分析**:

1. **主要创新点**

   - **创新1: 首个面向空间智能的无参数更新自演化框架**。把文本 Agent 的记忆自演化范式引入空间推理，并解决其两个特有挑战（视觉上下文多样性、程序迁移≠表面相似）
   - **创新2: 可迁移可靠性分数（TRS）+ 访问证据校准**。贝叶斯收缩式在线估计 (λv_0+c)/(λ+n)，将检索从"语义匹配"升级为"证据加权程序选择"——这是对 RAG 范式的本质改进
   - **创新3: 验证器引导的反思 + 反泄漏设计**。反思模型可见验证答案（精确定位失败原因）但教训中禁止复述答案（防止记忆库退化为答案缓存）
   - **创新4: One-Pass Memory Writing**。发现持续重写产生冗余记忆，单遍写作 + 后续仅校准更高效——对 Agent 记忆系统设计的实用洞察
   - **创新5: 系统的迁移与诊断分析**。跨模型迁移（+9.4）、跨基准迁移（+7.6）、TRS-准确率相关性、检索组合效应（93.0%/65.1%/39.0%）——实验分析深度罕见

2. **主要局限性**

   - **局限1: 依赖可验证环境**。经验获取需要 verifier（已知答案 + 可计算奖励）。真实物理世界的空间任务（导航、操作）大多没有即时可验证信号——扩展到具身场景需要奖励模型或人类反馈，引入新误差源
   - **局限2: 教训是文本形式**。语言化教训的表达力有限——细粒度几何直觉（视角变换的连续映射）难以用离散文字教训捕捉。与几何记忆（AlayaWorld 点缓存）相比，程序记忆缺少空间特异性
   - **局限3: 增益幅度有限且模型相关**。9B 上仅 +2.9，122B 上 +3.5；最强的 27B 是 +6.5。相比后训练路线（常报 +10 以上），记忆路线的绝对增益偏小
   - **局限4: 反思模型本身是 LLM**。R_φ 的教训质量受限于反思模型能力；若反思模型与基础模型同源，可能继承同样的空间盲区（自己反思不出自己的系统性错误）
   - **局限5: 记忆库规模与检索效率**。论文未报告记忆库大小的扩展性（万级以上记忆卡的检索延迟、语义过滤的计算成本）
   - **局限6: 静态环境假设**。只读部署意味着环境分布漂移后记忆库可能过时——需要重新进入经验获取阶段，论文未讨论漂移检测机制
   - **局限7: 单图/静态视觉输入为主**。评估基准（RoboSpatial、ERQA、SAT 等）以静态图像空间 QA 为主，未涉及视频、动态场景、主动感知

3. **与其他相关工作的对比**

   | 维度 | SMA | S-Agent/SpaceTools（工具路线） | SpatialVLM/RoboSpatial（后训练） |
   |------|-----|------------------------------|-------------------------------|
   | 参数更新 | ❌ 冻结 | ❌ 冻结 | ✅ SFT/RL |
   | 推理时工具 | ❌ 无 | ✅ 深度/重建工具 | ❌ 无 |
   | 经验积累 | ✅ 教训记忆 | ❌ 无跨任务积累 | 隐式（训练数据） |
   | 部署复杂度 | 低（纯prompt） | 中（工具链） | 低 |
   | 增益上限 | 中（+3~6.5） | 中 | 高 |
   | 可复用性 | 高（跨模型+跨基准迁移） | 中 | 低（绑定权重） |
   
   **与文本 Agent 记忆系统对比**（A-Mem、MemGPT、Reflexion）：
   - SMA 的差异化在 TRS：文本记忆系统多用相似度或简单价值更新，不区分"表面相关"与"程序可靠"
   - SMA 的空间特化：教训针对空间推理失败模式（朝向、遮挡、视角），非通用任务策略
   
   **与 Ouroboros-Spatial（数据-模型闭环，此前已读）对比**：
   - Ouroboros 更新模型参数（闭环在训练），SMA 更新外部记忆（闭环在运行时）
   - Ouroboros 增益大但绑定模型版本；SMA 增益小但即插即用

## 核心技术发现

- **发现1**: 空间推理经验可以被蒸馏为跨题、跨基准、跨模型迁移的程序性教训——模型迁移（122B→27B）在 RoboSpatial 上 +9.4，证明教训的模型无关性
- **发现2**: **最佳记忆不总是最近记忆**（Finding 4）——语义最近邻检索在空间程序选择上系统性失效，加入证据校准的 TRS 后排序质量显著改善（无语义过滤消融 -5.8，最大组件损失）
- **发现3**: 检索记忆的源质量组合直接决定推理成败：全成功源 93.0% vs 全失败源 39.0%（差距 54 个百分点）——记忆库质量是性能瓶颈
- **发现4**: Reward-only 反思（不给反思模型看验证答案）比完整反思低 5.5 点——失败归因需要 ground truth 锚定，纯奖励信号不足以定位错误步骤
- **发现5**: One-Pass 写作优于持续重写：记忆库更小、冗余更低、TRS 覆盖更高——记忆系统的瓶颈不在写作量而在校准充分性
- **发现6**: 原子空间能力增益普适（十项原子能力全部提升），最大在 correspondence 类空间检查——程序教训对"匹配/对应"类空间操作最有效

## 与Spatial AGI的关系

### 直接贡献

1. 提供了空间记忆的第三种形态（程序性教训）及其完整的运行时系统设计：写作（验证引导反思）、索引（任务嵌入）、校准（TRS）、检索（两阶段）、部署（只读）
2. 证明冻结模型 + 外部记忆的可行增益空间（+3~6.5 macro），确立与后训练/工具路线的可比性
3. 跨模型/跨基准迁移证据支持"共享空间教训库"作为社区基础设施的构想

### 技术启发

- TRS 公式 (λv_0+c)/(λ+n) 可直接移植到任何 Spatial AGI 记忆系统（3D 地图库、技能库、经验回放池）作为记忆价值估计器
- 反泄漏规则（教训禁复述答案）是防止记忆退化的关键设计，可推广到具身经验学习（防止记忆库变成轨迹缓存）
- 只读部署 + 阶段性重写是记忆系统的安全部署模式

### 应用场景

- 冻结 VLM 的空间推理中间件（API 服务形态）
- 机器人队的跨机体经验共享（教训库分发）
- 空间推理基准的持续提升管线（无训练成本刷分）
- 人机协同：人类专家空间知识写成教训卡注入记忆库

## 个人思考

### 最令人兴奋的发现

**TRS 的"证据加权程序选择"是对 RAG 范式的本质性升级**。传统 RAG 的隐藏假设是"相似即有用"，SMA 用数据证明这个假设在程序性知识上失效——一个关于"楼梯深度错觉"的教训可能对表面完全不同的题（室内照片 vs 航拍）都适用，而表面极相似的题可能需要不同推理程序。这提示 Spatial AGI 的记忆检索需要双通道：语义通道提候选（可能相关），证据通道定优先级（确实有用）。这个设计与推荐系统的"召回+重排"异曲同工，但目标是程序可靠性而非点击率。

其次是**失败教训的价值量化**（TRS 0.452 的失败源教训仍支持 61.4% 准确率）。空间推理研究的注意力大多放在成功案例上，SMA 提醒我们：**知道怎么错与知道怎么做对同样重要**——这与人学习空间技能（骑车、下棋）的经验一致。

### 潜在局限

最深的担忧是**可验证环境的依赖构成"经验获取瓶颈"**：
- 部署期遇到的新失败模式无法写入记忆（只读）——记忆库永远滞后于环境
- 具身场景缺乏 verifier，TRS 校准失去奖励信号——需要模拟器（引入 sim2real gap）或奖励模型（引入模型偏差）
- 记忆库的长期演化路径不明：何时重写？如何处理冲突教训？如何淘汰过时教训？

其次是**教训粒度的粗放性**：文本教训是"程序性知识的有损压缩"。精细的空间直觉（连续视角插值、度量推理）可能超出语言教训的表达能力。理想的 Spatial AGI 记忆应该是**几何记忆（陈述性）+ 教训记忆（程序性）+ 参数记忆（技能性）**的混合体，SMA 只覆盖了其中一层。

### 与昨日研究的关联

- 昨日 **SCOUT**（08-14_03，结构化 CoT + 多目标过程奖励）走 RL 路线提升空间推理，SMA 用记忆路线达到类似目标——两者是"改参数 vs 攒经验"的直接对照
- 昨日 **AtlasVLA**（08-14_04）的持久世界模型是几何/状态记忆，SMA 是程序记忆——互补关系，VLA 系统理想上应同时具备
- 08-13 **Chain of Spatial Thoughts**（模态无关空间接地）与 SMA 都主张空间能力的运行时增强而非重训练
- 此前 **Ouroboros-Spatial**（数据-模型闭环）是记忆路线的"训练化"版本；**EmbodiedLGR**（轻量图表示记忆）是几何记忆版本——本库已覆盖空间记忆的三个子形态

## 方法细节补充

### TRS 校准公式的贝叶斯解读

v_j = (λv_0 + c_j)/(λ + n_j) 本质是 **Beta-Bernoulli 后验均值**：
- v_0：均匀先验均值（所有记忆初始等权）
- λ：先验强度（伪计数）
- c_j/n_j：经验迁移成功率
- n_j 小时 → 收缩向先验（保守）；n_j 大时 → 收敛到经验值

这个设计与 A/B 测试中的贝叶斯平滑、推荐系统中的 Wilson 分数同源——处理小样本记忆的冷启动问题。

### 与 RLHF 的形式对照

| 组件 | RLHF | SMA |
|------|------|-----|
| 奖励来源 | 人类偏好 | 验证器（可验证环境） |
| 更新对象 | 模型参数 | 记忆卡 TRS |
| 经验回放 | 全轨迹 | 蒸馏后的教训 |
| 部署形态 | 新权重 | Prompt 前缀 |

可以视 SMA 为"把 RL 的信用分配从参数空间移到记忆空间"——代价是增益上限低，收益是零遗忘、可迁移、可解释（每张卡都能读懂）。

## 开放问题与未来方向

1. **无验证器的 TRS 校准**：用奖励模型/LLM-as-judge 替代验证器，或引入弱监督信号（执行结果、人类稀疏反馈）
2. **几何-程序混合记忆**：教训卡关联几何证据（关键视角图、深度图切片），形成"原则 + 例证"的富记忆
3. **记忆库治理**：冲突检测（ contradictory lessons）、过时淘汰（环境漂移后）、层次组织（通用原则→领域教训→场景特例）
4. **教训自动泛化**：从多条具体教训归纳出更抽象的元教训（meta-lesson），压缩记忆库
5. **主动经验获取**：Agent 主动选择"最能提高记忆库覆盖"的题去刷（好奇心驱动），而非被动遍历环境
6. **具身落地**：在模拟器（Isaac Genie、Habitat）中验证操作/导航任务的教训迁移

## 总结

### 核心发现总结

SMA 开辟了空间推理提升的第三条路线：冻结模型 + 程序性教训记忆 + 证据校准检索。核心技术创新是 TRS（可迁移可靠性分数）将记忆检索从语义匹配升级为证据加权程序选择，配合验证器引导反思（可看答案但禁复述）与 One-Pass 写作策略。在 5 基准 × 4 模型上 macro 全部第一（+2.9~+6.5），并验证跨模型（+9.4）与跨基准（+7.6）迁移。关键洞察：最佳记忆不总是最近记忆；失败教训与成功教训同样有价值；程序迁移可靠性必须用访问证据而非表面相似度估计。

### 对Spatial AGI的意义

1. **确立记忆自演化作为 Spatial AGI 的可行演化轴**：与后训练（改参数）、工具增强（加感知）三轴正交，可组合
2. **TRS 证据校准可移植到所有空间记忆系统**：3D 地图、技能库、经验池的检索排序都应引入"实际帮助证据"
3. **跨模型迁移证据支持"共享空间教训库"基础设施**：空间程序性知识具有模型无关性，社区级教训库可成为公共品
4. **暴露可验证性瓶颈**：具身场景的落地取决于无验证器校准方案——这是记忆路线从 QA 走向 Embodied 的关键缺口

## 相关工作谱系深度分析

### 空间推理提升三路线的哲学差异

三条路线不仅是技术方案不同，更隐含了对“空间智能是什么”的不同假设：

**后训练路线（SpatialVLM/RoboSpatial/SCOUT）的假设**：空间智能是模型参数中的**能力**——通过数据注入与 RL 强化，把空间知识“烘焙”进权重。适合构建强空间基座模型，但每次能力更新需要全量训练。

**工具路线（S-Agent/SpaceTools）的假设**：空间智能是**感知-推理分工**——模型负责语义推理，专家工具负责几何计算。运行时增强，但推理链路依赖外部服务的正确性，且工具调用本身消耗大量 token。

**SMA 记忆路线的假设**：空间智能包含大量**可敓述的程序性知识**——失败模式重复出现，可提炼、可检索、可复用。它是三路线中唯一支持“经验复利”的：用得越久，教训库越丰富。

### 与认知科学记忆分类的对应

| 认知科学分类 | Spatial AGI 对应 | 代表工作 |
|------------|----------------|---------|
| 情景记忆（episodic） | 具体任务轨迹存储 | 经验回放缓冲 |
| 语义记忆（semantic） | 3D地图/场景图 | Reasmory, R4DSG, 点缓存 |
| 程序记忆（procedural） | 可迁移教训/技能 | **SMA**, SkillMemo |
| 工作记忆（working） | 上下文内空间表征 | SpatialStack, Chain of Spatial Thoughts |

SMA 的贡献是首次在空间领域把**程序记忆**做成了完整的运行时系统（写作-索引-校准-检索-部署），并给出证据校准的量化方案。

### 记忆系统设计的四个深层决策

**决策1: 记忆写什么？—— 教训而非轨迹**

原始 rollout（完整推理链+图像描述）作为记忆有两个问题： token 冗长（检索后 prompt 爆炸）与答案泄漏（检索到原题时直接抄答案）。SMA 的教训抽象（模式+陷阱+检查）既压缩又防泄漏。反泄漏规则的必要性从消融可见：raw model output 作为指导比完整反思低 4.4 点。

**决策2: 记忆信任什么？—— 证据而非出身**

“这张卡是答对题时写的”不等于“这张卡能帮助新题”。失败源的教训（陷阱诊断）可能比成功源的更有指导价值。TRS 初始化均匀 + 访问证据校准，把“出身”与“效用”彻底分离。诊断数据显示失败源教训仍支持 61.4% 准确率——远高于无记忆基线。

**决策3: 记忆何时写？—— 单遍而非持续**

持续重写似乎“经验更多”，但产生大量重复卡（同一陷阱反复提炼），反而稀释 TRS 校准的证据密度（同一教训的多张卡分摊访问次数）。One-Pass 保证每张卡独立充分校准。

**决策4: 部署时改不改？—— 只读**

只读部署损失了在线适应，换来：可复现（同输入同输出）、可审计（记忆库版本固定）、防污染（部署期对抗样本无法写入记忆）。对安全敏感场景（机器人、驾驶）这是必要妥协。

### 工程落地的成本分析

| 阶段 | 计算成本 | 备注 |
|------|---------|------|
| 经验获取 | N题 × (检索+VLM推理+验证+反思) | 与后训练相比无梯度计算 |
| TRS校准 | O(1)每检索 | 纯标量更新 |
| 部署 | 检索 + VLM推理 + prompt前缀token | 额外 k×卡片长度 token |

对比后训练：无训练基础设施需求（无GPU集群梯度更新），但有推理成本放大（经验获取阶段每题多一次反思调用）。总成本取决于环境规模 N 与反思模型选择。

### 与检索增强范式（RAG）的本质区别

RAG 在空间推理上的失败（主表中 RAG 在 122B 上 64.2 甚至低于 No memory 65.3）揭示：检索无关知识会干扰推理。SMA 与 RAG 的三点区别：
1. **检索对象**：文档片段（陈述性） vs 推理程序（程序性）
2. **排序信号**：语义相似度 vs 相似度+迁移证据
3. **写入质量控制**：无 vs 验证引导反思+反泄漏

这提示 Spatial AGI 的知识增强不能直接搬 RAG，需要程序化改造。

## 附录D: 三路线组合的前景推演

SMA 与另外两条路线理论上可叠加：

**SMA + 后训练**：先用 SMA 记忆库提升推理 → 积累高 TRS 教训 → 用教训合成训练数据（类似 Ouroboros-Spatial 的数据闭环）→ 后训练固化到权重 → 清空记忆库重新积累。形成“记忆变现为参数”的周期化升级。

**SMA + 工具**：教训库指导“何时调用什么工具”——例如高 TRS 教训“深度顺序判断需多视角证据”触发 S-Agent 式工具调用。记忆路线提供策略层，工具路线提供感知层。

**三路线统一架构**（ speculative）：
```
新任务 → SMA检索教训(程序层)
       → 教训触发工具调用(感知层)
       → 冻结VLM推理(基座层)
       → 验证器打分 → 定期蒸馏为后训练数据(参数层)
```

## 附录E: TRS 公式的数值行为示例

设 v_0=0.5, λ=2：

| 访问次数 n | 累积奖励 c | TRS v=(2×0.5+c)/(2+n) | 解读 |
|-----------|-----------|---------------------|------|
| 0 | 0 | 0.500 | 初始均匀 |
| 1 | 1.0 | 0.667 | 一次成功，保守上移 |
| 3 | 3.0 | 0.800 | 三次全成，证据渐强 |
| 5 | 2.5 | 0.500 | 五次半成，回归中值 |
| 10 | 9.0 | 0.917 | 十次九成，高可靠 |
| 10 | 1.0 | 0.167 | 十次一成，应降权 |

关键行为：小样本时收缩保护（n=1 成功只到 0.667 而非 1.0），大样本时收敛真值。这防止“一次巧合成功”的卡被高估。
