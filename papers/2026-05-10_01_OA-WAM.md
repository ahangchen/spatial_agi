## Q1: 核心算法原理

### 1.1 核心思想和动机

OA-WAM解决了一个关键问题：现有World Action Models (WAM)在场景扰动下缺乏**对象可寻址性(Object Addressability)**。当指令引用特定对象时（如"把红色杯子放在绿色托盘上"），holistic token表示会将目标对象与周围上下文纠缠在一起，导致在布局、视角或光照变化时动作选择漂移。

核心洞察：**世界模型不仅要预测未来，还要提供稳定的每对象状态，使语言条件化的动作生成能直接查询任务相关对象。**

### 1.2 主要技术方法

**Slot-based Object Decomposition**:
- 每帧分解为N+1个slot（1个机器人slot + N个对象slot）
- 每个slot token = `addr_k`（冻结的身份地址）+ `content_k^t`（时变内容）
- addr由语言标签+初始DINOv3特征计算，每个episode只计算一次，永不更新
- content由SAM3 + DINOv3 masks刷新

**Block-Causal Sequence Fusion**:
- 将slot tokens与text、image-VQ、本体感知、历史动作token融合为block-causal序列
- 由7B Chameleon-style trunk处理
- World head回归下一帧每slot的(content_hat, pose_hat)
- Flow-matching action head解码16步连续动作chunk
- 单次前向传播完成世界预测和动作生成

**Object Addressability约束（核心创新）**:
- **addr-only key projection**: 跨slot注意力key只读取addr子向量
- **per-layer addr reset**: 每层transformer后用forward hook将residual中的addr切片重置为缓存的identity
- 这两个操作都是无参数的tensor级操作
- 效果：slot路由keys只依赖冻结的身份地址，场景上下文变化无法重写动作head读取的slot

### 1.3 算法流程

1. **Slot提取**: SAM3 + DINOv3检测对象，为每个对象分配slot
2. **地址初始化**: 从语言标签+初始DINOv3特征计算frozen addr
3. **Token构建**: addr+content → slot tokens，融合多模态输入
4. **Transformer处理**: 32层transformer，每层应用OA约束
5. **双头输出**: World head预测下一帧slot状态，Action head解码动作序列

### 1.4 输入输出

- **输入**: 多视角图像、语言指令、本体感知、历史动作
- **输出**: 16步连续动作chunk + 下一帧每slot状态预测

## Q2: 与Spatial AGI的关系

### 2.1 空间理解和表示

OA-WAM将空间理解为**以对象为中心的分解表示**：
- 将场景分解为独立的、可寻址的对象slots
- 每个对象有独立的身份(address)和时变状态(content)
- 空间关系通过slot间的cross-attention自然编码

### 2.2 空间关系处理

- **对象级定位**: addr子向量使系统能精确定位"哪个对象"
- **时变空间跟踪**: content^t跟踪对象随时间的空间状态变化
- **几何鲁棒性**: addr-only key使几何变换（相机、布局）不影响对象寻址

### 2.3 对Spatial AGI的启发

1. **可寻址空间表示**: Spatial AGI需要不仅能感知空间，还能通过稳定标识符"指向"特定空间实体
2. **解耦身份与内容**: 将"这是什么"与"它现在在哪里/什么状态"分开是空间智能的关键设计
3. **架构级约束**: 通过架构设计而非仅靠学习来保证空间一致性

### 2.4 可应用的Spatial AGI场景

- 家庭服务机器人：精确定位特定家具/物品
- 仓库物流：跟踪和操作特定货物
- 多步骤操作任务：维持对任务相关对象的持续关注
- 场景变化下的导航：对象标识不受视角变化影响

## Q3: 创新点与局限性

### 创新点

1. **Object Addressability概念**: 首次形式化WAM中的对象可寻址性问题，将鲁棒性问题归因为缺乏稳定的对象级接口
2. **addr-only key + per-layer reset**: 极简但有效的架构约束，无额外参数开销
3. **Slot干预实验**: 设计了因果slot干预测试，swap-binding cosine 0.87 vs ≤0.09 for baselines
4. **统一World-Action设计**: 单次前向传播同时输出世界预测和动作

### 局限性

1. **依赖上游slot提取**: SAM3 + DINOv3 pipeline的质量直接影响OA效果，传感器噪声（如LIBERO-Plus Sensor Noise轴）会导致slot提取失败
2. **固定slot数量N**: 无法处理超出预设数量的对象
3. **身份初始化依赖语言标签**: 对于无语言描述的对象难以建立稳定地址
4. **仅验证了桌面操作**: 未在更复杂的场景（户外、大规模）验证
5. **OA约束是路由级而非端到端语义保证**: 只保证key routing不变，不保证语义正确性

### 与相关工作对比

| 方法 | 表示 | 可寻址性 | LIBERO | LIBERO-Plus Camera | 对象鲁棒性 |

## 总结

OA-WAM提出了Object Addressability这一关键概念，通过将场景分解为可寻址的object slots，并在架构层面约束跨slot注意力的key只依赖冻结的身份地址，实现了在场景扰动下的鲁棒机器人操作。这一设计思路对Spatial AGI有重要启发：空间智能需要不仅能感知空间中的对象，还能通过稳定的标识符可靠地"指向"和"跟踪"这些对象。addr/content分离的设计原则可以推广到更广泛的空间推理任务中。
