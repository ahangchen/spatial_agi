## 一句话总结

Fréchet Forcing 提出一种无需教师、无需在线 critic、无需长视频的长时程世界模型微调方法：在部署的多步采样器上直接微调，用三个互补约束——生成锚定（自生成历史 + 真实数据结尾的 flow-matching 损失）、上下文保真（以自身 GT 为中心的 latent Fréchet 距离）、现实匹配（冻结感知特征空间对真实帧的 Fréchet 距离）——让在 253 帧片段上预训练的 MiniWorld-1B 在仅 36 GPU 小时的 381 帧片段微调后，rollout 稳定超过 4,000 帧（预训练时域的 16 倍），DROID 末段 FVD 降低 25 倍且动作跟随不丢失。

## 核心问题

### Q1: 这篇文章的核心算法原理是什么？

#### 1. 核心思想和动机

**问题：流式世界模型的训练-部署鸿沟**

- 流式视频世界模型逐 chunk 生成未来，条件于自己生成的历史 + 动作流——这是交互仿真、游戏引擎、具身智能的天然底座。
- 但训练时用 GT 历史，部署时自回归消费自己的预测 → 小误差回流上下文、逐步复利 → rollout 在约等于训练片段长度处开始漂移：变黑、褪色、溶解成纹理。
- **长时程漂移是流式生成的中心障碍**。

**主流方案的困境：DMD 的教师瓶颈**

- 主流思路是在自身 rollout 上训练 + 分布匹配蒸馏（DMD）：冻结教师分数 − 在线"假"分数提供梯度。
- 但动作条件世界模型的教师面临**根本两难**：
  - 外部大视频模型：不懂动作空间，把 rollout 拉向错配分布（违反"懂学生领域"）；
  - 自己的预训练网络：懂领域但它就是会漂移的那个——在长时程状态上它的分数和学生一致，**没有纠错信号**（违反"比学生准"）。
- 论文实验：两种教师都不比基线好。
- 逐样本 teacher-free 方案（FM 条件于自污染历史、反向 rollout）的缺陷：监督目标总在录制片段内，rollout 走到几千帧后的状态**从未被直接监督**。

**核心洞察（本文立足点）**

> 长 rollout 不必匹配某个教师，只需满足两点：(1) 是**自己场景的现实延续**；(2) **跟随指令动作**。
> - 现实性与场景保真 = rollout 的**分布性质**，可直接对真实数据统计量测量——真实帧分布在任意 horizon 上都有效；
> - 动作跟随 = 条件生成性质，模型预训练损失（FM）已经在监督。

#### 2. 主要技术方法：三个互补约束

**(a) Generative Anchoring（生成锚定）**

- 在"自生成历史 + **以单个真实 chunk 收尾**"的条件上施加 flow-matching 损失。
- 作用：保持动作条件生成能力；让 FM 暴露于模型自身的累积误差。
- **关键细节**：历史必须以真实数据结尾！若自生成历史直接接到干净目标，历史与目标衔接不平滑，模型学会"在每个 chunk 边界重画场景"（周期性重绘闪烁）。以单个真实 chunk 收尾消除接缝（flicker 从 1.31 → 1.07，接近 GT 的 1.03）。

**(b) Context Fidelity（上下文保真）**

- 对自由 rollout 的 latent 统计量计算 Fréchet 距离（FD），**以每个片段自身的 GT 统计量为中心**。
- 作用：保证每条 rollout 忠于自己的初始场景，防止"趋同到数据集平均外观"。
- **关键细节**：只在**梯度可达的尾部 K=8 chunks**上计算统计（graded 变体）——若对全部 N=40 chunks 池化统计而对尾部求梯度，被 detach 的前缀主导统计量，梯度被迫反向过冲补偿（对齐余弦从 0.96 跌到 0.39）。

**(c) Reality Matching（现实匹配）**

- 在**冻结的自监督感知特征空间（DINOv2）**中对生成帧与真实帧计算 FD。
- 作用：惩罚长 rollout 漂移的去向——变暗、发白、瓦片纹理；低阶 latent 统计无法约束语义结构，模型会钻空子生成"统计达标但不像真图"的退化帧，感知特征空间堵住这个漏洞。

**工程实现**

- 运行矩估计（running moment estimates）使 FD 在 **batch size = 1/GPU** 下可微。
- 对 rollout 尾部 K chunks 截断反传（truncated backprop），训练计算可控。
- 每个训练样本是 381 帧片段：锚定回归短真实窗口、上下文保真对比 317 帧 rollout 尾部 vs 自身片段对应区间、现实匹配对比生成帧与真实帧总体——**全程不需要长视频**。
- 部署时 rollout 长度只受动作流驱动，与训练时解耦。

#### 3. 算法流程

```
预训练模型: MiniWorld-1B（block-causal DiT, diffusion forcing, 滚动KV cache）
训练样本: 381帧真实片段
每步:
  1. 用部署采样器自回归生成 rollout（N=40 chunks）
  2. 生成锚定: 历史重渲染至真实chunk结尾 → FM损失（保动作跟随）
  3. 上下文保真: rollout尾部K=8 chunks latent统计 vs 自身GT中心 → FD损失（保场景身份）
  4. 现实匹配: 生成帧 DINOv2特征 vs 真实帧 → FD损失（保真实感）
  5. 三损失联合 → 只对尾部K chunks截断反传
微调: ≤36 GPU小时
部署: 动作流驱动, rollout 任意长
```

#### 4. 输入输出

- **输入**：单帧真实图像 + 动作流（机器人控制流 / 相机轨迹）。
- **输出**：chunk-by-chunk 流式视频，稳定超 4,000 帧（约 2.7 分钟 @24fps 或更长）。
- **模型**：MiniWorld-1B（1B 参数 block-causal DiT，预训练于 253 帧片段）→ MiniWorld-1B-FF。

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

#### 1. 如何理解和表示空间

- **空间一致性的时间维度**：世界模型的空间表示面临的最大威胁不是"不会建模空间"，而是**空间表示随自回归步数退化**——场景身份丢失（变成平均场景）、曝光漂移（Sekai 变黑到 0.40 倍）、空间纹理崩坏（DROID 饱和格纹从机械臂扩散）。Fréchet Forcing 本质是在**保护空间表示的时间不变性**。
- **分布性 vs 逐样本监督的空间哲学**：长时程状态没有配对真值，但"空间应该长什么样"的**统计约束**在任意 horizon 均成立——这暗示空间智能的监督可以分层：逐样本的（动作跟随）用回归，总体的（空间合理性）用分布匹配。
- **上下文依赖性作为空间智能的度量**：论文的 context-dependence slope 探针（rollout 输出对初始场景的依赖度）实际上就是"场景身份保持"的量化——从 0.92 跌到 0.50 意味着模型忘了自己从哪个房间出发。

#### 2. 如何处理空间关系

- **动作-空间因果链的保持**：DROID 上前后向往复操作 4,000 帧后 PSNR 仍 21.5 dB——机械臂改变的空间状态与动作流保持因果一致；Sekai 上 3,581 帧处分叉的转向分支 97% 服从指令方向——空间导航因果在 4,000 帧后依然成立。
- **跨 chunk 空间连续性**：chunk 边界闪烁指标（16×16 池化 luma 跨边界变化 / 界内变化）直接量化空间表示在生成块接缝处的撕裂——这是空间关系处理的微观质检。
- **自纠错的空间动态**：分布约束直接作用于自由 rollout，梯度教会模型"把漂移的轨迹拉回真实分布"——空间表示从开环退化变为闭环自稳。

#### 3. 对 Spatial AGI 的启发

1. **长时程是世界模型的分水岭**：253 帧内 25 dB、4,000 帧处 8.9 dB——世界模型的价值（交互仿真、机器人规划）恰恰在预训练时域之外。Spatial AGI 若要支撑分钟级任务，训练信号必须覆盖"模型自己走到的状态"。
2. **教师-free 的分布监督是可行路线**：真实数据统计（CLIP-FD 底线、DINOv2 特征）在任意 horizon 有效，绕开了动作条件世界模型的教师两难。这一思路可推广到 3DGS 世界模型、占据网格预测等任何自回归空间生成器。
3. **诊断探针方法论**：context-dependence slope（还认不认场景）、gradient-statistic alignment cosine（梯度是否作用在被测对象）、外部裁判一致性（感知空间是否买账）——三探针可移植到任何长时程空间生成系统的训练诊断。
4. **36 GPU 小时的性价比**：不用长视频、不用教师、不改采样器，微调 36 GPU 小时换来 16 倍稳定时域——空间智能的长时程能力可能比想象中便宜。
5. **失败模式学**：context decoupling（忘了场景）、gradient-statistic misalignment（测的和改的不一致）、feature-space exploitation（钻统计空子）、boundary redraw（接缝重画）——四种模式是所有自回归空间生成系统的通用坑 checklist。

#### 4. 可以应用的 Spatial AGI 场景

- **机器人操作仿真器**：DROID 式分钟级操作 rollout，用于策略评估与 model-based 规划（与 Ropedia W0 的应用面直接竞争/互补）。
- **神经世界引擎 / 游戏**：任意时长的可交互场景流。
- **导航预演**：相机轨迹驱动的环境探索模拟，长距离导航规划的"想象器"。
- **数据增强**：长 rollout 生成新视角/新状态作为下游模型训练数据。
- **具身 Agent 的前向模型**：world-action 模型（WAM）的流式骨干——TS-WAM、TrajWAM 类方法的即插即用底座。

### Q3: 基于前面的分析，这个方法的主要创新点和局限性是什么？

#### 1. 主要创新点

1. **首个对自身 rollout 用 Fréchet 距离对真实数据训练流式世界模型的方法**：no teacher、no online critic、no long videos，微调部署采样器本身。
2. **教师两难的破解**：把"rollout 要匹配教师"重构为"rollout 要现实 + 忠于场景 + 跟随动作"，三者分别由感知 FD、上下文 FD、条件 FM 覆盖。
3. **四个失败模式的发现与对应解**：
   - context decoupling → clip 中心化（以自身 GT 为中心）；
   - gradient-statistic misalignment → 只在梯度可达 chunks 上计算统计（graded）；
   - feature-space exploitation → 冻结 DINOv2 感知空间；
   - chunk-boundary redraw → 锚定历史以真实 chunk 收尾。
4. **三诊断探针**：context-dependence slope、gradient-statistic alignment cosine、外部裁判（CLIP-FD）一致性——训练动力学的可观测化。
5. **极致的数据效率**：DROID 中位片段比单个微调片段还短，仍实现 16 倍预训练时域的稳定 rollout。

#### 2. 主要局限性

1. **残余慢漂移**：Sekai FVD 从 186 缓升至 441（4,000 帧内）——稳定不等于永不漂移，更远处未知。
2. **短程小代价**：DROID 前 253 帧 PSNR 降 0.6 dB（24.4 vs 25.0）——分布约束对短程精度有轻微侵蚀。
3. **域内微调**：在 DROID/Sekai 各自微调，跨域泛化未测；新域需要重新微调（虽然只要 36 GPU 时）。
4. **超参敏感性未知面**：K=8、N=40、t_a 噪声水平等选择的鲁棒性只部分消融；换 backbone/采样器是否照搬有效未验证。
5. **亮度类漂移修得好、结构类漂移留尾巴**：FVD 仍有上升趋势，暗示场景内容级的缓慢语义漂移（物体渐变、布局微移）未被完全约束。
6. **评测依赖重放参照**：DROID 用 forward-backward 重放的 PSNR 作为动作跟随代理——它度量的是"回到起点"的能力，不完全等于开放场景的动作保真。

#### 3. 与其他相关工作的对比

| 方法 | 教师 | 长视频 | 动作条件 | 机制 |
|------|------|--------|----------|------|
| DMD 系 (CausVid, Self Forcing) | 需要 | 不需要 | 教师不懂动作 | 分数差蒸馏 |
| Self-Forcing++ / Rolling Forcing / LongLive | 需要 | 滚窗打分 | 部分 | 教师窗口化 |
| OPSD-V / CMD / RMD | 需要+变体 | — | 部分 | 教师缓存/条件改造 |
| Resampling Forcing / SVI / AR Forcing | 无 | 不需要 | 部分 | FM条件于自污染历史 |
| 反向 rollout 系 (Rolling/complementary) | 无 | 不需要 | 部分 | rollout 恢复 GT 起点 |
| **Fréchet Forcing** | **无** | **不需要** | **原生（FM 锚定）** | **真实统计 FD + FM 锚定** |

- **优势**：唯一同时满足"无教师 + 动作原生 + 不需长视频 + 微调部署采样器"的方法；提供系统性的失败模式分析与探针。
- **劣势**：与 DMD 系相比缺少强教师的细粒度语义纠偏（可能在需要高语义保真的开放域不如教师法）；残余慢漂移未根除。

## 核心技术发现

- **发现 1**：DROID 末段（3k-4k 帧）MiniWorld-1B-FF 的 CLIP-FD 44 vs 基线 431（约 10×），FVD 81 vs 2,058（25×）；Sekai 末段 CLIP-FD 226 vs 609、FVD 441 vs 1,193（2.7×）。
- **发现 2**：FM-only 微调几乎不改变长时程行为（DROID 末段 FVD 1,873；Sekai 亮度降到 0.59）——**开环单步目标修不了闭环复合误差**，且训练更久也无济于事（100→400 步 plateau）。
- **发现 3**：边缘 FD 匹配 50 步内让 context-dependence slope 从 0.92 崩到 0.50——rollout 趋同到"数据集平均外观"（偏红、过曝 2.1×）。
- **发现 4**：pooled 统计让梯度-统计对齐余弦从 0.96 跌至 0.39，锐度掉到 GT 的 0.30；graded 变体保持 0.63/0.74。
- **发现 5**：仅用低阶 latent FD，训练损失单调降（8.4→5.8）而 held-out CLIP-FD 先降后升（371→446）——模型用暗场、鱼鳞纹等退化纹理钻统计空子；DINOv2 现实匹配堵住漏洞（200 步 CLIP-FD 215 vs 446）。
- **发现 6**：自生成历史不在真实 chunk 结尾 → 每 8 帧（chunk 边界）周期性重画场景（flicker 1.31），像素/光流指标测不出来，需要专门的 chunk-boundary flicker 指标。
- **发现 7**：动作跟随全程保持：DROID 4,000 帧处 PSNR 21.5 dB（基线 8.9）；Sekai 3,581 帧分叉转向 97% 方向正确（基线 47%、幅度 -0.2%）。

## 与Spatial AGI的关系

### 直接贡献
- 提供了空间智能世界模型的"长时程稳定化"通用配方，直接适用于机器人仿真、导航想象、world-action 模型底座。
- 失败模式分类学与诊断探针构成可迁移的方法论资产。

### 技术启发
- 空间生成的监督应区分"逐样本因果"（动作跟随，回归解决）与"总体统计"（现实性/场景身份，分布匹配解决）——二元监督框架。
- 真实数据的统计量是唯一在任意 horizon 都有效的锚——空间智能的"现实性"可以定义得操作化。

### 应用场景
- 长时程机器人操作仿真与评估、导航规划前演、交互式世界引擎、WAM 流式骨干。

## 个人思考

### 最令人兴奋的发现
- **"真实数据统计在任意 horizon 有效"**这个看似平凡的观察，实际拆掉了长时程训练的最大基础设施障碍（长视频数据 + 强教师）。36 GPU 小时把 1B 模型的稳定时域拉 16 倍——长时程世界模型的门槛从"大厂专属"降到了"实验室可玩"。
- 诊断探针方法论的价值被低估：context slope / alignment cosine / 外部裁判三件套让"模型为什么漂移"第一次变得可观测——这种训练动力学的显微镜比最终分数更能指导研发。

### 潜在局限
- 分布匹配的哲学上限：它保证"像真的"，不保证"是对的"。一条 rollout 可以统计完美却空间错误（墙移动了一米但纹理自然）——FD 约束对结构性空间错误不敏感。未来需要把空间一致性（物体恒常、几何刚性）纳入分布约束的特征空间。
- Sekai FVD 的残余上升趋势提醒：4,000 帧只是里程碑不是终点，真正的交互世界引擎需要小时级稳定，那里的挑战（新房间、新物体组合）可能超出统计锚的覆盖。

### 与昨日研究的关联
- **与 T2-z（昨日 02）互补成对**：T2-z 在测试时优化环境 latent 纠偏（推理时修复漂移），Fréchet Forcing 在训练时教会模型自纠（训练时预防漂移）——一个治标一个治本，可以叠加：FF 微调的模型 + T2-z 的测试时优化。
- **与 ORD-WM（昨日 05）**：ORD-WM 用物体级结构保持空间一致性（结构化防漂移），FF 用统计约束防漂移（无结构化）——两条防漂移路线的对比实验值得做：显式结构是否比统计锚更耐长时程？
- **与 Ropedia W0（今日 01）**：W0 的分钟级实时 rollout 依赖蒸馏，蒸馏是否会引入 FF 所修的漂移？FF 配方可直接移植到 W0 类模型的蒸馏后稳定化。

## 关键数据

- **模型**：MiniWorld-1B（block-causal DiT，diffusion forcing，滚动 KV cache），预训练 253 帧片段；微调 381 帧片段 ≤36 GPU 小时。
- **rollout 长度**：4,001 帧（预训练时域 16 倍、微调片段 10 倍+）。
- **DROID（32 held-out episodes）**：
  - CLIP-FD 末段：44 vs 基线 431（GT 底线 5）
  - FVD 末段：81 vs 2,058（25×）
  - 亮度：GT 的 0.98-1.02（基线结构崩坏但亮度不变）
  - flicker：1.09-1.13（GT 0.98-1.13）
  - PSNR（vs 前后向往复重放）：末段 21.5 dB vs 8.9 dB
- **Sekai（相机探索）**：
  - CLIP-FD 末段：226 vs 609；FVD：441 vs 1,193（2.7×）
  - 亮度：0.92-1.07 vs 基线跌到 0.40
  - yaw 相关（1,021-1,789 帧）：0.69 vs 0.23（录制视频 0.92）
  - 893 帧分叉：100% 方向正确 / 60% 幅度（基线 59% / 19%）
  - 3,581 帧分叉：97% / 49%（基线 47% / -0.2%）
  - 4,000 帧处 yaw 相关：0.71/0.75 vs 0.06/-0.06
- **单条 rollout 体检**：frame 1,500 无伪影 98% → frame 4,000 79%（基线 8/8 全部在 3,000 帧被格纹覆盖）。
- **失败模式量化**：marginal FD 50 步 context slope 0.92→0.50；pooled 200 步对齐余弦 0.96→0.39；latent-only CLIP-FD 回升 371→446；re-rendered-to-end flicker 1.31 → real-chunk-ending 1.07。

## 总结

### 核心发现总结
Fréchet Forcing 把长时程世界模型训练从"找教师"重构为"对真实统计做分布匹配 + 条件 FM 锚定"，用三个互补约束（生成锚定、上下文保真、现实匹配）与四个针对性设计（clip 中心化、graded 统计、DINOv2 感知空间、真实 chunk 收尾），以 36 GPU 小时将 1B 流式世界模型的稳定 rollout 从 253 帧扩展到 4,000+ 帧，且动作跟随全程保持；同时贡献了长时程自回归训练的失败模式分类学与诊断探针方法论。

### 对Spatial AGI的意义
- 长时程稳定性是空间智能世界模型从"演示"走向"可用仿真器"的门票，FF 提供了目前最轻量的门票获取方式。
- "逐样本回归 + 总体分布匹配"的二元监督框架，适用于任何自回归空间生成系统（视频、3DGS、占据场）。
- 剩余挑战（结构级空间错误不受统计约束、小时级稳定、跨域泛化）标注了下一步：把空间一致性显式纳入约束特征空间。

## 附录 A：三约束的机制级精读

### A.1 Generative Anchoring 的精妙之处

**标准自历史训练的接缝问题**：
- 若历史是模型自己重渲染的、目标是干净真实延续 → 历史末帧与目标首帧之间存在"分布接缝"。
- 模型的最优策略是学会在接缝处"重画一遍场景"——每 8 帧（2-latent chunk）一次周期跳变。
- 树冠、山坡等中尺度结构的周期性跳位：像素指标与光流指标都测不出（高频叶纹理与噪声主导像素差），必须用专门的 chunk-boundary flicker 指标（16×16 池化 luma 的跨边界变化/界内变化比，自然视频应在 0.99-1.03）。

**解法的杠杆性**：只在历史末尾保留**一个真实 chunk**——一帧之改，flicker 1.31→1.07（GT 1.03），且远端现实性不受损（CLIP-FD 268 vs 248 @150步，225 步达 226）。

**消融数据（Table 4 精读）**：
| 配置 | 1-125帧 flicker | 1k-1.8k flicker |
|------|------|------|
| GT | 1.03 | 1.02 |
| MiniWorld-1B | 1.16 | 1.45 |
| 重渲染到尾 t_a=0.7 | 1.31 | 1.35 |
| 重渲染到尾 t_a=0.4 | 1.20 | 1.29 |
| **真实chunk收尾** | **1.07** | **1.13** |

降低重噪水平（0.7→0.4）只软化不消除（1.20）——接缝是分布不匹配问题，不是噪声大小问题。

### A.2 Context Fidelity 的两级防错

**第一级：为什么要以自身 GT 为中心（clip centring）？**
- 无条件边缘 FD 只检查"rollout 总体像真帧"——模型可以牺牲场景身份换总体达标。
- 实测：50 步内 context-dependence slope 0.92→0.50；视觉上 1,100 帧处溶成均匀红色调、1,021-1,789 帧过曝至 GT 的 2.1 倍。
- 中心化后：每条 rollout 的统计以"它自己的场景该有的样子"为参照 → 场景身份被强制保持。

**第二级：为什么要 graded（只测梯度可达 chunks）？**
- N=40 chunks 的 rollout，反传只走尾部 K=8 → 若统计池化全部 40 chunks，池化均值被 32 个 detach 前缀主导。
- 梯度无法改前缀 → 只能强迫尾部过冲反向补偿 → 锐度崩到 GT 的 0.30、过平滑。
- 实测：pooled 对齐余弦 0.96→0.39（200步），context slope 崩到 0.32；graded 保持 0.63/0.74。
- **一般原则：统计评估的样本集合必须与梯度作用的样本集合完全一致。**

### A.3 Reality Matching 的补位逻辑

- 前两个约束就位后，latent FD 单独训练仍会漂：训练损失单调降（8.4→5.8）但 held-out CLIP-FD 50 步触底 371 后回升至 446。
- 退化形态：暗场无结构（锐度 0.24×GT）或鱼鳞/菱形周期纹理——低阶 latent 矩（通道均值方差）对语义结构零约束。
- DINOv2 冻结特征的补位：自监督 ViT 对高层视觉内容敏感 → 暗场/周期纹理离真实流形远 → 漏洞关闭。
- 联合效果：200 步 held-out CLIP-FD 215（vs latent-only 446、FM-only 423）；400 步远端降到 188——**训练越久越好（单调）**，与所有变体的"先降后升"形成对照。

### A.4 为什么 FM-only 不行（三点机制归因）

1. **开环单步**：FM 回归单 chunk 单噪声水平的速度场，从不评估"采样器几百步把输出喂回 KV cache 后误差如何复合"。
2. **条件均值偏差**：未来不确定性下回归条件均值 → 轻微偏向平滑变暗——单步可忽略、闭环累积成 Sekai 的持续变暗（0.59）。
3. **锚定干净数据**：即使条件于自去噪历史，FM 的目标仍是录制片段的精确延续（≤317 帧内）——**FM 永远见不到一千帧之外的严重漂移状态**；历史与目标不一致时 FM 只会教模型"无视历史"，而不是"从历史中恢复"。

这三点合起来 = 开环回归目标在闭环部署系统上的结构性失配。分布约束直接在自由 rollout 上评测，漂移（曝光/锐度/内容）即时转化为统计差异并回传梯度——**闭环信号**。

### B.1 统计检验

- 配对 bootstrap（500 次重采样）：FF 对基线的 CLIP-FD 改善在**两域所有 bin 100% 重采样**中成立；FVD 改善 ≥97%——不是 cherry-pick 的均值差。

## 附录 D：诊断探针工具箱（方法论资产）

1. **Context-dependence slope**：rollout 输出对初始场景条件的依赖度回归斜率——衡量"还认不认自己的出身"。健康值 >0.7。

## 附录 I：公式与机制细节补遗

### I.1 训练目标的组合形式（概念还原）

```
L_total = L_FM(生成锚定) + λ_ctx · FD_ctx(上下文保真) + λ_real · FD_real(现实匹配)

L_FM:   在 [自生成历史 | 真实chunk收尾] 条件下的 flow-matching 损失
        → 目标: 保留动作条件生成 + 暴露于累积误差
        → 回归目标精确(真实chunk), 无教师

FD_ctx: Fréchet( μ_rollout_tail ‖ μ_GT_clip )   [latent 空间, clip 中心化, 仅尾部K chunks]
        → 每条 rollout 的统计距离以"自己的GT"为参照

FD_real: Fréchet( φ(gen_frames) ‖ φ(real_frames) )  [φ = 冻结 DINOv2]
        → 与真实总体比现实性, horizon 无关
```

- FD 的可微化：batch 内 running moment estimates（μ, Σ 的滑动估计），使单卡 batch=1 也能回传梯度。
- 截断反传：loss 只定义在尾部 K=8 chunks，计算量 O(K) 而非 O(N)。

### I.2 关键超参

| 超参 | 值 | 作用 |
|------|-----|------|
| N（rollout chunks） | 40 | 训练 rollout 长度（381帧） |
| K（梯度 chunks） | 8 | 截断反传窗口 / 统计评分范围 |
| t_a（锚定重噪水平） | 0.7 | 历史加噪重渲染强度 |
| 锚定历史结尾 | 1个真实chunk | 消接缝 |
| 感知空间 | DINOv2（冻结） | 现实匹配裁判 |
| 微调步数 | 100-225 步即显著 | ≤36 GPU 小时 |
| 上下文 | 253帧预训练 / 381帧微调 | 目标: 超出预训练时域 |

### I.3 MiniWorld-1B 底座说明

- block-causal DiT：chunk 级因果注意力（过去 chunks 可见、未来不可见）。
- diffusion forcing 训练：各 chunk 独立噪声水平、非递减调度。
- 部署：滚动 KV cache 的多步采样器——FF 微调的就是这个部署态采样器，训练-推理零失配。

### I.4 指标定义速查

- **CLIP-FD**：CLIP 图像特征空间的 Fréchet 距离（对真实帧）——per-frame 现实性。
- **FVD**：I3D 特征、16帧窗口的视频 Fréchet 距离——时空质量。
- **Brightness ratio**：rollout 相对自身 GT 的 60 帧窗均值亮度比——曝光漂移（1 为完美）。
- **Chunk-boundary flicker**：16×16 池化 luma 的边界变化/界内变化几何均值——接缝重绘（≈1 为无重绘）。
- **Context-dependence slope**：输出对条件场景的依赖回归斜率——场景身份保持。
- **yaw r**：指令偏航 vs VGGT 反估计偏航的相关——相机可控性。

## 附录 K：哲学层面的两点延伸

### K.1 "现实性"的操作主义定义

FF 的深层贡献是给"现实"下了可操作定义：**在某个冻结特征空间中与真实样本总体的统计距离**。这一定义的可贵之处在于 horizon 无关性——真实帧分布不随 rollout 长度变化。类比：法律上的"合理性社区标准"不因案情时长而改变。局限同样清晰：统计现实 ≠ 结构正确。一条墙移动了一米但纹理自然的 rollout 可以通过所有 FD。空间智能最终需要"结构性正确"的锚——物体级/几何级统计，这是特征空间的下一步进化方向。

### K.2 自回归系统的"自食尾巴"问题

FF 揭示的问题结构具有普适性：任何被部署为消费自身输出的系统（视频世界模型、代码 agent 的自我补全、对话系统的多轮记忆）都面临"训练分布 ≠ 部署分布"的复合误差。FF 的药方——在自己产生的状态上施加与 horizon 无关的外部统计约束——对所有这类系统都是候选解。可以预期"Fréchet 修正"会出现在 LLM 长程一致性、agent 记忆维护等场景的变体中。

## 附录 L：精读问答补充

**Q: 为什么不用真实长视频训练？**
A: 循环论证：长视频昂贵稀缺是动机本身；且即使有，rollout 超 4,000 帧后仍无配对监督——统计约束天然支持任意 horizon，长视频只解决有限段。

**Q: FD 在 batch=1 下估计可靠吗？**
A: 靠跨步 running moment estimates 平滑（μ/Σ 滑动累积），等效于大池化；且两个 FD 都是"分布级"正则，不需要逐步精确，只需要梯度方向正确（alignment cosine 探针监测的正是这个）。

**Q: 会不会把多样性抹平（所有 rollout 长得像）？**
A: 恰恰相反——clip 中心化强制每条 rollout 与"自己的 GT"比而非与"总体"比，场景多样性被显式保护。真正被抹平的风险来自无中心化的 marginal FD（实验已证实并修复）。

**Q: 与 diffusion forcing 原始训练的关系？**
A: FF 完全兼容：预训练照旧（GT 历史 + 独立噪声），FF 只是部署前的最后一公里微调——在自生成历史上重施 FM + 分布正则。可以理解为"diffusion forcing 的闭环补丁"。

**Q: 36 GPU 小时的配置推测？**
A: 论文给上限而非精确配置；从 225 步收敛看，每步是 40-chunk rollout 的前向 + 尾 8-chunk 反传，单卡 A100/H100 级别数十小时可完成——确实是"实验室友好"量级。
