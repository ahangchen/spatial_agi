## 论文概览

本文提出了UniT（Unified Latent Action Tokenizer via Visual Anchoring），一个建立统一物理语言的框架，用于将人类数据迁移到人形机器人。核心思想是：虽然人类和人形机器人的运动学完全不同，但它们执行动作后产生的**视觉后果是一致的**。因此，视觉观察可以作为通用锚点，将异构的运动学空间统一到共享的潜在空间中。

该工作同时在两个范式上验证了UniT：
1. **VLA-UniT（策略学习）**：通过预测统一token实现数据高效和OOD泛化的策略学习
2. **WM-UniT（世界模型）**：通过统一token条件实现跨embodiment的动态迁移和可控视频生成

## 核心问题

### Q1: 核心算法原理

**问题**: 这篇文章的核心算法原理是什么？

**分析**:

#### 1. 核心思想和动机

**问题背景**：人形机器人基础模型的scaling被稀缺的机器人数据瓶颈所限制。大规模egocentric人类数据（如EgoDex）提供了可扩展的替代数据源，但利用这些数据需要跨越人类和人形机器人之间的embodiment鸿沟——两者的运动学（DoF、控制模式）完全不同。

**现有方法的局限**：
- **Action-only方法**（FAST, VQ-BeT等）：只依赖本体感觉重建，缺乏外部锚定，人类和机器人之间存在严重分布偏移
- **Vision-only方法**（Moto, LAPA, UniVLA等）：直接从像素推断意图，绕过了运动学不匹配问题，但容易纠缠低级外观干扰因素（纹理、光照）
- **Decoupled方法**（METIS, XR-1等）：视觉和动作使用独立tokenizer，产生不相连的词汇表，没有深度统一

**UniT的核心洞察**：虽然人类和人形机器人的运动学在结构DoF上不同且包含embodiment-specific噪声，但它们意图的**物理后果共享一致的视觉表示**。例如，无论人手还是机器人手抓取杯子，杯子被移动的视觉变化是一样的。因此，**视觉观察可以作为通用锚点来锚定和对齐不同的运动学空间**。

这个洞察引导出一个优雅的设计原则：UniT作为一个**跨模态信息瓶颈**，蒸馏出底层的物理意图。

#### 2. 主要技术方法

##### 2.1 三分支编码器架构

UniT使用三个并行分支，每个分支使用带可学习query的Transformer编码器：

**视觉分支 (E_v)**：
- 以**逆动力学模型(IDM)**方式工作
- 输入：冻结的DINOv2特征对(o_t, o_{t+k})
- 输出：物理转换的潜在表示
- 设计理念：DINOv2的域不变性提供跨embodiment的稳定视觉锚点
- 遵循UniVLA的视觉特征设计

**动作分支 (E_a)**：
- 编码当前状态s_t和动作块a_{t:t+k}
- 处理跨embodiment差异：
  - 原始动作先padding到统一最大长度
  - 通过embodiment-specific MLP投影
  - 然后汇总为紧凑的潜在控制表示
- 这样不同DoF和不同参数化的动作都能被统一处理

**融合分支 (E_m)**：
- 取视觉和动作分支的特征作为输入
- 产生融合的视觉-运动潜在表示
- 捕获跨模态的互补结构
- 产生更紧凑和鲁棒的token

##### 2.2 共享离散量化

连续潜在表示通过**残差量化（RQ-VAE）**量化到共享码本：

```
ẑ_i = RQ(z_i; C), i ∈ {v, a, m}
```

关键设计：
- **共享码本**确保所有分支和所有embodiment的token驻留在统一离散空间
- **残差量化**通过多层码本逐步细化，同时捕获：
  - 粗粒度物理意图（第一层码本）
  - 细粒度运动细节（后续层码本）
- 这为下游任务提供了层次化的表示

##### 2.3 交叉重建（核心机制）

这是UniT最核心的设计。每个量化token ẑ_i 都被**两个解码器**解码：

**视觉解码器 D_v**（前向动力学模型）：
```
f̂_{t+k}^{(i)} = D_v(ẑ_i, f_t)
```
- 以当前观测的DINOv2特征f_t为条件
- 重建未来帧的DINOv2特征f_{t+k}
- 使用余弦相似度损失监督

**动作解码器 D_a**：
```
â_{t:t+k}^{(i)} = D_a(ẑ_i, s_t)
```
- 以当前状态s_t为条件
- 重建动作块a_{t:t+k}
- 使用动作重建损失监督

**双向约束实现了视觉锚定原则**：

1. **动作→视觉方向**：
   - 强制运动学特征重建视觉转换
   - 将异构动作锚定到实际物理后果
   - 防止网络仅记忆embodiment-specific运动学
   - 过滤掉视觉上不可观察的伪影

2. **视觉→动作方向**：
   - 强制视觉特征重建运动学
   - 剥离低级外观干扰因素（光照、无关背景）
   - 保留与物理运动相关的视觉信息

**结果**：不相关的噪声在优化过程中被丢弃，只保留两种模态的本质交集——**与embodiment无关的物理意图**。

##### 2.4 训练目标

总损失函数：
```
L = Σ_{i∈{v,a,m}} [λ_v · L_cos(f̂_{t+k}^{(i)}, f_{t+k}) + λ_a · L_act(â_{t:t+k}^{(i)}, a_{t:t+k})] + L_RQ
```

其中：
- L_cos：余弦相似度损失（视觉特征重建）
- L_act：动作重建损失
- L_RQ：RQ-VAE承诺损失

#### 3. 算法流程和关键步骤

##### 3.1 UniT Tokenizer训练

```
输入：人类数据集D_h = {(o, s, a)} 和 人形机器人数据集D_r = {(o, s, a)}

Step 1: 特征提取
  - 用冻结DINOv2提取每帧的视觉特征f_t
  - 对动作进行padding + embodiment-specific MLP投影

Step 2: 三分支并行编码
  - 视觉分支：E_v(f_t, f_{t+k}) → z_v
  - 动作分支：E_a(s_t, a_{t:t+k}) → z_a  
  - 融合分支：E_m(z_v, z_a) → z_m

Step 3: 共享RQ-VAE量化
  - ẑ_v = RQ(z_v; C)
  - ẑ_a = RQ(z_a; C)
  - ẑ_m = RQ(z_m; C)

Step 4: 交叉重建（每个分支的量化token都要两个方向重建）
  - 视觉解码：f̂_{t+k} = D_v(ẑ_i, f_t)  ∀ i ∈ {v, a, m}
  - 动作解码：â_{t:t+k} = D_a(ẑ_i, s_t)  ∀ i ∈ {v, a, m}

Step 5: 计算损失并优化
  - L = Σ [λ_v · L_cos + λ_a · L_act] + L_RQ

输出：训练好的UniT tokenizer（编码器 + 共享码本 + 解码器）
```

##### 3.2 VLA-UniT训练

```
Backbone：GR00T n1.5 + Qwen2.5-VL

Step 1: UniT Token生成
  - 将训练数据的(o_t, o_{t+k}, s_t, a_{t:t+k})通过预训练UniT编码
  - 得到离散token序列c_t

Step 2: VLM Token预测
  - 可学习query q_t附加到VLM序列
  - VLM根据(o_t, 指令ℓ)预测UniT离散码
  - p̂_t = f_VLM(o_t, ℓ, q_t)
  - L_token = CE(p̂_t, c_t)

Step 3: Flow Matching动作生成
  - 轻量级flow head从VLM特征生成连续动作
  - A_t^τ = τA_t + (1-τ)ε
  - L_fm = E[||V_θ(A_t^τ|x_t, Enc(o_t), τ) - (A_t - ε)||²]

Step 4: 联合训练
  - L_VLA = L_token + λ_fm · L_fm

关键：token预测和动作生成共享同一个VLM上下文特征x_t
```

##### 3.3 WM-UniT训练

```
Backbone：NVIDIA Cosmos Predict 2.5

Step 1: UniT动作特征提取
  - z̃_t^a = E_a(s_t, a_{t:t+k})  （使用action分支的预量化连续特征）
  - 注意：这里用连续特征而非离散token，因为WM需要更细粒度的控制

Step 2: 特征注入
  - MLP(z̃_t^a)通过cross-attention注入到视频生成模型
  - 与当前观测o_t一起作为条件

Step 3: Flow Matching训练
  - L_WM = E[||V_φ(X_t^τ|o_t, MLP(z̃_t^a), τ) - (X_t - ε)||²]
  - X_t是未来帧的潜在表示

Step 4: 自回归Rollout（推理时）
  - 生成的帧反馈为下一步的观测
  - 支持10步自回归，生成长达10秒的视频
```

#### 4. 输入输出总结

| 组件 | 输入 | 输出 |
|------|------|------|
| UniT Tokenizer | (o_t, o_{t+k}), s_t, a_{t:t+k} | 统一离散潜在动作token |
| VLA-UniT | o_t, 语言指令ℓ | UniT token预测 + embodiment-specific连续动作 |
| WM-UniT | o_t, s_t, a_{t:t+k} | 未来帧（视频生成）|

### Q2: 与Spatial AGI的关系

**问题**: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

#### 1. 如何理解和表示空间

UniT通过**视觉锚点**间接理解和表示空间。其空间表示方式有以下特点：

**隐式空间表示**：
- UniT不直接建模3D空间坐标或物体间的几何关系
- 而是通过"做什么动作导致什么视觉变化"来隐式理解空间关系
- 视觉变化（DINOv2特征差异）编码了空间中的物理交互后果

**相对变化编码**：
- Token捕获的是"相对物理变化"而非绝对状态配置
- 例如：不是记录"手在位置(x,y,z)"，而是记录"杯子从A位置移到B位置"
- 这种相对编码天然适合跨embodiment迁移

**DINOv2作为空间感知基础**：
- 冻结的DINOv2特征捕获了场景中的语义和空间信息
- DINOv2的域不变性确保了跨embodiment的稳定视觉锚点
- 这是整个系统的空间感知基础层

#### 2. 如何处理空间关系

**动作空间作为空间关系的桥梁**：
- 通过将不同embodiment的动作映射到共享token空间
- 实际上是在建立"空间中的意图"的统一表示
- 不同的运动学系统通过"我想要在空间中做什么"而非"我的关节如何配置"来统一

**前向动力学建模**：
- 视觉解码器本质上是一个前向动力学模型
- 给定当前观测和动作token，预测未来观测
- 这隐含了对"动作如何改变空间状态"的理解

**信息瓶颈过滤空间无关因素**：
- 交叉重建机制自动过滤掉：
  - 与运动无关的视觉因素（背景纹理、光照）
  - 与视觉后果无关的运动学细节（embodiment-specific的关节配置）
- 只保留"动作-空间后果"的交集

#### 3. 对Spatial AGI的启发

**关键启发**：

1. **跨embodiment统一是Spatial AGI的必要条件**
   - Spatial AGI需要服务不同形态的agent（人、人形机器人、机械臂、移动机器人）
   - UniT展示了如何通过视觉锚点实现这种统一
   - "视觉后果作为通用语言"的原则可以扩展到更广泛的Spatial AGI场景

2. **物理交互的token化**
   - 将连续的物理交互离散化为token序列
   - 这与语言模型的token化思路一致
   - 为将物理交互整合到统一的基础模型中提供了路径
   - 是构建"物理版GPT"的关键一步

3. **双向交叉重建作为跨模态统一范式**
   - "动作预测视觉 + 视觉预测动作"提取了两种模态的交集
   - 这种信息瓶颈设计原则可以推广到Spatial AGI中其他跨模态统一需求
   - 例如：触觉-视觉统一、语言-空间统一

4. **统一表示的双用途性**
   - 同一个token空间同时服务于策略学习（动作生成）和世界模型（场景预测）
   - 这暗示Spatial AGI中的空间表示也应该同时支持"做什么"和"预测什么"
   - 为统一的Spatial AGI架构提供了设计参考

5. **人类数据作为空间知识的可扩展来源**
   - UniT证明了人类数据可以有效迁移到机器人
   - 对Spatial AGI而言，海量人类视频是空间交互知识的宝库
   - 关键是找到正确的"统一语言"来桥接不同embodiment

#### 4. 可以应用到哪些Spatial AGI场景

1. **跨机器人知识迁移**：不同形态的机器人（人形、轮式、四足）共享学习到的空间交互知识
2. **人机协作**：人类示教直接迁移到机器人执行，无需复杂运动学映射
3. **世界模型构建**：用统一token作为条件生成未来场景，用于规划和想象
4. **大规模人类视频数据利用**：将海量人类操作视频转化为机器人可用的训练信号
5. **多任务、多场景泛化**：统一token空间有助于在不同任务和场景间迁移空间理解
6. **具身智能体的想象与规划**：通过WM-UniT生成未来场景，支持"在脑海中模拟"然后执行
7. **Sim-to-Real迁移**：统一token可能作为仿真和真实世界之间的桥梁

### Q3: 创新点和局限性

#### 1. 主要创新点

**创新点1：三分支交叉重建架构**
- 首次提出将视觉、动作和融合三个分支通过共享码本和双向交叉重建统一
- 相比action-only（FAST, VQ-BeT）：有视觉锚点，能跨embodiment
- 相比vision-only（Moto, LAPA, UniVLA）：保留了运动细节，去噪能力更强
- 相比decoupled（METIS, XR-1）：共享码本实现深度统一，而非松散的KL正则
- 相比Villa-X的V2A单向重建：双向交叉重建提供更精确的跨模态对应

**创新点2：视觉锚点（Visual Anchoring）概念**
- 将"视觉后果"作为通用锚点统一不同embodiment的运动学空间
- 不是试图统一动作空间（不可能，DoF不同），而是统一"物理后果"
- 这是一个优雅的哲学洞察，简化了跨embodiment问题
- 实际效果：t-SNE显示人类和机器人token高度重叠

**创新点3：同时服务两个范式**
- 同一个UniT token空间同时用于：
  - 策略学习（VLA-UniT）：token作为预测目标
  - 世界模型（WM-UniT）：token作为条件信号
- 展示了统一表示的广泛适用性
- 暗示物理交互的token化可以成为Spatial AGI的基础层

**创新点4：零样本任务迁移**
- 真实机器人上实现零样本stacking任务迁移（60%成功率）
- 机器人从未见过stacking训练数据
- 通过人类视频co-training获得stacking能力
- **涌现的上身协调**：自发展现腰部旋转、头部转向来调整视角
- 这表明统一token不仅迁移了"做什么"，还迁移了"怎么移动身体来做"

**创新点5：隐式去噪**
- 视觉锚点提供自然去噪：在动作中注入噪声σ=0.2时
  - FAST退化10.7×
  - Action-only tokenizer退化2.7×  
  - UniT仅退化1.7×
- 原因：视觉锚点提供了额外约束，过滤掉没有视觉对应的运动噪声
- 这对利用噪声较大的野外人类数据非常重要

**创新点6：10×数据效率**
- 仅用10%训练数据（100条/任务）就接近baseline的full-data性能（45.5% vs 47.8%）
- 说明token化压缩了策略学习的信息瓶颈
- VLM从结构化离散空间比从原始连续动作空间学习更高效

#### 2. 主要局限性

**局限1：依赖配对的结构化数据**
- 训练需要(观测, 状态, 动作)三元组
- 人类数据需要包含手部追踪等结构化信息（如EgoDex）
- 对于无标注的人类视频（如YouTube），可能无法直接应用
- **对Spatial AGI的影响**：限制了从互联网规模数据中学习的能力

**局限2：视觉锚点的精度限制**
- 依赖DINOv2特征质量
- 对于视觉上相似但物理上不同的交互可能混淆
- 对于视觉变化微小的精细操作（如轻微力度调整），视觉锚点可能不够精确
- 例如：同样是"转动旋钮"，轻柔转动和用力转动在视觉上差异很小

**局限3：仍需embodiment-specific组件**
- Action decoder是embodiment-specific的
- Embodiment-specific MLP用于动作投影
- 迁移到全新机器人需要重新训练这些组件
- 不是完全的"一个模型服务所有机器人"

**局限4：评估范围有限**
- 策略学习集中在桌面操作任务（pick-and-place、articulated manipulation）
- 未涉及移动操作、导航等需要更大空间理解的任务
- 世界模型评估主要在较简单的场景
- **对Spatial AGI的影响**：未验证在需要大范围空间理解（如家庭导航）的场景

**局限5：计算开销未讨论**
- 三分支架构 + RQ-VAE量化增加了训练复杂度
- 论文未详细讨论tokenizer训练的计算成本和时间
- 对于需要频繁添加新embodiment的场景，重新训练tokenizer的成本未知

**局限6：离散化的信息损失**
- 虽然RQ-VAE通过多层量化缓解了信息损失
- 离散化本身可能限制超精细操作的精度
- 对于需要亚毫米级精度的操作，离散token的粒度可能不够

**局限7：世界模型中的自回归误差累积**
- 10步自回归rollout中，误差会逐步累积
- 虽然UniT token条件改善了可控性
- 但长时域预测的可靠性仍受限于视频生成模型的固有限制

  - 在EgoDex动作轨迹中注入不同强度的高斯噪声σ

- **VLA内部**（Fig. 7b）：

- **WM内部**（Fig. 7c）：
  - Vanilla Cosmos：**完全分离**的集群

## 核心技术发现

### 发现1：视觉-动作交叉重建作为信息瓶颈
通过强制双向重建，UniT自动过滤掉embodiment-specific噪声和视觉干扰因素，只保留物理意图。这是一个非常优雅的设计——不需要显式定义什么是"噪声"，信息瓶颈自然地完成了这个工作。

### 发现2：共享RQ-VAE码本的关键作用
共享码本迫使不同分支和不同embodiment的token使用相同的"词汇表"。这是跨embodiment统一的基础。残差量化同时捕获粗粒度（物理意图类别）和细粒度（运动细节）信息，提供了一个层次化的物理语言。

### 发现3：Token级对齐传播到下游模型内部
UniT的token对齐不仅停留在tokenizer层面，还传播到了VLA和WM的内部表示中。t-SNE验证了vanilla模型中人类/机器人特征完全分离，而UniT-based模型中高度重叠。这意味着统一token提供了结构性的对齐基础，而不仅仅是表面的token映射。

### 发现4：涌现的上身协调模式
在零样本stacking任务中，机器人展现了腰部旋转和头部转向等在机器人训练数据中从未出现过的协调模式。这些模式来自人类视频的EgoDex数据。这表明UniT不仅迁移了"做什么"（任务语义），还迁移了"怎么移动身体来做"（协调模式），这是跨embodiment迁移的深层效果。

### 发现5：去噪作为视觉锚定的副产品
视觉锚点不仅统一了跨embodiment表示，还提供了自然的去噪效果。这是因为噪声（没有视觉对应的运动伪影）在交叉重建中被自动过滤。这使得UniT特别适合处理野外的噪声人类数据。

## 与Spatial AGI的关系

### 直接贡献

1. **跨embodiment物理语言**：为Spatial AGI提供了如何统一不同agent感知-动作空间的实例。未来Spatial AGI需要在不同形态的agent之间共享空间知识。

2. **利用人类数据扩展空间知识**：展示了如何将大规模人类操作数据（EgoDex等）转化为机器人可用的训练信号。这对Spatial AGI的数据规模化至关重要。

3. **统一策略学习+世界模型**：同一个token表示同时服务于动作生成和场景预测。这暗示Spatial AGI的空间表示也应该同时支持"做什么"和"预测什么"。

### 技术启发

1. **视觉锚点原则可以泛化**：
   - 不只是human-to-humanoid
   - 任何跨embodiment场景都可以用"视觉后果"作为统一语言
   - 例如：四足机器人 ↔ 轮式机器人、机械臂 ↔ 人手

2. **交叉重建作为跨模态统一范式**：
   - 这个思路可以应用到Spatial AGI中其他跨模态统一需求
   - 例如：触觉-视觉统一（强制触觉预测视觉、视觉预测触觉）
   - 语言-空间统一（强制语言描述预测空间配置、空间配置预测语言描述）

3. **离散token作为物理交互的"词汇"**：
   - 为构建"物理版GPT"提供了基础
   - 物理交互可以被离散化为类似自然语言的token序列
   - 这使得物理交互可以被LLM/VLM原生处理

4. **相对变化优于绝对配置**：
   - UniT的token捕获"相对物理变化"而非绝对状态
   - 这对Spatial AGI的启示：空间表示应该关注"改变"而非"状态"

### 应用场景

1. **大规模人类视频驱动的机器人策略学习**：利用YouTube等平台的海量操作视频
2. **跨机器人形态的知识共享**：新机器人只需训练embodiment-specific组件
3. **基于世界模型的规划和决策**：用WM-UniT生成未来场景，支持"在脑海中模拟"
4. **人形机器人的快速技能获取**：通过人类示教快速学会新任务
5. **Sim-to-Real迁移**：统一token可能作为仿真和真实世界之间的桥梁
6. **具身AI的基础模型预训练**：UniT token作为物理交互的预训练目标

## 个人思考

### 最令人兴奋的发现

**零样本stacking任务迁移 + 涌现的上身协调**：这是这篇论文最令人兴奋的发现。机器人从未在stacking任务上训练过，但通过人类视频的co-training，不仅学会了stacking的逻辑（把一个碗放在另一个上面），还自发地展现了腰部旋转和头部转向来调整视角。这种"涌现协调"意味着统一token空间捕获的不仅是"做什么"（任务语义），还有"怎么移动身体来做"（运动协调策略）。

**10×数据效率**：这个结果暗示了一个重要事实——现有的VLA模型（如GR00T）直接回归原始动作是低效的。通过将动作空间token化为结构化的离散表示，VLM可以更高效地学习。这对未来的Spatial AGI架构设计有重要启示。

**无交叉重建 = 0%零样本迁移**：这个消融结果非常说明问题。仅共享码本不够，必须是双向交叉重建才能建立真正的跨embodiment桥梁。这说明"统一"不仅需要共享词汇，还需要每个词汇都有跨模态的语义约束。

### 潜在局限

1. **桌面操作的天花板**：目前只验证了桌面操作任务。Spatial AGI需要的是全场景的空间理解（导航、抓取、放置、开门等），这些任务的空间范围远大于桌面。UniT能否扩展到移动操作（如整个房间的导航+操作）是一个关键的开放问题。

2. **对结构化人类数据的依赖**：EgoDex这类带手部追踪的高质量数据很稀缺且收集成本高。如何从无标注的人类视频中学习统一token是一个关键的开放问题。这可能是限制UniT扩展性的最大瓶颈。

3. **视觉锚点在精细操作中的可靠性**：对于需要精确力控制的交互（如插钥匙、拧螺丝），视觉变化可能不够显著，视觉锚点的有效性存疑。这类任务可能需要引入力觉或触觉作为额外的锚点。

4. **长时域任务**：论文中的任务都是短时域的（单步或少数几步交互）。对于需要长时域规划的任务（如"整理整个房间"），UniT的token表示是否能保持一致性和连贯性还不清楚。

### 与空间智能研究的关联

这篇论文展示了一个重要趋势：**将物理交互token化**，使之可以像语言token一样被基础模型处理。这与Spatial AGI的愿景高度一致——未来的空间智能需要将3D空间理解、物理交互、语言指令统一在一个模型中。

UniT的"统一物理语言"可以看作是Spatial AGI中"物理交互层"的一个实例。更完整的Spatial AGI可能需要多层统一语言：
- **感知层**：统一3D场景表示（如3D Gaussian Splatting, NeRF等）
- **理解层**：统一场景语义和空间关系（如Scene Graph, 3D-LLM等）
- **交互层**：统一物理交互语言 ← UniT所在的位置
- **规划层**：统一任务规划表示（如Language Model Planning等）

UniT证明了交互层的跨embodiment统一是可行的，而且可以通过简单的原则（视觉锚点）实现。这为Spatial AGI的可扩展性提供了重要信心。

**一个大胆的设想**：如果将UniT的token空间与3D场景表示（如3DGS）和语言表示（如LLM）统一，可能构建一个真正的Spatial AGI基础模型——它既能理解3D空间、又能用自然语言接收指令、还能通过UniT token执行物理交互。这种三层统一的架构可能是Spatial AGI的一个有前景的方向。

## 总结

### 核心发现总结

UniT提出了一种视觉锚定的三分支交叉重建tokenizer，通过将异构的人类和人形机器人动作映射到共享的离散潜在空间，建立了一个"统一物理语言"。该统一token同时服务于策略学习（VLA-UniT）和世界模型（WM-UniT）两个范式。

核心贡献包括：
1. **视觉锚点原则**：用物理后果的视觉一致性统一不同运动学
2. **三分支交叉重建**：信息瓶颈自动提取embodiment-agnostic的物理意图
3. **双范式验证**：同时改善策略学习和世界模型
4. **实际效果**：10×数据效率、强OOD泛化、零样本任务迁移、涌现协调

### 对Spatial AGI的意义

UniT为Spatial AGI提供了一个关键构建块：**如何将不同embodiment的物理交互统一到一个共享表示中**。其核心贡献不是直接建模3D空间，而是通过视觉锚点将"物理意图"从具体的运动学中解耦出来。

这篇论文也暗示了Spatial AGI的一个重要方向：**物理交互的token化**。将连续的物理交互离散化为token，使之可以被基础模型（VLM/LLM）原生处理，这为构建真正统一的Spatial AGI模型铺平了道路。

未来的Spatial AGI可能需要多层统一语言（感知层、理解层、交互层、规划层），而UniT为交互层提供了一个经过验证的设计方案。如果将UniT的token空间与3D场景表示和语言表示统一，可能构建出真正的Spatial AGI基础模型。
