# UniT: Toward a Unified Physical Language for Human-to-Humanoid Policy Learning and World Modeling

**ArXiv:** 2604.19734 | **Date:** 2026-04-21 | **Authors:** Boyu Chen, Yi Chen, Lu Qiu, Jerry Bai, Yuying Ge, Yixiao Ge (XPeng Robotics)

**Tags:** #Humanoid #CrossEmbodiment #WorldModel #VLA #HumanDataTransfer #UnifiedRepresentation

---

## 一句话总结

UniT 提出统一物理语言框架，通过三分支交叉重建机制将人类和人型机器人的异构运动学桥接到共享离散潜在空间，实现人类数据向人型机器人的零样本策略迁移和世界模型对齐。

## 核心贡献

1. **统一物理语言：** 提出 embodiment-agnostic 的离散潜在空间，编码跨身体的"物理意图"
2. **三分支交叉重建：**
   - Action → Vision：将运动学锚定到物理结果
   - Vision → Action：过滤无关视觉混淆
   - Fusion：将纯化后的模态融合到共享空间
3. **双范式验证：** 同时验证 Policy Learning (VLA-UniT) 和 World Modeling (WM-UniT)
4. **零样本任务迁移：** 人类数据直接迁移到人型机器人，无需机器人数据

## 方法细节

### 核心哲学
异构运动学（人类 vs 人型机器人）虽然执行方式不同，但共享**通用的视觉后果**。抓住视觉后果这个不变量，就能建立跨身体的统一表征。

### 三分支机制
1. **Action→Vision 分支：** 动作预测视觉结果 → 将运动学映射到物理效果
2. **Vision→Action 分支：** 视觉重建动作 → 过滤与动作无关的视觉噪声
3. **Fusion 分支：** 将两个纯化后的模态融合到离散潜在空间

### VLA-UniT (Policy Learning)
- 预测统一 token 来利用多样化人类数据
- 实现 SOTA 数据效率和 OOD 泛化
- 零样本任务迁移

### WM-UniT (World Modeling)
- 用统一 token 对齐跨身体动力学
- 人类数据直接转化为增强的人型视频生成可控性
- 实现 human-to-humanoid 的直接动作迁移

### t-SNE 验证
人类和人型机器人的特征在共享空间中收敛到同一流形，实证验证了表征对齐。

## 关键实验结果

- **Humanoid 仿真 benchmark：** SOTA 数据效率和 OOD 泛化
- **真实世界部署：** 验证了零样本迁移
- **视频生成：** 统一 token 条件下的跨身体动作迁移可控性

## 与空间智能的关系

**核心相关。** UniT 解决了空间智能的一个根本问题：
1. **跨身体空间理解：** 不同智能体如何共享对同一物理世界的理解
2. **抽象空间表征：** 统一 token 是物理意图的抽象，不受具体执行方式限制
3. **视觉-动作对齐：** "看到什么结果"比"怎么执行"更本质

## 启发与思考

1. **人类数据是人型机器人的金矿：** 大规模 ego-centric 人类视频可规模化获取，UniT 打通了利用路径
2. **"视觉后果"作为跨身体桥梁：** 这个洞察非常优雅 — 不同身体执行同一意图的视觉结果应该是相似的
3. **统一表示的双用途：** 同一个 token 空间既能做策略又能做世界模型，说明这是真正的物理语言
4. **对通用 spatial AGI 的启示：** 如果所有智能体都能映射到统一物理语言，多智能体协作就有了基础
5. **XPeng Robotics 出品：** 工业界的实践，从真实人型机器人需求出发

## 局限性

- 目前仅验证人型机器人，是否适用于非人型（轮式、四足等）未验证
- 视觉后果的假设在极端差异化的身体间可能不成立
- t-SNE 可视化作为对齐验证不够严格
- 真实世界评估的规模和多样性有限
