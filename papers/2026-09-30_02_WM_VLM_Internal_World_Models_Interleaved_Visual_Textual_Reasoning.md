# WM-VLM: Probing Internal World Models for Interleaved Visual-Textual Reasoning

## 论文摘要（原文要点）

- 人类解决空间问题时常通过"心理模拟视觉变换"（mental simulation of visual transformations）
- 传统 VLM 主要通过语言进行推理
- 研究问题：VLM 能否通过文本 + 生成中间视觉状态的混合方式解决空间问题？
- 提出 WM-VLM：给预训练 VLM 加一个轻量世界模型分支，用于生成中间视觉状态
- 两阶段训练：
  - 阶段一：学会生成"下一个视觉状态"
  - 阶段二：学会利用该状态进行推理
- 程序化构建带可验证中间视觉状态的空间推理任务
- 可分别评估：模型生成视觉状态的质量、模型对视觉状态的依赖程度
- 2D 与 3D 心理旋转任务上一致超越 SFT 后的骨干，最高提升 39.25 个百分点
- 消融：移除或破坏生成的视觉状态 → 性能骤降，证明增益确实来自视觉状态

## 核心问题

### Q1: 核心算法原理是什么？

**问题**: 这篇文章的核心算法原理是什么？请详细描述核心思想和动机、主要技术方法、算法流程和关键步骤、输入输出。

**分析**:

#### 1. 核心思想和动机

- 认知科学动机：
  - 人类 Shepard & Metzler 式心理旋转：在脑内模拟物体旋转来完成空间判断
  - 推理不总是语言符号操作，可以是"想象 + 检查"
- VLM 现状：
  - 链式推理全在 token 空间（文本 CoT）
  - 遇到空间问题（旋转、折叠、镜像）时，语言难以充分编码连续几何变换
- 核心假设：
  - 如果 VLM 在推理链中能"生成中间视觉状态"（相当于调用内部世界模型做一步模拟），
    再基于生成的视觉状态继续推理，空间推理能力会显著提升
- "Internal World Model"的含义：
  - 不是外挂视频生成模型
  - 而是让 VLM 自身具备一个轻量分支，能自回归地想象下一帧视觉状态

#### 2. 主要技术方法

- 架构：预训练 VLM + 轻量世界模型分支（world model branch）
  - 分支负责生成中间视觉状态（图像形式）
  - 与语言 token 交错（interleaved）进入推理上下文
- 关键设计：
  - 视觉状态的生成与使用是同一场推理的两个环节
  - 生成的中间状态作为证据（evidence）参与后续推理
  - 训练分为明确的两阶段，分别监督"想象"与"利用想象"

#### 3. 算法流程和关键步骤

**阶段一：学习生成下一视觉状态**
- 任务形式：给定当前视觉状态 + 变换指令（如"旋转 90°"）→ 生成变换后的图像
- 数据：程序化构造的空间任务，中间状态可以精确计算
- 监督：生成图像与真值中间状态对齐
- 目的：把"空间变换的内部模拟器"装进模型

**阶段二：学习利用视觉状态推理**
- 任务形式：完整空间问答，推理链 = 文本思考 + 生成的中间视觉状态 + 更多文本
- 监督：最终答案正确性，模型必须先生成状态再作答
- 目的：把"想象"接入"决策"

**推理时流程**：
1. 输入问题（图像 + 文本）
2. 模型生成文本推理片段
3. 调用世界模型分支生成中间视觉状态
4. 视觉状态注入上下文
5. 继续文本推理直至给出答案

#### 4. 评测设计（本文的方法论亮点）

- 程序化任务构造：
  - 2D 心理旋转、3D 心理旋转等
  - 中间视觉状态可验证（有真值）
  - 可做依赖性测试：把生成的视觉状态替换/破坏 → 看答案是否变化
- 两个评估维度：
  - 状态生成质量：生成的图像是否正确模拟了变换
  - 状态依赖程度：答案是否真的用了生成的状态（而非语言捷径）
- 对照组：SFT 后的同一骨干（纯语言推理）

#### 5. 输入输出

- 输入：图像 + 空间问题文本（如"旋转后的图形匹配哪个选项"）
- 输出：交错推理链（文本 + 中间视觉图像）+ 最终答案
- 训练输入：程序化任务及其真值中间状态

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**问题**: 这篇文章与Spatial AGI有什么关系？如何理解和表示空间、处理空间关系、对Spatial AGI的启发、可应用场景。

**分析**:

#### 1. 如何理解和表示空间

- 空间被表示为"可被内部模拟的视觉状态序列"：
  - 空间不是静态特征，而是"当前状态 + 变换算子 → 下一状态"的动态系统
  - 这正是世界模型的定义：状态转移函数的内化
- 中间视觉状态是一种显式的空间工作记忆（spatial working memory）：
  - 语言 CoT 是符号工作记忆
  - 视觉状态是图像式/模拟式工作记忆
- 对 Spatial AGI 的含义：
  - 空间表示应当支持"生成式查询"——不仅回答"这是什么"，
    还能想象"如果我转动它/移动它会变成什么样"
  - 心理旋转任务的成功暗示模型内部形成了物体的几何完整表征，
    而非仅是视角绑定特征

#### 2. 如何处理空间关系

- 空间关系的处理从"一次映射"变成"多步模拟"：
  - 传统：问题图像 → 直接映射答案（隐藏的空间推理全在权重里）
  - WM-VLM：问题图像 → 想象中间状态 → 显式检查 → 答案
- 交错的视觉-文本推理链让空间关系可分步验证：
  - 每一步想象都有真值可查（程序化任务）
  - 依赖性消融确认状态真的被使用 → 推理链不是装饰
- 这是"思考中的图像生成"（generative visual thinking）范式
  在空间推理任务上的系统化验证

#### 3. 对 Spatial AGI 的启发

- **世界模型的推理用法**：世界模型不仅用于机器人动作预演（WAM 类工作），
  也用于纯认知任务的空间推理——同一能力，两种消费者
- **双通道推理**：Spatial AGI 的推理系统应同时支持
  语言符号推理与视觉模拟推理，并能在两者间自由切换
- **可验证训练信号**：程序化构造 + 可验证中间状态是训练空间世界模型的
  高效数据策略——不需要真实机器人数据
- +39.25 个百分点的巨大差距说明：
  纯语言推理在空间任务上的上限远未达到，
  视觉模拟通道提供了质的增量
- 与本系列前日研究的关联：
  - 与 InternW0-Δ / Rolling WAM 的"世界模型→动作"不同，
    本文是"世界模型→认知"，补全了世界模型在感知-认知-动作三角中的认知角色
  - 与 SpatialEvo / Ouroboros-Spatial 的自演化数据思想呼应：
    可验证的空间任务可无限程序化生成

#### 4. 可以应用的 Spatial AGI 场景

- 心理旋转/折叠/镜像类空间测验（心理测量、教育评估自动化）
- 机器人操作前的动作想象预演（视觉层面的 what-if 查询）
- 空间谜题求解（积木装配、折叠包装、迷宫想象走位）
- 具身 Agent 的"闭眼规划"：不看新视角也能预测视野变化
- 3D 场景编辑的前瞻想象：编辑指令 → 预览中间状态 → 确认后执行
- 视频游戏 NPC 与虚拟环境的空间常识推理

### Q3: 主要创新点和局限性是什么？

**问题**: 这个方法的主要创新点和局限性是什么？与其他相关工作相比有什么优势和劣势？

**分析**:

#### 1. 主要创新点

- **创新一：内部世界模型分支**
  - 世界模型不是外挂大型视频生成器，而是 VLM 内的轻量分支
  - 保持预训练权重主体不动，工程友好
- **创新二：两阶段课程（先想象、后利用）**
  - 把"会模拟"与"会用模拟结果"两个能力解耦训练
  - 阶段一的纯预测任务给阶段二提供了可靠的想象基础
- **创新三：可验证中间状态的评测协议**
  - 程序化任务使中间状态有真值
  - 依赖性消融（移除/破坏状态 → 性能骤降）严格证明状态被真实使用
  - 这是对"视觉 CoT 是否只是装饰"质疑的有力回应
- **创新四：交错视觉-文本推理链**
  - 不同于纯文本 CoT 或一次性图像生成，
    推理链在两种模态间自然交错

#### 2. 主要局限性

- 任务范围限于 2D/3D 心理旋转类：
  - 变换算子清晰、状态空间离散
  - 对开放场景（真实照片的物理预测）尚未验证
- 生成中间状态的图像质量与保真度可能是瓶颈：
  - 复杂几何变换的高保真想象远比旋转难
- 推理链变长 → 推理成本上升：
  - 图像 token 比文本 token 昂贵
  - 多步想象在长推理链上的误差累积未知
- 世界模型分支的"轻量"是相对的：
  - 在极复杂 3D 场景上，轻量分支的模拟能力可能不足
- 程序化任务的分布偏差：
  - 模型可能学到程序化任务特有的捷径
  - 到自然图像的迁移需检验

#### 3. 与其他相关工作的对比

- vs 传统 Visual CoT / "thinking with images"：
  - 多数工作生成图像作为搜索/裁剪工具（看图找细节）
  - WM-VLM 生成的是"物理/空间变换后的未来状态"——功能是世界模拟而非感知增强
- vs 外挂扩散模型的空间推理（如用生成模型渲染候选视角）：
  - 外挂方案重、慢、与推理器脱节
  - WM-VLM 分支与推理器联合训练，想象服务于答题
- vs 视频世界模型（WAM/Cosmos 类）：
  - 它们预测长时序、动作条件、面向控制
  - WM-VLM 预测推理中一步的认知性中间状态，面向问答
  - 粒度不同：一个是环境级 rollout，一个是工作记忆级想象
- vs 纯 SFT 空间推理增强：
  - SFT 骨干最高落后 39.25 个百分点 → 结构性差异而非数据量差异
- 优势总结：轻量、可验证、推理链可解释
- 劣势总结：任务域窄、想象保真度受限、推理成本高

## 总结

### 核心发现总结

- WM-VLM 证明：给预训练 VLM 加一个轻量世界模型分支，
  用两阶段课程训练"先想象中间视觉状态、再基于状态推理"，

### 对Spatial AGI的意义

- 空间智能的推理引擎需要一条视觉模拟通道：
  语言 token 处理符号逻辑，内部世界模型处理几何变换。
- 可验证的程序化空间任务是训练与评测该通道的高性价比路径。
- "内部世界模型"概念统一了认知推理与机器人预演两类用法，
  为 Spatial AGI 提供了一个可复用的能力抽象。

## 拓展分析：训练范式深挖

### 两阶段课程的合理性论证

- 为什么不端到端联合训练？
  - 联合训练中模型可能学会跳过想象直接答题（捷径学习）
  - 阶段一的孤立想象任务强制模型先掌握"模拟器"本身
  - 阶段二在可靠的想象基础上学习"消费想象"
- 阶段一细节推断：
  - 监督信号：生成的中间视觉状态 vs 程序化真值
  - 相当于对 VLM 做"视觉预测预训练"
- 阶段二细节推断：
  - 答案监督 + 强制想象结构（先生成状态再作答）
  - 推理链格式：文本 → 视觉状态 → 文本 → 答案

### 评测协议的方法论价值

- 可验证中间状态带来三种诊断能力：
  1. 生成正确性：中间状态像不像真值变换结果
  2. 使用依赖性：破坏状态后答案是否崩坏
  3. 一致性：状态正确时答案是否更可能正确
- 依赖性消融的三种条件（推断）：
  - 移除状态（mask 掉）
  - 替换为错误状态
  - 替换为无关图像
  - 三者均导致性能骤降 → 状态是功能性的
- 这个协议可以推广到所有"生成式推理"工作：
  凡是声称"中间产物帮助推理"的论文都应做此类消融

### 心理旋转任务的特殊地位

- Shepard & Metzler (1971) 经典范式：
  - 判断两个 3D 物体是否为同一物体的不同旋转姿态
  - 人类反应时间与旋转角度线性相关 → 证据：人类在脑内连续模拟旋转
- VLM 复现该范式的意义：
  - 如果模型也表现出角度依赖的推理时间/正确率曲线，
    说明其内部机制与人类心理旋转类似
  - 这是"模型内部形成物体几何表征"的行为学证据

## 拓展分析：与世界模型研究谱系的关系

### 世界模型的三种消费端（本系列研究框架）

1. 感知端：想象遮挡区域、补全观测（如 3D-VCD 类反幻觉）
2. 认知端：心理模拟用于推理（本文 WM-VLM）
3. 动作端：动作条件预演用于控制（InternW0-Δ、Rolling WAM、RoGSW4RLD）
- 本文证明认知端可以独立成立且收益巨大
- 三个端点可能共享同一个世界模型权重 → 未来统一空间智能体的雏形

### 粒度谱系

- 环境级 rollout：视频世界模型，秒-分钟级，面向控制
- 工作记忆级想象：本文，单步变换，面向问答
- 神经级模拟：内部表征扰动（探针研究）
- WM-VLM 占据"工作记忆级"这个此前几乎空白的粒度

## 拓展分析：对 Spatial AGI 评测的启示

- 现有空间基准大多只有最终答案可验证
- 本文的"中间状态可验证"协议提示下一代基准应包含：
  - 中间想象产物的真值
  - 依赖性测试条件
  - 分步得分（想象分 + 消费分）
- 程序化任务生成器是可扩展的数据/评测基础设施：
  - 与 SpatialEvo（确定性几何环境自演化）一脉相承
  - 成本低、无版权问题、难度可控

## 阅读笔记要点（速查）

## 附录 B：三点深层思考

1. 想象的表示形式之争：

   - 但对机器而言，3D 几何 token 可能是更高效的想象格式

   - 认知级想象（本文）+ 动作级预演（WAM）若共享模拟器，

3. 依赖性作为可信度度量：
   - 推理链中每个中间产物都应报告"依赖性分数"
   - 这可能成为生成式推理系统的标准可解释性指标

## 附录 C：Q2 补充——空间理解的三层递进视角

### 第一层：空间感知（识别）

- 识别物体、位姿、布局
- 现有 VLM 已部分具备，但精度有限
- WM-VLM 的阶段一训练实际上强化了这一层：
  要生成正确的变换后图像，必须先"看清"当前状态

### 第二层：空间模拟（变换）

- 在内部执行旋转/平移/折叠等变换
- 这是本文的核心贡献层
- 类比人类心理旋转的 VLM 版本
- 世界模型分支就是这层的计算载体

### 第三层：空间决策（利用）

- 基于模拟结果回答问题/选择动作
- 阶段二训练的内容
- 模型必须学会"信任并检查"自己的想象，
  而不是退回语言捷径

### 三层与 Spatial AGI 能力栈的对应

- Spatial AGI 需要三层贯通：感知→模拟→决策
- WM-VLM 提供了一个把三层串成一条推理链的模板
- 该模板可直接迁移到具身场景：
  感知（看清场景）→ 模拟（想象动作效果）→ 决策（选择动作）

## 附录 D：Q3 补充——潜在风险与开放问题

1. 幻想的忠实性（faithfulness）：
   - 心理旋转的想象错误会被后续推理放大
   - 需要"想象置信度"估计与回退机制
2. 与符号空间推理的融合：
   - 解析几何方法可以精确做旋转，为何要学？
   - 答案：泛化到非解析场景；但混合系统（神经想象+符号校验）可能更稳
3. 评测外推风险：

   - 模型可能只是掌握了"算子查表"而非通用模拟
   - 需要零样本新算子测试来区分
4. 计算经济学：
   - 每次想象生成一张图像的推理开销
   - token 级几何想象（如空间 token）可能是效率方向

## 附录 F：推理链工作示例（示意性重构）

### 示例：3D 心理旋转判断

- 输入：
  - 图像 A：一个 3D 异形物体处于姿态 θ1
  - 图像 B：另一个物体处于姿态 θ2
  - 问题："物体 B 是否是物体 A 旋转后的结果？"
- 无世界模型骨干（SFT）的行为：
  - 直接生成文本："观察两个物体的形状……答案是：是/否"
  - 空间变换隐式发生在一次前向中，容易出错
- WM-VLM 的行为：
  - 步骤1（文本）："我先想象把物体 A 绕纵轴旋转约 90°……"
  - 步骤2（视觉）：世界模型分支生成 A 的旋转后图像 A'
  - 步骤3（文本）："比较 A' 与 B 的枝干朝向：A' 的突出端朝右，B 的朝左……"
  - 步骤4（答案）："不匹配，答案：否"
- 关键差异：
  - 判断发生在"想象产物"上而非原始输入上
  - 推理链留有可检查的中间证据

### 依赖性消融在此例中的体现

- 把步骤2生成的 A' 替换为随机图像：
  - 模型若真依赖 A'，比较步骤失去依据 → 正确率骤降
  - 若模型绕过 A' 直接作答 → 说明想象是装饰
- 实验结果：正确率骤降 → 想象是功能性的
