# MJev-Spatial: System One Spatial Intelligence via Native Attention Matching

**发表日期**: 2026-10-15

**PDF链接**: https://arxiv.org/pdf/2610.22276

---

## 一句话总结

MJev-Spatial 把 VLM 的空间问答从"自回归生成文本"改造成"**单次前向分类决策**"：把每个候选答案（选项/数值区间/图像区域）当作一个类，用骨干网络**预训练的 Q/K 投影**（native attention matching，零新增参数）对决策状态与候选状态打分——12.3M 空间 QA 对训练 Qwen3.5-4B 后，在 12 个空间基准上拿下 7 个第一、总分 65.64% 居八模型之首、12/12 全胜未改动的自回归底座，同时推理速度比最快自回归基线快 2.5×、比底座快 5.6×——空间判断这种输出空间紧凑的任务，"生成答案文本"本身就是浪费的间接层。

## 核心问题

### Q1: 这篇文章的核心算法原理是什么？

#### 1. 核心思想和动机

- **观察**：VLM 回答空间问题的输出空间其实极紧凑——从几个选项中选一个、输出一个标量、输出一个 2D 点。但主流 VLM 仍用自由文本生成作答，为自回归解码和答案解析付出双重代价。
- **Jev（JEV 接口）运动的延续**：论文自述属于 "Jev" 路线——**在声明的答案空间上直接预测，而非生成无约束文本**。Jev-Omni 扩到多模态输入，KEV 用学习的 Q/K 投影做候选打分；MJev-Spatial 的差异化在于：**用骨干预训练的原生 Q/K 投影**给候选内容打分（不引入新参数、不加 typed head），并用**同一个候选分类目标统一训练三种输出类型**。
- **System 1 定位**：空间交互中的大量判断必须在交互速率完成（哪个空间关系成立/多远/放哪）——这是 Kahneman 意义上的 System 1 任务，不需要自由生成的表达力，需要的是低延迟高吞吐的判别力。

#### 2. 核心方法：统一分类框架

**三种任务、一个打分器**：

| 输出类型 | 候选构成 | 阶段数 | 解码 |
|----------|----------|--------|------|
| 选择题 | 题目给的选项内容 | 1 | 选中的选项 |
| 数值预测（长度/计数/角度） | 粗区间 32 根 → 细区间 4/8/32 格 | 1-2 | 细区间中点；0 与溢出设终止类 |
| 点预测 | 3×3 空间区域 | 3 | 最终格中心（原图坐标） |

- **候选打分**（native attention matching）：
  - 取第 32 层（L32）的输入状态：决策位置状态 u_t 与各候选末位状态 v_{t,i}；
  - 用骨干**预训练的** W_Q / W_K 投影 + RMSNorm + partial rotary（保留原 token 位置）计算 16 头缩放内积，头平均得到候选 logit，softmax 仅在合法候选上；
  - 分组查询注意力式共享（每 4 个 query 头共享一个 key 头）；
  - L32 之后的 V 投影、输出门、FFN 等无梯度通路的部分**直接删除**——推理图更瘦。
- **为什么用预训练 Q/K？** 这些投影已经学会了"上下文状态与内容状态的相关性匹配"——候选打分本质上就是注意力打分的判别式重用。消融显示该设计在有竞争力的质量下训练成本更低（vs 加 typed head）。

#### 3. 关键机制

**(a) 数值编码**：
- 长度：32 根区间 + 每根 4/8 细格；计数：32 粗组 × 32 整数 = 精确覆盖 0-1023；角度：14 根 × 32 细格；
- 粗到细两阶段，零与溢出为一类终止——覆盖优先、精度其次（消融："Coverage comes before precision"）。

**(b) 点预测**：三次 3×3 区域选择，每阶段对裁剪图像重新编码——图像支持下的空间由粗到细定位。

**(c) 多点预测**：概率树扩展（同一空间层级的分支评估），用于多点计数评测扩展。

**(d) 联合阶段监督**：
- 所有粗细阶段的目标路径由标注答案确定，teacher forcing 下**单次前向**同时计算全部阶段的交叉熵损失；
- 每题按阶段数归一化——三点题与单选权重相同；
- 推理时阶段串行（下一阶段候选与裁剪依赖当前选择）。

**(e) 高效训练工程**：
- 全局批内按扩展后序列长度分组 + 最长优先（LPT）跨 GPU 分配 + 计入 padding 与视觉 token 的成本模型；
- 训练吞吐比原始 batching **+30.8%**；
- 全参数微调（12.3M QA 的规模下 PEFT 不划算）。

#### 4. 训练数据

- **12.3M QA 对**，从既有空间数据集转换：SAT 选择题、VST-P 长度、RefSpatial 指点等；
- 严格的数据质量流程：答案选项置换记录、数值监督核对、点与关系监督转换、重复过滤与**评测集隔离**（B.3 节专门防泄漏）。

#### 5. 主结果

- **12 个基准**：SAT、CV-Bench、BLINK、MMSI-Bench、RefSpatial-Bench、Where2Place、Point-Bench、RoboSpatial VQA+pointing、ERQA、EmbSpatial、VSI-Bench；
- **总分 65.64%**，八模型（含 Qwen3-VL-8B、InternVL3.5-8B、Molmo2-ER、Spatial-SSRL、SenseNova-SI、SpatialThinker）中第一；
- 12 个基准中 **7 个第一**，**12/12 全部胜过未改动的 Qwen3.5-4B 底座**（底座均分 54.80 → 65.64，+10.8 分）；
- **延迟**：比最快自回归基线快 2.5×，比底座快 5.6×。

#### 6. 消融要点

- **预训练候选打分**：vs LM head 读出 vs 新增 typed head——Q/K 原生打分在匹配对照下质量有竞争力且训练更省；深度上 L32 mean（浅于最后层的读出）就已足够——后期层融合并无一致收益（E.3）；
- **数值离散化**：覆盖率优先的 30×32 方案作为模型测试有效；削减细阶段候选数有损；
- **视觉精化**：ROI 特征 replay / 直接视觉 token 候选 vs 重新编码裁剪——权衡详尽（附录 F 实验）；
- **头干预分析**（E.4）：16 头贡献可分解，存在冗余头，因果干预验证打分的结构性。

#### 7. 输入输出

- **输入**：有序图像 + 空间问题（含声明的输出类型与候选空间）；
- **输出**：单次/少次前向的类别决策 → 选项 / 数值（区间中点）/ 点（格中心）；
- **无任何答案 token 生成、无文本解析**。

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

#### 1. 如何理解和表示空间

- MJev-Spatial 的空间知识存在**骨干的注意力投影里**——它不新增空间表示，而是把预训练 Transformer 已有的"状态-内容匹配"机制重定向为空间判别器。这隐含一个重要论断：**预训练多模态骨干已经编码了足够的空间关联结构，瓶颈在"读出方式"而非"表示容量"**。
- 空间量的表示是**离散码本**（区间树/区域树）：连续空间被结构化为可分类的层级离散空间。这与人类心理物理学的类别化空间判断（粗-细两阶段感知决策）惊人一致——System 1 空间认知本来就是分类式的。
- 输出表示的**契约化**（声明的候选空间）与本周 BetaMem 的写契约形成有趣对照：一个约束"读出"，一个约束"写入"——空间智能的接口契约化是共同趋势。

#### 2. 如何处理空间关系

- 三类空间任务（关系选择/数值估计/定位）被证明可以共享一个打分机制——**空间关系的语义判断与空间量的度量估计在表征层面同源**；
- 粗到细的点预测（3 次 3×3）把"指出位置"分解为三次空间注意力聚焦——空间定位 = 级联的空间注意力收缩；
- 数值任务的覆盖优先设计（0 与溢出类）承认空间估计的本质不确定性——System 1 不假装精确，它先保证量级正确。

#### 3. 对 Spatial AGI 的启发

1. **空间智能的分层架构获得了实证支撑**：交互速率的空间判断应当走判别式快路径（本文），深度空间推理走生成/想象慢路径（今日 CoWorld）。未来空间 Agent 的标准形态是**双档位系统**，本文提供了快档的最强基线。
2. **"读出即能力"的设计哲学**：不改骨干、不加参数，仅改读出方式就 +10.8 分、5.6× 加速——提示空间智能研究中有大量"表示已足够、接口是瓶颈"的低垂果实。对任何空间 VLM 的第一个优化建议：先试试换读出头再谈加大模型。
3. **数据引擎的规模验证**：12.3M QA 的转换-清洗-防泄漏产线证明空间监督数据可以从既有标注规模化合成——与 OpenSpatial 等数据引擎工作共同确认：空间智能的数据瓶颈已解，剩下的是训练目标与架构问题。
4. **机器人部署的直接价值**：5.6× 延迟降低 + 无 token 生成的确定性输出，使 VLM 级空间判断首次进入控制回路的延迟预算——Where2Place/RoboSpatial 的强表现（放置/机器人空间关系）直接对准操作任务。
5. **与端到端 VLA 的关系**：MJev-Spatial 可作为 VLA 的空间感知前置模块（快速回答"物体在哪/多远"），也可以看作对 VLA"一个模型全包"路线的质疑——分工式架构（专用 System 1 + 专用 System 2）可能优于全能单模型。

#### 4. 可以应用的 Spatial AGI 场景

- 机器人抓取前置判断（物体关系/可达性快速分类）；
- AR/VR 实时空间交互（放置点预测的低延迟要求完美匹配）；
- 自动驾驶即时空间关系判断（相对距离/角度快速估计）；
- 空间 Agent 的 System 1 组件（与 CoWorld 式想象 Agent 组队）。

### Q3: 基于前面的分析，这个方法的主要创新点和局限性是什么？

#### 1. 主要创新点

1. **原生注意力匹配读出**：复用预训练 Q/K 投影做候选打分，零新增参数、删除无梯度冗余计算——"预训练结构即判别器"的优雅设计；
2. **三任务统一分类框架**：选择/数值/点预测共享一个打分器，仅候选空间与精化规则不同——空间输出接口的极简统一；
3. **联合阶段监督 + 效率工程**：teacher forcing 单前向全阶段损失 + LPT 跨卡负载均衡，吞吐 +30.8%——让 12.3M 级训练实际可执行；
4. **System 1 空间模型的概念确立**：第一次把"空间判断的交互速率需求"作为设计第一性原理并系统兑现（2.5-5.6× 加速同时更强）；
5. **全面的消融与干预分析**：读出深度/头聚合/头干预/离散化/精化路径的完整对照——方法论的严谨度罕见；
6. **12 基准 × 8 模型的严格评测**，含防泄漏的评测隔离流程。

#### 2. 主要局限性

1. **输出契约依赖候选空间的事前声明**。开放输出（自由描述空间关系、任意坐标精度）不在框架内——System 1 的代价是表达力上限；候选空间设计本身成为新的手工环节。
2. **被动感知范式未突破**。输入仍是给定图像——单视角下的空间歧义（遮挡、尺度不确定）无法靠读出方式解决，需要主动探索（SpatialScout）或想象（CoWorld）补位。
3. **数值精度天花板**。区间中点解码 + 有限码本深度决定了精度上限——需要亚区间精度时（毫米级抓取）仍要让位于专用几何估计器。
4. **训练分布依赖**。12.3M QA 来自既有数据集转换，长尾空间概念与跨域泛化受限于源数据覆盖；点预测依赖重编码裁剪，多目标场景的候选爆炸未讨论。
5. **与思维链推理的正交性未探索**。System 1 定位放弃了显式推理链——难题（MMSI 类多步推理）上判别式是否够用？65.64% 的总分里 MMSI 的绝对分仍偏低，快慢档混合（先分类失败再升级 System 2）是缺失的自适应机制。
6. **可解释性权衡**。分类决策比文本生成更难自我解释——机器人安全场景中"为什么判定不可达"需要附加机制。

#### 3. 与其他相关工作的对比

| 工作 | 读出方式 | 参数增量 | 任务覆盖 | 延迟 |
|------|----------|----------|----------|------|
| SpatialVLM/RGPT 系 | 自回归文本 | 0 | 关系+数值 | 高 |
| Spatial-SSRL / SpatialThinker | 文本+推理链 | 0 | 关系为主 | 更高 |
| Molmo2-ER | 文本（指向 token 化） | 部分 | 指点强 | 中 |
| Visual Jev（LM head 读出） | 词表概率 | 0 | 分类 | 低 |
| KEV | 学习的 Q/K 头 | +新投影 | 分类 | 低 |
| **MJev-Spatial** | **预训练 Q/K 匹配** | **0（删冗余）** | **选择+数值+点** | **最低** |

- **vs SpatialThinker 等推理增强系**：正交而非竞争——一个向快、一个向深；合体（快档先行、慢档兜底）是明确的工程方向。
- **vs Molmo2-ER**：Molmo 把指点 token 化进语言接口（仍生成）；MJev 完全绕开生成——两种"非自然语言接口"路线的直接对比（Table 中 MJev 总分领先 Molmo2-ER 约 6.6 分）。
- **vs 今日 CoWorld**：认知档位的对偶（详见 CoWorld 附录 I）——快档分类 vs 慢档想象，共享同一"输出契约化"哲学。

## 核心技术发现

- **发现 1**：预训练 Q/K 投影直接可用作空间候选判别器——多模态预训练已隐式编码空间判别结构，读出是瓶颈（L32 mean 读出即可，后期层无一致增益）。
- **发现 2**：判别式读出不仅快还更准（12/12 胜底座）——文本生成的格式负担与监督噪声（learning the textual form）确实在伤害空间学习。
- **发现 3**：数值空间估计的覆盖率优先原则——先保证量级类正确（粗阶段），细精度边际收益递减。
- **发现 4**：空间数据可规模化转换（12.3M）+ 联合阶段监督 + 批处理工程 = 全参微调 4B 模型的可行配方（吞吐 +30.8%）。

## 与Spatial AGI的关系

### 直接贡献
- 提供 System 1 空间判断的最强开源基线（速度与精度双 SOTA 路径）；
- 确立"声明式输出契约 + 判别式读出"的空间接口范式。

### 技术启发
- 空间 VLM 优化顺序：先读出头、后骨干；
- 空间输出三原语（选项/标量/点）的统一分类接口。

### 应用场景
- 机器人操作前置判断、AR 实时放置、驾驶即时关系估计、空间 Agent 快档组件。

## 个人思考

### 最令人兴奋的发现
- **"删掉生成"反而全面变强**。这挑战了一个隐含信仰：多模态对齐必须经由语言接口。MJev 证明对空间任务，语言生成层是纯粹的间接损失源（格式学习、解码随机性、解析错误）。这与 Vision 模型绕开语言直接做检测/分割的历史同构——**空间智能正在重复"逃离语言接口"的范式迁移**，只是这次发生在 VLM 内部。
- **L32 读出的启示**：不用最后层、用中层状态打分更好——空间判别信息在中层已经就绪，最后层的语言特化反而是"污染"。空间智能的表征地理学（哪些层编码什么空间信息）值得系统测绘。

### 潜在局限
- 候选空间的手工设计是新瓶颈：每个新空间任务都要设计码本（区间树/区域树）——码本学习的自动化（从数据中学码本）是显然的下一步；
- 快档没有"知道自己不会"的机制——错分类是静默的；置信度校准（softmax 概率是否可靠）论文未报告，而这在安全相关场景是硬需求。

### 与前日研究的关联
- **与 CoWorld（今日03）**：System 1/2 对偶（详见 CoWorld 附录 I）——合体方向：MJev 判别低置信 → 升级 CoWorld 想象 → 结果回灌再分类的快慢闭环。
- **与 SpatialScout（10-21/03）**：SpatialScout 暴露的"精确级真空"（IoU>0.9 仅 3.25%）部分可由 MJev 的级联区域分类改善——3×3×3 的级联精化本质上是廉价的三角化替代；值得直接把 MJev 空间头接进 SpatialScout Agent 工具箱。
- **与 DynThinker/GeoThinker（10-20）**：它们给空间推理加思考链（向慢），MJev 去思考链（向快）——领域在双向探索后终将汇于分档架构。
- **与 BetaMem（今日01）**：BetaMem 的经验记忆可以修正 MJev 的系统性误判（"该用户环境里玻璃门常被误判为开放"）——记忆修正快判断的空间版。

## 关键数据

- 底座/训练：Qwen3.5-4B 全参微调，12.3M QA（SAT/VST-P/RefSpatial 等转换），吞吐 +30.8%
- 主结果：12 基准总分 65.64%（8 模型第一）、7/12 第一、12/12 胜底座（54.80→65.64）
- 速度：最快自回归基线的 2.5×、底座的 5.6×；无 token 生成、无文本解析
- 架构：L32 决策状态 × 候选末位状态的预训练 Q/K 匹配（16 头，GQA 式分组，partial rotary）
- 输出契约：选择=单阶段；数值=32根×(4/8/32)格 1-2 阶段；点=3×3×3 阶段（裁剪重编码）
- 消融：L32 mean 优于更深融合；覆盖优先离散化；ROI replay vs 直接 token 候选权衡完整

## 总结

### 核心发现总结
MJev-Spatial 证明了空间判断这类紧凑输出任务应当绕开自回归生成：以预训练 Q/K 投影为共享候选打分器、以声明式码本为输出契约、以联合阶段监督规模化训练，4B 模型在 12 个空间基准上同时取得最高精度与最低延迟（2.5-5.6×）——空间智能的 System 1 档位从此有了坚实的架构配方。

### 对Spatial AGI的意义
- 确立"读出即能力"的设计杠杆与双档位空间智能架构的快档基线；
- 与想象（CoWorld）、探索（SpatialScout）、记忆（BetaMem）共同拼出空间 Agent 的完整能力栈；
- 指明空间 VLM 的下一步优化顺序：先接口与读出，再规模与数据。

## 附录 A：Q/K 匹配打分的技术细节精读

**状态选取**：
- u_t：第 t 阶段**决策标记位**的 L32 输入状态（携带问题+观测+历史决策的上下文）；
- v_{t,i}：候选 i **末位标记**状态（候选内容的充分统计位）；
- 两者在原序列中都有真实位置 → rotary 保留原位置——相对位置信息参与匹配。

**投影复用的账本**：
- W_Q ∈ R^{4096×2560}（每头 256 维 query + 256 维 gate，仅取 query 半）；
- W_K ∈ R^{1024×2560}（GQA 4 组）；
- 全部取自官方预训练 checkpoint，**零训练新增**；
- 打分仅收集 S 个决策状态 + ΣK 候选状态做投影——**不构成全序列投影**，复杂度 O(Σ_t K_t · d)，远低于 L×L 注意力。

**删除的计算**（L32 之后的死代码）：V 投影、输出门行、输出投影、post-attention norm、SwiGLU FFN、最终 LM norm——因为损失梯度不经过它们。

**头干预发现**（E.4）：16 头贡献可加分解；存在高冗余头（干预后分数不变）；因果干预（置零/复制头）验证了打分结构的真实性——这是对"预训练 Q/K 是否真的在做判别"的严格自检。

## 附录 C：数值码本的覆盖-精度权衡精读

```
长度:   32 根区间 → 每根 4/8 细格      （两阶段）
计数:   32 粗组 × 32 整数 = 0-1023 精确（两阶段，32a₁+a₂）
角度:   14 根 × 32 细格                 （两阶段）
零值:   独立终止类（"没有"是高频答案）
溢出:   独立终止类（超出码本的诚实声明）
```

**设计哲学**：
- **覆盖优先**（"Coverage comes before precision"）：粗阶段错 → 全错，所以粗阶段的类间边界质量是生命线；细阶段只做精修；
- **诚实的失败出口**：零与溢出显式建模——避免模型被迫在码本内乱猜，这是分类框架独有的优雅（生成式模型无法"拒答一个区间"）；
- 消融确认：削减细格（精度）损失小；削减根数（覆盖）损失大——数据支撑了覆盖优先。

**对空间估计任务的通用启示**：任何空间数值接口都应内置三件事——覆盖优先的层级离散化、零/超界终止类、中点解码的误差上界声明。

## 附录 D：训练工程细节精读

**联合阶段监督的序列布局**：
- 每题展开为因果行：决策₁ → 目标选择₁ → 裁剪图 → 决策₂ → 目标选择₂…
- teacher forcing 保证早期决策看不到后期目标与裁剪（因果隔离）；
- 单前向算全部阶段损失 → 训练成本与阶段数解耦。

**LPT 调度**：
- 全局批内按扩展长度排序 → 相似长度微批 → 最长优先分配 GPU（Graham 1969 经典 LPT）；
- 成本模型计入 padding 与视觉 token 差异（点题多两张裁剪图）；
- 每 QA 独立因果行（不 packing——Qwen 的 Gated DeltaNet 状态需要隔离）；
- 效果：+30.8% 吞吐，12.3M 级语料全参训练落地。

**评测隔离**（B.3）：重复过滤时同时隔离评测集——12.3M 的转换产线最大的风险是评测污染，论文专门流程防泄漏，可信度加分。

## 附录 E：与其他读出方案的对照精读（附录 E 实验）

- **LM head 读出（Visual Jev 式）**：直接读候选 token 的词表概率——匹配对照下质量相近但需要候选文本固定措辞，灵活性差；
- **新增 typed head**：加分类头——需额外训练、与预训练表示的兼容性需从头学；
- **Q/K 匹配（本文）**：零新参数、直接匹配"上下文-内容"相关性、可分解可干预；
- **深度扫描**：L24-L40 全扫，L32 mean 最优——空间判别信息的表征地理学证据：中层编码"什么在哪里"，深层特化语言生成。

**结论**：读出方案的选择是"用哪个预训练组件当判别器"的问题——本文的选择（中层 Q/K）兼得质量、成本与可解释性。

## 附录 F：与空间 Agent 工具箱的接口设计（工程推演）

把 MJev-Spatial 接入空间 Agent（如 SpatialScout 型）的具体方案：

```
Agent 决策循环中新增快档工具:
  judge_relation(img, objA, objB) → {left/right/behind/...}, conf
  estimate_distance(img, obj)     → meters ± codebook bound, conf
  predict_point(img, "place target") → (x,y) + cell bounds, conf

设计要点:
 1. 置信度透传: softmax 概率 + 溢出/零类激活 → Agent 的升级触发器
 2. 失败升级路径: 低置信 → 触发三角化/换视角(SpatialScout) 或想象(CoWorld)
 3. 点预测的 cell bounds → 直接作为导航/抓取的误差包络
 4. 批量判断: 同一观测多问题共享一次编码（判别式的前向复用优势）
```

这个接口让 MJev 成为 Agent 的"直觉器官"——多数判断它秒答，
少数疑难才升级慢路径，Token 经济与延迟经济同时最优。

## 附录 G：精读问答补充

**Q1: 为什么叫 "MJev"？**
A: 从相关工作看，"Jev" 是这条"declared answer space 直判"路线的系列名（Jev → Jev-Omni → KEV → VideoJev → Visual Jev）,M 大概率指 Multimodal/Spatial 变体谱系。这不是孤立论文而是一个快速成形的研究 program——接口判别式正在多模态各子域铺开，空间智能是最新战线。

**Q2: 分类框架会不会学到数据集偏差？**
A: 会，且比生成式更隐蔽（无法从输出文本察觉推理依据）。缓解：论文的评测隔离与多基准覆盖；根本缓解需要置信度校准审计与对抗性评测集——这是后续工作的必修课。

**Q3: 与输出 token 极少的生成方案（如直接输出 "A"）相比优势在哪？**
A: 三点：(1) 无解码随机性——单前向确定输出，延迟方差小；(2) 候选可以是任意内容状态（图像区域、区间）而非必须文本化——点预测的候选是空间区域，文本化再生成是绕路；(3) 全阶段单前向训练——生成式无法并行监督多阶段。

**Q4: 最容易被忽视的贡献是什么？**
A: 训练基础设施。12.3M QA 的转换校验产线 + 联合阶段监督 + LPT 调度的完整配方，是任何想复现"判别式空间 VLM"团队的直接起点——方法论贡献不亚于 Q/K 打分本身。

## 附录 K：判别式空间接口的生态推演

如果"声明式候选空间 + 判别式读出"成为空间接口标准，生态将如何演化：

```
层 1  接口规范
      judge(候选集, 观测, 问题) → 分布
      候选空间三原语: 选项集 / 区间树 / 区域树
      （类似 JSON Schema 之于函数调用）

层 2  码本资产
      标准区间码本（长度/角度/计数）、标准区域树（3×3 级联）
      按域预制: 室内尺度 / 驾驶尺度 / 桌面操作尺度
      → 码本成为可复用的开源资产

层 3  打分器模型
      MJev 系列按底座/规模分化（4B/8B/72B 判别器）
      与生成式 VLM 共存于同一骨干（双头: LM head + 匹配读出）

层 4  上层系统
      Agent 快档调用判别器, 慢档调用生成/想象
      置信度协议统一升级路径
```

**对比历史**：这几乎是 NLP 从生成式 QA 走向"函数调用 + 结构化输出"的翻版——
空间智能正在经历同样的接口化进程，且由于输出空间天然紧凑，进程会更快。

## 附录 L：与视觉专用模型的分工边界

一个尖锐的问题：计数/指点为什么不直接用专用模型（检测器/分割器）？

| 需求 | 专用模型 | MJev 判别式 |
|------|----------|-------------|
| 开放词汇 | 需 DINO+CLIP 组合 | 语言问题直接理解 |
| 关系判断 | 弱（需手工逻辑） | 强（原生多模态） |
| 精确定位 | 强（亚像素） | 受码本限制 |
| 多任务统一 | 每任务一模型 | 一个打分器 |
| 长尾语义 | 弱 | 随底座词汇知识 |

**结论**：MJev 占据"语义丰富的中等精度判断"生态位——
精确几何让位给 SLAM/检测器，开放语义判断让位给判别式 VLM。
空间智能系统的正确姿势是**几何层 + 判别层 + 生成层**三层各司其职，
MJev 论文的价值在于把"判别层"从生成式 VLM 的低效形态中解放出来。

## 附录 M：头干预分析的深读价值

附录 E.4 的头干预实验在方法学上值得单独一提：

- **可分解性**：logit = 16 头贡献之和 → 每个空间判断可以问"哪个头在投票"；
- **冗余诊断**：置零单头分数不变 → 剪枝候选（判别器可瘦身）；
- **因果验证**：头间复制/交换 → 打分结构的因果而非相关证据。

这套分析范式对空间智能的意义：**空间判别的机制可解释性**——
未来可以回答"模型判断'左'是靠哪组头、它们关注图像哪个区域"，
这是安全关键空间系统（驾驶/手术机器人）的可解释性刚需，
生成式模型的思维链解释反而做不到这种因果粒度。
