## 核心问题

### Q1: 核心算法原理是什么？

**问题**: 这篇文章的核心算法原理是什么？请详细描述：1) 核心思想和动机，2) 主要技术方法，3) 算法流程和关键步骤，4) 输入输出。

**分析**:

#### 1. 核心思想和动机

多阶段机器人操作需要两种互补能力：**语义规划**（理解"把红块放到蓝块左边"意味着什么步骤序列）和**物理验证**（预测执行后场景会变成什么样）。现状的矛盾：

- VLM擅长语义规划，但对动作如何改变场景**没有任何接地的预测模型**
- 像素级世界模型可以提供这种预见力，但计算昂贵且长时域rollout会产生视觉漂移/伪影
- 潜在空间世界模型（DINO-WM、RLA-WM）更高效，但都不是为语言驱动的计划验证设计的：DINO-WM用CEM搜索（没有语言条件），RLA-WM是马尔可夫架构（没有时序记忆，遮挡下"失忆"）

Verify2Act的核心思想是**解耦**：
1. VLM降级为"语义启发式"——只负责提出少量候选计划（缩小组合搜索空间）
2. 物理可行性判断交给潜在世界模型V2A-WM——在冻结的DINOv2特征空间里"想象"每个候选的后果
3. 双头Critic对想象轨迹打分——时序一致性 + 目标满足度——不通过就打回去让VLM反思重提案

一句话：**VLM说"我觉得该这么做"，世界模型说"我想象了一下，这么做会翻车"，Critic当裁判，执行前先过审。**

#### 2. 主要技术方法

**（a）问题形式化**

给定RGB观测 o_t 和语言目标 g，需执行 H 步原语动作序列 a_{1:H}（pick/place/insert等）。学习DINOv2 patch特征空间上的潜在动力学模型 T̂：

```
Ŝ_k = T̂(Ŝ_{k-1}, a_k),  Ŝ_0 = S_t = E_DINO(o_t)
```

规划目标：a* = argmax C(Ŝ_{1:H}, g)，C是Critic对轨迹与目标的匹配评分。

**（b）V2A-WM世界模型**

两阶段训练（继承RLA-WM框架）：

- **Stage 1**：瓶颈自编码器把帧间残差 ΔS_t = S_{t+1} − S_t 压缩为潜在token z = f_enc(ΔS_t) ∈ R^{M×D_z}（M ≪ P），重建损失训练后冻结
- **Stage 2**：条件flow-matching网络 v_θ 预测残差潜在的速度场：

```
L_FM = E ||v̂ − (z_gt − z_0)||²,  z_τ = τ·z_gt + (1−τ)·z_0
```

推理时单步Euler积分：z_1 = z_0 + v̂，解码 Ŝ_{t+1} = S_t + f_dec(z_1)。多步Euler（N=2,4）无增益。

**两项架构创新**：

1. **交叉注意力动作接地（Cross-attention action grounding）**：RLA-WM用池化动作嵌入自注意力条件化，无法把语言命令关联到具体patch。V2A-WM用冻结CLIP文本编码器编码动作字符串（如"pick and place red block to the left of blue block"），历史patch特征作为query、CLIP token作为key/value做交叉注意力。每个历史patch带可学习的空间+时间位置嵌入：

```
S̃_{t-h,p} = S_{t-h,p} + E_spat,p + E_temp,h
```

2. **因果时序历史窗（Causal temporal history）**：马尔可夫模型在夹爪遮挡物体时"失忆"（物体特征从当前帧消失）。V2A-WM维护T_h帧滑动窗口，episode开头的空槽填可学习的[START]token（避免重复首帧造成零运动偏差），二元有效性掩码限制注意力到有效步。辅助稀疏惩罚 L_sparse 把静态背景patch的速度场正则化到零：L = L_FM + λ·L_sparse。

**（c）双头Critic**

```
s_gp = P_φgp(g | Ŝ_H)              # 空间目标头
s_tc = (1/H)·Σ cos(φ_tc(Ŝ_h), φ_tc(Ŝ_{h-1}))   # 时序一致性头
C = α·s_gp + (1−α)·s_tc
```

- **时序一致性头**：对比学习训练（相邻帧对 vs 非相邻帧对），还输出log方差，不确定性超θ_conf的rollout直接丢弃
- **空间目标头**：关键设计——**保留patch空间布局**（池化嵌入无法区分"红在蓝左"和"蓝在红左"！），用4层Transformer处理16×16 DINOv2 patch token + 目标的CLIP文本token，输出P(g|Ŝ_H)。二元交叉熵训练，训练数据是模拟器状态（目标标签来自物体位姿）+ 世界模型自己想象的状态（**让Critic在测试时看到的那种输入上校准**——这个自举细节很讲究）

**（d）Sim-to-Real迁移**

世界模型和Critic**只用数字孪生数据训练**：
- 孪生 = 工作台的MuJoCo场景，方块纹理取自真实相机帧，相机位姿拟合到真实帧
- 孪生是运动学的：规划器只在机械臂处于home位姿时观察场景，所以子任务渲染为"方块瞬移到目标位姿+放置噪声，然后物理沉降"——完全不建模机械臂本身
- **Real2sim输入对齐**：真实帧的特征与训练帧有差异，对齐在输入侧做——每次规划调用，把方块位姿和相机位姿拟合到相机帧的颜色掩码，世界模型和Critic看到的是**拟合后场景在训练域的渲染**，而VLM直接看真实相机帧。拟合残差>2.5px时直接用相机帧验证

#### 3. 算法流程和关键步骤

Algorithm 1（beam search式并行轨迹规划）：

```
输入: o_t, g, beam宽度B, 时域H, 阈值θ_c/θ_p/θ_conf, 重规划预算R_max

Stage 1 提案: P = VLM.propose(o_t, g, B)   # 一次few-shot调用出B个候选
for r = 0 to R_max:
    for 每个候选 a^(i):
        Ŝ_0 = E_DINO(o_t)
        for k = 1 to H:
            Ŝ_k = WorldModel(Ŝ_{k-1}, a^(i)_k, H_t)
            (s_k, σ̂_k) = Critic_TC(Ŝ_{k-1}, Ŝ_k)
            if σ̂_k ≥ θ_conf or s_k < θ_c: 标记不连贯, break
        if 连贯:
            s_gp = Critic_GP(Ŝ_H, g)
            C^(i) = α·s_gp + (1−α)·平均s_tc
        更新最优候选
    if 最优分 ≥ θ_p: return 已验证的最优计划
    P = VLM.reflect(o_t, g, 最优候选)   # 未通过 → VLM反思重新提案
return 预算耗尽后的最优未验证计划
```

关键分支逻辑：低s_gp触发VLM反思；低s_tc触发世界模型重采样。

#### 4. 输入输出

- **输入**：RGB观测 + 语言目标 + 动作历史
- **中间**：B个候选计划 → 每个的潜在想象轨迹 → Critic分数
- **输出**：经验证的最优动作计划，交给底层技能库执行
- **系统边界**：低层技能（pick-into-bin / place-on-block / place-left-right-of-block）独立于本框架

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**问题**: 这篇文章与通用空间智能（Spatial AGI）有什么关系？请分析：1) 如何理解和表示空间，2) 如何处理空间关系，3) 对Spatial AGI有什么启发，4) 可以应用到哪些Spatial AGI场景。

**分析**:

#### 1. 如何理解和表示空间

V2A-WM的空间表示是**预训练视觉特征空间中的动力学**：

- 场景状态 = DINOv2的16×16 patch特征网格——语义+几何信息都隐含在自监督特征里，无需显式3D重建
- 空间变化 = patch特征残差的潜在动力学——flow-matching学习"这个动作会让特征场怎么流动"
- **空间关系的判定必须保留patch布局**：论文用"red left of blue vs blue left of red在池化后几乎不可区分"这个例子，尖锐地指出了池化表示对空间关系的破坏。空间目标头用Transformer保持patch级结构，本质上是承认：**空间关系信息存在于特征的二维拓扑结构中，而不是特征向量里**

这是一个对Spatial AGI很重要的表征论断：空间关系是"结构性的"而非"汇总性的"，任何把空间信息压成单一向量的表示都会丢失左右/上下/包含等关系。

#### 2. 如何处理空间关系

三层处理：

1. **语言→空间接地**：CLIP交叉注意力把"red block to the left of blue block"这样的语言命令锚定到视觉patch——语言中的实体和空间关系词找到对应的视觉区域
2. **空间→空间预测**：世界模型在特征空间rollout动作后果，时序历史窗保证遮挡期间的空间记忆不丢（夹爪抓住方块时，方块的空间位置记忆仍在窗口内）
3. **空间关系验证**：目标头在想象终态的patch布局上判定目标关系是否成立——空间关系的最终裁决是在"保持了空间结构的想象"上做出的

#### 3. 对Spatial AGI的启发

**启发1：想象-验证分离是空间决策的正确架构。** Verify2Act证明：语义系统（VLM）负责"想出办法"，空间动力学系统（世界模型）负责"预演后果"，评判系统（Critic）负责"裁决"。这与人类运动规划的"心理模拟"（mental simulation）高度对应。Spatial AGI的空间决策不应由单一模型端到端包办，而应该有显式的"内部预演"环节。

**启发2：潜在空间想象比像素想象更适合验证。** Diffusion-WM在真机上反而不如VLM-Only（46.7% vs 53.3%）——像素级想象生成的不可靠图像反而误导反思。而V2A-WM一次rollout只需0.08s（Diffusion-WM 5.1s，63倍差距）。教训：**验证任务要的是"对结果打分"，不是"画出结果"——语义保真的特征空间比视觉逼真的像素空间更合适**。

**启发3：Critic要在自己测试时的输入分布上校准。** 空间目标头除了在真实模拟器状态上训练，还加入了世界模型自己想象的22k状态——想象是有偏差的，Critic必须在想象的分布上校准才能有效裁决。这个"在模型自身的幻觉上训练裁判"的思想，对一切"生成+验证"架构都适用。

**启发4：数字孪生+输入对齐是低成本sim-to-real配方。** 运动学孪生（不建模机械臂）+ real2sim输入对齐（拟合真实帧到训练域渲染）+ 残差超限回退——这套组合让35k过渡数据就把世界模型训到能直接迁移真实图像（无对齐71% Top-1 vs 6%随机）。对算力有限的Spatial AGI研究者是极其务实的路径。

**启发5：验证的价值在"过滤"而非"纠正"。** 实验揭示VLM在简单任务上93.3%的提案本来就正确——验证的增益是把这93.3%提升到100%，消灭规划性失败。这说明在真实系统中，**验证层的价值边界是"低频但致命的错误"**。

#### 4. 可以应用的Spatial AGI场景

- **家庭机器人操作**：多步清理、堆叠、抽屉整理——论文场景的直接扩展
- **工业装配**：Robosuite杂乱螺母装配已验证（58% vs VLM-Only 17%），预条件冲突多的场景增益更大
- **自动驾驶轨迹验证**：候选轨迹在潜在世界模型中rollout后由Critic筛——架构同构
- **无人机航线规划**：语言任务描述→候选航线→空间后果想象→验证
- **空间问答的行动化**：与Think-Capture类高层空间推理配合，验证"如果这么做，空间会怎么变"

### Q3: 主要创新点和局限性是什么？

**问题**: 基于前面的分析，这个方法的主要创新点和局限性是什么？与其他相关工作相比有什么优势和劣势？

**分析**:

#### 1. 主要创新点

1. **模块化验证架构**：VLM提案/世界模型想象/Critic裁决三层解耦，低层策略无关（low-level-policy-agnostic）——可插拔到任何技能库之上
2. **V2A-WM的交叉注意力动作接地**：把语言命令通过CLIP token锚定到视觉patch，解决了池化动作嵌入无法定位空间作用点的问题
3. **因果时序历史窗+有效性掩码+[START]token**：解决马尔可夫模型在夹爪遮挡下的失忆，细节设计（不重复首帧避免零运动偏差）体现工程深度
4. **双头Critic+不确定性丢弃**：时序一致性头（对比学习+log方差）与空间目标头（保patch布局的Transformer），分别触发世界模型重采样和VLM反思——错误来源不同，补救路径不同
5. **纯数字孪生训练+可选real2sim对齐**：零真实数据训练的世界模型在真机迁移成功，无对齐时仍71% Top-1（随机6%）
6. **评测设计严谨**：把规划失败与执行失败分离（所有失败episode都归因：Verify2Act零规划失败，16.7%执行失败来自低层技能滑动）；离线Top-1排序评测（42真实场景模拟所有有效计划打标签）剥离执行噪声度量验证质量

#### 2. 主要局限性

1. **任务空间窄**：4个30×30×60mm彩色方块+3种技能原语，桌面积木操作。铰链物体、接触丰富操作、非刚性物体未验证。而且VLM提案本来就93.3%正确——验证层几乎没有展示空间，作者自己也承认"预条件冲突更频繁的场景才是更强的测试"
2. **真机样本量小**：每任务10 episodes，60 episodes的差异（83.3% vs 61.7%）在统计上需要谨慎解读
3. **数字孪生依赖场景可拟合**：real2sim对齐只适用于"放在桌上的方块"，每帧数秒CPU处理；动态背景/移动相机下背景稀疏正则可能失效
4. **规划延迟**：每次规划调用24s（VLM-Only 3.4s），episode总时间109s；CALVIN上Critic拒绝率49%意味着近半提案要重采样
5. **语义任务上想象与验证的优势会缩小**：世界模型预测的是"物理后果"，对语义后果（"放进垃圾桶算不算完成清理"）仍依赖VLM/Critic的语义判断

#### 3. 与其他相关工作的对比

| 方法 | 验证方式 | 真机成功率 | 关键劣势 |
|------|---------|-----------|---------|
| VLM-Only (GPT-4o) | 无（执行首个提案） | 53.3% | 无物理预见 |
| Diffusion-WM (ReflectVLM式) | 像素扩散想象+反思 | 46.7% | 想象图像不可靠误导反思；5.1s/rollout；444次反思调用 |
| DINO-WM | CEM搜索（无语言） | — | 无法利用语言提案，杂乱场景搜索失败（Nut Assembly 20%） |
| RLA-WM | 潜在想象+目标头 | 61.7% | 马尔可夫失忆；池化动作嵌入；38%计划无法验证仍被执行且Critic判词与结果无关（已验证59% vs 未验证67%成功！） |
| Verify2Act | V2A-WM+双头Critic | 83.3% | — |

RLA-WM的Critic"已验证的计划成功率反而低于未验证的"（59% vs 67%）是全文最有说服力的反面教材：**弱世界模型+弱Critic不如不验证**。Verify2Act让验证重新变得可信（100%计划被验证，Top-1排序97.6%）。

## 核心技术发现

1. **像素想象会误导反思**：Diffusion-WM的反思式验证比不验证还差（46.7% vs 53.3%），潜在特征想象是验证的正确介质
2. **池化表示杀死空间关系**：目标头必须保留patch布局才能区分左右关系
3. **交叉注意力>AdaLN式条件化**：Nut Assembly上58% vs 30%，语言-patch锚定在杂乱场景是必需品而非锦上添花
4. **Critic自举校准**：在世界模型自己想象的22k状态上训练目标头，是Critic可靠的隐藏关键
5. **单步Euler足够**：flow-matching的推理成本可以压到极限（0.08s/rollout），多步积分无增益
6. **运动学孪生即可**：不建模机械臂、瞬移式渲染+物理沉降，35k过渡数据足以支撑真机迁移

## 个人思考

### 最令人兴奋的发现

"验证的价值结构"这个发现比83.3%的数字更重要。论文诚实地展示了：VLM提案93.3%正确时，验证层的增益空间看似很小，但Verify2Act仍然把规划失败降到0——因为那6.7%的错误提案会在任务序列中造成级联浪费。这给出了一个通用结论：**对于要长期自主运行的系统，验证层的价值不在平均成功率，而在尾部风险的消除**。这与工业界的"安全关键验证"思维一致。

另一个惊喜是Critic的自举校准设计：用世界模型的想象状态训练Critic，等于让裁判熟悉被告的造假方式。这个模式可以推广到一切"生成器+验证器"系统——今天早上读的Think-Capture用负样本挖掘训练VLM抵制误导性工具证据，Verify2Act用想象状态训练Critic识破想象偏差，两个领域不约而同地收敛到"在错误来源上训练鉴别器"。

### 潜在局限

最大的问题是**验证层的展示舞台太小**：93.3%基线正确率的任务让83.3% vs 53.3%的对比主要来自执行差异的间接效应。作者自己也承认需要预条件冲突更多的场景。第二个担忧是DINOv2特征空间的物理保真度上限：特征动力学学到的是"像素特征的统计演化"，对真实物理量（力、摩擦、形变）没有显式概念——方块操作里够用，接触丰富操作（倒水、插销）未必。第三，24s的规划延迟对动态环境（移动障碍、人机协作）不可用。

### 与昨日研究的关联

这篇论文与今天精读的Think-Capture形成"空间智能行动化"的上下两篇：Think-Capture解决"看懂空间并给出目标"（高层感知-推理），Verify2Act解决"验证行动的空间后果"（中层想象-验证），两者共同补上了从"空间理解"到"空间行动"的桥梁。与DynThinker的关系则相反——DynThinker在表征侧统一静态/动态，Verify2Act在功能侧统一语义/物理。三篇论文共同指向Spatial AGI的一个系统分层：语义规划（VLM）→ 空间想象（世界模型）→ 物理执行（低层策略），每层有独立的表示和验证机制。此外，Verify2Act的"latent verification"思想与近期读的Verify2Act同名类工作（CauSyncVLA因果潜在世界建模、WEVO世界模型优化VLA）共同构成了2026年底的世界模型验证浪潮——世界模型正从"生成式演示工具"转型为"决策安全组件"。

## 总结

### 核心发现总结

Verify2Act用"VLM提案→V2A-WM潜在想象→双头Critic裁决"的解耦架构，在纯数字孪生数据训练下实现真机83.3%任务成功、零规划失败、每个执行计划都经过验证。技术核心是交叉注意力动作接地（语言→patch）、因果时序历史（遮挡不失忆）、保留空间布局的目标判定（区分左右关系）、以及想象分布上的Critic自举校准。关键教训：像素级想象会误导反思，潜在特征想象+0.08s单步rollout才是验证的正确介质。

### 对Spatial AGI的意义

1. **确立"想象-验证"为空间决策的标准环节**：语义提案必须经过空间后果预演才能执行，这是Spatial AGI安全性的架构基础
2. **潜在空间验证>像素空间验证**：验证要的是语义保真而非视觉逼真，DINOv2特征空间的动力学是高效介质
3. **数字孪生+输入对齐的平民化sim-to-real路线**：零真实数据、低成本机械臂、35k过渡数据即可，对资源受限团队极具参考价值
4. **评测方法论贡献**：规划/执行失败分离、离线Top-1排序、Critic接受率与结果的相关性分析——为世界模型验证研究树立了评测标准

## 附录A：技术细节深挖

### A.1 V2A-WM训练与推理的完整数据流

**训练：**
```
S_t, S_{t+1} → ΔS_t = S_{t+1} - S_t → z_gt = f_enc(ΔS_t)
z_0 ~ N(0, I)
z_τ = τ·z_gt + (1-τ)·z_0
条件: 历史patch窗 H_t (带空间+时间位置嵌入, 交叉注意力CLIP动作token)
      + 动作 a_t (CLIP文本编码)
v̂ = v_θ(z_τ, τ; H_t, a_t)
L = ||v̂ - (z_gt - z_0)||² + λ·L_sparse(背景patch速度→0)
```

**推理：**
```
z_0 ~ N(0,I) → v̂ = v_θ(z_τ,...) → z_1 = z_0 + v̂ (单步Euler)
Ŝ_{t+1} = S_t + f_dec(z_1)
```

Delta参数化（预测残差而非绝对状态）的两个好处：静态场景下零残差是自然的默认解；背景稀疏正则可以直接作用在残差上。

### A.2 [START]token与零运动偏差

一个容易被忽略的细节：时序历史窗在episode开头需要填充。若用重复第一帧填充，flow-matching会学到"历史帧相同→没有运动发生"的虚假关联，在后续真正静止的场景中产生系统性零运动偏差。[START]可学习token把"尚无历史"编码为独立符号，切断了这种虚假关联。这种细节对复现者极其重要。

### A.3 双阈值分支的纠错拓扑

Critic的两个头不仅评分，还驱动**不同来源的纠错**：
- s_tc低（想象轨迹内部不连贯）→ 问题出在世界模型 → 重采样（重新rollout，换个噪声种子）
- s_gp低（想象终态不满足目标）→ 问题出在提案 → VLM反思重提案
- σ̂_k高（时序一致性头不确定性大）→ 世界模型对这段动力学问"我不知道" → 直接丢弃该候选

这种"错误归因→定向补救"的结构比单一的分数阈值更高效：不浪费VLM调用去修复世界模型的问题，也不浪费世界模型采样去修复提案的问题。真机上Verify2Act的VLM调用只有1.13次/episode（RLA-WM 1.84、Diffusion-WM 2.0）就是这个结构的直接收益。

### A.4 real2sim对齐的适用边界

对齐流程：相机帧 → 颜色掩码 → 拟合方块位姿+相机位姿 → 在训练域渲染拟合场景 → 喂给世界模型/Critic。VLM不受影响（直接看真实帧——VLM预训练见过真实图像，域差距由其自身泛化消化）。

三个边界：
1. 只适用"桌面上的块状物"（颜色掩码可拟合）
2. 每帧数秒CPU开销
3. 残差>2.5px的回退路径（直接用真实帧验证）仍保持71% Top-1——对齐是增益项而非依赖项

这个"可选增强+优雅回退"的设计哲学值得所有sim2real工作借鉴。

### A.5 统计解读的谨慎性

60个真机episodes上83.3% vs 61.7%的差异（13个episode）在没有报告置信区间的情况下不宜过度解读。作者用三个冗余证据链加固结论：任务级一致性（6任务全部最优或并列最优）、机制级证据（100%验证率、Top-1排序97.6%）、以及消融级证据（两个架构组件在Nut Assembly上各贡献约28个百分点）。这种"小样本+多证据"的报告方式比单纯的大N更诚实。

## 附录D：三个核心实验的设计解析

### D.1 实验1：真机六任务对照

控制变量设计严格：所有方法共享同一VLM（GPT-4o）、同一提示、同一低层技能库、同一孪生训练数据——唯一变量是验证层。这个设计把"验证层的净贡献"从"技能质量"和"提案质量"中干净地剥离出来。

Bin-cool和Bin-3（多方块清理）是区分度最大的任务（90/60 vs 最高50/30），预条件冲突和序列长度让无验证方法翻车——符合"验证价值随任务复杂度增长"的预期。Stack任务上80%的成功率说明对空间关系（上下叠放）的想象是可靠的。

### D.2 实验2：规划vs执行归因

把失败episode分为规划失败（计划本身不满足目标）和执行失败（计划正确但技能失败）：

- Verify2Act：0%规划失败，16.7%执行失败
- 其他方法：5-7%规划失败，33-47%执行失败

注意所有方法的执行失败都很高（低成本机械臂的技能滑移），Verify2Act的执行失败反而最低（16.7%），原因是更可靠的规划减少了"错误计划消耗技能尝试机会"的连锁损耗。

### D.3 实验3：离线Top-1排序

42个真实场景，离线模拟所有有效计划打标签，让各模型排序。这是验证质量的"纯度测试"——完全剥离执行噪声。结果：

- 对齐后：Verify2Act 97.6%，RLA-WM 71.4%
- 无对齐（真实帧直接验证）：Verify2Act 71.4%，RLA-WM 23.8%（接近随机6%的三倍但不可用）

这条实验线证明V2A-WM学到的是**可迁移的物理规律**而非训练域的记忆——特征空间动力学的泛化性首次被定量展示。

### D.4 实验4（模拟）：CALVIN与Nut Assembly

CALVIN五子任务链（ABCD→D）上SR5 75%为对比方法最高，但作者诚实地把SR5差异标注为"supporting rather than conclusive"（对应几个序列的差别）。Nut Assembly是真正的区分战场：杂乱多物体+语言引导缺失时CEM搜索崩溃（DINO-WM 20%），VLM无验证更惨（17%），架构消融（去交叉注意力30%、去时序窗31% vs 完整58%）证明两个创新组件的价值集中在困难场景。

## 附录H：深度问答——关于本文的五个关键问题

**Q: 为什么不用显式3D重建后做物理仿真验证？**
A: 显式3D+物理引擎的管线需要精确的几何/材质重建，感知成本高且在真实场景脆弱。V2A-WM用DINOv2特征隐式承载几何语义，绕过重建。代价是物理保真度无法保证——对桌面积木足够，对接触丰富操作不够。这是效率与保真的权衡，非优劣之分。

**Q: 潜在rollout会不会积累误差导致长时域验证失效？**
A: 会，但有三层防线：验证时域短（H=3~5步）；时序一致性头逐步检查（误差累积会先表现为不一致）；不确定性阈值σ̂直接丢弃可疑rollout。CALVIN五步链的成功说明5步内误差可控。更长的时域需要分段验证+状态重接地。

**Q: VLM只出3个候选，会不会漏掉正确计划？**
A: 会。这是beam search的固有风险，缓解方式是反思循环（VLM.reflect吸收Critic反馈后重新提案）。但预算耗尽后仍未验证的计划会被执行（论文的诚实设计）——所以最终成功率的下界由VLM提案质量决定，验证层只做上界提升。B的取值是精度-延迟的权衡。

**Q: 数字孪生训练的世界模型为什么能迁移真实场景？**
A: 两个原因：DINOv2特征本身就是真实图像预训练的，孪生渲染（真实纹理方块）与真实帧在特征空间的差距被大幅缩小；real2sim对齐进一步把输入拉回训练域。即使不对齐（71% Top-1），特征的域泛化也撑住了基本盘——这说明特征空间的动力学比像素空间的动力学更域不变。

**Q: 这套验证架构能直接用在具身智能体（VLA）上吗？**
A: 架构上兼容（VLA的action chunk就是候选计划），但本文的低层技能是离散原语，VLA输出连续动作序列，世界模型需要为连续动作条件化重训。相关方向已有CauSyncVLA、WEVO等在做——"VLA+潜在世界模型验证"是2026年底明确的趋势，Verify2Act提供了方法论模板。
