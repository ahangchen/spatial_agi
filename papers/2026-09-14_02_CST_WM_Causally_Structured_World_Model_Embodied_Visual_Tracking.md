## 0. 论文速览

CST-WM 针对具身视觉跟踪（Embodied Visual Tracking, EVT）提出了一个**因果结构化世界模型**。核心诊断非常锋利：通用动作条件世界模型存在一种**任务特定的因果幻觉（causal hallucination）**——模型会把"当前动作"直接写入"目标证据"的潜在更新，利用机器人控制与目标观测之间的强相关性走捷径，生成看起来合理、但语义错误的未来预测。这对依赖未来预测做规划的跟踪/重捕获任务是致命的。

CST-WM 的解法是**在架构层面切断这条因果捷径**：把潜在状态分解为三个分支——

- **目标证据分支 H**（GroundingDINO 置信度 + 归一化目标面积）：**禁止直接注入动作**
- **机器人分支 x**（由动作历史积分的运动学状态）：动作的合法载体
- **观测分支 Z**（冻结 VAE 的视觉潜变量）：由机器人分支和目标证据分支融合更新

配合基于 rollout 的模型预测控制（MPC + CEM），同一个模型同时支持稳定跟随和目标丢失后的重捕获。

**一句话总结**：世界模型不仅要"预测未来"，还要"以正确的因果结构预测未来"——动作只能通过移动机器人、改变下一次观测来间接影响目标证据，绝不能直接改写目标证据。

## 核心问题

### Q1: 核心算法原理

**问题**: 这篇文章的核心算法原理是什么？

**分析**:

#### 1. 核心思想和动机

**任务本质的重定义**：具身视觉跟踪看似简单（跟着移动目标走），实质是一个**预测性决策问题**而非反应式映射：

- 机器人需要在目标被遮挡、出视野、与干扰物混淆时，**在获得可靠目标证据之前**就决定怎么动
- 动作的价值不只在于改变机器人状态，更在于**如何改变未来的目标可见性与表观尺度**
- 反应式跟踪器（RL 主动跟踪、EVT 类离线 RL、VLA 变体）本质短视：目标一消失就失去行动依据

**通用世界模型为什么也不够**：Dreamer 类/NWM 类动作条件世界模型虽然能 rollout 未来，但通用转换函数允许"当前动作 → 目标证据"的直接边。于是模型学到一条捷径：不模拟"我动了 → 视角变了 → 目标重新可见"，而是直接幻想"我做了这个动作 → 目标证据变好了"。这就是**因果幻觉**：

- 未来看起来合理（拟合了动作-观测相关性）
- 但语义错误（动作没有通过物理途径影响目标）
- 后果：规划器无法区分候选动作序列 A（前进+左转）与 B（前进+右转）哪个能恢复目标可见性——两个 rollout 都"看起来行"

**关键洞察（Fig.1）**：EVT 规划**不需要每步恢复目标的完整外部状态**，只需要一个紧凑的"目标证据"表示：目标是否可观测、证据多强、表观尺度是否与合法跟随距离（协议 1–3 米）兼容。既然只需要证据，就可以对证据分支施加因果结构约束。

#### 2. 主要技术方法

**结构化状态构建 S_ℓ = [H_ℓ, Z_ℓ, x_ℓ]**

| 分支 | 构造方式 | 语义 |
|------|---------|------|
| 目标证据 H_ℓ ∈ [0,1]² | H_vis = GroundingDINO 开放词汇检测置信度；H_area = 检测框面积/图像面积 | 目标是否可见 + 表观尺度（跟随距离的定性代理） |
| 视觉潜变量 Z_ℓ | 冻结 VAE 编码器 φ(O_ℓ) | 场景外观信息 |
| 机器人状态 x_ℓ ∈ ℝ³ | 运动学积分 x_ℓ = F(a_{0:ℓ-1})，从动作历史恢复 | 机器人位姿（无需特权状态） |

H_ℓ 刻意做成**观测导出的证据表示**而非完整外部状态估计——推断时不需要目标真值位置，保持部署可行性。

**核心约束：因果非泄漏（Eq.2）**

```
p(H_{ℓ+1} | H_ℓ, Z_ℓ, x_ℓ, a_ℓ) = p(H_{ℓ+1} | H_ℓ, Z_ℓ, x_ℓ)
∂Ĥ_{ℓ+1} / ∂a_ℓ = 0
```

目标证据分支的更新**读不到当前动作**。作者明确说明这是对规划表征的结构性要求，而非强物理断言——它保证 H 始终绑定于可观测性与表观尺度，不吸收本应由机器人运动中介的控制信息。

**因子化转换（Eq.3）**

```
p(H,x,Z | H,Z,x,a) = p(H_{ℓ+1}|H_ℓ,Z_ℓ,x_ℓ)     ← 无动作
                   × p(x_{ℓ+1}|x_ℓ,a_ℓ)          ← 动作唯一入口
                   × p(Z_{ℓ+1}|Z_ℓ,H_{ℓ+1},x_{ℓ+1})  ← 间接接收动作
```

动作被排除出目标证据分支的直接更新，但保留通过机器人分支影响未来观测的合法通路。

**单层因果架构（固定去噪顺序）**

```
H_{ℓ+1} = f_H(H_ℓ, Z_ℓ, x_ℓ)          # 第一步：不读 a_ℓ
x_{ℓ+1} = f_x(x_ℓ, a_ℓ)               # 第二步：吸收动作
R_{ℓ+1} = [x_{ℓ+1}, W_a(a_ℓ)]         # R: 动作信息进入观测分支的唯一载体
Z_{ℓ+1} = g_θ(Z_ℓ; R_{ℓ+1}, H_{ℓ+1})  # 第三步：注意力+FFN 融合
```

计算图：a_ℓ → x_{ℓ+1} → Z_{ℓ+1}，H_ℓ → H_{ℓ+1} → Z_{ℓ+1}，**不存在 a_ℓ → H_{ℓ+1} 的边**。∂Ĥ/∂a = 0 的零雅可比性质本身用作架构约束生效的诊断指标。

**扩散训练（DDPM）**

- 训练数据：EVT-Bench 和 Habitat 3.0 的转换三元组 (O_ℓ, a_ℓ, O_{ℓ+1})
- 对下一结构化状态 S_{ℓ+1} 加高斯噪声：S̃_u = √γ̄_u · S_{ℓ+1} + √(1-γ̄_u) · ε
- 单一去噪目标训练（三分支共享一个扩散过程，因果掩码决定架构内允许的依赖）：

```
L_diff = E[ λ(u) · ||ε - ε_Θ(S̃_u; S_ℓ, a_ℓ)||² ]
```

- 辅助距离头：在 H 分支上挂轻量预测头 g_dist，用**仅模拟器可得**的相对距离 d_{ℓ+1} 导出二值标签 y_dist = 𝟙(d⁻ ≤ d_{ℓ+1} ≤ d⁺) 监督，训练后推断不需要特权几何监督——这是"训练用特权、推断无特权"的干净设计

#### 3. 算法流程和关键步骤

```
训练:
  1. 从 EVT-Bench / Habitat 3.0 收集 (O_ℓ, a_ℓ, O_{ℓ+1}) 转换
  2. 提取 H_ℓ (GroundingDINO), Z_ℓ (VAE), x_ℓ (运动学积分)
  3. DDPM 去噪训练，因果掩码固定依赖结构
  4. g_dist 辅助头用模拟器距离标签监督

推断（模型预测控制，滚动时域）:
  5. 从当前 S_0 出发，CEM 采样 N 条候选动作序列
  6. 世界模型 rollout 每条序列的未来结构化状态
  7. 规划目标打分: 跟随质量 + 距离区间 + 安全性
  8. CEM 更新采样分布，M 轮迭代
  9. 执行最优 top-K 序列的第一个动作，回到 5
```

稳定跟随与丢失重捕获在**同一个 rollout 打分框架**内自然涌现：目标可见时，保持 H 强且面积适中的动作序列得分高；目标丢失时，能最大化未来 H 恢复概率的搜索动作得分高——不需要为重捕获单独设计模块。

#### 4. 输入输出

- **输入**：自我中心 RGB 观测 O_ℓ；动作历史
- **输出**：
  - 世界模型层：未来结构化状态 (H, x, Z) 的多步 rollout
  - 控制层：下一动作 a_ℓ = (v_ℓ, ω_ℓ)（线速度 + 角速度）
- **推断时不使用**：目标真实位置等特权状态

### Q2: 与Spatial AGI的关系

**问题**: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**分析**:

#### 1. 如何理解和表示空间

CST-WM 的空间观是**以自我为中心的动态空间**：空间不是静态地图，而是"我的运动如何改变我能看到什么"的函数。它把空间压缩为任务最小充分统计量：

- 可观测性（H_vis：目标在不在视野里、检测器多确信）
- 表观尺度（H_area：目标占画面多大 → 距离的定性代理）
- 机器人运动学状态（x：我在哪、朝哪）

这与 GraFT（同日分析的另一篇）形成鲜明互补：GraFT 的空间是世界中心的符号地图（allocentric），CST-WM 的空间是自我中心的动态证据流（egocentric）。一个 Spatial AGI 同时需要这两种空间表示，以及它们之间的转换机制。

#### 2. 如何处理空间关系

- **机器人-目标空间关系**被分解为"证据"而非"坐标"：不估计目标 3D 位置，而维护"可观测 + 尺度合规"的布尔/连续证据
- **时间维度的空间关系**：动作 → 自我运动 → 视角变化 → 未来可见性，这条因果链被显式编码进架构
- **遮挡与重捕获**：空间关系推理被推向多步 rollout——在看不见目标的情况下，推理"往哪走能重新看见"，这正是空间想象力（mental imagery）的具身版本

#### 3. 对Spatial AGI的启发

这篇论文对 Spatial AGI 的价值主要在方法论层面，而且是**警世钟式**的：

1. **因果幻觉是空间世界模型的系统性风险**：任何动作条件预测器都可能学到相关性捷径。Spatial AGI 的世界模型如果不做因果结构审查，规划 rollout 可能"看起来对但语义错"。CST-WM 给出了通用处方：**审查"什么变量允许直接影响什么变量"，把物理因果链写进架构**。这个思路可以推广：
   - 静态场景：环境布局不应被智能体动作直接改写
   - 物体操作：物体状态只能通过接触交互改变
   - 其他智能体：他人行为不受我方动作直接影响（除非通信）

2. **结构先验 > 数据量（在因果正确性意义上）**：同样的数据，加上正确的因果掩码，规划质量显著提升（planning-value consistency 提升、action leakage 大幅下降）。对 Spatial AGI 的启示：与其无限堆数据，不如把物理世界的因果图作为归纳偏置注入模型

3. **任务最小充分表示的智慧**：不追求恢复完整外部状态（目标 3D 轨迹），只维护规划所需的证据。Spatial AGI 的空间记忆不必事事精确重建，应该按任务需求分层——这与 GaussMemory（任务驱动 3DGS 场景记忆）的思想呼应

4. **世界模型评估的新维度**：论文的离线诊断（rollout fidelity、planning-value consistency、action leakage）为"世界模型质量"提供了超越像素保真度的度量。Spatial AGI 需要这样的评估体系：想象出的未来不仅要好看，还要**因果可用**

#### 4. 可以应用的Spatial AGI场景

- **服务/陪伴机器人**：跟随主人穿越遮挡环境，丢失后智能搜索重捕获
- **自动驾驶**：对周围交通参与者的预测性跟踪与让行规划（类似因果约束：我的动作不直接改变他车意图）
- **搜索救援**：目标失踪后的主动视野规划
- **多智能体追踪/围捕**：因果分解防止把队友动作与目标状态混淆
- **视频世界模型的可控性改造**：交互式世界模型（如 Matrix-Game 类）中防止"动作直接影响不可及变量"
- **具身 VLA 的世界模型组件**：VLA 内嵌世界模型做 rollout 验证时，因果结构约束可直接移植

### Q3: 创新点和局限性

**问题**: 基于前面的分析，这个方法的主要创新点和局限性是什么？

**分析**:

#### 1. 主要创新点

1. **问题表述创新——"因果幻觉"概念的提出**：这是全文最锋利的贡献。它把"世界模型 rollout 质量差"细化为一个可命名、可诊断、可修复的任务特定失败模式：动作-证据相关性捷径。命名即诊断，诊断即疗法（切边）

2. **架构级因果约束**：不靠正则化或数据增广"希望"模型别学捷径，而是直接在计算图上删掉非法边，∂Ĥ/∂a = 0 由构造保证。零雅可比性质还能作为运行时诊断——约束是否生效可机器验证

3. **三分支最小化状态分解**：目标证据（2 维！）/机器人/观测的分解极其克制。H 只有 2 个标量，却足以支撑跟随与重捕获两种模式的规划——"用最小的充分表示承载因果结构"是教科书级的表征设计

4. **跟随与重捕获的统一规划**：无需为"目标丢失"设计专门的状态机或重捕获模块，MPC rollout 在两种模式下自然切换，简化系统复杂度

5. **评估方法论**：action leakage 诊断（动作对证据分支的泄漏度量）+ planning-value consistency（模型排名与模拟器排名一致性）为世界模型内部质量提供了可复用的度量

#### 2. 主要局限性

1. **H 的表达能力上限**：2 维证据（置信度+面积）在干扰物混淆（外观相似目标）、多目标、非对称遮挡下会失真。GroundingDINO 置信度本身是黑盒分数，其校准质量直接约束 H 的语义可靠性——证据表示继承了检测器的所有偏差

2. **因果约束的近似性**：作者自己声明这是"结构要求而非强物理断言"。现实中目标可能对机器人动作有反应（被追的人会跑！），此时动作与目标证据存在真实因果联系，切边在对抗性目标下是错误模型。论文假设目标运动与机器人动作条件独立，社交跟踪场景不完全成立

3. **单目标假设**：三分支结构没有为多目标/目标切换留接口，扩展到多证据源需要重新设计分支拓扑

4. **扩散 rollout 的成本**：MPC + CEM 需要在每个决策步做 N×M 次（多候选 × 多步）rollout，扩散模型的迭代去噪使实时性存疑（论文未给出控制频率的讨论）

5. **实验范围**：以室内 Habitat 类环境为主；跨数据集迁移有测但真实机器人部署、感知噪声（真实 GroundingDINO 误检率）、动力学误差等 sim-to-real 缺口未覆盖。作者对"改进跟踪与规划"vs"完整恢复目标外部状态"的谨慎声明也说明证据表示的边界

6. **无基线因果结构对比的粒度**：与 NWM 类通用世界模型对比存在，但没有系统消融"切哪条边"的贡献（如只切动作但保留 x 对 H 的其他通路变体）

#### 3. 与其他相关工作的对比

| 维度 | 反应式跟踪 (RL/EVT/VLA) | 通用世界模型 (Dreamer/NWM) | **CST-WM** |
|------|------|------|------|
| 决策范式 | 当前观测→动作映射 | rollout 未来→规划 | rollout 未来→规划 |
| 多步前瞻 | 弱（短视） | 有 | 有 |
| 丢失重捕获 | 无依据 | 语义可能错误 | 统一框架内正确语义 |
| 动作→目标证据 | - | **直接边（捷径）** | **架构切断** |
| 状态表示 | 隐式 | 单一潜空间 | 三分支显式分解 |
| 目标状态需求 | 部分 | - | 仅观测导出证据，无特权 |

与 Navigation World Models（NWM）的关系最直接：NWM 证明扩散世界模型可支撑自我中心导航规划；CST-WM 指出其转换结构对 EVT 任务存在因果幻觉，并给出结构修复。是典型的"批判性继承"。

## 核心技术发现

1. **命名了"因果幻觉"失败模式**：动作条件世界模型通过直接动作→证据边生成语义错误的"合理"未来，无法区分候选动作序列——世界模型规划的隐性地雷
2. **架构切边即可修复**：三分支分解 + 固定去噪顺序 + 严格掩码，∂Ĥ/∂a ≡ 0 由构造保证，且零雅可比可作为运行时诊断
3. **2 维目标证据（检测置信度 + 归一化面积）足以驱动跟随与重捕获规划**，无需特权目标状态
4. 因果结构修复同时改善外部指标（跟随质量/距离控制/安全/重捕获）与内部指标（rollout 保真度、planning-value 一致性、泄漏下降）
5. 跟随与丢失重捕获可统一在单一 MPC 框架，无需专门模块

## 与Spatial AGI的关系

### 直接贡献
为 Spatial AGI 的世界模型组件提供了因果结构设计的参考范式：先画"什么允许影响什么"的因果图，再把非法边从架构中物理删除。这把世界模型设计从"端到端学动态"提升为"因果正确的动态学习"。

### 技术启发
- 空间预测必须审查动作通路与物理因果链的一致性
- 任务最小充分表示 + 因果约束是高性价比组合
- 世界模型评估要包含语义/因果维度而非仅保真度

### 应用场景
跟随机器人、自动驾驶预测、搜救视野规划、交互式世界模型的可控性保障、VLA 内嵌世界模型。

## 个人思考

### 最令人兴奋的发现

**"未来预测本身不够，预测结构必须对齐目标证据进入规划的方式"**——这句论文里的总结句值得每个做世界模型的人贴在屏幕上。2025-2026 年世界模型大爆发（视频世界模型、交互世界模型、驾驶世界模型），大家卷的是 rollout 保真度和时长，CST-WM 冷静地指出：**一个保真度很高的世界模型仍可能因为因果结构错误而在规划中失效**。图 1 那个例子令人难忘：通用世界模型的 rollout 无法区分"左转"和"右转"哪个能找回目标——两个未来都"看起来合理"。这不是模型容量问题，是结构问题。

另一个精彩之处是**防御的优雅**：没有对抗训练、没有正则项、没有数据清洗，就是把一条边从计算图里删掉。深度学习时代我们太习惯"用更多数据/更大的 loss 项解决问题"，这篇论文提醒我们：当你确切知道正确的结构时，直接编码它。

### 潜在局限

我最关注的两个深层问题：

1. **切边的前提是因果图已知且正确**。CST-WM 的三分支因果图由人类先验给出，这对跟踪任务是清晰的；但 Spatial AGI 的通用场景里，因果图本身是开放问题（环境会因我而变吗？其他智能体呢？）。这篇论文解决"已知因果图如何强制执行"，没解决"如何发现因果图"。后者可能需要因果发现（causal discovery）与世界模型的结合

2. **对抗性目标暴露模型边界**：跟踪人类时，被跟踪者会对跟踪者动作做出反应（玩游戏、躲藏），动作与目标状态的真实因果耦合会让切边模型系统性失准。社交跟踪可能需要允许"间接博弈通道"的更精细因果模型

### 与昨日研究的关联

- 与 **NavArena**（3DGS 自动构造导航基准）同属具身导航评测-方法生态，但视角互补：NavArena 解决"在哪评测"，CST-WM 解决"如何规划"
- 与今天 **GraFT** 构成绝妙对偶：GraFT 处理**静态空间**（房间布局），用世界中心符号图 + 确定性工具；CST-WM 处理**动态空间**（目标-机器人相对运动），用自我中心证据流 + 因果约束。Spatial AGI 的空间记忆系统需要同时容纳这两种模式，以及 allocentric↔egocentric 的双向转换（有趣的呼应：GraFT 的 BEV 渲染正是在做这个转换）
- 与近期分析的 **NavThinker**（动作条件世界模型社会导航）、**EVA**（视频世界模型与机器人动作对齐）共同指向一个趋势：世界模型正在从"生成式卖点"转向"规划基础设施"，而基础设施需要正确性保证——CST-WM 的因果审查是正确性保证的第一课

## 总结

### 核心发现总结
CST-WM 诊断并修复了具身视觉跟踪世界模型中的因果幻觉问题：通过把状态分解为目标证据/机器人/观测三分支并在架构上切断动作对目标证据分支的直接注入，让 rollout 未来获得正确的因果语义，从而用一个统一 MPC 框架同时实现稳定跟随与目标重捕获，在外部跟踪指标与内部 rollout 质量上全面超越反应式和通用世界模型基线。

### 对Spatial AGI的意义
空间世界模型的下一步竞争维度是**因果正确性**而非保真度。Spatial AGI 需要为其世界模型组件建立"因果图审查"流程：明确什么状态变量允许被动作直接影响，把物理因果链写进架构。任务最小充分证据表示、无特权推断设计、泄漏诊断指标都是可直接复用的工程资产。开放缺口：因果图的自动发现、对抗性/社交目标的因果建模、多目标扩展。

## 附录A: 深度延伸分析

### A1. 为什么反应式跟踪必然短视

反应式策略 π(a|O_{ℓ-k:ℓ}) 的信息带宽被当前/近期观测锁死。考虑目标刚被高柜遮挡的瞬间：

- 观测流中目标证据 H 突然跌到 0
- 反应式策略面临分布外输入：训练数据里"证据消失"多对应"跟丢/终止"
- 它无法表达"向左绕行 3 步后目标大概率重新可见"这种**跨时间步的空间假设**

CST-WM 的 rollout 把这个假设变成可计算的量：向左绕行的序列在世界模型里 rollout 出 H 在未来几步回升 → 规划目标得分高。**短视不是策略网络的问题，是缺少"想象未来的机制"**。

### A2. 因果幻觉的信息论解读

动作与目标观测的相关性来源可以分解为：

```
I(a_ℓ ; H_{ℓ+1}) = I_mediated + I_leak
```

- I_mediated：动作 → 机器人位姿 → 视角 → 观测 → 证据的合法信息通路
- I_leak：训练分布中的伪相关（如数据采集策略让"前进"动作总伴随目标靠近）

通用世界模型最小化预测误差时会连 I_leak 一起吸收（因为它是训练分布内的有效预测线索）。CST-WM 用架构把 I_leak 的通路物理堵死——模型只能通过 I_mediated 解释证据变化。当二者冲突时（新场景中 I_leak 不再成立），因果结构的模型泛化，捷径模型崩溃。**这是"因果模型在分布偏移下更稳健"这一经典论断在世界模型上的实例化**。

### A3. 三分支的信息流审计

| 分支 | 读 | 写 | 语义守护 |
|------|----|----|---------|
| H (证据) | H, Z, x | → Z | 只反映可观测性与尺度，不受控制污染 |
| x (机器人) | x, a | → Z, 规划 | 动作的唯一直接消费者 |
| Z (观测) | Z, R', H' | → 下一层 | 场景外观，接受双路输入 |

审计要点：任何动作影响 H 的路径都必须长度 ≥ 2（先经 x 或 Z）。这保证"如果我换个动作，证据的变化只能通过'我会看到不同东西'来解释"。

### A4. MPC/CEM 规划目标的结构推断

论文的规划目标综合三类项（从任务协议反推）：

1. **跟随质量项**：H_vis 高 + H_area 落在合法区间 → 鼓励保持可见且距离合适
2. **距离区间项**：g_dist 头输出的 in-range 概率 → 软约束 1–3m
3. **安全项**：Z 分支 rollout 中的碰撞/风险线索 → 避障

CEM 在 N 条候选序列上迭代 M 轮，每轮用世界模型（而非模拟器）打分——因此"模型排名与模拟器排名的一致性"（planning-value consistency）成为关键内部指标：若世界模型把坏序列排前面，MPC 会系统性地选择坏动作。

### A5. 与模型预测控制经典理论的对接

CST-WM 本质是"学习动力学模型 + MPC"范式，与传统 MPC 的区别：

| 传统 MPC | CST-WM |
|---------|--------|
| 已知/辨识的物理动力学 | 扩散世界模型学到的潜空间动力学 |
| 显式状态（位姿/速度） | 结构化潜状态 [H,Z,x] |
| 代价函数手工设计 | 代价设计 + 学习的 g_dist 头 |
| 信赖域：模型局部有效 | 信赖域：rollout 保真度（被诊断指标监控） |

其贡献不在 MPC 本身，而在**学到的动力学模型第一次具有可声明的因果结构**——这让 MPC 的"model"不再黑盒。

### A6. 失败模式预测（论文未讨论但值得预研）

1. **检测器漂移**：光照变化使 GroundingDINO 置信度系统性偏移 → H_vis 语义漂移 → 规划目标失真。缓解：证据分支加时序滤波/校准
2. **相似干扰物**：H 将干扰物误锁为目标 → rollout "自信地跟错人"。需要 re-identification 信号进入证据表示
3. **动力学模型误差累积**：长 horizon rollout 中扩散模型漂移，CEM 基于漂移的未来选动作。缓解：滚动时域短 + 定期用真实观测重置
4. **目标反博弈**：见正文个人思考

## 附录B: 可迁移的设计模式清单

CST-WM 的处方可以提炼为可复用模式，适用于任何"动作条件预测 + 规划"的 Spatial AGI 子系统：

**模式1：因果边白名单**
画出允许的动作影响图（DAG），架构中只实现白名单内的边。例：环境静态结构不允许被动作直接改写。

**模式2：证据/状态分离**
把"我能控制什么"（机器人分支）与"我只能观察什么"（证据分支）分箱。混淆这两箱是因果幻觉的根源。

**模式3：最小充分证据**
问"规划真正需要什么信息"，只保留那么多。2 维证据驱动跟踪任务的案例证明：表示小 → 幻觉面小 → 诊断容易。

**模式4：约束即诊断**
每个结构性约束（如 ∂H/∂a=0）都配一个运行时检查量。约束若被后续改动意外破坏，诊断指标会报警。

**模式5：内部一致性评测**
除端到端任务指标外，评测"模型内部判断与真值判断的一致性"（planning-value consistency），直接度量 rollout 的规划可用性。

这五个模式共同构成一份"空间世界模型因果工程 checklist"。

## 附录E: 评测协议要点

- **标准跟踪**：从任意初始位置出发，定位移动目标并维持 1–3 m 面向距离
- **目标丢失恢复（recovery protocol）**：受控制造目标丢失（遮挡/出视野），度量重捕获成功率与恢复时间
- **跨数据集迁移**：在一套数据训练、另一套场景测试，检验因果结构带来的泛化
- **离线结构诊断**：
  - 多步 rollout 保真度（想象 vs 模拟器真值）
  - planning-value consistency（模型排名 vs 模拟器排名）
  - direct action leakage（∂Ĥ/∂a 数值诊断）
- **对照基线**：反应式策略（RL 主动跟踪 / EVT / VLA 变体）与通用世界模型（Dreamer 类 / NWM 类）
