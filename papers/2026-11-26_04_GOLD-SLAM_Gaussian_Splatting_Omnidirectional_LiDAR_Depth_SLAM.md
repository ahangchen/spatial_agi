# GOLD-SLAM: Gaussian-splatting Omnidirectional LiDAR-Depth SLAM

**发表日期**: 2026-11-24
**arXiv链接**: https://arxiv.org/abs/2611.32335
**PDF链接**: https://arxiv.org/pdf/2611.32335
**HTML版本**: https://arxiv.org/html/2611.32335v1
**作者**: Weicong Zhang, Yuan Huang, Yu Zheng, Chenxiao Lin, Yingying Li, Lilong Fan, Liangdong Zhuang, Yufan Chen, Ruiping Liu, Junwei Zheng, Jiaming Zhang
**机构**: Hunan University, Tsinghua University, Karlsruhe Institute of Technology, University of Oxford

---

## 一句话总结

GOLD-SLAM 是首个融合 LiDAR+IMU+全景相机的球域 3DGS SLAM 系统：统一球面几何做跟踪与建图，盲区视觉约束 + Patch Brightness Uncertainty 提升位姿估计，LiDAR 实测深度 + 全景预测深度联合初始化并配合 DAEP（深度感知地图扩展与剪枝）改善增量重建——相对全景基线 PSNR +5.56~9.10 dB、Depth-L1 降低 71.9~83.9%，并可在 Jetson Orin NX 上在线运行。

## 核心问题

### Q1: 核心算法原理

#### 1. 核心思想和动机

- **动机**：地面/空中机器人需要可靠定位、稠密几何与照片级渲染，且传感器预算有限。透视相机 FoV 窄，在重复纹理、稀疏纹理和快速运动下位姿估计脆弱；全景相机（360°×180° 球面 FoV）大幅扩展覆盖，但 ERP 投影非线性畸变强。ODGS-SLAM 已把增量高斯 SLAM 扩展到 ERP，但室外尺度漂移严重——需要 LiDAR 几何约束。
- **三大技术挑战**：
  1. ERP 非均匀采样与极区拉伸；
  2. LiDAR-相机 FoV 失配造成大盲区（球面立体角加权后比例可观），全景覆盖暴露更多无深度支撑区域，高斯初始化困难；
  3. 增量建图时已有高斯的累积不透明度阻碍新观测表面的 opacity-only 插入。
- **基准空白**：现有 LiDAR-视觉基准面向地面机器人或手持/背包采集，UAV 运动长期欠代表。

#### 2. 主要技术方法

**（a）统一球面几何**
- 定义径向距离 R、经度 φ=atan2(x,z)、纬度 λ=atan2(y,ρ) 的球面参数化；ERP 投影/反投影闭式公式；投影雅可比 J_π 用于全景位姿更新与高斯协方差投影（Σ_img = J_π Σ^C J_πᵀ + εI，低通项防止过小投影）。
- 跟踪与建图共享同一球面模型。

**（b）全景 LiDAR-惯性-视觉里程计**（借鉴 FAST-LIVO2 误差状态滤波框架）
- LiDAR 前端：体素平面地图，0.5/1/2 m 基础体素在线选择。
- **盲区视觉约束**：在 LiDAR 盲区提取角点、金字塔光流跟踪、前后向一致性剔除误匹配、足够视差时从历史 bearing 射线三角化；把 bearing 误差投到切平面得残差 r。
- **不确定性加权融合**：由视差与历史位姿不确定性估计三角点协方差，传播得残差协方差；视觉信息矩阵 Λ_V 通过 η=min(1.4, γ/λ_max(LᵀΛ_V L)) 缩放，限制视觉相对信息量，防止视觉约束主导滤波。
- **Patch Brightness Uncertainty（PBU）**：LiDAR 支撑区的直接视觉更新中，块级亮度变化会被误认为运动。用仿射亮度模型把变化建模为共享的增益 α 与偏置 b 扰动：C_photo = σ_n²I + σ_α² i_ref i_refᵀ + σ_b² 11ᵀ，用该协方差白化残差与雅可比。

**（c）高斯建图**
- 球面渲染：按径向深度排序、前向-后向 alpha 合成，累积不透明度 A 与渲染径向深度 D̂ 供 DAEP 使用。
- **初始化**：LiDAR 实测深度 + Depth Any Panoramas (DAP) 预测的全景径向深度联合初始化（盲区用预测深度）。
- 优化：光度损失 + LiDAR 深度损失。
- **DAEP（Depth-Aware Map Extension and Pruning）**三件套：
  - 深度感知插入：在新观测表面处依据深度冲突/覆盖插入新高斯，绕过累积不透明度的阻挡；
  - 深度引导自适应更新：按深度置信度调整更新强度；
  - 深度冲突剪枝：删除与 LiDAR 深度矛盾的高斯，抑制浮子。

**（d）WHOLE 数据集**
- 定制 UAV 平台采集 LiDAR + IMU + 全景图像，覆盖五类场景：Weak-geometry（弱几何）、High-dynamic（高动态）、Omnidirectional（全向）、Low-light（低光）、Easy。

#### 3. 算法流程和关键步骤

```
1. UAV 采集 LiDAR/IMU/全景
2. LiDAR scan-to-map + IMU 传播构建误差状态滤波骨架
3. 盲区角点跟踪+三角化 → 切平面 bearing 残差（协方差加权，η 限幅）
4. LiDAR 区直接视觉更新 + PBU 白化（抗亮度变化）
5. 关键帧：LiDAR 深度 + DAP 预测深度联合初始化高斯
6. 球面 alpha 合成渲染 → 光度+深度损失优化
7. DAEP：深度感知插入 / 自适应更新 / 冲突剪枝
8. 输出：位姿轨迹 + 球面 3DGS 地图（可实时全景渲染）
```

#### 4. 输入输出

- 输入：全景图像流（ERP）、LiDAR 点云、IMU。
- 输出：6DoF 轨迹 + 球面域 3DGS 地图（全景新视角渲染 + 稠密深度）。
- 部署：Jetson Orin NX 16GB 嵌入式配置可在线运行（以重建质量为代价）。

### Q2: 与 Spatial AGI 的关系

#### 1. 如何理解和表示空间

- 空间表示 = 球面域 3DGS：把"机器人第一视角的全方位感知"直接物化为可渲染的空间地图，视觉覆盖与地图覆盖同构（都是 360°），消除了透视 SLAM 的"看到哪建到哪"的碎片化。
- 多模态深度融合体现"空间 = 几何(LiDAR) + 惯性(IMU) + 外观(全景) 的联合概率场"：每条信息都有显式不确定性模型（三角点协方差、bearing 噪声、PBU 亮度协方差），信息按可信度加权融合——空间智能需要的不只是表征，还有表征的置信度。

#### 2. 如何处理空间关系

- 盲区问题的本质是"空间覆盖不均"：系统用视觉三角化补几何盲区、用预测深度补初始化盲区、用 η 限幅平衡多源信息的相对话语权——这是资源受限下空间关系推理的工程化样板。
- DAEP 解决的是时间维度的空间关系：新观测表面与已有地图的空间冲突检测与消解（插入 vs 剪枝）。

#### 3. 对 Spatial AGI 的启发

- **全景作为空间智能的输入形态**：360° 感知消除了主动转头/转身的决策负担，对 UAV 与机器人可能是更自然的"空间接口"；后续 Spatial AGI 模型值得更多在 ERP/球面 token 上预训练。
- **在线嵌入式 3DGS SLAM**（Orin NX 16GB）证明空间地图构建正在走向端侧实时——这是具身空间智能闭环（感知→建图→规划）的硬件前提。
- WHOLE 数据集的降级场景设计（弱几何/高动态/低光）直接对应空间鲁棒性的核心考题，可反哺空间基础模型的训练数据。

#### 4. 可以应用的 Spatial AGI 场景

- UAV 巡检/测绘/应急响应的全景空间地图。
- 机器人导航的实时 3DGS 世界模型底座（为下游 VLM/world model 提供可渲染空间记忆）。
- 低光/高动态等恶劣条件下的空间感知（搜救、隧道、夜间）。
- 与 Lost on Campus 类数字孪生互补：一个离线精重建，一个在线增量建。

### Q3: 创新点和局限性

#### 1. 主要创新点

- **首个 LiDAR-IMU-全景三模态球域 3DGS SLAM**：统一球面几何贯穿跟踪与建图。
- **盲区视觉约束 + η 信息限幅**：解决全景-LiDAR FoV 失配的定位问题，显式控制视觉信息相对权重。
- **PBU 亮度不确定性建模**：仿射亮度协方差白化，直接面向低光/光照变化场景的鲁棒定位。
- **DAEP**：深度感知的插入/更新/剪枝三联机制，解决增量建图的新表面覆盖不足与浮子问题。
- **WHOLE 数据集**：首个 UAV 全景 LiDAR 数据集，五类场景含降级条件。

#### 2. 主要局限性

- **嵌入式配置质量代价**：在线运行以重建质量为代价，尚未实现"嵌入式 + 高质量"兼得。
- **ERP 球面近似的固有误差**：局部切平面近似与极区畸变仍影响大纬度角区域精度。
- **依赖 LiDAR**：纯视觉或低成本平台（消费级无人机）不适用；DAP 预测深度在盲区的可靠性依赖训练分布。
- **动态物体**：High-dynamic 场景虽在数据集中，但方法本身无显式动态物体处理。

#### 3. 与相关工作的对比

- vs **ODGS-SLAM**（纯视觉全景 3DGS SLAM）：GOLD-SLAM 用 LiDAR 消除室外尺度漂移。
- vs **Gaussian-LIC2 / GS-LIVM / LIV-GaussMap**（透视多模态）：GOLD-SLAM 全景覆盖 + 球面渲染，PSNR/Depth-L1 大幅领先全景基线；比透视系统覆盖广。
- vs **MonoGS/Photo-SLAM/SplaTAM/GS-SLAM**：单目/RGB-D 透视，无 LiDAR 融合。
- **优势**：覆盖、几何精度、鲁棒降级场景、嵌入式可行性。**劣势**：传感器成本、极区畸变、动态处理。

## 核心技术发现

1. LiDAR-相机 FoV 失配在全景下被放大为显著盲区，必须用"盲区视觉三角化 + 预测深度初始化"双补丁。
2. PBU 显示：直接法视觉里程计的主要失败模式之一是块级亮度变化被误认为运动，显式协方差建模即可大幅缓解。
3. DAEP 的深度冲突剪枝同时压制浮子并改善新表面重建——深度真值是增量 3DGS 地图的最佳"质检员"。
4. 相对全景基线 PSNR +5.56~9.10 dB、Depth-L1 −71.9~83.9%；Jetson Orin NX 在线可行。

## 个人思考

### 最令人兴奋的发现

- PBU 的洞察很妙：把"光照变化"显式建模为增益/偏置扰动的协方差结构而不是靠鲁棒核硬抗，是经典的统计建模胜过深度学习蛮力的例子。
- 嵌入式在线 3DGS SLAM（16GB Orin NX）意味着"边走边建可渲染空间记忆"已经是现实——具身智能体可以带着自己的 3DGS 世界模型行动。

### 潜在局限

- 系统复杂度高、强依赖 LiDAR，难以普及到消费级平台；预测深度盲区初始化在分布外场景可能引入隐性错误表面。
- 动态物体仍是隐患，高动态场景的表现细节值得关注。

### 与昨日研究的关联

- 昨日 ArgsWorld 研究生成式 3DGS，今天 GOLD-SLAM 研究增量式 3DGS 地图——"重建的 3DGS"与"生成的 3DGS"正在合流为同一空间表示生态。
- 与今日论文1（Lost on Campus）互补：离线精孪生 vs 在线增量建图，共同覆盖空间智能的"地图生命周期"。
- 与前日 Pocket-SLAM（内存高效 3DGS-SLAM）同属"嵌入式 3DGS SLAM"浪潮，AnyPrune（今日论文3）的剪枝恰好可作为其地图压缩件——三条论文拼出一个完整端侧空间地图栈。

## 总结

### 核心发现总结
GOLD-SLAM 用统一球面几何融合 LiDAR/IMU/全景，配合盲区视觉约束、PBU 与 DAEP，实现高保真全景 3DGS SLAM，大幅超越全景基线并可在嵌入式平台在线运行。

### 对 Spatial AGI 的意义
它把"可实时渲染的空间记忆"推进到全景、度量、端侧三个维度，为具身空间智能提供了感知-建图层的系统蓝本，WHOLE 数据集亦将成为空间鲁棒性研究的重要资源。
