## 论文摘要

World Action Models (WAMs) 通过联合建模动作和未来观测来改进机器人策略学习。然而，仅以任务提示和观测上下文为条件来预测未来，可能会捕获通用任务进展而非特定动作的后果。本文提出 **SelfWAM**，一种基于模态专用Mixture-of-Transformers (MoT) 架构的统一自接地WAM。

SelfWAM联合预测动作、动作条件化的未来RGB帧和机器人自掩码（self-mask），从而将未来预测建立在机器人可见身体及其动作诱导运动的基础上。在训练期间，SelfWAM允许未来视觉查询关注已执行动作的干净副本，将视频分支转变为动作特定的后果模型，同时保持快速的仅动作推理路径不变。实验表明，SelfWAM在RoboTwin 2.0和真实世界操作任务上产生了更具动作敏感性的未来预测，并提升了策略性能。

## Q1: 核心算法原理

### 1. 核心思想和动机

**核心问题**: 现有WAM（如FastWAM）的未来视频预测不以动作为条件，因此无法区分不同动作的视觉后果。

**动机分析**:
- WAM = 动作预测 + 未来视觉建模
- FastWAM证明了未来视频预测只需作为训练目标，推理时不需要生成视频
- 但FastWAM的未来预测仅以当前观测为条件，不包含执行动作信息
- 这意味着视频分支学到的是"通用任务进展"而非"这个特定动作导致了什么变化"
- 需要让未来预测**动作敏感**

**核心思路**: 
1. **Clean-action conditioning**: 将已执行动作的干净副本暴露给未来视觉查询
2. **Robot self-mask prediction**: 预测机器人自掩码，聚焦于动作诱导的运动

### 2. 主要技术方法

#### (a) 模态专用Mixture-of-Transformers (MoT) 架构

双流架构：
- **视频流**: 预训练视频扩散骨干，处理当前观测 + 噪声未来视频latent
- **动作流**: 轻量级动作专家（action expert），处理噪声未来动作token
- 通过**混合注意力（mixed attention）** 控制不同token组之间的信息交换

#### (b) Clean-Action Conditioning

信息流设计（关键创新）:
```
噪声未来动作查询 Q_Ã → {O, Ã}           // 标准去噪
未来视觉查询 Q_Ṽ → {O, Ṽ, A}            // 新增：可访问干净动作！
干净动作查询 Q_A → {O, A}                 // 仅条件角色
```

- 创建动作的第二个副本（t=0时间步，未损坏）
- 仅暴露给未来视觉查询，不暴露给噪声动作查询（防止目标泄漏）
- 推理时移除clean-action路径，保持快速推理

#### (c) 机器人自掩码预测

- 使用同一视频骨干预测两种未来目标：
  - **RGB视频**: 标准未来帧预测
  - **自掩码视频**: 机器人本体分割掩码序列
- 自掩码移除外观细节，聚焦于动作诱导的机器人运动
- 自掩码的时间演化与条件动作紧密耦合

#### (d) 训练目标

```
L_total = L_act + L_rgb/mask
L_rgb/mask = L_rgb + L_mask
```
- L_act: 动作去噪损失
- L_rgb: RGB视频去噪损失  
- L_mask: 自掩码视频去噪损失

### 3. 算法流程

```
训练阶段:
输入: 当前观测o_t, 本体感知q_t, 语言指令ℓ_t, 动作chunk a_t
↓
1. 创建clean-action副本 A (t=0, 未损坏)
2. 创建噪声未来动作 Ã (添加噪声)
3. 创建噪声未来视频 Ṽ (添加噪声)
↓
4. MoT处理:
   - 动作专家: 从{O, Ã}去噪未来动作
   - 视频骨干(RGB prompt): 从{O, Ṽ, A}去噪未来RGB
   - 视频骨干(mask prompt): 从{O, Ṽ, A}去噪未来self-mask
↓
5. 计算损失: L_act + L_rgb + L_mask

推理阶段（快速控制）:
输入: 当前观测o_t, 本体感知q_t, 语言指令ℓ_t
↓
1. 当前观测编码一次
2. 动作专家迭代去噪 → 输出动作chunk
3. 无需生成未来视频！
↓
输出: 动作chunk a_t
```

### 4. 输入输出

**训练输入**: 当前多视角RGB观测 + 本体感知 + 语言指令 + 演示动作
**训练输出**: 动作预测 + 未来RGB预测 + 未来自掩码预测
**推理输入**: 当前多视角RGB观测 + 本体感知 + 语言指令
**推理输出**: 动作chunk（无需视频生成）

## Q2: 与Spatial AGI的关系

### 1. 如何理解和表示空间

- **自接地（Self-grounded）**: 通过机器人自掩码明确建模机器人在空间中的位置和运动
- **动作条件化**: 未来预测基于执行动作，建立"动作→空间变化"的因果关系
- **多视角空间感知**: 处理多视角RGB观测，隐式理解3D空间

### 2. 如何处理空间关系

- **机器人-场景交互**: 自掩码预测聚焦于机器人本体与场景的空间交互
- **动作诱导运动**: 通过不同动作产生不同的未来视觉变化，建模动作-空间因果关系
- **时序空间演化**: 预测未来K帧的空间状态变化

### 3. 对Spatial AGI的启发

1. **Self-grounding概念**: 机器人需要理解自己在空间中的位置——这是embodied spatial intelligence的基础
2. **动作条件化世界模型**: 未来预测必须与动作绑定，才能成为有用的策略学习信号
3. **双模式设计**: 训练时使用完整世界模型，推理时仅用快速动作路径——兼顾学习效果和推理效率
4. **自掩码作为空间锚点**: 机器人分割掩码提供了空间参照系

### 4. 可以应用的Spatial AGI场景

- **机器人操作**: 抓取、放置、装配等需要空间推理的任务
- **导航与避障**: 通过未来预测规划安全路径
- **人机协作**: 预测人类动作的空间后果
- **多机器人协调**: 各机器人预测自身运动的空间影响

## Q3: 创新点和局限性

### 1. 主要创新点

1. **Clean-action conditioning**: 将干净动作副本仅暴露给视频分支，实现动作条件化未来预测同时防止泄漏
2. **机器人自掩码预测**: 首次将机器人本体分割作为世界模型的预测目标，聚焦于动作诱导的运动
3. **非对称信息流**: 噪声动作查询和视觉查询有不同的信息访问权限——优雅的设计
4. **统一架构**: RGB预测和自掩码预测共享视频骨干，通过不同prompt切换
5. **推理效率**: 保持FastWAM的快速推理路径（仅动作专家）

### 2. 主要局限性

1. **自掩码质量**: 依赖机器人分割掩码标注，需要额外的分割模型或标注
2. **仅操作场景**: 主要在桌面操作任务上验证，导航/移动场景未探索
3. **视频生成质量**: 未评估生成视频的视觉质量，仅评估策略性能
4. **单机器人**: 仅建模单个机器人的自掩码，多机器人场景未考虑
5. **动作空间限制**: 在连续动作空间上验证，离散动作空间的适用性未验证

### 3. 与相关工作的对比

| 方法 | 动作条件化 | 推理时视频生成 | 自掩码 | 训练效率 |
|------|-----------|---------------|--------|----------|
| UWM | ✓ (共享) | 可选 | ✗ | 中 |
| FastWAM | ✗ | ✗ | ✗ | 高 |
| GigaWorld-Policy | ✓ | 保留 | ✗ | 中 |
| GeoSem-WAM | ✓ | 可选 | ✗ (几何/语义) | 中 |
| **SelfWAM** | **✓ (clean)** | **可选** | **✓** | **高** |

## 核心技术发现

1. **动作泄漏防护**: 通过非对称信息流设计，干净动作仅作为视觉条件，不进入动作预测路径
2. **自掩码聚焦**: 自掩码预测移除外观干扰，将学习信号聚焦于机器人空间运动
3. **Action sensitivity**: 不同动作缩放产生不同运动模式，证明模型确实学到动作-视觉因果
4. **部署友好**: 推理路径与FastWAM一致，不增加延迟

## 与Spatial AGI的关系

### 直接贡献
- 提供了动作条件化的世界模型，支持embodied spatial intelligence
- 自掩码预测为空间智能提供了机器人本体锚点
- 高效推理路径适合实时空间推理

### 技术启发
- **Self-grounding是关键**: 空间智能不仅是场景理解，还需要理解"我在哪里"
- **因果而非相关**: 动作条件化让世界模型学习因果关系而非简单时序相关
- **多目标协同**: RGB + 自掩码双目标比单一目标更有效

---

## 总结

SelfWAM的核心贡献是让世界模型从"被动观察者"变为"主动行动者"——未来预测不再是通用的场景演进，而是特定动作导致的空间变化。这对Spatial AGI很重要：真正的空间智能需要理解"我的动作如何改变空间"。clean-action conditioning + self-mask prediction的组合提供了一种优雅的解决方案，同时保持了推理效率。
