# SeeSE3: Emergence of 3D Space in Vision Features

**arXiv**: [2607.14228](https://arxiv.org/abs/2607.14228) | **Authors**: Caroline Chen, Sayna Ebrahimi, Fedor Kitashov, Ming-Hsuan Yang, Leonidas Guibas, Viorica Pătrăucean, Maks Ovsjanikov | **Affiliation**: Google DeepMind
**Published**: 2026-07-15 | **Categories**: cs.CV, cs.AI

---

## 论文概述

SeeSE3 提出了一个根本性问题：视觉基础模型是否能够"发现"3D欧几里得空间的结构？不同于以往通过回归深度或法线来探测3D感知的方法，本文直接研究视觉特征的内部结构是否反映了SE(3)欧几里得变换群的性质。受Poincaré假设启发——"不动观察者能否从被动视觉输入中发现3D空间结构"——本文给出了肯定的答案。

---

## Q1: 核心算法原理

### 1.1 核心思想和动机

本文的动机来自认知科学和哲学中的经典问题：发现欧几里得空间的几何是否需要"能动性"（agency）。Henri Poincaré曾假设"不动的存在永远无法获得空间概念"。现代视觉基础模型本质上是"不动的观察者"——即使是视频模型，也只是他人运动的被动观察者。

SeeSE3提出了**"Poincaré Task"**：给定一个静态场景中的被动视觉输入流，视觉模型是否能自然地在其潜在空间中组织出反映SE(3)变换的结构？

这不同于传统的3D感知探测（如深度/法线回归），而是探究特征空间本身的**拓扑和几何性质**是否与欧几里得空间一致。

### 1.2 主要技术方法

#### (a) Mutual Neighborhood Metric（互近邻度量）

评估特征空间的拓扑是否与SE(3)的空间拓扑一致：
- 对于场景中的每对视角(i,j)，计算它们在特征空间和位姿空间中的k近邻
- 使用Jaccard相似度衡量两个近邻集合的重叠程度
- 如果特征空间拓扑与SE(3)拓扑一致，近邻集合应有高重叠

#### (b) Poincaré Adapter（庞加莱适配器）

一个轻量级Siamese网络，用于测试从特征位移到相机运动的线性可达性：
- 输入：同一静态场景的两个视角的特征对(z_i, z_j)
- 输出：预测的相对SE(3)变换（平移+旋转）
- 关键：使用Siamese架构确保输出对特征对的排列不变性
- 验证特征空间中是否存在一个线性子空间与SE(3)的李代数se(3)同构

#### (c) Manifold Dimensionality Estimation（流形维数估计）

验证特征点集{z_t}是否局部形成6维流形（对应SE(3)的6个自由度）：
- 使用局部PCA分析特征邻域的固有维数
- 理论上如果特征空间忠实地反映了SE(3)，应该观察到约6维的局部流形

### 1.3 算法流程

1. **数据准备**：选择多样化数据集中的静态场景，用移动相机采集图像序列
2. **特征提取**：用视觉基础模型（如DINOv2/v3, CroCo等）提取每帧图像的特征向量
3. **拓扑分析**：计算互近邻度量，评估特征空间与位姿空间的拓扑对齐程度
4. **几何分析**：训练Poincaré Adapter，评估从特征位移到SE(3)变换的线性映射质量
5. **流形维数**：估计特征点的局部流形维数
6. **Latent-Space Navigation**：基于Poincaré Adapter的线性化能力，实现纯潜在空间的视觉里程计和定位

### 1.4 输入输出

- **输入**：同一静态场景的多视角图像序列 + 对应的相机位姿（用于训练和评估）
- **输出**：
  - 拓扑对齐分数（互近邻度量）
  - 几何对齐质量（Poincaré Adapter的位姿预测精度）
  - 流形维数估计
  - 潜在空间导航结果（视觉里程计/定位）

## Q2: 与Spatial AGI的关系

### 2.1 如何理解和表示空间

SeeSE3对空间的理解方式极为深刻——它不依赖于显式的3D坐标系统或重建，而是探究**视觉特征本身是否内化了3D空间的几何结构**。这对应了Spatial AGI中最根本的问题：智能体如何获得对空间的内化理解。

关键发现：
- 自监督视觉模型的潜在子空间与SE(3)有强相关性
- 这种相关性是"自然涌现"的，不需要显式3D监督
- 旋转比平移更容易被编码（这与认知科学发现一致）
- 存在"Visual Grid Code"——类似大脑网格细胞的表示

### 2.2 如何处理空间关系

SeeSE3通过以下方式处理空间关系：
- **拓扑一致性**：特征空间的近邻关系反映了物理空间的近邻关系
- **几何线性化**：通过Poincaré Adapter，特征空间中的线性位移对应于SE(3)中的刚体变换
- **闭合形式导航**：利用线性化特性，可以在潜在空间中直接进行路径规划和导航

### 2.3 对Spatial AGI的启发

1. **Implicit Spatial Understanding**: Spatial AGI不一定需要显式的3D重建模块——视觉特征本身可能已包含足够的几何信息
2. **Latent-Space Navigation**: 直接在潜在空间进行导航和定位，无需显式重建，这对实时 embodied AI 系统有重大意义
3. **Emergent Geometry**: 自监督学习可以自然发现3D几何结构，这为大规模预训练提供了理论基础
4. **Agency Question**: 挑战了"需要能动性才能理解空间"的传统观点——被动观察也能获得空间表示

### 2.4 可应用的Spatial AGI场景

- **Embodied Navigation**: 潜在空间导航可直接应用于机器人导航
- **Visual Odometry**: 无需特征提取和匹配的纯潜在空间里程计
- **Scene Memory**: 为构建持久空间记忆提供理论基础
- **World Models**: 世界模型的潜在空间设计可以参考SE(3)对齐原则
- **Multi-view Fusion**: 理解特征空间如何编码3D有助于多视角信息融合

## Q3: 创新点和局限性

### 3.1 主要创新点

1. **全新视角**：首次从"特征空间内部结构"角度研究3D感知，而非传统的深度/法线回归
2. **Poincaré Task**：提出了受哲学启发的全新问题形式化
3. **Poincaré Adapter**：轻量级探测工具，揭示特征空间的几何结构
4. **理论分析**：提供了自监督方法恢复几何结构的条件分析
5. **Latent-Space Navigation**：基于发现提出的实用技术
6. **Visual Grid Code**：发现了类似生物网格细胞的出现模式

### 3.2 主要局限

1. **仅限静态场景**：所有实验在静态场景中进行，动态场景的适用性未知
2. **需要位姿标签**：虽然模型不需要3D监督，但评估和训练Poincaré Adapter需要位姿真值
3. **线性化局限**：Poincaré Adapter只能捕获局部线性关系，全局非线性结构可能更复杂
4. **特定模型依赖**：结果依赖于特定的视觉基础模型，不同模型的表现差异较大
5. **尺度问题**：大范围环境（如室外场景）的泛化能力未验证

### 3.3 与相关工作的比较

| 方面 | SeeSE3 | Probe3D (El Banani et al.) | DUSt3R/VGGT | RUST |
|------|--------|---------------------------|-------------|------|
| 探测方式 | 特征空间结构 | 深度/法线回归 | 显式重建 | 生成模型潜在空间 |
| 是否需要重解码 | 否（轻量级） | 是（需解码器） | 是（重解码器） | 中等 |
| 发现vs计算 | 发现结构 | 计算属性 | 计算几何 | 发现结构 |
| 能动性要求 | 无 | 无 | 无 | 无 |

### 3.4 优势

- 理论深度强，从认知科学到实践打通
- 轻量级探测，不改变原模型
- 发现自监督模型的涌现几何能力

### 3.5 劣势

- 实际应用距离较远（主要是理解和分析工具）
- 动态场景、大规模环境的适用性待验证
- Poincaré Adapter仍需要一定的训练数据

## 详细技术分析

### Mutual Neighborhood Metric公式

对于特征空间中的点z_i，定义其k近邻集合N_k^F(z_i)；在位姿空间中的点P_i，定义其k近邻集合N_k^P(P_i)。

Jaccard相似度：M_1(i) = |N_k^F(z_i) ∩ N_k^P(P_i)| / |N_k^F(z_i) ∪ N_k^P(P_i)|

### Poincaré Adapter设计

使用Siamese架构：
- 两个共享权重的MLP分支分别处理z_i和z_j
- 输出为相对位姿预测ΔP = g(z_i, z_j)
- 训练目标：最小化ΔP与真实相对位姿的差异

关键特性：
- 齐次性：相同的相对位移在不同位置产生相同结果
- 线性可达性：特征空间中的线性路径对应物理空间中的平滑运动

### Latent-Space Navigation

利用Poincaré Adapter的线性化能力：
1. 给定源帧z_s和目标帧z_t
2. 在线性化子空间中插值：z(λ) = z_s + λ(z_t - z_s)
3. 对每个中间点，用解码器或检索找到对应的真实图像
4. 实现无需显式3D重建的视觉导航

### 理论分析要点

1. **旋转vs平移**：旋转信息比平移信息更容易从视觉特征中恢复，因为旋转直接影响整个特征图的全局结构
2. **自监督条件**：成功的关键在于自监督目标是否能迫使模型学习视角不变性和等变性
3. **流形假设**：如果特征空间确实形成6维流形，那么局部线性化是合理的近似

## 实验结果总结

### 测试模型
- DINOv2/v3（自监督ViT）
- CroCo（跨视图掩码自动编码器）
- CLIP（对比学习）
- 多种其他视觉基础模型

### 关键发现
1. 自监督模型（DINO系列）在拓扑和几何对齐上显著优于监督模型
2. 旋转编码优于平移编码
3. 训练数据多样性比数据量更重要
4. Visual Grid Code模式在高质量自监督特征中出现

## 个人思考

1. **"不动观察者"的突破**：SeeSE3挑战了 embodied AI 领域的一个常见假设——即真正的3D理解需要交互。被动观察的自监督模型已经"发现"了3D空间的结构，这非常令人振奋。

2. **对世界模型的启示**：如果视觉特征自然地与SE(3)对齐，那么世界模型的潜在空间设计应该利用这一结构。不需要显式地施加3D结构，而是应该让模型自然发现它。

3. **网格细胞的涌现**：Visual Grid Code的发现连接了AI和神经科学，暗示自监督学习可能自然地产生类似生物大脑的空间表示。

4. **实际应用路径**：虽然SeeSE3主要是分析工具，但Latent-Space Navigation指明了实际应用方向——直接在特征空间做导航和定位，绕过显式3D重建。

5. **与SpatialStack/SpatialForge的互补**：那些工作显式地注入3D信息到VLM中，而SeeSE3表明这些信息可能已经隐式存在。两者的结合——显式引导+隐式发现——可能是最佳路径。

6. **局限中的机遇**：目前仅限静态场景，但动态场景的扩展是自然的下一步。如果特征空间能够同时编码SE(3)和时间维度，那将是一个4D时空潜在空间。
