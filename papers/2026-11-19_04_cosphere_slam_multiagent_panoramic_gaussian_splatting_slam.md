# CoSphere-SLAM: Multi-Agent Panoramic Gaussian Splatting SLAM with Spherical Loop Closure

**发表日期**: 2026-11-17
**arXiv链接**: https://arxiv.org/abs/2611.22235
**PDF链接**: https://arxiv.org/pdf/2611.22235

**项目页**: https://cosphere-slam.github.io

## 论文一句话总结

CoSphere-SLAM 是首个面向全景相机的多智能体 3DGS SLAM 框架：用球面特征在 SO(3) 上的 FFT 相关实现任意朝向的回环检测，用全局 Sim(3) 共识（三-agent 环路约束）拒绝对称房间的系统性误回环，用方向性全局优化（各向异性 per-keyframe Sim(3) 位姿图，把光流平移方向与深度尺度漂移解耦）修正尺度漂移，最后用全向高斯融合沿视线射线联合精化位姿与地图——在室内和跨会话多智能体全景基准上达到单/多智能体方法中 SOTA 的轨迹精度与渲染质量。

## 核心问题

### Q1: 核心算法原理

**问题**: 这篇文章的核心算法原理是什么？

**分析**:

1. **核心思想和动机**

   密集协同建图对搜救、建筑巡检、仓储自动化至关重要，全景相机单帧捕获整个周围环境，室内特别有效。但即使有 360° 视角：
   - 单智能体只沿一条路径观测，墙壁与家具遮挡后方表面；
   - 逐房间访问很慢；
   - 单目尺度与位姿漂移跨房间累积。

   因此需要多智能体并行探索。但现有多智能体 SLAM（CP-SLAM、MNE-SLAM、MAGiC-SLAM、MAC-Ego3D、MAGS-SLAM、CoMo3R-SLAM）都基于窄视场 pinhole 视图 + RGB-D 输入或刚性子图：裁剪视图下错过不同朝向的相遇，且在等距柱状投影畸变、对称房间、全景尺度漂移下失败。

   把全景高斯 SLAM 扩展到多智能体需要解决三个耦合挑战：
   - **回环检测挑战**：相机以任意朝向 pitch/roll 时，yaw 使等距柱状图沿经度循环平移，tilt 却按纬度不同地扭曲行、破坏平面匹配；搜索全部 3D 旋转会匹配到"对称房间"——与随机外点不同，对称布局中的所有匹配暗示同一个错误变换，成对鲁棒核无法拒绝它们；
   - **尺度漂移挑战**：单目轨迹在远距离相遇之间尺度连续漂移；短基线处的深度误差按场景深度比例移动 3D 点对齐、污染平移方向；
   - **地图融合挑战**：变化的尺度校正会在重访墙面处撕裂刚性合并的子图；把 3D 高斯投影到切平面会在极点附近拉伸、在接缝处切断。

   核心洞察：单目全景观察单位球 S² 无视场限制，提供无尺度的观察方向，但房间离散对称性与连续径向尺度在单视图中不可观测。SO(3) 搜索会把对称房间变成"连贯的外点簇"——需要全局共识而非成对核；各向同性对齐会把光流方向与深度噪声混淆——需要方向性解耦。

2. **主要技术方法——四个组件**

   **组件 0：Per-Agent 跟踪与建图（III-A）**：
   - 等距柱状投影在极点附近拉伸像素、跨垂直接缝切断，标准 2D 卷积无法平等对待所有方向 → 每个智能体把每张全景重采样为 6 个 90° 立方体贴图面（共享一个光心、固定的体到面旋转 R_f）；
   - 用 DROID-SLAM 前端联合跟踪所有面（通过 T_i·R_f^T），估计每个关键帧的相机到局部位姿 T_i ∈ SE(3)；
   - 在更宽的重叠面上预测单目深度，用线性最小二乘对齐各面的 log 尺度成一张球面深度图 D_i: S²→R+；
   - 深度尺度跨房间漂移 → D_i 只约束最初几个关键帧的位姿更新，后续关键帧仅靠多视图光流和 agent 内回环；
   - 固定 T_i，对着 D_i 精化关键帧深度以沿视线监督局部 3D 高斯 G_i；
   - 通信：水平面特征跨行平均形成紧凑环形描述子 H_i ∈ R^{C×W_r}，与 T_i 一起发送。

   **组件 1：球面回环检测（Spherical Loop Closure, III-B）**：
   - 球面特征图 F_i: S²→R^C（6 面稠密特征重采样到等距柱状单位方向网格），相邻关键帧满足 F_j(x) ≈ F_i(R_ij·x)——旋转全景是无损置换 S²，不像 pinhole 旋转会裁剪场景；
   - 快速筛选所有 O(|V|²) 对：水平面特征按行池化得到 H_i（对 tilt 容忍、把 yaw 变成循环列移），用循环互相关 ρ_ij = max_v ⟨H_i, Π_v H_j⟩ 打分，只对 top 对请求面和深度；
   - **球面相关（核心算法）**：把旋转分解 R = Q·R_z(ψ)——先水平轴 2D 倾斜 Q，再竖直轴 yaw R_z(ψ)。固定 tilt Q 下，把 F_i 重采样为 F_i^Q，所有 yaw ψ ∈ [0,2π) 的相关变成沿经度 φ 的一维循环互相关，一次逆 FFT 完成：
     C_ij(Q,·) = F_φ^{-1}[Σ_θ cosθ · F̂_i^Q(θ,·)^⊤ · conj(F̂_j(θ,·))]
     其中 cosθ 按纬度立体角加权。N_Q 个 tilt 的粗到细搜索 + parabolic yaw 精化，复杂度 O(N_Q·C·H·W·log W)，覆盖 360° 朝向；
   - 从 R*_ij 初始化，各水平面与对方最近的旋转面配对做 6-DoF 光流位姿精化；置信光流对应点用 D_i/D_j 反投影为 3D 点对，加权 Umeyama 对齐求 Sim(3) 相似变换（相对尺度、旋转、平移）。

   **组件 2：全局 Sim(3) 共识——拒绝对称误回环（III-B 末）**：
   - 对称场景中存在非平凡刚体对称 G ≠ I（如 180° 旋转使房间/走廊自映射）：通过局部位姿变换得到 inter-agent 相似 Ŝ_ij = T_i·S̃_ij·T_j^{-1}，真回环在不同房间聚集到同一变换 S̄_ab 附近，而对称误匹配散布在 S̄_ab·G^{-1} 偏移处；
   - 关键：当整个共享区域服从同一对称 G 时，误回环形成第二个"连贯簇"S̄'_ab = S̄_ab·G^{-1}，成对鲁棒核无法拒绝；
   - 解法：在任意闭合三-agent 环路 (a,b,c) 上，真相似复合为 S̄_ab·S̄_bc·S̄_ca = I；代入对称簇 S̄'_ab 得 S̄_ab·G^{-1}·S̄_ab^{-1} ≠ I——其旋转角等于 G 的旋转角，远超慢漂移，环路约束直接暴露对称簇；
   - 形式化为全局共识最大化：把每对 (a,b) 的候选 Ŝ_ij 按平移+旋转聚成簇 H_ab = {(S̄_ab^h, n_ab^h)}，从每对至多选一个簇（可为空），最大化总支持数，约束所有三元组环路残差（平移 ‖t_abc‖ ≤ τ_t，旋转 ‖Log(R_abc)‖ ≤ τ_R）；
   - 对 top 对模式穷举搜索精确求解——在三-agent 环路上拒绝对称簇，在两-agent/树状结构上保留最大多房间簇。

   **组件 3：方向性全局优化（Directional Global Optimization, III-C）**：
   - 保留的回环连接多agent轨迹的多处位置；单目不可观测尺度漂移累积；
   - 每 keyframe 分配一个 Sim(3) 相似（各向异性），在 Sim(3) 位姿图上加 log 尺度正则；
   - 方向性解耦：光流给出的平移"方向"可靠（短基线深度噪声按场景深度比例污染的是"幅度"与 3D 点对齐）→ 把光流平移方向与基于深度的尺度大小分开处理，避免各向同性对齐混淆两者。

   **组件 4：全向高斯融合（Omnidirectional Gaussian Fusion, III-D）**：
   - 变化的尺度校正会在重访面处撕裂刚性合并的子图 → 按 keyframe 相似度变换每个高斯（deform by keyframe similarity）；
   - 渲染时在最大射线响应处渲染高斯（render at maximum ray response），避免切平面投影在极点拉伸与接缝切断；
   - 沿视线射线联合精化全部位姿与地图。

3. **算法流程和关键步骤**

   端到端流程：
   1. 各 agent：全景流 → 立方体贴图 → DROID-SLAM 前端跟踪 → 局部 SE(3) 位姿 → 球面深度图 → 局部 3D 高斯；环形描述子 H_i + T_i 上传服务器；
   2. 服务器筛选：循环互相关打分所有跨 agent 关键帧对 → top 对请求完整数据；
   3. 球面相关：tilt 分解 + FFT yaw 相关 → 粗旋转 R*_ij → 光流精化 + Umeyama → 候选 Sim(3)；
   4. 全局共识：候选聚类 + 三-agent 环路约束的共识最大化 → 保留的回环集合 L；
   5. 方向性全局优化：per-keyframe Sim(3) 位姿图 + log 尺度正则 → 校正全部位姿与尺度；
   6. 全向高斯融合：按 keyframe 相似变换高斯 + 最大射线响应渲染 → 联合精化 → 输出统一 3D 高斯地图（支持 360° 渲染）。

4. **输入输出**

   - 输入：多台单目全景相机的等距柱状视频流（未知初始位姿、未知尺度），可能的跨会话数据；
   - 输出：统一的多智能体联合轨迹（per-keyframe Sim(3) 位姿）+ 一张统一的稠密 3D 高斯地图（可 360° 新视角渲染）；
   - 通信：agent 间只传紧凑环形描述子（C×W_r），top 对才传面图像与深度——带宽友好。

5. **评测**

   - 室内 + 跨会话多智能体全景基准；
   - 对比对象包括单智能体与多智能体方法（ODGS-SLAM 等用 RANSAC+ICP 配准地图作对比基线）；
   - 指标：单 agent ATE、多 agent 联合 ATE、masked front-face PSNR；
   - 结果：轨迹精度与渲染质量在单/多智能体方法中均 SOTA。

### Q2: 与 Spatial AGI 的关系

**问题**: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**分析**:

1. **如何理解和表示空间**

   CoSphere-SLAM 的空间表示哲学是"**球面第一性**"：
   - 空间观测的单位是方向球 S²（全景=整球采样），而不是平面投影；
   - 所有空间关系（旋转、对称、尺度）在 S²/SO(3)/Sim(3) 的群结构上显式推理：yaw 是经度循环移位（群上的平移，FFT 天然处理）、tilt 是纬度形变（需要重采样）、对称是群自同构 G、尺度是 Sim(3) 中独立的自由度；
   - 与主流"投影到平面再套 2D 方法"的路线相反，它把几何结构（对称性、流形、群作用）直接写进算法——这是空间智能中"结构先验算法化"的范例。

   多智能体维度上，空间被表示为"多个观察路径的联合一致状态"——同一空间的多个探索者的观测必须在 Sim(3) 意义下兼容。这把空间理解从单视角问题升级为分布式一致性问题。

2. **如何处理空间关系**

   - **旋转关系**：任意朝向的两张全景的关系 = SO(3) 元素，通过 tilt-yaw 分解 + FFT 高效估计——空间旋转关系的快速求解模板；
   - **对称关系**：对称房间的误匹配不是噪声而是"结构化系统外点"（同错误变换的连贯簇）——空间智能必须区分随机噪声与结构性歧义，本文用环路一致性（cycle consistency）区分，这是处理空间歧义的高级策略；
   - **尺度关系**：单目尺度不可观测 + 漂移 → Sim(3) 显式建模；方向（光流可靠）与幅度（深度污染）分离——对空间信息的不同成分做可靠性分级；
   - **多智能体关系**：agent 间空间关系 = inter-agent Sim(3)，通过紧凑描述子 + 环路共识建立——分布式空间一致性。

3. **对 Spatial AGI 的启发**

   - **多智能体是 Spatial AGI 的必然形态**：单 agent 单路径的空间覆盖永远受遮挡与时间限制；CoSphere 展示了"多视角路径的分布式空间共识"的完整技术栈（通信压缩 → 匹配 → 共识 → 融合），对构建群体空间智能直接可复用；
   - **对称性是空间智能的试金石**：人类也会在对称走廊迷路。区分"真重访"与"对称混淆"需要超越局部证据的全局一致性推理——这与 VLM 空间幻觉（把对称房间认成同一个）是同一问题的不同层面，环路一致性思想可迁移到 VLM 的空间推理（如 Same Space or Not 这类跨视图矛盾基准的方法论）；
   - **群结构上的高效算法**：SO(3) FFT 相关把 O(欧拉角穷举) 降到 O(N_Q·CHW·logW)——空间智能的实时性需要这类"几何结构 → 算法加速"的转换；
   - **空间记忆的一致性维护**：与 GSExplorer（持久 3DGS 世界状态）呼应——SLAM 的尺度漂移校正 ≈ 记忆系统的重锚定；撕裂-修复子图的问题 ≈ 记忆更新时保持旧证据连贯的问题。

4. **可以应用的 Spatial AGI 场景**

   - 搜救机器人集群的实时稠密地图（论文动机）；
   - 仓储自动化多 AMR 协同建图与定位；
   - 建筑巡检的跨会话变化检测（跨会话评测支持）；
   - VR/AR 多用户共享空间理解（全景相机的消费级趋势）；
   - 为下游空间智能任务供图：统一 3DGS 地图可直接喂 GPWM 类物理世界模型（建的图 → 可模拟的世界）、供 DynThinker 类 VLM 做空间推理；
   - 群体机器人空间协调：多智能体 Sim(3) 共识可扩展为空间任务的分布式协商框架。

### Q3: 创新点和局限性

**问题**: 基于前面的分析，这个方法的主要创新点和局限性是什么？

**分析**:

1. **主要创新点**

   - **首个多智能体全景 3DGS SLAM 框架**：统一全球跟踪、紧凑描述子通信、无先验位姿/尺度的稠密建图——填补了"全景 + 多智能体 + 高斯稠密"的三重空白；
   - **球面回环检测**：tilt-yaw 分解 + 纬度立体角加权的 FFT 循环相关，O(N_Q·CHW·logW) 实现任意朝向的球面特征匹配——把 SO(3) 搜索从组合爆炸变成 FFT 问题；
   - **全局 Sim(3) 共识拒绝对称误回环**：形式化证明了"结构化对称簇可逃过成对鲁棒核"（Eq.4 的环路残差分析），并给出三-agent 环路共识最大化的精确解——这是对协同 SLAM 外点拒绝理论的实质推进；
   - **方向性全局优化**：per-keyframe Sim(3) 位姿图 + 光流方向/深度幅度解耦 + log 尺度正则——针对单目全景特有"方向可靠、尺度漂移"误差结构的定制化优化；
   - **全向高斯融合**：keyframe 相似变换每个高斯 + 最大射线响应渲染，解决极点拉伸与接缝切断的全景渲染特有问题。

2. **主要局限性**

   - **依赖全景相机硬件**：消费级部署受限（虽然全景相机正在普及，但多数机器人仍是 pinhole + RGB-D）；框架不可直接迁移到 pinhole 场景；
   - **服务器中心化架构**：集中式服务器做匹配与全局优化——通信中断/服务器失效时的降级策略未提及（对比分布式协同 SLAM）；
   - **三-agent 环路依赖**：对称簇的拒绝依赖三元组环路——两 agent 或树状拓扑只能保留最大簇，对称场景下两 agent 协同仍脆弱；
   - **深度网络依赖**：单目深度预测的跨房间尺度漂移只能靠"只信前几个关键帧"的启发式缓解，深度模型的系统性偏差仍会进入局部地图；
   - **动态场景未处理**：SLAM 假设静态世界，移动的人/物（搜救场景恰恰充满动态）会污染跟踪与地图——动态 SLAM 扩展是空白；
   - **实时性未确认**：FFT 相关是快的，但 DROID-SLAM 前端 + 光流精化 + 位姿图优化 + 高斯融合的多级流水线整体吞吐需要核对实验章节。

3. **与其他相关工作的对比**

   - vs **CP-SLAM/MNE-SLAM（神经隐式协同）**：它们 pinhole + 隐式表示；CoSphere 全景 + 显式高斯，渲染质量与编辑能力更强。
   - vs **MAGiC-SLAM/MAC-Ego3D（RGB-D 高斯协同）**：依赖深度传感器；CoSphere 纯单目。
   - vs **MAGS-SLAM（单目多agent高斯）**：子图级刚性 Sim(3) 对齐——重访面撕裂问题正是 CoSphere 用 per-keyframe 相似 + 高斯形变解决的。
   - vs **CoMo3R-SLAM（重建先验协同）**：CoSphere 不依赖大重建模型，靠几何群结构算法。
   - vs **360VO/OpenVSLAM（全景单agent VIO/SLAM）**：稀疏、无稠密地图、无多agent；CoSphere 全套补齐。
   - vs **Omni-swarm/D2SLAM（全向空中集群）**：稀疏状态估计、无回环/尺度校正/稠密地图；CoSphere 是全景集群的稠密版。
   - vs **GSExplorer（11-18，持久 3DGS 世界状态）**：GSExplorer 管单 agent 的持久世界状态，CoSphere 管多 agent 的联合空间共识——空间记忆的个体层 vs 群体层。
   - vs **GEMOR-GS（11-12，外参精化 3DGS SLAM）**：GEMOR 解决 LiDAR-惯性-视觉的外参一致性，CoSphere 解决跨 agent 的 Sim(3) 一致性——都是"多源空间信息的一致性"问题。

## 核心技术发现

- 发现1：全景旋转 = S² 的无损置换，使 yaw 相关可化为 FFT 循环互相关——几何性质直接转化为算法加速。
- 发现2：对称布局的误回环是"同错误变换的连贯簇"，成对鲁棒核原理上无法拒绝；三-agent 环路一致性（真相似复合=I，对称簇复合≠I 且旋转角=|G|）是判别武器。
- 发现3：单目全景的误差结构是"光流方向可靠、深度幅度污染"——方向性解耦的各向异性优化优于各向同性对齐。
- 发现4：per-keyframe（而非子图级）相似变换 + 按相似形变高斯 + 最大射线响应渲染，可消除重访面撕裂与极点畸变。

## 附录 A：Method 深入笔记

### A1. 全景几何预备知识

- **等距柱状投影（equirectangular）**：球面 → 2:1 宽高比平面图，经度 φ → 列，纬度 θ → 行。极点附近像素被水平拉伸（畸变），φ=±π 处存在垂直接缝。
- **立方体贴图（cube map）**：6 个 90° 面，等角分辨率，消除拉伸与接缝，可用标准 2D 卷积。
- **关键性质**：全景的 yaw 旋转 = 等距柱状图的循环列移（群 G 上的平移）→ FFT 对角化循环移位 → 互相关 = 频域乘法，一次 IFFT 得所有 yaw 的相关分数。
- **tilt 的问题**：pitch/roll 让点跨纬度移动，破坏列移结构 → 需要离散 tilt Q 网格粗到细枚举，每个 tilt 下重采样再做 FFT yaw 相关。

### A2. 球面相关的完整算法推演

输入：球面特征图 F_i, F_j: S²→R^C（H×W 等距柱状网格）。
1. 枚举 tilt Q ∈ {Q_1..Q_NQ}（水平轴 2D 旋转网格）；
2. 重采样 F_i^Q(x) = F_i(Qx)；
3. 对每行（纬度 θ）做 1D FFT 得 F̂（沿经度 φ）；
4. 频域组合：Σ_θ cosθ · F̂_i^Q(θ,·)^⊤ · conj(F̂_j(θ,·))——cosθ 立体角加权（高纬度单元实际面积小）；
5. 一次逆 FFT → C_ij(Q, ψ)：该 tilt 下所有 yaw 的相关分数；
6. 取 argmax，parabolic 亚列精化 ψ*；
7. 跨 tilt 取最优 → R*_ij = Q* R_z(ψ*)。
复杂度 O(N_Q·C·H·W·log W)，相比 SO(3) 三角穷举（O(N_Q²·W) 级甚至更大）大幅加速。

### A3. Umeyama 对齐（Sim(3) 求解）复习

给定 3D 点对 {(p,q)}，求 s, R, t 最小化 Σ ω‖p − sRq − t‖²：
- 经典 Umeyama 求无权 SE(3)+scale：SVD 分解协方差 H = Σ(q−q̄)(p−p̄)^⊤；
- 本文扩展：光流置信度作权重 ω_pq（加权版本）；
- 输出：相对尺度 s̃、旋转 R̃、平移 t^um——一次闭式求解，无需迭代。

### A4. 对称误回环问题的理论分析（全文最精彩段落复述）

场景：走廊两端对称（180° 旋转对称 G）。两个 agent 各从一端进入：
1. 球面匹配找到大量"高置信"匹配——但这实际是把房间 a 的观察映射到房间 b 的对称位置；
2. 通过局部位姿变换 Ŝ_ij = T_i S̃_ij T_j^{-1}，真回环聚在正确变换 S̄_ab 附近（一个簇）；
3. 对称误匹配聚在 S̄_ab·G^{-1} 附近（另一个簇）——两簇支持数可能相当；
4. 成对鲁棒核（PCM、GNC、DCS）只能拒绝"互相不一致"的外点；对称簇内部完全自洽，无法拒绝；
5. 三-agent 环路测试：若 a-b 匹配用对称簇 S̄'_ab = S̄_ab G^{-1}，则环路乘积 S̄'_ab S̄_bc S̄_ca = S̄_ab G^{-1} S̄_ab^{-1} ≠ I，旋转角 = |G| 的角（如 180°），远超正常漂移（通常 <几度）；
6. 全局共识最大化：选簇组合 maximizing Σn^h 满足所有三元组环路≈I → 对称簇被系统性排除。

### A5. 方向性优化的误差模型

单目全景观测的误差结构：
- 多视图光流（跨帧特征跟踪）→ 平移"方向"估计可靠（相对运动方向是视觉可直接观测的）；
- 单目深度预测 → 绝对"幅度"不可靠（尺度不可观测 + 跨房间漂移；短基线时 3D 点误差按场景深度比例放大，直接污染平移幅度估计）；
- 各向同性对齐会把方向误差与幅度误差混在一起；
- 解法：per-keyframe Sim(3) 位姿图中，方向项与尺度项分别加权/正则（log 尺度正则约束尺度变化平滑），实现"信方向、缓尺度"。

### A6. 全向高斯融合的渲染细节

- 问题1：变化的尺度校正 → 刚性合并的子图在重访墙面出现裂缝（同一面墙的两个子图高斯错位）；
- 解法1：每个高斯按其 keyframe 的相似变换 S_i 变换（deform by keyframe similarity）——高斯与关键帧"共同漂移"，重访处自然对齐；
- 问题2：把 3D 高斯投影到切平面 → 极点附近拉伸、接缝切断；
- 解法2：最大射线响应渲染——沿每条视线取高斯响应最大处，绕开平面投影；
- 附加：渲染误差反传联合精化位姿与地图（slam 式的 map-guided refinement）。

## 附录 B：QA 式补充精读

### B1. 为什么用 DROID-SLAM 做前端而不是更轻的？

DROID-SLAM 的密集光流迭代优化对全景的六面联合跟踪质量高；代价是算力。工程上可换轻量前端（如稀疏特征 VO），但六面联合跟踪 + 光流质量对后续 Umeyama 与方向性优化至关重要——前端质量是整条流水线的地基。

### B2. 描述子 H_i 为什么按行池化就够？

池化行→只保留纬度分布 + 经度轮廓（环形描述子）。tilt 会轻度改变纬度分布但池化后的"行轮廓"相对鲁棒；yaw 是循环移位由互相关处理。它只是筛选器（决定谁值得精匹配），不承担精确对齐——设计合理。

### B3. 全局共识最大化的规模问题？

每对 (a,b) 的候选簇数有限（按支持数取 top 模式），穷举 top 对模式组合精确求解式(5)。agent 数多、回环多时组合可能膨胀——工程上可用贪心/分支限界。论文未讨论大规模（>10 agents）场景。

### B4. 与 ORB 环路检测的 Bag-of-Words 相比强在哪？

BoW 只能匹配相似朝向的视图（视角不变性有限）；球面特征 + SO(3) 相关可匹配任意朝向——全景下"两个 agent 从相反方向路过同一区域"是常态而非例外，这正是 pinhole 协同 SLAM 的盲区。

### B5. 如果只能吸收一件事

结构化歧义（对称）要靠全局组合约束（环路一致性）解决，不要指望更强的局部鲁棒核——这一原则适用于 SLAM、SfM、VLM 空间推理的一切对称/重复场景。

## 附录 F：精读自测问答

Q: 全景 yaw 旋转在图像上是什么操作？
A: 等距柱状图的循环列移——因此可用 FFT 循环互相关一次算所有 yaw。

Q: 旋转分解 R = Q·R_z(ψ) 中两项各是什么？
A: Q 是水平轴 2D tilt（枚举+重采样），R_z(ψ) 是竖直轴 yaw（FFT 精解）。

Q: 为什么对称误回环逃过成对鲁棒核？
A: 它们形成内部自洽的连贯簇（同一错误变换 S̄G^{-1}），成对核只能拒互不一致外点。

Q: 三-agent 环路如何暴露对称簇？
A: 真相似复合=I；代入对称簇得 S̄G^{-1}S̄^{-1}≠I，旋转角=|G|，远超漂移。

Q: 方向性优化解耦什么？
A: 光流给出的平移方向（可靠）与深度给出的尺度幅度（漂移污染）。

Q: 全向高斯融合解决哪两个渲染问题？
A: 尺度校正导致的重访面撕裂（按 keyframe 相似形变高斯）与极点拉伸/接缝切断（最大射线响应渲染）。

Q: agent 间通信传什么？
A: 紧凑环形描述子 H（C×W_r）+ 位姿；top 对才传立方面与深度。

## 附录 K：数学细节补充（供复现参考）

1. 球面相关公式（式 2）逐项含义：
   - F̂ = F_φ[F]：沿经度 φ 的 1D DFT（每纬度行一个）；
   - cosθ：纬度 θ 处球面单元的立体角权重（真实面积 ∝ cosθ·dφdθ）；
   - Σ_θ：跨纬度求和（tilt 固定后各纬度独立贡献）；
   - conj：复共轭（互相关的频域实现）；
   - F_φ^{-1}[·]：逆变换得到所有循环移位 ψ 的相关值 C_ij(Q,ψ)。
2. Umeyama（式 3）：带光流权重的 Sim(3) 闭式最小二乘，输出 (s̃, R̃, t^um)。
3. 对称判别（式 4）：S̄'_ab S̄_bc S̄_ca = S̄_ab G^{-1} S̄_ab^{-1}，旋转角 = |G|（未知尺度在乘积中相消）。
4. 共识最大化（式 5）：max Σ n^{h_ab} s.t. 所有三元组环路 ‖t_abc‖≤τ_t 且 ‖Log(R_abc)‖≤τ_R；对 top 模式穷举精确解。
5. 估计目标：每 keyframe 相机到世界相似 S_i = (s_i, R_i, t_i) ∈ Sim(3) + 统一高斯地图 G。
