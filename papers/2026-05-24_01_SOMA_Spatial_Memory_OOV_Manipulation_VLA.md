# SOMA: Spatial Memory for Out-of-Vision Manipulation in Vision-Language-Action

**arXiv**: [2605.22283](https://arxiv.org/abs/2605.22283) | **Date**: 2026-05-22 | **Venue**: ICML 2026

---

## 一句话总结

SOMA 通过为 VLA 模型引入持久化空间记忆，解决了目标物体超出相机视野时的操作失败问题，实现了超越当前视野的机器人操作。

---

## 核心问题

现有 VLA 模型假设任务相关物体始终在相机视野内，一旦目标离开视野，模型就无法推理其位置，导致任务失败。这种"视野绑定"假设是 VLA 系统的核心局限。

## 方法概述

SOMA 由三个核心组件构成：

1. **Spatial Memory Construction（空间记忆构建）**：通过可移动头部相机扫描场景，结合 YOLO（语义检测）、DINOv3（语义编码）和 VGGT（几何估计），将多视角观测融合为统一的空间-语义记忆表示 M₀
2. **Dynamic Memory Refinement（动态记忆更新）**：在操作过程中，通过相似性感知的自适应融合机制，实时更新空间记忆以保持全局一致性
3. **Contextual Memory Retrieval（上下文记忆检索）**：通过交叉注意力机制，将指令相关的空间记忆信息注入 VLM 的视觉-语言 token，增强当前感知

**关键技术细节**：
- 使用 VGGT 预测相机位姿和场景几何，将 2D 检测提升到 3D 全局坐标系
- 跨视角实例关联：结合 DINOv3 外观相似度和 3D 空间一致性进行实例融合
- 动态更新使用时序指数移动平均：α = g·s（融合分数 × 语义相似度）

## 实验结果

| 基准 | SOMA | 最强基线 | 提升 |
|------|------|----------|------|
| OOV 真实世界 5 任务 (avg SR) | 28.3% | 19.8% (No-Scan) | +43% |
| RoboCasa GR1 (300 demos) | 52.0% | 44.9% (GR00T) | +16% |
| SimplerEnv Visual Matching | 63.2% | 60.6% (RoboVLM) | +4.3% |
| OOV 行为：首次注视时间 | ↓40-59% vs GR00T | | |

## 关键洞察

1. **空间记忆 > 视角调整**：仅扫描+无记忆（Scan+GR00T）最差，说明持久记忆是关键
2. **动态更新至关重要**：移除动态更新导致最大性能下降（49.3%→41.5%）
3. **行为质变**：SOMA 不仅提高成功率，还改变了操作行为模式——更快定位、更少搜索、接近一次性抓取

## 对 Spatial AGI 的意义

- **空间记忆是具身智能的基础能力**：SOMA 证明了持久空间表示对超越即时感知的推理至关重要
- **VLA + 空间记忆的融合范式**：将空间理解与动作生成统一在同一框架中
- **朝向空间 AGI 的关键一步**：从反应式感知到记忆引导操作的范式转变

## 局限性

- 依赖预定义扫描轨迹（非自适应探索）
- 短时距扫描假设（长时间操作中位姿漂移可能成为问题）
- 仅在桌面操作场景验证，大规模场景泛化性未验证
