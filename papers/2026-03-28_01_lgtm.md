## 论文概述

### 核心贡献

LGTM (Less Gaussians, Texture More) 是第一个前馈网络预测纹理化高斯 splatting 的方法。该方法解决了现有前馈 3DGS 方法在高分辨率渲染时面临的根本性挑战：

**主要问题**：
- 现有前馈 3DGS 方法预测像素对齐的基元（primitives）
- 基元数量随分辨率呈二次增长（例如从 512 到 4K 需要 64 倍的高斯）
- 在 2K 及以上分辨率时，网络预测和渲染变得计算和内存上不可行

**LGTM 的解决方案**：
- 通过预测紧凑的高斯基元配合每个基元的纹理
- 解耦几何复杂度与渲染分辨率
- 实现无需逐场景优化的 4K 新视角合成
- 使用显著更少的高斯基元

### 性能亮点

| 指标 | 结果 |
|------|------|
| **最大分辨率** | 4K (4096×2304) |
| **内存效率** | 64× 像素增加仅需 1.80× 内存，1.47× 时间 |
| **基元数量** | 512×288（与 1K 输出相同） |
| **LPIPS 提升** | 相比基线提升 23%-75% |
| **训练内存** | < 30 GB（单卡可训练） |

## Q1: 核心算法原理

### 1. 核心思想和动机

#### 1.1 问题背景

**现有方法的困境**：

传统前馈 3D Gaussian Splatting 方法面临一个根本性矛盾：

```
分辨率 ↑ → 基元数量 ↑↑ → 计算成本 ↑↑↑ → 不可行
```

**具体数据**：
- NoPoSplat 在 1024×576 分辨率下，训练内存已达 61.85 GB
- 在 2K 和 4K 分辨率下，训练直接因内存不足而失败（OOM）

**根本原因**：
1. **像素对齐策略**：每个输出像素对应一个高斯基元
2. **外观-几何耦合**：每个高斯仅编码单一颜色（含视角相关），难以表示高频纹理
3. **二次增长**：基元数量与图像分辨率呈二次关系

#### 1.2 核心洞察

LGTM 的核心洞察来源于对自然场景的观察：

**频率分离假设**：
```
自然场景 = 低频几何 + 高频外观
```

- **几何**：相对低频（大尺度结构）
- **外观/纹理**：相对高频（细节、图案）

**解耦策略**：
```
紧凑基元（低分辨率） + 丰富纹理（高分辨率） = 高质量渲染
```

#### 1.3 设计哲学

**Less Gaussians, Texture More** 的含义：

1. **Less Gaussians**：
   - 使用更少的高斯基元
   - 几何信息在低分辨率预测
   - 不随渲染分辨率增长

2. **Texture More**：
   - 每个基元配备独立纹理图
   - 纹理分辨率可调节
   - 承载高频外观细节

**类比**：
```
传统3DGS：每个像素一个基元 → 就像用小砖块铺路
LGTM：大砖块（基元）+ 砖块上的花纹（纹理）→ 更高效
```

### 2. 主要技术方法

#### 2.1 双网络架构

LGTM 采用解耦的双网络架构：

```
┌─────────────────────────────────────────┐
│         输入: {I^v} (高分辨率)          │
│             {I^v_low} (低分辨率)        │
└────────────┬────────────────────────────┘
             │
        ┌────┴─────┐
        │          │
   ┌────▼───┐ ┌───▼────┐
   │ f_prim │ │f_texture│  ← 双网络
   └────┬───┘ └───┬────┘
        │          │
        │   ┌──────┘
        │   │
   ┌────▼───▼────┐
   │  融合预测   │
   └─────┬───────┘
         │
   ┌─────▼───────────────────────┐
   │ 输出: {μ, s, r, c, T^c, T^α}│
   └──────────────────────────────┘
```

**网络 1: Primitive Network (f_prim)**

功能：预测几何基元

```python
f_prim: I^v_low → {F^v_prim, μ_i, s_i, r_i, o_i, c_i}
```

参数说明：
- `I^v_low` ∈ ℝ^(h×w×3)：低分辨率输入图像
- `F^v_prim`：ViT 解码器特征图（共享给 texture network）
- `μ_i`：高斯基元中心位置
- `s_i`：尺度参数
- `r_i`：旋转参数
- `o_i`：不透明度
- `c_i`：球谐（SH）基础颜色

**网络 2: Texture Network (f_texture)**

功能：预测每个基元的纹理图

```python
f_texture: (I^v, F^v_prim) → {T^c_i, T^α_i}
```

参数说明：
- `I^v` ∈ ℝ^(H×W×3)：高分辨率输入图像
- `T^c_i` ∈ ℝ^(T×T×3)：颜色纹理图
- `T^α_i` ∈ ℝ^(T×T)：alpha 纹理图
- `T`：纹理分辨率（可调节，如 2×2, 4×4, 8×8）

#### 2.2 2D Gaussian Splatting 基础

LGTM 基于 2DGS（Huang et al., 2024）构建：

**2D 高斯表示**：
- 在 3D 空间中表示场景的 2D 高斯基元集合
- 每个基元是一个朝向任意的椭圆盘

**渲染过程**：

1. **射线-基元相交**：
   ```
   对于像素 x=(x,y)，计算相机射线与基元 i 的交点
   u = M_{i,v}(x)  // 2D单应性变换
   ```
   其中 `u=(u,v)` 是基元局部坐标

2. **高斯函数评估**：
   ```
   G(u) = exp(-1/2 * (u² + v²))
   ```

3. **Alpha 和颜色计算（传统 2DGS）**：
   ```
   a_i(u) = o_i · G(u)
   ĉ_i(d_i) = SH(c_i, d_i)  // 球谐颜色，d_i 为视角方向
   ```

4. **Alpha 混合**：
   ```
   C = Σ_i a_i(u_i) ĉ_i(d_i) Π_{j=1}^{i-1} (1 - a_j(u_j))
   ```
   按深度排序后混合

#### 2.3 纹理化高斯扩展

LGTM 扩展了传统 2DGS，为每个基元添加可学习纹理：

**纹理类型**：
1. **颜色纹理** `T^c_i` ∈ ℝ^(T×T×3)：提供高频颜色细节
2. **Alpha 纹理** `T^α_i` ∈ ℝ^(T×T)：替代高斯衰减

**纹理采样（双线性插值）**：

```python
def bilinear_sample(T, T_size, u, v, σ):
    """
    T: 纹理图
    T_size: 纹理分辨率
    u, v: 局部坐标
    σ: 纹理区域范围（共享超参数）
    """
    # 转换到像素坐标
    u = (u + σ) / (2*σ) * T_size - 0.5
    v = (v + σ) / (2*σ) * T_size - 0.5
    
    # 边界裁剪（border clamping）
    u = clamp(u, 0, T_size - 1)
    v = clamp(v, 0, T_size - 1)
    
    # 双线性插值
    i_u, f_u = floor(u), u - floor(u)
    i_v, f_v = floor(v), v - floor(v)
    
    return (1-f_u)*(1-f_v)*T[i_u, i_v] + \
           f_u*(1-f_v)*T[i_u+1, i_v] + \
           (1-f_u)*f_v*T[i_u, i_v+1] + \
           f_u*f_v*T[i_u+1, i_v+1]
```

**无界采样策略**：
- 与 BBSplat 的有界采样不同
- 采用 border clamping 而非 zero-padding
- 允许纹理信息延伸到基元边界之外
- 提供更平滑的过渡和更好的覆盖

**纹理化渲染公式**：

```
a_i(u) = o_i · T^α_i[u]
ĉ_i(u, d_i) = T^c_i[u] + SH(c_i, d_i)
```

关键改进：
- **Alpha 纹理**替代高斯衰减 `G(u)`
- **颜色纹理**作为基础颜色的补充，零初始化后学习高频细节

#### 2.4 学习式投影纹理

**核心思想**：从高分辨率源图像反向投影纹理到基元

**投影先验纹理计算**：

```python
def compute_projective_prior(I^v, M_{i,v}^(-1), u):
    """
    I^v: 高分辨率源图像
    M_{i,v}^(-1): 逆单应性变换（基元局部 → 图像像素）
    u: 基元局部坐标
    """
    # 逆变换：从基元局部坐标到图像像素坐标
    x = M_{i,v}^(-1)(u)
    
    # 从源图像采样 RGB 颜色
    T^{c,proj}_i[u] = I^v[x]
    
    return T^{c,proj}_i
```

**直观理解**：
```
传统渲染：基元 → 图像（正向）
投影纹理：图像 → 基元（反向）
```

**优势**：
1. **高效**：4K 图像只需几毫秒
2. **高频细节**：直接从源图像提取
3. **强先验**：为纹理预测提供强特征

**特征提取流程**：

```
高分辨率图像 I^v
    ↓
图像 patchify + 卷积 → F^v_patch  (局部特征)
    ↓
投影纹理 T^{c,proj}
    ↓
特征提取网络 → F^v_proj  (高频纹理特征)
    ↓
与 F^v_prim 融合
    ↓
预测最终纹理 {T^c, T^α}
```

#### 2.5 训练策略

**两阶段渐进式训练**：

**阶段 1: 几何预训练**

目标：建立稳健的几何基础

```python
# 仅训练 primitive network
f_prim: I^v_low → {F^v_prim, μ, s, r, o, c}

# 关键：低分辨率输入，高分辨率监督
input_resolution = h × w  # 如 512×288
supervision_resolution = H × W  # 如 4096×2304
```

**高分辨率监督的作用**：
1. 强制网络学习适当的尺度参数 `s`
2. 避免渲染时出现孔洞（anti-aliasing 问题）
3. 建立强几何先验

**为什么低分输入高分监督可行？**
- 高斯基元可以在任意分辨率渲染
- 但没有高分监督，网络可能预测过小的尺度
- 高分监督确保基元覆盖足够区域

**阶段 2: 联合训练**

目标：引入纹理细节

```python
# 联合训练两个网络
f_prim + f_texture

# 保持几何稳定
learning_rate(f_prim) = 0.1 × base_lr

# 颜色纹理零初始化
T^c ← zeros()  # 逐渐学习高频细节
```

**损失函数**：

```
L = L_MSE + λ * L_LPIPS
```

标准光度损失（MSE + 感知损失）

**训练稳定性技巧**：
1. 预训练 primitive network 降低学习率
2. 纹理零初始化，逐步添加细节
3. 保持几何参数稳定

### 3. 算法流程和关键步骤

#### 3.1 完整算法流程

```
算法：LGTM Feed-Forward Textured Gaussian Splatting

输入：
  - 高分辨率图像 {I^v}_{v=1}^N
  - 低分辨率图像 {I^v_low}_{v=1}^N
  - 可选：相机位姿

输出：
  - 纹理化高斯基元集合 {μ_i, s_i, r_i, c_i, T^c_i, T^α_i}

步骤：

1. 【几何预测】Primitive Network
   输入: I^v_low ∈ ℝ^(h×w×3)
   处理: ViT encoder-decoder
   输出: {F^v_prim, μ_i, s_i, r_i, o_i, c_i}
   基元数量: h × w

2. 【特征提取】Texture Network - 特征分支
   2a. 图像 patchify 特征
       输入: I^v ∈ ℝ^(H×W×3)
       处理: patchify + CNN
       输出: F^v_patch
   
   2b. 投影纹理特征
       for each primitive i:
         计算投影先验 T^{c,proj}_i
         提取特征 F^v_proj
   
   2c. 几何特征
       从阶段 1 复用 F^v_prim

3. 【纹理预测】Texture Network - 融合与预测
   输入: {F^v_prim, F^v_patch, F^v_proj}
   处理: 特征融合网络
   输出: {T^c_i, T^α_i} for each primitive i
   纹理分辨率: T×T (可调节)

4. 【渲染】Textured 2D Gaussian Splatting
   for each pixel x in target view:
     for each visible primitive i:
       计算射线-基元交点 u = M_{i,v}(x)
       采样纹理:
         a_i = o_i * T^α_i[u]
         ĉ_i = T^c_i[u] + SH(c_i, d_i)
     按深度排序
     Alpha 混合得到最终颜色

5. 【监督】（训练阶段）
   计算损失: L = ||C_pred - C_gt||² + λ*LPIPS(C_pred, C_gt)
   反向传播更新网络参数
```

#### 3.2 关键技术步骤详解

**步骤 1 的关键：高分辨率监督**

```
传统做法：
  输入分辨率 = 输出分辨率 = 训练监督分辨率
  问题：高分辨率 → 训练不可行

LGTM 做法：
  输入分辨率：512×288（低）
  基元数量：512×288（低）
  渲染分辨率：4096×2304（高）
  监督分辨率：4096×2304（高）

优势：
  - 网络计算量低（低分输入）
  - 基元数量少（低分基元）
  - 渲染质量高（高分纹理）
```

**步骤 2b 的关键：投影映射**

```
投影变换 M_{i,v} 的计算：

给定：
  - 相机内参 K_v，外参 [R_v | t_v]
  - 基元位置 μ_i，法向量 n_i

计算单应性矩阵：
  H_{i,v} = K_v · [R_v | t_v] · [μ_i | n_i]^(-1)

正向变换（渲染）：u = M_{i,v}(x) = H_{i,v} · [x, 1]^T
逆向变换（投影）：x = M_{i,v}^(-1)(u) = H_{i,v}^(-1) · [u, 1]^T
```

**步骤 4 的关键：纹理化渲染与传统渲染对比**

| 方面 | 传统 2DGS | LGTM 纹理化 |
|------|-----------|-------------|
| **Alpha** | `o_i · G(u)` | `o_i · T^α_i[u]` |
| **颜色** | `SH(c_i, d_i)` | `T^c_i[u] + SH(c_i, d_i)` |
| **细节表示** | 需要更多基元 | 纹理图承载 |
| **可扩展性** | 差（二次增长） | 好（线性增长） |

#### 3.3 可扩展性分析

**为什么 LGTM 可扩展到 4K？**

1. **几何复杂度固定**：
   ```
   基元数量 = h × w（固定，如 512×288）
   不随渲染分辨率 H×W 变化
   ```

2. **纹理复杂度可控**：
   ```
   每基元纹理大小 = T×T（可调节）
   总纹理大小 = (h×w) × (T×T)
   
   例：512×288 基元，8×8 纹理
   总纹理像素 = 147,456 × 64 = 9,437,184
   对应输出：4096×2304 = 9,437,184
   ```

3. **内存和计算增长**：
   ```
   从 512×288 到 4096×2304（64× 像素）
   
   传统方法：
   - 基元数量：64×
   - 内存：> 64×（实际 OOM）
   - 时间：> 64×
   
   LGTM：
   - 基元数量：1×（不变）
   - 纹理大小：64×
   - 内存：1.80×
   - 时间：1.47×
   ```

### 4. 输入输出

#### 4.1 输入

**必需输入**：

1. **高分辨率图像集合** `{I^v}_{v=1}^N`
   - 分辨率：H×W（如 4096×2304）
   - 数量 N：可变
     - 单视图：N=1（Flash3D baseline）
     - 双视图：N=2（NoPoSplat, DepthSplat）
     - 多视图：N>2（VGGT baseline）

2. **低分辨率图像集合** `{I^v_low}_{v=1}^N`
   - 分辨率：h×w（如 512×288）
   - 由高分图像下采样得到
   - 用于 primitive network

**可选输入**：

3. **相机位姿**（取决于 baseline）
   - 有位姿方法：DepthSplat
   - 无位姿方法：NoPoSplat, Flash3D
   - LGTM 框架兼容两种设置

#### 4.2 输出

**中间输出**（网络预测）：

1. **几何参数**（每个基元）：
   ```
   {μ_i, s_i, r_i, o_i, c_i} for i = 1, ..., h×w
   ```
   - `μ_i` ∈ ℝ³：基元中心位置
   - `s_i` ∈ ℝ²：尺度参数（椭圆的两个轴）
   - `r_i` ∈ SO(3)：旋转（四元数或旋转矩阵）
   - `o_i` ∈ [0,1]：基础不透明度
   - `c_i` ∈ ℝ^(k×3)：球谐系数（k 为 SH 阶数）

2. **纹理参数**（每个基元）：
   ```
   {T^c_i, T^α_i} for i = 1, ..., h×w
   ```
   - `T^c_i` ∈ ℝ^(T×T×3)：颜色纹理图
   - `T^α_i` ∈ ℝ^(T×T)：alpha 纹理图

**最终输出**：

3. **任意视角渲染图像**：
   ```
   I^target ∈ ℝ^(H_target × W_target × 3)
   ```
   - 可在任意目标分辨率渲染
   - 可在任意相机位姿渲染
   - 实时渲染（高斯 splatting 的优势）

**额外能力**：

4. **深度图**（可选）：
   ```
   D^target ∈ ℝ^(H_target × W_target)
   ```
   从高斯混合的深度分布提取

5. **3D 场景表示**：
   - 纹理化 2D 高斯基元集合
   - 显式表示，便于编辑和操作

## Q2: 与Spatial AGI的关系

### 1. 如何理解和表示空间

#### 1.1 空间表示方式

LGTM 采用**混合显式-隐式**的空间表示：

**显式部分**：2D 高斯基元
```
空间 = {primitive_i} for i = 1, ..., N

每个 primitive:
  - 位置 μ_i ∈ ℝ³
  - 朝向 n_i ∈ S²
  - 尺寸 s_i ∈ ℝ²
  - 纹理 T_i ∈ ℝ^(T×T×C)
```

**隐式部分**：神经网络编码
```
primitive parameters = f_network(I^v)

网络隐式编码了：
  - 场景先验知识
  - 多视图一致性约束
  - 物理合理性
```

#### 1.2 与 Spatial AGI 的关系

**Spatial AGI 的空间理解要求**：

1. **几何理解**：物体/场景的 3D 结构
   - LGTM：通过高斯基元的位置和朝向表示
   - 支持多尺度几何（基元可大可小）

2. **外观理解**：纹理、颜色、材质
   - LGTM：通过纹理图表示
   - 解耦几何和外观，更灵活

3. **语义理解**：物体类别、场景语义
   - LGTM：当前不直接支持
   - 但显式表示便于后续语义分析

4. **动态理解**：运动、变化
   - LGTM：静态场景方法
   - 可扩展到动态（为每帧预测基元）

**对 Spatial AGI 的贡献**：

```
传统 NeRF：
  空间 → 隐式神经场
  优点：表示能力强
  缺点：难以编辑、理解

传统 3DGS：
  空间 → 大量小基元
  优点：实时渲染
  缺点：基元数量爆炸、难扩展

LGTM：
  空间 → 紧凑基元 + 纹理
  优点：
    ✓ 实时渲染（继承 3DGS）
    ✓ 可扩展到高分辨率
    ✓ 显式表示（便于理解和操作）
    ✓ 前馈泛化（无需优化）
```

#### 1.3 多尺度空间表示

LGTM 自然支持多尺度表示：

**尺度 1：基元级别**
```
单个基元 = 局部几何 + 局部纹理

```

**尺度 2：基元组合**
```

通过基元的空间组织表示
```

**尺度 3：场景级别**

- 几何和外观可以解耦处理
- 显式表示更便于跨尺度推理

### 2. 如何处理空间关系

#### 2.1 空间关系的类型

**1. 拓扑关系**（topological）

- 相邻、包含、重叠
- LGTM 表示：
  ```
  相邻基元在空间中位置相近
  通过基元中心的 k-NN 可分析邻接关系
  ```

**2. 度量关系**（metric）

- 距离、角度、尺度
- LGTM 表示：
  ```
  基元中心 μ_i 显式编码位置
  可直接计算欧氏距离、角度等
  ```

**3. 方向关系**（directional）

- 上/下、前/后、左/右
- LGTM 表示：
  ```
  基元朝向 n_i 编码方向
  通过 n_i 的相对方向判断
  ```

**4. 视角关系**（view-dependent）

- 可见性、遮挡
- LGTM 表示：
  ```
  通过渲染过程中的深度排序处理
  alpha blending 自然处理遮挡
  ```

#### 2.2 空间关系处理机制

**机制 1：ViT 注意力机制**

```python
# Primitive network 使用 ViT encoder
features = ViT_encoder(I^v_low)

# 自注意力捕获：
# - 空间相邻像素的关系
# - 长距离依赖（通过多头注意力）
# - 场景全局结构
```

**机制 2：跨视图特征融合**

```python
# 多视图输入时
for view v in views:
    F^v = extract_features(I^v)

# 融合策略（取决于 baseline）
F_fused = aggregate({F^v})
```

**机制 3：投影几何约束**

```python
# 投影纹理提供强几何约束
for primitive i:
    for view v:
        if visible(i, v):
            # 投影一致性
            T^proj_i[v] = project(I^v, i)
```

**机制 4：深度排序**

```python
# 渲染时处理遮挡关系
primitives_sorted = sort_by_depth(primitives, camera)
for primitive i in primitives_sorted:
    accumulate_color_and_alpha(i)
```

```
外观：
  - 高频信息
  - 丰富表示（纹理）
  - 高分辨率预测
```

   ```
   - 刚性 vs 非刚性
   - 语义 vs 几何

   ```

2. **频率分离**：

#### 1.1 技术创新

**创新 1：首个前馈纹理化高斯方法**

```
历史背景：
  2023: 3DGS（Kerbl et al.）→ 需要优化
  2024: Textured 3DGS（多篇）→ 仍需优化

突破性：
  ✓ 首次将两者结合
  ✓ 无需逐场景优化
  ✓ 泛化到新场景
```

**创新 2：双网络解耦架构**

```
传统：单一网络预测所有参数
  问题：几何和外观耦合，难以优化

LGTM：双网络解耦
  primitive network：几何（低分）
  texture network：外观（高分）
  
优势：
  ✓ 各自最优分辨率
  ✓ 独立训练策略
  ✓ 更好的泛化
```

**创新 3：分辨率解耦策略**

```
传统：输入分辨率 = 输出分辨率
  限制：高分辨率 → 计算爆炸

LGTM：输入低分，输出高分
  输入：512×288
  输出：4096×2304
  
关键：纹理承载高频细节
  几何：低频（低分足够）
  纹理：高频（高分必要）
```

```
传统纹理映射：
  - 手工 UV 展开

LGTM 投影纹理：

创新点：

  ✓ 高频细节强
```

```
纹理分辨率 T 可调：
  T = 2×2: 快，低质量
  T = 4×4: 平衡
  T = 8×8: 慢，高质量

应用：
  - 预览：低 T
  - 最终输出：高 T
  - 自适应：根据设备/网络
```

**创新 8：打破分辨率限制**

```
历史最高：
```

### 2. 局限性分析

#### 2.1 几何依赖性

**局限 1：依赖基线方法的几何质量**

```

  DepthSplat (有位姿双视图) + LGTM: 较好
  VGGT (多视图) + LGTM: 提升有限

原因分析：
  单视图：
    - Flash3D 几何虽不完美，但一致性高
    - 多视图不一致性不存在
```

## 技术细节

### 高分辨率重训练的必要性

**问题**：直接渲染低分辨率训练的模型在高分辨率下会出现孔洞

**三种策略对比**：

```
1. Direct Render:
   直接高分渲染低分模型
   结果：孔洞（anti-aliasing 问题）
   
2. Render and Upsample:
   低分渲染 + 图像上采样
   结果：无孔洞，但模糊
   
3. High-Resolution Re-train:
   高分辨率监督训练
   结果：最佳，无孔洞且清晰
```

**原因分析**：

```
Anti-aliasing in 3DGS:
  - 高斯基元在低分辨率下覆盖足够像素
  - 但在高分辨率下可能只覆盖部分像素
  - 导致孔洞

High-res supervision:
  - 强制网络学习适当的尺度 s
  - 确保基元覆盖足够区域
  - 无孔洞
```

### 双线性纹理采样的细节

**无界采样 vs 有界采样**：

```
BBSplat (有界):
  T^c[u] = I[x] if |u| ≤ σ
         = 0      otherwise
  
  问题：颜色从中心衰减

LGTM (无界):
  u' = clamp((u+σ)/(2σ)·T - 0.5, 0, T-1)
  T^c[u] = bilinear_sample(T, u')
  
  优势：
    - Border clamping 而非 zero-padding
    - 纹理可延伸到边界外
    - 更平滑的过渡
```

**实现细节**：

```python
def unbounded_bilinear_sample(T, T_size, u, v, σ=1.0):
    """
    T: 纹理图 [T_size, T_size, C]
    u, v: 局部坐标（可超出 [-σ, σ]）
    σ: 纹理区域范围
    """
    # 归一化到 [0, T_size-1]
    u = (u + σ) / (2 * σ) * T_size - 0.5
    v = (v + σ) / (2 * σ) * T_size - 0.5
    
    # Border clamping
    u = torch.clamp(u, 0, T_size - 1)
    v = torch.clamp(v, 0, T_size - 1)
    
    # 双线性插值
    u0, v0 = torch.floor(u).long(), torch.floor(v).long()
    u1, v1 = torch.min(u0 + 1, T_size - 1), torch.min(v0 + 1, T_size - 1)
    
    fu, fv = u - u0, v - v0
    
    # 四角加权
    w00 = (1 - fu) * (1 - fv)
    w10 = fu * (1 - fv)
    w01 = (1 - fu) * fv
    w11 = fu * fv
    
    # 采样
    return w00 * T[u0, v0] + w10 * T[u1, v0] + \
           w01 * T[u0, v1] + w11 * T[u1, v1]
```
