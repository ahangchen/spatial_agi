# VideoWeaver: Multimodal Multi-View Video-to-Video Transfer

**arXiv**: 2603.25420  
**Date**: 2026-03-26  
**Category**: Video Translation / Embodied AI  
**Tags**: #MultiView #V2V #4D #RobotLearning

---

## TL;DR

VideoWeaver 是**首个多视角视频到视频翻译框架**，通过将所有视角对齐到 Pi3 提取的共享 4D 点云潜空间，实现跨视角一致的 style transfer，支持自回归生成新视角，特别适用于具身 AI 的数据增强。

---

## 核心问题

**单视角 V2V 的问题**：
- 独立处理每个相机 → 视角间外观不一致
- 标准注意力 → O(V²) 计算爆炸

**具身 AI 的需求**：
- 多相机设置（egocentric + third-person）
- 领域随机化保留动作轨迹

---

## 核心创新

### 1. 共享 4D 潜空间

**关键洞察**：
> "在 2D 图像空间保持一致性 → 在底层 3D 世界保持一致性"

```
所有视角的帧 → Pi3 → 全局 4D 点云 (x,y,z,t)
                     ↓
              注入 Flow 模型潜空间
```

### 2. Mixture-of-Experts 多模态融合

```python
# 自适应融合深度和素描
c^τ = α^τ · E_s(f_s) + (1-α^τ) · E_d(f_d)

# α 由当前潜状态动态预测
α = Gate(x^τ, f_s, f_d, τ)
```

**动机**：
- 深度：可靠几何，但细小物体信息少
- 素描：稳定形状，但边缘模糊/重叠

### 3. 分解 4D 注意力

```
标准 DiT 块 → 视角内注意力 (T×H×W)
           → 跨视角注意力 (V×H×W)
```

- 视角内：时空 tokens
- 跨视角：同帧跨相机 tokens

### 4. 自回归视角生成

**问题**：模型原生只支持 3 视角，如何扩展到 K>3？

**解决方案**：训练时使用**不同时间步**

```python
# 常规路径：(0,0,0) → (1,1,1)
# 自回归路径：(1,0,0) → (1,1,1)  # 视角1 clean，其他 denoise
#            (0,1,1) → (1,1,1)  # 视角2,3 clean
```

**推理**：
1. 生成标准 3 视角
2. 用已生成视角作为条件，自回归生成剩余视角

## 技术细节

### Pi3 点云注入

```
1. Pi3 预测：每像素 3D 点
2. 分块：8×8 patches (匹配 VAE 下采样)
3. 深度感知池化：保留最近点（前景/接触区域）
4. 时间下采样：每 8 帧 → 1 点云
5. MLP 编码 → 加到噪声潜变量
```

### 损失函数

**主损失**：Rectified Flow
$$\mathcal{L} = \mathbb{E}[\|v_\theta(x^\tau, y, \tau) - (x - x^0)\|^2]$$

**小波一致性损失**：
$$\mathcal{L}_{wavelet} = \|W(\hat{x}^1) - W(x)\|_1$$

强化高频空间结构

### 训练细节

- **均匀时间步采样**：而非传统的中程过采样
- **相机姿态多样性**：增强 egocentric 配置
- **损失掩码**：clean 视角无梯度

## 实验

### 单视角 V2V Benchmark

| 方法 | Agibot | Droid | Bridge |
|------|--------|-------|--------|
| VACE | 0.72 | 0.68 | 0.75 |
| Cosmos-Transfer | 0.75 | 0.71 | 0.78 |
| **VideoWeaver** | **0.81** | **0.77** | **0.82** |

### 多视角一致性

| 方法 | 视角一致性 | 风格一致性 |
|------|-----------|-----------|
| Independent | 0.45 | 0.62 |
| + Cross-Attention | 0.58 | 0.71 |
| + Camera Rays | 0.63 | 0.74 |
| **+ 4D Points (Ours)** | **0.89** | **0.91** |
