## 论文概述（摘要翻译）

大多数面向未来预测的世界模型优先追求生成视频的美学质量，但由于缺乏显式 4D 建模，只能提供较弱的物理落地性和有限的时序几何一致性。本文提出 Plan4D，迈向"生成式可规划 4D 世界模型"的下一个里程碑：从观测场景上下文和文本指定的动作出发，同时预测未来 RGB 视频与稠密 4D 几何，包括深度、相机、点云和场景流。由于"动作+稠密 4D 标注"配对的训练数据天然稀缺，Plan4D 利用基础视频生成器与 3D 重建器的互补先验。具体地，提出模型缝合（model-stitching）架构，将 Depth Anything 3 与 LongCat-Video 耦合，并增补一个辅助 DPT 头做场景流预测。所得模型可以在动态 3D 场景中规划并生成复杂、长时程、细粒度的动作，同时显著提升未来视频的视觉保真度与几何准确性。在合成与真实数据集上的大量实验表明，Plan4D 在环境反应的生成式 4D 建模上达到 SOTA。

## 研究背景与动机

### 任务定义：生成式可规划 4D 世界

给定观测上下文 O = {I_i}（一组观测图像）和规划动作空间 A（文本动作描述序列 p），学习一个生成式可规划 4D 世界模型 f_θ：

f_θ: {O, A} → {I_t, D_t, r_t, V_t} (t=1..T)

输出四类量：

- **RGB 帧序列 I_t**：视觉外观演化；
- **稠密深度图 D_t**：每帧像素级深度；
- **相机光线图 r_t**：每像素相机原点+方向（可重建场景点云）；
- **4D 场景流 V_t**：每像素从 t 到 t+1 的 3D 前向运动。

为什么这四样缺一不可？论文的论点非常清晰：**人类和 AI 智能体要执行复杂、长时程、细粒度的动作（拿起杯子、开瓶子、穿越凌乱房间），必须在显式 3D 环境中规划**。纯 RGB 世界模型（UniSim、Genie 1-3、NWM、V-JEPA 2）本质是逐帧外观合成，没有可供规划器读取的空间量——无法测量、无法可靠仿真、无法精确执行。

### 数据瓶颈

任务的最大障碍是数据：需要"动作条件视频 + 丰富文本 + 完整 3D 标注（相机轨迹、稠密深度、运动）"三合一的数据集。

- 大规模视频-文本数据集：缺少细粒度物理动作标注；
- Action-100M：动作标注详细，但没有 3D 标注；
- 动态 3D 数据集：规模小或缺少自然动作。

三类数据源各自催生了强大的孤立系统：视频生成器（视觉逼真但物理不一致）、动作条件世界模型、3D 重建器（几何好但以重建为中心、偏静态）。即使是先进的 4D 框架（Aether、4DNeX、TesserAct 等）也只是从观测帧推断运动，无法生成动作条件的未来世界。

### 核心洞察：缝合而非从零训练

论文的关键设问：**既然这些不同数据源训练出的模型都在建模同一个底层 4D 世界，为什么不把它们缝合在一起？**

核心策略是解耦与重连：

- 解耦：强几何先验的获取（冻结的 3D 基础模型）与未来动力学的生成（预训练视频生成器）分开；
- 重连：通过缝合的潜在世界模型（stitched latent world model）联合规划 RGB 外观与稠密 4D 几何。

这大幅降低了学习难度和数据需求，不必像从零训练 4D 世界模型的方法那样极度 hungry for data。

## 核心问题

### Q1: 核心算法原理

**问题**: 这篇文章的核心算法原理是什么？

**分析**:

1. **核心思想和动机**

   动机链条：可规划的智能体需要显式几何 → 但 4D 标注数据稀缺 → 而"视频生成先验"和"3D 重建先验"分别在大规模数据上学到了世界的一半真相 → 把两者缝合，让一条视频 latent 轨迹同时承载外观与 4D 几何的解码。Plan4D 不把几何当作辅助约束，也不在 RGB 生成后才解码几何，而是**在共享的演化视频 latent 状态内部显式对齐未来外观与 4D 结构**。

2. **主要技术方法**

   **(a) 增强 DA3 做动态场景流预测（3.1节）**

   - 物理世界不是独立逐帧几何的集合，运动/对应关系是 4D 世界的本质；
   - 给 Depth Anything 3 增加稠密场景流头：沿用原 DPT 风格解码器，摄入冻结编码器的四个中间 token 图，经轻量预测层输出三通道稠密运动场；
   - 原 encoder、深度分支、相机位姿分支全部不动，只加运动分支；
   - 附录分析显示：冻结的 DA3 token 已经编码了跨帧运动线索，因此该分支只需轻量读取，不必是完整运动模型；
   - 表示设计：每帧 t 在像素格上存储 t→t+1 的前向 3D 位移；原始预测在帧 t 的局部相机基下产生，用轻量 adapter 映射到统一参考系：V_t^(0)(u,v) = R_{t→0} · V_t^(cam)(u,v)。只施加旋转，因为场景流是向量而非 3D 点。空间索引保持帧局部、运动向量表达在时序稳定基下——相机运动下动力学保持一致，且与 DA3 的深度/光线/点云几何自然对齐。

   **(b) Latent-to-Geometry 模型缝合（3.2节）**

   - 视频 clip 经 Wan 2.1 VAE 编码为 latent z_0^{1:T}；
   - 上采样到 DA3 所需的时空分辨率（Up_{(st,sh,sw)}）；
   - 可学习 3D 缝合模块 S_θ 将上采样 latent 映射进 DA3 某个 encoder block 的通道维度：h^(k) = S_θ(z̃_0^{1:T})；
   - S_θ 是紧凑时空投影，实现为 3D 卷积：时间核聚合相邻 latent 帧，空间步长把 VAE 网格对齐到 DA3 patch 网格；
   - 注入层不是拍脑袋选的：对配对 clip 集，从若干早期 encoder block 提取冻结 DA3 候选特征，对每个候选块 k 解正则线性拟合 (k*, θ_0) = argmin Σ‖S_θ(z̃) − g_i^(k)‖² + λ‖θ‖²，选择"从视频 VAE latent 线性可达性最好"的块；
   - 得到的缝合解码器提供从视频 latent 到完整 4D 几何的稳定、可微接口。

   **(c) 蒸馏 + 几何监督校准（3.3节）**

   - 缝合解码器用 token 蒸馏和几何监督训练校准；
   - 之后冻结，作为视频生成器的"可微几何评论家"（differentiable geometry critic）。

   **(d) 联合训练（3.4节）**

   - 视频生成器针对这个冻结几何接口训练；
   - 无 4D 标注的真实动作视频因此能同时监督视觉预测和物理落地的 4D 一致性——生成器被几何接口约束，几何错误会通过 critic 反传惩罚外观 latent；
   - 推理时：单个生成的 latent 未来经一次前向同时解码 RGB 帧与稠密 4D 几何。

3. **算法流程和关键步骤**

   训练：

   1) 阶段一：冻结 DA3 主干，训练场景流头 + 轻量 adapter（用带场景流标注的数据）；
   2) 阶段二：在配对数据上做线性可达性探测，选定注入块 k*，初始化缝合模块 S_θ；
   3) 阶段三：训练缝合模块（token 蒸馏对齐 DA3 特征 + 深度/相机/场景流几何监督），随后冻结；
   4) 阶段四：训练视频生成器，以冻结缝合解码器为几何 critic，在无标注动作视频上联合优化外观与几何一致性。

   推理：

   1) 输入观测上下文（图像）+ 文本动作序列；
   2) 视频生成器去噪产生 latent 轨迹；
   3) 缝合 DA3 解码器读同一 latent 状态，同步输出深度、相机光线、相机参数、点云、场景流；
   4) 光线图+深度 → 3D 点云；场景流 → 像素级 3D 运动 → 动态 4D 场景。

4. **输入输出**

   - 输入：观测场景上下文 O（图像集合）、文本动作描述序列；
   - 输出：未来 RGB 视频 + 逐帧深度图 + 相机光线图（→点云）+ 稠密前向场景流；
   - 中间表示：共享的演化视频 latent 轨迹（外观与几何的统一载体）。

## 相关工作定位

### 4D 世界模型

- **显式动力学路线**：ParticleFormer、PointWorld 预测粒子轨迹/点级运动，但运行在结构化 3D 状态空间，不生成丰富未来 4D；
- **4D 原生生成路线**：Aether（动态重建/视觉规划/图像到4D）、4DNeX、TesserAct、Robo4DGen（RGB-D 或几何感知场景生成）；GWM（高斯）、iMoWM（token 化）、Kinema4D（运动学驱动）；FantasyWorld、WorldReel、TeleWorld、HY-World 2.0、Lyra 2.0（视频生成+几何预测耦合）；
- 共同局限：要么偏显式几何预测，要么偏大规模生成仿真，很少把预训练几何基础模型的互补先验整合进视频生成的潜在动力学。

### 3D 重建与视频生成对齐

- 早期级联式：几何约束作用于生成输出而非内部生成状态；
- 重建引导扩散/蒸馏：GenFusion、VideoScene、Lyra；
- 特征/潜在空间对齐：Geometry Forcing（扩散中间特征对齐预训练几何表征）、Gen3R（几何与外观 latent 联合生成）、GLD（几何特征转多视角扩散 latent）；
- 模型缝合视角：VIST3A 将预训练视频 VAE 与 3D 网络在线性可匹配层连接；
- Plan4D 的位置：把视频扩散模型缝合到 3D 基础模型，使 RGB 合成与稠密 4D 几何从共享 latent rollout 联合优化与解码，并扩展到完整的动作条件 4D 世界生成。

### Q2: 与Spatial AGI的关系

**问题**: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**分析**:

1. **如何理解和表示空间**

   Plan4D 给出了目前最完整的"空间世界状态"参数化：外观（RGB）+ 度量几何（深度）+ 观测视角（相机光线）+ 动力学（场景流）。这四元组几乎覆盖了 Spatial AGI 感知-想象-规划闭环所需的全部空间信息：

   - 深度+光线 → 毫米级的空间度量与定位；
   - 场景流 → 物体级运动预测与碰撞规避；
   - RGB → 外观语义与材质识别；
   - 文本动作接口 → 语言到空间行为的映射。

   特别值得注意的设计是场景流的"帧局部索引 + 时序稳定基"表示：空间信息在感知坐标系（局部）与行动坐标系（全局稳定）之间的转换被显式建模——这正是任何空间智能体都绕不开的坐标系统一问题。

2. **如何处理空间关系**

   - 观测上下文 → latent 轨迹的演化承载了空间随时间的因果关系；
   - 动作以文本形式条件化 latent 演化，实现了"语言 → 空间动力学"的接口；
   - 4D 几何在解码端与外观共享同一 latent 状态，保证"看到的空间"与"度量的空间"永远同步——不会出现 RGB 说物体在那、深度说在别处的割裂。

3. **对Spatial AGI的启发**

   - **可规划性是空间智能的试金石**：论文直接点明世界模型的评价标准不应是视频好不好看，而是"人和智能体能否在生成的世界里规划并执行复杂动作"——这应该成为 Spatial AGI 世界模型的核心 benchmark 哲学；
   - **先验缝合 > 从零训练**：数据永远不够，把各数据源训练出的基础模型缝合起来覆盖同一世界的不同侧面，是数据稀缺条件下的务实范式；
   - **几何 critic 模式**：冻结的几何接口作为可微评论家约束生成器，这种"用一个模态的专家监督另一个模态的生成器"的模式可直接推广——用物理引擎 critic 约束世界模型、用地图 critic 约束导航想象；
   - **单一 latent 承载多模态解码**：空间智能的内部世界状态不必按模态分裂存储，一个统一状态、多个解码头即可。

4. **可以应用的Spatial AGI场景**

   - 机器人操作规划：在想象的 4D 世界里预演抓取/开瓶/倒水，读场景流和深度验证可行性；
   - 具身导航：文本指令"穿过凌乱的房间" → 生成未来几何 → 规划器在点云上寻路；
   - AR/VR 内容生成：文字描述直接生成可交互的动态 3D 内容；
   - 驾驶仿真：动作（变道、超车）条件的世界演化 + 完整几何，供下游规划器训练；
   - 数据引擎：生成的 4D 世界反哺策略训练，缓解真实机器人数据的稀缺。

### Q3: 创新点和局限性

**问题**: 这个方法的主要创新点和局限性是什么？

**分析**:

1. **主要创新点**

   - **提出"生成式可规划 4D 世界"新范式**：把世界模型的目标从"好看的 RGB"升级为"外观+完整 4D 几何联合生成"，并论证其对可规划性的必要性；
   - **模型缝合架构**：不训新 4D 模型，而是把冻结的 DA3（3D 基础模型）与预训练 LongCat-Video（视频生成器）缝合——用线性可达性探测自动选择注入层，训练量与数据需求大幅降低；
   - **轻量场景流头**：发现冻结 DA3 token 已含跨帧运动线索，一个 DPT 式轻量头即可读出稠密场景流，且"帧局部索引+稳定基"表示与深度/相机/点云天然对齐；
   - **几何 critic 训练法**：缝合解码器冻结后作为可微几何评论家，让无 4D 标注的真实动作视频也能监督几何一致性；
   - **一次前向、多模态解码**：推理时单个 latent 轨迹前向输出 RGB+深度+相机+点云+场景流。

2. **主要局限性**

   - **动作接口是文本**：文本描述动作的精度有限，细粒度操作（毫秒级的力控、微调轨迹）难以用语言精确指定——距真正的机器人动作空间还有接口差距；
   - **依赖上游模型天花板**：几何保真度受 DA3 重建质量约束，外观质量受 LongCat-Video 约束，缝合无法超越两个基础模型的能力上限；
   - **场景流只有前向流**：t→t+1 单向定义，遮挡区域的对应、双向一致性检验缺失；
   - **动力学无显式物理约束**：4D 一致性靠几何 critic 的监督间接获得，并非内嵌物理定律，长时程仍可能漂移；
   - **生成 vs 重建的张力**：缝合解码器在生成内容（未见区域）上的几何预测依赖 DA3 的泛化，幻觉区域的几何可靠性存疑。

3. **与其他相关工作的对比**

   - vs **Aether/TesserAct 等 4D 原生生成**：它们从零学几何先验，数据饥渴；Plan4D 缝合现成先验，数据高效且几何更稳；
   - vs **Geometry Forcing/Gen3R**：它们对齐特征/latent 用于静态或场景级 3D 生成；Plan4D 面向动作条件的完整 4D 动态未来；
   - vs **VIST3A**：同为模型缝合，VIST3A 连接 VAE 与 3D 网络做静态对齐；Plan4D 缝合的是扩散生成器与 3D 基础模型，且服务于动态世界生成；
   - vs **PointWorld/ParticleFormer**：它们在结构化 3D 状态空间预测运动，不生成丰富未来 4D；Plan4D 生成完整的动态 4D；
   - vs **ScaleWorld（今日论文01）**：ScaleWorld 优化渲染效率（无显式几何），Plan4D 优化几何可规划性（计算更重）——两大路线的互补在前文已述。

## 核心技术发现

1. **冻结 3D 基础模型的 token 已隐含运动信息**：场景流可以只是轻量读取头，不需要完整运动模型——几何基础模型的表征比想象中"动态"；
2. **线性可达性探测决定缝合层**：latent 空间之间的"线性可映射性"是模型缝合成功的先决条件，可以量化、可以自动搜索；
3. **几何 critic 让无标注数据产生几何监督**：生成器被冻结几何接口约束后，普通动作视频也能训练出 4D 一致性；
4. **统一 latent 承载外观与几何**：两者在共享演化状态下同步解码，避免了跨模型解码的对齐难题。

## 与Spatial AGI的关系

### 直接贡献

提供了目前最接近"Spatial AGI 世界模型"完整形态的系统：语言可规划、几何可度量、动力学可预测、外观可渲染，四位一体。

### 技术启发

- "缝合先验"范式可推广为 Spatial AGI 的系统构建方法论：感知基础模型、生成基础模型、几何基础模型各自学各自的数据，最后缝合；
- 几何 critic 模式可推广为"跨模态专家监督"的一般训练技巧；
- 场景流的稳定基表示为空间智能的坐标系统一问题提供了具体范例。

### 应用场景

机器人操作预演、具身导航规划、AR/VR 动态内容生成、驾驶仿真、4D 数据引擎。

## 个人思考

### 最令人兴奋的发现

最令人兴奋的是范式层面的：**世界模型的价值尺度从"美学"转向"可规划性"**。这意味着世界模型不再是"生成视频的研究"，而是"构建可被智能体使用的虚拟物理世界的研究"。Plan4D 输出的深度+光线+场景流，本质上是把世界模型从"显示器"变成了"可测量的沙盘"。

模型缝合这个工程哲学也很打动我：与其哀叹 4D 数据稀缺，不如承认"视频模型懂外观、3D 模型懂几何、动作数据集懂行为"这个事实，然后把三块真相拼起来。线性可达性探测把"拼哪里"从玄学变成了可计算的搜索问题。

### 潜在局限

文本动作接口是理想与现实之间的妥协。真实的机器人动作是连续的、毫秒级的、涉及力反馈的，用语言描述"拿起杯子"粒度太粗。要成为真正的机器人世界模型，动作接口必须支持轨迹级条件。另外，缝合架构的天花板由上游模型钉死——DA3 在极端视角/透明物体/反光表面的深度误差会原样传递给生成的未来几何。

更深层的问题：几何 critic 约束的是"几何上自洽"，不是"物理上正确"。模型可以生成一个几何上完美但违反物理的未来（物体悬浮、穿模被场景流圆滑地解释）。真正物理落地的 4D 世界还需要物理引擎级别的约束或物理 loss（呼应今天论文03 的发现：世界模型尊重的是学到的先验而非视觉证据）。

### 与昨日研究的关联

延续 4D 世界建模主线的加速：从 HY-World 2.0（统一重建/生成/仿真）、Kinema4D（运动学驱动）到 Plan4D（先验缝合+可规划性）。趋势清晰：世界模型正在从"视频生成器"进化为"带度量几何的可规划环境"，这正是 Spatial AGI 路线图上"想象引擎"→"可交互世界"的关键一跃。项目页展示的手-物交互与场景级相机运动两类示例，恰好对应空间智能的两个尺度：操作尺度与导航尺度。

## 关键数据

- **架构**：LongCat-Video（Wan 2.1 VAE）+ Depth Anything 3（冻结）+ 场景流头 + latent-to-geometry 缝合模块（3D卷积）；
- **输出规格**：RGB 帧 I_t（H×W×3）、深度 D_t（H×W）、相机光线 r_t（H×W×6）、场景流 V_t（H×W×3）；
- **注入层选择**：候选早期 encoder block 上解正则线性拟合（公式2），选线性可达性最优块；
- **训练数据策略**：动作视频无 4D 标注，靠冻结几何 critic 提供几何监督；
- **会议**: NeurIPS 2026；合成与真实数据集上均达 SOTA（场景流、3D重建、动作条件视频预测三项）。

## 总结

### 核心发现总结

Plan4D 通过"冻结 3D 基础模型 + 预训练视频生成器"的模型缝合，实现了从观测与文本动作生成"RGB+深度+相机+点云+场景流"完整 4D 世界的能力，以线性可达性探测自动选择缝合层、以冻结几何 critic 让无标注动作视频产生几何监督，在生成式 4D 建模上达到 SOTA。

### 对Spatial AGI的意义

- 确立"可规划性"为空间世界模型的核心评价维度；
- 提供数据稀缺条件下构建完整空间世界模型的"先验缝合"方法论；
- 其输出四元组（外观/深度/视角/运动）可以直接作为 Spatial AGI 想象引擎的标准世界状态接口。

### A.3 Method 精读：问题形式化

- 输入：观测上下文 O={I_i}（M 张图）+ 动作空间 A（文本动作序列 p）；
- 映射：f_θ: {O,A} → {I_t, D_t, r_t, V_t}，t=1..T；
- 各输出维度：I_t∈R^{H×W×3}，D_t∈R^{H×W}，r_t∈R^{H×W×6}，V_t∈R^{H×W×3}；
- 光线图 r_t 编码每像素相机原点+方向 → 可重建场景点云；
- 场景流 V_t 编码每像素 t→t+1 的 3D 前向运动（脚注：只定义前向流，V_{t→t+1} 简写 V_t）；
- 实现选择：LongCat-Video（Wan 2.1 VAE）为视频生成器，Depth Anything 3（DA3）为 3D 重建器；
- 精读体会：这个形式化的意义在于把"世界模型输出"标准化成四元组——未来做 Spatial AGI 世界模型评测，可以按这四个通道分别打分再聚合。

### A.4 Method 精读：DA3 场景流增强（3.1节）

- 立论："物理世界不是独立逐帧几何的集合"——运动与对应关系是 4D 世界的本质属性；
- 结构：新 DPT 式头摄入冻结 encoder 的四个中间 token 图 → 轻量预测层 → 三通道稠密运动场；
- 冻结范围：encoder、深度分支、相机位姿分支全部不动，只加运动分支；
- 关键证据（附录A）：冻结 DA3 token 本身已编码跨帧运动线索 → 新头是轻量读取而非完整运动模型；
- 表示设计：
  - 每帧 t 的像素格上存 t→t+1 前向 3D 位移；
  - 原始预测在帧 t 局部相机基下 → adapter 映射到第一帧相机基：V_t^(0)(u,v)=R_{t→0}·V_t^(cam)(u,v)；
  - 只施加旋转：场景流是向量不是点，平移无意义；
  - 效果：空间索引帧局部 + 运动向量时序稳定基 → 相机运动下动力学一致、与深度/光线/点云自然对齐；
- 实证效果：相比无运动建模的缝合变体，在重建、相机、深度估计质量上一致提升（多种动态场景）——"看似微小的改动，实践效果显著"。

### A.5 Method 精读：Latent-to-Geometry 缝合（3.2节）

- 流程：clip → Wan 2.1 VAE latent z_0^{1:T} → 上采样 Up_{(st,sh,sw)} → z̃_0^{1:T}∈R^{(st·t)×(sh·h)×(sw·w)×C} → 缝合模块 S_θ → 注入 DA3 encoder block 通道维：h^(k)=S_θ(z̃_0^{1:T})；
- S_θ 实现：紧凑时空投影 = 3D 卷积，时间核聚合相邻 latent 帧，空间步长对齐 VAE 网格到 DA3 patch 网格；
- 注入层自动选择（公式2）：
  - 配对 clip 集上提取各候选早期 block k 的冻结 DA3 特征 g_i^(k)；
  - 解 argmin_k Σ‖S_θ(z̃)−g_i^(k)‖²+λ‖θ‖²；
  - 语义：选"从视频 VAE latent 线性可达性最好"的块（引 VIST3A 等的可达性思想）；
  - 副产品：稳定初始化 θ_0；
- 精读体会：把"两个 latent 空间能否对接"变成线性回归拟合误差这个可计算量，是缝合范式工程化的关键一步——任何想缝合两个基础模型的人都可以先跑这个廉价探测。

### A.6 Method 精读：训练与推理流程

- 缝合模块训练：token 蒸馏（对齐 DA3 特征）+ 几何监督（深度/相机/场景流）；
- 缝合模块随后冻结 → 成为可微几何评论家；
- 视频生成器训练：针对冻结几何接口，无标注动作视频同时监督视觉与 4D 一致性；
- 推理：单个生成 latent 未来 → 一次前向 → RGB + 稠密 4D 几何同步输出；
- 图2流水线复述：生成器产生去噪 latent 轨迹；缝合 DA3 解码器读同一 latent 状态恢复同步深度/相机光线/相机参数/点云/场景流；训练期解码器冻结当 critic，推理期从共享 latent 轨迹解码。

## 附录B：架构要素逐项分析

### B.1 为什么用"缝合"而不是微调融合？

- 微调融合会破坏两个基础模型各自的预训练先验（论文明确以"不破坏生成先验"为约束ii）；
- 缝合保持两侧冻结（除轻量头），先验零退化；
- 训练成本集中在小模块（场景流头、3D卷积缝合器），数据需求低；
- 代价：能力上限被两侧模型钉死。

### B.2 线性可达性探测的深层含义

- 两个预训练模型若在某个中间层存在近似线性映射关系，说明它们对世界的中间表征已高度同构——都在编码同一物理世界；
- 探测误差因此还可当作"基础模型间表征对齐度"的度量工具，可推广为模型选型标准；
- 这暗示：不同模态的基础模型可能正在收敛到相似的世界表征——对构建统一 Spatial AGI 内部表征是利好信号。

### B.3 几何 critic 的训练动力学

- 生成器若生成几何上不自洽的未来，冻结解码器读出的深度/流会出现矛盾，被几何监督损失惩罚；
- 相当于给生成器装了一个"不可欺骗的度量裁判"：它不能被对抗性外观糊弄，因为评判的是 latent 结构而非像素；
- 与 GAN 判别器的区别：critic 是确定性解码器而非对抗训练的判别器，训练更稳定。

### B.4 场景流表示的坐标系哲学

- "帧局部索引 + 全局稳定基"分离了空间信息的两个正交属性：在哪（局部索引）与朝哪动（全局方向）；
- 这与机器人学中 body frame / world frame 的分离同构；
- 对 Spatial AGI 的启示：内部空间表征应始终显式维护"观测坐标系"与"世界坐标系"的双向映射，Plan4D 用一个旋转矩阵把这件事做在了架构里。

### C.1 可规划性的三层含义

1. **度量可规划**：深度+光线给出度量空间，规划器可算距离/碰撞；
2. **动力学可规划**：场景流预测环境如何响应动作，支持 MPC 式滚动优化；
3. **语言可规划**：文本动作接口让人类/LLM 直接下指令。
三层齐备才算"可规划世界"——大多数现有世界模型只有第三层的粗糙版本。

### C.2 生成式 4D 的验证难题

- 生成的是"没有 GT 的未来"，几何准确性如何评？
- 论文用合成数据（有 GT）+ 真实数据（重建一致性）双轨验证；

### C.3 与 Spatial AGI 技术栈的对接蓝图

- 感知层：DA3 式几何基础模型（重建当前世界）；

## 附录H：深度问答补遗

### H.1 为什么场景流选择"前向流"而不是双向流？

前向流（t→t+1）直接对应因果预测的方向：世界模型预测的就是未来，前向流天然匹配。双向流会增加解码负担且反向流在生成场景中缺乏明确监督来源。代价是遮挡区域（t+1 可见而 t 被遮挡）没有对应关系，这留给了未来工作。

### H.2 文本动作接口能否扩展到机器人轨迹？

架构上可以：把文本 token 替换/拼接为轨迹 token（如末端执行器位姿序列编码），latent 轨迹的演化条件机制不变。难点在数据——轨迹级条件+4D 几何的数据比文本动作更稀缺，这正是"几何 critic 让无标注数据产生几何监督"策略需要再次发挥作用的地方。

### H.3 缝合范式是否会成为 Spatial AGI 的主流构建方式？

很可能成为重要选项之一。它的经济学吸引力明显：基础模型各自的数据护城河不共享，缝合是唯一不动护城河的融合方式。但它不是终点——当某一模态的基础模型出现"大一统"（如原生 4D 基础模型），缝合的必要性会下降。在此之前，缝合是数据稀缺时代最理性的融合策略。

### H.4 Plan4D 生成的世界能用于真实机器人训练吗？

有前景但有 Gap：生成的几何是 DA3 风格的（相对度量、可能有尺度漂移），动力学是统计学习而非物理引擎，sim-to-real 需要额外校准。更现实的用法是"预演过滤"：真实策略先在生成的 4D 世界里预演，筛掉明显失败的动作序列，降低真实试错成本。
