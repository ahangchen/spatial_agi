# Masked Visual Actions for Unified World Modeling

**arXiv**: [2607.19343](https://arxiv.org/abs/2607.19343)
**发布日期**: 2026-07-21
**作者**: Hadi Alzayer, Wenlong Huang, Haonan Chen, Christopher Luey, Lvmin Zhang, Maneesh Agrawala, Gordon Wetzstein, Li Fei-Fei, Yilun Du, Jiajun Wu, Jia-Bin Huang
**机构**: Stanford University, MIT, Columbia University, UC Berkeley
**项目主页**: https://masked-visual-actions.github.io
**分类**: cs.CV, cs.RO

## 摘要

Video models absorb rich priors over how the visual world moves, interacts, and responds to contact, making them promising substrates for robotic world modeling. The central challenge is how to communicate action to such models in a form aligned with the visual space in which they learned these interaction priors, yet still grounded in physical manipulation. We introduce Masked Visual Actions, a pixel-space control interface that expresses action as a partially revealed trajectory of an arbitrary entity in a video. Revealing robot motion makes the model act as a forward dynamics model that predicts the scene's response to low-level robot actions, while revealing desired object motion makes the same model recover robot behavior consistent with that outcome. Finetuned with only 15 hours of masked examples from real videos and simulation, a single checkpoint achieves strong visual fidelity and controllability across diverse scenes and multiple embodiments. In downstream manipulation settings, the model produces imagined rollouts whose outcomes correlate with real-world execution for policy evaluation, improves decision making by ranking candidate futures in model-based planning, and supports inverse modeling by synthesizing robot motion from desired object motion.

## Q1: 核心算法原理

### 1.1 核心思想和动机

Masked Visual Actions（MVA）的核心思想极其优雅：**将动作表示为视频中的"部分揭示的轨迹"**，从而将机器人控制问题转化为视频模型已经擅长的视觉补全问题。

**动机分析**：

传统的机器人世界模型面临一个根本性的"接口问题"：
- 视频模型在纯视觉空间中学习了丰富的世界动态先验（物体如何运动、如何接触、如何响应）
- 但机器人控制需要的是物理空间中的精确动作（关节角度、末端执行器位姿等）
- 两者的"语言"不匹配：视频模型说"像素"，机器人说"关节角度"

现有的解决方案通常有两条路径：
1. **动作token嵌入**：将动作向量编码为token注入视频模型（如Sora类模型的做法），但这破坏了视觉空间的对齐
2. **从头训练世界模型**：在机器人数据上从头训练，但无法利用视频模型的海量先验

MVA提出了第三条路径：**在像素空间中表达动作**。具体来说，动作不再是一组数值向量，而是视频中某个实体（机器人手臂、物体等）未来运动轨迹的部分"揭示"（reveal/mask）。模型需要补全剩余的运动轨迹和场景响应。

这种设计的深层洞察是：**视频模型已经理解了"如果某个东西按照某种方式运动，周围环境会如何响应"**，我们只需要找到一种方式来"告诉"视频模型我们想要的运动模式。

### 1.2 主要技术方法

#### Masked Visual Action 接口设计

MVA的接口设计基于一个关键概念：**实体轨迹的部分揭示**。

具体操作流程：
1. **选择实体**：在视频帧中选择一个运动实体（机器人手臂、被操作的物体等）
2. **轨迹揭示**：揭示该实体在未来若干帧中的部分运动轨迹（如前3帧的位置）
3. **模型补全**：视频模型基于揭示的部分轨迹和上下文，补全完整的场景演化

**双向使用模式**：
- **前向模式（Forward Dynamics）**：揭示机器人运动轨迹 → 模型预测场景响应
  - 输入：当前场景 + 机器人手臂运动的前几帧
  - 输出：完整的场景演化（包括物体的位移、变形等）
  - 用途：策略评估、世界模拟

- **逆向模式（Inverse Modeling）**：揭示目标物体运动 → 模型推断机器人运动
  - 输入：当前场景 + 物体期望运动的前几帧
  - 输出：机器人手臂如何运动才能实现该物体运动
  - 用途：目标导向规划、任务指定控制

#### 训练策略

MVA的训练极其高效：
- **基础模型**：预训练的视频生成模型（继承了海量视频数据的先验）
- **微调数据**：仅15小时的掩码示例（来自真实视频+仿真）
- **单一checkpoint**：一个模型同时支持前向和逆向两种模式

这意味着MVA不需要从头训练一个世界模型，而是利用视频生成模型已有的世界知识，只需要教它理解"masked visual action"这种新的交互接口。

#### 多实体支持

MVA的一个重要特性是支持**任意实体**的动作指定：
- 不限于机器人手臂
- 可以是任何在场景中运动的物体
- 甚至可以是多个实体的协调运动

这种灵活性使得MVA可以泛化到不同的embodiment和任务场景。

### 1.3 算法流程和关键步骤

#### 推理流程

```
输入: 当前场景观察 O_t
      动作指定: 实体e的揭示轨迹 T_e[0:k]（前k帧）

Step 1: 实体定位
  - 在O_t中识别实体e的位置和形状
  - 提取实体的视觉特征

Step 2: 轨迹编码
  - 将T_e[0:k]编码为像素空间的运动模式
  - 生成mask，标记需要补全的区域

Step 3: 条件视频生成
  - 输入: O_t + T_e[0:k]的视觉mask
  - 视频模型补全: 完整轨迹 T_e[k:H] + 场景响应
  - H = 视频长度

Step 4: 输出
  - 前向: 场景演化视频 + 机器人轨迹
  - 逆向: 机器人运动轨迹（从物体目标运动反推）
```

#### 训练流程

```
Step 1: 数据准备
  - 从真实视频中提取实体轨迹
  - 在仿真中生成robot-object交互视频
  - 总计~15小时视频数据

Step 2: Mask构造
  - 随机选择视频中的实体
  - 部分揭示其未来轨迹
  - 构造input: (前文+masked trajectory) → target: (完整视频)

Step 3: 微调
  - 冻结或部分冻结视频模型
  - 在masked数据上微调
  - 混合真实视频和仿真数据

Step 4: 多embodiment训练
  - 不同形态的机器人数据混合训练
  - 学习通用的"masked action理解"能力
```

### 1.4 输入输出

**输入**:
- 当前场景的视觉观察（RGB图像/视频）
- Masked Visual Action：部分揭示的实体运动轨迹
  - 可以是机器人手臂的运动（前向）
  - 可以是目标物体的期望运动（逆向）

**输出**:
- 完整的场景演化视频（包含所有实体的协调运动）
- 机器人手臂的运动轨迹（隐含在生成的视频中）

## Q2: 与Spatial AGI的关系

### 2.1 如何理解和表示空间

MVA对空间的理解体现在以下几个层面：

#### 像素空间作为统一表示

MVA选择**像素空间**作为统一的空间表示，这具有深刻的意义：

1. **几何隐含性**：像素空间中天然包含了几何信息（深度、遮挡、相对位置），虽然不是显式的3D坐标，但视频模型通过大规模训练已经内化了这些几何理解

2. **物理直觉编码**：视频模型通过观察数百万小时的视频，已经学会了"物体如何碰撞"、"重力如何作用"、"材质如何影响变形"等物理直觉

3. **空间关系保持**：当视频模型补全masked轨迹时，它需要正确处理：
   - 空间遮挡关系（前景挡住后景）
   - 物体间的碰撞和接触
   - 运动的连贯性和物理约束

#### 动态空间理解

MVA的空间理解不是静态的，而是**动态的时空理解**：
- 物体在3D空间中的运动轨迹
- 运动引起的场景变化（阴影移动、遮挡关系变化）
- 多物体的协调运动（如机器人手臂碰到物体后物体的弹跳）

### 2.2 如何处理空间关系

MVA处理空间关系的方式非常独特：

#### 隐式空间推理

不需要显式的3D重建或空间推理模块，MVA通过视频生成模型隐式地完成空间推理：

1. **遮挡处理**：当揭示机器人手臂的运动时，模型自动处理手臂对物体的遮挡
2. **碰撞检测**：模型理解手臂接触物体时物体会如何运动
3. **空间约束**：模型理解物理空间对运动的约束（桌子边缘、墙壁等）

#### 多实体空间关系

MVA可以处理多个实体之间的复杂空间关系：
- 机器人手臂与物体的相对位置
- 物体之间的堆叠和碰撞
- 场景结构对运动的约束

### 2.3 对Spatial AGI的启发

MVA对Spatial AGI有几个重要的启发：

#### 1. 视觉接口优于数值接口

MVA证明了：**对于世界模型来说，视觉（像素空间）接口可能比数值（关节角度）接口更有效**。

这意味着Spatial AGI系统在设计世界模型时，应该考虑：
- 使用视觉信号而非数值向量作为动作接口
- 利用预训练视觉模型的空间理解能力
- 将物理控制转化为视觉补全任务

#### 2. 双向世界模型

MVA的前向+逆向双模式设计，为Spatial AGI提供了一个完整的"想象-规划"闭环：
- 前向：给定动作想象结果（用于评估）
- 逆向：给定目标反推动作（用于规划）

这种设计可以应用于：
- 空间任务规划（从目标状态反推操作步骤）
- 空间场景想象（从当前状态预测未来）
- 空间约束满足（在想象中验证约束）

#### 3. 少数据高效迁移

仅15小时微调就能获得强大的世界建模能力，说明视频模型中已经编码了大量空间先验。

#### 4. 统一的世界模型架构

单一checkpoint同时支持前向和逆向推理，这种统一性对Spatial AGI非常重要：
- 减少系统复杂度
- 共享世界知识
- 支持灵活的任务切换

### 2.4 可以应用到哪些Spatial AGI场景

1. **机器人操作规划**：利用逆向模式从目标物体状态反推机器人运动
2. **空间场景预测**：利用前向模式预测操作后的场景状态
3. **多智能体协调**：利用多实体支持实现多机器人协调规划
4. **空间安全验证**：在想象中验证操作的安全性
5. **空间交互学习**：通过视频学习物体间的交互模式
6. **数字孪生**：用视频模型作为轻量级数字孪生

## Q3: 创新点和局限性

### 3.1 主要创新点

#### 创新点1: Masked Visual Action接口

**核心贡献**：提出了一种将动作转化为像素空间中部分揭示轨迹的接口。

**为什么重要**：
- 解决了视频模型与机器人控制之间的"语言鸿沟"
- 利用了视频模型已有的视觉补全能力
- 支持双向使用（前向+逆向）

**与现有方法的对比**：
- 传统VLA（如RT-2）：将动作编码为token → 丢失空间对齐
- 世界模型（如Dreamer）：在潜在空间建模 → 无法利用视频先验
- 视频生成控制（如Sora控制）：语义级控制 → 无法精确到机器人动作级别
- **MVA**：像素空间动作接口 → 保持了空间对齐 + 利用了视频先验

#### 创新点2: 极低数据需求

**核心贡献**：仅15小时微调就实现了跨场景跨embodiment的通用世界建模。

**为什么重要**：
- 传统方法需要大量机器人数据（数千小时遥操作数据）
- MVA通过迁移视频模型先验，大幅降低了数据需求
- 证明了视频模型中已经编码了丰富的交互先验

#### 创新点3: 统一的前向-逆向世界模型

**核心贡献**：单一模型同时支持前向动力学预测和逆向动作推断。

**为什么重要**：
- 传统方法需要分别训练前向模型和逆向模型
- 统一模型共享了世界知识
- 便于构建"想象-规划"闭环

#### 创新点4: 下游任务验证

**核心贡献**：在真实机器人上验证了想象rollout与真实执行的相关性。

**具体验证**：
- 策略评估：用想象rollout评估策略质量
- 基于模型的规划：通过排序候选未来改善决策
- 逆向建模：从目标物体运动合成机器人运动

### 3.2 局限性

#### 局限1: 像素空间的精度限制

MVA在像素空间操作，这意味着：
- 精度受限于视频模型的分辨率
- 无法直接输出精确的关节角度或力矩
- 需要额外的轨迹提取模块将像素运动转换为控制指令

**影响**：对于需要亚毫米级精度的任务（如精密装配），MVA可能不够精确。

#### 局限2: 长时序一致性

视频生成模型在长视频生成中面临一致性挑战：
- 长时间rollout可能出现场景漂移
- 物体持久性（object permanence）可能丢失
- 多步骤操作的累积误差

**影响**：限制了MVA在长horizon任务中的应用。

#### 局限3: 3D几何的隐式表示

MVA使用2D像素空间，缺乏显式的3D几何：
- 无法直接处理深度信息
- 对于复杂的3D空间关系（如遮挡后的物体）可能理解不足
- 多视角一致性需要额外保证

**影响**：在需要精确3D理解的任务中可能受限。

#### 局限4: 物理精确性

视频模型的物理理解是基于视觉先验的，而非精确的物理模拟：
- 无法保证物理定律的严格遵循
- 对于非典型物理场景（如低摩擦、微重力）可能失效
- 不可压缩流体的精确模拟可能困难

**影响**：不适合需要物理精确保证的任务。

#### 局限5: 计算效率

视频生成模型的推理成本较高：
- 生成一段rollout可能需要多秒
- 实时控制需要更快的推理
- 高分辨率视频生成成本尤其高

**影响**：限制了在需要快速反应的场景中的应用。

## 技术细节深度分析

### Mask设计策略

MVA的mask设计是其核心创新之一。具体的mask策略包括：

1. **实体mask**：选择视频中的特定实体（如机器人手臂），揭示其前k帧的运动
2. **轨迹mask**：不揭示完整的实体，而是揭示一条抽象的运动轨迹
3. **混合mask**：同时揭示多个实体的部分运动

mask的比例和长度是关键超参数：
- 揭示太少：模型可能不知道要做什么
- 揭示太多：退化为普通的视频续生成

### 训练数据构成

15小时的微调数据包括：
- **真实视频**：从互联网和机器人实验室收集的robot-object交互视频
- **仿真数据**：从仿真环境生成的带有ground truth轨迹的视频
- **混合训练**：两种数据混合，确保模型同时具备真实感和多样性

### 多Embodiment支持

MVA的单一checkpoint支持多种机器人形态：
- 单臂机器人
- 双臂机器人
- 不同品牌的机器人（UR, Franka等）
- 甚至人类手部操作

这种泛化能力来自于：
- 像素空间接口的embodiment无关性
- 视频模型对多种运动模式的预训练知识
- 混合训练策略

### 下游应用深度分析

#### 应用1: 想象Rollout评估

MVA可以生成"想象的"机器人操作rollout，这些rollout的 outcome 与真实执行结果高度相关。

**价值**：
- 无需物理执行就能评估策略质量
- 可以批量评估多个候选策略
- 减少真实机器人的磨损和风险

**验证方法**：
- 计算想象rollout的成功率与真实执行成功率的相关性
- 在多种任务上验证泛化性

#### 应用2: 基于模型的规划

MVA通过排序候选未来来改善决策：
1. 采样多个候选动作
2. 生成每个动作对应的想象rollout
3. 评估每个rollout的质量（如任务完成度）
4. 选择最优动作

**优势**：
- 不需要显式的价值函数
- 利用视频模型的隐式评估能力
- 可以处理视觉复杂的任务

#### 应用3: 逆向建模

从目标物体运动反推机器人运动：
1. 指定物体的期望运动（如"把杯子移到这里"）
2. 将物体运动作为masked visual action输入
3. 模型生成机器人手臂的协调运动

**价值**：
- 自然的目标导向接口
- 无需显式规划器
- 支持复杂的多步骤操作

## 与Spatial AGI的深度关联分析

### 世界模型的"视觉接口"范式

MVA代表了一种新兴的Spatial AGI范式：**用视觉信号替代数值信号作为世界模型的接口**。

传统范式：
```
感知 → 特征提取 → 动作规划 → 控制执行
          ↓
    世界模型（潜在空间）
```

MVA范式：
```
感知 → 视觉mask → 视频模型补全 → 轨迹提取 → 控制执行
                        ↓
              世界模型（像素空间）
```

这种范式转变的意义：
1. **简化系统**：不需要显式的3D重建、特征提取、规划模块
2. **利用海量先验**：直接受益于视频模型的大规模预训练
3. **统一接口**：感知、想象、规划都在同一空间中完成

### 对空间智能层级结构的启示

Spatial AGI的空间智能可以粗略分为：
1. **感知层**：理解场景的几何、语义、关系
2. **预测层**：想象场景的未来演化
3. **规划层**：设计动作序列以实现目标
4. **执行层**：精确控制物理实体

MVA通过masked visual action接口，将**预测层和规划层统一**到了视频生成框架中。这是一个重要的简化——传统上这两层是分开的。

### 未来方向：3D-aware MVA

MVA当前的局限在于2D像素空间。一个自然的扩展是**3D-aware MVA**：
- 在3D Gaussian Splatting或NeRF空间中定义masked visual action
- 利用3D几何先验增强空间一致性
- 支持真正的6-DoF动作指定

这种3D-aware MVA将更直接地与Spatial AGI的空间理解能力对齐。

### 与其他Spatial AGI技术的协同

MVA可以与多种Spatial AGI技术协同：

1. **+ 3DGS**：用3DGS作为场景表示，MVA在3DGS空间中生成动作
2. **+ VLM空间推理**：VLM提供高层语义理解，MVA提供底层动态模拟
3. **+ SLAM**：SLAM提供实时场景地图，MVA在地图上预测操作结果
4. **+ 触觉感知**：结合触觉反馈验证MVA预测的物理交互

## 个人思考与见解

### 1. 视觉行动接口的哲学

MVA最让我印象深刻的是它的哲学优雅性：**不发明新的表示，而是用视频模型已经理解的"运动"作为接口**。

这类似于人类交流中的"展示而非描述"——与其用抽象的语言描述一个动作（关节角度1=0.5, 关节角度2=1.2...），不如直接"做"出来让对方看到。MVA就是让机器人通过"展示部分运动"来告诉视频模型"我要做什么"。

### 2. 世界模型的"免费午餐"

MVA证明了视频模型中编码的世界知识可以"免费"迁移到机器人世界建模中。这提出了一个重要问题：**我们的视频生成模型中已经编码了多少世界知识还没有被充分利用？**

如果15小时的微调就能解锁强大的世界建模能力，那么随着视频模型的进一步发展（更大规模、更高分辨率、更长时序），MVA的能力天花板还远未到达。

### 3. 从2D到3D的必然路径

MVA目前在2D像素空间操作，这在短期是优势（利用现有视频模型），但长期来看是局限（缺乏3D理解）。

我认为未来的发展方向必然是**3D-aware MVA**：
- 在3D空间中定义masked trajectory
- 利用3D-aware视频模型（如基于3DGS的生成模型）
- 输出3D运动而非2D像素运动

这将使MVA真正成为Spatial AGI的核心组件。

### 4. 因果推理的缺失

MVA通过视频生成隐式地理解因果关系（如果我这样推，物体就会那样动）。但这种隐式因果推理有其局限：
- 在未见过的物理场景中可能失效
- 无法进行反事实推理（"如果我换一种方式推会怎样？"）
- 缺乏因果解释能力

Spatial AGI需要的不只是"知道会怎样"，还需要"理解为什么会这样"。MVA提供了前者，但后者还需要额外的因果推理模块。

### 5. 与Embodied AI数据效率的关系

MVA的15小时微调数据需求，与当前Embodied AI领域动辄数千小时的数据需求形成鲜明对比。这种数据效率的突破来自于：
- 视频模型已经学习了通用的世界动态
- masked action接口与视频模型的预训练目标高度兼容
- 不需要从头学习物理直觉

这为解决Embodied AI的数据瓶颈提供了一条可行的路径。

### 6. 统一模型的系统意义

单一checkpoint同时支持前向和逆向推理，这在系统设计上有重要意义：

```
Spatial AGI系统架构（基于MVA）:

    感知 → 场景理解 ─┬─→ 前向想象 → 策略评估
                     │    ↓
                     │   排序选择 → 决策
                     │    ↓
                     └─→ 逆向规划 → 动作生成
                          ↓
                       执行验证 → 反馈
```

整个"想象-规划-执行"闭环都基于同一个世界模型，大幅简化了系统复杂度。

Masked Visual Actions（MVA）是一项具有里程碑意义的工作，它通过将动作表示为像素空间中部分揭示的轨迹，巧妙地解决了视频模型与机器人控制之间的接口问题。
