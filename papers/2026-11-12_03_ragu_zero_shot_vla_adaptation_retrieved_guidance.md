## 0. 一句话总结

RAGu 把语言模型的 RAG 思想引入机器人：从领域不匹配的大规模演示库（如 DROID）中检索轨迹，经过几何校正（warping）与策略感知筛选后，作为能量场引导冻结 VLA 的 flow-matching 去噪过程，实现零参数更新、零上下文占用的零样本 VLA 适配——真实世界成功率从 20% 提升到 80%。

## 核心问题

### Q1: 这篇文章的核心算法原理是什么？

**问题**: 这篇文章的核心算法原理是什么？请详细描述：核心思想和动机、主要技术方法、算法流程和关键步骤、输入输出。

**分析**:

#### 1. 核心思想和动机

VLA 模型（π0.5、GR00T 等）在演示数据预训练后展现了通用操作能力，但泛化性远不及语言/视觉基础模型——相机视角、背景、物体身份、机器人形态的轻微变化都会导致性能崩塌。原因：机器人数据与模型都相对小，且模型受近实时执行约束。

语言模型对付这一问题的成熟答案是 **RAG（检索增强生成）**：用检索到的外部知识弥补小模型的参数化知识不足。能否给 VLA 也来一套 RAG？直接移植面临三个机器人特有的挑战：

1. **跨域泛化**：机器人数据在视角、布局、本体上分布差异巨大，不像 LLM 有通用 token 空间。即使从 DROID 这样的大库中检索到最匹配的轨迹，也带有严重的域偏移。既有机器人检索方法只能限定在窄的同本体数据集或需要任务特定微调；
2. **策略感知检索（Policy-Aware Retrieval）**：几何上最近的轨迹不一定是策略能平稳跟随的轨迹——好的检索必须考虑"策略跟不跟得上"；
3. **上下文受限适配**：VLA 的上下文窗口装不下把检索到的演示轨迹拼进输入的方案。

RAGu（Retrieval-Augmented Guidance）的答案：**训练无关（training-free）的零样本适配框架**——检索到的轨迹不进上下文、不更新权重，而是构造一个**推理时引导场（guidance field）**，在 flow-matching 去噪过程中把 VLA 的输出"拽向"检索到的轨迹。

#### 2. 主要技术方法

**（a）基础机制：推理时引导（Inference-Time Steering）**

把 VLA 建模为 flow-matching 策略：从噪声 A_0 ~ N(0,I) 沿条件向量场 v(A_τ, o) 积分到干净动作块 A_1 = [a_t..a_{t+H-1}]。适配 = 施加可微约束 y 的能量 L_y(A_τ) = ½||A_τ - y||²，引导速度场为：

v_guided = v(A_τ, o) - γ ∇_{A_τ} L_y(A_τ)

先前工作的 y 来自人类操作员或外部规划器；RAGu 的关键贡献是让 y 来自**检索+跨域校正后的演示轨迹**。

**（b）语义任务类过滤**

从大规模数据集（DROID）中用语义关键词筛选结构兼容的轨迹：任务类运动学相似（如目标"把毛巾放盘子上"就检索含 "pick" "place" 的演示）。这一步保证检索池至少在任务语义上对齐。

**（c）跨域轨迹校正（Warping）**

- 用 Grounding DINO 在目标场景检测任务相关实体的语义边界框，提取目标航点 W'；
- 对应关系不按物体相似度定义，而按**任务中的功能角色**定义（"被抓的东西""放置的目标"）——这是跨域对应的关键抽象，允许源域毛巾对应目标域盘子旁的任意物体；
- 沿用 in-domain warping 公式：中间动作按相邻航点位移 Δd_i = w'_i - w_i 与插值系数 α 校正：a'_t = a_t + ((1-α)Δd_i + αΔd_{i+1})；
- **重要定位**：warp 后的路径不直接经逆动力学执行（跨域 warped 路径直接 IK 执行不可靠），而是**只作为空间先验**，闭环操作的细节交还给 VLA 自身的泛化能力。

**（d）两级检索**

- **粗检索（离线，DTW）**：每个任务类指定一条参考轨迹（任意有效演示即可），对每条候选用动态时间规整（DTW）一次性剪枝到 top-N，得到目标坐标系下的校正候选轨迹池 {W^(i)}；
- **细检索（在线，策略感知）**：在每个推理步，用 VLA 当前预测的动作块（τ=1 估计）经正运动学映射为笛卡尔末端路径 X_t；对每个候选取代价 C_i(X_t) = ||X_t - seqMatch(X_t, W^(i))||²，**选择代价梯度范数最小的候选**：

  i* = argmin_i ||∇_{A_0} C_i(X_t)||₂

  直觉：梯度范数估计"策略需要被拽离自身意图多远才能贴上这条轨迹"。梯度小 = 轨迹贴近 VLA 已学到的最优动作先验 = 策略能平稳跟随。选择在每个推理的**第一个去噪步**执行一次，其余去噪步固定使用。

**（e）推理时引导去噪**

选定 i* 后，以 L_warp(A_τ) = C_{i*}(X_t) 作为能量代入引导速度场公式，把去噪过程拉向检索轨迹同时保留 VLA 先验。

#### 3. 算法流程和关键步骤

```
离线准备:
1. DROID 中按语义关键词筛任务类轨迹池
2. 每类选一条参考轨迹, DTW 剪枝出 top-N 候选
3. Grounding DINO 检测目标场景实体 → 功能角色对应 → 航点映射
4. 所有候选 warp 到目标坐标系 (预校正, 存池)

在线推理 (每步):
5. VLA flow-matching 去噪开始
6. 第一个去噪步: 当前预测动作块 → 正运动学 → X_t
   对 top-N 候选算 ||∇_{A0} C_i(X_t)||, 选梯度最小者 i*
7. 用 L_warp = C_{i*}(X_t) 引导后续去噪: v_guided = v - γ∇L_warp
8. 输出动作块执行, 闭环循环
```

#### 4. 输入输出

- **输入**: 冻结的预训练 VLA（π0.5-DROID / GR00T-N1.7 / GR00T-N1.5）、大规模源演示库（DROID / MetaWorld）、目标场景观测与语言指令；
- **输出**: 被引导后的动作块（末端轨迹贴近校正后的检索轨迹，细节由 VLA 先验闭环完成）；
- **零更新**: 全程无参数训练，无上下文拼接。

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**问题**: 这篇文章与通用空间智能（Spatial AGI）有什么关系？请分析：如何理解和表示空间、如何处理空间关系、对Spatial AGI的启发、可以应用到哪些Spatial AGI场景。

**分析**:

#### 1. 如何理解和表示空间

RAGu 对空间的理解体现在三个巧妙的抽象上：

- **空间 = 笛卡尔轨迹（Cartesian trace）**：论文把 manipulation 的核心空间结构抽象为末端执行器的 3D 路径。这个抽象丢弃了外观、本体、速度细节，恰好保留了跨域不变的"任务空间骨架"——pick 类任务在哪个厨房、哪个机器人上，其空间骨架都是"接近→抓取→平移→放置"。**空间骨架的不变性是检索可行的前提**；
- **功能角色对应（functional-role correspondence）**：跨域空间对应不按外观相似度而按任务功能角色（"被抓物""放置目标"）。这是对空间语义的深刻处理——"这块布"和"这个盘子"在几何上毫无相似，但在任务结构中占据同一功能槽位。空间智能需要这种**关系性/角色性的空间理解**，而非纯粹的视觉匹配；
- **空间先验与闭环控制的分工**：warp 后的轨迹只当先验，执行细节交给策略。这承认了空间知识有两个层级：粗粒度的"该往哪走"（可检索、可校正、可显式表示）和细粒度的"怎么走好"（隐含在策略参数里）。RAGu 的成功证明这个分工是有效的。

#### 2. 如何处理空间关系

- **几何校正（warping）**：用语义检测定位目标场景航点，把源域轨迹的空间结构平移到目标域——这是显式的空间坐标变换操作，把跨域问题转化为域内问题；
- **空间兼容性度量**：策略感知检索用"引导代价梯度范数"衡量候选轨迹与策略空间习惯的兼容度——空间兼容不只是几何距离，还包括策略的动力学习惯（它习惯走的弧线、习惯的速度分布）；
- **时间-空间耦合**：DTW 处理时间轴不对齐，seqMatch 做单调最近邻投影处理空间序列不对齐——空间关系的处理始终与时间结构耦合，符合操作任务的时空一体性。

#### 3. 对 Spatial AGI 的启发

1. **空间知识的 RAG 化**：这是本文最大的启发。空间智能模型的空间知识也可以拆成"参数化知识"（模型权重里的隐式先验）与"非参数化知识"（可检索的外部空间数据）。与其微调模型适应新空间，不如检索相似空间经验+显式几何校正。这对 Spatial AGI 的记忆系统设计极有启发——**空间记忆的正确形态可能是一个可检索、可校正、可注入推理的轨迹/经验库**；
2. **训练无关适配的价值**：零样本、零更新、零上下文的适配三角在部署上价值巨大。Spatial AGI 系统进入新环境（新房子、新工厂）不可能每次都微调，RAGu 范式提供了"检索+校正+引导"的即插即用适配模板，可推广到导航（检索相似布局的导航轨迹）、场景图构建（检索相似场景的先验图）等；
3. **策略感知的检索准则**：检索不仅要"内容相关"，还要"消费者兼容"。任何 Spatial AGI 的记忆/检索系统都应内建对下游模块的兼容性评估——这把检索从相似度搜索升级为系统级决策；
4. **能量场引导作为通用空间约束注入机制**：任何可微空间约束（避障场、可达性、物理合法性、语义一致性）都可以用同样的 L + 梯度方式注入生成式策略。RAGu 只是用了"检索轨迹"这一种约束源，机制本身是通用的空间知识注入通道。

#### 4. 可以应用的 Spatial AGI 场景

- **机器人即插即用部署**：新环境无需数据收集与微调，从云端演示库检索+校正即可适配（论文已验证 Real→Real、Real→Sim、Sim→Real、跨形态人形机器人四种设置）；
- **跨具身空间技能库**：不同机器人的轨迹经本体校正后进入统一检索库，任何 VLA 都能借用全行业的操作经验——空间技能的"开源生态"基础设施；
- **空间导航先验注入**：把室内导航轨迹（不同房型）作为导航策略的引导场，新房间零样本适配；
- **空间反事实评估**：用检索到的"别人怎么做"作为对照，评估当前策略的空间决策偏差；
- **仿真数据校准**：Sim→Real 设置证明仿真轨迹可作为真机的空间先验，反哺 sim-to-real 管线。

### Q3: 基于前面的分析，这个方法的主要创新点和局限性是什么？

**问题**: 基于前面的分析，这个方法的主要创新点和局限性是什么？与其他相关工作相比有什么优势和劣势？

**分析**:

#### 1. 主要创新点

1. **范式移植创新**：把 LLM 的 RAG 完整映射到 VLA——检索库=演示数据集、文档=轨迹、上下文注入=能量场引导——并逐一解决了机器人特有的三个挑战（域偏移、策略兼容、上下文受限），映射干净且工程完整；
2. **功能角色对应**：跨域轨迹校正的关键创新，用任务功能槽位替代视觉相似度定义跨域对应，使"毛巾→盘子"这种外观完全不同的源-目标迁移成为可能；
3. **策略感知检索准则**：用引导代价梯度范数选择候选，是对"检索结果必须被消费者友好"这一被普遍忽视问题的首个机器人方案，且实现极轻（每步一次梯度范数计算）；
4. **训练无关的能量场引导**：不动权重、不占上下文，把检索知识注入推理过程。对比 RICL/REGENT 等需要域内轨迹做参数化适配的方法，RAGu 真正做到了"零成本适配"；
5. **实证冲击力**：真实世界 VLA 成功率 20%→80%（4 倍），跨 Real/Sim/人形四设置验证，在 VLA 适配文献中幅度罕见。

#### 2. 主要局限性

1. **依赖任务语义关键词过滤**：第一步的语义过滤要求源数据有语言标签且任务类运动学相似，对无标签数据或新任务类（检索池中没有的功能角色）失效——"零样本"的前提是检索池覆盖了任务骨架；
2. **warping 假设的局限**：功能角色对应 + 航点插值假设任务的空间结构可以由少量航点概括，对依赖连续接触力学或非结构化形变的任务（拧瓶盖的力反馈、叠衣服）失效——笛卡尔轨迹骨架无法表达力/接触信息；
3. **细检索每 episode 一次的假设**：候选在第一个去噪步选定后固定，若任务中途空间结构变化（抓取失败后重试），需要重新检索，论文对动态重检索的讨论有限；
4. **单轨迹引导**：一次只用一条检索轨迹，无法组合多个来源的经验（比如从 A 学接近、从 B 学放置），检索结果的聚合能力缺失；
5. **γ 引导强度的调节**：引导过强策略失去自主性（变相回放到开轨迹跟踪），过弱不起作用，最优 γ 与任务/域相关，自适应 γ 机制缺失。

#### 3. 与其他相关工作的对比

| 维度 | RICL / REGENT（检索+上下文/微调） | VLS / Omniguide（VLM 引导） | Tether（域内 warping） | RAGu |
|---|---|---|---|---|
| 源数据要求 | 域内演示 | 无（VLM 生成） | 域内演示 | 跨域大规模库 |
| 参数更新 | 需要 | 无 | 无 | **无** |
| 上下文占用 | 大 | 无 | 无 | **无** |
| 引导形式 | 输入拼接 | 稀疏目标点 | 执行 warped 轨迹 | 连续轨迹能量场 |
| 跨域对应 | 无 | VLM 语义 | 视觉匹配 | **功能角色** |
| 策略感知 | 无 | 无 | 无 | **梯度范数选择** |

**优势**：唯一同时解决跨域+免训练+免上下文+策略感知四项的方案。
**劣势**：结构化任务假设最强（检索池+航点+笛卡尔骨架），灵活性低于 VLM 引导路线。

## 核心技术发现

1. 跨域演示经语义功能角色校正后，可以作为冻结 VLA 的有效空间先验——空间骨架比外观更可迁移；
2. 策略感知检索（引导代价梯度范数最小）显著优于纯几何最近邻检索；
3. 能量场引导可在完全不更新参数、不占上下文的前提下把真实世界 VLA 成功率提升 4 倍（20%→80%）；
4. warp 后轨迹只需当先验而非直接执行目标——细粒度闭环交给策略自身泛化，这个分工是跨域成功的关键；
5. 同一框架覆盖 Real→Real、Real→Sim、Sim→Real、跨形态人形四种迁移设置。

## 与 Spatial AGI 的关系

### 直接贡献

提供了空间知识"检索-校正-引导"的完整范式，是 Spatial AGI 记忆与适配系统的首个端到端机器人实现。

### 技术启发

- 空间知识应分为参数化先验与可检索的非参数化库，适配=检索+校正+推理时引导；
- 跨域空间对应应按功能角色而非外观定义；
- 检索系统需要内建对下游消费者的兼容性评估。

### 应用场景

即插即用机器人部署、跨具身技能库、导航先验注入、sim-to-real 校准、策略偏差评估。

## 个人思考

### 最令人兴奋的发现

20%→80% 这个数字背后隐藏着一个更重要的信号：**VLA 的失败大多不是"不会"，而是"认不出"**。冻结的 π0.5 在域偏移下只剩 20% 成功率，但给它一条校正后的空间骨架作为引导就能回到 80%——说明策略内部的操作能力是完整的，缺的只是把当前场景映射回它熟悉的场景结构。这对 Spatial AGI 的诊断意味深长：空间智能的瓶颈可能更多在"场景对齐/检索"层而非"能力"层。

### 潜在局限

力与接触的缺席是我认为最大的天花板。笛卡尔轨迹骨架能表达"去哪"，表达不了"用多大力、感受打滑"。对接触主导的任务，检索到的空间骨架几乎没有信息量。未来方向可能是把检索物从轨迹升级为"多模态经验片段"（轨迹+力序列+接触图+事件语义），能量场也从轨迹距离扩展到多模态一致性——那将是真正的"空间经验 RAG"。

### 与近日研究的关联

- **vs LaST0.5（同日）**：LaST0.5 用交互中心表示做参数化的世界-动作桥接，RAGu 用检索做非参数化的适配。两者分别代表"把知识训练进参数"与"把知识留在库里"两种哲学，长期可能融合：检索库提供候选经验，交互中心表示负责消费与验证；
- **vs OnlyAct（同日）**：OnlyAct 的动作嵌入空间可以作为 RAGu 检索库的索引——按动作语义（而非任务关键词）检索演示，检索精度会更高；同时动作嵌入的跨域不变性正好补 RAGu 语义过滤的短板；
- **vs 2026-11-11 Spatial Harness**：Harness 的物理引擎可以提供比 DTW/航点更精确的 warping——在仿真里解析求解源-目标场景的对应，是"符号系统服务神经检索"的一个具体切入点；
- **vs MetaWAM**：都涉及"外部信号注入生成式策略"，MetaWAM 是训练时的潜空间注入，RAGu 是推理时的能量场注入，构成注入机制的训练/推理两端。

## 方法深度剖析

### A. 为什么 warp 后不直接执行而要当先验？

Tether 等域内 warping 工作直接把校正后的轨迹经 IK 执行，域内场景下可行。跨域时校正轨迹的动力学特性（速度、惯性、接触时机）已不可信，直接执行会摔。RAGu 的分工设计：骨架当先验（能量场只拉不动推），策略在引导场内自主决定速度、姿态、接触时机——策略参数里保存的闭环能力被完全保留。这是"检索知识负责 where，参数化能力负责 how"的分工哲学。

### B. 策略感知检索准则的几何直觉

||∇_{A_0} C_i(X_t)|| 衡量：从噪声 A_0 出发，要让去噪结果贴上候选 i，每单位去噪进程需要多少引导力。梯度小意味着候选轨迹本来就在策略输出分布的高概率区——策略"想这么做"。选它作为引导，引导场只需微调而非强行弯折轨迹，执行自然平稳。反之若选几何最近但策略不熟悉的轨迹，强引导会让动作变得僵硬、震荡甚至失控。这个准则把"检索的相关性"重新定义为"消费者视角的可用性"。

### C. 三级漏斗的成本设计

语义过滤（一次性，按标签）→ DTW 粗剪枝（一次性离线，每候选一次）→ 梯度细选（在线但只在第一个去噪步）。在线成本被压缩到"N 次梯度范数计算"，远小于逐步检索。这种把重计算尽量前移到离线的设计，让检索增强在近实时控制回路中变得可行——工程上的关键贡献常被论文叙述里的算法创新掩盖，值得注意。

### D. seqMatch 的作用

候选轨迹与策略预测的时间节奏不同（快慢、停顿），直接按索引对齐会惩罚本来正确的轨迹。单调最近邻投影把候选在时间轴上柔性对齐到策略预测后再算距离，等价于把 DTW 思想搬进了在线细检索。时间对齐 + 空间距离的双重容错是实际效果好的隐藏原因之一。

## 实验剖析

### 四种迁移设置的意义

| 设置 | 验证的问题 | 结果要点 |
|---|---|---|
| Real→Real | 跨视角/背景/物体域偏移 | 20%→80% 主结果 |
| Real→Sim | 跨渲染域（真实→仿真） | 结构先验在仿真环境同样有效 |
| Sim→Real | 仿真经验是否可用于真机 | 多阶段任务验证 sim 数据价值 |
| 跨形态（→GR-1 人形） | 本体差异最大的迁移 | warped 骨架 + 策略闭环跨形态可行 |

四个设置合成一个完整的"域偏移光谱"，从轻度（同平台换视角）到重度（形态完全不同），RAGu 全线有效，说明方法对域偏移程度的鲁棒性。

### 基线对比的实验设计

- **RICL**：用完全相同的 100 条校正候选做检索，但作为输入上下文——隔离"检索内容相同、注入方式不同"的对比，直接验证能量场引导优于上下文注入；
- **Omniguide/VLS**：VLM 预测静态目标点的引导——验证连续轨迹骨架优于稀疏目标点；
- **基线策略**：冻结的 π0.5/GR00T——量化域偏移的裸损失。

三组基线分别对应三个挑战（上下文受限、策略感知、跨域），实验设计与问题陈述严格对应，是论文写作的范本。

- 实验中候选池每任务 100 条，池大小对性能的敏感性未充分展示；
- 失败案例分析：引导失败（拉不过去）vs 检索失败（骨架错误）的比例未知；
- 跨形态设置中 warped 骨架的形态适配细节（7-DoF 臂 → 人形双手）论文未展开；

## 扩展讨论：RAGu 在 Spatial AGI 版图中的位置

### 空间记忆系统的完整蓝图

RAGu 演示了空间记忆系统的四个组件：**索引**（语义关键词+任务类）、**存储**（校正后的骨架轨迹库）、**检索**（两级漏斗+策略感知）、**注入**（能量场引导）。这四个组件的抽象足够通用，可以容纳更丰富的记忆内容（导航经验、场景图、操作技能、失败教训）与更丰富的注入机制（引导场、上下文、贝叶斯先验）。可以预期未来的 Spatial AGI 记忆论文都会在这个框架内竞争具体组件的改进。

### 与参数化知识的经济学

机器人数据的收集成本远高于文本，参数化（训练进权重）每条经验的使用被摊薄在所有相似场景；非参数化（留在库里）则可精确复用。RAGu 证明后者在新环境适配上的效率远超前者（免训练即 4 倍提升）。但参数化知识在检索库覆盖不到的长尾上仍不可替代。合理的资源分配：高频通用模式参数化，长尾场景经验库存化。这对 Spatial AGI 的训练数据投资策略有直接指导意义。

### 开放问题

1. 检索物从轨迹升级为多模态经验（力/接触/事件）后的校正与引导形式；
2. 多源经验的聚合检索与组合引导（不选一条而融合多条）；
3. 引导强度的自适应（基于策略自身不确定性）；
4. 失败经验的负向利用（检索到相似失败案例时主动避开其轨迹）；
5. 检索库的增量学习：真机执行的新经验如何自动校正入库。

## 术语表

- **VLA**: 视觉-语言-动作模型，接收观测与指令输出机器人动作的基础模型；
- **Flow Matching**: 通过学习条件向量场把噪声分布输运到目标分布的生成建模范式；
- **Energy Guidance**: 在生成过程采样/去噪时叠加能量函数梯度以引导输出；
- **DTW (Dynamic Time Warping)**: 动态时间规整，对齐两条不等长时间序列的距离度量；
- **Warping**: 把源域航点映射到目标域后按位移插值校正整条轨迹；
- **Functional-role correspondence**: 按任务功能角色（而非外观）建立跨域实体对应；
- **Policy-aware retrieval**: 以策略跟随兼容性（引导代价梯度范数）为准则的检索；
- **EE SPARC**: 末端执行器轨迹平滑度的谱弧长度量。

4. 功能角色对应是跨域空间语义的正确抽象级别。

## 常见问题（FAQ）

**Q1: RAGu 和 prompt 工程式的 in-context VLA 有什么本质区别？**

ICL 把演示拼进输入序列，受上下文窗口限制且要求 VLA 训练时见过类似格式；RAGu 的引导发生在输出生成的动力学过程中，与上下文无关，任何 flow-matching 策略即插即用。

**Q2: 能引导非 flow-matching 的 VLA（如自回归 token 策略）吗？**

论文的机制建立在连续去噪动力学上，自回归离散动作 token 没有直接对应的梯度引导。可能的桥接：在 token 策略的连续潜空间（如 VLA 的中间特征）施加引导，但这超出本文范围。

**Q3: 为什么真实世界提升（4倍）远大于仿真？**

因为域偏移的重灾区在真实世界（光照、纹理、视角的不可控变化），仿真环境相对结构化、域偏移轻，基线本来就高，提升空间相应小。这反过来印证：RAGu 解决的正是真实部署的核心痛点。

**Q4: 检索库怎么建？成本多大？**

直接复用公开数据集（DROID），只需标签筛选 + 一次性 DTW/warp 预处理。新增成本主要是存储与检索索引维护，相对数据采集成本可忽略。

## 伦理与安全视角

- **检索库治理**：如果检索库含危险操作（开锁、持刀），任何 VLA 都能零训练借用——检索库需要内容安全过滤与访问控制，这是比模型安全更难治理的分布式知识库问题；
- **域外滥用**：warping 机制无差别迁移能力，安全约束（如"不碰人"）本身不随骨架迁移，需要安全约束的持久注入层（如恒定的避人能量场叠加在 L_warp 之上）；
- **隐私**：演示轨迹泄露家庭空间布局信息，公共检索库需要轨迹脱敏（几何骨架+去除绝对坐标）的标准。

```python
pool = filter_by_keywords(DROID, task_keywords)        # 语义任务类过滤
ref   = pool[0]                                        # 任意参考轨迹
candidates = top_n_dtw(pool, ref, N)                   # DTW 粗剪枝
bboxes = grounding_dino(target_scene)                  # 目标域实体检测
warped = [warp_to_scene(c, waypoints=bboxes_roles(c))  # 功能角色对应+插值校正
          for c in candidates]

# ---- 在线推理（每控制步） ----
for tau in denoising_steps:
    if tau == 0:                                       # 仅第一步做细检索
        X_t = forward_kinematics(vla_estimate(A_tau1))
        costs = [grad_norm(dL_dA0, C_i(X_t, seqmatch(X_t, w_i)))
                 for w_i in warped]
        i_star = argmin(costs)                         # 策略感知选择
    v = vla_velocity_field(A_tau, obs)
    g = gradient(C_{i_star}(X_t))                      # L_warp
    A_tau = integrate(v - gamma * g)                   # 引导去噪
execute(action_chunk(A_1))
```

## 风险与缓解对照表

| 风险 | 场景 | 缓解方向 |
|---|---|---|
| 检索池无覆盖 | 全新任务类别 | 检索置信度估计 + 回退探索/询问机制 |
| warping 误差累积 | 非结构化场景、形变物体 | 世界模型辅助的更精细对应；闭环重校正 |
| 引导强度失配 | 过强僵硬/过弱无效 | 基于策略不确定性的自适应 γ |
| 中途结构变化 | 抓取失败、动态障碍 | 事件触发的在线重检索 |
| 力/接触信息缺失 | 接触主导任务 | 多模态经验单元（轨迹+力+接触图） |
| 安全约束不迁移 | 危险区域、人机共处 | 持久安全能量场叠加 |

## 与 Spatial AGI 记忆体系的理论定位

认知科学中记忆常分为：情景记忆（具体事件）、语义记忆（抽象事实）、程序性记忆（技能）。映射到 Spatial AGI：

- **参数化权重 ≈ 程序性记忆**：RAGu 中冻结 VLA 内化的"how"；
- **检索骨架库 ≈ 情景记忆**：具体时空经验，可精确复用；
- **功能角色抽象 ≈ 语义记忆**：跨域不变的槽位结构。

RAGu 的三步管线恰好是三种记忆的协同：语义记忆提供对应结构（role matching），情景记忆提供内容（warped 轨迹），程序性记忆提供执行（VLA 闭环）。这提示 Spatial AGI 记忆系统设计的完整性检验：三种记忆是否都有载体、有接口、有协同协议。
