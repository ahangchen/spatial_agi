## 摘要

这篇论文提出了**Multi-Object Generative Perception (MultiGP)**，一种生成式逆渲染方法，能够从单张图像中随机采样所有辐射度成分——反射率、纹理和光照。解决这个本质上模糊的辐射度解耦问题的关键思想是利用一个事实：虽然场景中的物体在纹理和反射率上可能不同，但它们都被相同的光照照亮。

MultiGP利用这种共识，基于四个关键技术贡献，从已知形状的单张图像中生成反射率、纹理和光照的样本：
1. **级联端到端架构**：结合图像空间和角度空间的解耦
2. **协调引导**：管理扩散过程的时间调度，确保不同物体的光照估计收敛到一个一致的环境贴图
3. **轴向注意力**：促进不同反射率物体之间的"交叉对话"
4. **纹理提取ControlNet**：保留高频纹理细节，同时确保与估计光照的解耦

实验结果表明，MultiGP有效地利用了多物体外观的互补空间和频率特征，恢复了个体纹理和反射率以及共同光照。

## 研究背景与动机

### 物体外观的丰富信息

物体的外观揭示的远不止其3D形状和语义身份。例如，看一眼杯子，还可以揭示其材料属性（如陶瓷、硬、重，可能有印刷的文字或图形），并提供周围光照的信息反射。解读这些丰富、纠缠的信息对于交互至关重要：
- 允许具身智能体根据感知的材料规划抓取
- 预测物体从不同视角看起来的样子
- 预测其他物体如果放在同一场景中会看起来如何

### 辐射度解耦的根本挑战

然而，这种辐射度解耦是极其病态的。周围的光以与每个表面点的局部几何和反射率唯一的角度响应进行反射，类似于具有位移相关核的角度卷积。这深度地将物体材料与环境光纠缠在一起，并且本质上有损，因为表面反射通常会衰减光的高角度频率细节。所有这些使得从单张图像恢复材料和光照在根本上具有模糊性。

### 生成式感知框架

"生成式感知"是解决视觉中这些模糊性的框架，通过使用随机生成模型从可能物理解释的分布中采样。先前的工作集中在于：
- 从图像中生成材料和形状的样本（无光照）
- 从视频中生成材料和形状的样本（无光照）
- DRM从已知形状的图像中生成反射率和光照的样本（但不能处理纹理物体）

### 多物体的关键洞察

本文的核心洞察：当图像中存在多个物体时，更丰富的辐射度成分——反射率、纹理和光照——的随机采样成为可能。**关键洞察：虽然场景中的物体在纹理和反射率上不同，但它们都被相同的光照照亮。**

## 核心问题与挑战

### 1. 内在模糊性

从单张图像恢复材料和光照是根本模糊的，因为：
- 光照与材料深度纠缠
- 表面反射衰减高频细节
- 多种解释可能同样有效

### 2. 频率损失

表面反射率通常会衰减光的高角度频率细节：
- 朗伯表面反射低通滤波的光照
- 更镜面的物体保留相对较高频率的细节
- 没有单一材料能保留所有频率

### 3. 空间稀疏性

不同物体的几何形状导致：
- 不同的可见表面法线覆盖
- 互补的空间覆盖范围
- 需要整合多个视角的信息

## 方法论

### 4.1 问题形式化

#### 渲染方程

物体的外观可以用其表面辐射度L_r描述，忽略全局光照效应时，由表面法线n、双向反射分布函数(BRDF) f_r和入射光照L_i决定：

```
L_r(x, ω_o) = ∫_ω f_r(x, ω_i, ω_o) L_i(ω_i) (ω_i · n(x)) dω_i
```

其中ω_i和ω_o是局部半球中的入射和出射光方向。

#### Disney BRDF模型

采用Disney BRDF模型：

```
f_r(x, ω_i, ω_o; ρ_d(x), Ψ := {ρ_s, r, γ}) = 
  (1-γ) [ρ_d(x)/π (f_diff + f_retro)] + f_spec
```

其中：
- ρ_d(x)是空间变化的纹理
- Ψ是空间均匀的反射率，包括：
  - r：粗糙度
  - γ：金属度
  - ρ_s：镜面强度

#### 联合后验

给定包含M个物体的图像I和已知形状S，求解：
- 每个物体的纹理T = {ρ_d(x)_m}
- 每个物体的反射率R = {Ψ^(m)}
- 共享光照L

联合后验：
```
p(T, R, L | I, S) ∝ p(I | S, T, R, L) p(T, R, L | S)
```

#### 级联分解

使用级联分解近似：
```
q(T, R, L | I, S) = q_φ(T | I, S) q_θ(R, L | I, S, T)
```

这个分解直接决定了架构：
1. 纹理提取模块q_φ
2. 联合反射率-光照模块q_θ
3. ControlNet精炼

---

### 4.2 级联分解架构

#### 架构概述

MultiGP采用三阶段级联架构：

**阶段1：纹理提取 (q_φ)**
- 输入：RGB图像 + 已知形状
- 输出：纹理T + 无纹理外观
- 方法：潜在扩散模型

**阶段2：反射率-光照估计 (q_θ)**
- 输入：无纹理反射率图
- 输出：共享光照L + 各物体反射率R
- 方法：多物体扩散反射率图

**阶段3：纹理精炼**
- 输入：估计的T, R, L + 已知几何S
- 输出：精炼的纹理T'
- 方法：ControlNet + 渲染器一致性检查

#### 工作流程

```
单张图像 → [纹理提取] → 无纹理外观
              ↓
         反射率图转换
              ↓
         [多物体扩散] → 共享光照 + 反射率
              ↓
         [ControlNet精炼] → 最终纹理
```

---

### 4.3 纹理提取先验 (q_φ)

#### 潜在扩散模型

第一阶段使用潜在扩散模型，条件是观察外观和物体形状的连接潜在表示c。

扩散动力学：
```
z_t = √(ᾱ_t) z_0 + √(1-ᾱ_t) ε
```

其中ε ~ N(0, I)。

#### 损失函数

基础损失：
```
L_φ = E_{z_0, t, ε} [||ε - ε_φ(z_t, t; c)||²_2]
```

网络ε_φ预测添加的噪声，估计纹理T和中间无纹理外观L_r(x; Ψ)。

#### 特点

- 处理全局光传输效应
- 考虑物体形状条件
- 同时估计纹理和中间无纹理外观

---

### 4.4 多物体扩散反射率图 (q_θ)

#### 反射率图表示

每个无纹理外观L_r^(m)(x)映射到形状不变的原始反射率图L̃_r^(m)(n)，这是一个按表面法线n索引的表面辐射度高斯球。

#### ObsNet扩展

原始反射率图通过学习的网络（ObsNet的多物体扩展）转换为完整反射率图：
- 利用轴向注意力
- 缓解全局光传输效应（如投射阴影和相互反射）

#### DRM框架扩展

基于Diffusion Reflectance Map (DRM)框架，扩展到多物体设置：
- 每个表面反射相同光照的不同空间范围和频带
- 由其独特的BRDF和几何决定
- 协调这些互补信号

#### 前向过程

索引每个反射率图按扩散步骤k：
- L_r^(m,K)(n)：初始观察
- L_r^(m,0)(n) = L̂_i(n)：目标镜面反射率图

前向过程不是马尔可夫噪声链，而是由渲染方程控制的确定性辐射度形成，加上高斯噪声：

```
q(L_r^(1:M,1:K) | L_r^(0), Ψ^(1:M,K)) = 
  ∏_{m=1}^M ∏_{k=1}^K N(L_r^(m,k) | L_r(Ψ^(m,k), L_r^(0)), σ²I)
```

#### 照明损失

证据下界(ELBO)分解为每物体项的总和：

```
L_i = E_{L_i, Ψ, m, k} ||μ'_{θ_i, θ_r} - {L_r(Ψ^(m,k-1), L_r^(0)) - L_r^(m,k)}||²_2
```

---

### 4.5 协调调度 (Coordinate Scheduling)

#### 目标

将M个观察到的反射率图L_r^(m,K)（每个代表不同材料）转换回单个镜面反射率图L_r^(0)(n)，揭示环境光照L̂_i(n)。

#### 线性调度

安排每个物体的反射率从其估计材料Ψ̂^(m,K)线性演化到已知镜面反射率Ψ_0，在K个共享步骤内：

```
Ψ̂^(m,k) = (k/K) Ψ̂^(m,K) + (1 - k/K) Ψ_0
```

这确保所有M个物体在k=0时同时达到镜面反射率，同时保持它们的相对比例。

#### 与DRM的对比

- **DRM**：需要无限步骤收敛
- **MultiGP**：有限K步同时收敛

#### 步骤数确定

总步骤数K与输入材料到镜面反射率的平均距离成正比：

```
K = (K_max / M) Σ_{m=1}^M ||(Ψ̂^(m,K) - Ψ_0) / √3||²
```

其中：
- K_max是最大允许步骤
- √3归一化3维反射率空间{金属度, 粗糙度, 镜面}中的最大可能距离

这保证最远反射率Ψ = {0, 1, 0}能在K_max步内达到镜面状态Ψ_0 = {1, 0, 1}。

#### 反射率损失

```
L_r = E_{L_i, f_r, m, k} [||Ψ̂_{θ_r}^(m,k) - Ψ^(m,k)||²_2 + ||Ψ̂_{θ_r}^(m,K) - Ψ^(m,K)||²_2]
```

总损失：L = λ_i L_i + λ_r L_r

---

### 4.6 轴向注意力 (Axial Attention)

#### 动机

从每个物体转换的无纹理反射率图L̃_r^(m)(n)在空间上是稀疏的——除非物体是球体，否则其几何不会密集覆盖相机面向表面法线的整个半球。

更重要的是，不同材料对环境光起到不同的频率滤波器：
- 朗伯表面反射低通滤波的光照
- 更镜面的物体通过带通滤波保留相对较高频率的细节
- **没有单一材料能保留所有频率**

#### 互补性

多个物体外观捕获共享光照的互补空间-光谱特征：
- 频率互补性：不同材料保留不同频带
- 空间互补性：不同几何覆盖不同法线方向

#### 多物体轴向注意力

受视频扩散中时间注意力的启发，在M个反射率图的每个对应空间位置（即相同表面法线方向）上操作。

**机制**：
- 跨多个部分观察的反射率图应用轴向注意力
- 允许物体从场景中其他物体借用信息
- 有效将多物体观察统一为对全局光照的连贯、完整估计

#### 局部空间注意力

也应用局部空间注意力，避免信息整合仅沿完美对齐的法线方向，使MultiGP对几何误差具有鲁棒性。

---

### 4.7 纹理精炼ControlNet

#### 动机

虽然级联分解产生多样化样本，但一些可能仍违反图像形成的物理规律。

#### 方法

引入最终精炼步骤，将渲染器一致性注入采样过程：

1. 给定采样因子(T, R, L)和已知几何S
2. 使用Mitsuba 3渲染物体L̂_r
3. 计算与观察图像I的残差
4. 通过ControlNet机制条件q_Φ于此残差

#### ControlNet条件

接受残差c_f = E(I - L̂_r)作为额外条件，强制纹理估计与全局光传输之间更紧密的物理一致性：

```
L_{φ_c} = E_{z_0, t, ε} [||ε - ε_{φ_c}(z_t, t; c, c_f)||²_2]
```

#### 特点

- 作为似然引导采样而非显式优化
- 使用基于渲染器的信号修改采样动力学
- 在保持生成多样性的同时提高物理一致性

## 实验结果

### 5.1 数据集

#### 训练数据

- **合成物体图像和反射率图**：使用Mitsuba3渲染
- **纹理**：
  - 96个纹理用于1100个Adobe 3D Assets
  - 24个形状相关纹理用于4000个Xu形状（使用MV-Adapter）

  - 金属度限制为0或1（避免Disney BRDF下的不现实反射率）

- **光照**：从Laval Indoor Dataset和Poly Haven HDRIs随机采样，共2000个独特环境贴图

#### 合成测试数据

- **准确性评估**：Adobe 3D Assets测试分割 + MV-Adapter纹理 + 保留光照，形成36个物体三元组
- **多样性评估**：从nLMVS-Synth形状构建伪原始反射率图

#### 真实世界数据

1. **Stanford-ORB**：14个物体，7个场景
2. **nLMVS-Real**：选择在大约相同位置、视点和光照下捕获的物体三元组，27个三元组
3. **MultiGP数据集**（新捕获）：
   - 9个真实场景（3个室外，6个室内）
   - 每个场景3个物体在共享光照下
   - 使用Artec3D扫描物体形状
   - 使用MegaPose对齐到相机坐标

### 5.2 模糊性感知的逆渲染指标

#### 标准指标

**光照评估**（128×256分辨率）：
- Scale-invariant logRMSE（HDR图像）
- PSNR, SSIM, LPIPS（色调映射的LDR图像）

**反射率评估**：
- Scale-invariant logRMSE（非参数MERL BRDF表示）
- 与DPI和DRM比较（生成空间变化BRDF的方法不兼容）

**纹理评估**（512×512）：
- Scale-invariant RMSE, PSNR, SSIM, LPIPS

#### 模糊性感知指标

**动机**：标准指标在逆渲染中经常失效，因为多种光照可以产生相同的外观，特别是在低频反射率下。

**方法**：
1. 对每个光照样本计算1089个球谐(SH)系数（最高32阶）
2. 对系数应用PCA（保留99%方差）
3. 建模样本分布
4. 报告ground truth在此分布中的：
   - 多元正态对数似然
   - 马氏距离

#### 评估协议

- 对所有随机方法（除ALP），采样10个预测并报告top 3的平均值
- 在多物体场景上评估单物体基线时，报告具有最清晰估计反射率的物体的结果

### 5.4 模糊性感知准确性分析

#### 异质反射率场景（图4a）

**设置**：具有不同反射率的物体（异质反射率）

**观察**：
1. 输入外观展现互补的光谱特征
2. 最闪亮的物体通常覆盖广泛频谱，但不提供详尽信息

## 创新点与优势

### 技术创新

#### 1. 级联分解架构

**创新**：
- 分离纹理和反射率-光照估计
- 图像空间和角度空间的协同解耦
- 端到端可训练

**优势**：
- 简化问题复杂度
- 专注不同方面的估计
- 提高整体性能

#### 2. 协调调度

**创新**：
- 多物体同步收敛到镜面反射率
- 有限步骤收敛（对比DRM的无限步）
- 保持相对比例

**优势**：
- 确保光照一致性
- 提高收敛效率
- 避免无限优化

#### 3. 轴向注意力

**创新**：
- 跨物体的信息共享
- 频率和空间互补性利用
- 鲁棒的几何误差处理

**优势**：
- 整合互补信息
- 提高估计准确性
- 增强鲁棒性

#### 4. 纹理精炼ControlNet

**创新**：
- 渲染器一致性注入
- 似然引导采样
- 保持生成多样性

**优势**：
- 提高物理一致性
- 避免显式优化
- 平衡准确性和多样性

### 方法论创新

#### 1. 多物体共识

**创新**：利用共享光照约束

**优势**：
- 提供强物理约束
- 提高估计准确性
- 建立物体间关系

#### 2. 生成式感知框架

**创新**：随机采样多种解释

**优势**：
- 捕获固有模糊性
- 提供多样化样本
- 支持不确定性量化

#### 3. 模糊性感知评估

**创新**：基于分布的评估指标

**优势**：
- 更准确的性能评估
- 考虑固有模糊性
- 适合逆渲染任务

### 与其他工作的比较

#### vs. 确定性方法

**优势**：
- 捕获模糊性而非单一估计
- 提供多样化样本
- 更适合不确定性场景

**劣势**：
- 计算成本更高
- 需要多次采样
- 结果解释更复杂

#### vs. 单物体方法

**优势**：
- 利用多物体互补信息
- 更准确的光照估计
- 场景级别一致性

**劣势**：
- 需要多物体场景
- 依赖已知几何
- 处理更复杂

#### vs. 无纹理方法（DRM）

**优势**：
- 处理纹理物体
- 更丰富的材料估计
- 更广泛的应用

**劣势**：
- 更复杂的架构
- 更多的计算需求
- 更多的训练数据需求
