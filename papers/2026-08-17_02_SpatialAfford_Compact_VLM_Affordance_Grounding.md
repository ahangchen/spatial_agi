## 论文一句话总结

SpatialAfford 诊断出紧凑自回归 VLM 在可供性接地中的"注意力-输出失配"问题（坐标预测在改进而跨模态注意力仍弥散错位），提出两阶段框架：先用 Spatial Attention Alignment（SAA）以 KL 散度将跨模态注意力对齐到真值可供性区域（教会"看哪里"），再用 Spatial-Aware GRPO 以 IoU+坐标邻近+格式复合奖励精炼坐标生成（教会"接地到哪"），使 4B 模型在 ShareRobot-Bench/ReasonAff/PartAfford 三个基准上超越 7B-8B 基线。

## 核心问题

### Q1: 核心算法原理

**问题**: 这篇文章的核心算法原理是什么？

**分析**:

1. **核心思想和动机**

   - **问题诊断先行**：作者发现紧凑自回归 VLM（如 Qwen3-VL-4B）在可供性接地任务上存在一个隐蔽但致命的现象——**注意力-输出失配**：
     - 标准 SFT 只对坐标 token 序列算交叉熵损失，梯度虽然反向传播经过中间层，但对跨模态注意力矩阵 A^(l) ∈ R^(N_text × N_img) **没有任何显式监督**；
     - 结果是模型可以"答对坐标"（通过全局物体捷径/伪相关），但其跨模态注意力密度在真值区域 M_gt 内反而低于区域外：E_{i∈M_gt}[A_{j,i}] < E_{i∉M_gt}[A_{j,i}]，且 NSS（Normalized Scanpath Saliency）接近零或为负；
     - Qwen3-VL-4B 还表现出**注意力沉溺（attention sink）**现象：注意力集中于初始 token 而非目标可供性区域；
   - **核心洞察**：**先修"看哪里"（attention），再修"接地到哪"（coordinate）**。当局部证据未被稳定锚定时，后续坐标解码容易被粗粒度物体线索驱动；先对齐视觉焦点，再优化坐标策略，接地才能从"纯输出约束目标"变成"视觉接地的推理过程"。

2. **主要技术方法**

   **阶段 1：Spatial Attention Alignment（SAA）——修"看哪里"**

   从真值可供性框 B=(x1,y1,x2,y2)（norm1k 归一化坐标）构造视觉 token 网格上的监督目标分布：

   - **Step 1 Bbox→网格掩码**：将 bbox 映射到视觉特征网格 H_g×W_g（按视觉编码器分辨率动态确定），g_x = ⌊x/1000·W_g⌋，得到二值掩码 M；
   - **Step 2 自适应盒式模糊**：用核大小 k = max(3, min(⌊max(b_w,b_h)/2⌋×2+1, 7)) 的均匀均值滤波器平滑二值掩码——核随目标尺寸自适应、限制在 3-7 奇数范围内以保持局部性，经 2D 卷积得 M̃；
   - **Step 3 归一化**：P_M = M̃ / Σ M̃[i,j]，成为概率分布形式的监督目标；
   - **SAA 损失**：L_SAA = KL(P_S ∥ P_M)，惩罚模型注意力分布 P_S 分配给任务无关区域的概率质量。P_S 是跨文本指令 token 与指定 Transformer 层聚合的归一化跨模态注意力图；注意力仅在指令 prompt 位置提取，防止 teacher-forcing 捷径泄漏；
   - **阶段 1 总目标**：L_Stage1 = L_SFT + α·L_SAA（α=0.1 最优）。

   **阶段 2：Spatial-Aware GRPO——修"接地到哪"**

   在 SAA 对齐后的特征空间 F_SAA 上做策略优化：

   - **GRPO 框架**：每个查询采样 G=4 个候选输出，组相对优势 Â_g = (R_g - R̄)/(σ_R + ε)，裁剪代理目标 + KL 正则（BNPO 变体，自适应 KL 控制 β∈[0.10,0.50]，KL_target=1.0）；
   - **空间奖励引擎**（三复合）：
     1. **空间重叠奖励 R_IoU**：预测框与真值框的最优匹配平均 IoU（支持多框）；
     2. **坐标邻近奖励 R_L1**：norm1k 空间中四坐标平均绝对距离，R_L1 = max(0, 1 - d̄_1/τ)，τ = 0.05·(W+H)/2（宽容带随图像尺寸缩放）；
     3. **格式奖励 R_format**：二值，验证输出严格遵循 [(x1,y1,x2,y2)] 语法；
   - **总奖励**：R = (R_IoU + R_L1)/2 + R_format。

3. **算法流程和关键步骤**

   ```
   输入: 图像 I + 指令 T（如 "reach the mug's handle"）+ 真值框 B_gt
   ── 阶段1: SFT + SAA ──
   1. 视觉编码器 → N_img 个 patch token
   2. LLM 第 l 层 → 跨模态注意力 A^(l) (text→image)
   3. B_gt → 网格二值掩码 → 自适应模糊 → 归一化 → P_M
   4. 聚合指令位置注意力 → 归一化 → P_S
   5. L = L_SFT(bbox tokens) + 0.1·KL(P_S∥P_M)
   ── 阶段2: Spatial-Aware GRPO ──
   6. 每查询采样 G=4 个坐标输出
   7. 解析 bbox → 计算 R_IoU, R_L1, R_format
   8. 组相对优势 + 裁剪目标 + KL 正则 → 更新策略
   输出: 高精度可供性边界框（注意力与输出同时对齐）
   ```

4. **输入输出**

   - **输入**：RGB 图像（视觉编码器产出 patch token 网格）+ 自然语言指令（指定交互意图，如"抓把手""按按钮"）；
   - **输出**：可供性区域边界框 [(x1,y1,x2,y2)]（norm1k 坐标），且内部跨模态注意力集中于该区域（可解释性副产品）。

5. **一个具体例子（帮助理解）**

   设输入图像含一个马克杯，指令为 "reach the mug's handle"：
   - 真值框 B = (420, 310, 580, 520)（把手区域，约占图像 16%×21%）；
   - 未对齐的 Qwen3-VL-4B：注意力弥散在杯身与背景，输出框可能罩住整个杯子（物体级捷径），P@50 勉强命中或脱靶；
   - SAA 训练后：指令 token 的跨模态注意力在把手网格区域密度最高，输出框紧贴把手；
   - Spatial-Aware GRPO 后：边界坐标误差被 L1 奖励逐步压低，IoU 从 0.5+ 提升到 0.7+，P@50-95 高阈值区间得分大幅提升。

6. **两阶段的互补性直觉**

   - SAA 解决"证据错定"：不看对地方，坐标迟早是统计猜测；
   - GRPO 解决"边界精细"：看对了地方，输出数字还可以更准；
   - 缺一不可：只 SAA 输出粗精（P@50 40.50 封顶），只 GRPO 表面精（45.55 但注意力仍错），两者结合 55.00 才是"看对且接准"。

### Q2: 与Spatial AGI的关系

**问题**: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**分析**:

1. **如何理解和表示空间**

   - SpatialAfford 的空间表示是**功能分区的 2D 空间**：它把"物体级"空间分解为"部位级"功能区域——把手、按钮、扳手头部。这对应 Gibson 可供性理论：空间的语义不由几何类别定义，而由**智能体可执行的动作**定义；
   - 其技术贡献在于把这种功能空间**显式注入注意力机制**：P_M 分布本质上是一张"功能显著图"，模型学到的是"空间中哪些位置是动作锚点"；
   - norm1k 坐标系 + 视觉 token 网格的双映射，建立了"像素空间 ↔ token 空间"的几何对应，这是 VLM 空间输出的通用底座。

2. **如何处理空间关系**

   - **指令-区域的绑定**：核心空间关系是"语言意图 → 视觉功能区域"的跨模态映射。SAA 强制这一映射走"注意力之路"而非"语言先验捷径"；
   - **粗到细的空间分解**：物体（粗）→ 可供性部位（细），两阶段训练先锚定细粒度证据，再精化坐标边界，模拟人类"先看到把手再看准边界"的视觉过程。

3. **对Spatial AGI的启发**

   - **"注意力失配"是 VLM 空间能力的深层瓶颈**：本文证明坐标输出正确 ≠ 空间理解正确——模型可以通过统计捷径"答对"而完全不看正确位置。这对整个 Spatial AGI 评估体系是重要警示：**只看输出指标的基准会高估空间智能**（呼应 GST-Bench 的"构造性防捷径"理念，一个防输入端捷径、一个防内部注意力捷径）；
   - **内部状态监督是空间能力训练的新维度**：传统 SFT/RLHF 只监督输出端，SAA 开辟了"中间表征监督"路线——注意力图作为可解释且可监督的空间接口。这一思路可推广至：深度注意力（单目度量）、朝向注意力（6D 位姿）、场景图注意力（拓扑关系）；
   - **小模型的空间能力可以通过"对齐"而非"堆参数"获得**：4B 超 8B 的结果说明，紧凑模型的空间瓶颈在于注意力路由质量而非表征容量——这对端侧 Spatial AGI（手机/机器人本体计算）极具工程价值（本文有 Vivo 参与，产业意图明显）。

4. **可以应用到哪些Spatial AGI场景**

   - **机械臂操作的抓取点定位**：ShareRobot 数据即来自机器人操作场景，可直接服务 VLA 系统的"动作锚点"模块；
   - **端侧助老/助残交互**：手机/眼镜识别"哪个是把手、哪个是按钮"，为视障者提供动作引导；
   - **3DGS 场景中的功能区域挖掘**：SAA 的注意力监督思路可与 3D 语言场（如 OutLangSplat）结合，在 3D 空间中定位可供性；
   - **空间注意力审计工具**：NSS/KLD/SIM 指标组合可作为任何 grounding 类 VLM 的"注意力诚实度"审计。

### Q3: 创新点和局限性

**问题**: 基于前面的分析，这个方法的主要创新点和局限性是什么？

**分析**:

1. **主要创新点**

   - **创新点 1：首次系统诊断并解决可供性接地的"注意力-输出失配"**——证明坐标预测改进与注意力错位可以并存，并给出 NSS 接近零的实证证据；
   - **创新点 2：SAA 把真值框几何转化为注意力监督目标**——bbox→网格掩码→尺寸自适应模糊→归一化→KL 对齐的构造链简洁优雅，无需额外标注（复用已有 bbox 标注）；
   - **创新点 3：训练范式的解耦**——"先对齐表征（SAA）再优化策略（GRPO）"的次序依赖在消融中被清晰证明：GRPO 在未对齐特征上单独用只有 45.55 P@50，在对齐后特征上达 55.00；
   - **创新点 4：奖励工程的实用性**——IoU（区域级）+ L1（坐标级）+ format（语法级）三层奖励覆盖不同粒度，τ 自适应宽容带设计合理。

2. **主要局限性**

   - **2D 框接地的天花板**：可供性本质是 3D 的（把手的可抓取方向、按钮的可按压法向），2D bbox 无法表达 6D 交互位姿——下游机械臂还需 6D 位姿估计补全；
   - **注意力监督的层选择敏感性**：P_S 需"指定 Transformer 层"聚合，最优层的选择论文未充分消融（不同层注意力语义不同）；
   - **KL 目标的刚性**：P_M 是从 bbox 生成的各向同性模糊分布，真实可供性的"功能热度"并非均匀（把手两端比中间更可抓），更精细的功能分布或许有益；
   - **依赖 bbox 真值**：SAA 需要 bbox 级标注，无法直接利用海量无标注图像；像素级可供性标注（AGD20K 式）与框级训练的融合未探索；
   - **评测集中在桌面物体域**：ShareRobot（机械臂操作）、PartAfford（工具部件）、AGD20K（日常物体），缺少大场景（门/抽屉/电梯按钮）与动态场景；
   - **GRPO 采样成本**：G=4 全参 GRPO 的训练成本对 4B 模型可控，但扩展到更大模型/更复杂多框任务的开销未讨论。

3. **与其他相关工作的对比**

   - **vs Affordance-R1**（最直接对手）：同样用 GRPO 优化坐标，但只在输出端给奖励；SpatialAfford 增加注意力对齐后 ReasonAff gIoU 74.92 vs 67.41（+7.51）——增益即"注意力对齐"的净贡献；
   - **vs RoboBrain2.5 / RynnBrain**（具身 VLM）：具身指令调优路线在 ShareRobot 上强（RoboBrain2.5-8B gIoU 48.07），但 PartAfford 上大幅落后（58.38 vs 76.37）——说明具身调优的接地能力不通用，注意力对齐更具迁移性；
   - **vs TokAG**（免训练注意力热图）：TokAG 发现内部注意力"含有"可供性线索，SpatialAfford 把这一观察推进为显式训练目标——从"观察现象"到"工程化利用"；
   - **vs 视觉重访类工作（visual retracing）**：诊断结论一致（解码中视觉注意力衰减/语言先验主导），但本文给出训练时修复方案；
   - **vs Faithful GRPO**（早期库内论文，空间推理约束策略优化）：同样用 RL 改空间能力，SpatialAfford 的差异在监督中间注意力而非只约束输出。

## 核心技术发现

- **发现 1：注意力-输出失配是真实且可量化的**——Qwen3-VL-4B 在真值区域内的注意力密度低于区域外，NSS≈0，即使坐标预测尚可；
- **发现 2：SAA 是消融中最大的单点增益**——ShareRobot P@50：SFT 22.50 → SFT+SAA 40.50（+18.0），超过 GRPO 单独使用（45.55 相对 baseline +28.05 但低于 SAA+GRPO 组合）；
- **发现 3：组件次序有依赖**——GRPO 在对齐特征空间上才能发挥全部效果（55.00），证明"表征对齐 → 策略精化"的功能依赖链；
- **发现 4：4B 超 8B**——ShareRobot P@50 55.00 vs RoboBrain2.5-8B 51.80；PartAfford gIoU 76.37 vs 58.38（+17.99）；
- **发现 5：注意力对齐带来 OOD 泛化**——AGD20K 零样本 P@50 37.44%、NSS 1.05 均为第一，gIoU/cIoU 仅次 RoboBrain2.5-8B，证明"看对地方"的能力跨场景迁移；
- **发现 6：α=0.1 的 KL 损失为最优权衡**——过大的注意力约束会损害语言建模能力（论文敏感性分析）。

## 与Spatial AGI的关系

### 直接贡献

- 提供了 VLM 空间接地训练的"中间表征监督"新范式：注意力图成为空间知识的显式接口；
- 证明紧凑模型的空间能力瓶颈在注意力路由而非容量，为端侧 Spatial AGI 提供可行路径。

### 技术启发

- **审计启发**：输出正确性指标之外，NSS/KLD/SIM 注意力诚实度指标应纳入空间能力评估标准；
- **训练启发**：SAA 的"标注几何 → 注意力目标"构造可零成本复用于一切带 bbox 标注的空间数据集；
- **架构启发**：注意力沉溺现象提示，可能需要在解码器中设计空间感知的注意力偏置机制（训练时 SAA → 推理时结构化归纳偏置）。

### 应用场景

- 机械臂抓取点/操作点定位（VLA 的空间前端）；
- 端侧（手机/Vivo 场景）交互引导；
- 3D 场景功能区域挖掘（与 3D 语言高斯结合）；
- 空间注意力可解释性审计工具。

## 个人思考

### 最令人兴奋的发现

- **"答对但看错"是空间智能的照妖镜**。SAA 之前，SFT 把 P@50 从 17.50 提到 22.50，看似在进步，但注意力仍在错误位置——模型的"进步"是学会了输出统计上像答案的数字。这与 GST-Bench 发现的"局部能答、全局失忆"形成互证：**空间智能的评估与训练都需要深入内部表征，输出端指标会系统性撒谎**。
- **消融的次序实验是方法论范本**：SAA-only 40.50 < GRPO-only 45.55 < SAA+GRPO 55.00，但 SAA 带来的表征修复使 GRPO 的增益从 +23.05（相对 SFT）变为 +14.50（相对 SAA）再组合达 55——次序依赖说明两阶段解决的是不同层次的问题，"对齐"与"精化"不可互相替代。
- Vivo 的参与值得注意：端侧模型（4B）+ 注意力效率优化，指向手机成为 Spatial AGI 第一载体的产业路径。

### 阅读中的信息增量

1. 此前认为 GRPO/RL 类方法已充分覆盖空间接地训练——本文证明纯输出端 RL 留有巨大的内部表征红利（+7.51 gIoU 的净差）；
2. 注意力沉溺在坐标生成任务中的表现首次被量化——这不仅是推理问题（之前工作），也直接削弱空间输出质量；
3. "标注几何 → 监督分布"的转化思路（bbox → 模糊掩码 → P_M）简单到令人惊讶其未被更早提出——好想法往往是"显然但没人做"。

### 潜在局限与批判性思考

- KL(P_S∥P_M) 的方向选择：正向 KL 对 P_M 为零区域的惩罚依赖 P_S 也近零，但注意力天然弥散，可能需要反向 KL 或 JS 散度对比实验；
- 群组大小 G=4 偏小：GRPO 优势估计方差较大，更大的 G 是否带来更好边界精化未验证；
- 可供性的"任务上下文依赖性"只在 ReasonAff 部分触及：同一物体不同指令的注意力分化效果未可视化对比。

## 方法论启示：可复用的训练设计清单

从 SpatialAfford 提炼的通用训练设计原则，适用于一切 VLM 空间能力训练项目：

1. **先诊断内部表征，再设计训练目标**
   - 在动手改进前，先用 NSS/注意力密度比等指标量化模型内部表征质量；
   - "输出指标停滞"往往意味着内部表征瓶颈，而非数据不够；
2. **中间表征监督是输出监督的必要补充**
   - 纯输出端损失（CE/RL 奖励）对内部计算路径的约束是间接且弱性的；
   - 任何可提取的中间量（注意力、隐藏状态、MLP 激活）都可以且应该成为监督接口；
3. **标注几何 → 监督分布的转化范式**
   - bbox→掩码→模糊→归一化的构造链可以零成本套用在任何已有标注上；
   - 核心技巧：监督目标要与被监督量的统计性质匹配（注意力弥散→目标也要适度弥散）；
4. **阶段次序实验是必要的**
   - A-only / B-only / A→B / B→A 的完整消融矩阵才能证明组件依赖关系；
   - 本文的 SAA→GRPO 次序增益（55.00 vs 45.55）只有在对照中才可见；
5. **奖励设计的稀疏→密集阶梯**
   - IoU（区域级，稀疏）+ L1（坐标级，密集）+ format（语法级，硬约束）的三层结构值得作为接地类 RL 任务的默认模板；
6. **防监督泄漏的工程细节**
   - 注意力只在指令位置提取（防 teacher-forcing 泄漏）——类似细节决定成败；
7. **小模型的注意力红利**
   - 参数量不是空间能力的决定因素，注意力路由质量才是；端侧场景优先优化注意力而非堆参数。

## 批判性分析：论文可能回避的问题

1. **注意力对齐与因果性的混淆风险**：SAA 提升性能，但注意力集中到底是原因还是伴随现象？缺一个"强制注意力分散但输出正确"的对照组来确认因果链；
2. **跨层注意力聚合的信息丢失**：指定层聚合可能掩盖层间分工（浅层感知/深层语义），更精细的层级策略可能带来额外增益；
3. **基准同源风险**：训练数据（ShareRobot/ReasonAff/PartAfford）与评测基准同名，域内增益需结合 AGD20K OOD 结果谨慎解读；
4. **"看哪里"的可迁移性边界**：AGD20K 仍是日常物体域，跨到驾驶/医疗/工业场景的注意力对齐效果未知；
5. **计算成本透明度**：全参 SFT+GRPO 两阶段的 GPU 时数、注意力提取的额外开销未报告，端侧叙事下的训练成本需谨慎评估。

## 与具身智能产业的接口分析

- **Vivo 参与的信号意义**：手机厂商关注端侧可供性识别（AR 实景交互、无障碍辅助、智能抠图）；4B 模型 + 全参优化的组合暗示其目标设备是旗舰手机 NPU；
- **与 VLA 栈的集成点**：SpatialAfford 可作为 VLA 系统中"空间前端"，为动作生成提供功能锚点——相比直接端到端，这种模块化集成更可控、可审计；
- **与机器人厂商的关系**：ShareRobot 数据源于机器人操作，SAA 增强的接地可直接服务抓取点选择，降低 6D 位姿估计的搜索空间；
- **商业化路径预测**：注意力对齐作为"训练即服务"组件（对任意 grounding 模型的后训练增强）可能比独立模型更有商业价值。

## 总结

### 核心发现总结

SpatialAfford 揭示并修复了紧凑 VLM 空间接地的深层缺陷：坐标输出与跨模态注意力的失配。通过"SAA 注意力对齐（看哪里）→ Spatial-Aware GRPO 坐标精化（接地到哪）"的两阶段解耦，4B 模型在三个基准上全面超越 7B-8B 对手，且注意力对齐带来 OOD 泛化（AGD20K 零样本第一）。消融证明组件间存在功能依赖：策略优化必须建立在表征对齐之上。

### 对Spatial AGI的意义

本文与 GST-Bench 从内外两面共同确立了一个新标准：**空间智能必须是"内部诚实"的**——不仅输出正确，注意力也必须锚定真实空间证据。SAA 开辟的中间表征监督路线，可推广到深度、位姿、拓扑等一切空间知识的注入；其"小模型对齐胜过大模型堆料"的结果，为端侧 Spatial AGI 指明了工程路线。当空间智能的训练从"教模型说答案"进化为"教模型看证据"，Spatial AGI 才真正获得可信赖的感知地基。

# 附录

## 附录A：SAA 构造链的逐步数学细节

### A.1 bbox → 网格掩码

- 输入：norm1k 坐标 B=(x1,y1,x2,y2)，x,y ∈ [0,1000]
- 视觉特征网格 H_g×W_g 由视觉编码器空间分辨率动态决定（不同输入分辨率 → 不同网格）
- 映射：g_x = ⌊x/1000·W_g⌋（连续坐标离散化到网格单元）
- 输出：二值掩码 M[i,j] ∈ {0,1}

### A.2 自适应盒式模糊

- 核大小：k = max(3, min(⌊max(b_w,b_h)/2⌋×2+1, 7))
  - b_w, b_h：以网格单元计的框宽高
  - 小目标（如按钮）→ k=3（轻微平滑，保持精细）
  - 大目标（如桌面）→ k=7（上限约束，防过度扩散）
  - 奇数核保证中心对称
- 操作：M̃ = Conv2D(M, (1/k²)·1_{k×k}, padding=k/2)

### A.3 归一化与 KL 监督

- P_M = M̃ / Σ_{i,j} M̃[i,j]（和为 1 的概率分布）
- L_SAA = Σ_{(u,v)} P_S[u,v]·log(P_S[u,v]/(P_M[u,v]+ε))，ε 保证数值稳定
- P_S：指令 token 位置 × 指定层的跨模态注意力聚合后归一化
- 关键工程细节：仅在指令 prompt 位置提取注意力——若在坐标 token 位置提取，teacher forcing 会让注意力"偷看"已生成的坐标，形成监督泄漏

### A.4 设计的合理性分析

- 为什么模糊而不是硬掩码：注意力天然弥散，硬掩码的 KL 目标会导致大量梯度浪费在"完全不可能达到的稀疏目标"上；模糊提供合理的梯度地形；
- 为什么核随目标尺寸自适应：固定核会导致小目标被过度稀释/大目标过度集中；
- 为什么用 KL 而非 MSE：注意力图归一化后是分布，KL 是分布匹配的自然度量；论文也做了损失函数敏感性实验。

## 附录B：Spatial-Aware GRPO 奖励引擎细节

### B.1 三层奖励的互补性

| 奖励 | 粒度 | 作用 | 取值 |
|---|---|---|---|
| R_IoU | 区域级 | 整体重叠质量 | [0,1]，最优匹配平均 |
| R_L1 | 坐标级 | 边界精调（IoU 盲区） | max(0, 1-d̄₁/τ) |
| R_format | 语法级 | 输出可解析性 | {0,1} |

- IoU 的盲区：IoU=0 时（完全不重叠）梯度信息为零，L1 奖励提供"离多远"的密集信号——这正是 RL 奖励设计中经典的稀疏→密集转换；
- τ = 0.05·(W+H)/2 = 50（norm1k 下 W=H=1000）：坐标平均误差在 50 以内线性衰减给分，超过为 0——宽容带与典型可供性区域尺度匹配。

### B.2 GRPO 配置

- G=4（组大小）：偏小但配合 BNPO 损失与自适应 KL 稳定训练
- β∈[0.10,0.50] 自适应：KL 超过 target=1.0 时增大 β 拉回
- 裁剪目标 + KL 正则的双重稳定机制继承 PPO 家族设计

## 附录C：注意力沉溺与失配现象的机制解读

### C.1 现象

- Qwen3-VL-4B 的跨模态注意力集中于序列初始 token（attention sink），而非目标区域
- 真值区域内注意力密度 < 区域外（公式2 的实证不等式）
- NSS ≈ 0 或为负：注意力与真值显著图几乎不相关

### C.2 为什么坐标还能"答对"

- 捷径1（物体级）：接地目标多在物体内，"框住整个物体"的输出在松阈值下部分得分；
- 捷径2（语言先验）："handle" 常出现在物体特定方位，语言模型的位置先验可猜中；
- 捷径3（中心偏置）：训练集 bbox 分布的中心化统计即可支撑粗略预测；
- 这些捷径在分布内有效，在 OOD（AGD20K 自中心视角+新类别）下暴露——但本文的 AGD20K 结果显示 SAA 后 OOD 反而第一，证明对齐打破了对捷径的依赖。

### C.3 与解码期视觉衰减研究的呼应

论文引用的多项研究（visual retracing、注意力正则化）表明：长链推理中视觉 token 注意力随解码推进而衰减、语言先验主导。SpatialAfford 的诊断（训练前即失配）与之互补：失配不仅在解码中产生，在训练后的静态表征中就存在——因此需要训练时（而非仅推理时）的修复。

## 附录J：与具身智能产业接口的补充讨论

- **手机端侧的可供性应用场景清单**：
  - AR 实景交互：识别环境中可点击/可抓取元素；
  - 无障碍辅助：告知视障用户"门把手在你左手边中部"；
  - 智能抠图/编辑：部件级选择（只选杯盖不选杯身）；
  - 拍照引导："把手转过来会更顺手"类交互建议；
- **机器人栈的接入位置**：感知（SAM/检测）→ **可供性接地（SpatialAfford）** → 位姿估计（6D）→ 动作生成（VLA），作为中间件降低下游搜索空间；
- **注意力可视化作为信任界面**：向用户展示"模型在看哪里"，提升人机交互透明度。

## 附录K：读者快查：本文核心贡献一句话版

1. 诊断：紧凑自回归 VLM 存在注意力-输出失配（答对但看错）；

5. 启示：空间智能训练需要监督内部表征，不只是输出。
