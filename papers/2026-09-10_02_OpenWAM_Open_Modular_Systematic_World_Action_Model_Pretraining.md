## 0. 一句话总结

OpenWAM 把世界-动作模型（WAM）预训练从"黑箱整体"改造成"可控实验程序"：模块化基础设施 + 三组受控实验提炼出三条设计原则，并据此训练出开源的 OpenWAM-α（约 6400 小时自我中心 + 机器人数据），在 8 个仿真基准与真机上保持一流表现。

---

## 1. 研究背景与动机

### 1.1 WAM：视频生成先验 → 可执行控制

World-Action Model 的定位：

- **世界知识**来自视频生成式预训练（对物理、场景、动力学的隐式理解）；
- **可执行性**来自具身经验（机器人轨迹把知识"信道化"为控制信号）。

ZimaBlue、GE-Act 2.0、Motus2 等近期工作都在这条线上，但各自为战。

### 1.2 核心批评：单体化（Monolithic）

现有 WAM 系统把以下所有决策耦合成一个不可分的黑箱：

1. 生成式 backbone 的选择；
2. 视觉表示（latent space）设计；
3. 架构与信息流（世界→动作）；
4. 推理流程；
5. 训练数据配方。

后果：**无法知道哪个设计选择真正起作用**——每篇论文的提升都可能是任何一个组件的功劳。这与 LLM 领域早期"炼丹"阶段如出一辙。

### 1.3 OpenWAM 的定位

> 把 WAM 预训练变成"受控实验科学"：Infra（可组合模块）+ Study（受控实验与原则）+ α（组合原则的开放模型）+ 全栈开源。

---

## 2. 系统组成

### 2.1 OpenWAM-Infra

- 把设计空间因式分解为**可组合模块**；
- 统一的训练、推理、部署与评测接口；
- 任何模块可替换、可消融——WAM 领域的"transformers 库 + 开源科学协议"。

### 2.2 OpenWAM-Study：三个问题与三条原则

**Q1: 继承什么（What to inherit）？**
- 原则 1：上游知识通过**足够强的生成式 backbone** 与**紧凑而信息丰富的潜在空间**迁移；
- 弱 backbone 或过度压缩/过度冗余的 latent 都会掐断知识迁移。

**Q2: 世界学习与动作学习如何互动？**
- 原则 2：世界-动作协同需要三个条件——**专门的动作容量**（dedicated action capacity）、**显式的世界→动作信息流**、**同步的联合去噪**（synchronized joint denoising）；
- 简单共享 trunk + 动作头的"贴皮"设计无法产生协同。

**Q3: 协同如何规模化？**
- 原则 3：具身预训练的主要收益是**域外泛化**（OOD generalization）；
- 自我中心人类数据与机器人数据的**一阶段协同训练**（co-training）优于两阶段，兼顾世界覆盖与动作接地。

### 2.3 OpenWAM-α

- 约 6400 小时自我中心人类 + 机器人数据预训练；
- 覆盖单臂、双臂、灵巧手多种 embodiment；
- 8 个仿真基准 + 真机实验均保持顶级表现（sim-to-real 一致性）；
- 全栈开源：基础设施、评测协议、预训练模型、数据配方。

---

## 3. 三个核心问题

### 3.1 Q1: 核心算法/技术方案是什么？

严格说 OpenWAM 的贡献不是单一算法，而是**方法论 + 蒸馏出的设计原则**：

1. 模块化 WAM 训练栈（backbone × latent × 信息流 × 去噪策略均可替换）；
2. 三组受控实验（每次只动一个变量）量化每个设计选择；
3. 由此导出的 α 模型：强生成 backbone + 紧凑 latent + 专用动作分支 + 显式世界→动作流 + 联合去噪 + 一阶段人机协同训练。

其中"同步联合去噪"值得注意：世界帧与动作在扩散/流匹配过程中**联合**去噪，而非先世界后动作的级联，这保证了两种模态在去噪轨迹上互相约束。

### 3.2 Q2: 与 Spatial AGI 的关系是什么？

1. **WAM 是 Spatial AGI 的"想象-行动"枢纽层**：它同时承载空间理解（世界分支）与空间作用（动作分支），其设计原则直接决定空间智能系统的上限；
2. **"紧凑信息丰富的潜在空间" = 空间表示问题**：原则 1 本质上在说——世界知识能否迁移，取决于视觉 latent 是否保留了足够的几何/动力学信息。这为空间表示研究（3D-aware token、几何 latent）提供了来自 WAM 侧的独立证据；
3. **OOD 泛化优先**：原则 3 表明具身预训练的真正价值不在域内刷点，而在"到没见过的空间配置仍能行动"——这正是空间智能的定义性能力；
4. **开源科学化**：Spatial AGI 需要可复现的实验科学。OpenWAM-Infra 提供了社区级的实验底座，后续空间模块（几何编码器、空间记忆）可以作为可插拔组件被系统评测。

### 3.3 Q3: 创新点与局限是什么？

**创新点**：
1. 领域首个系统化的 WAM 消融研究，三条原则有受控实验支撑而非 scaling 直觉；
2. 完整开源栈，复现与后续研究门槛大幅降低；
3. 一阶段人机数据协同训练的实证结论，纠正了两阶段微调的常见做法；
4. 6400 小时数据 + 多 embodiment 的一致表现，工程完成度高。

**局限**：
1. 数据规模（6400h）与工业级系统（数万小时级）仍有差距，原则在更大规模下是否成立待验证；
2. 消融维度未覆盖所有设计轴（如奖励模型、触觉、语言条件化深度）；
3. 世界分支仍是视频预测范式，显式 3D/几何表示未纳入对照；
4. 长时程任务（>分钟级）与移动操作场景表现未报告；
5. "OOD 泛化"的度量依赖所选基准，基准偏差可能影响原则 3 的普适性。

- Motus2 回答"如何自进化改进策略"；
- OpenWAM 回答"底层应该如何设计与预训练"。

## 5. 个人思考与启发

### 5.1 "科学化"是子领域成熟的标志

OpenWAM 最大的价值可能不是 α 模型本身，而是把社区从"每篇论文一个不可比系统"推进到"共享底座上的可消融实验"。Spatial AGI 领域太需要这种 move——空间表示、空间记忆、空间推理评测都可以复用这套"Infra + Study"范式。

### 5.2 原则 1 的空间智能解读

"紧凑而信息丰富的潜在空间"在空间语境下近乎矛盾律：紧凑要求压缩，信息丰富要求保几何。解决之道大概率是**结构化压缩**——以 3D 几何或场景图为先验组织 latent，而不是无结构 token 的均匀压缩。这给 3D-aware tokenizer 研究一个明确的价值主张。

### 5.3 与昨日思考的接续

昨天（ZimaBlue、Zeva）的结论是"世界-动作闭环与自进化是趋势"；OpenWAM 进一步指出闭环要有**专门的动作容量与显式信息流**才能成立——闭环不是把两个模块拼起来，而是要在架构与训练目标层面打通。
