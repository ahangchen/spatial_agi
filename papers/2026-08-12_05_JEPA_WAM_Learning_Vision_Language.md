## 论文摘要

鲁棒的机器人控制受益于显式建模状态转换，但视频生成的世界动作模型 (WAMs) 引入了大量部署成本。现有潜在 WAMs 避免显式未来生成，但通常压缩预测表示或将预测建模与动作生成使用的表示分离。本文引入 JEPA-WAM，一个在预训练 V-JEPA 空间中构建的潜在 WAM，通过共享预测器将潜在转换预测与连续动作生成耦合。JEPA-WAM 预测一个空间结构的联合当前-未来目标，捕获当前和未来观测之间的任务共享视觉时间结构，同时保持密集的 patch 级对应。通过共享预测器，转换监督直接塑造骨干网络，从中提取专用表示用于动作预测。在 LIBERO-Plus 上，JEPA-WAM 达到 79.2%（无大规模机器人策略预训练的最佳结果），其预训练 π₀.₅ 实例化达到 86.3%（总体最佳）。

## 核心问题分析

### Q1: 核心算法原理

#### 1. 核心思想和动机

JEPA-WAM 解决的是潜在 WAM 设计中的两个核心问题：

**问题1：学习什么预测目标？**

现有方法的局限：
- 从生成式世界模型复用中间特征 → 这些特征为迭代帧生成优化，不直接表示状态变化
- 压缩未来观测为少量潜在 tokens → 可能丢失细粒度空间结构
- 使用独立的潜在动力学模块 → 与动作生成的连接较弱

JEPA-WAM 的解法：在预训练 V-JEPA 2.1 表示空间中构建**联合当前-未来转换目标**。不是预测孤立的未来状态，而是编码当前和未来的时间关系——哪些区域稳定、哪些变化、局部物体和空间关系如何演变。

**问题2：如何将预测监督与动作生成整合？**

现有方法的局限：
- 将预测的未来表示作为动作模块的额外上下文 → 可能暴露冗余信息
- 引入独立的预测目标或潜在动力学模块 → 对动作表示的影响较弱

JEPA-WAM 的解法：使用**共享预测器**同时进行转换建模和动作生成。在一个前向传播中，预测密集的转换目标并产生专用表示用于动作条件化。

#### 2. 主要技术方法

**组件1：V-JEPA 表示空间和联合当前-未来目标**

使用冻结的 V-JEPA 2.1 编码器：

当前视觉表示：
```
Z_t = Concat_{v∈V} E_J(O_t^v) ∈ R^{N_vis × d_J}
```

联合当前-未来目标：
```
Y_{t,t+δ} = Concat_{v∈V} sg[E_J(Stack_time(O_t^v, O_{t+δ}^v))]
```

关键设计：V-JEPA 2.1 的视频分词器将每两帧分组为一个时间 tubelet，因此两帧联合输入产生的空间 token 网格与单帧相同。这意味着 Y_{t,t+δ} 和 Z_t 共享相同的相机和空间 token 排列。

联合目标的优势：
- 不需要重建完整或唯一的未来观测
- 强调时间端点之间的视觉关系
- 捕获稳定和变化的区域
- 保持密集的 patch 级结构（非全局池化）

**组件2：共享预测器**

共享预测器 F_θ（Qwen2.5-0.5B 实例化）同时支持：
- 转换目标的预测
- 动作条件化表示的提取

```
(Q_t^wm, C_t) = F_θ(P_vis(Z_t), ℓ, P_act)
```

其中：
- Q_t^wm：视觉 token 位置的隐藏状态，用于预测转换目标
- C_t：专用表示，用于动作生成

**组件3：转换预测和动作生成**

转换预测：
```
Ŷ_{t,t+δ} = G_φ(Q_t^wm)
L_wm = (1/BN_vis) Σ cos(Ŷ, Y)   # patch 级余弦距离
```

动作生成（流匹配）：
```
L_act = E ||A_ψ(a_τ, τ, s_t, C_t) - (a - ε)||²
```

联合训练：
```
L = L_act + λ_wm * L_wm
```

**预训练 VLA 扩展：π₀.₅ 实例化**

JEPA-WAM 可以直接注入预训练的 π₀.₅ 策略：
- 保持原始感知和动作路径不变
- 添加辅助的转换预测分支
- 转换监督通过共享骨干网络传播

#### 3. 算法流程

**训练流程**：
1. 冻结 V-JEPA 编码当前观测 → Z_t
2. 冻结 V-JEPA 联合编码当前+未来观测 → Y_{t,t+δ}（stop-gradient）
3. 视觉投影器映射 Z_t → 预测器输入空间
4. 共享预测器 F_θ 处理：投影的视觉 tokens + 语言指令 + 动作 placeholder tokens
5. 输出两个表示：
   - Q_t^wm → 转换预测头 G_φ → Ŷ_{t,t+δ}
   - C_t → 动作专家 A_ψ → 动作块
6. 反向传播：L_act + λ_wm * L_wm

**推理流程**：
1. V-JEPA 编码当前观测 → Z_t
2. 共享预测器处理 → C_t
3. 动作专家根据 C_t 生成动作块
4. 转换预测分支不参与推理

#### 4. 输入输出

- **输入**：多视角 RGB 图像、语言指令、本体感觉状态
- **训练额外输入**：δ 步后的未来观测
- **输出**：连续动作序列

### Q2: 与Spatial AGI的关系

#### 1. 如何理解和表示空间

- **V-JEPA 空间表示**：V-JEPA 通过视频自监督预训练获得的表示空间天然具有时间一致性。每个 patch token 保持了空间位置信息，同时编码了时序动态特征。

- **联合当前-未来表示**：JEPA-WAM 的核心创新——不预测孤立的未来，而是预测"当前→未来"的转换关系。这种表示更接近 Spatial AGI 的本质——理解"空间如何随时间/行动变化"。

- **patch 级空间分辨率**：与压缩为少量 tokens 的方法不同，JEPA-WAM 保持了完整的 patch 网格，提供细粒度的空间信息。

#### 2. 如何处理空间关系

- **密集 patch 级对应**：联合目标和预测在 patch 级别有一一对应，可以定位"哪个空间区域发生了什么变化"

- **多视角拼接**：多个相机视角按固定顺序拼接，保持了视角间的空间排列关系

- **cos 距离的 patch 级监督**：每个 patch 独立计算 cos 距离，提供空间局部化的学习信号

#### 3. 对Spatial AGI的启发

- **转换 > 状态**：JEPA-WAM 证明了预测"变化"比预测"未来状态"更有效。这是 Spatial AGI 的核心洞察——空间智能的本质是理解变化和关系，而非静态快照。

- **预训练表示空间的价值**：V-JEPA 的视频预训练提供了时间一致的表示，这对空间推理非常有价值。Spatial AGI 系统应该利用视频预训练来获得时空理解能力。

- **共享骨干的效率**：一个预测器同时服务转换预测和动作生成，是一种优雅的架构设计。

#### 4. 可以应用的Spatial AGI场景

- 机器人操作（精细操作、双臂协作）
- 视频理解与预测（时空变化检测）
- 空间变化检测与推理
- 自主系统的状态转换建模
- 物理推理（理解"什么变化了"和"为什么变化"）

### Q3: 创新点和局限性

#### 1. 主要创新点

- **联合当前-未来转换目标**：这是 JEPA-WAM 最核心的创新。不同于预测孤立的未来状态，联合目标让 V-JEPA 编码器同时看到两个时间点，从而能提取时间关系（稳定/变化区域）。

- **V-JEPA 空间中的 patch 级监督**：保持了密集的空间结构，避免了压缩带来的信息损失。

- **共享预测器架构**：转换预测和动作生成共享同一个骨干，确保预测监督直接优化用于动作的表示。

- **预训练 VLA 的即插即用扩展**：可以注入 π₀.₅ 等预训练策略，保持原始路径不变。

#### 2. 主要局限性

- **V-JEPA 依赖**：性能受限于 V-JEPA 表示空间的质量。如果 V-JEPA 在某些场景下表示不佳，JEPA-WAM 也会受限。

- **时间偏移 δ 的选择**：固定的 δ 可能不适合所有任务。快速操作需要小 δ，慢速操作需要大 δ。

- **余弦距离的局限**：patch 级余弦距离可能不够敏感来捕获细微但重要的空间变化。

- **无显式几何**：虽然 V-JEPA 通过视频学到了一些隐式3D理解，但没有显式的几何建模（如 VGGT）。

#### 3. 与相关工作的对比

| 方法 | 预测目标 | 表示空间 | 骨干共享 | 几何感知 |
|------|---------|---------|---------|---------|
| **JEPA-WAM** | 联合当前-未来 | V-JEPA | ✅ 共享 | 隐式 |
| VLA-JEPA | 未来潜在 | V-JEPA2 | ❌ 分离 | ❌ |
| GWM-VLA | 目标视角 patch | VGGT-Ω | 部分 | ✅ 显式 |
| World Tokens | 视频帧 | VLM→tokens | ❌ 独立 | ❌ |
| SLIM | 未来观测潜在 | DINOv2 | ✅ MoT | ❌ |

## 核心技术发现

### 发现1：联合目标的时间编码效率

V-JEPA 2.1 的视频分词器将每两帧分组为一个 temporal tubelet，因此当前+未来两帧的联合编码产生的空间 token 网格与单帧完全相同。这意味着联合目标"免费"获得了时间信息，而不增加表示维度。

### 发现2：patch 级空间监督的重要性

全局池化的预测目标会丢失"哪个区域变化了"的信息。patch 级监督保留了空间局部性，让模型能定位和理解局部变化。

### 发现3：共享预测器的梯度路径

共享预测器的设计意味着：L_wm 的梯度直接更新骨干 F_θ。这些梯度携带了时间演变的信号，直接塑造了动作表示的来源。

## 与Spatial AGI的关系

### 直接贡献

1. **转换表示学习**：JEPA-WAM 展示了如何学习"空间变化"的表示，而非"空间状态"的表示。这对 Spatial AGI 的核心目标——理解动态空间——至关重要。

2. **预训练视频表示的利用**：证明了 V-JEPA 等视频预训练模型可以为空间推理提供强大的基础。

3. **共享架构的效率**：一个骨干网络同时服务预测和控制，展示了架构效率的上限。

### 技术启发

- **变化是空间智能的核心**：Spatial AGI 系统应该聚焦于理解变化（关系如何改变、状态如何转移），而非仅仅记忆静态配置。

- **视频预训练 → 空间推理**：视频自监督预训练为空间理解提供了丰富的先验知识，应该被 Spatial AGI 系统充分利用。

- **即插即用增强**：JEPA-WAM 可以注入预训练的 π₀.₅，这种"增强已有系统"的能力对 Spatial AGI 的渐进式发展很重要。

### 应用场景

- 机器人操作（高精度、高泛化性）
- 双臂协作操作
- 视频分析与变化检测
- 物理事件识别与推理
- 空间时序推理系统

## 个人思考

### 最令人兴奋的发现

JEPA-WAM 的联合当前-未来目标是一个简洁但深刻的设计。它不要求模型"想象未来"，而是要求模型理解"当前和未来之间的关系"。这种转变——从"生成未来"到"理解变化"——可能代表了 Spatial AGI 中世界建模的正确方向。

更深层地说，这篇论文提出了一种新的预测范式：**不是预测"将会看到什么"，而是预测"将会发生什么变化"**。这两者的区别很重要：
- "将会看到什么"需要重建完整的视觉细节
- "将会发生什么变化"只需要捕获关键的空间-时间转换

### 潜在局限

V-JEPA 表示空间是通用的视频预训练表示，可能不是空间推理的最优表示。一个专门为空间变化设计的表示空间（如结合几何信息）可能更有效。

### 与近期研究的关联

JEPA-WAM 与同日发布的 World Tokens、SLIM，以及此前的 GWM-VLA、VLA-JEPA 构成了"Latent WAM"的完整谱系：

| 维度 | JEPA-WAM | World Tokens | SLIM | GWM-VLA |
|------|----------|-------------|------|---------|
| 预测目标 | 联合转换 | 视频帧 | 观测潜在 | 几何patch |
| 表示空间 | V-JEPA | VLM tokens | DINOv2 | VGGT-Ω |
| 几何先验 | 隐式 | ❌ | ❌ | 显式 |
| 参数量 | 中等 | 2B | 0.5B | ~2B+ |
| 主要优势 | 转换建模 | 训练-推理解耦 | 极简效率 | 几何感知 |

这四篇论文共同定义了2026年中期 Latent WAM 的设计空间，每种方法都在效率、表示质量和架构复杂度之间做出了不同的权衡。

## 总结

### 核心发现总结

JEPA-WAM 引入了一个在 V-JEPA 表示空间中构建的潜在世界动作模型，核心创新是：(1) 联合当前-未来转换目标捕获时间关系而非孤立状态，(2) 共享预测器让转换监督直接塑造动作表示，(3) 可以即插即用地增强预训练 VLA。在 LIBERO-Plus 上达到了无预训练最佳（79.2%）和总体最佳（86.3%）。

### 对Spatial AGI的意义

JEPA-WAM 为 Spatial AGI 提供了一个核心洞察：**空间智能的本质不在于表示状态，而在于表示变化**。通过在 V-JEPA 空间中预测联合当前-未来目标，模型学到了理解空间如何随行动和时间演变——这正是 Spatial AGI 的核心能力。这种方法的高效性（推理时无额外成本）和高性能证明了它的实用价值。
