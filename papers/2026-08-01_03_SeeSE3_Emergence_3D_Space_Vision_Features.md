# SeeSE3: Emergence of 3D Space in Vision Features

**arXiv**: 2607.14228
**发布日期**: 2026-07-15
**机构**: Google DeepMind
**作者**: Caroline Chen, Sayna Ebrahimi, Fedor Kitashov, Ming-Hsuan Yang, Leonidas Guibas, Viorica Pătrăucean, Maks Ovsjanikov
**分类**: cs.CV
**核心问题**: 视觉基础模型能否"发现"3D欧几里得空间的结构？

---

## 摘要概述

本文提出了一个根本性问题：视觉基础模型是否构建了反映3D欧几里得空间内在属性的表示？不同于以往通过回归深度或法线来探测3D感知的工作，本文研究视觉特征空间结构与欧几里得变换群SE(3)之间的关系。作者提出了一组探测方法，从拓扑和几何两个角度评估这种关系：互邻近度量（衡量特征邻域与空间拓扑的对齐）和Poincaré适配器（测试从潜在位移到相机运动几何的线性可达性）。研究表明，自监督视觉模型拥有与3D欧几里得空间高度相关的潜在子空间——即使这些模型没有接受过直接的3D监督。

## Q1: 核心算法原理

### 1.1 核心思想和动机

SeeSE3的出发点是一个深刻的科学问题，灵感来自哲学家亨利·庞加莱（Henri Poincaré）：

> "一个不动的存在永远无法获得空间的概念，因为他没有理由区分位置变化和状态变化。如果他的运动不是自愿的，他也无法获得它。"

——Poincaré

**核心问题**: 一个"不动的观察者"（被动的视觉模型），仅从被动视觉输入中，能否"发现"3D空间的结构？具体来说，视觉模型是否自然地将其潜在空间组织成反映特殊欧几里得群SE(3)的方式？

这是一个革命性的问题，因为：
1. **传统观点**: 发现欧几里得空间需要自主能动性（agency）
2. **现代视觉模型**: 是严格的"不动的存在"——被动观察别人的运动
3. **如果回答是肯定的**: 意味着3D空间感知可以从被动视觉统计中涌现

### 1.2 主要技术方法

#### 问题形式化

设S是一个静态场景，由移动相机观察。编码码器f_θ将时间t的图像I_t映射到高维特征向量z_t = f_θ(I_t)。

核心假设：如果特征空间是几何结构化的，则存在一个固定的、均匀的线性算子W，使得：
ΔP ≈ W(z_{t+s} - z_t)

其中ΔP是SE(3)李代数𝔰𝔢(3)中的6维切向量，包含3个平移速度和3个旋转速度。

这意味着：
- **潜在空间中的差异向量**可以投影为**6维物理运动**
- 这个投影是**线性且均匀的**——在任何空间位置都适用
- 模型"发现"了物理世界的主要自由度

#### 探测方法1 (M1): 拓扑对齐

互k-NN对齐度量：
- 比较视觉特征空间和相机位姿空间中的k近邻
- 如果特征空间的邻域结构与3D位姿空间一致，说明模型捕获了空间拓扑
- 这是无需训练的评估方法

#### 探测方法2 (M2): 内在维度

- 使用MLE和Two-NN估计器估计局部内在维度
- 内在维度接近6意味着表示捕获了6DoF（3平移+3旋转）
- 同样无需训练

#### 探测方法3 (M3): 线性等变性

- 训练线性回归器W从特征差异预测相对位姿变化
- 线性回归成功意味着流形本质上是平坦的
- 这是测试全局欧几里得性质的关键

#### Poincaré适配器

核心创新：一个轻量级Siamese解码器网络：
1. 接收两个视觉特征z_t和z_{t+s}
2. 通过Siamese架构处理
3. 输出预测的6维相对位姿ΔP
4. 产生的坐标系是**均匀的**——到处都适用

与DUSt3R/VGGT等重型Transformer架构的关键区别：
- DUSt3R/VGGT使用高容量解码器"计算"几何
- Poincaré适配器揭示视觉特征**已经组织好**的几何结构
- 这区分了"信息存在"和"结构化组织"

### 1.3 算法流程

1. **数据准备**: 收集静态场景的多帧图像和对应相机位姿
2. **特征提取**: 用预训练视觉编码器提取每帧特征z_t
3. **拓扑评估(M1)**: 计算特征空间和位姿空间的k-NN互对齐
4. **维度评估(M2)**: 估计特征流形的局部内在维度
5. **线性评估(M3)**: 训练线性回归器测试全局等变性
6. **Poincaré适配**: 训练轻量级Siamese网络预测相对位姿
7. **潜在导航**: 利用线性化实现闭式视觉导航

### 1.4 输入输出

- **输入**: 静态场景的图像序列 + 预训练视觉编码器
- **输出**: 
  - 3D空间结构对齐评分
  - 相机位姿估计
  - 闭式潜在空间导航

## Q2: 与Spatial AGI的关系

### 2.1 空间理解和表示

SeeSE3直接研究了空间理解的最根本问题：**视觉模型如何表示3D空间？**

1. **SE(3)涌现**: 研究表明SE(3)结构自然涌现于自监督视觉特征中。这意味着3D空间感知不需要显式3D监督——从视觉统计中可以推断空间结构。

2. **均匀坐标系**: 发现的6维坐标系是均匀的——在不同空间位置含义一致。这是物理空间的核心属性（平移不变性），能在视觉特征中找到对应非常令人惊讶。

3. **特征线性化**: 潜在空间中的线性路径对应物理运动。这意味着在特征空间中"走直线"等于在物理空间中做刚体运动——一种深层的光滑化和线性化。

### 2.2 空间关系处理

1. **相对位姿恢复**: 从特征差异可以线性恢复相对位姿，这意味着特征空间编码了**空间关系**（相对位置和方向）。

2. **邻域保持**: 特征空间的k-NN结构与位姿空间的k-NN结构对齐，说明空间邻近性在特征空间中得到保持。

3. **旋转vs平移**: 旋转比平移更容易编码——这可能反映了旋转在视觉数据中有更明确的线索（纹理梯度变化模式），而平移需要深度信息。

### 2.3 对Spatial AGI的启发

1. **空间表示可能自发涌现**: 不需要显式3D标注或结构化先验，SE(3)结构可以从大规模视觉数据中涌现。这对构建Spatial AGI非常重要——意味着通用的视觉预训练可能已经包含了空间理解基础。

2. **潜在空间导航**: 闭式潜在导航技术可以直接应用于Spatial AGI的导航任务——在特征空间中线性插值即可实现物理导航。

3. **6DoF自由度发现**: 模型能自主发现6个主要物理自由度，这对具身AI至关重要——不需要告诉模型世界是3D的，它能从数据中发现。

4. **旋转和平移的分离**: 旋转更容易学习的发现启示我们，Spatial AGI系统应该特别关注平移表示的改进。

5. **视觉网格编码**: 论文提到"Visual Grid Code"在被动观察者中涌现，挑战了网格细胞需要主动运动的观点。

### 2.4 可应用的Spatial AGI场景

1. **视觉里程计**: 潜在空间导航可以直接用于相机位姿估计
2. **场景定位**: 闭式解的视觉导航用于实时定位
3. **空间记忆映射**: SE(3)结构化的特征可以作为空间记忆的索引
4. **机器人导航**: 潜在空间中的路径规划等价于物理空间导航
5. **3D重建评估**: 作为3D感知质量的探测工具

## Q3: 创新点和局限性

### 3.1 主要创新点

1. **问题范式创新**: 首次提出"视觉特征是否包含SE(3)结构"的问题。这是一个更深层的问题——不是"能否预测深度"（信息层面），而是"特征空间是否被组织成3D形式"（结构层面）。

2. **Poincaré任务**: 将哲学问题（庞加莱的空间感知理论）转化为可计算评估的数学问题，是跨学科创新的典范。

3. **拓扑和几何双重探测**: 从拓扑（M1: k-NN对齐）和几何（M3: 线性等变性）两个角度评估，提供了全面的结构分析。

4. **闭式潜在导航**: 利用Poincaré适配器的线性化能力，实现了无需3D重建的闭式视觉导航。这是空间智能的直接应用。

5. **理论分析**: 提供了自监督方法恢复几何结构的理论条件，分析了SE(3)不同分量的恢复难度（旋转比平移容易）。

6. **Visual Grid Code发现**: 在被动观察者中发现网格编码样的结构，挑战了神经科学中网格细胞需要主动运动的共识。

### 3.2 局限性

1. **仅静态场景**: 所有实验限于静态场景。动态场景中特征-位姿映射不再稳定。

2. **单场景分析**: 分析是在每个场景内进行的。跨场景的SE(3)一致性（即不同场景间共享的空间坐标系）尚未验证。

3. **编码器依赖**: 不同编码器的SE(3)对齐程度差异很大。什么样的训练策略最优尚不完全清楚。

4. **局部vs全局**: Poincaré适配器在局部（相邻帧）有效，全局导航能力需要更多验证。

5. **SE(3)的局限**: 仅考虑了刚体变换SE(3)。真实世界的空间还包括非刚体变形、可变物体等。

6. **尺度模糊**: 单目视觉中平移的绝对尺度不可恢复，这在特征空间中也会有体现。

## 实验结果深度分析

### 视觉编码器比较

论文测试了多种视觉编码器：
- **DINOv2**: 自监督ViT，表现出较强的SE(3)对齐
- **CLIP**: 视觉-语言模型，对齐程度中等
- **MAE**: 掩码自编码器，对齐程度取决于训练数据
- **RADIO**: 近期融合模型，表现优异

关键发现：
1. 自监督模型 > 有监督模型（在SE(3)对齐上）
2. 更大模型通常更好，但不是线性的
3. 训练数据多样性比数据量更重要
4. 视频训练的模型不一定比图像训练的更好

### M1: 拓扑对齐结果

- 互k-NN对齐在短距离（相邻帧）上达到很高水平
- 自监督模型的对齐显著优于随机特征
- 这证明了视觉特征的邻域结构确实反映了空间邻近性

### M2: 内在维度结果

- 优秀编码器的局部内在维度在6-10之间
- 接近6表明特征流形确实被约束到接近6DoF的结构
- 但不是恰好6，说明还有非空间信息混入

### M3: 线性等变性结果

- 线性回归器在预测相对位姿上达到合理精度
- 这意味着特征空间近似全局欧几里得
- 旋转分量的预测精度普遍高于平移分量

### Poincaré适配器结果

- 轻量级Siamese网络有效提取SE(3)结构
- 在多个数据集上泛化良好
- 产生的坐标系确实是均匀的

### 消融研究关键发现

1. **训练范式**: 自监督 > 有监督（发现SE(3)不需要3D标签）
2. **数据组成**: 多场景 > 单场景
3. **架构**: ViT > CNN（全局注意力有助于空间理解）
4. **分辨率**: 高分辨率有助于细粒度空间理解
5. **旋转 vs 平移**: 旋转在所有设置下都更容易编码

## 理论深度分析

### 为什么SE(3)会涌现？

论文给出的理论解释：

1. **视觉数据的物理结构**: 自然图像由3D世界的2D投影生成，所以视觉数据天然编码了3D信息
2. **自监督目标**: 对比学习/掩码预测隐式鼓励模型发现数据的主要变化方向
3. **6DoF是主要变化源**: 在静态场景中，相机运动是图像变化的主要来源，所以自监督学习会优先编码这6个自由度

### 线性化的条件

论文分析了特征空间线性化的必要条件：
1. 编码器必须是局部平滑的（相邻图像→相邻特征）
2. 特征空间必须有足够的维度（至少6维来表示SE(3)）
3. 编码器必须对场景内容有一定程度的不变性（不同场景的相同运动应映射到相同方向）

### 与神经科学的联系

论文与神经科学的深层联系：
1. **网格细胞**: 大脑海马体中的网格细胞编码空间位置。SeeSE3发现视觉特征中也存在类似的网格编码
2. **位置细胞**: 位置细胞编码特定空间位置。视觉特征空间的邻域结构类似位置细胞的调谐
3. **V1直线化**: Hénaff等人的发现——V1将弯曲的视频轨迹转化为更直的路径——在人工神经网络中也有体现
4. **主动vs被动**: 挑战了网格细胞需要主动运动（theta振荡）的共识

## 潜在导航应用

### 闭式视觉里程计

利用Poincaré适配器的线性化：
```
相对位姿 = W * (z_target - z_source)
```
这提供了比传统VO更简洁的方案——不需要特征匹配、束调整等复杂流程。

### 场景内导航

给定起始帧和目标帧的特征：
1. 提取特征差异
2. 线性投影到位姿空间
3. 得到相对运动方向
4. 线性插值生成中间路径

### 与Navigation World Models的关系

SeeSE3为Navigation World Models提供了理论基础：
- NWMs隐式地利用了特征空间的几何结构
- SeeSE3明确揭示和分析了这种结构
- 理解了结构可以指导更好的NWM设计

## 对Spatial AGI的深层启示

### 1. 3D空间感知的涌现性

最重要的启示：**3D空间感知可以从2D视觉数据中自发涌现**。这支持了以下Spatial AGI构建策略：
- 大规模视觉预训练可能已经包含了足够的空间理解
- 不一定需要显式的3D监督
- 自监督学习是发现空间结构的关键

### 2. 特征空间几何 = 物理空间几何

潜在空间中的线性路径对应物理运动，这是一个深刻洞察。意味着：
- 很多空间推理可以在特征空间中完成
- 不需要显式3D重建就可以进行空间导航
- 特征空间算术可以有物理含义

### 3. 空间的均匀性

发现的坐标系是均匀的——到处含义一致。这是物理空间的标志特征（平移不变性），能在视觉特征中找到对应，说明模型真正"理解"了空间，而非死记硬背。

### 4. 对世界模型设计的指导

SeeSE3的发现对世界模型设计有直接影响：
- 潜在空间应该被约束为SE(3)结构化
- 可以用SE(3)等变性作为归纳偏置
- 连续时间模型（如ODEWorld）的速度场可以在SE(3)结构化空间中学习

### 5. 对VLM空间推理的指导

VLM的空间推理瓶颈可能来自语言模型部分（语言不擅长连续空间推理），而非视觉编码器（视觉特征已包含空间结构）。改进方向是更好地利用视觉编码器中已有的空间结构。

## 协议详细说明

### Metric 1 (M1): 互k-NN拓扑对齐

对于每对帧(i,j)，计算：
- 特征空间中的k近邻
- 位姿空间中的k近邻
- 互对齐分数：交集大小 / k

在不同距离尺度上评估，得到对齐曲线。

关键发现：
- 自监督模型在短距离上有高对齐（>0.7）
- 对齐随距离衰减的速度取决于模型质量
- DINOv2等自监督模型显著优于CLIP和监督模型

### Metric 2 (M2): 内在维度估计

理想SE(3)结构化表示的内在维度应该接近6。

实际发现：
- 优秀编码器：内在维度8-12
- 一般编码器：内在维度15-30
- 随机特征：内在维度>50

额外维度可能来自非空间信息（语义、光照等）。

### Metric 3 (M3): 线性等变性测试

训练线性回归器W预测相对位姿变化：
- R²>0.7（旋转）和R²>0.5（平移）
- 旋转分量一致比平移分量更容易预测

### Poincaré适配器架构

轻量级Siamese网络（<100K参数）：
- 共享权重编码器处理两个特征
- 拼接后回归6D twist坐标
- 输出均匀坐标系

```python
class SeeSE3Probe:
    def __init__(self, encoder, scene_data):
        self.encoder = encoder  # 预训练视觉编码器
        self.scenes = scene_data  # 静态场景数据
    
    def extract_features(self, images):
        """提取视觉特征"""
        with torch.no_grad():
            features = self.encoder(images)
        return features
    
    def metric_m1_topology(self, features, poses, k=10):
        """互k-NN拓扑对齐"""
        feat_dist = pairwise_distance(features)
        pose_dist = pairwise_distance(poses)
        
        feat_knn = feat_dist.topk(k, largest=False).indices
        pose_knn = pose_dist.topk(k, largest=False).indices
        
        alignment = (feat_knn[:, :, None] == pose_knn[:, None, :]).any(-1).float().mean()
        return alignment
    
    def metric_m2_intrinsic_dim(self, features):
        """估计内在维度"""
        # MLE估计器
        dists = pairwise_distance(features).sort(dim=-1).values
        local_id = estimate_mle(dists)
        return local_id.mean()
    
    def metric_m3_linear_equivariance(self, features, poses):
        """线性等变性测试"""
        # 构造特征差异和位姿差异对
        delta_z = features[1:] - features[:-1]
        delta_p = poses[1:] - poses[:-1]  # Lie algebra
        
        # 训练线性回归器
        W = torch.linalg.lstsq(delta_z, delta_p).solution
        
        # 评估
        pred = delta_z @ W
        r2 = r2_score(delta_p, pred)
        return W, r2
    
    def poincare_adapter(self, z_source, z_target):
        """Poincaré适配器"""
        # 轻量级Siamese网络
        h_s = self.shared_mlp(z_source)
        h_t = self.shared_mlp(z_target)
        delta_pose = self.regressor(torch.cat([h_s, h_t], -1))
        return delta_pose  # 6D twist
    
    def latent_navigation(self, z_start, z_end, num_steps=10):
        """闭式潜在导航"""
        delta_z = z_end - z_start
        alphas = torch.linspace(0, 1, num_steps)
        path = [z_start + a * delta_z for a in alphas]
        return path
```
