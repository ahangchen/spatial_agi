## 一句话总结

P³-VLM 揭露了 3D VLM 评测中的一个系统性漏洞——**边界框语义泄漏（bounding box semantic leakage）**：框的尺寸/长宽比本身就高度预示物体类别，一个"盲"LLM 只看框坐标就能在 Nr3D 上达到 36.4% 准确率。论文提出**点接地（point-based grounding）**更严格协议（只用单个 3D 点查询），并构建三通路架构的 P³-VLM，在点接地下达到 52.1% SOTA，同时提升鲁棒性、OOD 泛化和无接地 3D VQA 性能。

## 核心问题

### Q1: 核心算法原理是什么？

**分析**:

#### 1. 核心思想和动机

- **核心发现——语义泄漏**：3D VLM 的接地查询普遍用 bounding box 作为空间提示或表征原语。框的尺寸、形状、长宽比携带强类别线索（"高而窄立在地上的框=门"、"标准双人床尺寸=床"），模型可以完全绕过视觉感知走捷径。
- **两层泄漏证据**：
  1. **文本通道泄漏**：用 Qwen3-VL 4B 的 LLM 部分做 LoRA 微调，仅输入框的中心/yaw/extent（无任何视觉编码器），Nr3D 类别准确率达 **36.4%**；
  2. **架构通道泄漏**：把 object-centric VLM（LEO）的视觉特征替换为"框坐标的 2 层 MLP 编码"，性能几乎不掉（44.2% vs 完整 LEO 45.1%）——说明 OD-VLM 的 3D 视觉编码器在框提示下基本是摆设。
- **点接地协议**：查询只给目标物体上一个 3D 点 (x,y,z)。点不暴露尺寸/形状/范围，类别几何线索大幅减少。效果：盲 LLM 36.4%→18.0%（相对下降 50%）；现有 3D VLM 即使在点提示上微调仍大幅退化（LL3DA 47.7%→33.1%，GaussianVLM 46.2%→29.3%）——证明问题是**视觉容量**而非提示格式。
- **动机链**：诊断问题（泄漏）→ 定义更严格协议（点接地）→ 设计能通过该协议的模型（P³-VLM）。

#### 2. 主要技术方法

P³-VLM 是 detector-free、scene-centric、基于 3D Gaussian Splatting 输入的 3D VLM，核心是三通路（tri-pathway）视觉处理：

**(a) 场景编码**

- 输入 3D GS 场景 → 稀疏 3D GS 编码器 → voxel 特征 F ∈ R^{N×D} 及对应 3D 坐标 C ∈ R^{N×3}。
- 每个特征锚定在具体空间位置——这是点接地可行的结构基础。
- 稀疏化：体素特征在均匀 3D 网格上平均池化到每场景 ≤2048 tokens，然后经过空间感知自注意力层（queries/keys 都加 3D RoPE 旋转位置编码）上采样到 LLM 空间。

**(b) 三通路**

1. **位置感知通路（Location-aware）**：从查询点提取紧凑的位置线索——在原始（未稀疏化）编码特征上，直接在查询点位置提取 token。只关注局部性，不做全局处理。这回答"这个点摸到了什么"。
2. **任务感知通路（Task-aware）**：先用任务提示 token 精炼自身，再用精炼后的提示 token 对稀疏化特征做视觉精炼（prompt-guided visual refinement），产生与任务相关的稀疏场景 token。这回答"针对这个问题，场景哪些部分重要"。
3. **上下文感知通路（Context-aware）**：通过无条件 cross-attention 蒸馏出 8 个全局场景摘要 token，提供接地推理所需的场景全局上下文。这回答"这个场景整体是什么"。

**(c) LLM 输入**

- 视觉 token 序列 = [位置 token; 任务相关 token; 上下文 token] + 语言任务 token L_L → LLM 生成自由文本回答。

**(d) 设计原则**

- **Detector-free**：不依赖物体检测器，场景理解不被检测器召回率封顶。
- **Scene-centric**：整体编码场景，而非先切物体再理解。
- **3D GS 兼容**：直接消费高斯泼溅场景（3DGS 是当前空间捕获的主流表示）。
- **无框依赖**：全程不使用 bounding box 作为提示或表征原语。

#### 3. 算法流程和关键步骤

**推理流程**：
1. 输入 3D GS 场景 + 自然语言查询 + 查询点 (x,y,z)；
2. 稀疏 3D GS 编码器 → voxel 特征 F（带坐标 C）；
3. 位置通路：在查询点处从原始 F 提取位置 token；
4. F 平均池化稀疏化至 ≤2048 tokens + 3D RoPE 自注意力精炼；
5. 任务通路：任务 token 自精炼 → 引导稀疏特征的视觉精炼 → 任务相关 token；
6. 上下文通路：无条件 cross-attention → 8 个全局摘要 token；
7. [位置; 任务; 上下文] token + 查询文本 → LLM → 自由文本回答。

**训练流程**：
- 在 ScanNet 系数据（Nr3D/ScanRefer 的 captioning 标注）上训练；
- 关键：训练和评测都使用点接地协议（模型从架构上就不支持框依赖）。

#### 4. 输入输出

- **输入**：3D 高斯泼溅场景、自然语言任务查询、查询 3D 点坐标。
- **输出**：自由形式自然语言回答（类别/描述/问答）。
- **对比传统**：不需要框提示、不依赖检测器、可处理 3DGS 输入。

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**分析**:

#### 1. 如何理解和表示空间

- P³-VLM 的空间表示哲学：**空间锚定在体素上，语义来自视觉，而非来自几何先验**。每个视觉特征绑定 3D 坐标，位置查询通过坐标直接命中——空间索引与语义内容彻底解耦。
- 点是最小空间查询单元：从"框"到"点"的转变，本质是把空间提示的信息量从"位置+形状+尺度"压缩到"位置"，迫使语义判断回归视觉证据。
- 3D RoPE 将旋转位置编码从 1D 序列扩展到 3D 体素网格，使注意力天然感知空间邻接——这是"空间结构写进注意力机制"的干净做法。

#### 2. 如何处理空间关系

- 三通路分别处理三类空间关系需求：点-局部关系（位置通路）、任务-区域相关性（任务通路）、全局布局上下文（上下文通路）。
- 点接地评测本身就是一个空间关系测试：给定场景中一个点，模型必须推断该点所属物体及其属性，这是"局部→全局"的空间归纳。

#### 3. 对 Spatial AGI 的启发

- **评测协议决定研究质量**：语义泄漏的发现是本文最大贡献。Spatial AGI 的所有 benchmark 都应该做"盲模型测试"——如果一个没有任何视觉输入的模型能做得不错，这个 benchmark 就在测先验而非智能。这一方法论可直接推广到 VLN、空间推理、世界模型评估。
- **捷径学习是空间智能的头号敌人**：3D VLM 靠框先验作弊，与 VLM 空间推理靠语言先验作弊（CRISP、SpatialBrain 等论文的发现）同根同源。真正空间智能的进展必须以"捷径被封死后的残余性能"度量。
- **最小充分提示原则**：点提示是接地的最小充分信息。更严格协议下训练的模型反而获得更好的鲁棒性、OOD 和无接地下游性能——"训练时更难、测试时更强"的空间智能版验证。
- **3DGS 作为 VLM 输入的可行性**：P³-VLM 与 GaussianVLM 一起确立了"3DGS → 体素化 → 三通路 token 化 → LLM"的管线，为空间智能的"世界表示 → 语言接口"提供了模板。

#### 4. 可以应用的 Spatial AGI 场景

- **机器人指向交互**："那个东西是什么？"（人指着某处）——点查询正是人类指举示意的数学形式。
- **空间记忆检索**：结合情节记忆，"你在 (x,y,z) 看到的是什么"类查询。
- **3DGS 场景编辑/审计**：对重建场景做逐点语义审计。
- **Spatial AGI benchmark 建设**：把现有接地基准全部改造为点协议版本，消除捷径。
- **主动感知**：点查询 + 主动视角选择（Think-Capture 类）可组合成"看哪里、问什么"的主动空间智能体。

### Q3: 主要创新点和局限性是什么？

**分析**:

#### 1. 主要创新点

1. **科学发现**：首次系统性量化 bounding box semantic leakage——盲 LLM 36.4%（Nr3D）/38.1%（ScanRefer），LEO 换掉视觉编码器性能几乎不变。这一诊断对整个 3D VLM 领域是纠偏性的。
2. **新协议**：点接地（point-based grounding）——更严格、更便宜（无需框标注）、更贴近真实交互（人的指点）的评测协议。
3. **三通路架构**：位置/任务/上下文通路的分解干净且各司其职，稀疏化（≤2048 token）+ 3D RoPE + 8 个全局摘要 token 的效率设计使 10k+ 体素 token 可被 LLM 消费。
4. **泛化收益的论证**：点接地训练的模型在鲁棒性（非典型物体尺寸、噪声重建、错位框）、OOD、无接地 VQA（ScanQA/SQA3D）上全面更优——"去捷径"的系统性红利。

#### 2. 主要局限性

1. **点接地的信息瓶颈**：点本身不含物体范围信息，"这个点指的是哪个物体"的歧义（点在物体边缘/两个物体之间时）需要模型自行消解，某些场景下协议本身引入模糊。
2. **数据规模受限**：仍在 ScanNet 系数据上训练评测，室内、物体类别有限；是否能扩展到大规模开放世界（火腿难说）未验证。
3. **3DGS 依赖**：输入需要先重建 3DGS，动态场景、大场景、弱纹理场景的重建质量直接影响模型表现。
4. **三通路的超参敏感性**：稀疏化网格分辨率、摘要 token 数量（8）、任务 token 精炼层数等均为设计自由度，消融的完备性待查。
5. **点查询与人类指点的差距**：真实人类指点是 2D 射线（眼睛-指尖-目标），需要 depth 投影成点，误差传播未讨论。

#### 3. 与其他相关工作的对比

| 维度 | LEO / LL3DA（object-centric） | GaussianVLM（scene-centric, 框提示） | **P³-VLM** |
|---|---|---|---|
| 表征原语 | 检测器物体框+实例点云 | 3DGS + 框接地提示 | 3DGS 体素 + 点接地 |
| 检测器依赖 | **有（性能被召回率封顶）** | 无 | 无 |
| 捷径暴露 | 严重（盲 LLM≈全模型） | 有（点协议下降 17pp） | **最小** |
| Nr3D 点协议 | 33.1%（微调后） | 29.3%（微调后） | **52.1%** |
| 鲁棒/OOD | 弱 | 中 | **强** |
| 无接地 VQA | 一般 | 一般 | **一致提升** |

- **优势**：唯一在封死捷径后仍保持高 grounding 性能的模型；架构与协议互相自洽。
- **劣势**：专用 grounding 专家模型（结构化输出+大规模任务监督）在纯检测任务上仍会更强；P³-VLM 的自由形式通用性与专家性能的权衡未直接对比。

## 核心技术发现

- **发现1**：3D VLM 接地评测被框先验系统性污染，"接地能力"排行榜很大程度上是"框→类别映射"排行榜。
- **发现2**：object-centric VLM 的 3D 编码器在框提示下几乎不被使用（LEO 换 MLP 视觉特征性能不变）——这是对整个 object-centric 路线的有力质疑。
- **发现3**：点协议下盲 LLM 仍有 18%，说明位置本身（房间布局先验：厨房里的盒子多是电器）也携带类别信息——捷径只能减少不能根除，评测需叠加多种控制条件。
- **发现4**：去捷径训练的红利是全局性的——鲁棒性、OOD、无接地任务全部受益，说明捷径学习抑制了真正的视觉表征学习。

## 与Spatial AGI的关系

### 直接贡献
给 Spatial AGI 的评测体系提供了一个"反捷径"协议范式；给 3DGS→LLM 的空间语义接口提供了一个干净架构。

### 技术启发
- 任何空间智能 benchmark 都应报告盲模型基线。
- 点/射线级查询是与具身智能体交互的自然形式（视线、指尖、激光笔），值得作为 Spatial AGI 的标准查询接口。

### 应用场景
指向交互机器人、空间问答、3DGS 场景理解、benchmark 建设。

## 个人思考

### 最令人兴奋的发现

盲 LLM 实验的设计堪称 3D VLM 领域的"图灵测试"：36.4% 这个数字一出，整个领域的 grounding 排行榜可信度都要重新审视。更妙的是 18% 的残余——即使封死了框捷径，"位置本身"仍是捷径（房间类型→物体先验）。这暗示空间智能评测是一个"捷径的洋葱"：每剥掉一层（框→点→场景上下文），模型的真实能力才暴露一点。理想的空间智能评测应该同时报告"盲模型线"和"完整模型线"的距离。

NeurIPS 2026 Spotlight 的认可也说明社区已意识到评测危机——继语言模型领域（circular reasoning benchmarks、contamination scandals）之后，空间智能领域正进入"评测反思"阶段。

### 潜在局限

- 点协议只是anti-shortcut的一步：场景布局先验、语言先验、数据污染都还在。真正的"纯净评测"可能需要反事实场景合成（同一物体随机放置到反常位置）。
- 3DGS 输入把"感知"外包给了重建管线——重建失败处模型无能为力，而真实机器人恰恰在重建最难的场景（反光、透明、动态）工作。

### 与近期研究的关联

- 与 **CRISP（7-01）**、**SpatialBrain（10-23）**、**MJev-Spatial（10-22）**、**SpatialChain（10-07）** 同属"空间智能评测反思"潮流：CRISP 区分语言先验与真实空间推理，P³-VLM 区分几何先验与真实视觉推理——两者合起来构成"去捷径"评测的双子星。
- 与 **Decoding Geometry, Not Tokens（11-01_04，VLM 可供性）** 直接呼应：那篇发现 VLM 的 affordance 判断依赖几何而非 token 捷径，P³-VLM 则从训练端消除几何捷径——一个测"有多少几何"，一个逼"只用几何"。
- 与 **Seeing Across Views、MultiView-Bench** 等多视角一致性基准共同构成更严格的空间评测体系。
- 与 **GaussianVLM（baseline）**、**OneCanvas（6-21）**、**Occ-VLM（6-20）** 的 scene-centric 路线一致：场景级表征正在取代 object-centric 成为 3D VLM 主流。

## 总结

### 核心发现总结

P³-VLM 用一组干净的对照实验证明：3D VLM 的接地评测长期被 bounding box 的类别先验污染，"盲"模型的强表现揭露了排行榜的水分；点接地协议封死主要捷径后，P³-VLM 以三通路架构（位置/任务/上下文）在更严格的设定下取得 SOTA，并收获鲁棒性与泛化的全面提升。

### 对Spatial AGI的意义

这篇论文的价值一半在模型、一半在方法论。对 Spatial AGI 而言，"评测先于能力"——如果不能可信地度量空间理解，就无法积累真实的进展。P³-VLM 提供的"盲模型基线 + 最小充分提示协议"应成为所有空间智能 benchmark 的标配。

## 深度扩展分析

### A. 三通路架构逐通路拆解

#### A.1 位置感知通路（Location-aware）

- 输入：查询点 (x,y,z)；操作对象：**原始**（未稀疏化）voxel 特征。
- 为什么用原始特征：稀疏化（平均池化）会模糊局部细节，而点查询要回答的恰恰是"这个点及其紧邻区域的视觉内容"，局部保真优先。
- 实现：按坐标索引/最近邻检索查询点附近的特征 → 提取单个（或少量）位置 token。
- 类比：这是"指尖触觉"——只感知点下之物。

#### A.2 任务感知通路（Task-aware）

- 两步：任务 token 自精炼（提示词之间先做注意力，形成任务表示）→ 用精炼后的任务 token 对稀疏化场景特征做视觉精炼（prompt-guided refinement）。
- 效果：与任务无关的场景内容被抑制，输出"任务相关"的场景 token 子集。
- 类比：这是"带着问题看场景"——注意力被任务引导。

#### A.3 上下文感知通路（Context-aware）

- 无条件（unconditional）cross-attention：一组可学习查询（8 个）对稀疏特征做注意力，蒸馏全局摘要。
- "无条件"意味着不依赖任务——提供稳定的场景全局画像，与任务通路互补。
- 8 个 token 的量级选择：足以编码房间类型/布局风格/主要物体集合，远小于 2048。
- 类比：这是"扫一眼对场景的整体印象"。

#### A.4 三通路的token经济学

| 通路 | 输入 | 输出 token 数 | 计算对象 |
|---|---|---|---|
| 位置 | 查询点 | ~1 | 原始 voxel 特征（局部索引） |
| 任务 | 任务 token | 数十-数百 | 稀疏化特征（≤2048） |
| 上下文 | 可学习查询 | 8 | 稀疏化特征（≤2048） |
| **合计** | | **≪2048** | LLM 负担可控 |

三通路本质是把"注意力预算"按空间粒度（点/区域/全局）分配——一个有原则的 token 分配方案。

### B. 语义泄漏的完整解剖

泄漏三要素：
1. **信号源**：框的 (cx, cy, cz, l, w, h, yaw) → 尺寸/长宽比/离地高度/朝向；
2. **学习路径一（文本）**：框坐标出现在 prompt 文本 → LLM 直接学会"坐标→类别"映射；
3. **学习路径二（架构）**：OD-VLM 的视觉 token 本质是框内点云的池化 → 框几何信息主导 token 内容 → 3D 编码器可有可无。

对照实验矩阵：

| 实验 | 视觉输入 | 提示 | Nr3D Acc |
|---|---|---|---|
| 盲 LLM | 无 | 框坐标 | 36.4% |
| 盲 LLM | 无 | 点坐标 | 18.0% |
| 盲 LLM | 无 | 框坐标 | 38.1%（ScanRefer） |
| LEO | 完整点云 | 框 | 45.1% |
| LEO | 框坐标MLP | 框 | 44.2% |

解读：框坐标单独提供 36-38% 的准确率，而完整模型只有 45-47%——即**约 80% 的"接地性能"可由框先验解释**。

点协议下残余的 18% 说明位置先验（房间语境→物体）仍贡献约 18pp。彻底无捷径的评测需要反事实场景（物体随机重排），但这会破坏数据真实性——评测真实性与纯净性的权衡。

### C. 点接地的协议学分析

#### C.1 点 vs 框 vs 射线 vs 视线

| 提示形式 | 信息量 | 歧义性 | 现实对应 |
|---|---|---|---|
| Bounding box | 高（位置+形状+尺度） | 低 | 检测器输出 |
| 3D 点 | 低（仅位置） | 中（边缘/多物体） | 触摸、点击 |
| 射线（origin+direction） | 极低 | 高（整条射线上所有物体） | 视线、手指、激光笔 |
| 2D 像素 + depth | 低-中 | 中 | 触屏点击投影 |

P³-VLM 选择了"信息量-歧义性"权衡的一个甜点。射线协议（ray grounding）是更极端的版本，值得作为后续协议研究——尤其视线接地与人机交互最相关。

#### C.2 协议公平性

点协议下模型失去框先验，但也失去框提供的"目标确认"信息（框完全覆盖目标物体）。点在物体内部时无歧义，在边缘时有。Nr3D/ScanRefer 的点采样方式（物体表面/内部随机采样？中心？）影响难度，需查附录——评测协议的每个细节都应标准化并公开。

### D. 与"去捷径"评测运动的大图景

P³-VLM 属于 2026 年空间智能评测反思浪潮的代表作，该浪潮的共同方法论：

1. **构造盲模型/捷径模型基线**（blind LLM、language-only、2D-only）；
2. **定义最小充分协议**（点、反事实布局、控制变量）；
3. **报告"完整模型 − 盲模型"的净差距**而非绝对分数。

相关工作映射：
- CRISP（7-01）：语言先验 vs 空间推理的分解
- SpatialIQ / SpatialQ（7-30/7-31）：空间智能的层次化分解
- MetricBench / SpaceCast-Bench（9-26/10-12）：度量与预测性空间推理
- MindEdit-Bench（7-14）：反事实空间推理
- **P³-VLM（本文）**：接地的几何先验泄漏

共同结论正在形成：**当前 VLM/3D VLM 的空间智能大部分是先验回放，真实视觉-空间推理的净贡献远小于排行榜暗示的水平**。这对 Spatial AGI 的进度评估是重要的清醒剂。

### E. 批判性视角

1. **盲 LLM 36.4% 的另一种解读**：Nr3D 类别分布不均（椅子、桌子高频类）+ 框先验，36% 中相当部分可能来自类别频率基线。论文未报告 majority-class 基线（约 10-15%？），盲 LLM 的"净泄漏"应扣除频率效应。
2. **点协议下 52.1% 的含金量**：仍需与"人类在点协议下"的对照——人类看体素渲染+点标记的准确率是多少？若无人类线，52.1% 的绝对水平难以评判。
3. **数据集多样性**：ScanNet 系室内数据，模型可能学到的仍是"室内场景先验+局部视觉"，向开放世界外推的证据不足。
4. **3DGS 重建偏差**：ScanNet 的 3DGS 从稠密扫描重建，质量远高于真机稀疏视角重建；真机点查询场景下表现存疑。
5. **Spotlight 但未开源确认**：项目页已挂出，权重开源情况待观察；评测协议标准化依赖开源。

### F. 假想后续工作

1. **RayGround-Bench**：射线协议接地基准，测"视线理解"，配人类基线。
2. **Counterfactual-ScanNet**：物体重排的反事实版本，彻底封死位置先验。
3. **P³-VLM + 情节记忆**：点查询历史（"我上周指过的那个柜子"），与 MemVLN 类记忆结合。
4. **点接地机器人交互**：人手指/激光笔指点 → 3D 点 → P³-VLM 语义解释 → 机器人行动，完整的指向交互管线。
5. **净差距报告标准**：推动 benchmark 报告 (完整模型 − 盲模型) 为默认指标。

### G. 摘要卡（供每日思考引用）

> **P³-VLM（arXiv 2610.28018, INSAIT, NeurIPS 2026 Spotlight）**：揭露 3D VLM 接地评测的 bounding box semantic leakage——盲 LLM 仅凭框坐标达 36.4%（Nr3D），LEO 换掉视觉编码器性能几乎不变；提出点接地协议（单 3D 点查询）封死形状/尺度捷径（盲 LLM 降至 18%）。P³-VLM 为 detector-free、scene-centric、3DGS 输入的三通路 VLM（位置/任务/上下文，稀疏化 ≤2048 token + 3D RoPE + 8 摘要 token），点接地下 Nr3D 52.1% SOTA，且鲁棒性、OOD、无接地 VQA（ScanQA/SQA3D）全面受益。核心论断：去捷径训练的收益是全局的；空间智能评测必须报告盲模型基线。

### I. 方法选择背后的深层逻辑：为什么要 detector-free

Object-centric 路线的根本问题在本文语境下有了新维度：不仅是"召回率封顶"（GaussianVLM 论文已指出），而是**检测器的框既是表征原语又是泄漏源**。检测器给 VLM 的每个 token 都已带着框几何——等于把答案的一部分提前喂给了模型。detector-free 不是效率选择，是认识论选择：让 VLM 的每个 bit 语义都必须来自视觉。

这与 LLM 领域"benchmark contamination"的教训同构：当评测信号（框）泄漏进训练/输入通路，分数失去意义。P³-VLM 的三通路架构是对"信号纯净性"的架构级承诺。

### J. 对 Spatial AGI 研究者的操作建议

1. **立即行动**：给自己的任何空间任务评测加一个盲基线（仅坐标/仅语言/仅布局），成本低、信息量大。
2. **架构审查**：检查自己模型的空间提示通道是否携带类别信息（框、mask 包围盒、实例 ID 等）。
3. **协议升级**：报告点/射线协议下的性能作为严格指标，框协议作为宽松指标并列。
4. **训练启示**：在训练中加入提示信息量的随机化（有时给框、有时给点、有时给射线），迫使模型不依赖提示粒度——类似数据增强但作用于"提示空间"。
5. **长期方向**：人类指点的形式是 2D 射线 + 语言语境，真正面向交互的空间智能应以射线/视线接地为一等公民。

### M. 术语表

- **Semantic leakage（语义泄漏）**：评测/提示协议中携带类别信息的非视觉信号（如框几何）渗入模型决策。
- **Blind LLM**：无任何视觉输入、仅用坐标微调的 LLM，用作捷径检测器。
- **Point-based grounding**：用单个 3D 点指定查询目标对象的接地协议。
- **Object-centric vs Scene-centric**：先检测物体再理解 vs 整体编码场景的两种 3D VLM 范式。
- **3D RoPE**：将旋转位置编码推广到 3D 体素坐标的自注意力位置编码。
- **ToMe-free 稀疏化**：本文用网格平均池化而非 token merging（与 MemVLN 的 ToMe 选用形成对照——同一问题（token 过多）的不同解法）。
- **Nr3D / ScanRefer**：基于 ScanNet 的 3D 视觉定位/描述基准。
- **ScanQA / SQA3D**：3D 场景问答基准（无接地/自中心两种形式）。

### N. 认知科学注脚

点接地与人类注意的"spotlight"隐喻契合：视觉注意的聚焦区很小，人类对物体的识别几乎总是从局部注视（fixation）出发再整合上下文。P³-VLM 的三通路（点-区域-全局）恰好对应"注视-扫视-场景知觉"三级加工。这一对应暗示 tri-pathway 不只是工程分解，可能是空间语义加工的自然分解——若后续认知建模工作验证"人类接地也遵循点→任务→上下文的信息流"，tri-pathway 的生物学合理性将大幅提升。

### O. 一段话给"未来的自己"

三个月后回看这篇笔记，最要紧的是：任何空间 benchmark 的绝对分数都没有意义，意义在"净差距"（完整模型减盲模型）；point grounding 不是又一个提示格式，而是把"语义必须来自视觉"变成协议约束的机制；如果将来看到 ray-based grounding、counterfactual scene benchmarks，它们都是这篇文章开创的"去捷径"运动的延续；而 52.1% 这个数字本身不如"现有 SOTA 在点协议下掉 15pp"这个事实重要——空间智能的进步，先从诚实的尺子开始。
