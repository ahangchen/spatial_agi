# HiSpatial: Taming Hierarchical 3D Spatial Understanding in VLMs

**arXiv**: 2603.25411  
**Date**: 2026-03-26  
**Venue**: CVPR 2026  
**Tags**: #VLM #SpatialUnderstanding #Hierarchical #RGBD

---

## TL;DR

HiSpatial 提出了一个**四层层次化框架**来系统培养 VLM 的 3D 空间理解能力，从基础几何感知到抽象空间推理。通过自动化流水线处理 5M 图像、45M 物体，生成 2B QA 对，训练的 RGB-D VLM 超越 Gemini-2.5-pro 和 GPT-5。

---

## 核心贡献

### 1. 四层空间智能层次

```
Level 3: 抽象空间推理 ← 高层
    ↓
Level 2: 物体间关系理解
    ↓
Level 1: 物体级空间属性
    ↓
Level 0: 基础几何感知 ← 底层
```

### 2. 大规模自动化数据流水线

```
5M 图像 → 45M 物体 → 2B QA 对
```

### 3. RGB-D VLM 架构

- **输入**：RGB + 度量尺度点云图
- **骨干**：PaliGemma-2 (3B)
- **训练**：层次化 SFT

---

## 层次化任务设计

### Level 0: 基础几何感知

| 任务 | 描述 | 输出 |
|------|------|------|
| **像素级 3D 点查询** | 给定 2D 位置，输出 3D 坐标 | (x, y, z) |
| **成对深度排序** | 两个像素的相对深度 | A在B前/后 |

**无语义依赖**：纯几何感知

### Level 1: 物体级空间理解

| 任务 | 描述 |
|------|------|
| **物体定位** | 预测物体 3D 质心位置 |
| **方向估计** | 前/后/左/右/上/下 |
| **尺寸估计** | 物理宽度、高度 |

**输入**：语言描述或 2D bounding box

### Level 2: 物体间关系

| 任务 | 描述 |
|------|------|
| **相对方向** | 定性（左/右）或定量（方向向量） |
| **相对距离** | 欧氏距离、垂直/水平/深度分量 |
| **关系比较** | 最近/最远、最大/最小、同向/反向 |

### Level 3: 抽象空间推理

| 任务 | 描述 |
|------|------|
| **视角转换** | 想象从其他观察者视角的空间关系 |
| **空间计数** | 满足空间约束的物体数量 |
| **空间问题求解** | 多步推理 + 心理模拟 |

## 数据流水线

### 阶段 1: 空间信息估计

```
RGB图像 → MoGe-2 → 度量点云图
        → RAM + GroundingDINO + SAM → 物体分割
        → OrientAnythingv2 → 物体方向
        → Perspective Fields → 重力对齐坐标系
```

### 阶段 2: 文本引用生成

```
物体 → Describe Anything + Qwen-VL → 描述文本
     → 验证：描述是否唯一对应物体
     → 过滤：IoU < 阈值 → 丢弃
```

### 阶段 3: QA 合成

**三种格式**：
1. 自由问答
2. 多选题
3. 判断题

**Level 3 特殊处理**：GPT 生成复杂推理问题

### 数据源

| 来源 | 图像数 | 特点 |
|------|--------|------|
| KosMos-2 | 3.8M | 野外图像 |
| Objects365 | 1M | 带GT框 |
| CA-1M | 200K | 室内+3D标注 |
| **总计** | **5M** | 45M物体，2B QA |

## 模型架构

```
┌─────────────┐
│ RGB 图像    │ → SigLIP Encoder → 视觉tokens
└─────────────┘
                      ↓ Concat
┌─────────────┐
│ 点云图      │ → Positional Encoding + Conv2D
│ (H×W×4)     │    (x,y,z,valid)
└─────────────┘
                      ↓
              Linear Projector
                      ↓
              ┌─────────────┐
              │ Gemma-2 LLM │
              └─────────────┘
                      ↓
                 文本输出
```

**关键设计**：度量尺度点云 > 相对深度图

## 层次依赖性分析

### 关键发现

```
训练: Level 0+1 → Level 2+3 提升 15%
      Level 2 → Level 3 提升 8%
      跳过底层 → 高层性能显著下降
```

**结论**：**层次依赖清晰存在**
