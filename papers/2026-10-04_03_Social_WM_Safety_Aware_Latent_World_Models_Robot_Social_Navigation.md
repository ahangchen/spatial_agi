# Social-WM: Safety-Aware Latent World Models for Robot Social Navigation

- **arXiv**: [2609.40177](https://arxiv.org/abs/2609.40177) (cs.RO, v2 2026-10-01)
- **作者**: Zhihao Zheng, Mooi Choo Chuah（Lehigh University）
- **分析日期**: 2026-10-04
- **主题分类**: 世界模型 / 社交导航 / 具身安全

---

## 摘要概述

社交导航中"名义动作"（nominal action）与"可实现动作"（realizable action）存在系统性差异：朝行人前进的指令会被物理/社会约束截断。Social-WM 是一个潜在世界模型规划框架，从自我中心 RGB 视频离线训练：动作条件未来预测以"实际发生的未来"为目标（而非指令假设的未来），配合"可实现逆动力学"（用里程计得到的实际运动监督），将名义-可实现差异作为执行前安全信号。在 Social-HM3D 上 63.77% 成功率、人碰撞降至 21.67%，零样本迁移 Social-MP3D 仍强（54.15%/23.34%），全程无行人显式跟踪、无特权人类状态、无在线 RL。

## Q1: 核心算法原理

### 1. 核心思想与动机

- **关键观察**：社交导航经验数据中，指令与实际运动天然不一致——这不是噪声，而是**安全约束的信号**。机器人朝行人下发"前进"，实际执行的是"停止/绕行"，这个差异本身就编码了"哪里不能去"。
- **监督信号设计**：世界模型的预测目标是**实际观测到的未来**（被约束后的未来），因此模型自然学到"这个指令会导致被挡住"；逆动力学的监督目标是**实际执行的动作**（由里程计恢复），而非下发的指令。
- 与 Falcon（预测行人未来轨迹）和 NavThinker（世界模型特征喂给 DD-PPO 策略）不同：Social-WM 直接用想象轨迹评估候选动作块，拒绝"指令运动与可实现运动不一致"的候选。

### 2. 主要技术方法

#### (a) 问题形式化

- 状态 s_t = (x_t, ℳ, {h_t^(i)})：机器人位姿 + 静态环境 + N 个行人，均不可直接观测；
- 观测：前向 RGB + 自身位姿 + 目标 g（位置或图像）；
- 动作：本体坐标系连续动作 a_t = (fwd, lat, yaw)，按 H 步块规划；
- **核心定义**：名义动作 a_t（指令）vs 可实现动作 ã_t（x_t→x_{t+1} 的实际位姿变化）。自由空间二者一致，受约束时分离。

#### (b) 安全感知潜在世界模型

- **视觉表征**：冻结 DINOv2-small 编码 RGB → patch tokens → 自适应池化为 M 个 token → 轻量 projector 得 z_t；
- **动作条件预测**：Transformer 预测器 F_φ 以潜在历史+名义动作为条件预测下一潜在特征 ẑ_{t+1}，但目标是**真实观测的** E(I_{t+1})——被拒绝的指令配对的是"停下来的未来"；
- **训练目标**：单步 teacher-forcing + 表征正则 + **多步开环目标**（减少规划时多步 rollout 的累积误差）：
  L_pred = λ_tf L_tf + λ_ol L_ol + λ_sig L_sig
- 全程潜在空间预测，不重建 RGB、不估计深度、不跟踪行人轨迹。

#### (c) 可实现逆动力学（核心创新）

- 局部意图 m_t^ℓ = z_{t+1} − z_t，逆动力学模型 I_ψ 预测 ẫ_t = I_ψ(z_t, m_t^ℓ)；
- **监督信号用 ã_t（里程计恢复的实际运动）而非指令 a_t**：
  L_id = −log p_ψ(ã_t | z_t, m_t^ℓ)
- 预测 ã 而非 a 要求潜在转移保留与安全相关的场景信息（否则无法区分"执行了"和"被挡了"）；
- 总目标：L_WM = L_pred + λ_id L_id。

#### (d) 部署：propose–imagine–evaluate–select

1. **Propose**: CVAE 从潜在历史生成 K 个候选 H 步动作块（目标无关，覆盖前进/转向/等待/绕行等行为）；
2. **Imagine**: 世界模型 rollout 每个候选 → 想象潜在轨迹；
3. **Evaluate**: 逆动力学估计每个想象转移的可实现动作，计算安全代价 c_safe = (1/H)Σ‖a_τ − I_ψ(·)‖；c_safe < τ 的候选进入可行集；
4. **Select**: 可行集内选目标代价最小者——位置目标用轨迹-目标最近距离，图像目标用潜在相似度。只执行选中块的第一步，闭环重复。

### 3. 算法流程

```
离线训练（仅 RGB + 里程计）:
  RGB → DINOv2 → z_t
  L_pred: 名义动作条件预测真实未来（多步开环）
  L_id:   从潜在转移恢复可实现动作（里程计 GT）

在线规划（每步）:
  CVAE 提案 K 个动作块 → WM 想象 → ID 估 c_safe
  → 过滤不可行候选 → 目标代价最小者执行第一步
```

### 4. 输入输出

- **输入**: 自我中心 RGB 流、本体感知（位姿/里程计）、目标（位置或图像）；
- **输出**: 每步的连续动作；中间产物：候选动作可实现性评分（安全信号）。

## Q2: 与 Spatial AGI 的关系

### 1. 空间的理解与表示

- Social-WM 对空间的理解完全通过**潜在视觉动力学**隐式实现：不建显式地图、不显式表示行人位置，但能预测"这个方向走不过去"。这是空间知识的一种经济表示——**只在需要决策的粒度上表示空间约束**。
- 名义-可实现差异是一个优雅的空间概念：它把"物理空间中的阻挡"和"社会空间中的个人领域"（proxemics）统一成同一个可学习的信号。**社会约束被几何化了**——空间不只是欧氏几何，还包括"人的舒适区"这种软几何。

### 2. 空间关系的处理

- 动作条件预测 + 逆动力学形成闭环：正向预测"会怎样"，逆向推断"实际会执行什么"，两者的差 = 空间约束强度。这是对空间关系（障碍-自体、他人-自体）的操作性度量；
- 安全评估与目标解耦（目标只进 c_task）——空间可行性判断是目标无关的，这让同一空间模型可以服务任意任务，是 Spatial AGI 模块化的重要设计。

### 3. 对 Spatial AGI 的启发

1. **可实现性作为空间推理的原语**：Spatial AGI 不只要预测"世界会怎样"，还要判断"我能做到什么"。Social-WM 证明这两个问题可以分开学习再用差异耦合——这比端到端学一个"安全策略"更有解释性、更可迁移。
2. **约束信息免费存在于交互数据中**：不需要人工标注危险区域或行人框，交互经验的"指令-结果差"自动暴露约束。这为 Spatial AGI 从海量机器人日志中自学空间约束提供了范式。
3. **零样本空间迁移**：HM3D→MP3D 的零样本转移说明学到的是环境无关的空间动力学模式（"朝人走会被挡"），而非特定场景记忆。

### 4. 可应用的 Spatial AGI 场景

- **人机共存空间的全类具身智能体**：家庭机器人、服务机器人、配送机器人的社交安全层；
- **自动驾驶微观决策**：名义轨迹 vs 可实现轨迹的差异检测可用于预判加塞、鬼探头场景；
- **可检验的空间想象**：agent 在想象中测试动作，逆动力学作为"物理合理性检查器"，可推广到操纵（抓不稳的指令会显现为名义-可实现差异）。

## Q3: 创新点与局限性

### 1. 主要创新点

1. **概念创新：名义-可实现差异**。把数据中普遍存在的"指令未完全执行"从噪声提升为安全信号，这是对交互数据本质的重新解读——简单但深刻；
2. **可实现逆动力学**：把逆动力学的监督从指令改为实际运动，一行改动就让潜在表征被迫编码安全相关信息，与 L_pred 形成互补；
3. **目标无关的动力学+可行模型**：安全判断与导航目标解耦，位置目标/图像目标共用同一世界模型，架构上更接近通用空间引擎；
4. **实用性强**：无行人跟踪、无特权信息、无在线 RL、离线 RGB 训练；效率高（潜在空间 rollout，K 个候选并行想象）。

### 2. 局限性

1. **单一前向相机**：部分可观测下依赖想象，但视野外行人（身后接近）无感知手段，多相机/全景可显著加强安全；
2. **可实现动作由里程计近似**：依赖里程计准确；打滑、被推挤等未反映在位姿差中的约束无法捕获；
3. **短时程安全**：H 步块的想象范围有限，长时程博弈（与行人互相让路的协商）超出范围；行人的意图/未来行为未建模；
4. **效率指标偏弱**：SR 提升但 SPL（49.62）低于 NavThinker（55.00）——安全绕行带来路径变长，安全-效率权衡未充分优化；
5. **静态场景限制**：Benchmark 为室内多人仿真，真实人流密集场景（商场、医院）的开放性未验证。

### 3. 与相关工作对比

| 方法 | 未来推理方式 | 行人显式建模 | 在线RL | HM3D SR / H-Coll |
|------|------------|------------|--------|------------------|
| A*/ORCA | 无/规则 | 是（力模型） | 否 | 44.81 / 54.80 |
| Falcon | 行人轨迹预测 | 是 | 否 | 56.26 / 41.22 |
| NavThinker | WM特征→策略 | 隐式 | 是 | 59.46 / 39.09 |
| **Social-WM** | **想象+可实现性检验** | **否** | **否** | **63.77 / 21.67** |

**优势**: 碰撞率近乎减半；范式简单可复现；目标无关。
**劣势**: SPL 略低于 NavThinker；单目感知；无行人意图建模。

## 个人思考

1. 名义-可实现差异让我想到控制论里的"内部模型原理"：系统若含环境的内部模型，就能预测并抵消扰动。Social-WM 把它反过来用——**用预测残差暴露内部模型的盲区**，盲区即危险。这个模式对 Spatial AGI 的安全层设计很有普遍性：任何"想象-执行"闭环都能产生这类残差信号。

2. 与今天第一篇 Token-World 互补：Token-World 回答"在哪个空间想象"（策略对齐的紧凑 token），Social-WM 回答"想象之后怎么检验"（逆动力学可实现性）。两者拼起来正好是"想象 + 事实核查"的完整安全闭环。

3. 把社会约束几何化（proxemics 成为动力学的一部分）是 Spatial AGI 的重要一步：真实空间智能必须内建社会空间。目前的 3D 重建/世界模型几乎全是"无人世界"，Social-WM 提醒我们人的存在本身就是空间结构的一部分。

4. 一个可检验的推论：如果反过来用——用 c_safe 作为奖励做 RL——模型可能学会"钻安全信号的空子"（比如选可实现但绕远的行为）。安全的对齐设计应该保持检验与优化分离（检验器冻结），这与 AI safety 中 verifier 保持不可收买的思路一致。

## 与 Spatial AGI 路线图的衔接

- **短期**: 为导航世界模型加装可实现性检验头，作为执行前安全门；
- **中期**: 把该范式推广到操纵/人机协作——所有具身动作都有"名义-可实现"差异，可统一为通用安全信号；
- **长期**: 探索"社会空间"（他人意图、舒适区、群体动力学）在世界模型中的一等公民表示。
