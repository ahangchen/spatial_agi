# sensVLA: Spatially-Grounded Vision-Language-Action Model for Autonomous Wheel Loader

## 0. 一句话总结

sensVLA 把 Qwen3-2B VLM 与全可训练的 flow-matching 动作专家结合，用专用 cross-attention 通路把前后 LiDAR 融合的 BEV 特征**直接路由**给动作专家、VLM 只吃 RGB 提供语义上下文，实现"空间接地与语言推理解耦、决策时交互"的架构，在真实装载机数据上把纵向速度 RMSE 降低 28%、相机失效时性能退化减少 29%。

---

## 1. 研究背景与动机

### 1.1 问题

自主轮式装载机（wheel loader，矿山/工地重型机械）控制需要联合推理：

- 任务语义（装什么、装到哪）
- 自中心视觉（front/rear RGB）
- 本体感知（proprioception）
- **3D 场景几何**（料堆形状、铲斗相对位置）

通用 VLA 模型擅长语义，但把 3D 几何信息压缩进语言 token 流会损失米制精度；而重型机械作业对纵向速度、位移的米制精度要求极高。

### 1.2 核心思路

**解耦但保持交互**：空间接地（BEV 几何）走专用通路直达动作专家，语言推理（VLM）走语义通路，两条流在决策时刻交叉互动——既不牺牲几何保真度，又不放弃任务级语义条件化。

---

## 2. 核心算法原理（Q1）

### 2.1 主要技术方法

**(1) 双流架构**

- **语义流**：Qwen3-2B VLM 消费 front + rear RGB 视图，输出任务条件化的语义上下文
- **几何流**：front + rear LiDAR 融合提取 BEV 特征，经**专用 cross-attention 通路**直接送入动作专家——不经过 VLM 的 token 空间

**(2) 动作专家**

- 全可训练的 transformer action expert
- 训练目标：**flow-matching 速度回归**（flow-matching velocity regression）——连续动作生成的现代范式，优于离散 token 化动作

**(3) 动作空间（6 维）**

1. 纵向速度（longitudinal velocity）
2. 转向（steering）
3. 机体系位移（body-frame displacement）
4. 动臂速率（arm rate）
5. 铲斗速率（bucket rate）
6. （合计六个动作维度）

### 2.2 算法流程

```
Step 1: front/rear LiDAR → 融合 → BEV 特征（空间接地）
Step 2: front/rear RGB → Qwen3-2B VLM → 语义上下文（语言推理）
Step 3: BEV 特征经 cross-attention 通路注入动作专家
Step 4: 语义上下文条件化动作专家
Step 5: flow-matching 动作专家回归速度场 → 输出 6 维动作
```

关键设计：BEV 特征**绕过** VLM。几何信息不经过语言瓶颈，避免了 3D 信息在文本 token 化中的量化损失；但两条流在动作专家处交叉注意力，保留任务语义对动作的调制。

### 2.3 输入输出

- **输入**：front/rear RGB、front/rear LiDAR（→BEV）、本体状态、任务指令
- **输出**：6 维连续动作（行驶 + 作业机构）

## 3. 关键实验结果

真实装载机数据集上：

1. **整体逐步精度**：与强 camera-only 基线持平（aggregate per-step parity）——注意基线不弱
2. **装载核心场景**：纵向速度 RMSE **降低 28%**，位移误差**降低 9%**——恰好在最需要米制精度的场景收益最大
3. **容错性**：相机流损坏或移除时，性能退化**少 29%**——显式空间接地带来了传感器冗余

---

## 4. 与 Spatial AGI 的关系（Q2）

### 4.1 如何理解和表示空间

- 空间以 **BEV 米制特征**表示：自中心、可度量、与动作空间同构（body-frame）
- 关键主张：空间接地（spatial grounding）应是一种**独立于语言的表示服务**，而不是语言模型的内部副产物
- 双模态冗余（RGB 语义 + LiDAR 几何）本身构成对空间的多视角理解

### 4.2 如何处理空间关系

- 铲斗-料堆-车体的空间关系直接由 BEV 几何 + flow-matching 动作回归隐式推理，绕过语言
- 任务语义（"把这堆料装进卡车"）通过 cross-attention 调制几何驱动的动作生成——语义选择目标，几何决定执行

### 4.3 对 Spatial AGI 的启发

1. **"几何旁路"架构原则**：米制空间信息不应被强制通过语言瓶颈。Spatial AGI 的认知架构应有语义流与几何流的双通路，在决策点融合。这与"几何 token 注入 VLM"路线相反却互补：sensVLA 是让几何绕开语言，后者是让语言获得几何
2. **空间接地提升鲁棒性而不只是精度**：28% RMSE 改善在意料中，29% 的失效退化减少更有战略意义——空间智能的工程价值很大程度在于**冗余与降级安全**
3. **重型机械是 VLA 的好试金石**：动作低维连续、精度要求高、安全关键——它逼你把空间接地做扎实，而家用机械臂任务可能掩盖接地缺失
4. **flow-matching 连续动作**：动作生成从离散 token 走向连续速度场回归，与空间连续性本质更匹配

### 4.4 可应用的 Spatial AGI 场景

- 矿山/建筑/农林的自主重载机械（装载机、挖掘机、推土机）
- 任何"语义任务 + 米制执行"的机器人：送餐机器人、叉车、泊车系统
- 传感器降级场景（夜间、恶劣天气、相机污损）下的具身自主

## 5. 创新点和局限性（Q3）

### 5.1 主要创新点

1. **BEV-to-expert 专用通路**：几何特征绕过 VLM 直接驱动动作专家，架构级解决"语言瓶颈损失米制精度"问题
2. **解耦-交互双流设计**：空间接地与语言推理各自独立又决策时交互，是 VLA 架构光谱上介于端到端耦合与完全模块化之间的新点位
3. **重型机械 VLA 落地**：装载机是 VLA 文献中少见的非机械臂、非驾驶的工业具身形态，6 维异构动作空间（行驶+作业机构）
4. **flow-matching 动作专家** + 全可训练（VLM 用现成 Qwen3-2B，专家从头训练）的高性价比配置
5. **容错性量化**：显式报告传感器失效下的退化， rare but valuable

### 5.2 主要局限性

1. **聚合精度只与 camera-only 打平**：几何通路的收益集中在装载场景，一般场景下未显示整体优势——BEV 通路的性价比因场景而异
2. **单一机型单一数据集**：真实装载机数据，跨机型/跨场景泛化未验证
3. **开环/逐步指标**：per-step parity 与 RMSE 是离线指标，缺少闭环作业成功率
4. **2B 级 VLM 的语义上限**：复杂多阶段作业指令（多目标、约束组合）下语义流能力有限
5. **LiDAR 依赖**：几何通路建立在 LiDAR 之上，纯视觉场景下的空间接地退化问题未讨论

### 5.3 与相关工作的对比

- vs RT-2/OpenVLA 类通用 VLA：动作经语言 token 化，米制精度受限；sensVLA 用几何旁路
- vs 3DVLA/GEAR-VLA（3D 理解增强 VLA）：那些把 3D 表示注入 VLM 表示空间；sensVLA 把几何直接送到动作端，主张"动作需要的几何不必经过语言"
- vs 端到端驾驶模型：同为 BEV+连续动作，sensVLA 增加 VLM 语义条件化，面向作业而非纯导航
- 优势：架构原则清晰、工业落地证据实；劣势：任务域与泛化窄

## 6. 核心技术发现

- **发现 1**：几何信息绕过语言瓶颈能带来数量级达 28% 的米制精度提升——语言不是好的空间介质
- **发现 2**：显式空间接地的最大价值在故障模式：相机失效时退化少 29%，双流冗余是安全架构
- **发现 3**：收益集中在"装载核心场景"——空间接地的 ROI 与任务的米制敏感度成正比

---

## 7. 与昨日研究的关联

昨日论文里 VLA 方向（如空间 token 注入、层次化 VLA）多走"给语言模型加空间"路线；sensVLA 反其道行之"给动作专家直接供几何"。两方向合起来勾勒出完整设计空间：空间信息可以在 VLM 内融合（推理型任务）或在动作端融合（执行型任务），选择取决于任务的米制敏感度。这与今日 VABench 的发现呼应：感知-行动鸿沟正是发生在"语言推理 → 米制动作"的转换处，sensVLA 的几何旁路是填沟的一种架构方案。

## 9. 个人思考

### 最令人兴奋的发现

"相机失效时退化少 29%"。多数 VLA 论文追求峰值精度，这篇用消融揭示了架构的**失效模式优势**。对重型机械这种安全关键场景，降级性能比峰值性能更接近部署真相。空间接地被证明是一种冗余来源，这为"多模态空间智能 = 天然容错"提供了量化证据。

### 潜在局限

整体精度只打平 camera-only 基线这点值得警惕：如果 BEV 通路只在部分场景有用，架构复杂度（LiDAR + 融合 + 专用通路）是否值得？需要闭环作业成功率和更广任务分布的验证。

### 给 Spatial AGI 的启发

认知架构的分层路由思想：不同信息类型应走不同通路到决策点——语义走语言、几何走米制、二者在动作处汇合。这可能比"一个大模型吃掉一切"更接近空间智能的正确形态。

---

## 10. 总结

### 核心发现总结

sensVLA 用"BEV 几何旁路 + VLM 语义条件化 + flow-matching 动作专家"的解耦架构，在真实装载机上把装载场景的纵向速度 RMSE 降 28%、相机失效退化减 29%，证明显式空间接地同时改善精度与容错。

### 对 Spatial AGI 的意义

它确立了"几何不经过语言瓶颈"的架构原则并给出量化证据，同时揭示空间接地的容错价值——为空间 AGI 的多流认知架构与安全降级设计提供了工业级参照。
