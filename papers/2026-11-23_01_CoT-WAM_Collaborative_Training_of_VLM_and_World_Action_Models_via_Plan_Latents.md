## 0. 一句话总结

CoT-WAM 提出了一个 VLM 与世界动作模型（WAM）联合训练框架：通过可学习的潜在意图 token 作为两个模型之间的可微通信接口，用文本监督和目标图像监督双重信号约束接口的信息内容，使 WAM 获得开放世界语义理解、零样本泛化和长程规划能力，在 LIBERO、CALVIN、RoboCasa-Kitchen 等 6 个基准上取得 SOTA。

## 核心问题

### Q1: 核心算法原理

**问题**: 这篇文章的核心算法原理是什么？

**分析**:

#### 1. 核心思想和动机

论文的出发点来自当前具身智能两条主线各自的短板：

- **VLA（Vision-Language-Action）模型**：继承 VLM 的语义理解能力，通过离散动作 token 或动作专家输出控制信号，泛化性强。但它是**反应式（reactive）控制范式**——只根据当前观测直接映射动作，不能建模物理世界的演化，也不能预测动作后果。对开放世界操作智能体来说，"预见未来"是关键能力。

- **WAM（World Action Model）**：联合建模未来视觉状态转移和动作分布，可以从大规模视频预训练中获得对物理动力学的理解。但现有 WAM（Fast-WAM、LingBot-VA、DreamZero 等）**语义能力不足**：通常依赖一个独立的冻结文本编码器做语言接地，无法完成开放世界场景理解、语义推理和长程规划。

已有融合尝试的缺陷：
- **ST-WAM**：VLM 全程冻结，语义表示不与 WAM 联合优化，VLM 的语义知识无法适配未来状态预测和动作生成的需求。
- **SG-WAM**：VLM 规划器与 WAM 联训，但需要额外的冻结语义教师和几何教师来监督未来特征预测，依赖外部先验。

CoT-WAM 的核心主张：**用一个可学习的潜在接口（plan latents）连接 VLM 和 WAM，并让这个接口在联合训练中被双向塑造**——VLM 的输出不再是"硬文本"，而是编码了动作预期后果的连续意图表示。

#### 2. 主要技术方法

整个系统由三部分构成：

1. **VLM 规划器**：负责场景理解和子任务规划。
2. **潜在接口（Latent Interface）**：K 个可学习意图 token，是两模型之间的信息通道。
3. **WAM 模块**：MoT（Mixture-of-Transformers）架构，含视频专家和动作专家。

关键设计：

**（a）潜在 VLM–WAM 接口**

- 输入当前观测 o_t 和任务指令 ℓ，在 VLM 输入序列后追加 K 个可学习意图 token Q = (q_1, ..., q_K)。
- VLM 自注意力使这些 token 聚合场景与任务信息，其最终隐状态经过 MLP 投影层 P_ψ 得到连续意图表示 C_t：

  Z_t = F_φ(o_t, ℓ, Q)|_Q,  C_t = P_ψ(Z_t)

- 下游 WAM 的视频专家和动作专家通过 cross-attention 访问 C_t，作为未来状态预测和动作生成的条件。
- 由于接口是可微的，未来预测的梯度可以穿过接口回传到 VLM，实现真正的联合训练。

**（b）潜在接口的双重监督**

接口建立了通路，但还需要目标函数决定接口"传什么"。论文设计了两种互补监督：

- **任务文本监督（Task Text Supervision）**：
  - 不引入辅助语言模型，直接利用 VLM 自身的文本生成能力。
  - 训练时把目标文本 y_t 追加在意图 token Q 之后，让 VLM 自回归预测 y_t。
  - 关键技巧：注意力掩码设计——目标文本只能读取潜在查询，被禁止读取观测图像和任务指令。这强制潜在查询编码子任务预测所需的信息。
  - 普通操作任务用任务 prompt 作目标文本；长程规划任务用子任务描述作目标。
  - 推理时只需一次前向获得 C_t，不需要解码文本。

- **目标图像监督（Goal-Image Supervision）**：
  - 仅靠任务语义监督太粗糙，无法让潜在查询编码 VLM 丰富的场景理解和具体意图。
  - 用训练窗口末尾图像 g_t = o_{t+H} 作为目标图像。
  - 复用 WAM 的视频专家：训练它从当前观测和意图条件 C_t 预测目标图像。
  - 这迫使潜在接口编码与意图相关的具体视觉变化，把抽象意图接地到具体视觉状态。

**（c）目标条件化的世界动作建模**

- WAM 沿用 Fast-WAM 的 MoT 基础架构：视频专家预测视觉演化，动作专家预测动作序列，均通过 cross-attention 访问 C_t。
- 额外地，预测出的目标图像也作为动作和视频生成的条件：训练时从 (o_t, C_t) 预测 g_t，再从 (o_t, g_t, C_t) 预测动作序列和未来视频。
- 注意力掩码保证动作生成不能 attend 未来视频——未来预测只作为训练期的表征学习辅助监督，推理时跳过完整未来视频轨迹的显式预测以保证效率。
- 三种预测任务（目标图像、未来视频、动作序列）都用冻结 VAE 编码到潜空间，用统一的 flow-matching 目标：

  y_τ = (1−τ)y + τε,  L_FM(y) = E[‖f_θ(y_τ, τ; c) − (ε−y)‖²]

- 目标图像与视频生成共享视频专家；动作生成用动作专家。
- 推理流程：先从潜在查询预测目标图像，再用它条件化动作预测——**目标图像成为连接语义理解与控制的中间表示**。

**（d）两阶段训练策略**

- **Stage 1（语义接口学习）**：联合训练 VLM + 视频专家（不含动作专家），同时用文本监督和目标图像监督塑造潜在接口，使 VLM 输出能作为有效的生成条件。
- **Stage 2（动作策略学习）**：冻结接口，学习动作生成，保留视觉监督。

#### 3. 算法流程和关键步骤

完整流程：

1. 输入：当前观测 o_t、本体状态 s_t、任务指令 ℓ。
2. VLM 前向：o_t + ℓ + K 个可学习意图 token → 意图 token 隐状态 → MLP 投影 → 连续意图 C_t。
3. 视频专家：以 (o_t, C_t) 为条件 flow-matching 生成目标图像潜码 → 解码/保持潜码作为 g_t 估计。
4. 动作专家：以 (o_t, g_t, C_t) 为条件 flow-matching 生成动作块 A_t = (a_t, ..., a_{t+H-1})。
5. 闭环执行：机器人执行动作块，观测更新，回到步骤 2。
6. 训练：Stage 1 联合优化 VLM+视频专家（L_text + L_goal + L_video）；Stage 2 冻结接口优化动作专家（+L_action），注意力掩码阻止动作读取未来视频。

#### 4. 输入输出

- **输入**：RGB 观测 o_t（当前帧及历史帧）、机器人本体状态 s_t、语言任务指令 ℓ。
- **中间表示**：K 个意图 token 的连续隐状态 C_t；预测的目标图像 g_t。
- **输出**：长度 H 的动作序列 A_t（推理时不生成完整未来视频以加速）。

### Q2: 与 Spatial AGI 的关系

**问题**: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**分析**:

#### 1. 如何理解和表示空间

CoT-WAM 对空间的表示是**三层递进**的：

1. **感知层**：VLM 从观测中理解场景的空间布局、物体属性和可供性——这是语义层面的空间理解。
2. **意图层**：潜在接口 C_t 把"做什么"编码成连续向量。这个向量隐含了对空间中哪些物体要被如何操纵的压缩表示。
3. **物理层**：目标图像 g_t 把意图渲染成具体的未来空间状态——物体会在哪里、场景会变成什么样。这是最接近"空间想象"的表示。

有趣的是，论文实际上构建了一个**从抽象语义到具体空间状态的连续谱**：文本（最抽象）→ 潜在意图（中间）→ 目标图像（具体空间预测）→ 动作（空间中的物理执行）。这本身就是 Spatial AGI 需要的"空间思维链"（Chain-of-Thought for Space）的一种工程实现——论文标题中的 "CoT" 一语双关。

#### 2. 如何处理空间关系

- **空间动力学预测**：视频专家的预训练目标本质上是学习"如果执行这个意图，空间会怎么变"。目标图像监督使模型必须精确预测物体空间位置的演化。
- **空间条件化控制**：动作生成同时以语义意图（C_t）和空间目标（g_t）为条件，控制信号被"接地"到具体的空间终态上，而不是凭空从语义推断。
- **注意力掩码的信息流控制**：目标文本只能从意图 token 读取信息，这个设计强制空间-语义信息的瓶颈式压缩，类似人类"先想清楚再动手"的空间规划过程。

#### 3. 对 Spatial AGI 的启发

- **接口设计是关键**：Spatial AGI 系统必然是多模块的（感知、推理、预测、控制），模块间的通信接口设计比单模块能力更决定整体智能水平。CoT-WAM 证明：可学习 + 双重监督 + 可微梯度回传的接口，远优于硬文本或冻结特征。
- **联合优化优于冻结拼接**：ST-WAM 的失败说明冻结的语义模块无法适配空间预测需求。Spatial AGI 的语义知识与空间动力学知识必须共同演化。
- **中间表示的接地（grounding）**：目标图像作为"意图的空间投影"是很好的抽象-具体桥梁。Spatial AGI 可以推广这一思想：任何高级推理结果都应该被投影成可验证的空间状态预测。
- **推理时跳过昂贵预测**：训练时用世界模型监督塑造表征，推理时跳过完整视频生成——这种"训练用世界模型、推理走捷径"的效率思路对部署 Spatial AGI 很重要。

#### 4. 可以应用的 Spatial AGI 场景

- **家庭机器人长程任务**：RoboCasa365 式的多步移动操作，VLM 做任务分解，WAM 预测每步空间后果。
- **自动驾驶**：类似 Xiaomi Auto World Model 2.0 的思路——语义理解（交通意图）+ 空间预测（轨迹推演）通过潜在接口耦合。
- **空间导航**：意图 token 可以扩展编码导航子目标，目标图像预测可达的空间视图。
- **具身问答（Embodied QA）**：预测"如果我走过去会看到什么"，将问答接地到空间想象。
- **仿真与规划闭环**：预测的目标图像可以直接作为轻量级世界模型用于 MPC 式规划。

### Q3: 创新点和局限性

**问题**: 基于前面的分析，这个方法的主要创新点和局限性是什么？

**分析**:

#### 1. 主要创新点

1. **可微潜在接口 + 双重监督**：相比 DSWAM 的离散文本接口（不可微）、ST-WAM 的冻结特征、SG-WAM 的外部教师监督，CoT-WAM 的接口同时满足：可微（梯度可回传 VLM）、信息丰富（不止文本语义）、有明确监督信号（文本+目标图像）、无外部依赖。
2. **目标图像作为语义-控制桥梁**：把 VLM 的抽象意图投影为具体的视觉终态，再以此条件化动作生成。这个三段式（语义→空间预测→控制）架构是论文最优雅的设计。
3. **掩码设计实现信息瓶颈**：文本监督的注意力掩码强制意图 token 承载全部必要信息，是隐式的信息压缩正则化。
4. **两阶段训练解耦**：先学"想清楚"（接口+视觉预测），再学"做到"（动作生成），符合技能习得的自然顺序。
5. **实证全面**：六个基准覆盖控制性能（LIBERO/CALVIN/RoboCasa-Kitchen SOTA）、零样本泛化（LIBERO-Plus/Pro 无微调显著超越 Fast-WAM）、长程规划（RoboCasa365 超越有无外部规划器的基线），并有真机实验。

#### 2. 主要局限性

1. **目标图像假设的可观测性**：目标图像监督假设 o_{t+H} 是一个"好的目标状态"，但长程任务中间目标可能不可观或非唯一（同一意图对应多个可行终态），单帧目标图像监督可能引入多模态歧义，flow-matching 虽能部分处理但仍有信息损失。
2. **K 个意图 token 的容量上限**：固定 K 的连续接口是信息瓶颈，过于复杂的长程规划（几十个子任务、空间推理链）可能超出其容量。论文未讨论 K 的敏感性。
3. **推理仍需目标图像生成**：虽然跳过了完整视频，但每次推理仍需 flow-matching 采样目标图像，对高频控制场景延迟敏感。
4. **2D 图像目标 vs 3D 空间**：目标图像是 2D 投影，未显式建模 3D 空间几何。对需要精确空间推理的任务（如遮挡后的操作），2D 目标可能不够。
5. **VLM 冻结的 Stage 2**：第二阶段冻结接口（含 VLM），意味着动作学习中发现的问题无法反馈修正语义理解。

#### 3. 与其他相关工作的对比

| 方法 | 接口 | VLM 状态 | 外部教师 | 特点 |
|------|------|----------|----------|------|
| Fast-WAM | 冻结文本编码器 | 无VLM | 无 | 高效但语义弱 |
| ST-WAM | 冻结VLM特征 | 冻结 | 无 | 语义不适配 |
| SG-WAM | 连续 | 联训 | 语义+几何教师 | 依赖外部先验 |
| DSWAM | 离散文本 | 可选 | 无 | 不可微、无梯度通路 |
| **CoT-WAM** | **可学习潜在token** | **联合训练** | **无** | **可微+双重监督+目标图像接地** |

**优势**：接口设计的完整性和无外部依赖的简洁性。
**劣势**：相比 SG-WAM 缺少几何教师监督，3D 空间精度可能不足；相比更简单的 Fast-WAM 增加了系统复杂度和推理成本。

## 核心技术发现

- 发现1：VLM→WAM 的通信不应是硬文本，可学习的连续意图 token 能编码文本无法表达的"动作预期后果"信息。
- 发现2：目标图像是连接抽象语义与物理控制的理想中间表示——它既被语义监督塑造，又直接条件化控制生成。
- 发现3：注意力掩码可以精确控制"哪些信息必须流经潜在接口"，是塑造接口内容的有效手段。
- 发现4：两阶段训练（先语义接口、后动作策略）比端到端一锅炖更稳定有效。

## 与 Spatial AGI 的关系

### 直接贡献
提供了一个"语义理解→空间预测→动作控制"三段式的具身智能架构模板，其中空间预测（目标图像）是核心枢纽。

### 技术启发
- 多模块 Spatial AGI 系统的接口应可微、可学习、有监督；
- 任何高级推理都应投影为可验证的空间状态预测（grounded imagination）；
- 训练与推理可以不对称：训练用完整世界模型塑造表征，推理走轻量路径。

### 应用场景
家庭长程操作、自动驾驶决策、导航、具身问答、轻量级规划式世界模型。

## 个人思考

### 最令人兴奋的发现
"CoT"的命名暗示了深层洞察：具身智能的链式思考不一定是语言链，而可以是 **语义→空间预测→控制** 的异构链。目标图像就是这个思维链中"空间推理"环节的物化。这比纯语言的 chain-of-thought 更接近真正的空间智能——想象未来场景再决定行动，正是人类空间认知的核心机制。

### 潜在局限
2D 目标图像本质上把空间智能压缩到了图像平面。真正的 Spatial AGI 或许需要 3D 目标状态（点云、3DGS 场景）作为中间表示——那样意图才能编码遮挡关系、物体背面、精确几何等图像无法承载的空间信息。此外，意图 token 的固定容量让人担忧规模化问题。

### 与近期研究的关联
- 与 2026-11-22 精读的 Verify2Act（Critic 引导的潜在世界模型验证操作计划）互补：Verify2Act 用 critic 验证潜在计划，CoT-WAM 用目标图像接地意图——两者都在探索"潜在空间中的规划如何变得可靠"。
- 与 11-21 的 Point Dynamics as Proxy 呼应：都认为显式视频生成对控制不必要，潜在/稀疏的动力学代理更高效。
- 今天候选列表中的 CauSyncVLA、LaST1.0、MAWAM 显示"WAM + 潜在接口"已是 2026 年 11 月的爆发性方向，CoT-WAM 的接口设计可能是这波浪潮中的代表性方案。

## 深度技术拆解

### A. 为什么硬文本接口不够用？

传统 WAM 的语言接地链条是：指令 → 冻结文本编码器 → 嵌入向量 → 条件化视频/动作生成。这个链条有三个结构性缺陷：

1. **信息截断**：文本编码器只能输出指令本身的语义，无法融入当前观测的场景信息。"把杯子放到盘子旁边"这句话在不同桌面布局下含义完全不同，但冻结编码器给出的向量是同一个。
2. **无梯度通路**：冻结编码器不可训练，WAM 训练中的所有发现（什么样的条件向量让预测更准）无法反馈改善语言表示。
3. **离散瓶颈**：语言本身是低带宽离散信号。人类给机器人下指令时省略的大量细节（拿哪个杯子、绕过哪个障碍物、用多大力气）全部丢失，需要下游网络自己猜。

CoT-WAM 的潜在接口逐一解决：意图 token 在 VLM 内部与观测和指令共同编码（解决1）；MLP 投影层可训练且梯度可从 WAM 回传（解决2）；连续向量可携带任意细粒度的空间与动力学信息（解决3）。

### B. 双重监督的互补性分析

| 维度 | 文本监督 | 目标图像监督 |
|------|----------|--------------|
| 信息类型 | 任务语义、子任务序列 | 具体空间终态、物体位置变化 |
| 抽象层级 | 高层意图 | 低层空间状态 |
| 监督来源 | 标注的任务 prompt / 子任务描述 | 训练窗口末帧 o_{t+H} |
| 提供方 | VLM 自身文本生成 | WAM 视频专家 |
| 解决的问题 | 接口不知道"任务是什么" | 接口不知道"任务完成后的空间长什么样" |

两种监督缺一不可：只有文本监督，意图 token 退化为任务分类特征，丢失场景细节；只有图像监督，意图 token 可能编码与任务无关的视觉变化（如光照、他人移动），缺乏任务语义的锚定。

### C. 注意力掩码的信息流设计

论文最精巧的工程细节之一。训练期的注意力布局：

- 观测图像、任务指令 → 意图 token：允许（意图聚合信息）
- 意图 token → 目标文本：允许（文本只能从意图读取）
- 观测图像、任务指令 → 目标文本：**禁止**（强制信息瓶颈）
- 动作专家 → 未来视频：**禁止**（未来预测只做辅助监督，不泄漏给控制）
- 推理期：裁剪掉 VLM 任务文本 token 和 WAM 未来视频 token，保留意图接口和目标图像条件路径。

这套掩码本质上定义了一个**信息路由图**：什么信息必须流经哪里、什么路径被禁止。比起堆叠更多参数，精确的信息流控制可能是性能提升的更关键因素。

### D. Flow-Matching 统一三种预测的深意

目标图像、未来视频、动作序列用同一个 flow-matching 目标训练，这不是简单的工程便利：

1. **概率建模的一致性**：三者都被视为从条件分布中的生成式采样，动作序列因此获得了多模态表达能力（同一任务有多条可行动作轨迹）。
2. **表示空间对齐**：视频与动作在同一噪声-去噪框架下训练，隐式地对齐了"视觉预测"与"动作执行"的表征几何。
3. **与扩散策略谱系的衔接**：π0、Fast-WAM 均采用 flow-matching 动作生成，CoT-WAM 延续了这一技术路线并证明它与 VLM 联训兼容。

### E. 两阶段训练的理论直觉

Stage 1 不训练动作专家，只学接口+视觉预测，相当于先解决一个自监督的"视频预测 + 意图压缩"问题。这个顺序的好处：

- 动作专家面对的条件 C_t 和 g_t 已经是高质量的、稳定的输入，避免了三模块同时随机初始化时的优化震荡；
- 语义接口的形态由视觉预测损失决定，不受早期动作损失的干扰——动作数据通常比视频数据少得多，若一开始联合训练，动作损失梯度可能把接口拉向过拟合小数据的方向。

这与预训练-微调的经典范式同构：先在大量数据上学通用表示，再在小数据上学任务技能。

## 实验设计与方法论评析

### 基准覆盖的三个正交维度

1. **闭环控制性能**（LIBERO、CALVIN、RoboCasa-Kitchen）：考察标准操作任务成功率，CoT-WAM 在不做额外具身预训练的情况下达到 SOTA，说明 VLM 联训带来的语义增益可以替代部分具身预训练数据。
2. **零样本语义泛化**（LIBERO-Plus、LIBERO-Pro）：考察指令扰动、场景变化、干扰物等分布外情况。这是最能体现 VLM 联训价值的维度——冻结文本编码器的 Fast-WAM 在语义扰动下崩溃，CoT-WAM 无微调即大幅领先。
3. **长程移动操作**（RoboCasa365）：考察任务分解与子目标衔接，无论有无外部规划器，CoT-WAM 都优于基线，说明潜在接口承载的子任务信息是有效的。

### 消融逻辑推断

论文验证路径暗示的关键消融（基于架构设计推断）：

- 去掉目标图像监督 → 只剩文本语义，场景级泛化应显著下降；
- 去掉文本监督 → 意图 token 缺乏任务锚定，长程任务的子任务分解应退化；
- 单阶段联合训练 → 优化不稳定，性能下降；
- 冻结 VLM（退化为 ST-WAM 式）→ 无法适配预测需求，性能介于 Fast-WAM 与完整方法之间。

### 评价：实验叙事的完整性

六个基准 + 真机验证构成了从仿真到现实、从短期到长程、从分布内到分布外的完整证据链。唯一遗憾是摘要与正文未见对推理延迟的定量报告——对真机部署而言，每次推理额外一次目标图像 flow-matching 采样的开销是实际关切。

### 对 Spatial AGI 路线图的意义

如果 Spatial AGI 的终极形态是"能在三维世界中感知、推理、想象并行动的通用智能"，那么当前研究正在收敛到一个分层架构：

1. **语义层**（VLM）：理解世界是什么、任务是什么；
2. **想象层**（世界模型/WAM）：预测空间将如何演化；
3. **执行层**（动作专家/策略）：在物理世界中落地。

CoT-WAM 的价值在于证明了第1、2层之间的接口可以端到端学习，且**中间表示应该被监督成"可想象的空间状态"**。下一阶段的自然问题是：这个中间表示能不能从 2D 图像升级为 3D 场景表示（3DGS、点云、占据栅格）？如果能，想象层将真正具备三维空间推理能力，而不是停留在图像平面的投影想象。

## 方法细节补充笔记

### F. VLM 规划器的角色再审视

值得注意的是，CoT-WAM 中的 VLM 并非传统意义上的"规划器"（planner），因为推理时它从不显式输出计划文本。它的规划行为完全隐式地发生在意图 token 的前向计算中。这带来一个有趣的属性：

- **隐式规划**：计划存在于连续向量中，不可直接阅读，但通过 Stage 1 的文本监督，这些向量被约束为"能预测子任务序列"的表示；
- **可解释性折衷**：相比 DSWAM 那种显式输出子任务文本的方案，CoT-WAM 牺牲了可解释性换取了信息带宽；
- **调试启示**：实际部署中可以通过解码意图 token 附近的注意力分布或探针分类器来间接监测其内容，这是后续工程化需要补齐的工具链。

### G. 与 Fast-WAM 的继承关系逐项对比

| 组件 | Fast-WAM | CoT-WAM |
|------|----------|---------|
| 语言条件来源 | 冻结文本编码器 | VLM 意图 token（联训） |
| 场景感知条件化 | 无（语言独立于观测） | 有（意图融合观测+指令） |
| 中间目标表示 | 无 | 预测的目标图像 |
| 训练阶段 | 单阶段 | 两阶段 |
| 监督信号 | 视频预测+动作 | +文本+目标图像 |
| 推理路径 | 直出动作 | 意图→目标图像→动作 |
| 语义泛化 | 弱 | 强（LIBERO-Plus/Pro 验证） |

可以认为 CoT-WAM = Fast-WAM + 可微语义接口 + 目标图像接地 + 分阶段课程。每一项改动都指向同一个目标：让控制信号携带更多任务相关信息。

### H. 潜在失败模式分析

从架构出发可以预见的失败场景：

1. **目标歧义**：指令"把桌面整理干净"对应无数合法终态，单目标图像监督迫使模型选一个，可能学出与演示分布强相关的偏好，泛化到新桌面时选错目标。
2. **长程误差累积**：闭环执行中每步的目标图像预测误差会累积，RoboCasa365 上的提升幅度（相对短期任务）若不显著，可能正是这个原因。
3. **接口塌缩**：若 VLM 容量远大于 WAM，意图 token 可能退化为简单的任务嵌入（接口塌缩到文本监督主导），丢失场景细节；反之可能过拟合视觉预测而丢失任务语义。两种塌缩的平衡是训练超参的敏感点。
4. **动态干扰物**：目标图像把整帧场景作为目标，场景中非任务相关的动态元素（宠物、人走动）会被错误纳入预测目标。

### I. 推理效率的量化估算

假设 VLM ~3B 参数、WAM 视频专家 ~1B、动作专家 ~300M（量级推断）：

- Fast-WAM 推理：文本编码（毫秒级）+ 动作专家 flow-matching（若步）采样；
- CoT-WAM 推理：VLM 单次前向（~几十 ms）+ 目标图像潜码采样（单步流匹配可控制在数 ms）+ 动作专家采样。

总体推理开销增加主要来自 VLM 前向，但换来的是零样本泛化与长程规划的质变。这种"用推理时计算换泛化能力"的交换在 2026 年的具身智能论文中已成为主流价值主张。

## Q2 补充：空间认知科学的视角

从认知科学对照看，CoT-WAM 的三段式架构与人类空间问题求解的经典模型（如 Kosslyn 的心理意象理论）高度同构：

- **语义理解** ≈ 命题表征（任务是什么）；
- **目标图像预测** ≈ 心理意象（在脑中模拟动作后的场景）；
- **动作生成** ≈ 运动规划与执行。

人类在空间任务前的"心理模拟"（mental simulation）被证明是空间智能的核心机制，而 CoT-WAM 的目标图像正是机器版的 mental simulation。这个类比暗示：未来 Spatial AGI 的评测不应只看动作成功率，还应直接评测"想象质量"（目标图像预测的准确性与多样性）——这可能是比 LIBERO 系列更本质的基准维度。

进一步地，人类 mental simulation 的一个关键特征是**可控性**：可以模拟"如果我换个方式拿会怎样"，即反事实想象。CoT-WAM 的目标是单次确定性的（给定意图推出一个目标），不支持反事实查询。在接口上采样多个意图变体并对比各自的目标图像，就是最直接的反事实空间想象实现——这是论文框架天然支持但未探索的方向。

## Q3 补充：更宏观的优劣势权衡

### 优势的深层原因

CoT-WAM 的六个基准全面领先，表面原因是"加了 VLM"，深层原因是**监督信号的信息量**：文本+目标图像两种监督给接口注入的信息量，远大于单一任务 prompt 嵌入。在数据充足的预训练范式下，监督信息量往往比架构微调更决定性能上限。

### 劣势的系统性根源

其局限大多可归结为一个根源：**中间表示是 2D 且单帧的**。3D 几何缺失（遮挡、精确深度）、时序信息有限（单终态而非轨迹）、多模态歧义（单目标）都源于此。根本解法可能是把中间表示升级为结构化的 3D 空间状态序列——但这会显著增加接口带宽与训练难度，是明显的研究权衡点。

### 对比工作的公平评价

SG-WAM 引入几何教师监督看似"更重"，但其在 3D 一致性上可能优于 CoT-WAM；DSWAM 的显式文本计划看似原始，但可解释性和可干预性是 CoT-WAM 缺乏的。没有免费午餐：CoT-WAM 选择了信息带宽与端到端优化，放弃的是可解释性与显式几何。
