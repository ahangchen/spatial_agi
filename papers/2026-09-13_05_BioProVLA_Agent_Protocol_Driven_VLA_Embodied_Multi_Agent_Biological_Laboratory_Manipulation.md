## 一句话总结

BioProVLA-Agent 用 **~800-850 美元的低成本机械臂平台**（So-ARM101）构建了"自然语言实验协议即任务接口"的多智能体闭环系统：Tailored LLM 把湿实验协议解析为带前置条件/完成判据/知识库索引的可验证子任务 → VLM-RAG 用视觉+机器人状态+检索的成功/失败案例做执行前就绪性与执行后完成性双重校验 → 轻量 SmolVLA（经课程式在线视觉扰动增强，AugSmolVLA）执行——在 15 原子任务 + 6 组合工作流 + 3 双臂任务上，显著提升透明耗材、反光、过曝场景下的执行稳定性。

## 核心问题

### Q1: 这篇文章的核心算法原理是什么？

#### 1. 核心思想和动机

**(a) 三大现实痛点**

1. **协议非结构化**：生物实验协议是自然语言，含专业术语、隐含条件、严格步骤依赖——生物学家不该被迫把协议翻译成 ROS 脚本；
2. **视觉退化**：离心管、冻存管、血清瓶等耗材透明/反光/弱纹理，光照变化、镜面反射、过曝会破坏定位与抓取稳定性（VoxPoser/ReKep 类依赖深度感知与分割的方法在此不稳定）；
3. **需要状态感知执行**：多步流程要求系统持续判断"能否执行/是否完成/是否异常"，而非一次性指令跟随——VLA 直接 observation→action 映射缺乏执行前后语义校验，早期原子操作的微小误差会传播到后续步骤。

**(b) 系统定位**

- 低成本（~800-850 USD）、affordable、面向资源受限实验室；
- 协议即接口（protocol-centered）：任务分解、状态确认、机器人执行都通过自然语言协议驱动；
- 闭环可验证（closed-loop-capable）：执行前语义校验 + 执行后完成检查 + 失败时重试/重排序/人工介入。

#### 2. 主要技术方法

**(a) 四智能体协作框架**

1. **Guiding Decision Agent（调度者）**：系统初始化 S₀=G(P,ℳ,C_R)（协议 P、模型集 ℳ={M_LLM,M_VLM,M_VLA}、机械臂配置 C_R）、子任务顺序与完整性检查、闭环调度、重试决策、异常处理；
2. **Tailored LLM Protocol Agent**：prompt 约束的 LLM 解析 Y=F_LLM(P;Θ_p)（角色定义/实验意图理解/实体识别/动作空间约束/语义粒度约束/结构化 JSON 输出规则），分四步：意图 g=f_intent → 实体 E=f_entity → 动作谓词映射到**封闭原子动作集** A（开盖/合盖/放置/移除/抓取/移动/按键/等待）a_i=φ(v_i,A) → 输出子任务序列 𝒯={τᵢ}，每个 τᵢ=(Iᵢ, Preᵢ, Postᵢ, Kᵢ)（自然语言指令、前置条件、完成条件、知识库索引）；
3. **VLM-RAG Verification Agent**：验证请求 Qᵢʲ=(Cᵢʲ,Kᵢ,j)，j∈{pre,post}；整合实时观察 O_t、机器人状态 R_t、检索的实验操作知识（验证 prompt + 成功/失败参考案例），输出 vᵢ^pre=V(O_t,R_t,Preᵢ,Kᵢ) / vᵢ^post=V(O_{t+1},R_{t+1},Postᵢ,Kᵢ)；
4. **VLA Embodied Agent**：轻量 SmolVLA 策略 A_t=π_θ(O_t,R_t,Iᵢ)，输出长度 H 的动作序列，执行离心管放置、管盖操作、废液处理、双臂协同等。

**(b) 闭环调度逻辑（核心）**

- v^pre=1 → 执行；v^pre=0 → **不盲目执行**：① 若序列中未执行的子任务能满足前置条件 → 调整执行顺序；② 重排序无效 → 二次验证（抗视觉误判）；③ 仍失败 → 挂起并请求人工介入；
- v^post=1 → 进入下一子任务；失败 → 按失败原因与重试次数触发重执行/重排序/人工介入。

**(c) AugSmolVLA：课程式在线视觉扰动增强**

- 在线增强（训练时动态扰动，不需离线生成增强数据集）：Õ_t=𝒯_α(O_t)，𝒯_α 由亮度调整、对比度变化、低照度、过曝等光照扰动组成；损失 L(θ)=‖π_θ(Õ_t,R_t,I)−A*‖²；
- 三阶段课程：𝓔₁ 原始数据学基础映射 → 𝓔₂ 逐步引入低照/强光/过曝增强（扰动强度 α(e) 渐增）→ 𝓔₃ 原始+增强混合训练 λO_t+(1−λ)𝒯(O_t)；
- 目的：在不增加存储成本的前提下扩展视觉分布覆盖，提升透明耗材/反射/过曝下的定位与操作稳定性。

#### 3. 评测基准与指标

- **平台**：So-ARM101 机械臂（单臂+双臂模式）；资产：BY-80C 离心机、15 mL 离心管、1.8 mL 冻存管、离心管架、水浴锅、水浴浮漂、25 mL 血清瓶、垃圾桶——几何尺寸与物理属性对齐真实湿实验室；
- **数据**：每个原子任务 100 条遥操作示教轨迹，LeRobot 格式存储；
- **任务层级**：15 原子任务（12 单臂：开合离心机盖/水浴盖、插拔离心管/浮漂、精确放置离心管/冻存管到架、丢弃耗材、拧盖/紧盖、倒废液；3 双臂：拧开/拧紧管盖、倒废液入血清瓶）+ 6 组合工作流 + 3 双臂任务；
- **指标**：单任务成功率 SR（3 次重复实验取均值±标准误）；组合任务完成率 CR（步级完成比例，20 次试验，不要求全步骤成功——细粒度评估任务转换/状态维持/抗误差累积能力）。

#### 4. 输入输出

- **输入**：自然语言生物实验协议 + 实时相机观察 + 机械臂状态；
- **输出**：结构化子任务序列 → 验证判定（pre/post）→ 连续机器人动作序列 → 可解释的失败反馈与人工介入触发。

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

#### 1. 如何理解和表示空间

BioProVLA-Agent 的空间表示体现在三个层面：

- **协议级空间语义**：LLM 解析时显式提取" manipulated objects、spatial relationships、action order"——实验文本中的空间关系（管入架、液入瓶、盖合于离心机）被结构化为前置/后置条件。空间理解在此是**语言中的空间谓词 → 物理世界状态约束**的映射；
- **状态级空间验证**：VLM-RAG 判断的是空间配置问题——"管是否在架的孔位里""盖是否贴合离心机口""目标容器是否就位"。这些是**精细的物体间空间关系判定**（厘米级，如 1.8 mL 冻存管入红色管架孔位），比 GeoAgent 的大洲级定位精细几个数量级；
- **执行级空间控制**：VLA 输出的是 7-DoF 连续动作序列——末端执行器在工作空间中的轨迹，涉及接近方向、插入深度、旋拧的圆弧协调、倾倒的力矩控制。

三者构成 Spatial AGI 的完整栈：**符号空间（协议）→ 关系空间（验证）→ 度量空间（执行）**。论文的价值在于展示了这个栈的每一层都需要不同的表示与推理机制，且层间接口（子任务单元的 Pre/Post/K 三元组）是可靠性关键。

#### 2. 如何处理空间关系

- **前置条件 = 空间关系约束的显式化**：Preᵢ 把"执行这个动作需要世界处于什么空间状态"写成可验证的谓词。这本质上是把隐式的操作常识（倒废液前瓶必须在管下方、拧盖前必须先夹持）形式化，让 VLM 可以逐条核对；
- **验证作为空间关系检查器**：实验发现后置条件验证（72-80%）普遍易于前置条件验证（31-85%）——因为完成状态（盖合上了、管在位）是显式视觉结果，而就绪状态需要推断更细微的空间/状态线索。这个不对称性对任何 Spatial AGI 系统都是重要设计知识：**"能否做"的空间判断比"做没做成"更难**；
- **双臂空间协调**：拧盖与倒废液要求两臂的时空同步与接触稳定——空间关系从"物体间"扩展到"两个效应器之间"，是空间智能的高阶形态（所有方法在双臂任务上成功率骤降：拧盖最好也只有 55%）。

#### 3. 对 Spatial AGI 有什么启发

1. **验证先行是空间智能的可靠性范式**：BioProVLA 把 VLA 从"一次性指令执行器"升级为"可验证、可解释、可中断"的执行循环。这与 GeoAgent 的发现（VLM 确认偏误）互为镜像——GeoAgent 显示探索不能修复错误假设，BioProVLA 则展示显式的 pre/post 校验 + 重试/重排序/人工介入能在系统层面阻断误差传播。对 Spatial AGI：**执行智能的可靠性来自架构（验证闭环），不只来自策略模型**；
2. **领域知识检索增强空间判断**：RAG 使验证准确率提升 9.34 个百分点（73.33%→82.67%）——空间状态判断不是纯感知问题，检索到的操作知识（"正确的插入应该是什么样"）提供判断锚点。Spatial AGI 的感知模块应该接知识库；
3. **视觉退化的课程式适应**：透明/反光物体是空间感知的顽固难点（也是 SpatialBlock 等基准的核心难点之一）。AugSmolVLA 的在线课程增强是一个零额外数据成本的工程化答案，可迁移到任何视觉退化场景（水下、雾天、夜间驾驶）；
4. **低成本具身平台的民主化意义**：800 美元平台 + 100 条示教/任务就能做出有用的湿实验室操作——Spatial AGI 的落地路径未必需要百万级机器人。

#### 4. 可以应用的 Spatial AGI 场景

- **机器人生物/化学实验室**（直接应用）：协议驱动的实验执行；
- **工业质检/装配的验证闭环**：pre/post 校验 + 异常重试模板通用；
- **家庭服务机器人**：多步任务（洗衣流程等）同样需要状态感知执行；
- **视觉退化场景的 VLA 部署**：透明包装分拣、玻璃器皿处理、强反光车间；
- **遥感/勘探等多智能体系统**：Guiding Decision Agent 的调度/重试/人工介入模式可复用。

### Q3: 基于前面的分析，这个方法的主要创新点和局限性是什么？

#### 1. 主要创新点

1. **协议即任务接口**：首个把"自然语言协议直接驱动闭环机器人执行"完整打通的系统（LLM 解析 → 可验证子任务 → VLM-RAG 校验 → VLA 执行），摆脱 ROS 脚本与固定流水线；
2. **子任务三元组表示**：(指令, 前置条件, 完成条件, 知识索引) 的结构化单元是协议语义与机器人执行之间的桥——使每一步都可检查、可解释、可中断；
3. **VLM-RAG 状态验证机制**：把检索增强（操作知识 + 成功/失败参考案例）引入视觉状态校验，+9.34pp 准确率提升；pre/post 双端校验 + 失败时的重排序/二次验证/人工介入三级降级策略；
4. **AugSmolVLA 课程式在线增强**：针对湿实验室视觉退化（透明、镜面反射、光照变化、过曝）的在线扰动 + 课程式三阶段训练，无需离线增强数据集；过曝下 Place Cryotube 31.67%→71.67%；
5. **分层湿实验室操作基准**：15 原子 + 6 组合 + 3 双臂，含正常/过曝两种光照，全部在真实硬件上评测，LeRobot 格式数据可复用。

#### 2. 主要局限性

1. **任务规模与物体多样性有限**：作者自认——原子任务 15 个、物体约 9 种、场景单一实验室；协议长度与复杂度未充分压测；
2. **验证仍不完美**：最好的 RAG-Doubao 也只有 82.67%，前置条件最低的模型只有 30.77%——验证错误的代价在生物实验里可能是污染或样本损失，离安全关键应用有距离；
3. **双臂精细操作仍然薄弱**：最好 55%（拧盖）、36.67%（倒废液），接触力控制与时间同步是开放问题（作者计划引入灵巧手与多模态感知）；
4. **原子动作空间封闭**：动作集 φ(vᵢ,A) 限定了系统能力边界，超出集合的操作（移液、样品混匀）无法解析执行——通用性受限；
5. **评测统计量较小**：SR 仅 3 次重复实验、验证集仅 75 例，置信区间宽；LLM 协议解析的 F1 最高也只有 0.71，说明该环节仍是瓶颈；
6. **系统成本被低估的可能**：硬件 800-850 USD，但 VLM/VLM-RAG/LLM 的 API 调用成本与延迟未报告——闭环校验的每次调用都是开销。

#### 3. 与其他相关工作的对比

|---|---|---|---|---|
| A-Lab / 自驱动实验室 | 固定工作流 | 仪器内建 | 专用仪器 | 昂贵定制 |

**劣势**：每个环节都不是 SOTA（解析 F1 0.71、验证 82.67%、原子任务最好 90%），是系统集成创新而非单点突破。

## 核心技术发现

1. **协议解析能力现状**：五个 LLM 对比（Kimi-K2.6/GLM-5.1/MiniMax-M2.5/DeepSeek-V4-Pro/Qwen3.6-Plus），Qwen3.6-Plus 动作解析最佳（P 0.6777 / R 0.7371 / F1 0.7062）；DeepSeek-V4-Pro 召回最高（0.7784）但精确率低（倾向多生成）；Kimi-K2.6 召回崩塌（0.3608）。前置条件生成 F1 普遍低于动作解析（最高 0.4387）——**"什么条件下能做"比"做什么"更难形式化**。
2. **VLM-RAG 验证**：75 例验证集（39 pre + 36 post）；RAG-Doubao-Seed-2.0-Pro 82.67% 总准确率（比无 RAG +9.34pp）；post 普遍易于 pre（显式视觉结果 vs 细微状态线索）；Qwen3-VL-thinking 仅 38.67%——推理型 VLM 未必适合状态校验任务。
3. **单臂任务**（Table 3 摘选，SmolVLA → AugSmolVLA）：
   - Place Cryotube to Red Rack: 40.00% → **65.00%**（透明小物体精确放置，最大增益）
   - Place Centrifuge Tube to Orange Rack: 43.33% → 53.33%
   - Discard Cryotube: 48.33% → 55.00%
   - Close Centrifuge Lid: 100% 持平；Open Centrifuge Lid: 53.33% → 56.67%
   - ACT 在 Insert Tube 只有 16.67%；X-VLA 整体最弱——模型底座差异显著
4. **组合任务**：AugSmolVLA 的 Clean up waste materials 达 75.00%（超 SmolVLA 12.5pp）；Loading centrifuge tube 组合 39.45%（vs SmolVLA 37.00%）——长流程中误差累积仍然显著。
5. **双臂任务**：Unscrew Tube Cap 55.00%（ACT 11.67%）；Pour Waste Liquid 36.67%（X-VLA 10.00%, ACT 3.33%）——双臂协调对所有方法都是断崖式难点。
6. **过曝消融**（Table 7）：SmolVLA 直接暴露于过曝普遍退化（Loading CR 55.00%→39.60%）；AugSmolVLA 恢复甚至反超（Place Cryotube 31.67%→**71.67%**，超正常光照 SmolVLA）——课程增强的分布覆盖效果显著。

## 关键数据

- **平台**: So-ARM101 双臂，~800-850 USD；每原子任务 100 条遥操作示教，LeRobot 格式；
- **基准**: 15 原子（12 单臂 + 3 双臂）/ 6 组合 / 3 双臂任务 × 正常/过曝光照；
- **LLM 解析**: Qwen3.6-Plus F1 0.7062（动作）/ 0.4387（前置条件）；Kimi-K2.6 召回仅 0.3608；
- **VLM 验证**: RAG-Doubao 82.67%（pre 84.62% / post 80.56%）vs 裸 Doubao 73.33% vs Qwen3-VL-thinking 38.67%；
- **执行增益**: 过曝下 Place Cryotube +40pp（31.67→71.67）；正常光下 +25pp（40→65）；组合 Clean up 75.00%。

## 与 Spatial AGI 的关系

### 直接贡献
展示了"符号空间（协议）→ 关系空间（验证）→ 度量空间（执行）"三层空间智能栈的工程化整合，确立验证闭环作为空间智能体可靠性的架构级方案。

### 技术启发
- pre/post 语义校验 + 重试/重排序/人工介入的降级模板可推广到一切长程空间任务；
- RAG 增强空间状态判断（+9.34pp）提示空间感知应接领域知识库；
- 课程式在线视觉增强是视觉退化场景（透明/反光/过曝）的低成本适应方案。

### 应用场景
湿实验室自动化、协议驱动的工业流程、家庭服务机器人长程任务、视觉退化场景 VLA 部署。

## 个人思考

### 最令人兴奋的发现

RAG 对验证的增益细节最有启发：验证不是"看图说话"，而是"带着操作常识看图"。检索到的成功/失败案例为 VLM 提供了判断锚点（"正确的插入深度长什么样"），这其实是把 **procedural knowledge 注入 perception**——对 Spatial AGI 的启示是，空间理解的瓶颈可能不在感知模型，而在感知模型与领域知识的接口。另一个亮点是前置条件验证普遍难于后置条件验证这个不对称性——它说明"就绪性判断"（一个前瞻性、反事实的空间推理）比"完成性判断"（一个回顾性的视觉匹配）在认知上更难，这与 GeoAgent 中"初始假设决定成败"的发现共同指向：**空间智能的前瞻环节是当前模型的最大短板**。

### 潜在局限

验证闭环的可靠性天花板就是验证器本身——82.67% 的验证准确率意味着每 6 个子任务约有 1 次误判，在长协议中这些误判本身会累积。系统的三级降级策略（重排序/二次验证/人工介入）在论文中只有定性描述，缺少"闭环 vs 开环"的端到端消融（闭环到底把组合任务成功率提高了多少？）——这是评测设计上最大的缺口。另外 LLM 解析 F1 只有 0.71，错误解析会直接污染下游，但论文没有分析解析错误的传播效应。

### 与近期研究的关联

- 与 NavArena/GeoAgent（今日论文 1、4）共同描绘 Spatial AGI 的评测版图：导航执行（米级移动）/ 地理推理（千米级认知）/ 操作执行（厘米级接触）——三者能力几乎不重叠，Geo-R1 的失效与 VLM 验证的薄弱都说明**空间智能是多个正交技能的组合而非单一能力**；
- AugSmolVLA 与 BinauralVAE（论文 2）呼应同一个主题：**用目标化的辅助信号增强表征鲁棒性**（一个用视觉扰动课程，一个用双耳音频重建）；
- 与 UAV 搜索（论文 3）同为"LLM 分解任务 + 底层执行"架构，但 BioProVLA 多了验证闭环——这个差异恰好解释了两者的可靠性定位差异；
- SmolVLA/ACT/X-VLA 的对比延续了 VLA 领域"底座决定上限、增强决定下限"的经验规律。

### 批判性思考

论文的"affordable"叙事需要拆解：800 美元是硬件，但系统依赖三个大模型 API（LLM+VLM+RAG 服务），长期运行成本与延迟未报告；对资源受限实验室而言，API 依赖可能比硬件成本更成问题。其次， SR 的 3 次重复实验偏少， Success Rate 的标准误在 ±1.67-7.27 之间波动，部分任务间差距（如 46.67% vs 50.00%）可能在噪声范围内——AugSmolVLA 的增益在大多数量化放置/丢弃任务上明确，但在开盖类任务上可能并不显著。最后，"协议即接口"的愿景与实际评测之间有落差：评测任务都是预定义的原子组合，真实协议（含"incubate for 30 min"这类时间约束、异常分支、随机化步骤）的解析与执行未被检验。

## 总结

### 核心发现总结

BioProVLA-Agent 在 ~800 美元平台上打通了"自然语言协议 → LLM 结构化解析（指令/前置/完成/知识索引四元组）→ VLM-RAG 执行前后双重校验（82.67%）→ AugSmolVLA 课程增强执行"的全链路闭环，在 15 原子 + 6 组合 + 3 双臂任务的湿实验室基准上，于透明耗材、反光、过曝等视觉退化场景取得明确增益（过曝下最高 +40pp），并系统量化了协议解析（F1≤0.71）、状态验证（38-83%）、单臂执行（17-100%）、双臂协调（≤55%）各环节的能力现状。

### 对 Spatial AGI 的意义

这篇论文是 Spatial AGI "系统派"的代表：它不追求单点模型 SOTA，而是用**架构（验证闭环、检索增强、课程增强、三级降级）**把不完美的组件组合成可用的系统。对 Spatial AGI 的核心信息是：可靠性不来自更强的策略模型，而来自**执行前后的语义校验结构**与**失败时的智能降级**——这与 GeoAgent 揭示的"模型自身纠错能力缺失"互为补充：既然模型不会自我修正，就给它们搭一个会修正的脚手架。

## 深度扩展分析

### 扩展一：三层空间智能栈的抽象

BioProVLA-Agent 的架构可以被抽象为一个通用的空间智能栈：

```
┌─────────────────────────────────────────────┐
│ 符号空间层（协议/任务）                        │
│  输入: 自然语言任务描述                        │
│  表示: 子任务四元组 (I, Pre, Post, K)          │
│  引擎: LLM + 封闭动作空间约束                  │
│  失败模式: 解析错误 → 下游污染 (F1≈0.71)       │
├─────────────────────────────────────────────┤
│ 关系空间层（状态验证）                         │
│  输入: 视觉观察 + 机器人状态 + 检索知识         │
│  表示: 空间关系谓词的真值判定                   │
│  引擎: VLM + RAG（操作知识+成败案例）           │
│  失败模式: pre 判断难于 post（前瞻>回顾）       │
├─────────────────────────────────────────────┤
│ 度量空间层（连续执行）                         │
│  输入: 观察 + 指令                            │
│  表示: 7-DoF 动作序列（horizon H）             │
│  引擎: VLA（AugSmolVLA 课程增强）              │
│  失败模式: 视觉退化 → 定位漂移                  │
└─────────────────────────────────────────────┘
          ↑ 层间接口 = 可靠性关键
   Guiding Decision Agent 负责跨层调度与降级
```

这个栈的通用性值得强调：把"协议"换成"导航指令"、"验证"换成"场景充分性检查"、"执行"换成"底盘控制"，就得到一个移动机器人版本；换成"检修手册"/"部件就位检查"/"螺栓紧固"就得到工业版本。**Spatial AGI 的系统模板正在收敛**。

### 扩展二：验证闭环 vs 模型自纠错

把今天 GeoAgent 与本文的发现并置，得到一个互补的可靠性图景：

| | GeoAgent 发现 | BioProVLA 方案 |
|---|---|---|
| 模型自纠错 | 确认偏误，错误假设不可恢复 | —（未依赖模型自纠错） |
| 外部验证 | 无（模型自己决定 GUESS） | VLM-RAG pre/post 双端校验 |
| 失败处理 | 无限预算反而强化偏误 | 重试/重排序/人工介入三级降级 |
| 结论 | 模型内部纠错失效 | 用架构外部化纠错 |

组合起来的设计原则：**不要指望空间智能体"想明白"，要让它"被检查"**。每一次不可逆动作（物理操作、最终猜测）之前都应该有一个独立的、知识增强的验证器把关，验证失败时的默认行为是降级而非坚持。

遗留问题：验证器本身的错误率（17.33%）如何处理？理论上可以级联验证（多验证器投票），但成本翻倍。实践中一个可行的折中是**风险分级验证**：不可逆/危险操作（倒废液、拧盖）用双重验证，可逆操作（放置）用单次验证。

### 扩展三：AugSmolVLA 增益的机制分析

课程式在线增强为什么有效？三个机制假说：

1. **分布覆盖扩展**：透明物体的视觉外观强烈依赖光照（背景透过率、镜面高光位置），原始示教数据只覆盖采集时刻的光照分布；在线扰动以零存储成本采样了更宽的分布；
2. **课程学习防止灾难遗忘**：直接混合强扰动会破坏基础动作映射的学习（扰动太强的样本梯度过大）；𝓔₁→𝓔₂→𝓔₃ 的顺序让模型先建立稳定的本体表征，再逐步外推；
3. **隐式的不变性正则**：同一动作在不同扰动下的配对训练相当于约束策略对光照不变——类似对比学习的效果但无需负样本。

证据支持：增益最大的任务恰是"透明小物体精确放置"（+25pp）与"过曝恢复"（+40pp），而对光照不敏感的合盖任务（已 100%）无增益——与分布覆盖假说一致。

可迁移场景：水下机器人（浑浊/色偏）、夜间驾驶（低照/眩光）、温室农业（直射阳光/阴影）、玻璃幕墙建筑检测。凡是"视觉外观 = f(物体, 光照)"且光照不可控的领域都适用。

## 附录 H：结果读数的三点提醒

1. **验证器错误≠系统安全**：82.67% 验证准确率意味着闭环的可靠性上限被验证器封顶；论文未报告验证器在系统级（而非孤立样本级）的错误率，真实长协议中的累积误判可能更严重。
2. **SR 的重复次数少**：3 次重复的 SE 在部分任务间差异（如 46.67% vs 50.00%）不足以区分——读 Table 3 时应关注大差距（>10pp）的增益，小差距视为噪声。
3. **双臂任务的对比基线弱**：ACT 3.33%、X-VLA 10.00% 的废液倾倒成绩说明这些方法根本没学会该任务——AugSmolVLA 的 36.67% 是"矮子里的将军"，绝对水平仍不可用。

## 附录 I：跨尺度空间智能缺陷的统一视角（综合讨论）

将 2026-09-13 五篇论文的发现压缩到一个统一框架中：

```
空间智能任务 = 感知(不确定) → 表征 → 推理/假设 → 决策 → 行动(不可逆)
                    ↑_______________反馈_______________|
```

| 阶段 | NavArena | BinauralVAE | UAV搜索 | GeoAgent | BioProVLA |
|---|---|---|---|---|---|
| 感知 | 3DGS 伪影 | 音频稀疏 | 遥感图像 | 街景视口 | 透明/反光 |
| 表征 | 场景重建 | 空间音频潜变量 | 语义图 | 地理假设 | (I,Pre,Post,K) |

| 决策 | 终止判据 | — | 任务规划 | 探索策略✗ | 三级降级✓ |
| 行动 | 导航执行 | — | 飞行轨迹 | 网页工具 | 机械臂控制 |
| 反馈 | — | — | — | 无✗ | 闭环验证✓ |

三个跨论文共性缺陷：
1. **前向推理弱于后向匹配**（GeoAgent 假设固化 + BioProVLA 前置条件 F1 0.44 + UAV 规划受限）；
2. **感知退化下的鲁棒性靠数据不靠架构**（NavArena 3DGS 伪影、BioProVLA 过曝 +40pp 增强、BinauralVAE 数据稀疏）；

→ Spatial AGI 的研究议程：把"反馈闭环 + 前向假设管理 + 扰动鲁棒表征"作为三个一等公民组件，而非事后的工程补丁。
