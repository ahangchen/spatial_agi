## 论文摘要

Vision-Language-Action (VLA) 模型是具身策略的主流范式。它们擅长高效闭环控制，但不显式建模物理场景如何随任务展开而演变。新兴的世界-动作模型 (WAMs) 利用预训练视频世界模型捕获时空演变，但在控制循环中保留未来生成或大型视频骨干会大幅增加推理成本。本文引入 World Tokens，一个围绕 World Adapter 构建的具身策略架构，桥接视觉语言理解、世界动态建模和动作生成。它利用世界建模在训练期间增强动作策略，同时保持高效部署。具体来说，World Adapter 将 VLM 特征转换为固定数量的 world tokens，这些 tokens 同时条件化联合微调的未来视频去噪器并作为动作专家唯一的视觉-语言上下文。在部署时，世界模型分支被移除，只保留 VLM、World Adapter 和动作专家。以 2B 骨干且无 embodied 动作预训练，World Tokens 在 LIBERO 上高度竞争，在 SIMPLER 上达到最佳报告平均值，在真实 R1 Pro 上显著改进。

## 核心问题分析

### Q1: 核心算法原理

#### 1. 核心思想和动机

World Tokens 解决的是一个核心矛盾：**世界建模可以提升策略性能，但保留世界模型在推理时太贵**。

具体背景：
- VLA 策略擅长高效闭环控制，但缺乏对场景动态演变的显式建模
- WAMs 通过预训练视频世界模型捕获时空演变，但在控制循环中保留视频生成或大型视频骨干增加了大量推理成本
- 之前的工作（如 Fast-WAM）虽然减少了推理开销，但仍保留了视频 DiT 作为编码器

核心问题：**如何让世界建模的收益在训练时获得，而在推理时完全不需要运行世界模型？**

#### 2. 主要技术方法

**核心创新：World Adapter**

World Adapter 是一个 Perceiver Resampler 风格的模块，将变长的 VLM 特征映射为固定数量的 world tokens：

```
h_t = f_φ(o_t, ℓ)          # VLM 编码
q_t = b_ψ(h_t) ∈ R^{K×d}   # World Adapter 映射
```

其中 K 是 world tokens 数量（论文中使用 256）。

World tokens 有两个关键约束：

**约束1：动作专家的唯一视觉-语言上下文**
- 动作专家不直接访问完整 VLM 序列
- 所有视觉和语言信息必须通过 world tokens 传递
- 这是一种"exclusive routing"——防止策略绕过被世界模型监督的表示

**约束2：视频世界模型的条件化**
- 同一组 world tokens 也条件化未来视频去噪器
- 视频去噪的梯度直接塑造 world tokens 的表示
- 这确保 tokens 携带足够的信息来预测场景演变

**结构锚点（Structural Anchor）**

一个巧妙的设计：视频分支不使用完整 RGB 第一帧，而是使用 Canny 边缘图：

```
c_t = E(Canny(o_t^1))
```

这保留了场景布局的空间结构，但抑制了颜色和纹理线索。迫使 world tokens 必须携带丰富的视觉-语义内容来指导世界模型。

**训练架构（双分支）**

1. **动作分支**：world tokens → 流匹配动作专家 → 生成动作块
   ```
   L_act = L_den(g_θ; a_t^H | q_t)
   ```

2. **视频分支**：world tokens + Canny锚点 → 视频去噪器 → 生成未来视频
   ```
   L_vid = L_den(W_ω; z_t | q_t^wm, c_t)
   ```

3. **联合训练**：
   ```
   L = L_act + λ_w * L_vid,  λ_w = 0.5
   ```

**部署架构**

推理时移除：
- 视频VAE编码器 E
- 世界模型投影 p_ρ  
- 视频去噪器 W_ω
- 结构锚点生成
- 未来目标 v_t

仅保留：
- VLM f_φ
- World Adapter b_ψ
- 动作专家 g_θ

推理延迟接近标准 VLA！

#### 3. 算法流程

**训练流程**：
1. VLM 编码多视角观测和语言 → 变长特征序列 h_t
2. World Adapter 将 h_t 映射为 256 个 world tokens q_t
3. **并行路径A**：q_t → 动作专家 → 生成动作块（流匹配）
4. **并行路径B**：q_t → 视频去噪器 + Canny锚点 → 生成未来视频
5. 两个路径的梯度在 q_t 处汇合，共同优化 World Adapter

**推理流程**：
1. VLM 编码观测和语言 → h_t
2. World Adapter 生成 256 个 world tokens q_t
3. 动作专家根据 q_t 生成动作块

#### 4. 输入输出

- **训练输入**：多视角 RGB、语言指令、未来 RGB 视频片段
- **推理输入**：多视角 RGB、语言指令
- **输出**：连续动作序列（action chunk）

### Q2: 与Spatial AGI的关系

#### 1. 如何理解和表示空间

World Tokens 通过一种独特的方式编码空间信息：

- **间接空间编码**：World tokens 不是直接的空间坐标或几何表示，而是被"压缩"后的视觉-语言-空间信息。World Adapter 通过 Perceiver Resampler 机制，学会保留对动作控制和场景动态预测最重要的信息。

- **场景布局的结构化表示**：Canny 边缘锚点提供了场景的布局骨架——物体边界、空间结构、深度线索——而将外观细节留给 world tokens。这种分离类似于 Spatial AGI 中的"结构 vs 外观"分解。

- **时空演变建模**：视频去噪器隐式地建模了场景如何在时间中演变——物体如何移动、接触如何发生、遮挡如何变化。

#### 2. 如何处理空间关系

- **exclusive routing 强制空间信息压缩**：动作专家只能通过 256 个 tokens 获取所有视觉-语言信息，这迫使 World Adapter 学会高效地编码空间关系。

- **外观抑制的空间锚定**：Canny 锚点只保留空间布局，抑制外观。这让 world tokens 必须编码语义和动态信息，而非依赖外观匹配。

- **预测性空间监督**：视频去噪的梯度确保 world tokens 包含足够的空间信息来预测场景如何演变。

#### 3. 对Spatial AGI的启发

- **训练-推理解耦**：World Tokens 展示了一个重要的 Spatial AGI 设计原则——复杂的空间推理可以在训练时进行（通过世界模型），而推理时只保留高效的策略网络。

- **信息瓶颈设计**：通过限制为 256 个 tokens，World Adapter 被迫学习高效的空间信息编码。这种"瓶颈"设计可能是 Spatial AGI 中高效表示学习的关键。

- **结构-外观分离**：Canny 边缘 + world tokens 的组合实现了结构（边缘）和外观/语义（tokens）的分离，这是一种优雅的空间信息分解。

#### 4. 可以应用的Spatial AGI场景

- 高效机器人操作系统（VLA级延迟）
- 训练时增强、推理时精简的通用框架
- 空间信息压缩和编码
- 视频预测与动作控制的联合学习

### Q3: 创新点和局限性

#### 1. 主要创新点

- **完全移除推理时的世界模型**：与 Fast-WAM（保留视频 DiT 作为编码器）不同，World Tokens 在推理时完全移除视频分支，真正实现了"训练时增强，推理时精简"。

- **Exclusive routing 设计**：动作专家只能通过 world tokens 获取信息，防止策略绕过被监督的表示。这是一个巧妙的架构约束。

- **Canny 锚点**：用边缘图替代 RGB 作为视频模型的第一帧条件，抑制外观、保留结构。这迫使 world tokens 承担更多的视觉-语义责任。

- **Perceiver Resampler 桥接**：用固定数量的 learnable queries 将变长 VLM 序列映射为紧凑表示，同时服务于控制和预测。

#### 2. 主要局限性

- **视频模型依赖**：训练时需要预训练的视频世界模型，质量直接影响 world tokens 的学习。

- **固定 token 数量**：256 个 tokens 对所有场景可能不是最优——简单场景太多，复杂场景太少。

- **Canny 边缘的信息损失**：虽然保留了空间布局，但在低纹理或复杂场景中，边缘图可能不足以提供可靠的锚定。

- **视频训练的计算开销**：虽然推理时不需要视频模型，但训练时的视频去噪计算量很大。

- **token 解释性有限**：world tokens 的具体语义不明确——它们编码了什么空间信息？

#### 3. 与相关工作的对比

| 方法 | 训练时WM | 推理时WM | 信息瓶颈 | 空间锚定 |
|------|---------|---------|---------|---------|
| **World Tokens** | ✅ 视频去噪 | ❌ 完全移除 | ✅ 256 tokens | ✅ Canny |
| Fast-WAM | ✅ | ✅ 保留DiT | ❌ | ❌ |
| DreamVLA | ✅ | 部分 | ❌ | ❌ |
| GWM-VLA | ✅ VGGT-Ω | ❌ (仅VGGT) | ❌ | ✅ VGGT |
| SLIM | ✅ JEPA | ❌ | ❌ | ❌ |

## 核心技术发现

### 发现1：Exclusive Routing 是关键

论文的核心洞察之一：如果动作专家可以同时访问完整 VLM 序列和 world tokens，它可能学会忽略后者。通过 exclusive routing，模型被迫通过 world tokens 进行所有视觉-语言推理，确保世界模型的监督真正塑造了策略使用的表示。

### 发现2：外观抑制促进语义编码

将视频模型的第一帧从 RGB 换成 Canny 边缘图，是一个简单但有效的设计。它防止了视频模型依赖外观持续性（appearance persistence），迫使 world tokens 携带丰富的语义和动态信息。

### 发现3：256 tokens 的效率

仅用 256 个 tokens 表示完整的场景理解+任务语义+动作条件，证明了信息压缩的巨大潜力。相比之下，标准 VLA 的 VLM 序列可能有数千个 tokens。

## 与Spatial AGI的关系

### 直接贡献

1. **训练-推理非对称设计**：为 Spatial AGI 系统提供了一种实用范式——可以在训练时使用昂贵的空间推理，在推理时保持高效。

2. **信息瓶颈驱动的空间表示**：通过瓶颈设计学习高效的空间信息编码，这是 Spatial AGI 系统效率化的关键方向。

3. **结构-外观分离**：Canny + tokens 的组合提供了一种简单有效的空间信息分解方法。

### 技术启发

- **表示压缩**：Spatial AGI 不需要传输所有空间信息，关键是找到高效的压缩表示
- **多目标联合训练**：动作生成和视频预测共享表示，互相增强
- **部署效率**：真正的 Spatial AGI 系统需要在实际设备上运行，训练-推理解耦是必要的

### 应用场景

- 机器人操作系统（需要在边缘设备上实时运行）
- AR/VR 空间理解（训练时用大模型，部署时用轻量模型）
- 自动驾驶系统（训练时用世界模型，推理时只用策略）
- 任何计算资源受限的 Spatial AGI 场景

## 个人思考

### 最令人兴奋的发现

World Tokens 的核心设计哲学——**"让世界模型在训练时塑造表示，推理时完全消失"**——是一个非常优雅的解决方案。它解决了困扰 WAM 领域的核心问题：如何获得世界建模的收益而不付出推理代价。

更深层地说，这个方法暗示了一个重要观点：**表示才是关键，而非生成**。World Tokens 不需要生成高质量视频，它只需要让 world tokens 携带足够的空间和动态信息来指导动作。视频去噪只是达到这个目的的手段。

### 潜在局限

256 个固定 tokens 是否足以表示所有复杂的空间场景？在高度杂乱的场景中（如多物体操作、精细装配），信息瓶颈可能太紧。未来可能需要自适应 token 数量。

另一个问题：Canny 边缘是否是最优的结构锚定？其他替代（如深度图、法线图、语义分割）可能携带更多空间信息。

### 与近期研究的关联

World Tokens 与同一天发布的 JEPA-WAM、SLIM 以及此前的 GWM-VLA 形成了有趣的对比：
- **World Tokens**：训练时用视频WM，推理时移除 → 中等复杂度
- **JEPA-WAM**：用 V-JEPA 潜在空间 + 共享预测器 → 低推理开销
- **SLIM**：完全自监督的掩码预测 → 最低参数量
- **GWM-VLA**：用 VGGT 几何感知 → 最强几何先验

这四篇论文代表了"如何高效地将世界建模注入VLA"这一核心问题的四种不同解法，共同推动了 Spatial AGI 的前沿。

## 总结

### 核心发现总结

World Tokens 提出了一个优雅的训练-推理解耦框架：通过 World Adapter 将 VLM 特征压缩为 256 个 world tokens，训练时用视频世界模型和动作专家联合优化，推理时完全移除世界模型。这种设计在保持 VLA 级推理延迟的同时，获得了世界建模带来的性能提升。

### 对Spatial AGI的意义

World Tokens 为 Spatial AGI 的工程化提供了关键洞察：高效的空间智能系统不一定需要在运行时执行复杂的空间推理。通过精心设计的训练流程，可以将世界模型的空间理解能力"蒸馏"到紧凑的表示中，实现高效部署。这是 Spatial AGI 从研究走向实际应用的重要一步。
