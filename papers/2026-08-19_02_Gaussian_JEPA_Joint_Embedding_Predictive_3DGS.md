## 论文一句话总结

Gaussian-JEPA 首次将 JEPA（联合嵌入预测学习）范式引入 3D Gaussian Splatting 资产的自监督预训练：在线编码器从可见上下文预测被遮蔽高斯 token 块的潜在表示（由共享 EMA 编码器提供 stop-gradient 目标），配合多尺度目标块、几何/外观双互补目标空间和特征空间 grounding 正则，无需解码原始高斯属性，学到的特征在重采样一致性、部分观测检索、可渲染补全和语义迁移上全面超过匹配的重建式预训练（Gaussian-MAE）。

## 核心问题

### Q1: 核心算法原理

**问题**: 这篇文章的核心算法原理是什么？

**分析**:

#### 1. 核心思想和动机

- **问题背景**：3DGS 正在成为学习型场景理解的"原生输入"（scene understanding 的输入直接是高斯而非图像）。但要获得可复用的 3DGS 特征，需要自监督预训练。
- **表示特有的困难**：实际编码器有固定输入预算（如 1K 个高斯），而一个资产可能有 34.3K 个高斯。同一个物体经独立固定预算重采样会得到**不同的高斯实现**——物体没变，但原语级观测变了。这种"实现方差"不是设计出来的数据增强，而是密集资产与固定预算编码器接口处的固有噪声。
- **现有方法的缺陷**：
  - **Gaussian-MAE（重建式）**：重建被遮蔽高斯的质心和属性，需要输入空间解码器处理异构属性（位置/不透明度/尺度/旋转/球谐），且监督信号绑定在"某一个采样实现"上——模型被迫记住这次采样的具体原语，而非物体的可预测结构；
  - **对比学习**：不变性依赖挑选的视图和增强，全局一致性不显式监督缺失的空间内容。
- **核心主张**：预测"可预测的物体结构"的表示，而不是"某个采样的精确属性"。这正是 JEPA 原则（LeCun 系）：在表示空间预测，不做原始输入解码，不需要负样本对。

#### 2. 主要技术方法

**(a) 高斯 token 化（沿用 Gaussian-MAE 的设计）**

物体表示为 X = [C, O, S, R, SH] ∈ R^(N×14)：质心、不透明度、尺度、旋转四元数、DC 球谐系数。

从 p=1024 个采样高斯出发：
- FPS（最远点采样）选 n=64 个组中心；
- 每个中心 KNN(k=32) 聚邻域，保留 14 维属性，质心相对化；
- PointNet 风格 tokenizer ψ 产生 token T ∈ R^(64×384)；MLP ρ 嵌入中心作为位置特征。

**(b) 多尺度目标块采样（heterogeneous targets）**

等尺寸目标块只暴露单一粒度。论文设计递减尺度表 s = [s1 ≥ ... ≥ sM]，默认 M=4、s=[11,9,7,5]，总目标预算 n_t=32（64 个 token 中 32 个为目标、32 个为上下文）。顺序采样保证块互不相交：

```
a_m ~ Unif(A_{m-1})                    # 随机选种子
B_m = NN_{s_m}(u_{a_m}, U_{A_{m-1}})   # 最近邻扩块
A_m = A_{m-1} \ B_m                     # 移除，保证不相交
C = A_M                                 # 剩余为共享上下文
```

固定 n_t 使"目标粒度"与"mask 比例"解耦——不同块覆盖不同空间支撑（细粒度局部 vs 粗粒度整体）。

**(c) 非对称编码（online + EMA）**

- 在线编码器 f_θ 只编码共享上下文（一次）：Z_C = f_θ(T_C, ρ(U_C))；
- 共享 EMA 编码器 f_ξ 对每个目标块处理**完整 token 场**，再按块索引选取目标特征：Z_m^ξ = f_ξ(T, ρ(U))[B_m]；
- f_ξ 不接收梯度，参数按 EMA 跟随 f_θ；完整场编码使每个目标特征天然带物体级上下文；在线分支既看不到目标 token 内容也看不到目标中心索引（除位置）。

**(d) 目标条件化预测**

- 上下文特征投影到预测器宽度：Z'_C = W_p Z_C；
- 可学习查询 q 对每个目标 token 复制：Q_m = 1_{s_m} q^T；
- Transformer 预测器 h_φ 以 [Z'_C; Q_m] 为查询、[ρ_φ(U_C); ρ_φ(U_{B_m})] 为位置，输出查询侧特征 V_m；
- 两个线性头 r_b 输出预测：Ẑ_m^b = r_b(V_m)，b ∈ {geo, app}；
- **预测器知道目标的位置但不知道内容**——这是 JEPA 式"预测缺失"的关键。

**(e) 互补目标空间 + 特征空间 grounding**

- 两个独立参数化 MLP 投影器 g_geo / g_app 将 EMA 特征映射到互补潜在空间：Y_m^b = g_b(Z_m^ξ)，目标 Z_m^b = LN(sg(Y_m^b))；
- geo/app 是"学习到的目标空间"而非硬属性拆分——两个投影器都消费全部高斯属性的特征；
- 损失：
  - L_pred = (1/M) Σ_m Σ_b SmoothL1(Ẑ_m^b, Z_m^b)（块级、双空间对齐）；
  - L_ground：因 Y^b 在构成目标前被 detach，L_pred 训不到投影器 g_b，故借鉴 VISReg 正则特征均值/尺度并用随机一维投影匹配高斯参考（防坍缩），并额外惩罚两空间跨协方差 Γ = (1/L_t)(Ỹ^geo)^T Ỹ^app， discouraging 冗余线性因子——保证 geo/app 真正互补。

#### 3. 算法流程（一次训练迭代）

1. 资产 X → 随机固定预算采样 X'（1024 高斯）；
2. FPS+KNN token 化 → 64 tokens；
3. 多尺度块采样 → 4 个目标块（32 token）+ 上下文（32 token）；
4. 在线编码器编码上下文 → Z_C；
5. EMA 编码器编码完整场 → 按 4 组块索引取目标特征；
6. 预测器从上下文 + 目标位置预测 4×2 个潜在目标；
7. L_pred 对齐 + L_ground 正则投影器；
8. 梯度更新 f_θ/预测器/头；f_ξ ← EMA(f_θ)。

#### 4. 输入输出

- **输入**：物体级 3DGS 资产（N×14 属性，N 可远大于编码器预算）；
- **输出**：预训练的冻结编码器 + tokenizer，可迁移到部件分割、物体分类、部分观测检索、可渲染高斯补全。

**评估结论**：与匹配重建式预训练（Gaussian-MAE）相比——
1. 独立重采样下特征更一致；
2. 部分观测下保留更多实例信息（检索更强）；
3. 冻结特征支持更强的高斯补全（同一解码器训练）；
4. 部件分割与分类验证语义迁移。

### Q2: 与 Spatial AGI 的关系

**问题**: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**分析**:

#### 1. 如何理解和表示空间

- 空间被表示为**"可预测结构的潜在空间"**而非"可重建属性的输入空间"。这是对"空间理解 = 重建"这一默认假设的挑战：Spatial AGI 需要的不是逐点重建世界，而是抓住世界的可预测结构（物体形状的规律、部件间几何关系、外观分布）。
- 高斯 token 同时耦合几何（各向异性支撑）、可见性（不透明度）与外观（球谐）——比点云更丰富的空间原语。Gaussian-JEPA 是第一个为这种"富原语"设计的 JEPA。

#### 2. 如何处理空间关系

- **多尺度块 = 多尺度空间关系课程**：[11,9,7,5] 的块尺寸让模型同时练习"补全大块缺失区域"（全局结构推理）与"补全小块细节"（局部连续性推理）；
- **上下文→目标预测即空间关系推理**：预测一个块的特征需要理解它与周围块的空间关系（位置编码 ρ_φ 绑定查询到目标中心）；
- **geo/app 双空间解耦**：隐式分离"这个物体在哪里/什么形状"与"它看起来什么样"，这是空间认知中几何与外观的软分工。

#### 3. 对 Spatial AGI 的启发

- **3DGS 原生预训练的起点**：当 3DGS 成为机器人/场景理解的输入格式（如 GaussMemory、LaGSplat），直接在"高斯资产"上预训练的 backbone 比经由图像/点云绕道更高效。Gaussian-JEPA 填补了"3DGS 界的 Point-MAE→Point-JEPA 演化"的空白；
- **实现方差鲁棒性**：重采样不变性对 Spatial AGI 至关重要——同一空间在不同传感器/帧率/密度下产生不同高斯实现，特征必须跨实现一致；
- **部分观测 = Spatial AGI 常态**：机器人永远只看到物体/场景的一部分，Gaussian-JEPA 的部分观测检索与补全能力直接对应"从看到的一面推断整体"的空间推理；
- **与 JEPA-WAM（昨日论文4）呼应**：JEPA-WAM 在视频+动作上做世界动作模型的联合嵌入预测，Gaussian-JEPA 在静态高斯资产上做结构预测——两者共同指向"联合嵌入预测作为空间智能统一学习目标"的趋势。

#### 4. 可以应用的 Spatial AGI 场景

- 机器人感知 backbone：从实时 3DGS 重建中提取物体/部件特征供 VLA 消费；
- 场景检索与重定位：部分观测查询匹配完整资产（"我看到的这个角属于哪个物体"）；
- 3D 内容生成/编辑：冻结特征引导高斯补全与编辑；
- 与 GaussMemory 组合：高斯记忆条目的 h_i 特征可用 Gaussian-JEPA 编码器初始化，提升物体重识别；
- 数字孪生资产库的语义索引。

### Q3: 创新点和局限性

**问题**: 基于前面的分析，这个方法的主要创新点和局限性是什么？

**分析**:

#### 1. 主要创新点

1. **首个 3DGS 的 JEPA**：将联合嵌入预测从点云（Point-JEPA/3D-JEPA）迁移到耦合几何+外观+可见性的高斯原语，解决"异构属性、非均匀空间支撑"带来的目标构造难题；
2. **多尺度非重叠目标块**：固定目标预算 n_t 与 mask 比例解耦，递减尺度表提供异质空间支撑的目标；
3. **互补双目标空间 + 跨协方差惩罚**：geo/app 学习空间而非硬拆分，Γ 惩罚保证互补性，防止两个投影器学到冗余线性因子；
4. **特征空间 grounding 替代解码器**：VISReg 式正则 + stop-gradient 目标，完全无输入空间解码器、无原始属性损失；
5. **面向表示问题的评估协议**：不只测分类，而是测重采样一致性、部分观测检索、可渲染补全——评估本身是贡献。

#### 2. 主要局限性

- **物体级资产设定**：作者自陈聚焦 object-level（受控环境），场景级（稀疏、无界、动态）未验证——场景高斯的密度分布、背景噪声与物体资产差异巨大；
- **静态表示**：无时间维度，动态 4D 高斯（运动、形变）未覆盖；
- **无语言/多模态对齐**：纯 3DGS-only 路线，与 CLIP 式语言空间无接口；迁移到开放词汇任务需要额外对齐（对比 GaussianVLM 等语言监督路线）；
- **tokenizer 上限**：64 token 的 FPS+KNN 分组对超精细物体（多尺度细节丰富的有机形状）可能丢信息；
- **计算开销**：每个目标块需 EMA 编码器跑完整场（M 次完整前向共享参数但序列不同），训练成本高于单次 MAE；
- **泛化证据有限**：与匹配重建基线对比充分，但与对比学习基线、多模态蒸馏基线的对比不足。

#### 3. 与相关工作的对比

| 方法 | 范式 | 输入空间解码 | 目标 | 原语 |
|------|------|------------|------|------|
| Point-MAE / Point-BERT | 掩码重建 | ✓ | 原始坐标 | 点 |
| Gaussian-MAE | 掩码重建 | ✓（异构属性解码）| 采样实现的属性 | 高斯(14维) |
| CrossPoint 等对比 | 对比 | ✗ | 全局一致性（增强依赖）| 点 |
| Point-JEPA / 3D-JEPA | 潜在预测 | ✗ | 点块表示 | 点 |
| **Gaussian-JEPA** | **潜在预测** | **✗** | **多尺度高斯块双空间表示** | **高斯(几何+外观)** |

优势：免解码器、跨实现一致、部分观测鲁棒、补全友好；劣势：暂限于物体级静态资产，无语言接口。

## 核心技术发现

1. 潜在预测目标在"重采样方差"下天然优于重建目标——重建迫使模型记忆采样实现，潜在预测只要求结构可预测性；
2. EMA 编码完整场再索引取目标，使目标特征带全局上下文（对比 MAE 中被遮蔽位置的孤立即编码）；
3. 固定 n_t + 递减尺度表 = 目标粒度课程，单一 mask 比例下的多粒度学习；
4. 跨协方差惩罚 Γ 是让双空间真正互补的廉价有效手段；
5. VISReg 式特征 grounding 可完全替代解码器防坍缩。

## 与 Spatial AGI 的关系

### 直接贡献
提供 3DGS 原生的自监督 backbone 预训练方案，是"3DGS 作为空间智能通用底座"技术栈缺失的一环（此前有渲染、有分割、有 QA，缺预训练目标函数）。

### 技术启发
- 预测式学习目标可推广到 4D 高斯（预测时空块）、场景级高斯（预测房间区域块）；
- "实现方差"概念提示所有基于高斯输入的系统都应做重采样鲁棒性测试；
- geo/app 双空间与 VLA 的几何/外观双流设计天然对齐。

### 应用场景
VLA 感知前端、部分观测重定位、高斯补全、资产语义索引、与空间记忆系统组合。

## 个人思考

### 最令人兴奋的发现
"同一个物体、不同高斯实现"这一观察精准命中了 3DGS 作为学习输入的根本性噪声源——此前几乎无人正视。把"实现方差"转化为评估协议（重采样一致性测试）本身就是对领域的方法论贡献。JEPA 迁移到高斯原语的成功也再次印证 LeCun 的预判：预测式潜在学习是通向空间智能的通用路径，无关具体模态。

### 潜在局限
最遗憾的缺席是**动态性与交互性**。Spatial AGI 的高斯输入来自交互过程（机器人边动边重建），分布与静态资产库（Objaverse 式）差异极大。下一个自然的步骤是"4D-JEPA"：预测时空高斯块 + 动作条件化（看到动作预测高斯变化），那就是高斯版的世界模型预训练。另外 64 token 的瓶颈与 32K 高斯记忆（GaussMemory）之间的粒度鸿沟需要桥接层。

### 与昨日研究的关联
- 昨日 **JEPA-WAM**：世界动作模型的联合嵌入预测（视频+动作）↔ 本文静态高斯的结构联合嵌入预测——JEPA 家族正在多模态全面开花，今日思考中将梳理"JEPA for Spatial AGI"的版图；
- 昨日 **Embodied Multimodal Grounding（语义 3DGS）**：接地需要好的高斯特征，Gaussian-JEPA 恰好提供自监督获得它们的方法；
- 昨日 **Chain of Spatial Thoughts**：空间 token 推理的质量取决于空间 token 的表征质量——Gaussian-JEPA 是更底层的"token 质量供应商"。

## 关键数据

- token 化：p=1024 采样高斯 → n=64 组（FPS）× k=32 邻域（KNN）→ D=384
- 目标调度：M=4，s=[11,9,7,5]，n_t=32（mask 比例 50% 但粒度异质）
- 目标空间：geo/app 双 MLP 投影器 + LayerNorm + stop-gradient
- 损失：SmoothL1 块级预测 + VISReg grounding + 跨协方差惩罚
- 编码器：online f_θ + EMA f_ξ（共享，完整场编码）
- 基线：Gaussian-MAE（匹配重建式）
- 任务：重采样一致性 / 部分观测检索 / 可渲染补全 / 部件分割 / 物体分类

## 总结

### 核心发现总结
Gaussian-JEPA 用多尺度潜在块预测 + 互补目标空间 + 特征 grounding，为 3DGS 建立了第一个免解码器的自监督预训练范式，在实现方差、部分观测、补全三类 Spatial AGI 关键能力上超越重建式基线。

### 对 Spatial AGI 的意义
3DGS 正在成为空间智能的通用世界表示；Gaussian-JEPA 补上了"表示学习目标函数"这块拼图。当高斯记忆（GaussMemory）、高斯物理仿真（LaGSplat）、高斯世界模型都能共享同一个预训练 backbone 时，Spatial AGI 的技术栈才真正闭环。下一步：4D/动作条件化/场景级扩展。

## 附录A：逐公式精读笔记

### A.1 高斯属性的 14 维构成

| 属性 | 维度 | 空间角色 |
|------|------|----------|
| C 质心 | 3 | 位置 |
| O 不透明度 | 1 | 可见性/存在性 |
| S 尺度 | 3 | 各向异性大小 |
| R 旋转四元数 | 4 | 朝向 |
| SH (DC) | 3 | 基础外观颜色 |
| 合计 | 14 | 几何+可见性+外观耦合 |

关键点：这 14 维是异构的（不同量纲、不同分布），这正是重建式方法解码困难的根源，也是本文转向潜在空间的直接动机。

### A.2 多尺度块采样的算法性质

- **不相交性证明**：A_m = A_{m−1} \ B_m 的顺序删除构造保证 B_i ∩ B_j = ∅；
- **上下文互补性**：C = A_M 是所有目标块的严格补集，无泄漏；
- **预算可调性**：固定 n_t = Σ s_m，改变 s 的分布可以调整"粒度课程"而不影响 mask 比例——例如 [16,8,4,4] 更偏粗粒度，[8,8,8,8] 均匀。论文默认 [11,9,7,5] 是递减的温和课程。

### A.3 非对称编码的信息流

```
        完整 token 场 T (64 tokens)
              │
      ┌───────┴────────┐
      ▼                ▼
  上下文 C (32)     EMA f_ξ（无梯度）
      │                │ H^ξ (64×D)
  online f_θ           │ 按块索引选取
      │ Z_C            ▼
      ▼          Z^ξ_m = H^ξ[B_m], m=1..4
  W_p 投影            │
      │          g_geo/g_app 投影 + sg + LN
      ▼                ▼
  [Z'_C; Q_m] + 位置  目标 Z^b_m
      │                │
  预测器 h_φ           │
      │ Ẑ^b_m          │
      └── SmoothL1 ────┘   （L_pred）
```

细节：预测器查询侧拼接了上下文特征与目标查询（位置绑定 ρ_φ(U_{B_m})），但**内容侧只有上下文**——模型必须从上下文的结构规律外推目标块表示。

### A.4 特征空间 grounding 的三重作用

1. **防坍缩**：VISReg 的随机一维投影 + 高斯参考匹配，阻止 EMA-投影空间退化为常数；
2. **训练投影器**：sg 使 L_pred 的梯度不进 g_b，grounding 损失是 g_b 的唯一训练信号；
3. **空间解耦**：跨协方差 Γ 惩罚让 geo/app 不含冗余线性成分——两个空间被迫编码不同的可预测结构。

### A.5 为什么 SmoothL1 而非 MSE

块级潜在目标经过 LN 后分布稳定，SmoothL1 对离群块（结构极难预测的块，如细节丰富的表面）更鲁棒，避免少数困难块主导梯度。

## 附录B：实验设计的深意

### B.1 三类"表示问题"评估

| 评估 | 考察能力 | Spatial AGI 对应 |
|------|---------|-----------------|
| 重采样一致性 | 实现方差鲁棒性 | 同一场景不同重建质量下特征稳定 |
| 部分观测检索 | 实例信息保留 | 从局部观测识别物体（重定位/检索） |
| 可渲染补全 | 结构化空间先验 | 从看到的一面推断整体几何 |
| 部件分割/分类 | 语义迁移 | 下游理解任务 |

这个评估矩阵的精髓：**每个任务对应 Spatial AGI 的一个真实子问题**，而非刷分类准确率。

### B.2 "匹配基线"的实验伦理

论文强调 "matched reconstruction pretraining"——同 tokenizer、同编码器容量、同数据，只换目标函数（重建 vs 潜在预测）。这种控制变量设计使结论（潜在预测 > 重建）可归因于目标函数本身，是预训练论文的良好范本。

## 附录D：失败模式与风险推演

1. **EMA 漂移失稳**：小 batch 下 EMA 目标不稳定，VISReg grounding 的作用被放大；若 grounding 太强会压制预测信号；
2. **tokenizer 瓶颈**：FPS+KNN 的 64 组对薄壁/细丝结构（植物、发丝）欠采样，潜在预测学到的"结构"可能是 token 化伪影；
3. **geo/app 命名误导**：两空间是学习出来的，不保证语义上纯几何/纯外观——下游若假设硬拆分（只用 geo 特征做几何任务）可能失望；
4. **场景级迁移风险**：场景高斯含大量背景/天空/噪点，物体级预训练的分布先验可能失效，需要场景级课程。

## 附录E：与今日其他论文的组合实验设想

1. **Gaussian-JEPA + GaussMemory**：用预训练编码器初始化 GaussMemory 的 MLP_enc 与高斯特征 h，检验记忆条目的跨实现重识别精度提升；
2. **Gaussian-JEPA + LaGSplat**：LaGSplat 的 latent 高斯若用 JEPA 式目标预训练，物理仿真前的表征可能更结构化；
3. **Gaussian-JEPA → 4D-JEPA**：把块采样从空间扩展到时空（s 变为时空体素预算），加动作条件查询，即为高斯世界模型预训练——这是我认为最值得做的下一步。

## 附录G：金句摘录与评注

> "We seek targets that capture predictable object structure rather than the exact attributes of one sampled realization."

评注：全文最核心的一句。空间表示学习的正确目标不是"忠实记录世界"而是"预测世界的结构"——这与 GaussMemory 的"任务效用定义记忆价值"形成有趣的二元对立：一个追求可预测性，一个追求效用。统一两者（效用加权的可预测结构）是开放问题。

> "This variation arises at the interface between a dense asset and its encoder rather than from a designed semantic augmentation."

评注：对"实现方差"来源的精确刻画——它是接口噪声而非语义增强。这个区分对设计鲁棒的空间感知系统至关重要：你不能通过"更多增强"解决接口噪声，只能在目标函数层面免疫它。

## 附录H：术语表

- **JEPA**: Joint-Embedding Predictive Architecture，联合嵌入预测架构
- **EMA**: Exponential Moving Average，指数移动平均（动量编码器）
- **sg**: stop-gradient，截断梯度
- **VISReg**: 一种特征空间正则方法（控制均值/尺度 + 随机投影匹配高斯参考）
- **FPS/KNN**: 最远点采样 / K 近邻
- **实现方差（realization variance）**: 同一物体因固定预算重采样产生的原语级观测差异
- **Gaussian-MAE**: 高斯掩码自编码器，本文的匹配重建基线

## 附录J：逐贡献点批判性评估

### 贡献1：问题形式化（随机固定预算观测下的自监督高斯学习）

**价值评估：高**。将"实现方差"从工程烦恼提升为问题设定的一部分，是概念层面的贡献。后续所有高斯输入系统都可以引用这个问题形式化。

**批判**：形式化停留在"独立重采样"这一种接口噪声。真实部署中还有：密度漂移（重建轮次间高斯数变化）、精度异质（近处密远处疏）、时间对齐误差（4D 输入）。问题设定可以更一般化为"资产-观测分布族"。

### 贡献2：多尺度目标 + 互补空间 + grounding

**价值评估：高**。三者都是可迁移的组件级创新：多尺度块采样可移植到任何 token 化模态；跨协方差惩罚是双头表示学习的通用正则；VISReg 替代解码器的做法降低了 JEPA 工程门槛。

**批判**：geo/app 双空间的效果依赖 grounding 强度超参——论文未系统报告对 Γ 惩罚权重的敏感性分析。若权重过低两空间冗余，过高则互相回避导致信息丢失。

### 贡献3：评估协议

**价值评估：很高（被低估的贡献）**。重采样一致性/部分检索/可渲染补全三件套应成为 3D 表示学习的标准评估。特别是"可渲染补全"——用同一解码器在冻结特征上训练补全——干净地分离了"特征质量"与"解码器容量"。

**批判**：缺少与对比学习基线（Gaussian 对比方法）和跨模态蒸馏（CrossJEPA 式图像→高斯）的对比，"JEPA 优于一切"的结论为时过早，严谨说法是"JEPA 优于匹配重建"。

## 附录M：方法论迁移指南（给 Spatial AGI 系统设计者）

1. **如果你的系统消费 3DGS 输入**：考虑用 Gaussian-JEPA 式预训练初始化高斯编码器，而非从零训练或借用点云预训练权重——高斯的 14 维耦合属性与点云 3 维输入分布不同；
2. **如果你在做掩码建模**：审视你的目标是否绑定在"单次采样实现"上；若是，考虑潜在目标 + EMA 完整场编码的改写；
3. **如果你在做双流/多头表示**：跨协方差惩罚 Γ 是保证头间互补的最低成本手段；
4. **如果你的评估只有分类**：补上重采样一致性与部分观测协议——它们对 Spatial AGI 下游的预测力更强；
5. **如果你的输入有接口噪声**（固定预算采样、量化、分辨率差异）：把噪声纳入问题设定而非用增强对抗，潜在预测目标是接口噪声的天然解药。

## 附录N：与重建-预测之争的历史脉络

- 2020s 初：MAE 在 2D 图像的成功 → 掩码重建成为默认自监督范式；
- 2023：I-JEPA 论证"预测表示优于重建像素"（语义抽象层面的预测）；
- 2024-2025：Point-JEPA/3D-JEPA 在点云验证；V-JEPA 在视频验证；
- 2026（本文）：在高斯原语上验证，且首次面对"属性异构 + 实现方差"双重挑战；
- 趋势外推：下一个战场是"结构化世界状态"（场景图、高斯场+物理属性）上的预测式学习——LaGSplat（今日论文5）的物理高斯正是候选输入。

这场之争的本质：**监督信号应该放在感知端（重建输入）还是认知端（预测抽象）**。Spatial AGI 作为"认知端"事业，理应押注预测式学习。

## 附录P：补充思考——高斯表示学习的生态位

在"3DGS 生态"中，表示学习 occupies 如下生态位：

```
重建/渲染（下游消费）──► 语义理解（Gaussian Grouping、GaussianVLM）
        │                        │
        ▼                        ▼
   预训练表征（本文 Gaussian-JEPA）◄── 数据基建（Gaussian-MAE 数据集）
        │
        ▼

```

生态位判断：预训练表征是"中间件"——上承重建产物，下启记忆与世界模型。其价值取决于上下游标准化程度：高斯资产格式越统一（属性约定、坐标系、单位），预训练收益越大。目前 3DGS 生态的格式碎片化（各引擎属性顺序/球谐阶数不同）是比算法更大的推广障碍——值得社区优先解决。
