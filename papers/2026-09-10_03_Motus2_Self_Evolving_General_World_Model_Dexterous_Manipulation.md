## 0. 一句话总结

Motus2 用单一共享权重的模型同时充当策略（WAM）、模拟器（动作条件 WM）与评估器（价值模型），三者的耦合构成闭环的"决策-学习"回路，配合从单目自我中心数据到双目再到机器人数据的规模化路线，实现灵巧操作的自我进化。

---

## 1. 研究背景与动机

### 1.1 世界模型 agent 的"贴皮"问题

现有具身世界模型系统的通病：

> 在世界模拟器外面**接一个动作输出头**，就称之为 world-action model。

问题在于：策略、模拟器、评估器三者**没有耦合进闭环**——

- 策略不利用模拟器做前瞻规划；
- 评估器不参与训练信号的生成；
- 系统不会从自己的失败经验中改进。

结果是一个开环系统：预测归预测，动作归动作，改进靠外部数据。

### 1.2 Motus2 的命题

> 通用具身智能体应在**统一系统内**完成感知、预测、行动、评估与改进（perceive, predict, act, evaluate, improve）。

这五个动词构成闭环，缺一环就不叫 self-evolving。

## 2. 核心方法

### 2.1 三接口一模型（Model Scaling 轴）

单一共享权重模型暴露三个控制接口：

| 接口 | 功能 | 输入 → 输出 |
|---|---|---|
| Policy (WAM) | 提议候选动作块 | 观测历史 → 动作 chunk |
| Simulator (AC-WM) | 预测动作视觉后果 | 观测 + 动作 → 未来帧 |
| Evaluator (Value) | 评估预测结局质量 | 预测的未来 → 价值分数 |

**闭环**：策略出 N 个候选 chunk → 模拟器逐个想象后果 → 评估器打分 → 选最优执行；执行后的真实结果（尤其失败/次优交互）回流为动力学与价值学习的训练证据。

### 2.2 数据 Scaling 轴（三阶段课程）

1. **大规模单目自我中心数据**：人类第一视角视频，学世界先验与手-物交互统计；
2. **同步双目自我中心数据**：引入立体视差，强化深度/度量结构；
3. **机器人域适应**：机器人轨迹 + 人机对齐补充数据，把先验信道化为具体 embodiment 的控制。

### 2.3 其他扩展

- **上下文扩展**：滑动窗口之外，研究 global-autoregressive 与 hybrid-memory 变体（与昨日 Linguistic Trajectory Encoding 的长时程记忆问题同构）；
- **触觉反馈**：加入触觉模态实现接触感知控制（contact-aware）；
- **仿生平台**：双目视觉 + 双臂 + 双灵巧手 + 触觉的完整硬件实例化。

### 2.4 监督信号的全利用率

一个值得注意的数据哲学：

- 专家演示 → 动作学习；
- **失败与次优交互** → 动力学建模与价值学习。

失败不再是废数据，而是"世界不按策略预期演化"的证据——这正是世界模型与价值模型最需要的负样本。

## 3. 三个核心问题

### 3.1 Q1: 核心算法/技术方案是什么？

1. 权重共享的三接口架构（policy / simulator / evaluator 同源）；
2. 推理时闭环：候选生成 → 想象 → 评估 → 选择（test-time compute 换取动作质量）；
3. 训练时闭环：真实 rollout（含失败）持续反哺动力学与价值头；
4. 单目→双目→机器人的数据课程，以立体视觉为空间度量的注入点；
5. 混合记忆上下文 + 触觉的多模态扩展。

与昨天 Zeva 的对照：Zeva 用 in-context 因果学习做外挂式自进化（冻结策略），Motus2 做全参数闭环自进化（共享权重的内生进化）。两者代表"适应"光谱的两端。

### 3.2 Q2: 与 Spatial AGI 的关系是什么？

1. **自我中心数据是空间先验的天然来源**：人类手-物交互视频蕴含抓取几何、遮挡动力学、工具可供性——Motus2 验证了这条空间先验注入路径；
2. **双目→度量的显式注入**：从单目到双目的课程升级，本质是把"空间度量结构"（深度）显式补进表示，佐证"空间智能需要度量几何而非仅统计相关"的立场；
3. **想象-评估闭环 = 空间反事实推理**：模拟器+评估器的组合使系统可以在想象空间中做反事实实验（"如果我这样抓会怎样"），这是空间认知的高级形态；
4. **触觉加入多模态空间表征**：空间智能不只视觉——接触、力、滑动构成物体的另一套空间证据；
5. **灵巧操作是空间智能的试金石**：20+ DOF 的手部控制要求毫米级的空间预测精度，比导航更严苛地检验世界模型的空间保真度。

### 3.3 Q3: 创新点与局限是什么？

**创新点**：
1. 三接口权重共享的内生闭环设计，超越"模拟器+策略头"贴皮范式；
2. 失败经验系统化利用的数据哲学；
3. 单目→双目→机器人的空间度量注入课程；
4. 全仿生硬件平台（双目+双臂+双手+触觉）的完整系统验证；
5. 团队（Jun Zhu 组）的视频生成技术底座使模拟器质量有保证。

**局限**：
1. 系统极其复杂（数据课程+三接口+触觉+仿生硬件），复现门槛极高；
2. 闭环改进的幅度与饱和点未明：test-time 想象的收益随任务复杂度的 scaling 关系待观察；
3. 评估器本身的可信度问题：用学到的价值模型筛选动作，价值偏差会被策略放大；
4. 长时程记忆扩展停留在变体研究层面，小时级任务未覆盖；
5. 真机自进化的安全性：失败探索在真实硬件上的成本与风险约束未充分讨论。

## 5. 个人思考与启发

### 5.1 "评估器"是被低估的第三接口

世界模型领域大量讨论 policy 与 simulator，Motus2 把 evaluator 提到同权重地位，并让失败数据喂养它——这实际上构建了世界模型内部的 RLHF 式回路。空间智能系统同样需要"空间预测质量"的评估器：哪里会撞、抓取是否会滑，这些判断不能全靠生成似然。

### 5.2 双目课程的空间启示

人类婴儿的深度知觉也高度依赖双目线索。Motus2 的课程（单目先验 → 双目度量 → 机器人接地）意外地与发育认知的叙事同构。对 Spatial AGI 的启发：**数据模态的升级节奏**可能比数据总量更影响空间能力的形成。

### 5.3 自进化的边界

闭环自进化依赖评估器与模拟器的相互制衡；一旦两者共谋（评估器偏好模拟器容易想象的结局），进化就会跑偏。这与_alignment 问题在结构上同源，值得在 Spatial AGI 路线图中作为风险项跟踪。
