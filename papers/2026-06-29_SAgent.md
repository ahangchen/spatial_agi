# S-Agent: Spatial Tool-Use Elicits Reasoning for Spatial Intelligence

**论文标题**：S-Agent: Spatial Tool-Use Elicits Reasoning for Spatial Intelligence（S-Agent：空间工具使用激发空间智能推理）

## 核心问题

真实世界的空间智能要求模型能够理解一个**连续演化的 3D 世界**——它隐藏在多视角图像和视频流中，每一帧只是场景的部分、瞬时的 2D 投影。然而，当前的视觉语言模型（VLM）和工具增强型 Agent 普遍受限于**静态、无状态的单帧推理**：它们从孤立的视觉观察出发，缺乏跨视角、跨时刻的证据累积能力。这导致了一个根本性的"语义-几何鸿沟"——VLM 擅长定性的语义推断，却无法忠实捕捉高保真的 3D 几何信息，容易依赖文本模式和语义先验而非几何证据来做空间判断。

## 方法创新

S-Agent 的核心洞见是：**空间推理不应是孤立帧级别的预测，而应是时空证据的逐步累积过程**。它提出了三个关键设计：

**1. VLM 作为语义规划器 + 层次化空间工具体系。** S-Agent 将 VLM 定位为"决定需要什么证据"的规划器，而非直接做几何计算的工具。空间工具分为三层：Level 1 的 2D 感知工具（关键帧选取、目标定位、开放词汇检测）→ Level 2 的 2D-to-3D 几何提升（深度估计、3D 坐标恢复、相机位姿、鸟瞰图生成）→ Level 3 的空间知识聚合专家（计数、测量、方向、相对位置）。这种分层设计让 VLM 聚焦语义规划，将几何计算交给专业工具。

**2. 双重记忆机制。** Scene Memory 维护以物体为中心的持久化场景状态——跨帧绑定同一物体、累积其视觉和几何属性；Agent Memory 记录推理轨迹（已调用工具、观察结果、中间决策），避免重复推理和自我矛盾。两者配合，使 Agent 能基于累积证据而非孤立视觉印象进行推理。

**3. 从零样本到蒸馏的训练范式。** 零样本模式下，S-Agent 可直接接入任意 VLM（开源/闭源）无需训练；进一步地，利用零样本 S-Agent 生成的 29.2 万条空间推理轨迹（S-300K 数据集）微调 Qwen3-VL-8B，蒸馏出 S-Agent-8B 紧凑模型。

## 关键结果

- **零样本最优**：S-Agent 在 MMSI-Bench 上达到 46.4%，超越 Gemini 3 Pro（45.2%）和 GPT-5.4（41.9%），在 ViewSpatial-Bench 上达 60.0%。相比基座 VLM（InternVL3.5-8B 的 29.0%），提升高达 17.4 个百分点，其中相机运动维度提升 +31.1pp。
- **蒸馏效果显著**：S-Agent-8B 在 MMSI-Bench 上从基座 31.1% 提升至 41.6%（+10.5pp），在 ViewSpatial-Bench 上从 42.2% 提升至 46.8%（+4.6pp），达到与 GPT-5.4 相当的水平。
- **跨模型通用性**：框架对 Gemini、GPT、Qwen 等多种 VLM 均有一致提升，证明了范式的普适性。

## 对 Spatial AGI 的意义

S-Agent 代表了空间智能研究从"帧级识别"到"场景级推理"的重要范式转变。它的核心贡献在于指出了一条可行路径：**不需要让 VLM 内化所有 3D 知识，而是通过工具使用和记忆机制，让 Agent 主动获取、累积和复用空间证据**。这种"规划器 + 工具 + 记忆"的解耦设计，与人类空间认知中"感知-记忆-推理"的分离机制高度一致。

从 AGI 视角看，S-Agent 的价值有三：（1）证明了空间工具使用本身能激发 VLM 的潜在空间推理能力，无需大规模 3D 训练数据；（2）轨迹蒸馏范式（零样本 Agent → 数据集 → 紧凑模型）为规模化构建空间智能提供了可复制的路线；（3）双重记忆机制为具身 Agent 在持续演化的真实环境中保持一致的空间理解提供了基础架构。这是朝向能够在物理世界中自主感知、推理和决策的 Spatial AGI 的关键一步。
