# 3DSS: 3D Surface Splatting for Inverse Rendering

**发表日期**: 2026-05-07  
**arXiv链接**: https://arxiv.org/abs/2605.05876  
**PDF链接**: https://arxiv.org/pdf/2605.05876  
**作者**: Mae Younes, Adnane Boukhayma  
**机构**: INRIA, University of Rennes, France

## 核心问题

### Q1: 核心算法原理

**分析**:

1. **核心思想和动机**
   - 当前可微渲染两大范式各有缺陷：三角网格光栅化需要固定连接且优化困难；体渲染（NeRF/3DGS）混合射线上的辐射度，破坏表面语义
   - 核心洞察：Surface Splatting的表面分离问题可以直接用重建核本身来表述——两个surfel在同一表面层当且仅当其视空间深度范围重叠
   - 填补了可微渲染中"表面splatting"这一缺失的第三范式

2. **主要技术方法**
   - **多层表面分离算法**：将排序后的图元流上的区间合并问题替代传统的二值/三元深度测试
   - **覆盖度合成模型**：每层不透明度直接来自累积的EWA重建权重
   - **对象空间MIP滤波器**：利用splatting的重采样结构抑制采样混叠
   - **正向微面着色**：在联合优化的HDR环境光照下进行物理着色

3. **算法流程**
   - 输入：多视角图像
   - 使用无结构的方向性surfel集表示场景
   - 通过3DSS可微渲染器联合优化：几何形状 + 空间变化BRDF材质 + HDR光照
   - 优化的surfel集可直接通过Screened Poisson重建转换为mesh

4. **输入输出**
   - 输入：多视角照片
   - 输出：几何 + 材质(BRDF) + 光照(HDR环境图) 的完整分解

### Q2: 与Spatial AGI的关系

1. **如何理解和表示空间**
   - 通过方向性surfel（表面元素）表示空间中的表面
   - 每个surfel有位置、方向、材质属性——提供了表面的完整物理描述
   - 无需网格连接或纹理参数化，比mesh更灵活

2. **如何处理空间关系**
   - 多层表面分离自然处理遮挡关系
   - EWA核的重叠定义了表面连续性
   - 深度范围重叠 → 同一表面层；深度间隔 → 不同层

3. **对Spatial AGI的启发**
   - **表面语义保留**：比体渲染更适合需要物理理解的任务
   - **材质分解能力**：空间智能需要理解材质属性（金属、木材等）
   - **mesh桥接**：优化后的表示可直接用于下游mesh工作流

4. **可以应用的Spatial AGI场景**
   - 机器人感知中的材质识别与理解
   - 数字孪生构建
   - 交互式3D场景理解

### Q3: 创新点和局限性

1. **主要创新点**
   - 首个用于物理逆向渲染的可微表面splatting渲染器
   - 基于区间合并的多层表面分离算法
   - 覆盖度不透明度直接源自EWA权重
   - 抗锯齿且有信息量的梯度

2. **主要局限性**
   - 计算效率可能不如nvdiffrast（mesh-based）
   - 新视角合成质量可能不如3DGS
   - 表面splatting社区相对较小，工程支持有限

3. **与相关工作的对比**
   - vs NVDiffRec (mesh): 无需网格连接，优化更灵活
   - vs 3DGS: 保留表面语义，不混合辐射度
   - vs NeRF: 更适合材质分解和下游应用

## 核心技术发现

- 表面分离可以用重建核的深度区间重叠来定义
- EWA权重可直接作为覆盖度不透明度
- 表面splatting在逆向渲染中具有独特优势：无需连接性 + 保留表面语义

## 关键数据

- **评估基准**: Stanford-ORB
- **对比方法**: mesh-based (NVDiffRec), implicit (NeRF), Gaussian-splatting
- **评估维度**: 几何重建、新视角合成、新光照重照明

## 总结

### 核心发现总结
3DSS填补了可微渲染中表面splatting的空白，通过区间合并的表面分离和EWA覆盖度不透明度，实现了首个物理逆向渲染的可微表面splatting渲染器。

### 对Spatial AGI的意义
为空间感知提供了新的表示范式——既灵活又保留表面语义，同时支持材质分解和下游mesh工作流桥接。这对需要理解物体表面物理属性的Spatial AGI系统尤为重要。
