## 摘要要点

- 通用机器人需要：汲取多样经验、选择动作、预判动作对世界的影响
- XPACE 是统一具身世界模型，兼具两种角色：
  - **世界动作模型**（world action model）：联合预测可执行机器人动作 + 未来视频
  - **世界模拟器**（world simulator）：预测规定动作下的视觉后果
- 核心洞察：**视频预测既能把异构经验连接到动作学习，又能生成新经验用于策略改进**
- 关键组件：
  - 策略与模拟器共享视频骨干
  - 动作无标签视频学视觉动力学；动作标注的人类+机器人演示联合学视频与动作预测
  - 粗到细训练课程：逐步强调机器人控制，同时保留人类经验
  - 模拟器生成"偏差-恢复"轨迹作为策略的恢复监督（DAgger 式微调）
- 真机结果（XPENG IRON 人形机器人）：
  - 异构训练提升鲁棒性
  - 人类观察到的技能可迁移到机器人演示中不存在的任务
  - 模拟器生成的恢复数据进一步提升真实世界任务完成率

## 核心问题

### Q1: 核心算法原理是什么？

**问题**: 这篇文章的核心算法原理是什么？

**分析**:

#### 1. 核心思想和动机

- **人类的技能获取模式**：观察他人 + 亲自交互 → 预判动作后果 → 改进行为。通用具身系统应当复刻这个循环。
- **现状诊断**：视频-动作模型（video-action models）把未来预测与动作生成连进了共享网络，但**联合预测本身不解决技能如何从多样来源获取、又如何通过模拟经验改进**的问题。
- **三个连环问题**（本文的组织骨架）：
  - **Q1（数据）**：模型应该从什么经验学习？
    - 人类视频：行为覆盖广，但监督从纯视觉到与机器人控制命令不同的运动标注不等
    - 机器人演示：动作可执行，但跨环境采集昂贵
    - 简单混合两种来源无法解释不同监督如何服务于同一个策略与模拟器
  - **Q2（模型）**：一个模型如何同时用于动作生成与模拟？
  - **Q3（训练）**：训练如何把这些能力转化为机器人控制与随后的自我改进？
    - 模仿已录演示对"执行错误导致偏离熟悉状态"提供不了纠正监督
    - 预测模拟要能自我改进，其输出必须能变成可靠的策略训练样本
- **核心主张**：视频预测是连接异构经验与动作学习的"公共学习任务"，同时是策略自我改进的"经验发生器"。

#### 2. 主要技术方法

**异构经验的数据金字塔**（回答 Q1）：

- **动作无标签的自我中心视频**：提供多样的视觉交互经验，学视觉动力学
- **运动学标注的人类演示**：监督操作行为（人类骨架运动标签）
- **机器人遥操作演示**：目标本体上的直接控制监督
- **人类桥接数据（bridge data）**：任务与外观对齐的人类数据，缩小人类演示与机器人部署之间在任务覆盖与视觉条件上的差距
- 数据金字塔结构：广覆盖的交互经验在底部，机器人特定监督在顶部，各来源保留其独特信息

**共享骨干的双模式架构**（回答 Q2）：

- **共享因果视频骨干（causal video backbone）**：策略模式与模拟器模式共用
- **策略模式（policy mode）**：
  - 条件：观测 + 当前状态 + 任务指令
  - 输出：可执行动作 + 未来视频
- **模拟器模式（simulation mode）**：
  - 条件：视觉历史 + 规定的骨架控制（skeleton controls）+ 相机位姿
  - 输出：未来视频
- **动作 Transformer**：
  - 读取骨干的**多层级视觉特征**（multi-level visual features）
  - 动作损失的梯度更新与模拟器共享的同一个骨干
- **本体特定动作投影（embodiment-specific action projections）**：
  - 适配人类与机器人的不同动作空间
  - 保持动作 Transformer 本体共享
- 效果：纯视频经验与动作标注演示可以训练同一个模型，共享的视觉动力学同时支撑控制与模拟

**渐进训练与模拟驱动的自我改进**（回答 Q3）：

1. **阶段一**：先训视频预测
2. **阶段二**：联合训练动作预测与模拟——动作损失只在有有效监督的数据上施加
3. **粗到细课程**：逐步强调桥接数据与机器人数据，但在机器人适配全程保留人类经验
4. **模拟器自适应**：通过 self-gradient forcing 让模拟器适配自己生成的视觉上下文（不需要反传完整 rollout——借鉴 Self Gradient Forcing）
5. **恢复数据合成**：
   - 在专家演示周围合成"偏差-恢复"（deviation–recovery）轨迹
   - 用规定的规定骨架控制渲染轨迹
   - 对生成的轨迹做恢复一致性过滤
   - 保留的恢复样本与专家续段组合
   - 在增广数据上微调**单独的策略副本**（DAgger 式，保护原策略）
- 结果：模型自己的模拟器供给"名义演示中缺失的纠正性经验"，预测能力转化为策略自我改进的实用来源

#### 3. 算法流程和关键步骤

1. 视频预训练：在动作无标签视频上学习视觉动力学
2. 联合训练：视频预测 + 动作预测 + 模拟（异构数据金字塔，动作损失按监督有效性掩码）
3. 粗到细课程：数据配比从人类为主逐渐转向桥接+机器人为主
4. 模拟器自适应：self-gradient forcing 适配自生成上下文，提升自回归稳定性、降低推理成本
5. 恢复合成：围绕专家演示规定偏差 → 模拟器渲染恢复轨迹 → 过滤
6. 策略微调：增广数据（恢复样本+专家续段）微调策略副本
7. 真机部署：IRON 人形机器人执行

#### 4. 输入输出

- **策略模式输入**：观测（图像）+ 当前状态 + 任务指令；**输出**：可执行动作 + 未来视频
- **模拟器模式输入**：视觉历史 + 规定骨架控制 + 相机位姿；**输出**：未来视频
- **训练输入**：异构经验金字塔（自我中心视频 / 运动学标注人类演示 / 机器人遥操作 / 桥接数据）
- **自我改进输出**：经合成恢复数据微调的策略（真机任务完成率更高）

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**问题**: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**分析**:

#### 1. 如何理解和表示空间

- **空间作为视频预测的公共表征**：XPACE 用未来视频作为"公共学习任务"统一异构经验——空间/时空动态是连接"看过的"（人类视频）、"被教的"（人类演示）与"做过的"（机器人演示）的媒介。空间理解在这里是动作学习的地基而非独立目标。
- **骨架控制作为身体空间表示**：模拟器以规定骨架控制+相机位姿为条件——身体姿态的空间配置成为可编程的空间变量，这是具身空间表示的独特维度。
- **多层级视觉特征**：动作 Transformer 读多层级特征而非单层——隐含承认空间决策需要多尺度的空间信息（低层纹理/接触 → 高层布局/目标）。

#### 2. 如何处理空间关系

- **动作-视觉的空间因果**：模拟器模式编码了"给定身体配置变化，视觉（即空间观测）如何变化"的因果——这正是空间智能中"能动性-环境"关系的核心。
- **桥接数据对齐空间视角差异**：任务与外观对齐的桥接数据处理人类视角与机器人视角的空间不一致——跨视角空间对齐的工程解法。
- **偏差-恢复的空间轨迹**：恢复数据合成本质是探索"偏离专家空间轨迹后如何回到目标"——空间轨迹邻域的对抗性数据增广。

#### 3. 对 Spatial AGI 的启发

- **"预测作为通用接口"**：XPACE 用视频预测统一了异构监督；对 Spatial AGI，空间预测（未来观测/状态）可以成为统一多源空间经验的接口——不管经验来自谁的身体。
- **跨本体空间智能**：本体特定投影 + 共享主干的设计让"人类看到的空间经验"服务于"机器人的空间行动"——Spatial AGI 不应绑定单一传感器/身体。
- **自我改进闭环的蓝图**：模拟器生成自己的训练数据 → 过滤 → 微调策略副本——这是 Spatial AGI"自我演化"的工程雏形，与数据引擎路线（WorldContact）殊途同归但更闭环。
- **课程学习的空间意义**：粗到细课程（人类→桥接→机器人）暗示空间智能的习得也有类似的"由远到近"结构——先广学世界的样子，再精学自己的身体如何作用于它。

#### 4. 可以应用的 Spatial AGI 场景

1. **人形机器人通用操作**：直接应用域——从人类视频学广覆盖技能
2. **跨具身空间经验库**：多机器人/人类视频共享的空间动力学预训练
3. **模拟驱动的空间策略安全改进**：偏差-恢复合成可推广到导航（偏离路线后返回）
4. **世界模型评估**：模拟器自适应后的自回归稳定性可作为世界模型质量的操作性指标
5. **空间智能的数据金字塔方法论**：无标签视频→弱标注→强标注的分层利用策略适用于任何空间任务

### Q3: 这个方法的主要创新点和局限性是什么？

**问题**: 基于前面的分析，这个方法的主要创新点和局限性是什么？

**分析**:

#### 1. 主要创新点

- **三位一体的系统回答**：不是单点创新，而是对"数据（异构金字塔）-模型（共享骨干双模式）-训练（课程+自我改进）"三个问题的协调设计。文献中多数工作只回答其中一个。
- **视频预测的双重角色**：明确提出并实现"视频预测既是连接异构经验的公共任务，又是生成新经验的工具"——这个双重角色把 joint video-action modeling 从表示学习技巧升级为自我改进引擎。
- **模拟器自适应 + 恢复合成的完整管线**：self-gradient forcing 适配自生成上下文 → 规定偏差渲染恢复轨迹 → 一致性过滤 → 策略副本微调。特别是"模拟器先适配自己的生成上下文再用来生成训练数据"这一步，解决了"用不稳定的生成器造数据"的可靠性问题。
- **跨本体动作空间处理**：本体特定投影 + 共享动作 Transformer，让人类运动学标注与机器人控制命令在同一个动作头里各得其所。
- **工业级真机验证**：XPENG IRON 人形机器人，验证了"人类观察技能迁移到机器人演示中不存在的任务"这一关键主张。

#### 2. 主要局限性

- **视频生成的成本与延迟**：策略模式同时生成未来视频——推理时是否真的需要视频输出？文献自己也提到 Fast-WAM 等工作"保留视频共训练但跳过测试时未来预测"。视频生成的实时性对机器人控制是硬约束。
- **恢复数据的质量边界**：合成恢复依赖模拟器保真度；过滤标准（recovery consistency）的有效性决定增广数据的上限——错误恢复样本可能教策略"如何优雅地失败"。
- **骨架控制的依赖**：模拟器条件于规定骨架控制，意味着需要运动学可执行的中间表示；末端执行器之外的全局动力学（物体响应）没有显式建模（对比 WorldContact 的物体级预测）。
- **单一机器人平台**：所有真机结果在 IRON 上；跨本体的泛化声明主要靠架构设计而非实验直接验证。
- **自我改进的收敛性**：模拟器生成数据→微调策略的循环迭代几次会饱和/退化，论文未展示多轮自我改进的曲线。
- **评估协议细节**：真机任务数量、种类、试验次数需查正文；"人类技能迁移到无机器人演示任务"的评估覆盖面存疑。

#### 3. 与其他相关工作的对比

- **vs UWM / UVA / τ0-WM 等统一 video-action 模型**：同为共享网络联合预测；XPACE 的差异在训练方法论（异构金字塔 + 粗到细课程）与自我改进闭环（恢复合成），而非模型结构本身。
- **vs Dreamer 系（latent imagination）**：Dreamer 在潜空间想象；XPACE 在像素空间（视频）想象——可解释性与计算成本的取舍。且 XPACE 的恢复合成是离散的、过滤过的数据增广，不是连续的策略梯度。
- **vs DreamGen**：DreamGen 从生成视频回收伪动作；XPACE 从规定动作生成视频再筛恢复样本——方向相反，后者对动作的可控性更强。
- **vs WM-DAgger**：同样做模拟器合成的恢复轨迹；XPACE 加入了模拟器自适应（self-gradient forcing）与本体金字塔，系统更完整。
- **vs V-JEPA 2**：JEPA 路线在潜空间做动作条件预测，无视频生成开销；XPACE 选择显式视频——两条路线的长期对赌仍在进行。
- **vs WorldContact（今日论文 2）**：WorldContact 用显式物体状态+物理教师造数据；XPACE 用视频生成+自我自适应造数据。前者保真可度量、后者覆盖更广，两种数据引擎哲学。
- **劣势总结**：模型结构上属于 2025-2026 video-action model 大潮中的一员，真正差异化在训练配方与自我改进闭环；单平台验证限制泛化结论。

## 核心技术发现

- 发现1：视频预测可以同时充当异构经验的"公共学习任务"和策略改进的"经验发生器"——双重角色是 joint world-action modeling 的真正价值
- 发现2：粗到细课程（人类→桥接→机器人）在机器人适配中保留人类经验的行为覆盖，使人类观察技能可迁移到无机器人演示的任务
- 发现3：模拟器先用 self-gradient forcing 适配自生成上下文，再用于合成恢复数据——生成器可靠性先于数据合成
- 发现4：偏差-恢复轨迹合成 + 一致性过滤 + 策略副本微调 = 世界模型驱动的 DAgger，在真机上提升任务完成率

## 个人思考

### 最令人兴奋的发现

"模拟器先适应自己的生成上下文，再去生成训练数据"这一步的哲学含义：模型在当自己的老师之前先校准自己。这解决了生成式数据增强最根本的信任问题。加上最终在真机 IRON 上验证闭环有效，这是"世界模型自我改进"从论文概念走向工程现实的标志之一。

另一个被低估的设计是策略副本微调——生成数据有风险，所以改进发生在隔离副本上。这是 AI 自我改进安全性的朴素但正确的工程姿态。

### 潜在局限

- 视频生成的推理成本：控制频率要求高的任务上，"边生成未来视频边出动作"的模式可能不经济——文献自己列出的 Fast-WAM/GigaWorld-Policy 等工作就是在解决这个问题，说明这是公认痛点。
- 恢复数据合成的质量控制本质上是"用模型判断模型输出的好坏"，过滤器与生成器共享偏见的风险。
- XPENG 工业背景意味着细节（数据规模、任务集、评估协议）可能受商业保密限制，复现难度高。

### 与昨日研究的关联

- 昨日（09-19）的 sensVLA 做空间接地的 VLA——XPACE 可视为其世界模型增强版：sensVLA 输出空间上正确的动作，XPACE 还预演这些动作的视觉后果。
- 昨日 DexTouch-WM 的动作条件触觉世界模型与 XPACE 的模拟器模式同构，只是模态不同（触觉 vs 视频）。
- 本周 GLAM、NavWM 等导航世界模型解决"往哪走"，XPACE 解决"手怎么动"——空间智能的导航与操作两翼正在分别成熟。

## 关键数据

- 统一模型双模式：策略模式（动作+视频）与模拟器模式（视频）
- 数据金字塔：4 类来源（动作无标签视频 / 运动学标注人类演示 / 机器人遥操作 / 桥接数据）
- 训练：两阶段（视频预训练 → 联合训练）+ 粗到细课程
- 自我改进：模拟器自适应（self-gradient forcing）→ 偏差-恢复合成 → 过滤 → 副本微调
- 真机平台：XPENG IRON 人形机器人
- 关键结论：异构训练提升鲁棒性；人类技能迁移到无机器人演示任务；合成恢复数据提升真机任务完成率

## 总结

### 核心发现总结

XPACE 把"联合世界-动作建模"从模型结构问题重构为数据-模型-训练的协调设计问题：异构经验金字塔解决"学什么"，共享因果视频骨干+双模式+本体特定投影解决"怎么用一个模型"，粗到细课程+模拟器自适配+恢复合成解决"怎么变强"。IRON 人形机器人上的真机结果证明：人类经验可迁移、模拟器可造可靠的新经验、闭环自我改进有效。

### 对Spatial AGI的意义

- **学习论**：空间智能的习得路径可以复刻人类"观察-预测-行动-纠错"循环，视频预测是循环的枢纽
- **数据论**：空间经验的价值分层明确——广覆盖经验学"世界什么样"，具身经验学"我做了会怎样"
- **演化论**：Spatial AGI 可以成为自己的数据引擎，但必须先校准生成器、隔离改进副本——自我改进需要工程护栏
- **开放问题**：视频生成的控制频率矛盾、模拟器保真度的评估、跨本体泛化的实证

## 深度延伸分析

### A. 逐模块技术拆解

#### A.1 数据金字塔的信息论解读

四类数据源可以按"动作监督强度 × 行为覆盖广度"排成一个二维谱：

```
行为覆盖 ↑
│  动作无标签视频（广/无监督）
│  运动学标注人类演示（广/弱监督）
│  人类桥接数据（任务对齐/中等监督）
│  机器人遥操作（窄/强监督）
└──────────────→ 动作监督强度
```

XPACE 的洞察是：这个谱上的每一层都有独特信息，丢弃任何一层都损失一种学习信号。粗到细课程本质是沿对角线从左上滑向右下——先吸收覆盖广度，再注入监督精度，且不清空之前吸收的。

#### A.2 双模式的条件设计差异

| | 策略模式 | 模拟器模式 |
|---|---|---|
| 条件 | 观测+状态+任务指令 | 视觉历史+骨架控制+相机位姿 |
| 输出 | 动作+未来视频 | 未来视频 |
| 动作来源 | 模型生成（自主） | 外部规定（编程） |
| 用途 | 控制 | 数据合成/评估/规划 |

关键设计：动作 Transformer 只在策略模式活跃，但动作损失梯度回传到共享骨干——模拟器模式的视觉动力学因此被动作语义"污染"（丰富）了，反过来模拟器生成的视频又隐含动作可解释性。两个模式共享的不只是参数，还有语义。

#### A.3 Self-Gradient Forcing 的作用机制

自回归视频生成的经典困境：训练时见真实上下文、推理时见自己生成的上下文（exposure bias）。完整 rollout 反传（backprop through time）解决偏差但计算贵且不稳定。Self Gradient Forcing 的折中：用未来预测的梯度更新上下文表示，但不展开完整反传链。XPACE 在模拟器自适应阶段用它，让模拟器在"自己的视觉风格"上保持预测能力——这是后续合成数据可靠性的前提。

#### A.4 恢复合成管线的数据质量控制

1. **偏差规定**：围绕专家轨迹主动注入偏差（偏离状态）
2. **模拟器渲染**：以规定骨架控制渲染恢复过程——注意是"规定的控制"而非策略生成的控制，恢复轨迹本身仍来自专家级控制设计
3. **一致性过滤**：验证"恢复"确实恢复了（回到目标状态附近）——过滤掉模拟器幻觉出的假恢复
4. **专家续段拼接**：恢复后接上真实专家轨迹——保证恢复之后的未来仍是真实的
5. **副本微调**：隔离环境，防污染原策略

这个管线的每一环都在控制生成数据的"虚构程度"——恢复是合成的，但恢复的标准、终点、后续都是真实的。

#### A.5 与 DAgger 的理论联系

DAgger 的核心是"在学员访问的状态上要专家标签"以修复分布偏移。经典 DAgger 需要专家在线标注，昂贵且慢。XPACE 的恢复合成实际上是"模拟专家在偏差状态上的标签"——用世界模型代替真专家进行标注。这继承 WM-DAgger 的思想，但加入了模拟器自适应与跨本体数据金字塔，把理论想法推到了工业真机。

### B. 与空间智能文献的逐点对照

#### B.1 与今日 WorldContact 的深度对照

| 维度 | XPACE | WorldContact |
|---|---|---|
| 状态表示 | 视频（像素） | 显式网格顶点 |
| 动作接口 | 骨架控制（人类+机器人投影） | 14 维双臂命令 |
| 数据引擎 | 自生成视频+一致性过滤 | 大步长神经模拟 |
| 教师来源 | 专家演示+模拟器自举 | 标定物理仿真 |
| 验证度量 | 任务完成率+视频质量 | 顶点误差/穿插率+真机成功率 |
| 部署目标 | 人形通用操作 | 购物袋类可变形操作 |

两者共同印证一个趋势：世界模型的最终评价标准正在从"预测准"转向"策略好"。

#### B.2 与视频-动作模型大潮的定位

2025-2026 的 video-action model 论文爆炸（UWM、UVA、VideoVLA、Motus、τ0-WM、LingBot-VA、Riemann、Cosmos Policy……相关工作列表超过 15 个）。XPACE 在这个拥挤赛道中的辨识度不在结构（都是共享骨干+动作头变体），而在训练方法论与自我改进闭环——这是值得注意的论文差异化策略：当结构趋同时，配方成为护城河。

#### B.3 与跨本体迁移工作的对照

EgoScale（人类预训练+对齐适配）、EgoWAM（像素/特征/运动预测的迁移对照）、DreamDojo（潜动作迁移）都在解"人类经验→机器人"的问题。XPACE 的独特贡献是把这个问题嵌入世界模型框架——迁移的媒介不是特征对齐而是共享的视频动力学。

#### B.4 与导航世界模型的互补

本周 GLAM（空间记忆导航）、NavWM（前瞻规划）解决移动性空间智能；XPACE 解决操作空间智能。Spatial AGI 的完整版图需要两者：空间中的"走"与"拿"。恢复合成方法论在导航域的直接类比：偏离路径后的返回轨迹合成。

### C. 实验结果的批判性解读

#### C.1 强项

- 真机平台是人形机器人（IRON）而非桌面机械臂——难度与实用价值更高
- 三个主张分别有对应实验：异构训练→鲁棒性；人类技能→无演示任务迁移；恢复数据→任务完成率提升
- 模拟器实验单独验证了自适应的价值（自回归提升+推理成本下降）

#### C.2 需要警惕的点

- 工业论文的评估协议透明度：任务数量、试验次数、基线选择可能不如学术论文详细
- "人类技能迁移到无机器人演示任务"的任务集合如何选取——若任务与人类演示任务本质相似，迁移声明的含金量打折
- 视频生成质量与策略性能的因果关系未解耦：视频预测可能只是辅助表示学习，测试时未必需要真的生成视频
- 自我改进闭环的轮数与饱和行为未报告——一次增广有效不代表可持续自我进化

#### C.3 复现可行性

- 数据金字塔的规模与构成（尤其桥接数据的具体制作）可能涉及内部数据，难以完全复现
- 训练算力需求为视频扩散/自回归模型级别，成本高
- 概念与配方（课程、自适应、恢复合成）可迁移，具体数字存疑

### D. 开放问题

1. 测试时是否可以跳过视频生成只出动作（Fast-WAM 式）而保留训练收益？最优的"训练生成、部署跳过"边界在哪里？
2. 恢复合成能否迭代多轮？世界模型与策略的联合进化会不会进入"共谋幻觉"（模拟器越来越会圆谎，策略越来越自信地错）？
3. 骨架控制接口如何覆盖灵巧手的高维动作空间？
4. 数据金字塔各层的最优配比是否存在可迁移的普适规律？
5. 跨本体的动作投影能否学习（自动发现本体映射）而非手工设计？

### E. 对今日研究组合的位置

今日五篇中，XPACE 是学习层/数据层的核心，与另四篇构成完整栈：

- 与 WorldContact 直接对话：两种数据引擎哲学（视频生成式 vs 物理仿真式）的并置
- 与 JEPA-Anything 对照：显式视频生成 vs 潜空间预测的两条世界模型路线
- 与 VGGT-GS SLAM 衔接：SLAM 提供真实空间状态，XPACE 学习这些状态的受控行为演化
- 为 ANASSA 的 S5 执行层提供具体的执行智能实现

## 结论性评述

XPACE 的价值在于把 joint world-action modeling 从"一个模型两个头"的结构创新，推进到"数据金字塔 + 渐进课程 + 自校准数据引擎"的训练科学。视频预测的双重角色（统一异构经验的接口 + 自我改进的经验发生器）是对世界模型功能定位的清晰化。在 IRON 人形机器人上的真机验证让"模拟器生成数据改进真机策略"从概念变为可复制的工程路径。限制主要在视频生成的控制频率矛盾与工业评估的透明度。

### F. 深度讨论：视频生成路线 vs 潜空间路线的长期对赌

XPACE（显式视频）与 V-JEPA 2 / JEPA-Anything（潜空间）代表世界模型的两大路线：

| 维度 | 视频生成路线（XPACE） | 潜空间路线（JEPA 系） |
|---|---|---|
| 可解释性 | 高（人可看生成结果） | 低（需探针解码） |
| 数据可用性 | 生成结果可直接当训练数据 | 潜变量需解码才能复用 |
| 控制频率 | 受生成延迟限制 | 高频友好 |
| 计算成本 | 高（像素级生成） | 低（潜空间预测） |
| 物理保真度评估 | 可人工/自动视觉检查 | 只能间接评估 |
| 适合任务 | 慢速操作、数据合成 | 高频控制、在线规划 |

可能不是二选一：训练时用视频生成学丰富的空间先验，部署时用潜空间分支做高频控制——XPACE 的共享骨干实际上已经为这种混合形态留了接口。

### G. 恢复合成方法论的跨域推广

"主动制造偏差 → 合成恢复 → 过滤 → 副本微调" 是一个领域无关的自我改进模式：

- **导航**：从路径上随机偏离 → 合成返回轨迹 → 过滤 → 微调导航策略
- **对话**：引入误解 → 合成澄清修复对话 → 过滤 → 微调对话策略
- **驾驶**：注入扰动 → 合成危险规避轨迹 → 过滤 → 微调驾驶策略
- **空间编辑**：错误编辑 → 合成回滚/修复操作 → 过滤 → 微调编辑 agent

前提条件：存在 (1) 可控生成器 (2) 可验证的恢复标准 (3) 隔离的微调环境。三个条件在大多数空间任务中都可满足，这使恢复合成可能是比 RL 更实用的在线改进方案（不需要奖励设计，只需要恢复标准）。
