# Depth-Regularized JEPA World Models Learn More Transferable Representations from Real Outdoor Robot Data

**arXiv**: [2607.16314](https://arxiv.org/abs/2607.16314) | **Date**: 2026-07-14 | **Category**: cs.CV, cs.LG, cs.RO
**Authors**: Usman M. Khan
**Affiliation**: Aigen (agricultural robot fleet)

---

## 摘要概要

JEPA 架构的世界模型在模拟环境中表现良好，但从视觉复杂的真实世界数据中学习仍然具有挑战性，特别是在不可预测的户外环境中。本文引入**深度作为几何先验**来学习更鲁棒的潜在动态。

核心方法是对 LeWorldModel (LeWM) 增加一个**仅训练时使用的深度正则化目标**：将 RGB 嵌入与从配对深度图像计算的嵌入对齐，但推理时仅使用 RGB。LeWM 的 SIGReg 正则化器最大化潜在多样性，而深度项约束这种多样性的组织方式——两者的组合目标瞄准与场景几何一致的**最高熵表示**。

在真实农业机器人数据上训练 18M 参数模型，深度正则化使视觉里程计探针误差降低 33%，显著提升了域内和域外的惊喜检测分离度，并改善了多步潜在 rollout 保真度。

## Q1: 核心算法原理

### 1) 核心思想和动机

**问题**：JEPA 世界模型在模拟环境中成功，但真实户外数据面临：
- 光照变化、阴影、运动模糊、植被杂乱
- 像素级预测容易建模干扰因素而非场景结构
- LeWM 的 SIGReg 正则化器鼓励各向同性高斯特征——最大化多样性但不指向物理意义

**核心洞察**：深度是物理 3D 结构的监督信号 — 作为训练时的几何先验，将 JEPA 表示导向场景结构

**类比**：SIGReg = 最大熵压力（无约束的多样性）；深度 = 几何约束（物理有意义的方向）；组合 = 最高熵但与场景几何一致的表示

### 2) 主要技术方法

#### LeWorldModel (LeWM) 基础
- 紧凑的 JEPA 世界模型
- SIGReg（Structured Isotropy-Regularized Gaussian regularizer）：防止表示坍塌，鼓励各向同性高斯潜在分布
- 在模拟基准上表现良好，但未在真实户外数据上验证

#### 深度正则化目标
```
训练时：
RGB 图像 → 编码器-投影器 → RGB 嵌入
深度图像 → 同一编码器-投影器（stop-gradient）→ 深度嵌入
                    ↓
         余弦损失对齐 RGB 嵌入 ↔ 深度嵌入

推理时：
RGB 图像 → 编码器-投影器 → 嵌入（不需要深度）
```

- 深度作为"几何教师"：训练时引导 RGB 表示趋向场景结构
- 推理时无需深度传感器 — 纯 RGB 推理

#### 训练时过参数化（Training-only Overparameterization）
- 问题：几何对齐目标增加了编码器需要满足的约束，但容量有限的预测器会产生反压力
- 解决方案：训练时添加额外的预测器分支（过参数化），吸收部分预测负担
- 训练后通过**结构重参数化**（structural re-parameterization）将额外分支代数合并到基础权重中
- 部署模型完全不变

### 3) 算法流程

```
训练阶段：
┌─────────────────────────────────────┐
│ 输入：RGB 帧 + 配对深度帧           │
│   ↓                                  │
│ 编码器-投影器                        │
│   ├── RGB → 嵌入 e_rgb              │
│   └── Depth → 嵌入 e_depth (sg)     │
│   ↓                                  │
│ JEPA 预测器（过参数化分支）          │
│   └── 预测下一帧潜在表示             │
│   ↓                                  │
│ 损失 = SIGReg + 深度对齐(余弦) + 预测 │
│       + 过参数化正则                  │
└─────────────────────────────────────┘
        ↓ 训练完成后
┌─────────────────────────────────────┐
│ 结构重参数化：合并过参数化分支       │
└─────────────────────────────────────┘
        ↓
推理阶段：
RGB 帧 → 编码器 → 嵌入 → 预测器 → 未来潜在状态
（无深度传感器需要）
```

### 4) 输入输出

- **训练输入**：RGB 视频流 + 配对深度图像（来自立体相机）
- **推理输入**：纯 RGB 视频流
- **输出**：潜在空间表示（可用于 VO、惊喜检测、rollout 预测）
- **模型大小**：18M 参数

## Q2: 与 Spatial AGI 的关系

### 1) 如何理解和表示空间

本文提出了一个关键问题：**如何在不增加推理成本的情况下为世界模型注入空间先验？**

空间理解的两个层次：
- **SIGReg（无先验）**：各向同性高斯 — 不对潜在空间做任何几何假设
- **深度正则化（几何先验）**：约束潜在空间的组织方式，使其与 3D 场景几何一致

**核心洞察**：好的空间表示不一定要显式的 3D 重建 — 但需要某种形式的几何先验来指导表示学习

### 2) 如何处理空间关系

- **隐式深度理解**：通过训练时深度对齐，编码器学会从 RGB 中提取 3D 结构信息
- **潜在空间几何组织**：潜在维度被组织为与场景几何一致的方向
- **域迁移**：几何先验帮助模型在视觉外观变化时保持对场景结构的理解

### 3) 对 Spatial AGI 的启发

1. **训练-推理不对称范式**：
   - 训练时使用特权信息（深度、3D 标注等）
   - 推理时仅需 RGB — 零额外成本
   - 这是 Spatial AGI 系统的实用设计模式：**利用训练时的 3D 监督获得推理时的效率**

2. **几何 + 最大熵 = 更好的表示**
   - 单纯的多样性（SIGReg）不够 — 需要物理约束来组织
   - 单纯的几何对齐也不够 — 需要多样性来处理长尾场景
   - 两者结合产生"与几何一致的最高熵表示"

3. **紧凑世界模型的实用性**
   - 18M 参数即可在真实户外数据上工作
   - Spatial AGI 不一定需要巨大的模型
   - 正确的训练目标比模型大小更重要

4. **惊喜检测作为世界模型的评估指标**
   - 通过模型预测的"惊讶程度"来检测异常事件
   - 深度正则化改善了域内和域外的惊喜分离度
   - 这对 Spatial AGI 的异常检测和场景理解有直接价值

### 4) 应用场景

- **户外机器人导航**：农业、林业、采矿等非结构化环境
- **视觉里程计（VO）**：紧凑的几何感知表示
- **异常/惊喜检测**：识别场景中的意外事件
- **域迁移**：从训练域到新环境的零样本迁移
- **世界模型预训练**：为下游任务提供高质量表示

## Q3: 创新点与局限性

### 主要创新点

1. **首次在真实户外机器人数据上训练紧凑 JEPA**
   - 之前 LeWM 仅在模拟环境验证
   - 证明了 JEPA 在真实农业数据上的可行性

2. **训练时深度正则化范式**
   - 简单但有效：仅添加余弦对齐损失
   - 33% VO 误差降低、显著改善惊喜检测
   - 推理时零成本

3. **过参数化 + 重参数化**
   - 训练时增加容量缓解预测器瓶颈
   - 推理时通过代数合并消除额外成本
   - 精巧的工程设计

4. **多维度评估协议**
   - VO 探针、惊喜检测、多步 rollout 保真度
   - 域内和域外（TartanGround）评估

### 局限性

1. **单平台数据**：仅在 Aigen 农业机器人数据上训练
   - 其他平台（无人机、室内机器人）的效果未知
   - 数据多样性有限

2. **深度质量依赖**：训练效果依赖配对深度的质量
   - 立体深度在户外可能不准确（植被、反光表面）
   - LiDAR 深度可能更好但成本更高

3. **模型容量限制**：18M 参数可能不足以处理非常复杂的场景
   - 更大模型+深度正则化的效果未探索

4. **评估任务有限**：VO、惊喜检测、rollout 保真度
   - 下游任务（导航、操控）的效果未直接验证
   - 与其他世界模型（DreamerV3 等）的比较缺失

5. **SIGReg + Depth 的理论最优性**：两者的最佳权重比例需要手动调整
   - 自适应权重调整策略未探索

### 与相关工作的比较

| 方法 | 架构 | 训练数据 | 几何先验 | 推理需求 |
|------|------|---------|---------|---------|
| Depth-Reg JEPA | JEPA 18M | 真实户外 RGB+D | ✅ 训练时深度 | RGB only |
| LeWM (原版) | JEPA 18M | 模拟 RGB | ❌ | RGB only |
| V-JEPA | JEPA 大型 | 网络视频 | ❌ | RGB only |
| DreamerV3 | RSSM | 模拟/游戏 | ❌ | 像素重建 |
| TartanGround | 多种 | 模拟户外 | ✅ GT 深度 | 取决于方法 |

## 关键术语

- **JEPA (Joint-Embedding Predictive Architecture)**：联合嵌入预测架构，在潜在空间而非像素空间预测
- **LeWM (LeWorldModel)**：基于 SIGReg 的紧凑 JEPA 世界模型
- **SIGReg**：结构化各向同性正则化的高斯正则化器，防止表示坍塌
- **过参数化 (Overparameterization)**：训练时使用更大容量，推理时通过重参数化消除
- **结构重参数化**：将训练时的额外分支代数合并到基础权重中
- **VO (Visual Odometry) Probe**：用冻结表示训练轻量 VO 头来评估表示质量
- **惊喜分数 (Surprise Score)**：模型对意外事件的预测惊讶程度

---

## 总结

这项工作提出了一个简洁但深刻的方法：通过训练时深度正则化为 JEPA 世界模型注入几何先验，推理时零额外成本。其核心贡献——**几何约束的最高熵表示**——为如何在紧凑模型中获得物理感知的世界表示提供了实用方案。对 Spatial AGI 而言，"训练时特权信息 + 推理时零成本"的范式特别有价值，表明空间智能可以以低成本部署。18M 参数在真实户外数据上的有效性也挑战了"需要巨大模型才能理解世界"的假设。
