## 一句话总结

E0.5 是首个**几何原生（geometry-native）**的世界-动作模型（WAM）：它不以视频或 VLM 为骨干，而是直接把 3D 基础模型（VGGT-Omega）作为主骨干，并在动作生成的同时显式预测**未来 3D 几何状态**（动作 chunk 末端的深度、点图、相机参数），从而把 3D 基础模型从"重建当下"升级为"预测未来"。

## 核心问题

### Q1: 核心算法原理是什么？

**分析**:

#### 1. 核心思想和动机

- **问题背景**：世界-动作模型（WAM）主流做法是以视频基础模型或 VLM 为主骨干，即使引入 VGGT 等 3D 模型的几何特征，也只是把几何当作**辅助输入或预测目标**，几何永远不是表征的"地基"。
- **核心洞察**：机器人操作的本质是空间结构在动作驱动下的演化。如果表征基础本身是几何的，那么"世界如何随动作变化"这一核心问题就可以在几何空间内直接建模，而不需要经由视频外观（appearance）这一中间层。
- **两个假设**：
  1. 3D 基础模型（如 VGGT-Omega）的预训练几何表征是机器人动作学习的优良起点；
  2. 直接监督**未来 3D 状态**（而非当前重建或未来视频）能迫使骨干学习跨环境可迁移的空间结构动力学。
- **与 VGA 的关键区别**：VGA（Song et al., 2026）也用了原生 3D 骨干，但只做当前场景几何重建 + LoRA 适配，其消融实验显示全参数训练会严重退化。E0.5 则**解冻整个几何骨干**，用未来几何预测 + 动作生成联合优化，证明在该问题设定下骨干优化是可行且有效的。

#### 2. 主要技术方法

**(a) 3D 基础模型作为主骨干**

```
h_t = B_θ(O_t, ℓ)                        # 语言条件化的 3D 基础骨干
Ĝ_t⁺ = Q_ψg(h_t)                         # 几何预测头：未来深度/点图/相机参数
Â_t ~ π_ψa(· | h_t, ℓ, s_t)              # 动作解码器：flow-matching 生成动作 chunk
```

- 骨干 B_θ 实例化为 VGGT-Omega（2026 年的 3D 基础模型，联合估计多几何量）。
- 动作解码和几何预测头**都**建立在几何骨干的表征之上，几何不是传给另一个 VLM/视频骨干的前端特征。

**(b) 骨干内的语言条件化（Task Conditioning）**

- 在骨干的 global attention 层，把语言 token 拼接到所有图像/几何 token 之后：
  - `FrameAttn`：帧内注意力，不包含语言——保持帧局部处理的几何结构；
  - `GlobalAttn`：跨帧全局注意力，语言 token 在此与视觉/几何 token 交互。
- 这样指令融合只发生在全局层，帧内几何计算不被语言"污染"，但后续帧注意力层处理的是已被语言信息化的视觉特征。

**(c) 动作视界对齐的未来几何预测（Action-Horizon-Aligned Prediction）**

- 任务定义：t 时刻输入 x_t = (O_t, ℓ, s_t)，目标动作 chunk A_t = (a_t, ..., a_{t+Ha-1})。
- 设 t_f 为动作 chunk 最后一步对应的记录帧时间戳。E0.5 同时预测：
  - `G_t⁺ = (D_{t_f}, P_{t_f}, C_{t_f})`：未来帧的深度图、点图、相机参数。
- **关键对齐设计**：动作目标和世界状态目标描述**同一个交互区间**——几何预测的终点恰好是动作 chunk 的终点。这让"世界建模"有了控制相关的视界（control-relevant horizon）。
- 未来观测和几何**只作为训练监督**，推理时不需要，推理成本与普通策略相同。

**(d) Flow-Matching 动作生成**

- 动作解码器使用 flow-matching（类似 π0 系列的流匹配策略头）从几何表征生成连续动作 chunk。
- 层级化的"几何-动作注意力"（layer-wise geometry-action attention）让动作 token 逐层关注几何表征。

**(e) 全参数联合优化**

- 与 VGA 的 LoRA 不同，E0.5 解冻几何骨干，所有策略模块（骨干 + 几何头 + 动作头）端到端联合训练。
- 未来几何监督贯穿预训练全程，使几何基础在显式空间约束下学习操作相关的动力学。

#### 3. 算法流程和关键步骤

**训练流程**：
1. 输入当前多视角图像 O_t、指令 ℓ、机器人状态 s_t；
2. 语言条件化 3D 骨干计算 h_t（FrameAttn + GlobalAttn 交替）；
3. 几何头输出未来 t_f 时刻的 (D̂, P̂, Ĉ)，与真值未来帧几何计算损失；
4. 动作头以 flow-matching 生成动作 chunk Â_t，与真值动作计算流匹配损失；
5. 联合损失 L = L_action + λ·L_future_geometry，反向传播更新包括骨干在内的全部参数。

**推理流程**：
1. 同样计算 h_t（只需当前观测）；
2. 丢弃几何预测头，直接由动作头采样动作 chunk 执行；
3. 未来几何预测不增加任何推理开销。

**预训练流程（第二阶段）**：
1. 在 AgiBotWorld-Beta 的 160k+ 真机轨迹上预训练；
2. 联合学习"机器人动作 + 未来几何"；
3. 之后在 AgileX Piper 和 Zerith H1 两种不同本体上微调评估。

#### 4. 输入输出

- **输入**：多视角 RGB 图像 O_t、语言指令 ℓ、机器人本体状态 s_t。
- **训练时额外监督**：动作 chunk 末端帧的深度图 D、点图 P、相机参数 C，以及动作 chunk 真值。
- **输出（推理）**：长度 H_a 的动作 chunk（连续动作序列）。
- **输出（训练辅助）**：未来 3D 几何状态预测（仅训练用）。

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**分析**:

#### 1. 如何理解和表示空间

- E0.5 给出了一个激进答案：**空间就是计算的根基，而不是附加特征**。它把 DUSt3R/VGGT 一脉的"几何基础模型"从被动重建者改造成主动预测者——空间表征不仅描述"现在在哪"，还要内蕴"动作之后会在哪"。
- 空间动力学（spatial dynamics）被显式地表示为几何量的演化：深度场、点云、相机位姿的变化，而非像素/外观的变化。这是一种**剥离了外观的空间状态表示**。

#### 2. 如何处理空间关系

- "动作 → 几何后果"的因果映射被直接写在训练目标里：模型必须回答"执行这串动作后，场景的 3D 结构变成什么样"。
- 几何-动作注意力让每一步动作生成都以几何状态为条件，空间关系（物体位置、可达性、遮挡）天然蕴含在点图表征中。

#### 3. 对 Spatial AGI 的启发

- **"未来预测几何"可能是 Spatial AGI 的核心训练信号**：视频预测混杂了外观变化与几何变化，几何预测则直指空间智能的本质。E0.5 的 OOD 实验是强有力的证据——在分布外设定下，几何预测式 WAM 的成功率约为视频预测式基线的 30 倍。这说明几何抽象的泛化性远高于外观抽象。
- **3D 基础模型可以承载动作**：此前社区默认动作生成需要 VLM/视频骨干的语义和先验，E0.5 证明纯几何骨干在加入语言条件化后同样能生成高质量动作，甚至更好。这动摇了"VLM 必然是具身智能底座"的假设。
- **预测视界与控制视界对齐**是一个普适设计原则：无论导航、操作还是空间推理，让"想象的未来"与"计划的行动"在时间上对齐，可能显著提升表征的决策相关性。

#### 4. 可以应用的 Spatial AGI 场景

- **机器人操作**（论文验证场景）：E0.5 本身。
- **空间推理 VLM 的训练目标改造**：把"预测未来几何"作为辅助任务注入空间推理模型的预训练，可能比几何特征蒸馏（GLaD 类方法）更有效。
- **导航世界模型**：预测"走到某处后的场景几何"而非未来视频，可提升长视界导航的空间一致性。
- **世界模型的评估基准设计**：几何级未来预测可作为比视频级更纯净的世界模型评估信号。
- **Sim-to-Real**：几何表征对光照、纹理等外观变化不敏感，天然利于 sim-to-real 迁移。

### Q3: 主要创新点和局限性是什么？

**分析**:

#### 1. 主要创新点

1. **范式创新——几何原生 WAM**：首次把 3D 基础模型作为 WAM 的唯一主骨干（而非特征提供者），并且证明全参数微调可行（打破了 VGA 报告的"全参训练退化"结论）。
2. **目标创新——未来 3D 状态预测**：把 WAM 的预测目标从"未来视频"换成"未来几何"，并与动作 chunk 终点对齐。消融显示：
   - 比无几何重建版本 +9.43 个百分点；
   - 比当前帧重建版本 +7.93 个百分点；
   - OOD 设定下成功率约为视频预测基线的 **30 倍**。
3. **架构创新——骨干内语言条件化**：FrameAttn/GlobalAttn 分离的指令注入方式，在不破坏几何预训练结构的前提下实现指令跟随。
4. **实证贡献**：160k AgiBotWorld-Beta 轨迹的具身预训练让 Piper +15pp、Zerith H1 +7pp，证明几何原生基础可以吸收大规模机器人知识。

#### 2. 主要局限性

1. **外观信息丢失**：几何预测剥离了外观，但很多操作任务需要外观（液体多少、物体材质、可步行表面）。纯几何目标可能对需要视觉属性推理的任务不利。
2. **依赖多视角/良好观测**：VGGT-Omega 类骨干在遮挡严重、纹理弱、单目窄基线的真实场景下几何估计质量会下降，E0.5 的鲁棒性未见系统评估。
3. **动态场景与物体**：点图/深度预测的是整场景几何，对于被机器人推动后发生非刚体形变（布料、绳子）的物体，几何预测目标的有效性存疑。
4. **命名暗示的不完整**：E0.5/E1.0 的版本号暗示这是中间形态；当前只在桌面级操作任务验证，长视界、多房间、移动操作尚未涉及。
5. **计算成本**：全参数微调一个 3D 基础模型 + 160k 轨迹预训练，训练成本显著高于 LoRA 方案。

#### 3. 与其他相关工作的对比

| 维度 | OpenVLA / π0.5 (VLA) | PAR / DreamZero (视频WAM) | VGA (3D骨干+LoRA) | **E0.5** |
|---|---|---|---|---|
| 主骨干 | VLM | 视频扩散 | 3D 基础模型 | 3D 基础模型（VGGT-Omega） |
| 几何角色 | 特征融合/蒸馏 | 无 | 原生，但只重建当前 | **原生 + 预测未来** |
| 预测目标 | 无（仅动作） | 未来视频 | 当前几何 | **未来几何 + 动作** |
| 骨干训练 | 微调 | 微调 | LoRA | **全参数联合优化** |
| OOD 泛化 | 一般 | 基线（1x） | 未报 | **约30x基线** |
| 推理开销 | 有语义开销 | 需生成视频 | 低 | 低（几何头仅训练用） |

- **优势**：泛化性（OOD）、推理效率、表征与任务的本质对齐。
- **劣势**：语义先验弱于 VLM 系（语言理解依赖较浅的条件化）、外观建模缺失、动态场景待验证。

## 核心技术发现

- **发现1**：几何骨干可以被"重编程"为预测式世界模型——预训练的重建能力并不与预测能力冲突，反而互相增强。
- **发现2**：动作 chunk 终点对齐的几何预测比"当前帧重建"高约 8pp，说明**预测性监督的价值在于时间视界**，不在于几何信息本身。
- **发现3**：OOD 泛化的数量级优势（30x）是本文最强证据：几何抽象 > 外观抽象，在分布偏移下尤其如此。
- **发现4**：语言可以通过 global attention 轻量注入几何骨干而无需 VLM，指令跟随能力与几何原生性可以共存。

## 与Spatial AGI的关系

### 直接贡献
提供了 Spatial AGI 技术栈中"动作生成层"的一个新基础范式：几何原生、预测式、控制对齐。

### 技术启发
- 未来几何预测可作为通用 Spatial AGI 模型的辅助目标（类似"几何版的 next-token prediction"）。
- "预测视界 = 控制视界"原则可推广到所有具身空间智能系统。

### 应用场景
机器人操作、导航世界模型、空间推理数据引擎、sim-to-real 迁移。

## 个人思考

### 最令人兴奋的发现

30 倍 OOD 优势这个数字值得反复咀嚼。视频预测 WAM 学到的是"像素如何流动"，其中绝大部分容量花在与控制无关的外观细节上；几何预测强迫模型只保留"空间结构如何演化"。这几乎是一个信息论层面的论证：**控制相关的信息是几何的，不是外观的**。如果这个结论在更多任务上成立，那么整个"视频生成模型作为世界模型"的路线可能只是一个过渡形态，终点是几何（或几何+语义）原生世界模型。

另一个有趣点是版本号：E0.5 明显在向 π0.5 致敬并宣示对标——"VWA（Vision-World-Action?）/几何原生家族"的自我定位，暗示团队后续会有 E1.0，可能解决动态物体和长视界问题。

### 潜在局限

- 几何预测目标在非刚体、流体、遮挡密集场景的退化值得警惕；
- 语义理解较浅：复杂长指令（"把干净的那个杯子放到微波炉旁边"）可能超出几何骨干语言条件化的能力；
- 30x 的 OOD 数字来自特定评估设定，需要看任务细节才能判断普适性。

### 与近期研究的关联

- 与 **UNITAS（10-10，3D-Native WAM）**、**VGA**、**Geometric WM 系列一脉相承**：3D 原生 WAM 正在从"用 3D 特征增强 VLA"（7-9 月主流）转向"3D 骨干直接承载动作"（10 月新趋势）。E0.5 是这条路线目前最强的实证。
- 与昨天分析的 **Probing Spatial State Representations in VFM**（11-01_03）形成有趣呼应：那篇论文发现 VFM 表征中"空间状态的持续性和可行动性"依赖相机位姿读出——E0.5 直接把位姿/点图作为一等公民预测目标，从架构上回应了这一发现。
- 与 **AEON（10-24，统一视频与3D世界模型）** 相比，E0.5 更激进（完全抛弃视频分支），AEON 更保守（保留双分支）。未来哪个方向胜出值得跟踪。

## 总结

### 核心发现总结

E0.5 证明了两件事：其一，3D 基础模型可以直接作为世界-动作模型的主骨干并被全参数地改造为预测式模型；其二，"预测动作视界末端的几何状态"这一训练信号比当前重建和未来视频预测都更有效，尤其在分布外泛化上呈现数量级优势。

### 对Spatial AGI的意义

这是"几何原生 Spatial AGI"路线的里程碑：空间智能的表示、预测、行动可以在同一个几何基础模型内闭环。如果后续工作把语义（VLM 分支）与几何预测目标在统一骨干中结合，几何原生 WAM 可能成为通用空间智能的最终形态候选。

## 深度扩展分析

### A. 技术架构逐模块拆解

#### A.1 语言条件化 3D 骨干（B_θ = VGGT-Omega）

VGGT 系列骨干的原始设计是交替的 Frame Attention（帧内）与 Global Attention（跨帧），最终输出每帧的深度、点图、相机参数、跟踪点等。E0.5 的改造点非常克制：

1. **只在 Global Attention 引入语言 token**：`GlobalAttn([Concat_i Z̃_i; L])`。语言 token 数量相对图像 patch token 极少（通常 <100 vs 数千），因此不显著增加注意力开销。
2. **Frame Attention 保持纯视觉**：帧内几何结构的计算（对应局部对应、深度估计）不被语言干扰，保住了几何预训练学到的局部归纳偏置。
3. **信息流方向**：语言 → global 层 → 影响后续 frame 层的输入 → 帧级特征被语言调制。这是一种"先全局对齐、再局部细化"的条件化顺序。

**设计哲学评价**：这种最小侵入式改造是 E0.5 能全参数微调成功的重要前提——它没有改变骨干的计算图拓扑，只是往全局层加了 token。VGA 全参训练退化的原因可能正是改造过于激进（如插入新的跨模态模块）破坏了几何预训练结构。

#### A.2 未来几何预测头（Q_ψg）

- 预测三元组 (D̂_{t_f}, P̂_{t_f}, Ĉ_{t_f})：深度图描述可见表面布局、点图描述 3D 空间配置、相机参数描述成像几何。
- 论文明确说明"不要求每个量有独立头"，即可以共享头 + 多任务解码。
- 损失设计（从论文推断）：深度用 scale/shift-invariant 或相对损失，点图用 L2/L1，相机参数可能用旋转/平移的几何一致损失。三者共同约束的是**同一个未来场景**，互为正则。

**关键洞察**：点图（pointmap）作为预测目标比深度更强——它同时编码几何与跨视角对应。未来点图预测本质上是"预测未来的 DUSt3R 输出"，这把几何基础模型的预训练目标形式原封不动地平移到了未来时态。

#### A.3 Flow-Matching 动作头 + 几何-动作注意力

- Flow matching 是当前 WAM/VLA 动作头的主流（π0、GR00T 等）：学习从噪声分布到动作分布的向量场，采样质量高、推理步数少。
- "Layer-wise geometry–action attention"：动作 token 不只看最终汇总特征，而是逐层与几何表征交互。这与 cross-attention 注入条件的主流做法一致，但强调几何信息在**每个抽象层级**都可用。
- 推理时动作头独立工作，几何头丢弃——**训练信号与推理成本解耦**是该设计最优雅之处。

#### A.4 联合优化与损失权重

L_total = L_action(流匹配) + λ_g · L_future_geo

λ_g 的平衡是隐含的关键超参：几何损失梯度太大可能破坏动作生成（表征被拉向重建任务），太小则失去预测监督价值。论文未详细公开消融，但从"未来预测 +7.93pp vs 当前重建"看，监督信号的时间属性是主要增益来源，而非几何损失的正则效应。

### B. 实验设定深度解读

#### B.1 RoboTwin 2.0 仿真结果

- clean 89.90% / randomized 50.09%：随机化设定腰斩，说明即使几何原生模型对视觉-物理随机化（光照、纹理、物体位姿）仍有明显脆弱性。50% 的 randomized 成功率在当前 WAM 中属正常偏上，并非压倒性。
- 亮点在于这是**零具身预训练**的结果——纯靠 VGGT-Omega 的几何先验 + 少量微调。

#### B.2 OOD 30x 的含义

需要谨慎解读：30 倍是相对视频预测 WAM 基线在**特定 OOD 设定**下的比值。若基线成功率只有 ~1-2%，30x 即 30-60%，绝对值并不惊人。但它揭示了趋势：视频预测模型在 OOD 下几乎是灾难性失败（学到的是外观捷径），几何模型的失败是渐进的。这个"失败模式的质量差异"比比值本身更有价值。

#### B.3 真机预训练收益的不对称

Piper +15pp vs Zerith H1 +7pp：两种本体架构不同（Piper 是协作臂，H1 应为人形/不同末端），收益减半说明几何原生预训练的知识迁移存在本体鸿沟。几何表征本身是本体无关的，但动作分布、运动学约束是本体相关的——预训练动作知识只部分迁移。

### C. 与 Spatial AGI 理论框架的对接

#### C.1 空间智能的层次与 E0.5 的位置

按"感知 → 表征 → 预测 → 推理 → 行动"的空间智能栈：

- 感知/表征层：由 VGGT-Omega 预训练承担（成熟）
- 预测层：E0.5 的核心贡献（未来几何）
- 推理层：较薄弱（仅指令条件化，无显式空间推理链）
- 行动层：flow-matching 动作头（成熟）

E0.5 把栈的中枢从"VLM 语义空间"搬到了"几何空间"，但推理层仍是短板。几何空间内如何做符号化/组合化推理（如物体关系、可供性）是开放问题。

#### C.2 "几何作为世界模型的接口"假说

E0.5 提供的实证支持了一个更强假说：**世界模型的最小充分接口是几何 + 语义标注，而非像素**。视频世界模型的全部价值可以被分解为：
1. 几何演化（E0.5 直接预测）
2. 外观/材质/光照（与控制无关或低相关）
3. 语义属性（可用语言条件化注入）

若假说成立，Spatial AGI 的世界模型应该是"几何主干 + 可插拔属性预测头"的 modular 架构，而不是端到端视频生成器。

#### C.3 与认知科学的双过程对照

- 视频/外观预测 ≈ 表象式想象（image-like mental imagery）
- 几何未来预测 ≈ 空间布局式想象（spatial layout imagination）

人类空间认知研究（如脑损伤病人的分离性证据）表明布局想象与视觉想象是可分离的能力，且布局想象与行动规划更紧密耦合。E0.5 的结果意外地与这一认知科学图景吻合。

### D. 可复现性与工程细节评估

- **数据**：AgiBotWorld-Beta 公开，RoboTwin 2.0 公开，可复现性较好。
- **骨干**：VGGT-Omega 为 2026 年模型（VGGT 的机器人/操作特化版？），公开权重情况待确认。

### E. 潜在后续方向预测

1. **E1.0**：加入动态物体/铰接物体的几何预测（预测点图 → 预测物体级 6D 轨迹场）。
2. **几何 + 语义统一**：把 VLM 语义 token 也作为 global attention 的一部分联合训练，形成真"VWA"（Vision-geometry-language-Action）。
3. **导航扩展**：把动作 chunk 从机械臂轨迹换成机器人基座轨迹，未来几何预测变成"ego-motion 后的场景几何"，直接对接 NavWM 类工作。
4. **几何预测作为评估器**：训练好的几何预测头可用于 rollout 评估——想象的动作序列对应的几何是否合理，作为 verifier 过滤动作。
5. **与 3DGS 结合**：未来点图可直接栅格化为 3D 高斯/点云场景记忆，与空间记忆类工作（GaussMemory、Slot3R）串联成完整系统。

### F. 批判性视角

1. **数据引擎依赖**：AgiBotWorld-Beta 的轨迹质量与多样性决定了预训练上限，E0.5 的收益有多少来自方法、多少来自数据，需要同数据下的公平基线对比。
2. **仿真 benchmark 偏置**：RoboTwin 类仿真中相机位姿已知且稳定，真实场景相机漂移/标定误差对点图预测的影响被低估。
3. **"预测未来几何"的监督成本**：需要训练数据带未来帧几何真值（深度/位姿），这限制了可用数据集范围（大量人类视频数据没有真值几何）。用伪标签（如用 VGGT 自身标注未来帧）可以缓解但引入自举偏差。
4. **与纯 VLA 的语义差距**：在需要开放词汇理解的任务上（如指令含罕见物体类别），几何骨干的语言条件化可能远弱于 VLA 的 LLM 语义模块。论文未测语言复杂度分层。

### G. 对个人研究议程的启示

- **监督信号设计 > 架构设计**：E0.5 的最大增益来自换了一个监督信号（未来几何），而非新架构。这再次验证"目标函数是第一性"的经验法则。
- **对齐原则的可推广性**：动作视界对齐几何预测 → 可推广为"任何辅助预测目标都应与决策视界对齐"。
- **观察 3D 原生 WAM 生态**：UNITAS、E0.5、VGA 构成 2026 Q4 的 3D 原生 WAM 三部曲，值得做一篇专门的对比笔记。

### M. 方法论复盘：为什么"简单改动"能赢

回顾 E0.5 的全部改动清单，你会发现它没有任何"大动作"：

1. 没有发明新架构（骨干就是 VGGT-Omega 原封不动）
2. 没有新的大规模数据（AgiBotWorld-Beta 是公开数据集）
3. 没有新的训练范式（联合多任务 + flow matching 都是成熟技术）
4. 唯一的"新"是两个位置互换：几何从配角变主角、预测从当下变未来

这种"位置互换式创新"在深度学习史上反复出现且成功率高：
- ResNet：把恒等映射从"需要学习"变为"默认存在"
- MAE：把遮蔽从数据增强变为预训练目标
- DUSt3R：把多视图几何从"两阶段流水线"变为"直接回归"
- E0.5：把几何从"VLA 的输入"变为"WAM 的本体"

**经验法则**：当一个组件长期被当作辅助存在时，把它提升为第一性对象，往往能解锁数量级的收益——因为它改变了梯度的流向，让大容量模型的所有参数都直接为该对象服务。

### N. 风险对冲视角：什么证据会推翻 E0.5 的结论

科学上要问反面：什么实验结果会让"几何原生"路线失效？

1. **语义任务失败**：若在语言复杂度分层的 benchmark 上，E0.5 在长指令/开放词汇任务上大幅落后 VLA，说明几何骨干无法承载语义，需要混合骨干，"纯几何原生"叙事破产。
2. **伪标签未来几何**：若未来几何只能依赖真机真值监督（人类视频不可用），则数据规模天花板被锁死，几何预训练的数据优势（互联网级）无法兑现。
3. **外观依赖任务**：若操作任务评测中加入材质/透明度/液位判断，几何原生模型系统性失败，则需要外观分支，回归 AEON 式双分支。
4. **视频派反击**：若视频 WAM 通过几何一致性正则（如 DepthWorld 类约束）也达到同等 OOD 鲁棒性，则"换骨干"不是必要的，"加约束"即可——这会削弱 E0.5 的架构叙事但保留其监督信号洞察。

以上四个方向都是值得持续跟踪的"判决性实验"。

### T. 术语表

- **WAM (World-Action Model)**: 世界-动作模型，联合建模动作与未来世界状态。
- **Geometry-native**: 几何原生，指 3D 几何模型直接作为主骨干而非辅助模块。
- **Pointmap**: 点图，每个像素对应的 3D 空间点坐标图，DUSt3R 系列的核心输出。
- **Flow matching**: 流匹配，学习概率密度间向量场的生成建模方法。
- **Action chunk**: 动作块，一次预测的多步连续动作序列。
- **OOD (Out-of-Distribution)**: 分布外，测试分布偏离训练分布的泛化设定。
- **AgiBotWorld-Beta**: 智元机器人发布的开源大规模真机操作数据集。
- **RoboTwin 2.0**: 双臂机器人仿真 benchmark，支持域随机化评测。
