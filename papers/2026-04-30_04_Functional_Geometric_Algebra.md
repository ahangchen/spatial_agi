## 摘要

### 核心主张

本文主张**几何代数（Geometric Algebra, GA）**——特别是**Clifford代数**——为语义表示提供了数学上更优越的基础。功能几何代数（FGA）框架将GA扩展为类型化的组合语义，能够支持推理、变换和可解释性，同时完全兼容分布式学习和现代神经架构。

### 核心贡献

1. **数学基础**：将Clifford代数引入自然语言语义学作为基础表示框架
2. **结构化表达**：将n维嵌入空间扩展为2^n维的多向量代数，基础语义概念和高阶交互在单一、原则性的代数框架中表示
3. **类型系统**：利用GA的分级结构建立内在的语义类型层次
4. **组合机制**：提供明确的操作符（收缩、楔积、转子变换等）来建模谓词应用、角色绑定和类型强制

### 核心论点

**中心论点不仅仅是增加维度，而是增加结构组织**：GA在多向量代数中将基础语义概念及其高阶交互组织在单一、原则性的代数框架中。

## 引言

### 背景

分布式和神经方法在自然语言语义学中几乎完全建立在传统的线性代数基础上：向量、矩阵、张量及其伴随操作。这些方法取得了显著的经验成功，但在组合语义、类型敏感性和可解释性方面面临持续的结构限制。

### 线性代数的四大局限

#### 1. 结构化组合的弱点

向量加法、拼接和双线性映射**没有内在编码语义组合的模式**。无论动词与主语结合、形容词修饰名词，还是量词对谓词起作用，代数操作都相同：学到的矩阵乘法。组合结构必须完全从数据中诱导。

这是自Frege以来理解的含义是组合性的领域的奇怪情况。

#### 2. 高阶交互的参数膨胀

建模超越成对相似性的交互——三元关系、事件结构、辖域歧义——需要更深的网络、额外的张量参数或明确的架构机制（如多头注意力）。交互结构隐含在权重中，而不是在代数中明确。

#### 3. 对类型的内在支持有限

自然语言含义从根本上说是类型化的：实体、谓词、命题、事件和修饰语在类型上不同，不仅仅在共享向量空间中的方向上。标准LA没有维持类型区别的本地机制；这些必须通过架构选择从外部施加。

在形式语义学工作的人会立即认识到其代价：没有类型，没有原则性的方法说"John sleeps"形式良好而"*Sleeps John very"不。

#### 4. 难以集成符号和几何结构

形式语义理论提供组合规则、变量绑定、量化和推理，但操作于离散结构。分布式模型提供连续相似性和基于梯度的学习，但缺乏逻辑结构。在标准LA的限制内桥接两者已被证明极其困难。

### 解决方案主张

本文主张**几何代数（GA）**，特别是Clifford代数Cl(V,Q)，为语义表示提供了更具表现力的数学基底，同时解决所有四个限制。此外，**功能几何代数（FGA）框架**将GA扩展为类型化的组合语义，其中词汇含义、组合结构和上下文调制都在单一代数中表达。

## 核心问题分析

## Q1: 核心算法原理

### 1.1 核心思想和动机

#### 问题诊断

传统线性代数在自然语言语义学中的根本问题是：**代数结构与语言结构不匹配**。

具体表现为：
- **运算单一化**：不同的语义组合模式（动词-主语、形容词-名词、量词-谓词）使用相同的代数操作
- **类型扁平化**：实体、谓词、命题等不同语义类型都映射到同一向量空间
- **关系隐式化**：角色绑定、参数方向、类型强制等结构信息必须从数据中学习

#### 解决方案

**几何代数（GA）**提供了一个结构丰富的代数框架，其内在结构与语言结构天然匹配：

1. **分级结构**对应类型层次
2. **多向量表示**可以同时包含不同等级的语义信息
3. **明确的代数操作**对应不同的组合模式
4. **可恢复性**代数运算允许提取和回溯结构

### 1.2 主要技术方法

#### 几何积

对于向量空间V中的两个向量a, b，几何积分解为：

```
ab = a·b (标量，grade 0) + a∧b (双向量，grade 2)
```

**关键特性**：
- **第一项** a·b：熟悉的对称内积——语义相似度
- **第二项** a∧b：楔（外）积，反对称量（a∧b = -b∧a），表示a和b张成的有向平面
- **同时保留**：几何积在单个代数对象中同时保留这两部分信息

**语义意义**：
- 内积捕获相似性
- 楔积捕获方向和关系信息——内积丢弃的信息
- 这种分解使GA能够在一次操作中同时建模相似性和结构

#### Clifford代数

**定义**：设V是配备二次型Q: V → ℝ的实向量空间，维度为n。Clifford代数Cl(V,Q)是由V生成的结合代数，满足基本关系：

```
v² = Q(v) 对所有 v ∈ V
```

对于正交基{e₁, ..., eₙ}，这意味着：

```
eᵢeⱼ = -eⱼeᵢ (i≠j),  eᵢ² = Q(eᵢ)
```

**签名（signature）**：二次型Q决定签名(p, q, r)，其中p个基向量平方到+1，q个到-1，r个到0，p+q+r=n。

**语义意义**：
- **混合签名**：正向平方生成器可以编码空间、外延或相似性保持特征；负向平方生成器可以编码内涵、模态或对比特征
- **零生成器**：用于投影构造，如GATr使用的投影几何代数Cl(3,0,1)
- **签名作为设计参数**：语义空间的设计参数，不仅仅是数学技术性

**转子和旋转**：
- 由双向量生成的转子的类型取决于双向量的平方符号
- 负平方双向量生成椭圆转子（平滑、循环旋转）
- 正平方双向量生成双曲转子（非循环、沿轴拉伸或压缩）

#### Grade（分级）结构

任何多向量M ∈ Cl(V,Q)唯一分解为grade投影之和：

```
M = Σₖ⟨M⟩ₖ
```

其中⟨M⟩ₖ是M的grade-k投影。

**维度**：对于n维基础向量空间，Cl(V,Q)有2ⁿ个基元素，按grade组织：

```
grade 0: 1 个标量
grade 1: n 个向量
grade 2: C(n,2) 个双向量
...
grade n: 1 个伪标量
```

**语义意义**：
- **Grade对应类型**：grade 0 → 真值，grade 1 → 实体/一元谓词，grade 2 → 二元关系，grade n → n元谓词
- **内在类型系统**：grade结构是代数强制执行的，不是外部施加的
- **类型算术**：grade投影⟨·⟩ₖ提供提取和类型检查

### 1.3 算法流程和关键步骤

#### 四个核心操作

**(1) 内积**

```
a·b = ⟨ab⟩₀
```

- 提取几何积的标量（grade-0）部分
- **语义用途**：相似度度量、完全谓词应用
- **类型转换**：Cl¹ × Cl¹ → Cl⁰ (一元谓词×实体 → 真值)

**(2) 楔积**

```
a∧b = ⟨ab⟩₂ (对于向量)
```

- 提取双向量（grade-2）部分
- **反对称性**：a∧b = -b∧a，内在编码参数顺序
- **语义用途**：角色-填充子绑定，如r_agent ∧ john

**(3) 左收缩**

对于grade-j元素A和grade-k元素B（j≤k）：

```
A ⌟ B = ⟨AB⟩ₖ₋ⱼ
```

- B的grade减少A的grade，A从左侧作用
- **语义用途**：函数应用，grade-1实体向量收缩到grade-2关系双向量产生grade-1一元谓词
- **类型转换**：Cl¹ ⌟ Cl² → Cl¹

**(4) 右收缩**

```
B ⌞ A = ⟨BA⟩ₖ₋ⱼ
```

- B的grade减少A的grade，A从右侧作用
- **语义用途**：编码二元关系的不同参数位置
- **非对称性**：a⌟B ≠ B⌞a，编码参数方向性

**(5) 转子夹积变换**

```
x′ = R x R̃
```

其中R是转子（偶数grade元素，满足R R̃ = 1），R̃是R的逆。

**关键特性**：
- **Grade保持**：如果x是向量，x′也是向量
- **范数保持**：|x′| = |x|
- **可逆**：x = R̃ x′ R
- **可组合**：先应用R₁再应用R₂等价于应用R₂R₁

**语义用途**：
- 类型强制和上下文调制
- 在grade子空间内旋转表示以转换其解释而不改变其本体类别
- 经典的生成性词典例子："begin the book"将"book"强制转向其telic quale"reading"

#### 组合流程

**基本谓词应用（一元）**：

```
⟦P(x)⟧ = P·x ∈ Cl⁰ (标量/真值)
```

**二元谓词应用（柯里化）**：

```
ℓ ⌞ m = ℓₘ ∈ Cl¹ ("love Mary"作为一元属性)
j ⌟ (ℓ ⌞ m) ∈ Cl⁰ ("John loves Mary"作为真值)
```

收缩序列：Cl² ⌞→m Cl¹ ⌟→ⱼ Cl⁰对应类型归约e→(e→t)依次应用于两个参数。

**内应用（选择性组合）**：

```
⟦P(arg)⟧ = P ⌟ (R_Q ⟦arg⟧ R̃_Q)
```

其中R_Q是编码quale Q（Telic、Constitutive、Agentive、Formal）的转子。

- **两步过程**：首先，quale定向转子变换参数的多向量，前景化相关子空间组件；然后收缩饱和参数位置
- **外应用**：当R_Q是单位元时，内应用归约为外应用（经典函数应用）
- **内应用**：谓词探测参数的内部组织并提取它需要的方面

### 1.4 输入输出

#### 输入

**词汇项**表示为多向量：

- **实体**（proper名词、限定描述）：grade-1向量，在实体子空间V_E中
  ```
  ⟦John⟧ = j ∈ Cl¹(V_E), |j| = 1
  ⟦the book⟧ = b ∈ Cl¹(V_E), |b| = 1
  ```

- **一元谓词**（不及物动词、普通名词、一元形容词）：grade-1向量，在V_E⊕V_P中
  ```
  ⟦run⟧ = R ∈ Cl¹(V_E⊕V_P)
  ⟦human⟧ = H ∈ Cl¹(V_E⊕V_P)
  ⟦happy⟧ = S ∈ Cl¹(V_E⊕V_P)
  ```
  V_E组件编码选择信息，V_P组件编码谓词自身语义内容

- **二元关系**（及物动词）：grade-2双向量，在V_E⊕V_P中
  ```
  ⟦love⟧ = ℓ ∈ Cl²(V_E⊕V_P)
  ⟦kick⟧ = K ∈ Cl²(V_E⊕V_P)
  ⟦read⟧ = ρ ∈ Cl²(V_E⊕V_P)
  ```
  作为双向量，它们是有向平面，方向编码哪个参数位置是哪个

#### 输出

**语义组合结果**根据组合模式返回不同grade的结果：

- **真值**（grade 0标量）：完全饱和的谓词应用
  ```
  ⟦Mary laughs⟧ = L·m ∈ Cl⁰
  ⟦John loves Mary⟧ = j ⌟ (ℓ ⌞ m) ∈ Cl⁰
  ```

- **部分应用结果**（grade 1向量）：部分饱和的二元关系
  ```
  ℓ ⌞ m = ℓₘ ∈ Cl¹ ("love Mary"作为一元属性)
  ```

- **修饰结果**（grade 1向量）：经转子变换的表示
  ```
  ⟦good knife⟧ = G ⌟ (R_telic ⟦knife⟧ R̃_telic)
  ```

## Q2: 与Spatial AGI的关系

### 2.1 如何理解和表示空间

#### 空间作为代数签名

在FGA中，**空间概念**可以通过Clifford代数的签名设计来编码：

**正向平方子空间**（eᵢ² = +1）：
- 编码空间、外延或相似性保持特征
- 对应可逆、保持的操作
- 建模：欧几里得空间、距离、方向

**负向平方子空间**（eᵢ² = -1）：
- 编码内涵、模态或对比特征
- 对应非循环、有损的操作
- 建模：定性关系、状态变化、可能性

**零平方子空间**（eᵢ² = 0）：
- 用于投影构造
- 建模：齐次坐标、无穷远点

#### 空间概念的等级编码

**Grade 0**：标量
- 真值：空间状态的存在性
- 度量：距离、面积、体积

**Grade 1**：向量
- 点位置、方向、速度
- 空间实体

**Grade 2**：双向量
- 定向平面、区域
- 二元空间关系（在、之上、之间）
- 有向面积元素

**Grade 3**：三向量
- 定向体积、体素
- 三元空间关系（在...之间、从...穿过）
- 体积元素

#### 示例：空间谓词编码

```
⟦in⟧ = ℓ_in ∈ Cl²(V_spatial⊕V_rel)
⟦above⟧ = ℓ_above ∈ Cl²(V_spatial⊕V_rel)
⟦through⟧ = ℓ_through ∈ Cl³(V_spatial⊕V_rel)
```

其中V_spatial是空间特征子空间，V_rel是关系内容子空间。

### 2.2 如何处理空间关系

#### 角色填充子绑定

**楔积**提供空间关系的参数绑定机制：

```
⟦in⟧(box, ball) = ⟦ℓ_in ⌞ ball⟧ ⌟ box
                      = (ℓ_in ⌞ b) ⌟ x ∈ Cl⁰
```

**过程**：
1. 右收缩（⌞）饱和"容器"参数位置：ℓ_in ⌞ b ∈ Cl¹（"in ball"作为空间区域）
2. 左收缩（⌟）饱和"内容物"参数位置，返回真值

**方向性**：楔积的反对称性确保box和ball的角色区分清楚：
```
⟦in⟧(box, ball) ≠ ⟦in⟧(ball, box)
```

#### 复杂空间推理

**组合空间关系**：多向量的组合允许链式空间推理：

```
⟦in⟧(⟦above⟧(shelf), book)
```

通过收缩和楔积的组合，可以表示复杂的空间配置。

#### 类型强制

**空间类型强制**：通过转子实现：

```
⟦the box⟧ (实体) → ⟦region_of(box)⟧ (空间区域)
```

转子R_entity→region在实体子空间和空间区域子空间之间旋转。

### 2.3 对Spatial AGI的启发

#### 启发1：统一的代数框架

FGA为**空间和语言**提供统一的代数框架：

- 空间表示和语言语义在相同的Clifford代数中编码
- 空间推理和语义推理使用相同的操作
- 消除符号空间表示和连续向量表示之间的鸿沟

**对Spatial AGI的意义**：
- 支持跨模态推理（视觉-语言空间推理）
- 提供结构化的可解释性（grade投影、关系提取）
- 实现组合泛化（通过grade算术）

#### 启发2：内在的类型系统

FGA的**grade结构**提供内在的类型系统：

- 类型不是外部注解，而是代数强制执行的
- 类型转换通过grade归约（收缩操作）实现
- 类型错误通过grade不匹配自动检测

**对Spatial AGI的意义**：
- 保证空间推理的一致性
- 防止语义不合法的空间组合
- 提供自动类型检查机制

#### 启发3：可逆性和可恢复性

转子的**可逆性**和收缩的**可恢复性**：

- R̃ = R⁻¹允许精确恢复原始表示
- 楔积允许精确提取关系和参数
- 不会像向量叠加那样丢失信息

**对Spatial AGI的意义**：
- 支持回溯和错误纠正
- 允许分解复杂推理
- 实现可解释的空间推理链

### 2.4 可应用的Spatial AGI场景

#### 场景1：空间问答

**问题**："Is the red book on the shelf?"

**FGA表示**：
```
⟦on⟧(shelf, book) ⟦red⟧(book) ⟦book⟧ ⟦shelf⟧
```

**推理**：
1. 组合空间关系：on(shelf, book) → 真值
2. 组合属性：red(book) → 真值
3. 组合实体和关系，验证整个场景

#### 场景2：空间导航指令

**指令**："Go through the door, then turn right, and stop at the table"

### 3.1 主要创新点

#### 创新点1：统一的组合框架

**传统方法**：
- 分布式语义学：向量表示 + 双线性组合
- 形式语义学：类型逻辑 + 组合规则

## 从线性代数到几何代数

### 线性代数给予NLP的——以及它遗漏的

#### 线性代数提供什么

标准嵌入模型将词汇项表示为向量v ∈ ℝⁿ。测量语义相似性的基本操作是内（点）积：

```
a·b = Σᵢ aᵢbᵢ ∈ ℝ
```

这是一个标量：编码两个含义"对齐"程度的单个数字。

这极其有用——它驱动余弦相似度、注意力分数，以及基本上所有神经检索——但它也是有损的。两个向量与第三个具有相同点积但可以指向非常不同的方向。点积将两个向量之间的完整几何关系坍缩为单个数字，丢弃它们如何以及在什么平面中不同的所有信息。

#### 线性代数遗漏什么

**组合更加有限**。向量加法(a+b)、拼接([a;b])和学到的双线性映射(aᵀWb)是标准工具包，但这些操作都没有内在编码正在执行什么类型的组合。

**根本限制**：
- 无论是动词与主语结合、形容词修饰名词，还是量词对谓词起作用，代数操作都相同：学到的矩阵乘法
- 组合模式必须完全从数据中诱导
- 这是一个显著的限制——这是几何代数直接解决的

**重要澄清**：
这个限制不是特定于像Word2Vec或GloVe这样的静态嵌入，其不充分性对于组合性已被充分建立，这是移向语境模型的主要动机。我识别的限制是结构性的：它关于向量空间基底本身。

**BERT和GPT的限制**：
- BERT和GPT将含义表示为ℝⁿ中的向量，通过学到的矩阵乘法和注意力操作组合它们——完全相同的代数工具包，应用于语境化而非静态
- 语境化解决了固定词表示的问题，但不解决代数操作没有本地绑定、类型、定向组合或可恢复结构的更深问题
- 即使向量化语境化，平面向量空间的组合限制仍然持续，这些是代数限制，FGA针对它们

### 几何积：一个操作中的相似性和结构

对于向量空间V中的两个向量a, b，几何积分解为：

```
ab = a·b (标量，grade 0) + a∧b (双向量，grade 2)
```

**第一项** a·b：熟悉的对称内积——LA提供的相同标量相似度。

**第二项** a∧b：楔（或外）积：一个反对称量（a∧b = -b∧a），表示a和b张成的有向平面。其幅度是由两个向量形成的平行四边形的面积；其符号编码哪个向量先来。

- 如果a和b平行，a∧b = 0
- 如果a和b正交，a∧b最大

**楔积恰好捕获点积丢弃的方向和关系信息。**

#### 关键洞察

几何积ab在单个代数对象中同时保留这两部分信息。

这**不是拼接或元组**——它是一个代数中一个结构化元素，其中这些组件在乘法下相互作用。

#### GA中的加法注记

熟悉超维计算或向量符号架构的读者可能在这种背景下想知道"加法"意味着什么，因为像α + v + B这样的多向量似乎在"相加"不同类型的对象（标量、向量、双向量）。

**答案**：这不是VSA意义上的捆绑。

- 在HDC/VSA中，添加两个超向量在同一空间中产生噪声叠加，并且随着更多项被捆绑，相似性检查退化
- 在GA中，跨越grades的加法是直和：标量、向量和双向量组件居住在Clifford代数的代数正交子空间中，并且将它们组合成单个多向量时不会丢失或模糊信息
- 每个grade组件可以随时通过grade投影⟨M⟩ₖ干净地提取

"加法"是形式簿记——将不同信息打包成一个代数对象的方式——而不是有损叠加。**VSA捆绑本质上有噪声，GA加法是精确的。**

### Clifford代数：形式框架

采用主要经典处理中的标准定义和符号。

#### 定义2.1（Clifford代数）

设V是配备二次型Q: V → ℝ的实向量空间，维度为n。Clifford代数Cl(V,Q)是由V生成的结合代数，受基本关系约束：

```
v² = Q(v) 对所有 v ∈ V
```

对于正交基{e₁, ..., eₙ}，这意味着：

```
eᵢeⱼ = -eⱼeᵢ (i≠j),  eᵢ² = Q(eᵢ)
```

#### 签名语义

二次型Q决定签名(p, q, r)，其中p个基向量平方到+1，q个到-1，r个到0，p+q+r=n。

**为什么这重要？**

"负向"生成器——满足eᵢ² = -1的q个基向量——在任何空间意义上不是"负维度"。它们是二次型负定的方向：沿着这样的方向平方向量产生-1而不是+1。

与闵可夫斯基时空的类比是合适的，并且值得明确：
- 在Cl(1,3,0)中，熟悉的度量t² - x² - y² - z²恰好是二次型
- 其中时间维度平方到+1，而三个空间维度平方到-1
- 符号差异正是编码时空因果结构的东西

**在FGA中**，我们可以类似地利用混合签名：
- 正向平方生成器可能编码空间、外延或相似性保持特征
- 负向平方生成器可能编码内涵、模态或对比特征
- 零生成器（r个平方到0的基向量）用于投影构造，如GATr使用的投影几何代数Cl(3,0,1)

**签名是语义空间的设计参数，而不仅仅是数学技术性。**

#### 代数后果

这个设计参数有代数后果，我将在论文中利用。

**示例**：
- 如果v居住在正向平方子空间（v² = +|v|²）而u居住在负向平方子空间（u² = -|u|²），那么由各一个子空间中的向量形成的双向量v∧u平方到正值：
  ```
  (v∧u)² = -v²u² = -(+|v|²)(-|u|²) = +|v|²|u|²
  ```

- 相比之下，由两个正向平方向量形成的双向量平方为负：
  ```
  (v₁∧v₂)² = -|v₁|²|v₂|² < 0
  ```

**符号差异决定**由双向量生成的转子的特征：
- 负平方双向量生成椭圆转子（平滑、循环旋转）
- 正平方双向量生成双曲转子（非循环、沿轴拉伸或压缩）

在第6.4节，我将展示这种区别直接映射到语义区别：
- **外延修饰**（循环、基于相似性）← 椭圆转子
- **内涵修饰**（非循环、功能导向）← 双曲转子

#### 直观解释

定义中的两个方程有直观解释。

**方程(3)** v² = Q(v)：
- 说在Clifford代数中平方向量产生标量
- 直觉上，一个方向的"自相似性"
- 这将代数与底层空间的几何联系起来

**方程(4)** eᵢeⱼ = -eⱼeᵢ 对于i≠j：
- 说两个不同基向量的乘积是反交换的
- 这是方向的代数来源：它使楔积反交换，使a∧b区别于b∧a，最终使GA能够内在编码参数顺序

这两个性质——标量自积和反交换叉积——从向量空间及其二次型生成整个Clifford代数。

#### 熟悉的示例：四元数

一个熟悉的例子：Cl(3,0,0)在3D欧几里得空间上生成代数。

**四元数**出现为偶子代数Cl⁺(3,0,0)：
- 三个单位双向量e₂e₃、e₃e₁、e₁e₂每个平方到-1
- 它们成对反交换
- 关键：它们的乘积彼此闭合，例如 (e₂e₃)(e₃e₁) = -e₁e₂

这种闭合使它们同构于Hamilton的{i,j,k}；通过适当的符号选择（例如 i = e₃e₂, j = e₁e₃, k = e₂e₁），恢复关系ij = k。

**重要澄清**：
- 上面 Quaternion 的例子故意简单
- 第一次接触这种材料的读者可能形成FGA是四元数应用的印象，这**不是**
- 四元数是四维子代数（Cl⁺(3,0,0) ≅ Cl(0,2,0)），仅处理3D中的旋转，没有别的
- 完整的Clifford代数Cl(V,Q)远更丰富：它包括从0到n的所有grades，支持任意维度和混合签名，并提供不仅转子，还有收缩（函数应用）、楔积（绑定）、grade投影（类型提取）和精确解绑——四元数没有的任何东西

**Quaternions 的例子**：
- 包含是因为它将不熟悉的代数连接到熟悉的对象
- 但FGA框架使用完整Clifford代数，其中四元数是特殊情况

### Grades：内置的类型系统

对于语义目的，Clifford代数最重要的结构性质是它的**分级分解**。

任何多向量M ∈ Cl(V,Q)唯一分解为grade投影之和：

```
M = Σₖ=₀ⁿ ⟨M⟩ₖ,  ⟨M⟩ₖ ∈ Clᵏ(V,Q),  dim Clᵏ(V,Q) = C(n,k)
```

我们写⟨M⟩ₖ表示M的grade-k投影——提取仅grade-k组件的操作。这类似于从复杂表达式中提取标量或向量部分；这将是本文中的中心符号工具。

#### 分级结构示例

使分级结构清晰，考虑最小非平凡例子。对于n=4，基{e₁,e₂,e₃,e₄}，完整Clifford代数Cl(4,0,0)有2⁴ = 16个基元素按grade组织：

**Grade 0（标量）**：1个
- α

**Grade 1（向量）**：4个
- e₁, e₂, e₃, e₄

**Grade 2（双向量）**：6个
- e₁e₂, e₁e₃, e₁e₄, e₂e₃, e₂e₄, e₃e₄

**Grade 3（三向量）**：4个
- e₁e₂e₃, e₁e₂e₄, e₁e₃e₄, e₂e₃e₄

**Grade 4（伪标量）**：1个
- e₁e₂e₃e₄

**一般元素**：Cl(4,0,0)中的一个多向量是所有16个基元素的线性组合：

```
M = α           (⟨M⟩₀)
  + v₁e₁ + ... + v₄e₄           (⟨M⟩₁)
  + B₁₂e₁e₂ + ... + B₃₄e₃e₄   (⟨M⟩₂)
  + T₁₂₃e₁e₂e₃ + ...           (⟨M⟩₃)
  + ωe₁e₂e₃e₄                  (⟨M⟩₄)
```

**grade结构不是符号产物——它是代数强制执行的。**

- 两个grade-1向量的几何积总是产生grade-0标量加上grade-2双向量
- 三个向量的楔积总是产生grade-3三向量
- 依此类推

#### 语义意义

这使GA具有"内置类型系统"：代数表达的grade由其输入的grades和应用的运算确定，就像语义表达的类型由其组成部分的类型和组合模式确定。

#### Grade-类型对应

表的右列暗示这为什么对语言学重要，我想在继续操作之前提请读者注意。

在形式语义学中，含义按类型组织：实体、真值、谓词、关系等。**grade层次提供这种类型结构的直接代数编码。**

- **Grade 0标量**：真值的自然位置——完全饱和谓词的最终结果
- **Grade 1向量**：表示实体或一元谓词
- **Grade 2双向量**：表示二元关系：它的两条"腿"对应两个参数位置，它的方向编码哪个是哪个（agent vs patient，例如）
- **关键后果**：将grade-2关系与grade-1实体收缩产生grade-1结果——一个参数饱和的一元谓词——镜像类型规则

代数自动进行类型簿记。这种对应在第4节形式开发，在第5节组合上工作。

#### 术语注记

本文中使用的术语"多向量"专门指上述Clifford代数意义：Cl(V,Q)的单个元素，由多个grades的组件组成。

这不应与信息检索文献中"多向量"的不相关使用混淆，其中它指将文档表示为单独向量的集合（每个标记一个），如ColBERT风格的晚期交互模型。在那个设置中，"多向量"是标准向量的集合；在我们的设置中，多向量是具有内部grade结构的单个代数对象。两个概念共享表面术语但有完全不同的数学内容。

#### Blades

相关术语，贯穿论文出现的是**blade**。

k-blade是可以表示为k个向量的外（楔）积的多向量：B = v₁∧v₂∧...∧vₖ。它表示向量空间的k维有向子空间。

每个blade是同质多向量——它有单个确定grade k——但不是每个grade-k多向量是blade（例如不同平面中两个双向量的和可能不能因式分解为单个楔积）。

**Blades是每个grade的"纯"元素**，它们在FGA中起重要作用：
- 角色-填充子绑定是双向量blades（r∧f）
- 动词模板是角色空间中的k-blades
- 概念可以建模为表示有向语义子空间的blades（第6.4节）

### 四个操作及其语义类比

多向量的四个操作对FGA框架是根本的。我将每个与其语义动机一起介绍，因为语言回报在每个情况下都是即时的。

#### (1) 内积

```
(a·b = ⟨ab⟩₀)
```

提取几何积的标量（grade-0）部分。

**语义用途**：
- 这是熟悉的点积——语义相似度
- 在FGA中，它也作为完全谓词应用的机制：当一元谓词与其参数收缩时，结果是真值（标量）

#### (2) 楔积

```
(a∧b = ⟨ab⟩₂ 对于向量)
```

提取双向量（grade-2）部分。

**反对称性**：a∧b = -b∧a，所以它内在编码参数顺序。

**语义用途**：
- 作为角色-填充子绑定：双向量r_agent∧j绑定agent角色到其填充子
- 反对称性确保角色和填充子被区分
- 这是Smolensky张量积变量绑定的GA类比，但在有界代数中而非无限膨胀的张量空间中

#### (3) 左收缩

```
A ⌟ B = ⟨AB⟩ₖ₋ⱼ
```

对于grade-j元素A和grade-k元素B，j≤k：B的grade减少A的grade，A从左侧作用。

**语义用途**：
- 函数应用的代数类比：grade-1向量（参数）收缩到grade-2双向量（二元关系）产生grade-1向量（一个参数饱和的一元谓词）

#### (4) 右收缩

```
B ⌞ A = ⟨BA⟩ₖ₋ⱼ
```

左收缩的镜像：B的grade减少A的grade，A从右侧作用。

**语义用途**：
- 左和右收缩**不等价**——a⌟B ≠ B⌞a——并且这种非对称性在语义上关键
- 对于二元关系ℓ ∈ Cl²，右收缩与参数m饱和一个参数位置（ℓ ⌞ m ∈ Cl¹），而左收缩结果与主语j饱和另一个（j ⌟ (ℓ ⌞ m) ∈ Cl⁰）
- 两个收缩编码谓词的两个不同参数位置，代数跟踪哪个是哪个
- 这直接编码参数方向性而不需要外部分类结构

#### (5) 转子夹积

```
x′ = R x R̃
```

通过在转子R和其逆R̃之间"夹心"变换多向量x。

转子是满足RR̃ = 1的偶数grade元素。

**夹积乘积性质**：
- **Grade保持**：如果x是向量，x′也是向量；如果x是双向量，x′也是双向量。本体类别被维持。
- **范数保持**：|x′| = |x|。概念的"幅度"不失真。
- **可逆**：x = R̃ x′ R。原始含义可恢复。
- **可组合**：先应用R₁再应用R₂等价于应用R₂R₁。变换链代数组合。

**语义用途**：
- 转子建模类型强制和上下文调制：在其grade子空间内旋转表示以转移其解释而不改变其本体类别
- 经典生成性词典例子——"begin the book"将"book"强制转向其telic quale"reading"——建模为作用于book的向量的转子

### GA vs. LA：并列比较

在此退一步看整个图景可能是有帮助的。下表总结标准NLP操作如何在两个框架之间映射：

| LA操作 | GA对应 | 语义意义 |
|---------|---------|----------|
| 内积 | ⟨ab⟩₀ | 相似度 |
| 向量加法 | 同grade加法 | 信息积累 |
| 矩阵向量乘法 | 收缩 | 谓词应用 |
| 拼接 | Grade-1 + Grade-1 | 组合（非结构） |
| 外积 | 楔积 | 关系绑定 |
| - | 转子夹积 | 类型强制 |

**比较的中心点**：
- 不是GA给LA添加操作
- 而是它统一它们
- 内积、楔积和收缩都是单个操作的不同方面——几何积——通过grade投影分解

**代数统一**：
- 使单一框架方法组合语义成为可能
- 这是我相信框架值得认真关注的原因

## 表达能力和参数效率

### 自然的反对

一个自然的反对立即出现：从n维移动到2ⁿ基元素看起来计算上禁止的。

我想直接处理这个担忧，因为答案既重要，我认为，也令人惊讶。

**关键反驳是结构性的：**

几何代数不添加任意参数；它在闭合代数结构内系统地组织交互。

### 具体检查

让我们具体检查情况。

**传统嵌入模型**（n=10）：
- 将每个词放置在ℝ¹⁰中
- 建模维对交互需要学习单独参数——双线性模型需要n×n权重矩阵（100参数），建模三路交互需要n×n×n张量（1000参数）
- 每个交互级别乘参数计数

**Clifford代数**（Cl(10,0,0)）：
- 有2¹⁰ = 1024个基元素按grade组织：1标量，10向量，45双向量，120三向量，等等
- **关键**：这1024维度在平坦向量意义上不是自由参数；双向量e₁e₂是e₁和e₂的反称积，它们的交互规则由几何积代数确定

**学习参数与代数约束**：
- 在学到的多向量嵌入中，每个grade的系数是训练期间的自由参数
- 但组合两个多向量的操作——一个表示的双向量组件与另一个的向量组件如何交互——由代数约束

**节省在组合时间而非表示时间。**

### 结构化信息"免费"

这意味着GA嵌入携带**结构化的高阶信息"免费"**：
- 词的多向量表示的双向量组件编码关系信息
- 三向量组件编码三路交互
- 依此类推，全部在单个代数对象中而非需要单独参数张量

**结果**：
表示比相同总维度的平面向量信息上更丰富，**因为其内部结构约束和组织组件如何在代数操作下交互。**

### 实践注记

对于神经实现，不需要表示完整的2ⁿ维多向量。

**Grade截断表示**仅保留grades 0通过k（对于小k）：
- 捕获语义最相关的结构
- 保持维度可管理

**示例**：
对于基础维度n=64（可比较小嵌入模型），保留grades 0-2给出：
1 + 64 + 2016 = 2081个组件——实质但远小于完整的2⁶⁴，并且丰富到在单个代数对象中编码实体、谓词和二元关系。

### 参数优势陈述

对于n维中的grade-k截断多向量：
```
组件数 = Σⱼ=₀ᵏ C(n,j)
```

相同对象的对应LA表示，具有k元关系结构，需要rank-k张量：
```
参数数 = nᵏ
```

**量化对比**（n=300, 标准嵌入维度）：

**k=2（二元关系）**：
- FGA：1 + 300 + 44,850 = 45,151
- 张量：300² = 90,000
- 节省：~50%

**k=3（三元事件结构）**：
- FGA：~4.5百万
- 张量：27百万
- 节省：~83%

**增长趋势**：
- 优势随arity增长
- FGA参数计数增长为O(nᵏ/k!)（通过二项系数）
- 张量计数增长为O(nᵏ)没有k!压缩

**压缩不是技巧**：
- 它反映代数事实：楔积反称编码关系结构，消除对称张量必须明确表示的冗余自由度

## 分级结构作为语义类型系统

第2.4节预览的grade-to-type对应不仅仅是类比——它是代数强制执行的。

因为grade分解M = Σₖ⟨M⟩ₖ在每个代数操作下保持——多向量的每个乘积产生结果，其grade由其输入的grades确定——类型结构对代数是内在的而非外部施加的。

### 利用grade结构的前例

为语义目的利用grade结构有前例：
- **Mani (2016)**提出grades可以在多向量词嵌入中编码词性层次，更具体概念在更小grades，更一般概念在更大grades
- 训练Word2Mvec模型，在skip-gram架构中使用几何积

**本文扩展**：
我这里提议的直觉从经验嵌入策略扩展到形式组合框架，其中grade-to-type映射由自然语言语义的类型理论结构激励，并且代数操作尊重类型区别。

### 完整grade-to-type对应

| 类型 | Grade | 表示 | 示例 |
|------|--------|--------|--------|
| 实体 (e) | Grade 1 | 向量 | John, Mary, the book |
| 真值 (t) | Grade 0 | 标量 | true, false |
| 一元谓词 (e→t) | Grade 1 | 向量 | run, human, happy |
| 二元关系 (e→e→t) | Grade 2 | 双向量 | love, kick, read |
| n元谓词 | Grade n | n向量 | give (三元), put (三元) |

**重要**：
这些类型区别对代数是内在的。

在标准LA中：
- 表示实体的向量和表示谓词的向量生活在同一空间
- 它们仅通过惯例或网络架构区分

在GA中：
- 它们占据不同grades
- 代数操作尊重这些区别：将grade-1实体向量收缩到grade-2关系双向量产生grade-1结果，镜像类型理论规则：将二元关系应用于一个参数产生一元谓词

#### 代数归纳偏置

这不是仅仅是符号便利。它提供我称之为**代数归纳偏置**的东西：

grade结构约束什么操作良好形成以及它们产生什么结果，减少模型在训练期间必须搜索的可能组合空间。

当组合尊重grade结构时，代数强制一种形式纪律，LA模型必须完全从数据学习。

### 关于对应状态的坦率说明

我在提议**grade-type映射作为归纳偏置**：
- 组织表示空间的假设结构
- 约束学习问题
- **不是**声称学到的表示将干净分解为grade-0真值、grade-1实体、grade-2关系等

**分布式表示的历史**：
- 学到的嵌入的实际几何通常比任何先验方案预测的更混乱
- BERTology研究（Rogers et al., 2021）显示transformer表示以可恢复但非预期的方式编码句法和语义信息

**对多向量嵌入的预期**：
- 我会预期学到的多向量表示类似地跨grades扩散，反映数据的统计结构如同理论类型层次
- **基于grade的归纳偏置购买**的不是保证对应是干净的，而是约束使其比在平面向量空间中更有可能出现——并且关键，一组尊重grade结构的代数操作（收缩、楔积、转子操作）即使当表示非完美grade对齐时

**正确的经验问题**：
- 不是"实体是否exclusively居住在grade 1？"
- 而是"带有grade敏感组合的grade截断表示是否在组合泛化任务上优于相同维度的平面向量？"

那个问题是可测试的，我相信它是重要的。

## 组合机制：从类型到推导

上面引入的grade-to-type对应不仅仅是标注方案——它驱动完全组合语义，其中词条、谓词应用、参数结构和类型检查都有特定代数实现。让我现在详细开发这个机制，因为它形成FGA的操作核心。

### 类型化域

我将type-to-grade映射精确为以下分配：

```
e (个体)      → Cl¹(V)           (向量作为个体)
t (真值)      → Cl⁰(V)           (标量作为真值)
e→t (一元谓词) → Cl¹(V)           (向量作为一元谓词)
e→(e→t) (二元关系) → Cl²(V)     (双向量作为二元关系)
n-place谓词   → Clⁿ(V)      (n向量作为n元谓词)
```

#### 两个观察

**第一**：实体和一元谓词都是grade-1向量，但它们通过子空间支持区分。

**直和分解**：写V₁⊕V₂为两个子空间的直和。

直和确保非干涉：V₁和V₂中的组件独立可访问并且在投影下不相互污染。这是保持类型化域在单个代数内的代数机制。

设基础语义空间分解为V_E⊕V_P⊕...，其中：
- V_E是实体子空间
- V_P是谓词内容子空间

**实体**仅支持在V_E中：
```
j ∈ Cl¹(V_E)
```

**一元谓词**支持在V_E和V_P中：
```
R ∈ Cl¹(V_E⊕V_P)
```

- V_E组件编码选择信息——它应用于什么类型的实体
- 并且是参与与实体参数收缩的组件
- V_P组件编码谓词自身语义内容

**应用（收缩）**利用共享V_E组件：
```
R·j = R_E·j + R_P·j = R_E·j ∈ Cl⁰
```
因为V_P ⟂ V_E确保R_P·j = 0。

实体和谓词的区别因此是代数内在的——通过子空间投影可检查——而非外部注解。这镜像Montagovian情况，其中e和t都是基本类型，通过它们的域区分。

**第二**：谓词的arity直接在其grade中编码：
- n元谓词需要n次收缩达到grade 0（真值）
- 每次收缩消耗一个参数

### 词条

词条接收多向量表示，其grades反映它们的语义类型。

下面示例故意简单——点是展示type-to-grade映射即使最基本情况下产生良好行为的组合行为。

#### 实体

专有名词和限定描述表示为实体子空间中的grade-1向量：

```
⟦John⟧ = j ∈ Cl¹(V_E)
⟦Mary⟧ = m ∈ Cl¹(V_E)
⟦the book⟧ = b ∈ Cl¹(V_E)
```

贯穿全文，实体向量假设为单位规范化：
```
|j| = |m| = |b| = 1
```

这确保：
- 内积j·m = cosθ是具有恒定标识值（j·j = 1所有实体）的余弦相似度
- 转子操作保持范数

**规范化不仅仅是惯例而是代数承诺**：它确保涉及实体向量的任何几何积的标量部分具有稳定、可解释的规模。

**注记**：⟦the book⟧这里被处理为预组合实体而非从限定词和普通名词book组合导出。这是说明性目的的简化。

**完整处理**：
- 限定词是运算符——grade保持或grade修改变换——与普通名词谓词组合产生实体类型指称表达
- 机制类似于类型提升：定冠词将谓词类型普通名词转移为实体类型表达，通过与唯一性预设收缩
- 指示将涉及额外编码空间或话语指示方向的转子

#### 一元谓词

不及物动词、普通名词和一元形容词表示为V_E⊕V_P中的grade-1向量：

```
⟦run⟧ = R ∈ Cl¹(V_E⊕V_P)
⟦human⟧ = H ∈ Cl¹(V_E⊕V_P)
⟦happy⟧ = S ∈ Cl¹(V_E⊕V_P)
```

谓词的V_E组件与实体向量的内积产生标量（grade-0），对应真条件评估。

普通名词额外携带quale转子；形容词携带修饰特定配置（参见第6.4节）。

#### 二元关系

及物动词表示为V_E⊕V_P中的grade-2双向量：

```
⟦love⟧ = ℓ ∈ Cl²(V_E⊕V_P)
⟦kick⟧ = K ∈ Cl²(V_E⊕V_P)
⟦read⟧ = ρ ∈ Cl²(V_E⊕V_P)
```

作为双向量，及物动词是有向平面——方向编码哪个参数位置是哪个。代数的反交换性确保：
```
⟦love⟧(j,m) ≠ ⟦love⟧(m,j)
```
因为从双向量不同侧收缩产生不同结果。

### 通过收缩应用

谓词应用——任何语义中最基本的组合操作——在FGA中通过内积（收缩）实现，每次参数减少一个grade。这镜像类型理论规则：将函数应用于参数消除一层函数类型。对应是精确的，值得详细看。

#### 一元应用

对于一元谓词P ∈ Cl¹和实体x ∈ Cl¹：
```
⟦P(x)⟧ = P·x ∈ Cl⁰ (标量/真值)
```

收缩Cl¹×Cl¹ → Cl⁰对应类型归约

#### 示例：Mary laughs

```
⟦laugh(Mary)⟧ = L·m ∈ Cl⁰
```

结果是标量，其幅度编码谓词成立的程度——在布尔模型中，这是0或1；在分级模型中，它是反映合理性或分布支持度的连续值。

#### 及物动词的柯里化应用

二元关系ℓ ∈ Cl²通过连续收缩取两个参数——但现在方向性重要。

**右收缩**从右侧应用对象：
```
ℓ ⌞ m = ℓₘ ∈ Cl¹ ("love Mary"作为一元属性)
```
通过饱和对象位置将双向量归约到向量。

**左收缩**从左侧应用主语：
```
j ⌟ (ℓ ⌞ m) ∈ Cl⁰ ("John loves Mary"作为真值)
```

饱和另一个参数位置。

**收缩序列**：
```
Cl² ⟶⌞m Cl¹ ⟶ⱼ Cl⁰
```
镜像柯里化类型归约
```
e→(e→t) 应用于两个参数
```

Grade随每个参数饱和减少，左和右收缩的区别编码正在填充哪个参数位置——标准LA的对称内积不能表达的区别。

### 外应用和内应用

上面开发的收缩机制——我将称之为**外应用（OA）**——是函数-参数组合的经典情况：谓词接受其参数作为未分化的整体，收缩相应减少grade。

在Montagovian传统中，这对应函数应用；在经典向量空间语义学中，它对应矩阵-向量乘法。

**但自然语言中的组合几乎从不这么简单。**

绝大多数谓词不接受其参数作为未分化的整体：
- "Wipe the table"针对table的表面，非table作为整体
- "Tie your shoe"访问laces，满足打结物理条件的特定子部分
- "Begin the book"访问book的特征函数并开始它
- "Good knife"沿cutting功能评估knife，非沿某些绝对质量量表

在每种情况下，谓词选择进入参数的内部结构，组合不是与整体而是与其特定方面。

#### 内应用（IA）

在分布式组合性理论中，最近在生成性词典理论内开发（Pustejovsky and Jezek, forthcoming），这种选择性组合模式称为**内应用（IA）**。

在FGA中，**内应用**实现为两步过程：
1. 首先，quale定向转子变换参数的多向量，前景化相关子空间组件
2. 然后收缩饱和参数位置与转子变换的表示

```
⟦P(arg)⟧ = P ⌟ (R_Q ⟦arg⟧ R̃_Q)
```
其中R_Q是编码quale Q（Telic, Constitutive, Agentive, Formal）的转子。

**转子在Clifford代数中是内应用**：
- 它是谓词探测参数的内部组织并提取它需要的方面的形式机制
- 当没有quale定向转子活动时——当R_Q是单位元——内应用归约为外应用，并且推导是经典函数应用

**中心主张**：
- 内应用是一般情况
- 外应用是特殊情况
- 像"exist"或"disappear"这样真正想要完整未分化参数的谓词是例外

#### 统一机制

动词-参数组合的默认模式涉及转子——quale介导探查参数的子空间结构——在收缩应用之前。这是机制：

- "Begin the book"中的类型强制不是由类型不匹配触发的特殊机制；它是内应用与跨子空间转子（从V_E到V_P）
- "Wipe the table"中的构成性投影是内应用与子空间内转子（在V_E内）
- "Good knife"中的子sective修饰是内应用访问Telic quale

**机制统一；变化的是转子的几何目标**：

- **外应用**（仅收缩，无转子）：谓词接受参数作为未分化整体。这是像"exist"、"disappear"或"arrive"等谓词的模式
- **内应用，子空间内**（V_E内转子）：谓词选择参数的特定方面，但保持在同一类型中。示例："wipe the table"、"good knife"
- **内应用，跨子空间**（V_E和V_P间转子）：谓词强制参数到不同类型。示例："begin the book"

这提供谓词-参数组合的统一代数框架，其中不同组合模式对应不同转子类型，但底层数学相同。

对于Cl(V,Q)中的多向量M, N：

- 8个基元素：1标量，3向量，3双向量，1三向量
- 偶子代数同构于四元数
- 物理和计算机图形学中广泛使用

**Cl(1,3,0)**（闵可夫斯基时空）：
- 16个基元素
- 编码时间和空间维度
- 相对论物理学中使用

- 增加齐次坐标
- 用于投影几何和计算机视觉
