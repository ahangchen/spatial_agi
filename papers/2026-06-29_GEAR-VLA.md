## 核心问题

当前 Vision-Language-Action (VLA) 模型虽然在基准测试中表现优异，但在真实世界部署中仍面临三大泛化瓶颈：

1. **动作表征不统一**：现有 VLA 将连续控制离散化为 token 进行预测，导致模型倾向于轨迹模仿而非体身推理（embodied reasoning），低层轨迹监督与高层语义之间缺乏有效桥梁。
2. **3D 几何特征未对齐**：深度图、3D 位置编码等空间先验并未与 VLM 的语义空间自然对齐，直接注入会扰乱已有的视觉-语言表征。
3. **跨本体迁移困难**：不同机器人的运动学差异被引入到高层策略表征中，导致数据不均衡时迁移效率低下，尤其对训练中未见过的新机器人本体泛化能力差。

## 方法创新

GEAR-VLA 提出三大核心设计，构建统一的几何感知动作表征：

### 1. 由粗到细的动作学习（Coarse-to-Fine Action Learning）

- **第一阶段（体身 VLM 预训练）**：在多源数据上训练 VLM，包括视觉语言理解、空间定位、轨迹推理和操作视频。采用 FAST 风格的动作 token 提供离散监督，同时引入因果 VQ-VAE 从操作视频中提取潜在动作 ID（latent action IDs），学习与具体动作无关的高层动作语义和视觉动态。
- **第二阶段（连续动作生成）**：在冻结的 VLM 基础上，通过潜在动作 token（latent action tokens）的 K/V 缓存连接一个基于 DiT 的连续动作专家，使用 flow matching 损失训练。关键在于**梯度解耦**——通过 stop-gradient 阻止连续动作损失回传到 VLM 主干，保护已学好的语义表征不被连续回归任务破坏。

### 2. 语义对齐的 3D 几何融合（Semantic-Aligned 3D Integration）

- 在原始 2D 视觉编码器（Qwen2.5-VL）旁并行添加一个可训练的 3D 空间编码器（VGGT），利用多视角一致性建模场景布局和物体形状。
- **零初始化连接器**：2D 分支保留原始预训练权重，3D 分支的投影权重初始化为零，使训练初期模型输出完全等同原始 VLM，然后逐步学习 3D 几何特征。这种设计既注入了几何信息，又保护了 VLM 的语义空间。

### 3. 本体规范化（Embodiment Canonicalization）

- **动作侧**：采用相对末端执行器动作（Relative End-effector Action），所有未来位姿相对于当前末端位姿表示 SE(3) 变换，避免步进式 delta 的误差累积，也减少对机器人基坐标系和工作空间几何的依赖。
- **状态侧**：将末端位姿与关节角度配对输入，隐式编码本体信息（自由度、关节布局、运动学约束）。每个机器人只需一个轻量级状态投影器映射到共享 VLA 表征空间。
- **新本体迁移**：仅需两阶段轻量适配——先冻结主干对齐新状态投影器，再做少量端到端微调。

## 关键结果

| 评测维度 | 结果 |
|---------|------|
| **LIBERO**（仿真基准） | 达到 SOTA |
| **LIBERO-Plus**（零样本泛化） | 达到 SOTA |
| **RoboTwin 2.0**（大规模多任务仿真） | 达到 SOTA |
| **AgileX 双臂真实任务**（3个接触丰富任务） | 85.9% 平均成功率 |
| **LDT-01 跨本体迁移**（预训练中未出现的本体） | 81.0% 成功率 |
| **通用抓取基准**（212个未见物体，6,360次试验） | **90.1%** 成功率 |
| ↳ 对比 π₀.₅ | 79.1%（GEAR-VLA 高出 11 个百分点） |

最亮眼的成果是：在 212 个未见物体、3 个挑战场景的 6,360 次抓取试验中取得 90.1% 成功率，以及在没有相似训练数据的 LDT-01 机器人上实现 81% 的迁移成功率，充分验证了几何感知表征的跨物体和跨本体泛化能力。

## 对 Spatial AGI 的意义

GEAR-VLA 对通向 Spatial AGI 具有重要启示：

1. **几何与语义的统一**：零初始化的 3D 注入策略首次优雅地解决了 3D 几何特征与 VLM 语义空间对齐的难题。这对 Spatial AGI 至关重要——真正的空间智能必须同时理解"这是什么"（语义）和"它在哪里、怎么交互"（几何），GEAR-VLA 的方法为此提供了一条可行路径。

2. **跨本体的通用策略**：通过本体规范化将机器人差异限制在底层接口，而非高层策略表征中，使同一套 VLA 模型可服务于不同硬件。这是实现通用具身智能体的关键能力——Spatial AGI 需要在不同物理形态下保持一致的空间理解与操作能力。

3. **从动作语义到连续控制的分层架构**：梯度解耦的 DiT 动作专家设计启示我们，Spatial AGI 的决策架构可能天然需要分层——高层进行语义推理与空间规划，底层负责精细运动控制，两者通过结构化接口（潜在动作 token）桥接，而非端到端地混为一谈。

4. **规模化验证范式**：6,360 次试验的通用抓取评测代表了具身智能评测的新标准——从单个任务的成功率走向大规模、多物体、多场景的统计性验证，这正是 Spatial AGI 从实验室走向真实世界必须跨越的评测门槛。

5. **视觉动态的跨域学习**：利用因果 VQ-VAE 从人类视频和网络视频中提取动作语义（不依赖动作标签），为解决具身智能数据稀缺问题提供了新思路。Spatial AGI 需要海量空间交互经验，从非机器人数据中迁移动作知识将是一个重要方向。
