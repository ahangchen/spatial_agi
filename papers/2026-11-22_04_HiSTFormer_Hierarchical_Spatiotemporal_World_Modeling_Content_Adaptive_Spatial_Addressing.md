## 核心问题

### Q1: 核心算法原理是什么？

**问题**: 这篇文章的核心算法原理是什么？请详细描述：1) 核心思想和动机，2) 主要技术方法，3) 算法流程和关键步骤，4) 输入输出。

**分析**:

#### 1. 核心思想和动机

第一人称世界模型需要在长时交互中做两件事：从连续观测预测局部动力学，以及用过去轨迹的空间信息维持场景一致性（场景重访时"认得路"）。现有空间记忆方法各有短板：

- **几何方法**（SpMem、3D Persistent World Model、PERSIST、Spatia、LSM-World、MosaicMem）：维护显式/潜在3D地图，跨视角约束好，但需要额外的几何估计、3D建图和记忆维护开销
- **位姿+潜在记忆方法**（ReMind、ReWorld、WorldCrafter、MemoryVLN）：用相机感知RoPE或位姿索引记忆库，但**时间与空间关系如何在Transformer深度中协调仍未被充分探索**
- 计算分工类（CoME的记忆专家、LOCI的几何条件化循环记忆）：分工方式多样但缺少系统性的组织原则

作者从生物神经系统得到两个核心洞见：

1. **局部时间整合与远程空间检索有不同的信息需求**——前者靠连续观测+动作，后者访问跨时间的空间相关经验。这两件事应该分层处理，而不是在层内混合。
2. **空间地址不必与视觉内容一一对应**——一个观测帧可能包含多个物理位置的内容（一个局部经验表征聚合了多帧信息），固定的自我中心地址会限制检索精度，需要**内容自适应的空间寻址**。

生物基础：内嗅皮层网格细胞的多尺度空间表征（路径积分），海马体整合空间/时间/情景信息。计算对应物是网格细胞的多周期编码——多尺度周期性编码有减少周期性位置歧义的理论支持（Mathis et al. 2012等）。

#### 2. 主要技术方法

**（a）层次化时空Transformer**

时间层与空间层分层组织：

- **时间层**：标准时间RoPE + 滑窗注意力（默认关注最近32个token），整合连续观测和动作，捕捉局部动力学
- **空间层**：多周期空间RoPE + 有界KV缓存（最近32步 + 最多96个较早时间步的覆盖采样），通过路径积分空间地址检索历史经验，实现跨时间间隔的场景恢复

每层都是标准Pre-LN Transformer块（4头注意力，256维QKV）。空间层检索到的条目已含时间层提取的局部上下文——单条记忆携带多帧信息。

**（b）空间表征RoPE（多周期网格编码）**

路径积分维护空间地址：运动编码器（因果时间卷积）从动作估计位移（想象时只用动作，观测时用动作+视觉表征），用真值朝向单位向量变换到世界系：

```
Δr_t = ŝ_t · [cos θ_{t-1}, sin θ_{t-1}]^T
```

位置用多周期傅里叶相位表示：p个对数尺度间隔的空间周期，每个周期w个均匀分布的平面波方向（w是3的倍数，**波向量按120°间隔三元组组织，对应六边形空间码的方向结构**——正是网格细胞的几何）。每个平面波维护独立复数相位，通过路径积分更新：

```
c_t(k) = c_{t-1}(k) · exp(i·k^T·Δr_t),  c_0(k) = 1
```

每个单位复数相位旋转query/key的二维通道对 → 空间RoPE，把估计位置间的相对位移显式引入注意力计算。多周期提供多尺度位置信息：局部辨别 + 大范围消歧。真值朝向θ_t重复16个通道对并与位置相位合并。

**（c）内容条件化空间寻址（Content-Conditioned Spatial Addressing）**

核心创新：从时间层输出用轻量MLP为每个空间注意力头 h 预测二维位置偏移 Δp^h，通过额外旋转生成头专属空间地址：

```
c̃_t^h(k) = c_t(k) · exp(i·k^T·Δp^h)
```

不同注意力头可以为同一经验表征学习不同的内容条件化空间关联。额外参数仅**0.05M**。

**（d）固定容量结构化记忆**

KV存储和每步注意力成本有界（不随序列增长）：空间层缓存 = 32个最近步 + 96个覆盖采样的较早记忆（R+C策略）。附录显示只要保持宽时间覆盖，具体选择规则不敏感；有界缓存防止KV增长且对预测质量影响可忽略。

**（e）训练目标**

320帧序列、K=16帧分块的观察-预测循环（observe chunk → 自回归预测下一chunk → 观察真值 → 重复）。四项损失：

```
L = L_recon + L_pred + L_student + 0.03·L_pair
```

- L_recon：观测帧的图像重建MSE
- L_pred：开放环预测的平均重建误差
- L_pair（0.03权重，无位置监督的空间一致性）：只作用于观测轨迹，监督视觉-动作运动编码器。选间隔>K帧、朝向差≤15°的帧对——视觉余弦相似度≥0.98为正对（拉近距离相似度到0.9），<0.1为负对（推开距离相似度到0.7以下）。**用视觉相似性作为空间表征一致性的代理监督**——相似视觉内容应有相似路径积分表征
- L_student：动作-only运动编码器（学生）对齐视觉-动作运动编码器（教师）的输出，SmoothL1，教师侧stop-gradient——为想象时（无观测）准备动作-only位移估计

#### 3. 算法流程和关键步骤

1. 观测 o_t 编码为视觉表征 z_t（紧凑潜码）
2. 运动编码器估计位移 ŝ_{t+1}（观测时用a+视觉，想象时只用动作），坐标变换到世界系，路径积分更新多周期相位 c_{t+1}
3. 时间层（时间RoPE+滑窗）从 z_t 和动作 a_{t+1} 提取上下文经验表征
4. 轻量MLP从时间层输出预测每头内容条件偏移 Δp^h，修正空间地址
5. 空间层（多周期空间RoPE+有界KV缓存）检索空间相关历史经验并整合
6. 解码器自回归生成预测帧 ẑ_{t+1}
7. 开放环预测时，上一步的预测表征作为当前输入（无真值观测）

#### 4. 输入输出

- **输入**：历史RGB帧序列 + 离散动作 + 真值朝向方向
- **输出**：自回归的未来视觉帧预测（开放环，条件于未来动作和朝向）
- **内部状态**：路径积分网格相位（空间地址）、固定容量KV记忆（时间上下文化经验）

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**问题**: 这篇文章与通用空间智能（Spatial AGI）有什么关系？请分析：1) 如何理解和表示空间，2) 如何处理空间关系，3) 对Spatial AGI有什么启发，4) 可以应用到哪些Spatial AGI场景。

**分析**:

#### 1. 如何理解和表示空间

HiSTFormer的空间表示是**神经科学启发的连续相位空间**：

- 空间位置 = 多周期复数相位向量（六边形波向量结构）——不是离散地图格子，不是3D点云，而是"网格细胞式"的多尺度相位码
- 空间关系 = 注意力中的相对相位旋转——两帧的空间关系直接由路径积分位移的相位差表达，无需显式坐标
- 关键的表示论断：**空间地址是路径积分的（积累式、有漂移），不是绝对定位的**——这正是动物导航的现实约束（无GPS，靠本体累积位移），HiSTFormer在漂移条件下仍保持功能

**内容与地址的解耦**是第二个表示创新：一个视觉表征可以关联到多个空间位置（每头一个偏移后的地址），承认了"一帧视觉包含多位置信息"的现实。这比"一帧一位址"的刚性绑定更符合视觉内容的本质。

#### 2. 如何处理空间关系

三层处理：

1. **局部时间关系**：时间RoPE+滑窗——"刚发生的事"用连续上下文处理
2. **远程空间关系**：多周期空间RoPE——"以前在别处看到的相关内容"用相位寻址检索，跨时间间隔恢复场景
3. **内容-空间绑定**：每头偏移——同一经验的不同内容面向不同空间位置检索

层次组织的消融结论本身就是一个空间处理原则：**时间先于空间（TS优于ST优于层内混合JJ）**——先理解"现在发生了什么"，再问"这与过去哪里的事相关"。以及**时间层和空间层需要不同的记忆组织**：时间层要连续近窗（FIFO），空间层要广覆盖采样（R+C）—— swapped后双双退化。这说明局部时间建模依赖连续上下文，空间检索依赖长时间广覆盖——两类记忆的信息结构本质不同。

#### 3. 对Spatial AGI的启发

**启发1：空间记忆需要分层架构，不是单一记忆模块。** 时间上下文和空间检索是两种信息需求，硬塞进同一个注意力机制（层内混合JJ）两头不讨好。Spatial AGI的记忆系统应该显式分层：情景时间轴 + 语义空间索引，对应海马-内嗅的双系统。

**启发2：路径积分式空间地址+内容条件修正的混合范式。** 纯路径积分有漂移，纯绝对定位需要外部定位系统。HiSTFormer的混合——路径积分提供基础地址，内容条件偏移（0.05M参数！）做自适应修正——提供了一个不需要精确SLAM的务实中间态。92.4%的样本修正后地址更接近视线所及的墙面，说明模型自己学出了"把地址校准到可见地标"的行为。

**启发3：固定容量记忆是长期部署的前提。** KV缓存有界（32近+96覆盖）使每步成本不随交互时长增长——Spatial AGI要能运行几小时几天，无界记忆不可持续。更妙的发现：只要保持时间覆盖广度，具体选哪些记忆不敏感——说明空间索引（而非记忆内容精选）是检索质量的主要来源。

**启发4：超越训练长度的泛化来自结构而非容量。** 320帧训练→1000帧泛化，靠的是多周期编码的尺度结构和相位寻址的相对性，不是更多参数（7-8M小模型！）。对Spatial AGI的启示：长时域空间一致性是归纳偏置问题，不是规模问题。

**启发5：无位置监督的空间学习是可行的。** L_pair用视觉相似性代理空间一致性（正对0.98相似度→表征应相似），完全绕开了真值位置标签。这为大规模无标注视频的空间预训练开了路径。

#### 4. 可以应用的Spatial AGI场景

- **导航世界模型**：机器人/无人机的长时域视觉前瞻（HM3D环境直接相关）
- **开放世界游戏NPC/智能体**：MemoryMaze类环境的持久空间记忆
- **具身智能体情景记忆**：房间级重访识别、"我之前在哪见过这个"式检索
- **VR/AR场景一致性**：用户转头回看时场景保持一致的生成式渲染
- **自动驾驶长时域预测**：绕圈行驶后的路口重访预测

### Q3: 主要创新点和局限性是什么？

**问题**: 基于前面的分析，这个方法的主要创新点和局限性是什么？与其他相关工作相比有什么优势和劣势？

**分析**:

#### 1. 主要创新点

1. **层次化时空组织的系统性研究**：T/ST/J/N五种编码×2/4/6层深度×多种排布的系统消融，确立了"分层的TS排布、块状优于交替（TTTSSS>TSTSTS）、深度增加收益持续"的设计准则。这是对"时空信息如何在Transformer中组织"这一开放问题的首个系统回答。

2. **多周期网格空间RoPE**：把网格细胞的多周期六边形结构转译为注意力机制中的相对相位编码，路径积分驱动、支持任意空间距离的相对关系计算。零样本迁移到11×11/13×13更大环境仍最稳。

3. **内容条件化逐头地址偏移**：仅0.05M参数带来LPIPS约9.0%/5.5%的降低；可解释性分析漂亮——92.4%的偏移把地址移近视线墙面、四头方向偏好均匀分布覆盖80°视野、扰动检索结果导致明确预测错误。这是"可解释、可干预、有因果证据"的创新。

4. **无位置监督的空间一致性学习**：L_pair的视觉相似性代理监督 + 师生运动编码器对齐（想象时动作-only）——完整摆脱真值位置依赖（除朝向外）。

5. **小模型长泛化**：7-8M参数在MemoryMaze全面超越297M的CoME（长时域协议），500→500协议（训练长度外）误差增长最慢，上下文超过训练长度后误差稳定不升。

#### 2. 主要局限性

1. **依赖真值朝向**：头方向θ_t是ground-truth输入——真实部署需要额外的朝向估计（IMU/视觉里程计），其误差会传导进路径积分。论文未测试带噪朝向。
2. **环境尺度有限**：9×9/13×13的迷宫和HM3D室内场景，城市/室外大尺度下的多周期编码周期设置需要重新设计。
3. **视觉预测任务、非决策任务**：输出是像素预测，未接到策略学习（没有在导航/操作任务上验证世界模型的决策价值）——与Verify2Act等"世界模型服务决策"的工作形成任务空隙。
4. **离散动作假设**：MemoryMaze是离散动作，连续控制（机械臂）下的路径积分精度未知。
5. **固定记忆预算的极端场景**：超长交互（数千帧后）早期记忆被覆盖采样淘汰，永久性场景知识（"这栋楼的地基"）无法保留——需要与持久语义记忆结合。

#### 3. 与其他相关工作的对比

| 方法 | 空间记忆方式 | 短板（相对HiSTFormer） |
|------|------------|----------------------|
| SpMem/3D PWM/PERSIST/Spatia | 显式/潜在3D地图 | 需几何估计与建图维护 |
| LSM-World/MosaicMem | 视觉潜码+3D空间关联 | 视角变换+特征对齐开销 |
| ReMind | 相机感知RoPE | 固定自我中心地址，无内容自适应 |
| ReWorld | 位姿注意力+Landmark Bank | 需要位姿索引的外部记忆库 |
| WorldCrafter | 3D感知隐式记忆 | 目标位姿条件检索，无路径积分 |
| CoME | 短期/长期/空间记忆专家 | 297M参数，长时域误差增长快 |
| HPC-MEC | 海马-内嗅启发 | MemoryMaze上次优，无内容条件寻址 |
| Transformer/Mamba/RSSM | 通用序列模型 | 无空间归纳偏置，长时域崩坏 |

优势：无几何建图开销、参数小、长时域泛化强、可解释寻址。
劣势：朝向依赖、无决策验证、尺度受限。

## 核心技术发现

1. **分层>混合**：时间与空间位置编码分到不同层，优于层内联合编码；时间在前空间在后（TS）最优；块状排布（TTTSSS）优于交替（TSTSTS）且种子方差更小。
2. **两类层需要不同记忆**：时间层FIFO近窗，空间层R+C覆盖采样——互换则双双退化。这是"局部时间建模依赖连续性、空间检索依赖覆盖度"的直接证据。
3. **内容条件偏移是结构化行为**：92.4%样本偏移后地址更接近视线墙面；四头覆盖80°视野各集中20°；偏移幅度与最近墙距离正相关（3格内最强后饱和）；干预实验（均值化/打乱/置零）全部退化。
4. **检索互补视觉线索**：定性案例中两个头的检索记忆分别距目标5.85m/4.40m，都不含完整目标视图，但各自提供目标墙的部分线索——打乱任一头检索即出错。
5. **空间编码鲁棒**：多周期网格 vs 笛卡尔 vs 单周期，差异在长时域协议下收窄，多周期是最稳默认；零样本迁移大环境仍最优。

## 个人思考

### 最令人兴奋的发现

**内容条件化地址偏移的可解释性证据链**是本文最精彩的部分。一个0.05M的MLP，没有任何墙面监督，却学出了"把空间地址校准到视线所及地标"的行为——92.4%的样本地址向墙移动、头间方向偏好均匀分布、扰动检索即出错。这是"涌现出结构化行为"的干净案例：不是黑箱中的神秘参数，而是有因果证据（干预实验）、有几何解释（墙面对齐）、有功能验证（检索互补线索）的完整证据链。Spatial AGI研究中，这种"小组件+强解释"的贡献比大模型的分数提升更有长期价值。

其次，"时间层与空间层需要不同记忆组织"这一发现看似简单，实则深刻：它证明了记忆不是一种东西——**情景连续性和空间覆盖性是两种正交的记忆需求**，任何统一的记忆设计（单一KV缓存、单一检索机制）都在浪费其中一种。今天读的AFTER（快慢时标世界模型）与本文在"记忆的多组织"上形成呼应——空间分层、时间分层，记忆系统的多维分解可能是2027年世界模型架构的主旋律。

### 潜在局限

真值朝向是最脆弱的依赖。路径积分对朝向误差是二阶敏感的（位移方向错了，位置积分整体偏移），真实机器人上视觉朝向估计的误差会在几百步后让空间地址漂出有效范围。论文的L_pair缓解了位移估计的误差，但没有触碰朝向误差。第二个担心是多周期编码的周期超参（p个周期、对数间隔）对新环境的适应性——13×13迷宫里最优的周期设置搬到室外城市可能完全失配，虽然零样本迁移实验给了部分信心，但尺度跨度还是小。

### 与昨日研究的关联

这篇论文与今天读的DynThinker、Verify2Act形成了"空间记忆三重奏"：DynThinker用D-EMA保护训练中的空间能力（参数空间的记忆），Verify2Act用潜在rollout验证空间后果（想象空间的记忆），HiSTFormer用路径积分+相位寻址组织空间经验（经验空间的记忆）。三者共同把"空间记忆"从一个模糊概念分解为可工程化的组件。与近期读的HandWorldBench（手部中心世界模型基准）、AFTER（快慢时标误差驱动记忆）并列，可以看到世界模型研究正在从"生成质量竞赛"转向"记忆架构科学"——如何在有限容量下组织、索引、检索时空经验，正在成为独立的研究问题。对Spatial AGI而言，HiSTFormer式的空间记忆可能是"空间智能的长期记忆系统"，而DynThinker式的几何先验是"空间智能的短期感知增强"——完整的Spatial AGI认知架构需要两者。

HiSTFormer把海马-内嗅记忆系统的组织原则转译为Transformer架构：时间RoPE层处理局部时序上下文（FIFO近窗），多周期网格空间RoPE层做路径积分驱动的远程空间检索（R+C覆盖缓存），内容条件化逐头偏移让空间地址适配视觉内容（0.05M参数，92.4%样本地址向可见地标校准）。8M小模型在MemoryMaze/HM3D长时域视觉预测全面超越297M基线，320帧训练泛化1000帧rollout，且确立了"分层时空组织、TS排布、块状优于交替、时间空间记忆异构"等架构设计准则。

## 附录A：技术细节深挖

### A.1 多周期网格编码的几何设计

波向量组织：p个周期（对数尺度间隔）× 每周期w个方向（3的倍数，120°三元组）→ 六边形网格结构：

- 六边形是单位圆最高效覆盖（蜂窝格），网格细胞正是六边形放电场
- 多周期（对数间隔）保证：近距离两个位置在某高频周期可分辨，远距离在某低频周期不混叠——多尺度消歧
- 每个平面波的复数相位 exp(i·k^T·r) 旋转QK的二维通道对 → 注意力logit自然包含 k^T·(r_i − r_j) 的余弦调制——相对位移直接进入相关性计算

总旋转维度 D_r = 2pw。朝向θ_t重复16通道对，与位置相位拼接为最终空间RoPE——位置与朝向正交编码。

### A.2 路径积分+师生运动编码器

运动编码器是因果时间卷积：
- **观测模式**：输入 (a_{t+1}, z_{t+1})——动作+视觉都参与位移估计（视觉提供观测修正，类似里程计融合）
- **想象模式**：输入只有 a_{t+1}——预测未来时没有观测，只能靠动作推算

师生对齐：教师（视觉-动作版）在观测时提供更准的位移估计；学生（动作-only版）用SmoothL1+stop-gradient学习教师的输出。这样想象模式下学生能以观测模式教师的质量运行。这个设计与Dreamer系列的动作条件动力学一脉相承，但显式分离了"观测修正"与"纯推算"两种模式。

### A.3 L_pair的代理监督设计

选对规则：间隔>K帧 + 朝向差≤15°——控制朝向变量，让视觉相似性主要由位置决定。

标签规则：V_ij≥0.98（几乎相同视野）→ 正对（应同位置）；V_ij<0.1（完全不同视野）→ 负对（应不同位置）；中间忽略（视觉相似但位置不同的歧义区不强行假设）。

损失：正对 [0.9−S_ij]₊（路径积分表征相似度S_ij应≥0.9），负对 [S_ij−0.7]₊（应≤0.7）。0.03的权重表明它是正则项而非主力信号。

这个设计的哲学：**在无法获得真值位置时，用"视觉相似⇒空间相近"的启发式作为弱监督**。它有系统性偏差（不同房间可能有相似墙面→被误判为同位置），0.03的低权重和大量主力重建信号稀释了这个风险。

### A.4 固定容量记忆的R+C策略

空间层KV缓存：32个最近时间步（保证近期精细上下文）+ 96个较早步（按时间覆盖采样——确保长历史的时间跨度被代表）。消融显示：换成纯FIFO（空间检索失去覆盖）→ TS退化；给时间层换成R+C（局部时序失去连续性）→ 长时域明确退化。附录A.4进一步显示"只要覆盖广度保持，具体选择哪些记忆不敏感"。

结论的记忆科学解读：**空间索引是检索质量的主要来源**——只要记忆条目在时间上分布广、且都带着内容条件化地址，用哪条都行；索引错了才是致命的。

### A.5 可解释性实验的设计质量

四个互补的证据类型：
1. **相关性**（G.1）：运动编码器的位移表征有空间意义
2. **稳定性**（G.2）：注意力头的偏移方向偏好稳定、均匀覆盖视野
3. **几何一致性**（G.3）：偏移后地址与检索记忆的几何关系合理（92.4%向墙移动）
4. **因果干预**（G.2/G.4）：均值化/打乱/置零偏移→退化；打乱特定头的检索→明确预测错误

这套"相关性-稳定性-几何-因果"四段验证可以作为所有"可学习寻址/检索机制"研究的可解释性模板。

## 附录C：批评性审视

1. **朝向真值是最大软肋**：所有路径积分依赖真值θ_t。真实部署需要朝向估计，其误差对路径积分的影响（方向误差×距离）未量化。建议后续加入带噪朝向的鲁棒性实验。
2. **预测≠决策**：全部评测是视觉预测指标（MSE/SSIM/LPIPS/PSNR），世界模型的价值最终要看它服务的策略学到多少——与TECO/MemoryMaze原论文同样的局限。
3. **参数量控制的公平性**：CoME 297M vs HiSTFormer 8M的对比中，CoME保留了自己的扩散训练方案（可能不适配潜码预测目标）——架构对比中混入了训练配方差异。
4. **场景重访的判定阈值**：重访目标定义（32帧前、2m内、朝向差45°内）影响2D分析结论，阈值敏感性未报告。
5. **离散动作、小环境**：MemoryMaze离散动作+对称网格环境可能对相位编码格外友好，连续控制+不规则真实建筑的泛化存疑。

## 附录F：实验结果补充解读

### F.1 重访 vs 新位置预测（Fig 2D）

把预测目标分为三组：重访（32帧前2m内、朝向差≤45°有观测）、新位置（所有上下文观测都>2m）、其他。HiSTFormer在两组的MSE都最低，LPIPS在新位置与CoME差异不显著。

解读：重访位置的预测优势来自空间记忆检索——"认出这里"后调用历史观测；新位置的预测主要靠局部几何连续性外推。两者都强说明HiSTFormer不是只靠记忆（novel也最优）也不是只靠外推（revisit领先）。

### F.2 上下文长度实验（Fig 2C）

固定预测"未来64帧"，逐步增加可用上下文：HiSTFormer误差随上下文增长而下降，且**超过320帧训练长度后保持稳定**——尽管路径积分误差在积累、KV缓存固定。对比：Transformer训练范围内受益、超范围退化；Mamba/RSSM几乎不受益。

这是"结构化空间索引让长历史有用"的最直接证据：上下文越长→越多可检索的空间相关记忆→预测越好，泛化到训练外长度说明索引机制本身是尺度无关的。

### F.3 每步LPIPS曲线（Fig 2B）

256→64协议的逐步误差：前16步（训练内）各方法接近；16步后HiSTFormer误差增长最慢且优势随时域扩大。CoME前几步LPIPS更低（扩散模型的逐帧质量高）但随后快速恶化（无空间一致性约束的累积漂移）——"短期好看 vs 长期可靠"的分野，验证类任务（Verify2Act）应优先长期可靠的模型。

### F.4 空间编码变体与零样本迁移（Fig 3E）

9×9训练→11×11/13×13零样本：256→64下多周期网格编码LPIPS全面最低；500→500下各编码差距收窄但多周期仍稳定。附录F还报告了距离分层分析和多周期长程预测的进一步证据。结论：多周期网格是可靠默认，但不是巨大优势——**分层组织（层次结构）比具体编码选择更关键**。

### F.5 记忆管理敏感性（附录A.4）

有界 vs 全量空间记忆：有界（128 token）防止KV增长且预测质量损失可忽略——空间索引使得"不必记住一切"成为可能。具体淘汰规则不敏感（保持覆盖广度即可）进一步说明索引质量优先于内容精选。

## 附录J：本文对"空间智能记忆理论"的四个命题

从HiSTFormer的结果可以归纳为四个可检验命题，供后续研究引用与验证：

**命题1（分层命题）**：时间上下文与空间检索应分配到不同Transformer层，先时间后空间（TS排布），且该收益随深度增长。
— 证据：Fig 3A/B的编码×深度×排布消融。

**命题2（异构记忆命题）**：局部时间建模需要连续近窗记忆（FIFO），远程空间检索需要覆盖采样记忆（R+C），两者不可互换。
— 证据：Fig 3C的缓存互换实验（双向退化）。

**命题3（内容-地址解耦命题）**：视觉表征与空间地址应允许一对多映射（逐头偏移），且模型会自发学习把地址校准到可见地标。
— 证据：Fig 4A的偏移消融+干预，Fig 4B的墙面对齐统计（92.4%），G.x附录的检索案例分析。

**命题4（结构>容量命题）**：长时域空间一致性的泛化主要来自编码结构的尺度性（多周期相位），而非模型容量或记忆容量。
— 证据：8M模型超越297M基线；320→1000帧泛化；固定128 token记忆无显著损失。

这四个命题共同构成一个"空间记忆的最小架构理论"，其可检验性（每个都有明确的反例条件）是比任何单项分数更持久的贡献。若后续研究在大尺度环境、连续控制、真实机器人上复验这四个命题，空间记忆的工程科学就能真正建立起来。
