## 论文摘要

ViewSplat提出了一种视图自适应的3D高斯泼溅（3D Gaussian Splatting）网络，用于从未标定图像进行新视图合成。该工作的核心创新在于将传统的静态基元回归范式转变为视图自适应的动态泼溅。

**关键成果：**
- 在保持快速推理（17 FPS）和实时渲染（154 FPS）的同时，达到了最先进的保真度
- 无需预先计算的相机位姿
- 有效捕捉复杂的视图依赖效果（如镜面反射、高光）

**核心机制：**
- 预测基础高斯基元和动态MLP的权重
- 在渲染时，MLP根据目标视图坐标预测视图依赖的残差更新
- 对高斯基元的所有属性进行细化（位置、缩放、旋转、不透明度、颜色）

## Q1: 核心算法原理

### 2.1 核心思想和动机

#### 2.1.1 问题识别：静态基元的瓶颈

传统的feed-forward 3DGS方法存在一个根本性的保真度瓶颈。作者将这个瓶颈归因于：

**单步前馈网络的容量限制**
- 现有方法试图在单次前向传播中回归满足所有视角的静态高斯基元
- 这是一个**病态问题**（ill-posed problem），特别是对于：
  - 复杂几何形状
  - 非朗伯表面（non-Lambertian surfaces）
  - 镜面反射和视角依赖的外观变化

**优化方法 vs. 前馈方法的差距**
- 优化方法：通过数千次迭代细化高斯属性，能够捕捉锐利的镜面反射和视角依赖的SH系数
- 前馈方法：缺乏在推理时修正初始预测的能力

#### 2.1.2 核心洞察：从通用到专用

作者提出了一个关键洞察：
> 从特定视图实现高保真2D渲染相对容易，前提是底层的3D基元可以针对该视角进行调整。

**范式转变：**
```
传统方法：努力预测通用的3D高斯 → 学习困难
ViewSplat：生成视图特定的更新 → 学习可行
```

这种转变允许模型：
1. 修正初始错误
2. 捕捉复杂的视图依赖细节
3. 静态模型无法捕捉的非朗伯效应

#### 2.1.3 设计理念：视图自适应动态泼溅

**核心概念：**
- 不是回归刚性的高斯表示
- 学习一个视图可适应的潜在表示
- 根据目标视角动态更新高斯基元

**实现方式：**
1. 预测基础高斯基元
2. 预测动态MLP的权重
3. 渲染时使用MLP生成视图依赖的残差更新

### 2.2 主要技术方法

#### 2.2.1 整体架构

ViewSplat基于SPFSplat架构构建，由以下主要组件构成：

```
┌─────────────────────────────────────────────────────────────┐
│                      输入图像                                │
│                   {I^v}_{v=1}^N                              │
└─────────────────────┬───────────────────────────────────────┘
                      │
                      ▼
┌─────────────────────────────────────────────────────────────┐
│              Geometry Transformer Backbone                  │
│        (MASt3R / VGGT ViT encoder-decoder)                  │
│                                                             │
│  ┌─────────────┐    ┌──────────────┐    ┌───────────────┐  │
│  │  ViT编码器  │ →  │  解码器      │ →  │ 多视图特征   │  │
│  │ (自注意力)  │    │ (跨视图交互) │    │    tokens     │  │
│  └─────────────┘    └──────────────┘    └───────────────┘  │
└──────────┬──────────────────┬──────────────────┬───────────┘
           │                  │                  │
           ▼                  ▼                  ▼
    ┌─────────────┐    ┌──────────────┐  ┌─────────────────┐
    │ Gaussian    │    │ Pose Head    │  │ View-Dependent  │
    │ Center Head │    │ (位姿估计)   │  │ Head (新增)     │
    │ (DPT)       │    │ (轻量MLP)    │  │ (Hypernetwork)  │
    └─────────────┘    └──────────────┘  └─────────────────┘
           │                  │                  │
           ▼                  ▼                  ▼
    ┌─────────────┐    ┌──────────────┐  ┌─────────────────┐
    │ 基础高斯    │    │ 相机位姿     │  │ 动态View MLP   │
    │ μ, r, s, α, c│    │ P^{v→1}      │  │ 权重           │
    └─────────────┘    └──────────────┘  └─────────────────┘
           │                  │                  │
           └──────────────────┴──────────────────┘
                              │
                              ▼
                    ┌──────────────────┐
                    │ 渲染阶段         │
                    │                  │
                    │ 输入：目标位姿   │
                    │ 输出：细化高斯   │
                    └──────────────────┘
```

#### 2.2.2 Geometry Transformer（几何变换器）

**架构设计：**
- 基于ViT的编码器-解码器架构
- 处理patchified RGB输入

**编码器功能：**
```
输入图像 → Patch分割 → 自注意力处理 → 编码特征
```

**解码器功能：**
- 启用跨视图交互
- 聚合几何和外观信息

**两种变体：**

1. **MASt3R-based模型：**
   - 成对交叉注意力（pairwise cross-attention）
   - 视图之间的双向信息流

2. **VGGT-based V2-L变体：**
   - 统一token序列上的全局自注意力
   - 更全面的信息聚合

3. **SPFSplatV2和V2-L：**
   - 额外引入masked attention策略
   - 改进相机位姿估计和几何重建

#### 2.2.3 Canonical 3D Gaussian Reconstruction（规范3D高斯重建）

**两个DPT-based Heads：**

1. **Gaussian Center Head（高斯中心头）：**
   - 预测每个像素的3D坐标
   - 定义高斯中心位置 μ

2. **Gaussian Parameter Head（高斯参数头）：**
   - 估计剩余的高斯属性

**高斯基元参数化：**

每个高斯基元包含：
```python
Gaussian = {
    μ ∈ ℝ³:           # 中心位置 (3D coordinates)
    r ∈ ℝ⁴:           # 旋转四元数 (rotation quaternion)
    s ∈ ℝ³:           # 缩放向量 (scale vector)
    α ∈ ℝ:            # 不透明度 (opacity value)
    c ∈ ℝ^k:          # SH系数 (spherical harmonics coefficients)
}
```

**规范空间定义：**
- 第一个输入视图I₁作为全局参考坐标系
- 所有高斯在此规范空间中对齐

**数学表示：**
```
{G^{v→1}}_{v=1,...,N} = {(μ_j^{v→1}, α_j^v, r_j^{v→1}, s_j^v, c_j^{v→1})}_{j=1,...,H×W}
```

#### 2.2.4 Pose Estimation（位姿估计）

**设计目标：**
- 无需ground-truth位姿
- 单次前馈步骤估计相机位姿

**实现细节：**

1. **输入：**
   - 编码器和解码器的拼接和池化表示

2. **输出：**
   - 10维相对位姿：
     - 6D旋转表示
     - 4D齐次平移向量 [tx, ty, tz, 1]ᵀ

3. **转换矩阵：**
```
P^{v→1} = [R^{v→1}  t^{v→1}]
          [0ᵀ       1     ]

其中：
- R^{v→1} ∈ ℝ³ˣ³: 旋转矩阵
- t^{v→1} ∈ ℝ³:   平移向量
```

**坐标系一致性：**
- 第一个输入视图I₁定义为原点
```
P^{1→1} = [I  0]
          [0ᵀ 1]
```

#### 2.2.5 View-Dependent Head（视图依赖头）**核心创新组件**

**设计理念：**
- 采用Hypernetwork架构
- 预测像素级残差偏移

**工作流程：**

```
┌──────────────────────────────────────────────┐
│          View-Dependent Head                 │
│                                              │
│  输入：Geometry Transformer的特征tokens      │
│         (捕获几何和材质上下文)               │
│                                              │
│  处理：                                      │
│  ┌─────────────────────────────────────┐    │
│  │ 动态生成每个像素的View MLP参数      │    │
│  │ - 针对局部场景特性定制响应函数      │    │
│  │ - 高光表面：复杂映射                │    │
│  │ - 漫反射区域：简单函数              │    │
│  └─────────────────────────────────────┘    │
│                                              │
│  输出：像素级View MLP权重                   │
└──────────────────────────────────────────────┘
         │
         ▼
┌──────────────────────────────────────────────┐
│       View MLP (推理时)                      │
│                                              │
│  输入：目标相机位姿的4D表示                  │
│        - 3D单位观察方向                      │
│        - 1D距离项                           │
│                                              │
│  输出：高斯参数的残差偏移                    │
│        Δμ, Δα, Δr, Δs, Δc                   │
└──────────────────────────────────────────────┘
```

**关键优势：**

1. **上下文驱动的权重生成：**
   - 根据场景内容自适应
   - 不同表面类型采用不同策略

2. **位姿驱动的偏移计算：**
   - 实时响应目标视角
   - 捕捉高频外观变化

3. **分离设计：**
   - 不受静态预定义参数空间限制
   - 灵活适应各种视图依赖效果

```python
# 上下文视图位姿
context_poses = PoseHead(features)

target_pose = PoseTargetHead(context_features, target_features)
```

```python
# 生成像素级View MLP权重

# 这些权重是scene-conditioned的
```

**步骤5：损失计算**
```python
# 渲染损失
rendered_image = render(canonical_gaussians, target_pose)
L_render = MSE(rendered_image, gt_image) + λ * LPIPS(rendered_image, gt_image)

# 重投影损失（几何约束）
L_reproj = reprojection_loss(gaussian_centers, estimated_poses)

# 总损失
L_total = L_render + λ_reproj * L_reproj
```

#### 2.3.2 推理/渲染阶段

**步骤1：获取基础表示**
```python
# 从输入图像提取特征
features = GeometryTransformer(input_images)

# 获取规范高斯
canonical_gaussians = {
    'centers': GaussianCenterHead(features),
    'params': GaussianParamHead(features)
}

# 获取View MLP权重
view_mlp_weights = ViewDependentHead(features)

# 估计上下文位姿
context_poses = PoseHead(features)
```

**步骤2：目标位姿重参数化**
```python
# 原始目标位姿 P^{t→1} ∈ ℝ⁴ˣ⁴
target_pose_matrix = get_target_pose()

# 重参数化为4D表示
view_direction = normalize(target_pose_matrix[:3, 3])  # 3D单位观察方向
distance = compute_distance_metric(target_pose_matrix)  # 1D距离项
target_pose_4d = concat(view_direction, distance)       # 4D输入
```

**重参数化的好处：**
- 降低维度：从16个标量到4个
- 保留视图依赖线索
- 避免旋转矩阵的正交性约束

**步骤3：视图依赖细化**
```python
# 对每个像素的高斯
for pixel_j in all_pixels:
    # 构建该像素的View MLP
    mlp_j = build_mlp(view_mlp_weights[pixel_j])
    
    # 预测残差偏移
    offsets_j = mlp_j(target_pose_4d)
    # offsets_j = {Δμ, Δα, Δr, Δs, Δc}
    
    # 应用残差更新
    refined_gaussian_j = canonical_gaussians[pixel_j] + offsets_j

refined_gaussians = all refined_gaussian_j
```

**步骤4：渲染**
```python
# 使用细化后的高斯渲染目标视图
rendered_image = Rasterizer(target_pose, refined_gaussians)
```

**完整流程伪代码：**
```python
def viewsplat_render(input_images, target_pose):
    """
    ViewSplat渲染流程
    
    Args:
        input_images: N张输入图像
        target_pose: 目标相机位姿
    
    Returns:
        rendered_image: 渲染的目标视图
    """
    # 1. 特征提取
    features = geometry_transformer(input_images)
    
    # 2. 规范高斯重建
    gaussians = {
        'μ': gaussian_center_head(features),
        'r': rotation_head(features),
        's': scale_head(features),
        'α': opacity_head(features),
        'c': sh_head(features)
    }
    
    # 3. View MLP权重生成
    mlp_weights = view_dependent_head(features)
    
    # 4. 目标位姿重参数化
    pose_4d = reparameterize_pose(target_pose)
    
    # 5. 视图依赖细化
    for j in range(num_gaussians):
        mlp = build_mlp(mlp_weights[j])
        deltas = mlp(pose_4d)
        
        gaussians['μ'][j] += deltas['Δμ']
        gaussians['α'][j] += deltas['Δα']
        gaussians['r'][j] += deltas['Δr']
        gaussians['s'][j] += deltas['Δs']
        gaussians['c'][j] += deltas['Δc']
    
    # 6. 渲染
    rendered_image = rasterize(target_pose, gaussians)
    
    return rendered_image
```

#### 2.3.3 关键技术细节

**1. 目标位姿重参数化（Target Pose Reparameterization）**

**动机：**
- 原始4×4变换矩阵包含16个标量
- 矩阵约束（如旋转正交性）难以被MLP优化

**解决方案：**
```python
# 原始：P^{t→1} ∈ ℝ⁴ˣ⁴
# 重参数化：4D表示 (view_direction, distance)

view_direction = R^{-1} @ [0, 0, 1]^T  # 相机观察方向
distance = ||t||                        # 相机到原点距离

pose_4d = [view_direction_x,
           view_direction_y,
           view_direction_z,
           distance]
```

**优势：**
- 维度降低：16 → 4
- 几何意义明确
- 便于网络学习

**2. 高斯细化（Gaussian Refinement）**

**残差更新公式：**
```
μ̂ = μ + Δμ           (位置)
α̂ = α + Δα           (不透明度)
r̂ = r + Δr           (旋转)
ŝ = s + Δs           (缩放)
ĉ = c + Δc           (SH系数)
```

**残差表示的优势：**
- 零初始化：初始时保持基线重建
- 渐进学习：逐步学习视图自适应细化
- 稳定训练：避免大幅偏离规范表示

**3. View MLP架构**

```python
class ViewMLP:
    """
    像素级视图MLP
    
    架构：单隐藏层
    输入：4D目标位姿
    输出：高斯参数偏移
    """
    def __init__(self, weights):
        self.hidden_dim = 16  # 隐藏层维度
        self.weights = weights  # 由View-Dependent Head生成
    
    def forward(self, pose_4d):
        # 输入：4D
        # 隐藏层：16D
        # 输出：Δ(μ,α,r,s,c)
        
        h = relu(self.weights['W1'] @ pose_4d + self.weights['b1'])
        out = self.weights['W2'] @ h + self.weights['b2']
        
        return {
            'Δμ': out[0:3],
            'Δα': out[3],
            'Δr': out[4:8],
            'Δs': out[8:11],
            'Δc': out[11:]
        }
```

### 3.1 空间理解和表示

#### 3.1.1 ViewSplat的空间表示方法

**1. 显式3D表示**

ViewSplat采用显式的高斯基元表示空间：

```python
空间 = {高斯基元_i}_{i=1}^{N}

每个基元 = {
    位置: μ_i ∈ ℝ³,
    旋转: R_i ∈ SO(3),
    缩放: S_i ∈ ℝ³,
    不透明度: α_i ∈ [0,1],
    外观: c_i (SH系数)
}
```

**空间表示的特性：**

| 特性 | ViewSplat | 隐式表示(如NeRF) |
|------|-----------|------------------|
| 表示类型 | 显式（离散基元） | 隐式（连续函数） |
| 渲染速度 | 实时（>100 FPS） | 较慢（通常<1 FPS） |
| 空间查询 | 直接访问 | 需要网络推理 |
| 几何可解释性 | 高 | 低 |
| 内存占用 | 与基元数量成正比 | 与网络大小相关 |

**2. 规范空间（Canonical Space）**

ViewSplat定义了一个规范坐标系：

```
规范空间 = 第一个输入视图的坐标系

优势：
1. 提供全局一致的参考框架
2. 简化多视图融合
3. 便于相对位姿估计
```

**3. 视图自适应表示**

ViewSplat的关键创新：空间表示不是静态的

```
静态表示：空间 = 固定的高斯基元
ViewSplat：空间 = f(基础基元, 观察视角)

这意味着：
- 空间表示随观察角度动态调整
- 能够捕捉视角依赖的几何和外观
- 更接近人类感知（观察角度影响理解）
```

#### 3.1.2 与人类空间认知的对比

**人类空间理解的特点：**

1. **多模态融合：**
   - 视觉、触觉、运动感知等

2. **层次化表示：**
   - 物体 → 场景 → 环境
   - ViewSplat是场景级表示

3. **主动感知：**
   - 人类主动移动以获取信息
   - ViewSplat是被动的（给定输入）

4. **语义理解：**
   - 理解"是什么"，不仅仅是"长什么样"
   - ViewSplat缺乏语义层次

### 4.1 主要创新点

#### 4.1.1 概念创新：从静态到动态表示

**创新1：视图自适应范式**

传统方法：

**核心差异：**
- 传统：一个表示服务所有视角
- ViewSplat：表示随视角动态调整

- 解决了单步回归的ill-posed问题
- 使学习目标更可行
- 捕捉复杂的视角依赖效果

**创新2：Hypernetwork架构在3D重建中的应用**

**优势：**

- 不同区域自适应复杂度
- 更高的表示能力

#### 4.1.2 技术创新

**创新3：全面的高斯属性细化**

### 5.1 数学公式详解

#### 5.1.1 高斯基元参数化

**完整的高斯表示：**

```
𝒢 = {μ, r, s, α, c}

其中：
- μ ∈ ℝ³: 高斯中心位置
- r ∈ ℝ⁴: 旋转四元数（单位四元数）
- s ∈ ℝ³: 三个轴的缩放因子
- α ∈ ℝ: 不透明度（通过sigmoid限制到[0,1]）
- c ∈ ℝ^{3(1+l)²}: SH系数（l阶SH）
```

**协方差矩阵：**

```
Σ = R · S · S^T · R^T

其中：
- R: 由四元数r导出的3×3旋转矩阵
- S: 对角缩放矩阵 diag(s)
```

**3D高斯函数：**

```
G(x) = α · exp(-½ (x-μ)^T Σ^{-1} (x-μ))
```

#### 5.1.2 View-Dependent细化公式

**残差更新：**

```
𝒢̂ = 𝒢_{canonical} + Δ𝒢_{view}

展开：
μ̂ = μ + Δμ(pose_t)
α̂ = α + Δα(pose_t)
r̂ = r + Δr(pose_t)
ŝ = s + Δs(pose_t)
ĉ = c + Δc(pose_t)
```

**View MLP：**

```
Δ𝒢 = MLP_view(pose_4d; W_view)

其中：
- pose_4d = [d_x, d_y, d_z, dist]
- d: 单位观察方向向量
- dist: 相机距离
- W_view: 由View-Dependent Head生成的权重
```

#### 5.1.3 损失函数

**渲染损失：**

```
ℒ_render = (1-λ) · ||Î - I||² + λ · LPIPS(Î, I)

其中：
- Î: 渲染图像
- I: 真实图像
- LPIPS: 感知相似度度量
- λ: 平衡系数
```

**重投影损失：**

```
ℒ_reproj = Σ_j ||π(P^{v→1}, μ_j) - p_j||²

其中：
- π: 投影函数
- P^{v→1}: 估计的相机位姿
- μ_j: 高斯中心
- p_j: 对应的2D像素
```

**总损失：**

```
ℒ_total = ℒ_render + λ_reproj · ℒ_reproj
```

```python
class ViTEncoder:
    def __init__(self):
        self.patch_size = 16
        self.embed_dim = 768
        self.depth = 12
        self.num_heads = 12
    
    def forward(self, image):
        # 1. Patch embedding
        patches = PatchEmbed(image, self.patch_size)  # [N_patches, embed_dim]
        
        # 2. 位置编码
        patches += PositionalEncoding(patches.shape)
        
        # 3. Transformer blocks
        for block in self.blocks:
            patches = TransformerBlock(patches)
        
        return patches
```

**解码器（MASt3R风格）：**

```python
class Decoder:
    def forward(self, features_view1, features_view2):
        # 成对交叉注意力
        for decoder_block in self.blocks:
            # 视图1 attend to 视图2
            features_view1 = CrossAttention(
                query=features_view1,
                key_value=features_view2
            )
            
            # 视图2 attend to 视图1
            features_view2 = CrossAttention(
                query=features_view2,
                key_value=features_view1
            )
        
        return features_view1, features_view2
```

#### 5.2.2 DPT Head

```python
class DPTHead:
    """Dense Prediction Transformer Head"""
    
    def __init__(self, output_dim):
        self.reassemble_blocks = ReassembleBlocks()
        self.fusion_blocks = FusionBlocks()
        self.output_conv = Conv(output_dim)
    
    def forward(self, encoder_features, decoder_features):
        # 1. 从编码器提取多尺度特征
        multi_scale = self.reassemble_blocks(encoder_features)
        
        # 2. 与解码器特征融合
        fused = self.fusion_blocks(multi_scale, decoder_features)
        
        # 3. 输出预测
        output = self.output_conv(fused)
        
        return output
```

#### 5.2.3 View-Dependent Head架构

```python
class ViewDependentHead:
    def __init__(self, feature_dim):
        # DPT架构预测MLP权重
        self.dpt = DPTHead(
            output_dim=calculate_mlp_weight_size()
        )
    
    def forward(self, features):
        # 预测每个像素的View MLP权重
        # 输出形状：[H, W, weight_size]
        weights = self.dpt(features)
        
        return weights

def calculate_mlp_weight_size():
    # View MLP: input(4) -> hidden(16) -> output(所有偏移)
    
    # 隐藏层权重
    W1_size = 4 * 16  # input_dim * hidden_dim
    b1_size = 16      # hidden_dim
    
    # 输出层权重
    # 输出：Δμ(3) + Δα(1) + Δr(4) + Δs(3) + Δc(k)
    output_dim = 3 + 1 + 4 + 3 + k
    W2_size = 16 * output_dim  # hidden_dim * output_dim
    b2_size = output_dim
    
    return W1_size + b1_size + W2_size + b2_size
```

```python
def train_viewplat(dataloader, model, epochs):
    # 初始化
    model.load_pretrained_spfsplat()
    freeze_backbone(model)
    zero_init_view_dependent_head(model)
    
    optimizer = Adam(
        model.view_dependent_head.parameters(),
        lr=1e-4
    )
    
    for epoch in range(epochs):
        for batch in dataloader:
            context_images = batch['context']
            target_image = batch['target']
            
            # 前向传播
            outputs = model(context_images, target_image)
            
            # 计算损失
            render_loss = compute_render_loss(
                outputs['rendered'],
                target_image
            )
            reproj_loss = compute_reproj_loss(
                outputs['gaussians'],
                outputs['poses']
            )
            total_loss = render_loss + 0.1 * reproj_loss
            
            # 反向传播
            optimizer.zero_grad()
            total_loss.backward()
            optimizer.step()
        
        # 课程学习：增加帧距离
        dataloader.increase_frame_distance()

def freeze_backbone(model):
    # 冻结预训练部分
    for param in model.geometry_transformer.parameters():
        param.requires_grad = False
    for param in model.gaussian_heads.parameters():
        param.requires_grad = False
    for param in model.pose_head.parameters():
        param.requires_grad = False
```

```python
            # 3. 执行动作
            self.动作执行.执行(动作)
            
            # 4. 反馈循环
            验证结果 = self.验证动作(动作)
            if not 验证结果.成功:
                self.重新规划()
```

### 7.3 关键挑战

#### 7.3.1 技术挑战

**挑战1：可扩展性**

```
ViewSplat当前：
- 单场景（一个房间）
- 静态
- 少量视图

Spatial AGI需要：
- 大规模环境（整个建筑/城市）
- 动态变化
- 持续感知

解决方案方向：
1. 层次化表示（局部-全局）
2. 增量更新机制
3. 压缩和索引技术
```

**挑战2：多任务学习**

```
ViewSplat：单任务（新视图合成）

Spatial AGI：多任务
- 导航
- 操作
- 对话
- 问答
- 规划

挑战：
- 任务冲突
- 负迁移
- 计算资源

可能方案：
- 任务条件化架构
- 多头输出
- 渐进式多任务学习
```

**挑战3：长期记忆与推理**

```
ViewSplat：瞬时重建

Spatial AGI需要：
- 长期记忆
- 场景变化跟踪
- 历史推理

技术需求：
1. 紧凑的空间记忆表示
2. 高效的检索机制
3. 时序推理能力
```

#### 7.3.2 系统挑战

**挑战4：实时性与准确性平衡**

```
ViewSplat：17 FPS推理

Spatial AGI可能需要：
- 更高帧率（机器人控制）
- 更低延迟（交互）
- 更准确（安全关键）

权衡：
- 快速粗略表示 + 精细异步更新
- 多分辨率表示
- 任务自适应精度
```

**挑战5：鲁棒性**

```
ViewSplat假设：
- 静态场景
- 充足重叠
- 良好光照

Spatial AGI现实：
- 动态物体
- 遮挡和稀疏视图
- 光照变化

需要：
- 异常检测和处理
- 不确定性估计
- 失败恢复机制
```

### 8.1 ViewSplat核心贡献总结

#### 8.1.1 技术贡献

1. **范式创新：**

2. **架构创新：**
   - View-Dependent Head with Hypernetwork
   - 动态生成像素级View MLP
   - 全面细化所有高斯属性

3. **性能成就：**
   - 最先进的保真度（PSNR 26.798）
   - 保持实时性能（154 FPS）
   - 优异的跨数据集泛化

### 8.4 结语

ViewSplat代表了3D视觉和神经渲染领域的重要进展。它不仅解决了feed-forward 3DGS的保真度瓶颈，更重要的是展示了动态表示机制的威力。

对于Spatial AGI的发展，ViewSplat提供了宝贵的启示：

1. **空间表示不应是静态的** - 应该根据任务、视角、上下文动态调整
2. **显式与隐式的平衡** - 高斯的显式性 + MLP的隐式灵活性
3. **残差学习的力量** - 基础表示 + 任务特定调制
4. **架构创新的重要性** - Hypernetwork等机制可以显著提升能力

尽管ViewSplat仍有局限性（无生成能力、仅静态场景、无语义理解），但它为未来的研究奠定了坚实基础。我们期待看到基于ViewSplat的进一步创新，最终实现真正的通用Spatial AGI。
