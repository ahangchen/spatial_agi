# Physical Diffusion Policy via MPM-Guided 3D Gaussian Simulation

**发表日期**: 2026-11-03
**arXiv链接**: https://arxiv.org/abs/2611.04493
**PDF链接**: https://arxiv.org/pdf/2611.04493
**HTML版本**: https://arxiv.org/html/2611.04493v1

**机构**: The University of Hong Kong

## 论文概览

这篇论文解决一个具体而关键的问题：**扩散策略（diffusion policy）会把不同材料的物体"平均化"**——软的果冻和硬的积木在视觉上相似，但需要完全不同的抓握力与速度。现有扩散策略把物体当纯视觉实体，缺乏物理属性意识。作者的方案是：

1. 用前馈 3DGS 重建物体 → 绑定到 MPM（Material Point Method）粒子 → 可微物理仿真；
2. 用演示视频做监督，**反向**优化出物体的材料参数（杨氏模量 E、泊松比 ν、屈服应力 τY、粘度 η）；
3. 把估计出的物理参数作为条件，注入**材料感知的 MoE 扩散策略**；
4. 部署时用**物理记忆库（physics memory bank）**检索相似物体的参数，免去在线仿真优化。

## 核心问题

### Q1: 这篇文章的核心算法原理是什么？

**1) 核心思想和动机**

- 人类操作者会根据材料的刚度、可变形性、柔顺性自适应调整行为；机器人只依赖视觉观察和演示，遇到材料不同的异质物体时，单一策略会输出"平均化的、两头不讨好"的动作。
- 传统系统辨识需要专门设计的交互、力测量或物体专用仿真器，无法规模化。
- 可微仿真（differentiable simulation）提供了机会：通过把仿真结果对观测做梯度优化来反推物理参数。但已有可微仿真工作只做参数估计或 sim-to-real，没有把物理理解**注入策略学习**。
- 本文立场：**仿真不应只是训练环境，而应作为策略的"物理推理模块"**——从视觉演示反演材料属性，然后作为条件喂给策略。

**2) 主要技术方法**

**(a) 可微物理场景表示：FF-3DGS + MPM 一一绑定**

- 多视角图像（环绕半球视频均匀采样 64 帧）→ ZFormer 前馈 3DGS 一次性重建高斯集合 G={Gk}，每个高斯有中心 μk、不透明度 αk、旋转 rk、尺度 sk、颜色 ck。
- 建立 MPM 粒子系统 P={Pk}，与高斯一一对应。每个粒子携带速度 vk、质量 mk、体积 Vk、形变梯度 Fk，以及本构参数 θ={E, ν, τY, η}。
- 高斯中心跟随粒子运动：μk^t = xk^t；
- 高斯协方差随粒子形变更新：对形变梯度做极分解 Fk^t = Rk^t·Sk^t，则 Σk^t = Rk^t·Σk^0·(Rk^t)ᵀ。
- MPM 是混合欧拉-拉格朗日方法：P2G（粒子→网格）算力、G2P（网格→粒子）更新状态，形变梯度更新为 F^{t+1} = (I + Δt∇v^{t+1})·F^t。
- 由于仿真器与可微光栅化器都可微，图像重建损失可以一路反传：渲染像素 → 高斯 → 粒子动力学 → 物理参数 θ。

**(b) 物理引导的可微仿真（参数反演）**

- **VLM 冷启动初始化**：用视觉语言模型对物体材料类别做粗略估计，为 θ 提供初值——物理先验从语义知识中来。
- **材料感知参数裁剪**：VLM 估计可能不准，梯度更新也可能越界。对每个参数 θi 按推断的材料类别定义可行区间 [θi_low, θi_up]，初值和每次梯度更新后都投影回区间：θi ← clip(θi, θi_low, θi_up)。这是把"语义类别→物理量级"的先验硬编码为约束。
- **视频引导优化**：最小化仿真动力学与演示视频观测的差异，梯度穿过可微光栅化器反传到 θ。
- **粒子级物理约束**：
  - **Dirichlet 边界条件**：对操作事件（夹爪接触处粒子）施加边界约束，保证仿真与演示中接触行为一致；
  - **几何一致性约束**：时间 Chamfer 距离对齐仿真粒子云与演示视频观测的几何，约束粒子轨迹贴合真实运动。
- 目标是估计物体专属的材料参数：弹性（E, ν）、塑性（τY）、粘性（η）相关属性。

**(c) 材料感知 MoE 扩散策略**

- 策略输入：语言指令 + 静态相机与腕部相机观测 + 估计的物理参数 θ。
- 采用 Mixture-of-Experts 架构：**学习型路由器（router）根据物理参数动态选择材料专属专家**，不同物理 regime（弹性主导/塑性主导/粘性主导）由不同专家生成动作轨迹，避免单一网络对异质材料做动作平均。
- 输出：去噪后的机器人动作与夹爪状态。

**(d) 物理记忆库（physics memory bank）**

- 训练阶段把估计过的物体物理参数归档；
- 部署时对新物体**检索**最相近的物理参数（而非重新跑昂贵的在线仿真优化），直接喂给策略；
- 效果：绕开在线物理参数优化的计算成本，同时保持物理一致的操作行为。

**3) 算法流程和关键步骤**

```
多视角视频（64帧）
  → FF-3DGS（ZFormer）一次性重建高斯
  → 高斯↔MPM粒子一一绑定，构建可微物理场景
  → VLM 初估材料参数 θ₀ → 按材料类别裁剪到可行区间
  → 可微仿真 rollout + 可微渲染
  → 与演示视频比对（图像损失 + Dirichlet边界 + 时间Chamfer几何约束）
  → 梯度反传更新 θ（每次更新后再裁剪）
  → θ 注入材料感知 MoE 扩散策略联合训练
  → 部署：物理记忆库检索 θ，策略直接推理，无在线仿真
```

**4) 输入输出**

- **参数估计阶段输入**：环绕物体的多视角视频；输出：物理参数 θ={E, ν, τY, η}。
- **策略阶段输入**：语言指令、双相机观测、θ；输出：连续机器人动作块 + 夹爪状态。
- **部署阶段输入**：单次（或少视角）观测 → 记忆库检索 θ → 策略推理。

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**1) 如何理解和表示空间**

本文的空间表示是**"视觉-物理双层"的**：3DGS 层负责外观与几何（空间怎么看起来），MPM 层负责物理动力学（空间怎么变化、受力后如何响应）。两层用一一绑定+形变传播（极分解协方差更新）耦合。这种"几何为皮、物理为骨"的表示，把空间从"静态几何"升级为"带材料属性的动力学介质"——对 Spatial AGI 来说，这是空间表示从感知层走向物理常识层的关键一步。

**2) 如何处理空间关系**

- **接触空间关系**：Dirichlet 边界条件显式建模了"夹爪-物体"接触这一最关键的空间关系，把操作事件的空间语义注入物理仿真。
- **形变空间关系**：粒子级形变梯度与 Chamfer 几何约束，刻画了物体内部各部分在操作过程中的相对空间演化。
- **跨物体关系泛化**：物理记忆库用"物理参数相似性"而非"视觉相似性"组织物体间关系——两个长得不一样的物体，只要材料参数接近，就应该用相似的操作策略。这是对空间关系的一种非视觉度量。

**3) 对 Spatial AGI 的启发**

- **物理常识应该是空间智能的一等公民**：VLM 给物理参数提供先验、可微仿真做精调的分工，暗示了"语义大模型提供量级假设、物理引擎负责精确校验"的通用 Spatial AGI 架构模式。
- **可微性打通感知-物理-控制**：整条链路（像素→高斯→粒子→参数→策略）全程可微，说明空间智能的各层可以端到端梯度耦合，而不必是离散的模块拼接。
- **记忆库模式**：物理记忆库是"从经验中积累物理常识"的雏形——Spatial AGI 的长期记忆不一定要存向量化的情景，也可以存结构化的物理参数。
- **避免动作平均化**：MoE 按物理 regime 分专家的设计原则，可推广到任何"异质条件导致多峰行为分布"的空间决策场景。

**4) 可以应用的 Spatial AGI 场景**

- 可变形物体操作（食品、织物、软体物件）的通用策略；
- 家庭机器人对日常异质物体的自适应操作；
- 机器人学习的数据引擎：估计出的物理参数可直接用于仿真数据增广（Real2Sim）；
- 触觉缺失场景下的"视觉推断物理"（vision-inferred physics）；
- 空间物理推理基准的构建：材料参数 ground truth 可由本框架批量估计。

### Q3: 基于前面的分析，这个方法的主要创新点和局限性是什么？

**1) 主要创新点**

1. **逆向使用 3DGS-MPM**：已有 3DGS+MPM 工作（PhysGaussian、PhysDreamer 等）都是"给定材料参数做正向动画/渲染"，本文反过来"从视频反演材料参数"，且把结果用于策略条件而非图形学应用——问题视角的翻转是最大创新。
2. **VLM 初始化 + 材料感知裁剪**：巧妙地把语义先验与硬物理约束结合，既加速收敛又防物理荒谬解。
3. **材料感知 MoE 扩散策略**：以物理参数驱动专家路由，直接对治"动作平均化"痛点。
4. **物理记忆库**：工程上关键的一步——把昂贵的可微仿真反演从部署路径上摘掉，用检索替代优化。

**2) 主要局限性**

1. **参数可辨识性问题**：从纯视觉（无力/触觉传感）反演 {E, ν, τY, η} 四个参数，本质上是病态逆问题。视频里"看起来软"可能由多个参数组合解释，可行区间裁剪缓解但不消除歧义。论文未报告参数估计的 ground truth 误差。
2. **FF-3DGS 重建质量的上限**：前馈重建的几何/外观噪声会传导进 MPM 粒子初始化，对透明、反光、细小物体可能失效。
3. **MPM 本构模型的适用范围**：MPM+固定本构族适合连续介质材料，对刚体、铰接体、流体混合场景需要扩展。
4. **记忆库的冷启动与近邻风险**：新材料物体若不在记忆库分布内，检索到的参数可能误导策略；记忆库的组织方式（如何定义"物理相似"）论文着墨不多。
5. **仿真-真实材料残差 gap**：可微仿真校准仍基于本构模型假设，真实材料的非线性、率相关性、各向异性未必被四参数捕获。

**3) 与其他相关工作的对比**

| 维度 | 本文 | Diffusion Policy/DP3/3D Diffuser Actor | PhysGaussian/PhysDreamer 类 | 传统系统辨识 |
|------|------|----------------------------------------|------------------------------|--------------|
| 物理意识 | 显式参数条件 | 无 | 有但参数预设 | 有 |
| 参数来源 | 视频反演（VLM先验+可微仿真） | 无 | 人工指定 | 力测量/专门交互 |
| 用途 | 策略条件 | — | 动画/图形 | 工程辨识 |
| 部署成本 | 低（记忆库检索） | 低 | — | — |
| 可微性 | 全链路可微 | 部分 | 渲染可微 | 否 |

**优势**：唯一把"视觉反演物理参数"闭环进策略条件的框架；部署零仿真成本。
**劣势**：参数辨识的病态性未量化；对刚体/铰接体不友好；依赖 FF-3DGS 重建质量。

## 核心技术发现

- **发现1**：3DGS 高斯与 MPM 粒子一一绑定 + 极分解协方差传播，构成视觉-物理双层可微表示的最小可行方案。
- **发现2**：VLM 可以充当物理参数的"量级先验提供者"，把病态逆问题约束到物理合理区间。
- **发现3**：Dirichlet 边界条件 + 时间 Chamfer 距离两组约束，让视频监督足以驱动粒子级参数反演。
- **发现4**：按物理 regime 分专家的 MoE 比单一策略在异质材料上显著减少动作平均化。
- **发现5**：物理记忆库证明"检索代替在线优化"在物理参数层面可行。

## 个人思考

### 最令人兴奋的发现
VLM 粗估 + 可微仿真精调的分工。这实际上回答了"大模型的物理常识如何落地为精确数值"这个老大难：语言模型知道"果冻比积木软"这种序数关系，但给不出 5 kPa 还是 50 kPa；可微仿真把序数先验锚定为绝对数值。这个"LLM给方向、梯度给数值"的模式我认为可以推广到质量、摩擦、阻尼等一切物理量。

### 潜在局限
纯视觉反演物理参数的可辨识性是我最大的疑虑。没有触觉反馈的闭环，视频观测对参数的约束可能存在系统性简并（比如高粘度+低屈服应力和中粘度+中屈服应力可能产生几乎相同的形变视频）。我预期后续工作会加入触觉或多视角力线索来正则化这个逆问题。另外记忆库检索的"物理相似性度量"若只基于参数欧氏距离，在参数量纲差异大时会很脆弱。

### 与昨日研究的关联
昨天精读的 AuroraWorld（结构化 4D 世界建模）强调世界模型需要超越像素的结构化状态；本文正好给出了一个具体的结构化维度——材料物理参数。两者互补：AuroraWorld 式的世界模型若把估计出的材料参数作为显式状态通道，其对可变形物体未来预测的物理一致性应会提升。这条"从演示中反演物理参数 → 注入世界模型/策略"的管线，可能是空间智能物理常识获取的标准范式。

## 总结

### 核心发现总结
本文把可微物理仿真从"参数估计工具"升格为"策略的物理推理模块"：FF-3DGS+MPM 双层可微表示支撑视频反演材料参数，VLM 先验与物理裁剪保证可辨识性，MoE 扩散策略消费参数生成材料自适应动作，记忆库让部署摆脱在线仿真。
