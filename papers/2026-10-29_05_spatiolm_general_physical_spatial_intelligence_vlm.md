# SpatioLM: Towards General Physical Spatial Intelligence in Vision-Language Models

**发表日期**: 2026-08-03（ICML 2026，PMLR 306）
**arXiv链接**: https://arxiv.org/abs/2608.01899
**PDF链接**: https://arxiv.org/pdf/2608.01899
**作者**: Jing Wu*, Jianhua Wu*, ..., Long Chen✉（小米 EV + 同济大学）

## 一句话总结

不加 3D 先验输入、不加外部空间编码器、不微调主干：冻结 VLM，在中间层视觉 token 上挂一个 ControlNet 式的"空间视觉模块"（6×50M 参数，VGGT 式帧内/全局交替注意力），用伪深度+相机射线图做双重 DPT 辅助监督，经零初始化投影把几何感知 token 注回 LM 各层——VSI-Bench 71.6（首个破 70），深度任务 MD-S 83.5，通用能力几乎无损（VideoMMMU 还 +12%），并可直接迁移到 LIBERO 操作（79.2%→96.3%）。

## 核心问题

### Q1: 核心算法原理

**问题**: 这篇文章的核心算法原理是什么？

**分析**:

1. **核心思想和动机**

   VLM 语义强、空间弱，3D 度量推理差。现有三条路线各有硬伤：
   - **显式几何增强**（SpatialBot/DepthLM/RoboRefer 等）：喂深度图/点云/相机参数——依赖传感器或脆弱的估计流水线，限制开放世界 RGB-only 场景的鲁棒性和可扩展性；
   - **架构级改造**（SpatialLLM/VLM-3R/Spatial-MLLM 等）：外挂空间编码器+大规模 3D 数据微调——侵入式微调破坏预训练特征分布，通用能力显著退化；
   - **工具使用/Agentic**（ViperGPT 类、RL+verifier）：VLM 当高层规划器调外部 API——多步延迟、API 错误级联，且视觉骨干的内在空间推理根本没改善。

   核心问题："如何在不要外部 3D 输入、不要第三方编码器的前提下，端到端按需激发 VLM 内在的空间结构，且不牺牲通用智能？"

   核心假设（来自近期发现）：VLM 视觉编码器的**中间层** token 比最终层蕴含更丰富的空间/几何信息——空间知识已经在预训练权重里，只是没被 elicited（激发）出来。

2. **主要技术方法**

   **核心范式："Frozen Backbone + Plug-and-Play SV-Module"**

   - **视觉条件**：视觉编码器与 LLM 全部冻结。从 24 层 ViT 的第 16 层取中间视觉 token H'v0（经验上 16/24 层空间嵌入最强，引 Bolya et al. 2026），区别于送入 LLM 的最终层 token。
   - **空间特征激发（Spatial Feature Elicitation）**：SV-Module 由 K=6 个 SV-Block 组成（每块仅 50M 参数），与 LM Block 严格一一对应（间隔 s 层放置一次）。第 i 个 SV-Block 处理第 j−1 个 LM block 输出的视觉 token 子集 Hv(j−1)=Hm(j−1)[Iv]（Iv 为视觉 token 索引集）：
     Hg_i = Msv(Hv(j−1) + Pz(Hg(i−1)))
     其中 Msv 是 SV-Block 计算，Pz 是零初始化投影。
   - **零初始化投影注入**：融合方式为 Ĥm_j[Iv] = Hm_j[Iv] + Pz(Hg_i)，替换回多模态 token 序列后进入冻结 LM block。零初始化保证训练起点不扰动预训练分布（ControlNet 式 side-tuning），推理时可灵活启用/停用（即插即用）。
   - **Spatio-Vision Block**：借鉴 VGGT 的**交替注意力**——Frame Attention（帧内独立注意力，保留细粒度几何细节）与 Global Attention（跨帧全 token 注意力，聚合多视角/时序几何一致性）各交替一次；只存在于 SV-Block 内部，不修改冻结 LLM 的因果自注意力。
   - **Dual DPT Head（训练期专用）**：几何感知特征 Hg 送入来自 Depth Anything V3 的双分支 DPT 头，预测（a）稠密深度图 D̂（度量或相对深度，依监督而定）、（b）相机射线图 R̂（由内外参编码的逐像素视线方向）。用伪深度+相机信息作为辅助监督，引导模型学习物理一致的表征（形式化为 P(Y_t, Y_g | Xv, Xt) = P(Y_g|·)·Π P(y_i | y<i, Y_g, ·)）。
   - **推理**：DPT 头可拆除；SV-Module 仅在 prefilling 时前向一次编码空间上下文，之后就是标准 VLM 解码（KV cache），零额外推理开销。

   **训练数据**：15 个数据集统一低层感知与高层理解，覆盖室内/室外、真实/合成（ScanNet、ScanNet++、MVS-Synth、ARKitScene、Waymo、Virtual KITTI 2、Hypersim、VSI-590K、ScanQA、SQA3D、VSI-Bench 任务、深度任务等），643K QA 对 + 20K 视频；严格只用官方训练 split 防泄漏。两个配置：SpatioLM_SenseNovaSI-8B（InternVL3 架构）与 SpatioLM_InternVL3.5-8B；64×H200，感知任务 600 epoch、理解任务 2 epoch。

3. **算法流程和关键步骤**

   图像/视频 → 冻结视觉编码器（取第 16 层中间 token）→ SV-Block 交替注意力激发几何感知 token + DPT 辅助监督（仅训练）→ 零投影注入对应 LM 层 → 冻结 LLM 解码文本答案（推理无额外开销）。

4. **输入输出**

   - 输入：纯 RGB 图像/视频 + 文本指令（无任何 3D 先验）。
   - 输出：文本回答（距离数值、速度、方位、路线规划、物体计数等）；训练期额外输出深度图+射线图。

### Q2: 与Spatial AGI的关系

**分析**:

1. **如何理解和表示空间**

   SpatioLM 的立场是"空间知识是预训练 VLM 的潜在能力，不是外来的输入模态"——空间不是以点云/深度图形式**加入**模型，而是从视觉 token 里**激发**出来。它用伪深度和射线图作为训练期的"物理一致性脚手架"（supervision），推理期完全隐去。这给出一种中间道路的空间表示观：**隐式 3D 结构内嵌于视觉 token 分布中，只需旁路计算显式化**。

2. **如何处理空间关系**

   - 帧内/帧间分离的交替注意力显式对应"单帧几何结构"与"多视角/时序几何一致性"两类空间关系；
   - 空间增强 token 在 LM 各层间**反复注入**（每 s 层一次），而非只在入口注入——空间信息深度参与语言推理的全过程；
   - 任务谱系从低层感知（米制深度、点距）到高层理解（VSI-Bench 的房间面积、路线规划、时序出现顺序）统一处理。

3. **对Spatial AGI的启发**

   - **"激发 vs 注入"的路线选择**：CL4D（今日第 4 篇）代表"注入"路线（几何原生输入），SpatioLM 代表"激发"路线。两者在动态场景 VQA 上直接竞争的问题域，但 SpatioLM 赢在通用能力保留与部署零开销（RGB-only、无传感器依赖），CL4D 赢在几何保真度。Spatial AGI 可能两条路都要：部署受限场景用激发，几何密集场景用注入。
   - **非侵入式改造是保住通用性的关键**：Spatial-MLLM 通用能力跌 8-25%，SpatioLM 基本持平甚至 +12%——对"空间智能不应以牺牲通用智能为代价"这一 Spatial AGI 基本要求给出了架构答案。
   - **伪监督的杠杆**：用 Depth Anything V3 的伪标签+相机射线做辅助监督就能激发空间能力，说明高质量几何基础模型的输出可以低成本蒸馏进 VLM——再次呼应本周"几何基础模型作为空间任务监督源"的主线。

4. **可以应用的Spatial AGI场景**

   现有 VLM 的空间能力升级（即插即用、可卸载）、具身操作 VLA（LIBERO 四套件统一策略）、自动驾驶空间推理（小米 EV 背景，Waymo/VKITTI 数据）、RGB-only 部署的机器人空间问答。

### Q3: 创新点和局限性

**分析**:

1. **主要创新点**

   - **非侵入式空间激发范式**：首个"冻结 VLM+旁路 SV-Module+零投影注入"的空间智能方案，同时解决"加 3D 输入不可扩展"和"改架构伤通用性"的两难；
   - **中间层 token 激发**：利用中间 ViT 层空间信息更丰富的发现，从第 16 层取 token 作为激发起点——这是"空间知识已存在于预训练权重"假设的直接实现；
   - **伪深度+射线图双重辅助监督**：训练期给物理一致性梯度，推理期零负担；
   - **感知-理解-VLA 三级验证**：VSI-Bench 71.6 首破 70；LIBERO 从 79.2→91.0（离散）/95.3→96.3（连续），2B 参数无机器人预训练即有竞争力。

2. **主要局限性**（作者自述+分析）

   - **伪标签天花板**：依赖 Depth Anything V3 等教师模型的伪标签，教师误差必然传播，为 3D 理解上限设限；
   - **运动-静态权衡**：几何监督强调静态空间结构，与时间动态线索部分竞争——MVBench 运动密集子任务（动作计数、运动方向）退化，作者承认需要补充显式时间信号（这正是 CL4D 类 4D 编码器的用武之地）；
   - 安全关键场景不可靠（作者明示）；
   - SV-Module 每块 50M×6=300M 参数虽小但非零，且 prefilling 时多一遍前向；
   - 评测集里 MD-S/MD-M/DR 为自建基准，主场成分存在；伪深度监督本质上是"蒸馏另一个网络的空间能力"，真正的开放式空间泛化（从未见过的极端视角/尺度）未验证。

3. **与其他相关工作的对比**

   - vs **Spatial-MLLM**（外挂空间编码器代表）：VSI/深度任务相当或更好，但通用能力保留完胜（Spatial-MLLM 在 MMMU/VideoMMMU/MVBench 跌 8~25%，SpatioLM ≈0 或 +12%）；
   - vs **DepthLM/SpatialBot**（3D 先验输入）：不依赖深度图/相机参数输入，开放世界 RGB-only 可部署；
   - vs **SenseNovaSI-8B**（自家基座）：同基座下 MD-S 52.6→83.5、DA-2K 71.8→83.8、SQA3D ER1 50.1→58.6——SV-Module+伪监督的净增益清晰；
   - vs **CL4D/4DVLM**（今日第 4 篇）：SpatioLM 用 2D 输入激发内在空间能力；CL4D 用 4D 点云原生输入。在动态场景语言推理上 CL4D 声称几何优势，SpatioLM 声称通用性+部署优势，且 SpatioLM 自认缺时间信号——两者互补而非替代；
   - vs **DepthVLA/π0**（VLA）：SpatioLM-OFT 96.3 平均已超 π0（94.2）和 DepthVLA（94.9），但 LIBERO 基准偏静态桌面，差距的实际意义需谨慎。

## 核心技术发现

- VLM 中间层（约 16/24 层）视觉 token 蕴含的空间信息可被 6×50M 参数的旁路模块有效激发——空间能力是"锁着的"而非"没有的"。
- 伪深度+相机射线图辅助监督是激发物理一致表征的充分信号，无需真 3D 传感器输入。
- 零初始化投影+冻结主干使空间增强不破坏通用能力（对照外挂编码器方案的大幅退化）。
- 空间增强可零额外推理开销（prefilling 一次前向）并可直接迁移到 VLA 操作任务。
- 几何（静态）监督与运动动态线索存在竞争，需显式时间信号补足。

## 与Spatial AGI的关系

### 直接贡献
给"通用物理空间智能"提供了一个工程可落地的答案：任何预训练 VLM 都可以通过即插即用模块获得 SOTA 级空间感知/理解能力，同时保住通用智能——这是 Spatial AGI 作为"通用"系统的必要性质。

### 技术启发
- 中间层激发 > 输入端注入 > 全量微调的资源效率排序（在通用性保留意义上）；
- 伪几何监督（教师深度模型输出）是廉价而有效的空间脚手架；
- 空间增强应设计为可启停的运行时组件，而非模型固有改版。

### 应用场景
存量 VLM 空间能力升级、具身操作 VLA、自动驾驶空间推理、RGB-only 部署。

## 个人思考

### 最令人兴奋的发现
"冻结的 VLM 里已经藏着空间智能，300M 参数的旁路就能解锁"这一发现本身。它把空间智能的瓶颈从"预训练数据里没有 3D"重新定位为"现有训练目标没有要求模型表达 3D"。加上 VSI-Bench 71.6 首破 70 和通用能力零损失，这是 2026 年"激发派"路线目前最强证据。另一个细节值得注意：空间 token 每隔 s 层反复注入而非入口一次注入——几何信息需要在语言推理的每个抽象层级可用。

### 潜在局限
伪深度监督是双刃剑：它把 Depth Anything V3 的偏差（合成训练域、室内偏置、动态物体处理弱）固定进了 SpatioLM。而"激发"路线的天花板问题是根本性的——如果预训练分布里某类空间结构（如高频动态、大尺度户外几何）从未以可激发的形式存在，旁路模块再大也激发不出来。作者承认的 MVBench 运动退化正是这个天花板的露头。相比之下 CL4D 的"注入"路线在动态场景的优势提示：激发与注入的边界可能就是"静态空间 vs 动态空间"。

### 与今日其他研究的关联
今日五篇构成光谱两端：
- **几何生产端**：DepthWorld（世界模型深度监督）、SG²SLAM（动态 3DGS 地图）；
- **几何消费端-注入派**：CL4D/4DVLM（4D 点云原生输入，动态场景语言推理）；
- **几何消费端-激发派**：SpatioLM（纯 RGB 激发内在空间能力）；
- **检验端**：WorldSimProbe（动作→运动→响应的物理忠实度验收）。
SpatioLM 与 CL4D 的对比是本周最有意思的方法论张力：前者证明"空间知识可以低成本激发"，后者证明"几何原生输入在动态场景更强"。对 Spatial AGI 的启示是分层的：静态空间理解已可工程化（激发派够用），动态空间理解仍需几何原生表示（注入派），而两者都需要上游几何基础模型提供监督信号。

## 关键数据

- 架构：冻结 VLM（InternVL3/3.5 8B 或 SenseNovaSI-8B）+ 6 个 SV-Block（各 50M）+ 零初始化投影 + 双 DPT 头（训练期，Depth Anything V3 风格）；中间层取自 24 层 ViT 第 16 层
- 训练：15 数据集、643K QA + 20K 视频、64×H200、感知 600 epoch/理解 2 epoch
- 空间感知：MD-S 83.5 / MD-M 69.0 / DA-2K 83.8 / DR 41.8（SpatioLM_SenseNovaSI-8B，全面第一）
- 空间理解：VSI-Bench 71.6（首破 70，超全部 13 个对比模型）；ScanQA B1 48.4/CIDEr 101.8；SQA3D E1/ER1 56.5/58.6
- 通用能力：VideoMME/VideoMMMU/MVBench/MMMU 基本持平（VideoMMMU +12%），对比 Spatial-MLLM 跌 8-25%
- VLA 迁移（LIBERO 4 套件，每套 500 trials）：SpatioLM-VLA0（离散）91.0 vs 基线 79.2；SpatioLM-OFT（连续）96.3 vs 95.3，2B 参数无机器人预训练超 π0（94.2）/DepthVLA（94.9）
- 消融：SV-Module 使 MD-S +22.1（52.6→74.7）、DA-2K +12.2（71.8→84.0）

## 总结

### 核心发现总结
SpatioLM 证明预训练 VLM 的空间智能可以被小参数旁路模块"激发"而非"注入"：伪深度+射线图监督引导的即插即用 SV-Module 在感知/理解/VLA 三级任务全面领先，同时零损伤通用能力。

### 对Spatial AGI的意义
给出了空间智能与通用智能兼容的架构范式，把 RGB-only 空间推理推到 VSI-Bench 70+ 时代；其自认的运动动态短板恰好界定了几何原生（4D 注入）路线的必要领地——两条路线的边界正在清晰化。
