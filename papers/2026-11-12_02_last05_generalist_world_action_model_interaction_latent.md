## 0. 一句话总结

LaST0.5 指出现有世界动作模型（WAM）把为"全局场景演化"优化的表示直接搬去生成动作，忽略了操作所需的"局部机器人-物体交互"细节；它在世界专家与动作专家之间插入一个**交互中心潜在专家**（由视觉交互线索监督），并以任务进度一致性自适应决定动作执行视界，在 14k 小时机器人数据预训练后取得 LIBERO 99.5%、RLBench 88.0% 的 SOTA。

## 核心问题

### Q1: 这篇文章的核心算法原理是什么？

**问题**: 这篇文章的核心算法原理是什么？请详细描述：核心思想和动机、主要技术方法、算法流程和关键步骤、输入输出。

**分析**:

#### 1. 核心思想和动机

通用机器人基础模型需要策略既能理解当前场景，又能推理物理世界在机器人动作下如何演化。VLA 模型通过直接映射视觉观测到动作取得了强劲性能；世界动作模型（WAM）进一步引入世界建模，让策略利用从视频数据学到的时间因果性、隐式物理和运动先验，是更可泛化、可迁移的范式。

但现有 WAM 有一个共同盲区。它们分两派：

- **Imagine-then-Execute**：先预测未来观测，再通过逆动力学推断动作；
- **Joint Modeling**：统一框架内同时预测未来观测和机器人动作。

两派共享同一个假设：**为建模世界演化而优化的表示，天然有利于动作生成**。作者认为这个假设有问题——世界建模的预测目标是全局场景演化，其表示被广域环境特征主导（背景、布局、大范围动力学），容易淹没操作真正需要的细粒度交互线索（夹爪与物体的接触、物体的可供性变化、局部运动）。全局世界表示与动作生成所需表示之间存在**表征失配（representation mismatch）**。

LaST0.5 的解法：在世界模型与动作模型之间插入一个**交互中心潜在推理层**，把全局世界表示先蒸馏成"以交互为中心"的紧凑物理抽象，再由动作专家消费。整体形成 **视频 → 交互 → 动作** 的层次化推理链。

#### 2. 主要技术方法

**（a）Mixture-of-Transformers（MoT）三专家架构**

预测分布被因式分解为三段（时间对齐的 M 段，如 12 步动作块分 M=3 段）：

p(a, Z, V̂ | c_t) = p(V̂ | c_t) · p(Z | V̂, c_t) · p(a | Z, V̂, c_t)

- **世界专家（World Expert）**：实例化为 Cosmos-Predict2.5-2B（预训练扩散 Transformer）。5 帧主视角历史经因果视频 tokenizer 压缩成潜在上下文，指令经交叉注意力注入（缓存文本嵌入）。256×256 分辨率下逐步去噪预测 12 帧未来视频，切成 M 个时间对齐段。保留 Cosmos 原始生成目标 L_world；
- **潜在专家（Latent Expert）**：从 Janus（统一多模态理解与生成模型）初始化。以世界专家预测的未来场景表示为条件，少量可学习 query token 单次并行前向提取紧凑的交互中心表示 Z。计算高效；
- **动作专家（Action Expert）**：与潜在专家同语言骨干初始化但参数独立，以 flow-matching 目标 L_act 整块精炼动作块。每时间步用两个专用噪声 token + MLP 头分别预测腕部运动和执行器命令，按最大具身维度 padding，支持异构本体。

三个专家共享全局注意力流（MoT），用分块因果注意力掩码强制"视频→潜在→动作"的层次方向。关键工程细节：**世界专家的 key/value 被 detach**，阻断潜在/动作专家向世界专家的梯度回流——预测的场景动力学被当作只读上下文，保护昂贵的预训练物理先验不被下游任务梯度污染。

**（b）交互中心潜在推理（ICLR）的监督构造**

潜在空间不能凭空"知道"要关注交互。LaST0.5 用未来帧的**交互视觉线索增强**作为监督目标：

- 对未来帧添加两类视觉线索：**操作运动线索**（如末端执行器轨迹/运动区域）和**目标物体可供性线索**（affordance，如接触区域/把手区域标注）；
- 增强后的未来帧经原生视觉编码器编码为**潜在目标**；
- 潜在专家的 query 输出被训练去匹配这些潜在目标，从而学会"把全局世界表示蒸馏成以交互为中心的紧凑表示"。

这与视觉提示（visual prompting）工作的区别：已有工作把点/草图/轨迹作为**输入端**的任务指令，LaST0.5 则把未来交互线索作为**监督端**的表示目标，中间建立了一个真正的交互表示空间。

**（c）自适应世界-动作迁移（AWAT）**

世界模型预测的质量会波动：某些段的未来预测可靠，某些段不可靠。直接执行整个动作块可能在不可靠段上翻车。AWAT 让世界模型**联合预测未来表示及其任务进度值（progress value）**：

- 进度值衡量任务完成程度（借鉴可迁移进度建模，而非任务特定 return）；
- 用**进度一致性**检查：如果某段的预测进度值出现下降（进度应单调增，下降意味着预测或执行出了问题），则动态截断执行——只执行进度时间对齐的动作，并触发**未来重采样**（重新从世界模型采样）；
- 即：动作执行视界由预测进度序列动态决定，而非固定块长。

**（d）预训练数据**

14k+ 小时异构机器人语料：遥操作演示、UMI 手持夹爪野外数据、人类自我中心数据。多模态采集覆盖是"通用 WAM"定位的数据基础。

#### 3. 算法流程和关键步骤

```
输入: 语言指令 l + 多视角观测 I_t
1. 世界专家: 5帧历史 → 因果tokenizer → Cosmos扩散去噪 → 12帧未来视频 V̂ (M段)
2. 潜在专家: 条件于 V̂，可学习query单次前向 → 交互中心潜在序列 Z
   (训练时: 未来帧+运动线索+affordance线索 → 视觉编码器 → 潜在目标监督 Z)
3. 动作专家: flow-matching 生成动作块 a (M段, 每步腕部位姿+执行器命令)
4. AWAT: 联合预测各段进度值 → 检查进度一致性
   - 一致: 按对齐动作执行
   - 进度下降: 截断执行视界, 触发未来重采样
输出: 长度自适应的动作块 (6-DoF末端位姿 + 本体执行器命令)
```

#### 4. 输入输出

- **输入**: 自然语言指令、多视角视觉观测（主视角历史 5 帧）、（训练时）动作标签与交互线索增强的未来帧；
- **中间输出**: 未来场景视频段 V̂、交互中心潜在序列 Z、进度值序列；
- **输出**: 动作块（相对 6-DoF 末端位姿 + 本体特定执行器命令，如二值夹爪或多指灵巧手配置）；
- **执行行为**: 视界自适应的动作执行 + 失败时自动重采样。

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**问题**: 这篇文章与通用空间智能（Spatial AGI）有什么关系？请分析：如何理解和表示空间、如何处理空间关系、对Spatial AGI的启发、可以应用到哪些Spatial AGI场景。

**分析**:

#### 1. 如何理解和表示空间

LaST0.5 对空间表示的核心贡献是提出了一个**表示的分层分工**问题：为"看世界如何变"优化的空间表示 ≠ 为"改变世界"优化的空间表示。

- **全局空间表示**（世界专家的输出）：适合预测场景演化，包含背景、布局、光照、大范围动力学。这是"观察者视角"的空间理解；
- **交互中心空间表示**（潜在专家的输出）：以机器人-物体接触区域、物体可供性、局部运动为中心的紧凑抽象。这是"行动者视角"的空间理解。

这个区分对 Spatial AGI 是根本性的：空间智能不只是"理解空间"，更是"理解空间中的可作用性（affordance）与因果可变性"。LaST0.5 用视觉交互线索监督显式构造了"行动者视角"的空间表示，是目前对"操作空间智能"最直接的建模之一。

#### 2. 如何处理空间关系

- **层次化空间推理链**：视频（像素级空间）→ 潜在交互表示（语义级空间关系）→ 动作（度量级空间变换）。空间信息在链条中被逐级抽象：从"画面长什么样"到"谁和谁在交互、交互会怎样"再到"末端应该怎么移动"；
- **可供性作为监督信号**：affordance 线索把"物体可以被怎样操作"这一空间关系知识注入表示——可供性本质上就是物体几何、物理属性与 agent 能力的交集中的空间关系；
- **时间对齐的空间段划分**：M 段时间对齐设计让空间预测（未来视频）、交互预测（潜在序列）、动作预测共享时间结构，空间与时间严格耦合，符合物理世界"空间变化沿时间展开"的本质；
- **进度值作为时空一致性度量**：进度单调性是"操作在空间中逐步接近目标"的量化，用它的异常检测空间执行中的漂移。

#### 3. 对 Spatial AGI 的启发

1. **表示专用化（representation specialization）**：不要指望一个万能表示服务所有空间任务。Spatial AGI 架构应该显式设计"表示的分工与流转"——观察表示、交互表示、控制表示各司其职、级联连接。LaST0.5 的 MoT + 分块因果注意力是这种分工的一种干净实现；
2. **中间监督的可构造性**：交互中心表示之所以可学，是因为作者能构造它的监督目标（交互线索增强的未来帧）。这提示 Spatial AGI 的关键研究问题之一是：**对每个中间抽象层级，如何用自动数据管线构造监督目标**？可视化线索（轨迹、affordance、分割）是廉价且有效的监督载体；
3. **保护预训练先验的梯度隔离**：detach 世界专家的 KV 是一个容易被忽视但极重要的工程决策——大模型时代的空间智能系统普遍建立在昂贵预训练之上，下游梯度回灌破坏先验的风险必须被架构级防护。这一模式值得推广到所有 Spatial AGI 分层系统；
4. **用进度一致性做可靠性监控**：世界模型预测不可靠时的动作截断+重采样，是"知道自己不知道"的机制化。空间智能系统在开放世界部署必须内建这种置信度自评。

#### 4. 可以应用的 Spatial AGI 场景

- **通用机器人操作**（直接应用）：双臂操作、长时程家务任务、灵巧手精细操作（论文已在 Tianji 机器人四项双臂任务验证）；
- **人机协作空间规划**：交互中心表示天然聚焦"人在哪、物在哪、将要怎样"，适合共享工作空间的安全规划；
- **空间数据引擎的标签层**：交互线索增强管线可以反向用于为无标签视频自动标注交互区域，反哺空间数据集构建；
- **具身仿真评估**：AWAT 的进度一致性可作为仿真基准的自动失败检测器；
- **空间智能体的分层控制栈**：世界专家（想象）→ 潜在专家（交互推理）→ 动作专家（控制）的三层结构可推广到导航、装配等非操作领域。

### Q3: 基于前面的分析，这个方法的主要创新点和局限性是什么？

**问题**: 基于前面的分析，这个方法的主要创新点和局限性是什么？与其他相关工作相比有什么优势和劣势？

**分析**:

#### 1. 主要创新点

1. **问题诊断创新**：首次明确指出 WAM 的"全局表示直接迁移到动作"是表征失配，并给出交互中心中间层这个具体解法——问题定义本身就有洞察力；
2. **ICLR 框架**：用视觉交互线索（运动 + affordance）自动构造中间表示的监督目标，无需人工标注交互，数据管线可规模化；
3. **三专家 MoT 架构**：视频→交互→动作的层次化推理被注意力掩码结构化，且 KV detach 保护预训练先验，架构与理念自洽；
4. **AWAT 进度一致性机制**：把进度值从"外部评估信号"变成"内部执行视界控制器"，实现世界模型可靠性感知的自适应执行，这在对可靠性敏感的机器人部署中价值很高；
5. **规模验证**：14k 小时多模态预训练 + LIBERO 99.5% / RLBench 88.0% SOTA + 真机双臂长时程验证，工程完整度高。

#### 2. 主要局限性

1. **交互线索监督的构造依赖**：潜在目标来自"未来帧 + 交互线索增强"，线索本身（轨迹、affordance 区域）需要由另一套系统生成（可能来自检测/分割模型或仿真渲染）。线索质量上限决定了交互表示的上限；线索生成误差会系统性传入；
2. **单次并行潜在查询的表达瓶颈**：少量 query token 单次前向提取的 Z 是高度压缩的抽象，对极精细的接触力学（软物体形变、打滑）可能表达不足——紧凑性与表达力又是一对权衡，只是从"场景/动作"换成了"全局/交互"；
3. **进度值的假设较强**：进度单调性对可清晰定义阶段的任务成立，对含回退、重试、探索的任务（如插孔失败后重新对准）会误判，进度下降不一定是失败信号；
4. **世界专家固定于 Cosmos**：物理先验被锁死在 Cosmos-Predict2.5 的能力边界内，且 256×256 的低分辨率世界预测对精细操作场景的保真度存疑；
5. **计算成本**：扩散世界专家每步去噪 12 帧 + 三专家串行推理，实时性是部署挑战（论文未突出推理延迟数字）；
6. **评测集中操作**：LIBERO/RLBench 都是桌面操作基准，交互中心表示对非操作类空间任务（导航、大范围场景理解）是否同样必要，未验证。

#### 3. 与其他相关工作的对比

| 维度 | Imagine-then-Execute | Joint Modeling WAM | LaST0.5 |
|---|---|---|---|
| 表示迁移方式 | 未来帧→逆动力学 | 全局表示共享 | 全局→交互→动作层次化 |
| 交互监督 | 无 | 无 | 视觉交互线索构造 |
| 可靠性控制 | 无 | 无 | AWAT 进度一致性截断+重采样 |
| 预训练先验保护 | N/A | 梯度混合 | KV detach 隔离 |
| 具身支持 | 单一 | 部分 | 异构本体 padding 设计 |
| 代表方法 | UniPi 系 | 各类 WAM | 本文 |

**优势**：表示分层清晰、可靠性机制独有、真机验证充分。
**劣势**：系统复杂度高于两派基线；进度机制对非单调任务脆弱；交互线索管线引入新的误差源。

与同日 OnlyAct 的对比很有意思：OnlyAct 解决"动作条件从哪来"（无标签视频），LaST0.5 解决"动作表示长什么样"（交互中心蒸馏）。前者是数据问题，后者是架构问题，两者组合可能互补：用 OnlyAct 的动作嵌入流替换 LaST0.5 世界专家的条件输入，缓解其对动作标注数据的依赖。

## 核心技术发现

1. 全局世界表示对动作生成存在系统性表征失配——世界预测被广域特征主导，交互细节被淹没；
2. 视觉交互线索（运动+affordance）可作为中间表示的自动监督目标，训练出交互中心的紧凑潜在空间；
3. 分块因果注意力 + KV detach 能在共享注意力流中实现层次化推理并保护预训练先验；
4. 进度值一致性可以作为世界模型预测可靠性的内建检测器，驱动动作执行视界自适应与重采样；
5. 14k 小时异构数据（遥操+UMI+自我中心）预训练后，交互中心推理在仿真与真机均取得 SOTA。

## 与 Spatial AGI 的关系

### 直接贡献

提供了空间智能"行动者视角"表示的具体构造方法与三层推理架构模板，是操作类 Spatial AGI 系统的当前最完整工程参考。

### 技术启发

- 表示分工与流转是 Spatial AGI 架构设计的核心问题；
- 中间抽象的监督目标可以通过视觉线索自动构造；
- 预训练先验需要架构级梯度防护；
- 可靠性自评（进度一致性）应内建于空间执行循环。

### 应用场景

通用操作、双臂/灵巧手控制、人机协作规划、空间数据标注引擎、仿真失败检测。

## 个人思考

### 最令人兴奋的发现

"交互中心表示"这个中间层的实证有效性令人兴奋。它证明了一个更一般的猜想：**在世界模型与控制策略之间，存在一个可以显式建模、显式监督的'行动语义层'**。这一层既不是像素也不是电机指令，而是"谁在与谁交互、交互进展如何"的结构化空间语义。如果这个层在导航（路径语义）、装配（连接语义）、协作（意图语义）中都有对应物，那 Spatial AGI 可能会收敛到一个通用的分层认知架构。

### 潜在局限

AWAT 的进度单调假设是我最想质疑的点。真实操作充满合法的"进度回退"——重试、绕过、探索性接触。把这些一律判为异常会截断本可成功的执行。更好的方向可能是学习"进度分布"而非点值，用不确定性而非单调性做截断判据。另外，交互线索监督管线引入的系统复杂度值得警惕：三个专家 + 线索生成 + 进度头，系统级调试难度显著上升，学术基准上的收益能否覆盖工程成本有待工业界检验。

### 与近日研究的关联

- **vs OnlyAct（同日）**：OnlyAct 给无标签动作条件，LaST0.5 给交互中心动作表示架构。组合方案：OnlyAct 动作嵌入作为世界专家条件，LaST0.5 潜在专家消费其输出——打通"无标签数据 + 交互推理"全栈；
- **vs 2026-11-11 WorldMind**：WorldMind 在潜空间做测试时缩放推理，LaST0.5 在训练时构造层次化潜在空间。两者都在回答"世界模型的潜空间应该是什么"，一个从推理时间入手，一个从监督结构入手，可能融合为"层次化潜空间 + 测试时缩放"；
- **vs MetaWAM（同日）**：MetaWAM 关注机器人信号如何注入视频扩散潜空间（接口格式），LaST0.5 关注表示语义分层（架构语义），拼起来是 WAM 设计的两个正交维度；
- **vs 2026-11-11 Spatial Harness**：Harness 用物理引擎提供精确世界状态，LaST0.5 用视频扩散提供想象先验。AWAT 的进度一致性恰好可作为连接两者的桥——用引擎状态校准想象进度。

## 方法深度剖析

### A. 因式分解的隐含假设

p(a, Z, V̂ | c_t) = p(V̂ | c_t) · p(Z | V̂, c_t) · p(a | Z, V̂, c_t)

这个链式分解并非唯一选择。它隐含假设：交互语义可以完全从想象的未来中恢复（Z 只条件于 V̂ 和当前上下文，不直接条件于动作）。也就是说 LaST0.5 相信"正确的动作会先在世界想象中呈现为正确的交互演化"。若世界想象本身失败（如罕见物体动力学超出 Cosmos 先验），Z 与 a 会连锁失败。AWAT 是对这一风险的补救而非消除。另一极端——直接 p(a | V̂, Z, c_t) 联合建模——会重新引入两派 WAM 的老问题。这种设计取舍值得在阅读中反复品味。

### B. 为什么用视觉线索而非标签做交互监督？

直接标注"接触点、受力、可供性"成本高且定义不清。视觉线索增强的巧妙之处：它把交互语义"渲染"回图像域——运动箭头画在末端口轨迹上、affordance 高亮画在把手区域——然后让普通的视觉编码器编码。这样监督信号重用了视觉 encoder 的全部能力，且增强管线可复用已有检测/分割/跟踪工具，天然可规模化。代价是线索渲染风格可能与真实视觉分布偏移，需要增强多样性控制。

### C. KV detach 的系统意义

不做 detach 时，动作损失会通过注意力梯度改造世界专家的表示——世界预测开始"讨好"动作生成而偏离真实物理（reward hacking 在表示层的翻版）。detach 把世界专家变成只读的"物理图书馆"。这与 RLHF 中冻结 reward model、与大模型系统中小模型对齐大模型时冻结教师权重是同构的工程智慧。任何"预训练大模型 + 任务适配"的 Spatial AGI 栈都应考虑类似的先验保护点。

### D. AWAT 的控制论解读

AWAT 本质是把开环执行（固定块长 rollout）变成带观测的闭环执行：进度值充当"里程计"，单调性充当一致性检验，不一致即触发重规划。这与 MPC 的滚动时域思想同源，但检验信号来自世界模型自身而非外部传感器——所以它检验的其实是"世界想象的自洽性"。这个机制不依赖任何额外传感器，可以廉价移植到其他 WAM。

### 仿真结果

- **LIBERO**: 平均成功率 99.5%。LIBERO-Object/-Spatial/-Goal/-Long 四套件全覆盖接近饱和，说明交互中心表示对指令跟随、空间关系、长时程组合均有效；

### 真机验证

- Tianji 机器人、4 项双臂任务；
- 长时程执行验证了 AWAT 的重采样在真实失败恢复中的价值；
- 零样本泛化（未见物体、背景、位置）说明交互中心表示抓的是"交互模式"而非"物体外观"——这正是表示泛化性的证据。

### 消融维度（论文重点强调的对比）

1. 去掉潜在专家（全局表示直接接动作）→ 性能下降，验证交互中心层的必要性；
2. 潜在监督换成普通未来帧编码（无交互线索）→ 下降，验证线索构造的必要性；
3. 去掉 AWAT → 长时程任务成功率明显下降，验证可靠性机制价值。

### 值得追问

- 推理延迟：扩散世界专家每步去噪开销未在正文突出，实际控制频率存疑；

- 99.5% 的 LIBERO 已近饱和，benchmark 区分度问题——社区可能需要更难的基准。

## 术语表

- **WAM (World Action Model)**: 联合建模世界演化与机器人动作的模型范式；
- **ICLR (Interaction-Centric Latent Reasoning)**: 本文提出的交互中心潜在推理框架（缩写与 ICLR 会议同名，纯属巧合）；
- **AWAT (Adaptive World-to-Action Transfer)**: 进度一致性驱动的自适应世界-动作迁移机制；
- **MoT (Mixture-of-Transformers)**: 多组独立权重共享全局注意力流的 Transformer 架构；
- **Flow Matching**: 用常微分方程流匹配目标训练的生成模型方法，常用于连续动作生成；
- **Affordance**: 物体可供 agent 操作的可能性（几何、物理与能力的交集）；
- **UMI**: 手持夹爪采集的野外机器人数据规范；
- **Progress Value**: 任务完成程度的可迁移标量估计。

## 应用场景展开

### 场景1：家庭长时程任务

收拾桌面、洗碗等多阶段任务天然需要 AWAT：某阶段想象失真（打滑、掉落）时进度一致性检测触发重采样，避免错误级联。LaST0.5 的零样本泛化能力应对家庭场景的物体多样性。

### 场景3：人机共享工作空间

交互中心表示天然包含"人手在交互什么"的语义，可用于预测人类动作意图并调整机器人行为；进度值可扩展为"共享任务进度"，支持真正的人机协作规划。

### 场景4：空间数据引擎

交互线索增强管线反向运行即为标注引擎：对无标签机器人视频自动生成轨迹/affordance 标注，构建带交互语义的空间数据集。

## 训练与推理伪代码（示意）

```python
# 架构
world_expert  = CosmosPredict25_2B()      # 预训练扩散 Transformer, 冻结先验+微调
latent_expert = JanusInit()               # 多模态专家
action_expert = FlowMatchingHead()        # 同骨干独立参数
# MoT: 共享注意力流, 分块因果掩码; 世界专家 KV detach

# 训练
for batch in pretrain_corpus:             # 14k+ h 遥操/UMI/自我中心
    ctx = causal_tokenizer(history_5frames, instruction)
    V_hat = world_expert.denoise(ctx, steps=12)          # L_world
    # 交互监督: 未来帧 + 运动线索 + affordance 线索 → 视觉编码器
    z_target = vision_encoder(augment_future_frames(future, cues))
    Z = latent_expert(queries, cond=detach_kv(V_hat))    # 匹配 z_target
    a_chunk = action_expert(flow_matching, cond=[Z, V_hat])   # L_act
    progress = world_expert.predict_progress(V_hat)       # 进度头
    backward(losses)   # 注意 KV detach 阻断→world_expert 的动作梯度

# 推理 (AWAT 闭环)
while task_not_done:
    V_hat = imagine(); Z = abstract(V_hat); a = act(Z)
    p = progress_sequence(V_hat)
    horizon = first_index_where(p decreases) or len(a)
    execute(a[:horizon])
    if horizon < len(a): resample()      # 截断→重想象
```

## 风险评估（工程落地视角）

1. **延迟风险（高）**：扩散世界专家在线去噪难以达到实时控制频率。缓解：异步想象（想象 N 步执行 M 步）、蒸馏世界专家、或低频想象+高频局部策略分层；
2. **管线复杂度（中高）**：线索生成质量决定交互表示上限。缓解：线索多样性增强、线索置信度加权损失、逐步自举（用训练后的模型重新生成更好的线索）；
3. **进度误判（中）**：合法回退被截断。缓解：进度不确定性估计、仅在连续多段下降时触发、结合外部传感器校验；
4. **基准饱和（中）**：LIBERO 99.5% 后区分度消失，社区需要更难基准；论文的长时程真机任务是自建评估，可比性有限。

## 常见问题（FAQ）

**Q1: LaST0.5 与 VLA 模型（如 π0.5、OpenVLA）的关系？**

LaST0.5 是在 VLA 之上的增强范式：动作专家本质仍是 VLA 式策略，但被世界专家的物理先验和潜在专家的交互语义加持。可以理解为 "VLA + 世界模型 + 交互中间层" 的三明治结构。

**Q2: 为什么潜在专家用 Janus 初始化而动作专家用同骨干但独立参数？**

潜在专家需要多模态理解能力（编码交互线索目标、读世界表示），Janus 的统一理解生成能力匹配；动作专家只需语言骨干的结构先验，独立参数避免两个任务梯度互相拉扯。这是"共享结构先验、隔离任务梯度"的又一处细节。

**Q3: 交互线索增强具体长什么样？**

论文描述为操作运动线索 + 目标物体可供性线索：例如在末端口轨迹上绘制运动标注、在目标物体交互区域绘制高亮。增强后的未来帧经视觉编码器成为潜在目标。具体渲染实现细节在附录。

**Q4: AWAT 触发重采样后会发生什么？**

执行在进度下降的时间点截断，世界专家从当前真实观测重新想象未来、潜在专家重新提取交互表示、动作专家重新生成动作块。相当于一个基于自洽性检验的隐式 replanning。

**Q5: 14k 小时数据里 UMI 和人类自我中心数据起什么作用？**

UMI 与人类数据没有真机动作标签（只有手部/夹爪运动），主要贡献世界演化先验与交互模式多样性；真机遥操作数据贡献精确动作监督。异构数据的分工利用是通用 WAM 预训练的关键工程问题。

## 与 Spatial AGI 长期主义议题的连接

### 空间智能的"语义粒度阶梯"

综合近期工作，空间表示正在形成一个从细到粗的粒度阶梯：像素/几何（3DGS、NeRF）→ 物体与关系（场景图、可供性）→ 交互与事件（LaST0.5 潜在空间）→ 技能与规划（任务分解）。每层有不同消费者：渲染、感知、操作、规划。Spatial AGI 的系统设计问题正在从"选哪种表示"转向"如何让阶梯上的各层高效互译"。LaST0.5 的贡献是把"交互"这层从隐含状态变成显式建模对象。

### 通用空间认知架构的猜想

如果导航、操作、装配最终都需要一个类似 LaST0.5 潜在专家的"任务域语义中间层"，那么可以猜想 Spatial AGI 的通用架构将是：

- 一个共享的世界先验底座（视频/物理基础模型）；
- 一组任务域中间专家（交互/路径/结构/意图）；
- 一组轻量执行头（控制、语言、规划）。

MoT 式共享注意力 + 分块因果掩码恰好是实现这种架构的天然容器。

### 对基准设计的启示

现有基准把感知、推理、控制拆开测（VQA、规划题、操纵任务），缺少"中间表示质量"的直接测量。LaST0.5 的交互线索监督提示了一种新基准形态：给定场景与任务，评测模型预测的交互演化是否与真值交互线索一致——这能隔离"世界想象能力"与"动作执行能力"，定位失败原因。
