## 0. 一句话总结

L3G-World 用"潜在 3D 高斯记忆"（Latent 3D Gaussian Memory, L3G）作为交互式世界模型的持久场景记忆：记忆只随**场景覆盖范围**而非**生成流长度**增长，且每个高斯直接存储 VAE 潜特征，可跳过 VAE 重编码直接渲染进视频 DiT 的潜空间，最终在单张 H100 上实现 9.02 FPS 的实时无限世界生成。

## 核心问题

### Q1: 核心算法原理是什么？

**问题**: 这篇文章的核心算法原理是什么？

#### 1. 核心思想和动机

交互式视频世界模型（Genie 系、Yume、Spatia、NeoVerse 等）以用户动作为条件生成视觉内容，是现实模拟、交互式游戏生成、具身仿真的基础框架。其核心矛盾是：**长时程探索的空间一致性 vs 实时生成**。

现有两条路线都有根本缺陷：

1. **时间上下文路线**（WorldKV、Yume 1.5 等）：靠检索历史帧或 DiT 自注意力的 KV cache 来维持一致性。问题是内存与注意力成本随生成流长度 T 和分辨率 R 线性增长，即 O(TR)。论文实测：Yume 1.5 生成 400 帧需要 66.7 GiB、仅 1.42 FPS，WorldKV 直接 OOM。
2. **显式 3D 记忆路线**：
   - **前馈式**（Spatia 点云 32.6 GiB / 0.24 FPS；NeoVerse 3DGS 36.8 GiB / 1.99 FPS）：逐帧密集重建后不断堆积 primitives，同一空间区域被反复覆盖，记忆随 O(TR) 膨胀，渲染越来越慢，且旧 primitives 从不修正，几何错误永久留存。
   - **优化式**（ArtiFixer 等）：记忆规模 O(S)（S 为场景覆盖），紧凑且可修正，但逐场景迭代优化延迟巨大（0.10 FPS），无法实时。

L3G-World 的洞察是：**世界模型的记忆不该是"帧的堆积缓冲区"，而应是"随时间被持续修订的持久场景表示"**。两个关键设计决策：

- **选择性更新**：只为新观测到的几何 spawn 新高斯，对已探索区域的高斯做残差精炼（refinement），使记忆规模主要由场景空间范围决定，而非生成帧数。
- **潜空间直通**：每个高斯额外存储一个 VAE 潜特征（latent feature），渲染时直接输出 DiT 潜空间的条件张量，省掉"渲染 RGB → VAE encode"这一昂贵环节，这是实现实时的关键。

#### 2. 主要技术方法

框架由两个模块自回归交替构成：

- **L3G-Mem**（前馈记忆更新器）：读入当前窗口帧 + 相机参数 + 旧记忆，输出更新后的记忆。
- **L3G-Gen**（记忆条件化视频 DiT）：以记忆在目标相机下渲染出的潜空间条件为输入，生成下一段视频。

**记忆的数学表示**：

```
M_k = {(G_j, T_j)}_{j=1..N_k} = {G_k, T_k}
G_j = Head(T_j)   # MLP Gaussian head 从 memory token 解码高斯参数
M_k = Update(M_{k-1}, W_k)   # 窗口 W_k = {(I, C, z)}，z 为 VAE 潜码
```

即记忆 = memory token 集合 + 对应 3D 高斯，N_k 随场景范围（而非帧数）增长。

**模块一：Adaptive Gaussian Spawning（自适应高斯生成）**

- 把旧记忆 M_{k-1} 渲染到当前相机的视角，得到 RGB 图和 opacity 图。
- opacity 低（未被记忆覆盖）或 RGB 误差高（记忆复现不准）的像素被标记为"表示不足"，汇成 spawn mask S_k。
- 用几何基础模型（VGGT 类，选 3 层特征）编码当前帧得到几何特征 F_k，只保留 S_k 内的特征作为 spawn 候选。
- 沿用 ZipSplat 的做法，对候选做 K-means 聚类，初始化一小组紧凑的 spawning query tokens Q_k。
- 关键点：**聚类预算只花在记忆缺失的内容上**，而不是对所有像素特征聚类——这是记忆保持 O(S) 的直接原因。

**模块二：Gaussian Refinement（高斯精炼）**

- 同样把旧记忆渲染到当前视角，检索可见高斯对应的 memory tokens 作为 refinement tokens T_rf。
- 这些 token 与高斯参数用当前窗口的观测做**残差更新**——早期生成步骤的几何误差会被后续观测逐步纠正。这让记忆具备"自我修复"能力，是优化式方法才有的性质被搬进了前馈框架。

**模块三：Joint Token Processing（联合 token 处理）**

- spawning tokens 与 refinement tokens 沿 token 维拼接，喂给单个 transformer F_θ：

```
(Q̄_k, T̄_rf) = F_θ([Q_k ; T_rf], F_k)
```

- 每个 block：两路 token 先对当前层几何特征 F_k^l 做 cross-attention，再做流内 self-attention；最后加一层全局 self-attention 让"新内容"与"旧内容"交换信息。
- 这样新 spawn 的高斯能感知已有场景结构（例如对齐已有表面），旧高斯也能吸收新观测的证据。

**模块四：VAE Latent Lifting（VAE 潜特征提升）**

- 专设 latent-lifting 分支：用与 spawning query 相同的空间索引从 z_k 初始化 latent queries Q_z，cross-attend 到 z_k。
- 输出的 VAE latent tokens 与 spawning tokens 在空间上一一对应，逐通道拼接后解码：每个新高斯除几何/外观参数外还带一个 VAE 潜特征。
- 已有高斯的潜特征也随 refinement 一同残差更新。

**模块五：L3G-Gen（记忆条件化视频生成器）**

- 目标相机下把记忆直接 splatting 渲染到 DiT 的潜空间（而非像素空间），得到条件张量注入视频 DiT。
- 配合少步蒸馏（few-step distillation，基于模型自身生成历史训练以缓解 exposure bias / on-policy 蒸馏），实现低延迟流式生成。
- 生成的 chunk 回喂 L3G-Mem 更新记忆，闭环自回归。

#### 3. 算法流程和关键步骤

完整自回归循环（第 k 步）：

1. **生成**：L3G-Gen 以 M_{k-1} 在目标相机 C_k 下渲染的潜空间条件 + 用户/智能体动作为输入，生成下一段视频（少步采样）。
2. **渲染诊断**：L3G-Mem 把 M_{k-1} 渲染到新窗口的相机，得到 RGB + opacity，与生成帧对比算出 spawn mask S_k。
3. **Spawn**：几何基础模型编码新帧 → 只取 S_k 内特征 → K-means 初始化 spawning queries。
4. **Retrieve**：检索可见旧高斯的 memory tokens 作为 refinement tokens。
5. **Joint processing**：双流 token 经 L 层 transformer（cross-attn 几何特征 → 流内 self-attn → 全局 self-attn）。
6. **Latent lifting**：并行分支从 VAE 潜码 lift 出与新高斯空间对齐的 latent tokens。
7. **Decode & update**：spawning tokens+latent tokens 解码为新高斯（带 VAE 潜特征）；refinement tokens 解码为残差更新量，修正旧高斯。
8. **记忆规模**：N_k ≈ 场景已覆盖范围决定，与 k 无关（渐近）。

#### 4. 输入输出

- **输入**：一张初始图像 + 相机轨迹/动作序列。
- **输出**：空间一致的可探索世界的流式视频（480×832），以及伴随的潜在 3D 高斯场景记忆（可作为几何副产物）。
- **运行环境**：单张 H100，9.02 FPS 实时。

### Q2: 与通用空间智能（Spatial AGI）有什么关系？

#### 1. 如何理解和表示空间

L3G-World 给出了对"空间记忆"的一个非常工程化但深刻的回答：

- 空间记忆应当是**以场景为索引**（object/region-anchored），而不是**以时间为索引**（frame-anchored）。人脑再认一个走过两次的房间不会"内存翻倍"——L3G 的 O(S) 缩放正是这个原则的形式化。
- 空间记忆不只是存储，还需要**可修订性**：新证据应该能修正旧信念（残差 refinement），这是把"信念修正"（belief revision）机制引入空间记忆。
- 空间记忆应该**与生成/推理的表示空间对齐**：L3G 把记忆渲染到 DiT 潜空间，相当于让"记忆"与"想象"共享一个坐标系。对 Spatial AGI 的启示是：空间记忆的接口设计（以什么格式被下游模型消费）与其内容同样重要。

#### 2. 如何处理空间关系

- **空间一致性通过渲染闭环保证**：spawn mask 由"记忆渲染 vs 新观测"的差异驱动，这是一个 perception-memory-action 闭环：记忆决定预期，预期与观测的差异决定学习/更新。
- **全局 self-attention 实现新旧几何的协调**：新区域的高斯生成会参考邻近已有高斯，保证接缝处的几何连续。
- **相机可控性**：显式 3D 记忆天然支持任意相机轨迹（回访、闭环、回看），这是纯视频时间上下文做不到的。

#### 3. 对 Spatial AGI 的启发

1. **O(S) 记忆缩放是 Spatial AGI 的必要条件**。无限世界/终身智能体不可能承受记忆随经验时长线性增长。L3G 的"按需 spawn + 残差修正"是通用的记忆管理策略，可迁移到语义记忆、物体级记忆。
2. **潜特征直通接口**：记忆的读写如果每次都要跨表示空间翻译（VAE encode/decode），实时性就死了。Spatial AGI 系统中记忆→感知/规划模块的接口应该原生对齐（例如记忆直接输出 planner 的 token 空间）。
3. **生成与重建的统一**：L3G-Mem 本质上是一个流式前馈 3D 重建器，L3G-Gen 是条件生成器，两者共享 VAE 潜空间。这暗示 Spatial AGI 的"想象"（生成）与"感知"（重建）可以共享一套空间记忆基础设施。
4. **自我修正的空间信念**：refinement 机制说明空间记忆应该存储"token + 可被新证据修正的参数"，而非一次性写入的静态内容——这接近预测加工（predictive processing）的框架。

#### 4. 可以应用的 Spatial AGI 场景

- **具身智能体的持久空间记忆**：机器人把 L3G-Mem 挂在自身相 机流上，维护场景的紧凑几何+外观记忆，供导航（闭环检测）、操作（桌面几何）和想象（未来预测）共用。
- **交互式仿真/训练环境生成**：为 VLA/RL 提供无限、空间一致的训练世界，回访区域不会"变样"，避免智能体学到虚假的物理。
- **游戏与内容生成**：从一张概念图实时生成可无限探索的世界。
- **数字孪生与 VR**：边探索边构建紧凑场景记忆，且记忆规模可控。
- **世界模型评测基础设施**：O(S) 记忆使 400+ 帧长时程一致性评测成为可能（此前方法 OOM）。

### Q3: 主要创新点和局限性是什么？

#### 1. 主要创新点

1. **潜在 3D 高斯记忆（L3G）表示**：首次让 3DGS 记忆的每个 primitive 直接携带 VAE 潜特征，实现记忆→DiT 潜空间的无编码渲染（359× 渲染吞吐提升），这是实时化的决定性一步。
2. **选择性 spawn + 残差 refinement 的前馈记忆管理**：把优化式方法的 O(S) 紧凑性与可修正性，以前馈方式实现（3.0–3.2× 重建加速），兼得两派优点。
3. **记忆更新器与生成器自回归交替的世界模型架构**：记忆不是生成器的附属品，而是与生成器对等的闭环组件。
4. **系统性效率验证**：单卡 H100、400 帧生成的对照实验干净利落——7.4 GiB vs 11.7–66.7 GiB，9.02 FPS vs 0.10–1.99 FPS，且生成质量与长时程自一致性同时 SOTA。

#### 2. 主要局限性

1. **分辨率与保真度上限**：480×832 分辨率在高斯记忆容量固定的情况下，复杂场景细节可能被欠采样；记忆 token 数量有预算，场景极度复杂时 spawn 预算分配策略（K-means 均匀性）未必最优。
2. **静态世界假设**：论文处理的是静态可探索场景，动态物体、光照变化、可变形场景未覆盖；refinement 机制在非静态世界中可能把合理变化误当作误差抹掉。
3. **动作空间受限**：以相机轨迹为主的探索动作，未见物体交互、物理事件条件生成。
4. **误差累积未完全消除**：refinement 能修正几何，但若早期生成在语义上走偏（生成出幻觉结构），记忆会"忠实地"记住幻觉，后续观测可能将其合理化而非纠正。
5. **评测依赖生成质量指标**：长时程自一致性在自生成闭环里评测，缺少真实扫描 ground truth 的硬约束。

## 核心技术发现

1. **"记忆规模 ∝ 场景范围而非时长"在世界模型中首次被实时实现**，O(S) 与 O(TR) 的差距随生成时程无限拉大。
2. **VAE 潜特征可以"挂"在几何 primitive 上**，被 splatting 渲染到潜空间——这是一个通用技巧，任何"3D 表示 → 扩散模型条件"的管线都可借用，绕过 VAE encode 的延迟瓶颈。
3. **前馈残差更新可以达到优化式修正的效果**：refinement tokens + 全局 self-attention 让新观测的证据流回旧高斯，等于把 test-time optimization 蒸馏进了一次前向。
4. **spawn mask 是一个极简而有效的"记忆缺口检测器"**：opacity + RGB 误差两个信号就足以定位需要新记忆的区域。

## 个人思考

### 最令人兴奋的发现

潜特征直通渲染拿到 359× 加速，说明**世界模型的实时性瓶颈往往不在生成器本身，而在记忆与生成器之间的表示转换**。这提示我们优化 Spatial AGI 系统时，优先审视模块边界的表示翻译成本。另外，把优化式的"可修正性"蒸馏成前馈的"残差预测"，这种跨范式的能力搬运手法值得在记忆系统设计中反复使用。

### 潜在局限

静态世界假设是最大的护城河裂缝：真实空间智能体所在的世界充满动态。把记忆从"几何+外观"扩展到"几何+外观+动力学"（每个高斯附一个局部动力学潜码）是显然的下一步，但 spawn/refine 协议能否处理物体级移动（同一物体的高斯应整体迁移）尚未可知——K-means 式空间聚类对物体没有概念。

### 与昨日研究的关联

昨日精读的 LingGS 处理前馈几何预测与相机跟踪的解耦，本质也是"流式场景记忆如何保持一致性"问题，L3G-World 给出了生成侧的对应答案：跟踪侧用解耦降低漂移，生成侧用 spawn+refine 控制记忆膨胀。两条线正在合流——未来的世界模型大概率内嵌一个 SLAM 式的记忆子系统。昨日 Gaussianspline 的 4D 动态高斯，恰好是补上 L3G 动态短板的候选表示。

## 总结

### 核心发现总结

L3G-World 用"选择性 spawn + 残差 refine + 潜特征直通"三件套，把交互式世界模型的空间记忆从 O(TR) 压到 O(S)，并把记忆→生成器的条件化延迟降到接近零，首次实现实时无限世界生成。它证明：实时长时程空间一致性的关键不在更大的生成器，而在更聪明的记忆表示与接口。

### 对 Spatial AGI 的意义

这是"空间记忆工程化"的标志性工作。Spatial AGI 需要的三大能力——感知构建、记忆保持、想象推演——在 L3G-World 中第一次以实时闭环的形式同时在线。其记忆管理协议（缺口检测→按需分配→证据修正）是通往终身学习空间智能体的直接蓝图。

```python
# 输入: M_{k-1} = {(G_j, T_j)}, 新窗口 W_k = {(I, C, z)}
# 1. 渲染诊断
rgb_r, opacity = render(M_{k-1}, C_k)          # 旧记忆投影到新视角
S_k = (opacity < tau_o) | (|rgb_r - I_k| > tau_e)   # spawn mask

# 2. Spawn 流
F_k = geo_foundation_model(I_k)                 # 3 层几何特征
cand = F_k[0][S_k]                              # 只取缺口区域特征
Q_k = kmeans_init(cand, budget)                 # 紧凑 spawning queries

# 3. Refinement 流
vis_ids = visible_gaussians(M_{k-1}, C_k)       # 当前可见旧高斯
T_rf = T_{k-1}[vis_ids]                         # 取回 memory tokens

# 4. 联合处理
for l in range(L):
    Q, T_rf = cross_attn([Q; T_rf], F_k[l])
    Q, T_rf = self_attn(Q), self_attn(T_rf)
Q, T_rf = global_self_attn(Q, T_rf)             # 新旧内容交流

# 5. Latent lifting
Q_z = init_from(z_k, same_indices_as_Q)
Q_z = cross_attn(Q_z, z_k)

# 6. 解码与更新
G_new, T_new = decode_head(cat_c(Q, Q_z))       # 新高斯 + 潜特征
delta = decode_head(T_rf)
G_old[vis_ids] += delta                          # 残差精炼
M_k = merge(M_{k-1} \ vis_removed, G_new)
```

### A.2 为什么渲染潜特征是可行的？

普通 3DGS 渲染把每个高斯的颜色 c 和透明度 α 做 alpha-blending：
`C = Σ α_i c_i Π(1-α_j)`
L3G 把"颜色"换成 d 维 VAE 潜向量，alpha-blending 在潜空间线性成立（VAE 解码近似线性于低幅扰动）。渲染输出直接是 DiT 输入分辨率的潜张量。数学上并不严格等价于对渲染图像 encode，但论文实证该近似足以支撑高质量条件生成。这也是全文最"冒险"的一步假设——它赌 VAE 潜空间对 alpha-composition 足够线性，而实验证明赌对了。

### A.3 记忆规模的博弈分析

记忆规模 N_k 的动力学：
- 新探索区域 → spawn 增加 N
- 重访区域 → refinement 不增加 N
- 理论上没有删除机制——N 单调不减，但增速只由新覆盖面积驱动
- 因此对有限空间场景 N 饱和；对真正无限世界 N 仍会缓慢增长，需要未来引入记忆遗忘/合并机制（如按空间格子 LOD 合并）

## 附录 C：延伸讨论

### C.1 与 SLAM 社区的深层联系

L3G-Mem 本质是一个"生成式 SLAM 前端"：
- 关键帧窗口 = sliding window SLAM
- spawn mask = 地图覆盖检测
- refinement = bundle adjustment 的前馈近似
- 潜特征 = 传统 SLAM 没有的外观记忆

SLAM 社区几十年的地图管理经验（子图、关键帧剔除、回环检测）是世界模型记忆尚未吸收的宝库。L3G 没有 loop closure 显式机制，靠 refinement 隐式处理，回环大漂移场景可能失效。

### C.2 记忆的语义缺失

L3G 高斯只带几何+外观+VAE潜码，没有物体级/语义级组织。Spatial AGI 需要回答"那个杯子在哪"，需要物体锚定的记忆层级。近期 token-based 3DGS（ZipSplat 等）已有把高斯组织成语义簇的先例，L3G 的 K-means 初始化天然提供了空间簇结构，往上挂语义是低成本扩展。

### C.3 对齐到 VLA 的想象路径

把 L3G-World 接到 VLA：
1. VLA 动作 → 相机/末端轨迹
2. L3G-World rollout 未来视觉
3. 价值模型/世界模型奖励评估 rollout
4. 反传给 VLA 策略

这就是"在脑内世界模型里排练"的完整链路，L3G 的实时性让 rollout 数量不再受限。

### C.4 开放问题清单

1. 动态物体的记忆表示（移动高斯组？物体中心化记忆？）

## 附录 E：与近期相关工作的逐点对照

### E.1 vs Genie 3 / WorldKV（时间上下文派）

- 一致性来源：注意力对历史帧的检索 vs 空间锚定的几何记忆

- 成本曲线：O(TR) 线性上升直至 OOM；L3G 平坦
- 结论：探索越长，几何记忆优势指数级放大

### E.2 vs Spatia（点云记忆派）

- 点云稠密、无外观参数化，渲染需 NeRF 式查询，慢（0.24 FPS）
- 点云逐帧堆积，无 refinement，几何噪声永久
- L3G 用解析高斯 + 潜特征，渲染是并行 splatting，快两个数量级

### E.3 vs NeoVerse（前馈 3DGS 堆积派）

- NeoVerse 每帧前馈预测 per-pixel 高斯并全部入库 → O(TR)
- L3G 每窗口只对缺口区域做 token 化少量高斯 → O(S)
- NeoVerse 无修正；L3G 有残差 refinement

### E.4 vs ArtiFixer（优化式修正派）

- ArtiFixer 证明"可修正的紧凑记忆"是正确方向，但用梯度优化实现，0.10 FPS
- L3G 用前馈残差网络蒸馏了这一能力，90× 加速
- 哲学差异：test-time optimization → 训练时内化的 amortized inference

### E.5 vs ZipSplat（token 3DGS 源头）

- ZipSplat 提供了"K-means 初始化少量 query tokens → 解码高斯"的骨架
- L3G 的贡献是在其上加：记忆条件化（只对缺口聚类）、refinement 流、latent lifting
- 站在组件创新与系统集成的交界，工程整合质量很高

## 附录 G：深度问答（自我检验式精读）

### G.1 spawn mask 的两个阈值如何影响系统行为？

- tau_o（opacity 阈值）过低 → 大量半透明边缘像素被判"已覆盖"，新区域欠采样，出现几何洞。
- tau_e（RGB 误差阈值）过高 → 记忆错误区域不被标记，refinement 也无法发现，错误固化。
- 两者共同决定了记忆的"覆盖率-精度"工作点。论文未讨论自适应阈值，场景光照变化时固定阈值可能误判（光照差被当成几何差）。这是工程落地第一个要调的旋钮。

### G.2 为什么用 K-means 而不是可学习的 token 化？

K-means 保证 token 与空间内容对齐（每个 token 对应一个空间簇），这使"按空间索引检索 refinement tokens"成为可能——可见高斯 ↔ memory token 是一一对应的。若用纯可学习 query（如 DETR 式），token 与空间解耦，检索机制就断了。这是一个被低估的设计耦合：**token 化方式决定了记忆的可检索性**。

### G.3 残差 refinement 与漂移的关系？

前馈几何预测存在系统性漂移（尺度、位姿偏差）。refinement 用后续观测反复修正，功能上类似 SLAM 的回环优化，但没有显式的位姿图。风险：单视角快速掠过的区域只被观测一次，refinement 机会少，误差留存；频繁回访的区域收敛好。记忆质量因此与探索策略耦合——空间智能体的主动探索（哪里值得再看一眼）成为记忆质量的上游问题。

### G.4 潜特征直通会损失什么？

VAE 潜码编码的是压缩外观，alpha-blending 潜码近似会引入混叠伪影（两个不同纹理区域的潜码混合，解码出的纹理可能"不存在于任一原区域"）。生成器能容错这部分（它本来就是生成模型，条件只需"足够引导"），但若把记忆渲染直接当重建结果用（如 SLAM 定位），精度就不够。L3G 潜特征渲染是给生成器看的，不是给人眼/测量用的——用途边界要清楚。

### G.5 9.02 FPS 的瓶颈分解猜测

- L3G-Gen 少步蒸馏后单 chunk 生成应占大头
- 记忆渲染 359× 加速后已近免费
- L3G-Mem 前向（几何基础模型编码 + transformer）次之
- 说明进一步提速要靠更激进的生成蒸馏或异步记忆更新（生成 chunk N 时并行更新记忆 N-1），这是显然的系统优化空间

### G.6 如果把 L3G-Mem 单独拿出来用？

完全可行：它就是一个流式前馈 3D 重建器（输入视频流 → 输出 O(S) 高斯地图 + 每高斯 VAE 潜特征）。对机器人：单目相机的实时紧凑建图；对 AR：场景锚定的外观记忆。记忆组件的复用价值可能不亚于世界模型整体。

## 附录 H：风险与伦理速记

- 生成世界的"幻觉固化"：记忆会把早期生成错误当作事实保留，长时间探索的"世界历史"可能建立在错误几何上；对用作训练环境而言，系统性偏差会被策略继承。
- 单卡实时的可及性：H100 门槛意味着复现/部署成本高，开源权重与蒸馏到消费级 GPU 是社区关切。
- 版权与内容：从单图生成无限世界，潜在的风格模仿与 IP 问题与一般图像生成模型相同。

## 附录 J：术语表

- **L3G (Latent 3D Gaussian Memory)**: 潜在 3D 高斯记忆，每个高斯除常规参数外携带一个 VAE 潜特征向量。
- **L3G-Mem**: 前馈记忆更新器，执行 spawn + refinement + latent lifting。
- **L3G-Gen**: 记忆条件化视频 DiT，少步蒸馏实现实时。
- **Spawn mask**: opacity 低或 RGB 误差高的像素集合，标记记忆缺口。
- **Spawning queries**: 从缺口区域特征 K-means 初始化的 token，解码为新高斯。
- **Refinement tokens**: 可见旧高斯取回的 memory tokens，解码为残差更新。
- **Latent lifting**: 把 VAE 潜码提升为与新高斯空间对齐的潜 token 的分支。
- **O(S) 缩放**: 记忆规模随场景空间覆盖 S 增长，与生成帧数 T 无关。
