## 0. 论文速览

AffordanceVLA 直击 VLA 模型的核心结构缺陷：**VLM 预训练在语义空间对齐视觉-语言，而机器人动作本质是 3D 物理空间的表征**——这个结构性失配使端到端的感知→动作映射难学、易表征坍缩。解法：引入**结构化可供性预测（structured affordance forecasting）**作为任务导向的中间表示，通过三个互补模块渐进式建模操作先验：

- **Which2Act**：物体级接地——预测目标的视觉潜变量（冻结编码器），抑制干扰物
- **Where2Act**：2D 交互定位——预测可供性热力图，精确定位交互区域
- **How2Act**：3D 几何推理——扩散生成 3D 形状 + 回归 10-DoF 空间布局，提供运动学约束

架构上是 **Mixture-of-Transformer (MoT)** 三专家（理解/可供性生成/动作），通过单向 Understanding→Affordance→Action (UAA) 渐进注意力协调。训练用三阶段渐进数据课程，辅以自动化管线合成 **10万+ 稠密可供性标注**。

**关键成绩**：
- LIBERO 平均 **95.8%**（超 π0 的 94.4%、F1-VLA 95.7%，对比组最高）
- CALVIN ABC→D 平均长度 **4.33**（5连任务完成率 75.9%），OOD 泛化强
- 真实世界：基础任务 88.3%（π0 70.8%）；严重视觉混叠的复杂任务 Drawer-close 100% vs π0 的 40%
- 数据效率：40% 下游数据即超越全量微调的 π0

**一句话总结**：不让低层动作损失侵蚀 VLM 的语义能力，而是让"哪里可以交互、怎么交互"的可供性预测作为语义锚点，把感知-动作映射分解为可解释的子问题。

## 核心问题

### Q1: 核心算法原理

**问题**: 这篇文章的核心算法原理是什么？

**分析**:

#### 1. 核心思想和动机

**问题的结构化诊断**：

- VLM 预训练目标：语义空间中的视觉-语言对齐
- 机器人动作：3D 物理空间中的连续控制
- 端到端 VLA 直接回归动作时，低层动作损失反向传播进 VLM backbone，**逐渐侵蚀预训练赋予的指令跟随能力**——论文的 Toaster 案例极具说服力：π0 在"按下烤面包机按钮"上失败（26.7%），坏例集中在它根本不理会指令、直接做抓放动作——**行为由主导性动作先验驱动而非语言命令**

**中间表示的选型论证**（对比两条既有路线）：

- 视频预测/视觉预见路线：稠密像素信号高度冗余、rollout 慢
- 文本推理/全局表征路线：过粗，捕捉不了操作的 what/where/how

**可供性是天然的最优中间表示**，因为它同时满足三个性质：
- 空间接地（spatially grounded）：在视觉里定位
- 语义条件化（semantically conditioned）：由语言指令决定
- 动作耦合（action-coupled）：直接指导执行

直觉类比：人类看到马克杯的把手，自然地把它感知为"抓握的邀请"——可供性就是这种感知的数学化。

**与既有可供性工作的关键区别**：以往可供性是**外部消费的先验**（稀疏接触点+方向，配外部抓取生成器和运动规划器，开环脆弱）；AffordanceVLA 把可供性预测**内化到 web 级预训练 VLA 内部**，与 VLM backbone 和动作专家联合优化——可供性从"外部线索"升级为"动作耦合的中间表示"。这也呼应 π0.5/π0.7 的趋势：train-only 结构化中间监督，防止低层控制目标侵蚀 backbone 的视觉-语言能力。

#### 2. 主要技术方法

**MoT 三专家架构**：

| 专家 | 输入→输出 | 职责 |
|------|----------|------|
| 理解专家 M_und | (O_t, l) → h_t^und | 指令感知的多模态融合，细粒度视觉-语言对齐（本体感知 s_t 按 π0 式解耦直接进动作专家） |
| 可供性生成专家 M_gen | h_t^und → Â_t | "视觉规划器"：解码结构化可供性 token（Which/Where/How） |
| 动作专家 M_act | (h_t^und, Â_t) → â_{t:t+k} | 平滑时序一致的动作块生成，专注精确物理执行 |

**UAA 渐进注意力机制**（架构的关键纪律）：
- 专家内部：双向注意力充分融合上下文
- 专家之间：严格因果的单向流——M_gen 只查询 M_und；M_act 读两者
- **防止动作信息泄漏进预测阶段，保持可供性特征的纯度**——注意这与今日 CST-WM 的因果切边思想惊人一致：信息流向必须与功能结构对齐

**三个可供性子模块（从粗到细、2D到3D）**：

**Which2Act（哪个物体）**
- 按目标包围盒裁剪观测，重建目标连续视觉潜变量 ẑ（冻结编码器如 Flux VAE）
- MSE 损失：L_which = (1/CHW)·Σ‖ẑ − z_q‖²
- 作用：隔离交互实体，过滤背景干扰

**Where2Act（在哪里交互）**
- 1D 查询 token 经轻量 Transformer 解码器展开为 2D 可供性图
- 像素级 BCE 损失对齐真值掩码 M
- 作用：显式接触点引导，定位交互热点

**How2Act（怎么交互）**
- 双分支：扩散式 3D 形状生成分支（L_shape，DDPM 去噪目标）+ 10-DoF 空间布局回归分支（旋转/尺度/平移，SmoothL1）
- 作用：为动作专家提供空间先验与运动学约束；在复杂 6-DoF 真实交互中收益最大

三头在共享指令感知表征下**双向注意力联合精炼**——不是脆性的串行 Which→Where→How 流水线（消融证明去掉任一头只是优雅退化而非灾难崩溃）。

**自动化可供性标注管线**（解决机器人数据集无稠密可供性标签的瓶颈）：
1. 从动作序列提取关键帧
2. 文本 LLM（Claude Opus 4.5）把全局指令分解为逐关键帧子指令
3. VLM（Qwen3-VL）把关键帧转为检测类别与空间可供性查询
4. 微调的 RexOmni（经 PRISM）+ SAM + SAM-3D 产出 **10万+ 稠密标注**

**三阶段渐进训练课程**：

| 阶段 | 数据 | 可训练部分 | 目标 |
|------|------|-----------|------|
| I 通用可供性接地预训练 | AGD20K, RefSpatial, PRISM | 仅 M_gen+查询+解码器（其余冻结） | 视觉-语言对齐中的可供性先验 |
| II 可供性增强机器人协同训练 | 大规模合成机器人数据（InternData-A1 等） | 解冻 M_und, M_act 端到端 | L_act + L_afd 联合 |
| III 目标任务后训练 | LIBERO/CALVIN | 适配下游 | 对齐目标视觉分布与运动学 |

#### 3. 算法流程和关键步骤

```
推断:
 1. RGB观测 O_t + 指令 l → 理解专家 → h_t^und
 2. h_t^und → 可供性生成专家 → Â_t = {Which潜变量, Where热力图, How形状+布局}
 3. (h_t^und, Â_t) + 本体感知 s_t → 动作专家 → 动作块 â_{t:t+k}
（Where2Act 热力图同时是可视化输出，展示模型"决定在哪里动"）

训练: 三阶段课程，损失 = λ_which·L_which + λ_where·L_where
      + λ_shape·L_shape + λ_layout·L_layout + λ_act·L_act
```

#### 4. 输入输出

- **输入**：RGB 观测 O_t、语言指令 l、本体感知状态 s_t
- **中间输出**：结构化可供性 Â_t（目标潜变量/2D 热力图/3D 形状潜变量+10-DoF 布局）——中间监督可部署也可不部署（train-only 性质）
- **最终输出**：平滑时序一致的动作块

### Q2: 与Spatial AGI的关系

**问题**: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**分析**:

#### 1. 如何理解和表示空间

AffordanceVLA 的空间表示是**以操作为核心的三层分解**：

- **实体层**（Which）：空间中的任务相关实体，以视觉潜变量锚定——空间理解的第一步是"分离出重要的东西"
- **表面层**（Where）：交互可能性在物体表面的分布——2D 可供性图是"空间×动作可能性"的密度场
- **结构层**（How）：物体的 3D 形状与 10-DoF 空间位姿——支撑运动学规划的几何骨架

三层从 2D 到 3D、从粗到细，共同构成"操作空间"的完整描述。与 GraFT 的米制符号空间、CST-WM 的证据空间不同，这是**动作空间（action space）的空间表示**——空间的语义由"能对它做什么"定义，是 Gibson 可供性理论在 VLA 内的直系实现。

#### 2. 如何处理空间关系

- **语言-空间关系**：指令中的语义概念被理解专家接地到空间视觉 patch（"红色的杯子"→特定区域），可供性进一步把"在哪交互"具体化
- **指令消歧的空间机制**：真实实验中最亮眼的展示——同一场景、不同指令（"关抽屉" vs "拿抽屉" vs "拿烤面包机"），Where2Act 热力图准确指向不同交互区域。空间关系成为语言消歧的**可视化中介**
- **物体-物体空间关系**：How2Act 的 10-DoF 布局回归隐式编码了目标物体的空间排布约束

#### 3. 对Spatial AGI的启发

1. **中间表示是弥合"语义空间-物理空间"鸿沟的关键武器**：这一诊断超出机器人范畴——任何 Spatial AGI 系统（空间问答、场景编辑、世界模型）都面临同样的结构失配。可供性作为中间表示的三个性质（空间接地/语义条件/动作耦合）可作为选择中间表示的通用标准

2. **结构化监督保护基础模型能力**：train-only 中间监督（π0.5/π0.7 的离散动作 token/框，本文的可供性）防止低层目标侵蚀预训练能力——对 Spatial AGI 的启示：在基础模型上叠加空间能力时，要设计"离语义空间近"的中间任务，而不是让空间损失直接冲击 backbone

3. **数据效率的结构性来源**：可供性监督让每个样本同时监督动作、物体接地、空间定位、3D 推理——**一次监督多重信号**。40% 数据超越 π0 全量的结果说明：表示设计可以倍增数据的价值，这对数据稀缺的机器人/Spatial AGI 领域是重要结论

4. **消融的架构启示**：Frozen-Afd（冻结可供性专家当外部先验）灾难性崩溃（67.1%/2.83）——可供性必须与控制策略联合优化。这与"外部工具 vs 内化能力"的路线之争相关：至少在操作领域，内化+联合优化 > 外部先验。但注意与 GraFT 的"外挂工具"结论并不矛盾——GraFT 是知识查询（确定性事实），AffordanceVLA 是感知-动作映射（需要梯度对齐）

5. **自动标注管线的杠杆作用**：LLM 分解指令 + VLM 生成查询 + 分割/3D 基础模型产标注——用基础模型栈自动生成空间监督信号的范式，可推广到任何空间监督稀缺的场景

#### 4. 可以应用的Spatial AGI场景

- **家庭服务机器人**：指令跟随操作（颜色/形状/语义类别泛化，已在真实世界验证 88.3%）
- **长程自主任务**：Pick all the rubbish 式的持续重规划 + 抗人类干扰
- **空间指令消歧界面**：Where2Act 热力图作为"机器人理解确认"的人机交互可视化
- **VLA 通用训练配方**：可供性中间监督可移植到导航（哪里可走）、装配（哪里可接合）等领域
- **空间数据引擎**：自动标注管线可改造为通用空间标注工厂
- **仿真到真实的可供性迁移**：与 SceneTeract 的验证器结合可做数据质检

### Q3: 创新点和局限性

**问题**: 基于前面的分析，这个方法的主要创新点和局限性是什么？

**分析**:

#### 1. 主要创新点

1. **可供性的"内化"范式转变**：从外部消费的先验（AffordDP/CoA-VLA 的外部线索）到 VLA 内部联合优化的动作耦合中间表示——改变了可供性在机器人学习中的架构地位

2. **Which/Where/How 三分解的可供性本体**：第一次把操作先验系统性分解为物体接地/交互定位/3D 几何三个可独立监督、联合精炼的子问题，覆盖操作决策的完整信息链

3. **UAA 单向渐进注意力**：专家间严格因果的信息流——保持可供性特征纯度、防动作泄漏。消融显示去掉结构化注意力（Block-wise Tokens）即降至 90.3%/3.89，证明信息流架构本身是增益来源

4. **三重对照消融的说服力**（论文的方法论亮点）：
   - No-Afd（同数据无可供性目标）：92.4%/3.93 → 增益不是数据量
   - Frozen-Afd（冻结可供性先验）：67.1%/2.83 → 必须联合优化
   - Block-wise（同监督密度禁跨注意力）：90.3%/3.89 → 不是多任务密度
   三者合围，把增益严格归因于"结构化、联合精炼的表示"

5. **10万级自动可供性标注管线**：基础模型栈（Claude Opus 4.5 + Qwen3-VL + RexOmni + SAM/SAM-3D）的全自动监督合成——空间监督数据工程的标杆

6. **数据效率曲线**：π0 快速触顶 vs AffordanceVLA 在 40% 数据即破 π0 天花板——"架构×表示×数据相互放大"的实证

#### 2. 主要局限性

1. **可供性监督的上界取决于标注管线质量**：10万标注由 VLM+分割模型自动产出，错误标签（错误交互区域、错误部件识别）会成为系统性噪声；管线对长尾物体/罕见交互的覆盖未讨论

2. **How2Act 的 3D 表示仍是单视角推断**：从单个 RGB 观测扩散生成 3D 形状 + 回归布局，遮挡/透明/镜面物体上的形状先验可靠性存疑；10-DoF 布局回归对堆叠/含接场景的表达能力有限

3. **单臂双指设定的隐含约束**：消融显示 How2Act 在简单桌面双指任务收益有限（复杂 6-DoF 才显著）；灵巧手、双臂、工具使用未覆盖

4. **长程任务的记忆缺口**：论文自己承认 LIBERO-Long 上增益收窄（89.8 vs F1-VLA 91.3）——"极长程任务会从显式记忆中受益"，可供性是逐帧重算的，无跨时间记忆

5. **中间表示的推理开销**：三专家串行 + 扩散形状生成分支，推断延迟未详细报告；对高频控制（对比 π0 的流匹配动作专家）是否拖慢未讨论

6. **因果单向性的双刃剑**：UAA 禁止动作→可供性回流，保持纯度但也断绝了"控制反馈修正感知预测"的闭环通道——与 CST-WM 的因果约束同构，也继承同样的 trade-off

#### 3. 与其他相关工作的对比

| 维度 | 视频预测路线 | 文本推理路线 (CoT-VLA) | π0.5/0.7 train-only 监督 | 外部可供性 (AffordDP) | **AffordanceVLA** |
|------|------|------|------|------|------|
| 中间表示 | 稠密视频 | 文本理由 | 离散token/框 | 稀疏接触点 | **结构化可供性** |
| 冗余度 | 高 | 低但过粗 | 中 | 低 | **适中** |
| 空间接地 | 弱 | 无 | 部分 | 强 | **强** |
| 语义条件 | 弱 | 强 | 强 | 中 | **强** |
| 动作耦合 | 间接 | 间接 | 直接 | 外部开环 | **内部闭环** |
| backbone保护 | — | 部分 | ✓ | — | **✓（语义锚点）** |
| LIBERO 平均 | — | 83.9 | — | — | **95.8** |

## 核心技术发现

1. **VLA 的表征坍缩可以被结构化中间监督阻止**：可供性目标"离 VLM 语义空间近"，作为语义锚点防止动作损失侵蚀指令跟随（Toaster 案例：π0 忽视指令做抓放，86.7% vs 26.7% 的反转）
2. 三重对照消融严格证明增益来自**结构化表示+联合优化**，非数据量/监督密度
3. **指令消歧的空间机制**：同一场景不同指令，Where2Act 热力图准确区分交互目标（真实 Drawer/Toaster 组 86.7-100% vs π0 的 26.7-46.7%）
4. 数据效率：可供性监督使每样本产生四重学习信号，40% 数据破 π0 天花板
5. 三头联合精炼的冗余设计（去任一头优雅退化）优于脆性串行流水线
6. UAA 单向注意力是必要架构组件（破坏即降到 90.3%/3.89）

## 个人思考

### 最令人兴奋的发现

**"语义锚点"假说是全文最有理论味道的洞见**：动作损失直接反传进 VLM 会侵蚀指令跟随，而可供性目标因为"贴近视觉-语言语义"，起到锚定作用。这解释了一个普遍现象（为什么 VLA 常常无视指令）并给出优雅解法——与 π0.5/π0.7 的 train-only 监督殊途同归，但可供性是其中"最自然"的选择，因为它本身就是视觉、语言、动作的共同语言。

**Toaster 案例的震撼力不亚于任何数字**：π0 被要求"按按钮"，却反复做抓放动作——这不是能力问题，是预训练能力被动作微调侵蚀后的"失语"。而 AffordanceVLA 86.7% 的成功率背后，是 Where2Act 热力图清晰地聚焦在按钮上——**模型先"看清要动哪里"再动**。这种可解释的中间产物让 VLA 的失败可以诊断（热力图错 = 感知错 vs 热力图对动作错 = 执行错），对 Spatial AGI 的工程调试文化是重要贡献。

另一个惊喜是消融的严谨：三重对照把审稿人最难缠的"是不是数据多而已"问题提前堵死。No-Afd 只 +2、Frozen-Afd 崩溃、Block-wise 掉 5.5——三个实验各堵一条解释路径，增益归因无懈可击。

### 潜在局限

1. **标注管线的循环依赖隐患**：用 Qwen3-VL 生成可供性查询再训 VLA——教师模型的空间弱点会遗传给学生。管线生成的标注质量分布未审计，长尾物体可能是"幻觉标注"重灾区
2. **可供性是逐帧快照**：没有时间维度的交互预测（"接下来会怎样"），这与视频预测路线的缺失互为镜像——理想中间表示可能需要"可供性×时间"的联合体（可供性轨迹），但那会牺牲紧凑性
3. **与因果视角的潜在冲突**：UAA 的单向性与 CST-WM 的切边哲学一致，但操作任务里控制反馈对感知修正有真实价值（接触反馈改变对物体状态的判断）；单向架构把这类信息只能绕道环境观测循环，延迟一个控制周期

### 与今日研究的关联

- 与 **SceneTeract** 构成可供性研究的完美对偶：SceneTeract 是"验证侧"（给定场景+身体，检查交互可能性，确定性几何），AffordanceVLA 是"生成侧"（给定观测+指令，预测交互方式，神经网络学习）。两者可以闭环：SceneTeract 的验证器可以为 AffordanceVLA 的训练数据质检（自动标注管线的 10 万标注正需要这种质检），甚至提供 GRPO 奖励（正如同它在论文里对 Qwen3-VL 做的）
- Gibson 理论的一日双响：上午读的 SceneTeract 把可供性形式化为"关系性验证"，这篇把它实现为"感知-动作桥梁"——具身 AI 正在把 1977 年的生态心理学概念变成工程主干
- 与 **CST-WM** 共享因果信息流纪律（UAA 单向 ≈ 切断非法因果边），与 **GraFT** 共享"结构化中间产物提升可靠性"的哲学——今天五篇论文竟高度同构：**空间智能的增益来自把正确的结构放进正确的位置**

## 总结

### 核心发现总结
AffordanceVLA 用结构化可供性预测（Which/Where/How2Act）作为感知与动作之间的任务导向中间表示，配合 MoT 三专家架构与 UAA 单向渐进注意力，解决了 VLA 的语义-物理空间失配与表征坍缩问题。三重对照消融证明增益来自结构化表示本身；LIBERO 95.8%、CALVIN 4.33、真实复杂任务对 π0 的压倒性优势、40% 数据破天花板，共同确立了"可供性作为 VLA 语义锚点"这一范式的有效性。

### 对Spatial AGI的意义
空间智能的感知-行动闭环需要"离语义近、离动作也近"的中间表示，可供性是目前最优候选。对 Spatial AGI 更广的启示：(1) 在基础模型上叠加具身能力时用结构化中间监督保护预训练能力；(2) 表示设计可以倍增数据价值；(3) 中间预测产物（热力图/潜变量）天然提供可解释性与可诊断性。开放缺口：时间维度、标注质量审计、灵巧手与工具使用、显式长程记忆。

## 附录B: 深度延伸分析

### B1. "语义锚点"假说的机制推演

论文对侵蚀机制的直觉：动作损失 ∂L_act/∂θ_VLM ≠ 0 时，梯度持续把 backbone 的表征往"利于动作回归"的方向拉，语义对齐逐渐漂移。可供性锚点的作用机制可以形式化为多目标优化的视角：

```
min_{θ} L_act(θ) + λ·L_afd(θ)

L_afd 的梯度处在 VLM 预训练分布的高密度区（视觉-语言对齐目标附近）
→ 对 θ 形成"回拉力"，约束 L_act 引起的漂移
```

这解释了为什么 Frozen-Afd 反而崩溃：冻结的先验提供不了回拉梯度，只剩 L_act 单向拉扯（甚至更糟——外部特征与漂移中的 backbone 表征失配）。**锚点必须是活的**。这个"训练目标须处于预训练流形附近"的原则，可推广到任何在基础模型上加具身任务的设计。

### B2. Where2Act 作为人机交互界面

真实实验中热力图的可视化不只是调试工具，它开启了一种交互范式：

- **指令确认**：机器人显示其对"拿抽屉"的理解（热力图聚焦抽屉把手），用户在执行前即可发现误解
- **失败归因**：热力图错 → 感知/接地问题；热力图对但动作错 → 控制/执行问题
- **校正接口**：用户点选热力图上的正确区域 → 在线修正（未来工作）

这呼应了 Spatial AGI 的可解释性需求：中间表示不仅要"好用于模型"，还要"可读于人类"。

### B3. 数据效率曲线的深层含义

π0 触顶 vs AffordanceVLA 持续上升的曲线对比，暗示两种学习动力学的差异：

- π0：动作监督是单一信号，样本边际价值快速递减（学习信号饱和）
- AffordanceVLA：每样本 4 类监督（动作/接地/定位/3D），等效于"同一场景的多次不同任务"——类似多任务学习中样本复用的增益

推论：**表示的"监督分解度"决定数据的样本效率上限**。对数据最稀缺的机器人领域，这可能是比采集更多数据更现实的杠杆。

### B4. 与扩散动作专家的潜在协同

AffordanceVLA 的 How2Act 用扩散生成 3D 形状，动作专家生成动作块——双扩散结构有合流的潜力：以预测的形状/布局为条件做动作扩散，可实现"几何感知的接触丰富操作"（如铰接物体、可变形物体）。当前论文的 How2Act 在简单任务上收益有限，恰恰说明该通路尚未被充分利用——3D 先验的消费方式（进动作专家的条件）还有很大设计空间。

### B5. 失败边界与安全考量

- 热力图错误在安全敏感场景（利器、热表面）可能造成危险动作——可供性图上应叠加置信度与安全 veto 层
- 抗人类干扰实验（Pick all the rubbish）展示了鲁棒性，但干扰类型限于物理推抢；对"假装的可供性"（贴纸伪装的把手、图片中的杯子）等对抗样本未测——可供性预测器可能被视觉欺骗
- 10 万级自动标注若混入系统性偏差（如总把物体中心标为交互点），模型会学到"伪可供性先验"

### B6. 后续研究路线图

1. 可供性轨迹（spatio-temporal affordance）：联合预测交互区域的时间演化
2. 双向信息流的安全版本：受控的执行反馈进预测层（接触状态修正形状估计）
3. 灵巧手/工具中介的可供性本体扩展（How2Act 需表达工具使用链）
4. 标注管线的质量自检（用 SceneTeract 类几何验证器过滤伪标注）
5. 显式长程记忆与逐帧可供性的融合（LIBERO-Long 缺口的解法）
6. 跨可供性的统一：导航可供性（可走区域）+ 操作可供性的统一 token 空间

## 附录E: 方法论遗产——三重对照消融的设计模板

论文的消融设计值得作为模板记录，任何"结构化表示有效性"主张都应过这三关：

```
主张: 增益来自结构化表示 X
├─ 对照1 (No-X):    同数据同骨干, 去掉 X     → 排除 "数据量"
├─ 对照2 (Frozen-X): X 作为冻结外部先验      → 排除 "有特征就行", 证明需联合优化
└─ 对照3 (Unstructured-X): 同监督密度, 破坏 X 的结构 → 排除 "多任务密度", 证明是"结构"本身
```

三关全过（本文分别 92.4 / 67.1 / 90.3 vs 全量 95.8）才能把增益归因于结构化表示。这个模板对 Spatial AGI 领域的评测文化有普遍价值——大量工作声称"3D 先验有效"但只做了其中一关甚至零关。

## 附录F: 可供性本体与今日其他论文的概念对齐

| 概念问句 | SceneTeract（验证侧） | AffordanceVLA（生成侧） |
|---------|---------------------|------------------------|
| What（对什么） | 物体语义类 + 检测 | Which2Act 目标潜变量 |
| Where（在哪里） | P_reach/P_inter 几何检查 | Where2Act 热力图 |
| How（怎么交互） | P_clear 开启空间检查 | How2Act 形状+布局 |
| 条件于谁 | 身体档案（5参数） | 机器人本体（隐式，单臂） |

对齐点：What/Where/How 的三问结构完全一致——两个独立团队不约而同把可供性分解为相同的三元结构，这暗示该分解可能是可供性的**自然类别**（categorical structure），未来工作可以在此基础上直接对话与组合（验证器生成标签 → 生成器消费训练）。
