## 核心问题

### Q1: 核心算法原理是什么？

**问题**: 这篇文章的核心算法原理是什么？

**分析**:

#### 1. 核心思想和动机

现有世界模型（Latent World Model, LeWM）的范式是：
- 用编码器把观测编码为潜在状态 z_t = f_θ(o_t)
- 学习显式前向动力学模型 f_ψ: Z × A → Z，即 z_{t+1} = f_ψ(z_t, a_t)
- 规划时在潜在空间中通过 rollout + 搜索（CEM/MPPI）或优化来寻找动作序列：a* = argmin_a d(f_ψ^(H)(z_s, a), z_g)

这条路线存在三个根本性问题：

1. **表示塌缩风险需要额外正则**：前向预测目标本身无法阻止表示塌缩，需要引入 SIGReg 之类的固定先验正则化（如 VICReg/SIGReg 系），这些先验对潜在空间强加了人为假设，随数据和任务规模扩大会变得具有限制性。
2. **代理预测目标保留无关信息**：预测式目标鼓励表示保留"对预测有用"的一切信息，包括与动作无关的状态信息，导致表示几何并不围绕任务相关的转移和规划来组织。
3. **规划是推理时重计算**：搜索式规划在推理时需要评估大量候选未来（例如 CEM 300×30 即每步 9000 次 rollout），计算昂贵且与表示质量解耦。

RWM 的核心思想是：**把"规划"本身变成表示空间的几何操作**。即不学显式前向动力学，而是直接学一个表示几何，使得"从当前状态表示到目标状态表示之间构造一条潜在路径"就是一份可执行的计划。规划不再是通过搜索计算出来，而是通过几何构造" instantiate（实例化）"出来。

这解决一个关键的学习论问题：如果直接用动作级监督端到端训练编码器+规划器，动作损失只约束二者的组合输出，表示与规划之间的分工是欠定的（强规划器可补偿弱表示，弱规划器又让编码器无法吸收规划计算）。RWM 的答案是**把规划约束为表示空间中的直接几何构造**，然后把动作监督施加在构造出来的潜在转移上，从而把学习信号直接导向表示几何本身。

#### 2. 主要技术方法

**（1）潜在路径构造（Latent Path Construction）**

给定同一条轨迹中的两个观测 o_t 和 o_u（t < u），编码端点 z_t = f_θ(o_t)、z_u = f_θ(o_u)，然后按时间比例线性插值构造中间表示：

```
z̃_m = (1 - α_{t,m,u}) · z_t + α_{t,m,u} · z_u,   α_{t,m,u} = (m - t) / (u - t)
```

关键点：插值得到的 z̃_m 在学习之前只是几何上的构造中间点，**插值本身并不意味着有效的转移或可执行轨迹**。RWM 的全部训练目标就是让这些构造的中间点获得任务相关的状态、转移和动作语义。

**（2）构造路径上的逆动力学监督（IDM-on-Constructed-Path）**

训练一个共享逆动力学模型 f_φ: Z × Z → A，从相邻的插值表示对恢复真实执行的动作：

```
L_IDM_int = (1/(u-t)) · Σ_{i=t}^{u-1} || f_φ(z̃_i, z̃_{i+1}) - a_i ||²
```

这个目标让构造路径"落地"到动作语义上：相邻的插值表示必须支持恢复轨迹上真实执行的动作。

**（3）辅助目标（可选）**

- 编码态逆动力学：L_IDM_enc = 直接对相邻编码态 (z_i, z_{i+1}) 做 IDM，为观测到的潜在转移提供直接动作监督。
- 软插值一致性：L_consist = ||z̃_i - z_i||²， softly 对齐构造转移表示与对应时间位置的真实编码态，只约束构造路径不漂离观测轨迹几何，不决定保留什么信息。

**总目标**：

```
L_all = L_IDM_int + λ_enc · L_IDM_enc + λ_consist · L_consist
```

训练时只学编码器 f_θ 和 IDM f_φ，**完全不需要前向动力学模型（FDM）**。

**（4）为什么插值上的 IDM 能塑造表示？**

- **防塌缩**：如果所有观测映射到同一表示，相同的潜在输入对应不同动作，IDM 目标无法满足——动作监督本身排除了平凡塌缩解，无需 SIGReg 类正则。
- **保留转移相关状态**：如果不同的物体构型塌缩到相似的潜在端点，它们会诱导相似的插值路径，产生矛盾的 IDM 监督信号。因此编码器必须保留区分状态、支持动作恢复的信息。

#### 3. 算法流程和关键步骤

**训练阶段**：
1. 从离线数据集 D 采样动作标注的轨迹段 (o_t, a_t, ..., a_{u-1}, o_u)
2. 编码端点 z_t = f_θ(o_t), z_u = f_θ(o_u)
3. 按线性插值构造路径上的过渡表示 z̃_i
4. 用共享 IDM 从相邻表示对恢复动作，计算 L_IDM_int（+ 可选的 L_IDM_enc、L_consist）
5. 联合优化 f_θ 和 f_φ

**推理阶段（Rollout-free）**：
1. 编码当前观测和目标观测：z_t = f_θ(o_t), z_g = f_θ(o_g)（encode）
2. 直接在两个端点之间构造潜在路径 P_{t:g} = (z̃_t, z̃_{t+1}, ..., z̃_g)（construct）
3. 共享 IDM 对每个相邻对解码动作：â_m = f_φ(z̃_m, z̃_{m+1})（decode）
4. 动作序列可以**并行解码**、开环执行；闭环控制时每个动作块执行完后重新编码当前观测、重新构造潜在计划（replan）

整个推理流程是 encode–construct–decode，没有递归前向预测，没有动作空间搜索。

#### 4. 输入输出

- **输入**：离线动作标注轨迹（视觉观测序列 + 动作序列）；推理时输入当前观测 o_t 和目标观测 o_g
- **输出**：训练得到编码器 f_θ 与逆动力学模型 f_φ；推理时输出从当前到目标的动作序列（或动作块）
- **模型规模**：LIBERO 上 RWM 仅 0.03B 参数（对比 LeWM+OFT-head 0.07B、OpenVLA-OFT 7B）

### Q2: 与通用空间智能（Spatial AGI）有什么关系？

**分析**:

#### 1. 如何理解和表示空间

RWM 提出了一种激进的立场：**空间（以及更一般的状态空间）的"可导航性"应该内嵌在表示几何中**。传统表示学习把空间理解为"状态的集合"（每个点一个表示），RWM 则要求表示空间的连续区域也有语义——端点之间的插值路径本身就是从 A 到 B 的行动计划。这对 Spatial AGI 的启发是：

- 空间理解不只是"识别物体在哪"，而是"知道如何从一个空间状态到达另一个空间状态"
- 空间的度量结构应该由动作可达性（actionability）定义，而不是由视觉相似性定义
- 一条潜在插值路径对应物理世界中一条可执行的轨迹，这是"空间即行动地图"的形式化

#### 2. 如何处理空间关系

RWM 处理空间关系的方式是几何式的：
- 状态之间的"距离" = 完成转移所需的动作数量/难度（由 IDM 可恢复性隐式定义）
- 状态之间的"路径" = 潜在空间中的插值线段，且这条线段被训练为可执行的
- 空间关系（before/after、toward、reachable）都退化为潜在几何中的构造与解码操作

这与认知科学中的认知地图（cognitive map）假说呼应：生物的空间记忆不仅存储地标，还存储地标之间的可通行路径。RWM 是这一假说的最小化机器实现。

#### 3. 对 Spatial AGI 的启发

1. **搜索-free 规划是空间智能系统的关键工程属性**：98.25% macro SR 且无推理时搜索，意味着空间规划可以做到实时、可并行、低算力——这是 Spatial AGI 走向端侧/具身部署的前提。
2. **动作监督可以替代表示正则**：对 Spatial AGI 的表征研究（如 VLM 空间推理）而言，这是一个重要信号——与其用视觉预测目标+正则化塑造空间表示，不如直接用"可执行性"（能否恢复正确动作）来塑造。空间表示的质量标准是"能不能行动"，不是"能不能重建"。
3. **规划即几何构造**：为空间智能体提供了一种新的规划原语。导航、操作、场景图遍历都可以被表述为"在合适的表示空间中构造路径"，而搜索只是在几何没学好时的兜底。
4. **分层扩展的潜力**：当前 RWM 的路径是直线插值，对短程任务足够；对长程空间任务，可以设想在分层表示上构造分段路径（房间级路径 + 物体级路径），这与空间智能中层级空间记忆的思路天然契合。

#### 4. 可以应用的 Spatial AGI 场景

- **机器人导航与操作**：goal-conditioned 控制，LIBERO-Goal 上 93% SR 已验证；可扩展到家庭级长程任务
- **视觉语言导航（VLN）**：把语言目标解析为目标表示，路径构造直接给出动作序列
- **世界模型的记忆检索**：GLAM 类全局时空记忆中，"回到记忆中的某个状态"可表述为潜在路径构造
- **自动驾驶**：从当前交通场景表示到目标场景表示（如变道完成态）的路径构造
- **空间推理基准训练信号**：VABench 这类 observe-reason-act-revise 基准中，act 环节可用 RWM 式规划器实例化

### Q3: 主要创新点和局限性是什么？

**分析**:

#### 1. 主要创新点

1. **第三种规划范式**：不同于搜索式（rollout+CEM/MPPI）和摊销式（goal-conditioned IDM 直接映射端点到动作），RWM 提出构造式规划——构造潜在路径再局部解码动作。它在端点映射（太粗）和全搜索（太贵）之间取得中间态：路径提供了中间的结构化子目标，但构造是 O(H) 且并行的。
2. **IDM-on-Constructed-Path 目标**：这是全文最核心的技术贡献。把动作监督施加在"插值出来的"表示上，一举三得：防塌缩（无需 SIGReg）、保留转移相关状态、把无约束的表示区域变成可执行计划。
3. **去 FDM 化**：训练中完全不需要前向动力学模型，模型更小（LIBERO 上 0.03B）、推理更快、避免了 FDM 多步 rollout 的误差累积。
4. **实证结果强**：连续控制 macro SR 98.25%，超过所有搜索式基线（最强 INTACT guarded actor 96.86%，且其每步评估 384 条候选轨迹）；LIBERO-Goal 93% 大幅领先同规模 LeWM（71.2%）与 RC-aux（81.2%），逼近 7B 的 OpenVLA-OFT（97%）。

#### 2. 主要局限性

1. **直线路径假设**：潜在路径是线性插值，隐含假设表示空间中端点之间的"直线"对应物理可行的转移。对需要绕障碍、多阶段长程任务，直线路径可能穿越"不可达区域"。论文没有测试强非凸、长时程的空间任务。
2. **目标观测依赖**：推理需要目标观测 o_g。在目标只有语言描述或部分可观测的场景（LIBERO-Goal 的 goal-unobserved 设定靠附录 A.2 的特殊处理），如何获得目标表示是开放问题。
3. **插值点的物理性有限**：消融显示随着插值表示参与比例增加，动作可恢复性下降；TwoRoom 上状态探针 R² 低于 LeWM，说明构造表示并非完全保物理。
4. **开环执行退化**：闭环间隔 h=25 时 macro SR 从 98.33% 掉到 69.17%，说明对执行误差累积敏感，需要频繁重规划，这对高延迟的视觉系统是负担。
5. **评价局限**：连续控制任务较简单（PushT/Cube/Reacher/TwoRoom），LIBERO-Goal 虽是操作基准但仍属桌物操作；真正长程、大空间、动态环境下的表现未知。

#### 3. 与相关工作的对比

| 维度 | Dreamer 系 | LeWM/Fast-LeWM | GC-IDM | RWM |
|------|-----------|----------------|--------|-----|
| 动力学模型 | 显式 FDM（RSSM） | 显式潜在 FDM | 无 | **无** |
| 防塌缩手段 | 重构+KL | SIGReg 正则 | 动作监督 | **动作监督（IDM-on-path）** |
| 推理时规划 | rollout+搜索 | rollout+CEM | 端点直接映射 | **路径构造+局部解码** |
| 推理成本 | 高（搜索） | 中-高（CEM 300×30） | 极低 | **低（O(H) 并行解码）** |
| 计划结构 | 无显式计划 | 无 | 无中间结构 | **有（潜在路径=显式计划）** |
| 连续控制 macro SR | — | 85.75-92% | 96.0% | **98.25%** |

相对 DINO-WM/LeWM 系：RWM 把"规划器"从推理时算法搬进表示几何，避免了 SIGReg 先验。
相对 GC-IDM：RWM 保留了中间路径结构，PushT 上 85.78%→95.44% 的提升证明中间子目标结构在高接触性任务（连续推动）上很关键。

## 核心技术发现

- 发现1：动作级逆动力学监督可以完全替代前向预测+表示正则，学到信息量相当的表示（探针实验：状态/动作可恢复性与 LeWM 相当，Cube 上动作探针大幅更好）
- 发现2：插值构造的表示 z̃ 不是任意点——状态信息高度可恢复，且当一端或两端被构造表示替换时动作仍可恢复（PushT/Cube 上尤其好），证明"表示空间的无约束区域"确实可以被训练出转移语义
- 发现3：L_IDM_int 是可执行性的唯一关键：去掉它 PushT SR 从 96.00% 崩到 39.37%；L_IDM_enc 提升状态保真（探针 R² 0.95→0.98），L_consist 提供几何锚定
- 发现4：闭环频率是性能生命线：h=5 时 98.33%，h=25 时 69.17%，重规划是必要机制而非可选优化

## 与Spatial AGI的关系

### 直接贡献

RWM 为 Spatial AGI 提供了"规划即几何构造"的范式验证：在共享表示空间中，状态、转移、计划三者统一表达。这是把空间智能从"理解空间"推进到"表示空间中的可行动性"的一步。

### 技术启发

1. 空间表示的训练信号应该来自动作/可执行性，而非视觉重建或预测——这与近期"几何优先于语言先验"的思潮一致
2. 计划应该是一等公民的表示对象，而不是推理时临时搜索出来的副产品
3. 小模型（0.03B）+正确表示几何 可以逼近 7B VLA 的性能，表示效率是空间智能的可扩展性关键

### 应用场景

具身导航规划、机器人操作、自动驾驶轨迹生成、空间记忆的"状态回放"、VLN 的动作解码器、世界模型 rollout 的替代品。

## 个人思考

### 最令人兴奋的发现

最有趣的是概念层面的重新定位：**世界模型的传统定义是"预测器"（给定状态和动作预测下一状态），RWM 把世界模型重新定义为"可执行几何"**。在这个视角下，学习一个好的世界模型 = 学习一个"任意两点之间的直线都是可行路径"的空间。这个空间如果存在，规划问题就退化为作图问题（ ruler-and-compass construction）。当然，物理世界的组合复杂性意味着这种"欧氏化的世界"只在小尺度/单一技能域内成立，但"把可达性学进度量"的思想可以分层复用：房间级图 + 物体级 RWM + 接触级 RWM。

### 潜在局限

线性插值是最朴素的路径构造规则，它之所以 work，是因为这些连续控制任务的表示空间已经被 IDM 训练得足够"良性地形"。一旦地形不良（比如需要绕开障碍物构型），直线会穿过语义不连续区。后续工作很自然会引入非欧构造（geodesic、流形上的测地线）或图结构（离散路标点+局部 RWM）。另外，把语言目标映射为目标表示这一步是缺失的——这是连接 RWM 与空间智能语言接口的关键缺口。

### 与昨日研究的关联

- 昨天的 GLAM（Latent World Model Global Spatiotemporal Memory）关注全局时空记忆，其记忆检索本质上是"找到与当前相关的历史状态"；RWM 提供了互补的能力——"构造到达目标状态的路径"。二者结合：记忆提供目标候选（哪里有过成功状态），RWM 提供到达手段（如何走过去）。
- 昨天 LightNav-0 用 VLM 激发空间智能做导航，其动作头是任务特定的；RWM 的路径解码可作为 VLM 之后的统一动作接口，让"语言→目标表示→路径构造→动作"成为导航的完整链路。
- 近几天多篇论文（IGGT4D、PatchWAM、AWM-VLA）都在往"世界模型与动作统一"的方向收敛，RWM 是这一趋势的极简主义代表：统一到极致——连动力学函数都不要了。

## 总结

### 核心发现总结

RWM 证明：表示空间本身可以学会"可执行的计划结构"。通过在端点构造的潜在插值路径上施加逆动力学监督，编码器被迫保留动作相关状态并把表示几何组织成"任意两点间的路径即计划"的形态。推理时规划退化为 encode–construct–decode 三步，无 rollout、无搜索，在连续控制上以 98.25% macro SR 超过所有搜索式方法，在 LIBERO-Goal 上以 30 倍小的模型逼近 7B VLA。

### 对Spatial AGI的意义

RWM 为 Spatial AGI 指出一条"表示效率"路线：空间智能的规划能力不必来自更大的模型或更重的推理时搜索，而可以来自更聪明地组织的表示几何。当空间表示的每一条内部路径都携带可执行语义时，"理解空间"与"在空间中行动"合二为一。这是从 Spatial Understanding 迈向 Spatial Agency 的关键一步，尽管直线插值假设和目标观测依赖提示了通往真实开放世界还有长路要走。

## 附：方法逐步走查（Step-by-Step）

### A. 训练一次迭代的完整数据流

```
输入: 轨迹段 (o_t, a_t, o_{t+1}, a_{t+1}, ..., o_u)
  │
  ├─ [1] 端点编码
  │      z_t = f_θ(o_t)
  │      z_u = f_θ(o_u)
  │
  ├─ [2] 路径构造（纯几何，无学习参数）
  │      对 i = t..u:
  │          z̃_i = (1-α_i)·z_t + α_i·z_u,  α_i = (i-t)/(u-t)
  │      注: z̃_t = z_t, z̃_u = z_u（端点即插值起点终点）
  │
  ├─ [3] 构造路径上的 IDM 损失（主损失）
  │      对 i = t..u-1:
  │          â_i = f_φ(z̃_i, z̃_{i+1})
  │          L_IDM_int += ||â_i - a_i||²
  │      归一化: L_IDM_int /= (u-t)
  │
  ├─ [4] 编码态 IDM 损失（可选辅助）
  │      L_IDM_enc = mean ||f_φ(z_i, z_{i+1}) - a_i||²
  │
  ├─ [5] 插值一致性损失（可选辅助）
  │      L_consist = mean ||z̃_i - z_i||²  (i = t+1..u-1)
  │
  └─ [6] 联合反向传播
         更新 f_θ（编码器）与 f_φ（共享 IDM）
         L_all = L_IDM_int + λ_enc·L_IDM_enc + λ_consist·L_consist
```

要点：
- 步骤 [2] 无参数、无动力学模型；所有学习信号都通过 [3] 的动作恢复误差流回编码器
- IDM 是共享的：训练中它既是损失的计算工具，也是推理时的动作解码器
- 这里的 f_φ 是"浅层 IDM"（论文图2标注 Shallow-IDM），暗示解码很轻，重活都由表示几何承担

### B. 推理一次规划的完整数据流（闭环模式）

```
输入: 当前观测 o_t, 目标观测 o_g, 动作块长度 h
  │
  ├─ [1] encode:  z_t = f_θ(o_t),  z_g = f_θ(o_g)
  ├─ [2] construct: 规划时域 H（对应动作块）内构造
  │       z̃_m = (1-α_m)·z_t + α_m·z_g,  m = t..g
  ├─ [3] decode:  â_m = f_φ(z̃_m, z̃_{m+1}), 对所有 m 并行
  ├─ [4] execute: 机器人执行前 h 步动作（h 默认 5）
  └─ [5] replan:  用新的当前观测回到 [1]
```

并行性：因为每个 z̃_m 只依赖端点（不依赖前一时刻的预测输出），整个动作序列可以一次并行解码——这与递归 FDM rollout（必须串行）形成鲜明对比，是搜索-free 且 rollout-free 的双重优势。

### C. 问题形式化的数学表述

- 离线数据集 D = {τ}, τ = (o_0, a_0, o_1, ..., a_{T-1}, o_T)
- o_t ∈ O：观测或固定长度观测块（observation chunk）
- a_t ∈ A：动作或固定长度动作块（action chunk）
- 编码器 f_θ: O → Z
- 传统 LeWM 额外学习 f_ψ: Z × A → Z
- 传统规划的搜索目标：a* = argmin_{a_{s:s+H-1}} d(f_ψ^(H)(z_s, a), z_g)
- RWM 取消 f_ψ，规划目标变为：构造 P_{s:g} = (z̃_s, ..., z̃_g)，再逐段解码 a_m = f_φ(z̃_m, z̃_{m+1})

### D. 三个损失的分工总结表

| 损失 | 约束对象 | 提供的信息 | 去掉后果 |
|------|---------|-----------|---------|
| L_IDM_int | 构造路径上的相邻插值对 | 可执行性（核心） | PushT SR 96%→39%，不可执行 |
| L_IDM_enc | 观测态相邻编码对 | 状态保真度 | 状态探针 R² 0.98→0.95 |
| L_consist | 插值点 vs 对应编码态 | 几何锚定 | 构造路径可能漂离观测流形 |

## 附：实验深度解读

### E. 连续控制结果的深层观察

1. **PushT 是分水岭任务**：PushT 需要连续接触推动（推动滑块到目标形状），转移高度依赖精确的中间状态。GC-IDM 系（无中间结构）只有 84-86%，而 RWM 95.44%、Fast-LeWM+SC 98.0%。这证明**中间路径结构**正是接触丰富任务最需要的——它相当于隐式的子目标序列。
2. **搜索式方法的代价结构**：INTACT guarded actor 96.86% 需要每步评估 128×3=384 条候选；LeWM CEM 300×(30/10) 是 9000 次 rollout/步。RWM 一次前向并行解码，成本差 2-3 个数量级。
3. **TwoRoom 上 RWM 99.67%**：TwoRoom 需要绕房间导航（非凸拓扑），RWM 依然近乎满贯，暗示线性插值在学好的表示中隐式处理了拓扑障碍——插值路径的语义由 IDM 训练重新定义，不再是欧氏直线，而是"任务空间直线"。

### F. LIBERO-Goal 结果的深层观察

1. **T5 任务（最难）**：RWM 90% vs LeWM 44%。T5 类任务（论文未展开细节，LIBERO-Goal 中最难子集）的多阶段结构使无中间结构的端点映射崩溃，而路径构造天然给出阶段分解。
2. **参数效率**：0.03B vs 0.07B（同系基线），模型减半性能反升 12-22 个点，说明增益来自表示组织方式而非容量。
3. **与 7B OpenVLA-OFT 的差距仅 4 个点**：OpenVLA-OFT 是在大规模语料上预训练的通用 VLA，RWM 是任务域内训练的小模型。两者非同一赛道，但差距之小说明"表示几何规划"路线的天花板不低。

### G. 探针实验的方法论价值

论文用冻结编码器+微型 MLP 探针回答了两个 critics 必问的问题：

1. **"没有正则化，表示不会塌吗？"** —— 不会。状态/动作探针 R² 与 LeWM 相当（Cube 动作探针大幅更好），动作监督内建了防塌缩机制。
2. **"插值点只是几何玩具吧？"** —— 不是。状态信息在 z̃ 上高度可恢复（接近 z）；动作探针在 (z_t, z̃_{t+1})、(z̃_t, z̃_{t+1}) 等混合对上仍可恢复动作（PushT/Cube 尤佳），随构造表示比例增加性能渐进衰减而非崩溃。

这套探针协议本身值得 Spatial AGI 研究借鉴：评价空间表示质量时，不要只看下游任务成功率，还要探测表示中状态信息与转移信息的保真度。

## 附：批判性问答（自问自答）

**Q: 线性插值会不会太弱？为什么不用学习式路径生成器？**
A: 论文的立场是"构造规则保持最简，把全部智能交给表示几何"。线性插值保证构造可微、可并行、无额外参数。若路径生成器可学习，会重新引入"表示与规划分工欠定"问题（第一章动机）。代价是对表示地形的良态性要求高——这被 IDM 监督缓解但未消除。

**Q: RWM 和 Diffusion Planner（如 diffuser 类轨迹扩散模型）什么关系？**
A: 二者都是"生成计划而非搜索计划"。区别：diffuser 在观测/动作空间用迭代去噪（推理多步），RWM 在表示空间一步构造；diffuser 通常需要轨迹分布训练数据，RWM 只需要动作标注轨迹段。RWM 可视为"确定性、一步式、潜在空间的计划生成器"。

**Q: 目标观测从哪来？语言任务怎么办？**
A: 连续控制设定直接给出目标观测。LIBERO goal-unobserved 设定在附录 A.2 处理（细节未在正文展开）。语言→目标表示的映射是明确的未来工作方向，也是接入 VLM 空间智能生态的接口。

**Q: 与层级强化学习（HRL）的 option/subgoal 什么关系？**
A: RWM 的路径中间点功能上类似 subgoal，但它们不是离散的、由高层策略采样的，而是连续的、由几何构造的。可以说 RWM 是"连续、免学习的 subgoal 生成"，HRL 的分层先验可以嫁接到路径粒度选择上（例如先在粗时序上构造路径再细化）。

## 附：对后续研究的三条具体建议

1. **非线性路径构造**：在表示空间学习测地线（例如用局部度量张量加权的最短路径），或用少量可学习路标点（waypoints）分段插值，验证对绕障/长程任务的增益。
2. **语言条件化的目标编码**：把 o_g 替换为语言目标经 VLM 编码的表示，或用检索从空间记忆（GLAM 类）中取目标表示，打通"语言→表示目标→RWM 路径→动作"链路。
3. **不确定性感知的 replan 触发**：当前固定 h=5；可以让 IDM 动作置信度或构造路径与重编码观测的偏离度自适应决定何时 replan，降低高延迟视觉系统的重规划开销。

```
   ↓

   ↓
[缺陷1] 前向预测目标 → 需 SIGReg 类先验防塌缩 → 固定假设限制扩展
   ↓
[缺陷2] 代理预测保留动作无关信息 → 表示几何不围绕规划组织
   ↓

   ↓

```

### 相关工作三分法

1. **表示学习线**：重构（AE/VAE）→ 不变性自监督（MoCo/SimCLR/BYOL/VICReg/DINO）→ 时序预测（V-JEPA）→ 具身交互（LeWM 等）→ RWM：不仅表示状态，还表示状态之间的区域
2. **世界模型线**：Ha&Schmidhuber → PlaNet/Dreamer 系 → MuZero（面向规划优化）→ 生成式（Genie/Cosmos，视觉想象昂贵）→ 潜在预测（LeWM，仍需正则）→ RWM：去预测化
3. **规划线**：推理时搜索（CEM/MPPI；DINO-WM/LeWM/Fast-LeWM 都属此类）→ 摊销策略/GC-IDM（端点直接映射）→ RWM：路径构造式（第三种）

### 消融细节补充

- **表示信息探针**（Fig.3）：冻结编码器，单 epoch 训练微型 MLP：
  - 状态探针：从单个 z 预测模拟器构型（不含速度），报告 episode 划分验证集 R²
  - 动作探针：从相邻对 (z_t, z_{t+1}) 预测动作
  - 结果：RWM 状态可恢复性与 LeWM 在 PushT/Cube/Reacher 相当，TwoRoom 略低；动作可恢复性在 PushT/Reacher/TwoRoom 持平，Cube 大幅更好
- **构造表示信息探针**（Fig.4）：状态探针只在 z 上训练、在 z 和 z̃ 上评估；动作探针在 (z_t,z_{t+1}) 上训练、在三类混合对上评估
  - 结果：z̃ 上状态高度可恢复；混合对上动作可恢复，随构造比例增加渐进衰减
- **闭环间隔**（Fig.5）：h∈{5,10,15,20,25}，macro SR 单调下降 98.33→69.17；PushT 最敏感（95.67→26），Cube/TwoRoom 最鲁棒（h=25 仍 90/97.67）
- **目标函数消融**（Table 3，seed 3072，PushT）：
  - 只有 L_IDM_enc + L_consist（无 L_IDM_int）：39.37%（灾难性）
  - 只有 L_IDM_int：95.56%
  - L_IDM_int + L_IDM_enc：96.17%（最佳）
  - L_IDM_int + L_consist：95.23%
  - 全部：96.00%（默认，兼顾状态探针 R²）
