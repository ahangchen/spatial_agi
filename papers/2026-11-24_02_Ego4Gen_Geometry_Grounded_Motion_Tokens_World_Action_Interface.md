# Ego4Gen: Generating Geometry-Grounded Motion Tokens as a World-Action Interface

**发表日期**: 2026-11-20
**arXiv链接**: https://arxiv.org/abs/2611.27513
**PDF链接**: https://arxiv.org/pdf/2611.27513
**HTML版本**: https://arxiv.org/html/2611.27513
**作者**: Yang Liu, Chao Ye, Jiahao Zhang, Zeyuan Hou, Ruijie Fang, Xiyin Ni, Xinyang Ren, Weiyang Lin
**主题分类**: 4D 世界模型 / 世界-动作接口 / 机器人操作

## 一句话总结

Ego4Gen 基于 Cosmos3-Nano 生成式骨干，从单张自我中心图像和文本提示联合生成时间对齐的 RGB 帧、稠密点图和稠密场景流，并引入 FlowInverse 轻量逆动力学网络把预测的 4D 潜变量翻译为机器人动作，提出"几何接地的运动 token"作为连接 4D 未来生成与机器人操作的世界-动作接口。

## 核心问题

### Q1: 核心算法原理是什么？

**问题**: 这篇文章的核心算法原理是什么？

**分析**:

#### 1. 核心思想和动机

机器人学习的一个根本瓶颈是**动作标注数据的稀缺**：遥操作数据采集成本极高，而互联网上存在海量无动作标注的视频。世界模型的承诺是"从想象中学习"——如果能预测动作执行后的场景变化，就能在想象空间中评估和优化策略。

但现有方法存在一个关键断层：

- **视频世界模型**预测未来像素，外观逼真但缺少显式 3D 结构与运动，无法直接转化为控制；
- **潜在动作方法**（latent action）把视频压缩成抽象潜变量，牺牲了几何细节，控制精度不足。

Ego4Gen 的核心主张：**世界模型与动作策略之间应该有一个"几何接地的运动 token"接口**——这个接口既是显式 3D 的（点图 + 场景流，可解码为真实几何），又是潜在可生成的（作为生成式骨干的中间潜变量），还是可逆的（经逆动力学网络映射回动作）。一个接口同时服务"看未来"和"控制未来"两个需求。

这与 11-20 的 zSight（统一 VLA 与潜在世界建模）、11-23 的 CoT-WAM（plan latent 协同训练）构成同一条线：**世界模型的输出表示正在从像素转向结构化潜在量**，本周多篇论文都在定义这个潜在接口应该长什么样。

#### 2. 主要技术方法

**（a）联合 4D 未来生成**

给定自我中心初始图像 + 文本指令，联合生成三种时间对齐的模态：

```
RGB 帧         → 场景外观演变
稠密点图        → 场景空间结构（每像素 3D 坐标）
稠密场景流      → 每点 3D 运动（结构如何动）
```

时间对齐意味着三种模态逐帧一致——外观、结构、运动共享同一时间轴，不是独立生成再拼接。这保证了几何一致性：物体移动时其点图位置与场景流向量必须自洽。

**（b）生成骨干扩展：Cosmos3-Nano + 模态路由 LoRA + 非对称注意力**

- 基座是 NVIDIA Cosmos3-Nano（视频世界模型预训练骨干），继承其视频先验；
- **模态路由 LoRA**：为几何模态（点图、流）分配专属 LoRA 分支，避免破坏预训练的视频生成能力——生成新模态而不遗忘旧能力；
- **非对称注意力**：外观模态与几何模态间的注意力设计不对称（几何以外观为条件更强，反之较弱），反映"外观主导生成、几何锚定结构"的因果方向。

**（c）几何伪标签：MotionCrafter**

训练几何模态的监督来自 MotionCrafter 提供的伪标签（从视频推断几何与运动），无需真实深度传感器或 3D 标注——这是把"几何接地"目标与"大规模视频数据"兼容的关键工程选择。

**（d）FlowInverse：两阶段逆动力学**

4D 潜变量 → 动作的翻译由轻量网络 FlowInverse 完成，两阶段训练：

1. 第一阶段：在大规模无动作视频上学"视觉变化 ↔ 潜在运动"的对应；
2. 第二阶段：在少量动作标注数据上学"潜在运动 ↔ 真实机器人动作"的映射。

这个设计把昂贵的手臂动作标注需求压缩到第二阶段的小数据上，是"用世界模型减少动作标注依赖"主张的直接实现。

#### 3. 算法流程和关键步骤

```
输入: 自我中心图像 I_0 + 文本指令 l
  ↓
[Cosmos3-Nano + 路由LoRA] 生成未来 T 帧:
  - RGB 帧 (外观)
  - 点图序列 (结构)
  - 场景流序列 (运动)
  → 输出 4D 潜变量 z_{1:T}（几何接地运动 token）
  ↓
分支A [几何解码]: z → 显式 3D 结构 + 运动（可视化/评估/规划用）
分支B [FlowInverse]: z_{1:T} → 动作序列 a_{1:T} → 机器人执行
  ↓
闭环: 执行后观测新状态，滚动生成下一个 4D 未来
```

#### 4. 输入输出

- **输入**：单张自我中心 RGB 图像 + 语言任务指令。
- **输出**：
  - 时间对齐的 RGB 帧、稠密点图、稠密场景流（4D 未来）；
  - 经 FlowInverse 的机器人动作序列。

#### 5. 关键实验结果

- **OOD 泛化**：几何与运动潜在量在分布外设置下优于被评估的潜在动作基线与视频潜在基线——几何接地带来的不只是更好看，而是更可迁移；
- **闭环策略**：预测的 4D 潜在量经 FlowInverse 翻译后可驱动真实闭环控制，验证了"世界-动作接口"的端到端可用性。

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**问题**: 这篇文章与通用空间智能有什么关系？

**分析**:

#### 1. 如何理解和表示空间

Ego4Gen 的空间表示是"**生成的 4D**"：空间结构（点图）与空间动力学（场景流）都不是从输入重建的，而是从生成模型中采样出来的。这体现了 Spatial AGI 的一个核心命题——**理解空间的能力最终要表现为"想象空间"的能力**。如果说 StereoVLM 解决"感知现在"，Ego4Gen 解决"想象未来"，而想象必须携带正确的几何（点图）与正确的动力学（场景流），否则想象无法支撑行动。

#### 2. 如何处理空间关系

- 空间关系在 4D 潜变量中以稠密、逐点的方式编码：每个点的位置与速度随时间演化，物体间关系（接近、支撑、包含）隐含在点云的时空组织里；
- 文本指令通过条件生成改变 4D 未来的走向——语言到空间的接口是生成式的，语言"导演"几何与运动的演变；
- FlowInverse 提供"几何变化 → 动作"的逆向通道，使空间关系变化可以被主动 cause（控制闭环）。

#### 3. 对 Spatial AGI 的启发

1. **世界-动作接口的标准化**：Spatial AGI 需要在"想象"与"行动"之间反复切换，Ego4Gen 证明了一个几何接地的潜在接口可以同时服务两者，避免了像素生成（不可控）与抽象潜变量（不接地）的两极；
2. **几何伪标签路线**：MotionCrafter 式伪标签说明几何监督可以从视频大规模自动获得——4D 世界模型不必依赖 3D 传感器数据即可接地；
3. **模态路由的持续学习**：给预训练生成模型加新模态而不遗忘，是构建多模态 Spatial AGI 基础模型的通用工程模式；
4. **减少动作标注依赖**：两阶段 FlowInverse 把动作标注需求降到最低，直指机器人数据瓶颈。

#### 4. 可以应用的 Spatial AGI 场景

- **机器人操作预演**：执行前在 4D 想象中评估动作后果（预演-验证-执行），与 Verify2Act（11-22）的 critic 验证互补；
- **遥操作数据增广**：从少量演示生成大量几何一致的 4D 变体；
- **具身导航规划**：场景流预测直接服务移动机器人/无人机的轨迹规划；
- **sim-to-real 桥梁**：4D 潜在接口可作为仿真与真实策略之间的通用中间语言。

### Q3: 主要创新点和局限性是什么？

**问题**: 基于前面的分析，这个方法的主要创新点和局限性是什么？

**分析**:

#### 1. 主要创新点

1. **几何接地运动 token 作为世界-动作接口**：首次把"点图 + 场景流"的联合潜在量定义为世界模型与动作策略的中间接口，兼顾接地性与可生成性；
2. **单图条件 4D 未来生成**：从一张自我中心图 + 文本生成时间对齐的三模态未来，输入极简；
3. **模态路由 LoRA + 非对称注意力**：优雅解决"在预训练视频骨干上增加几何模态不遗忘"的工程问题；
4. **两阶段 FlowInverse**：以最小动作标注成本闭合"想象 → 控制"回路。

#### 2. 主要局限性

1. **几何伪标签的上限**：MotionCrafter 的几何/运动估计本身有误差，监督噪声会内化到模型中；接触密集的操作场景（形变、遮挡严重）伪标签质量最差，而那里恰恰最需要精确几何；
2. **单目自我中心视角**：遮挡区域与物体背面没有信息来源，4D 想象在这些区域本质上是脑补，长程预测误差会累积；
3. **预演 ≠ 物理保证**：生成式 4D 未来是"看起来合理"而非"物理必然"，缺乏显式物理约束（力、摩擦、稳定性），精细操作（插孔、系绳）可能想象成功实际失败；
4. **FlowInverse 的策略上限**：轻量逆动力学网络的表达能力有限，复杂多步任务可能需要更强的策略头。

#### 3. 与其他相关工作的对比

- **vs zSight（11-20）**：zSight 统一 VLA 与潜在世界建模但以抽象潜在空间降低成本；Ego4Gen 坚持显式几何潜变量（点图/流），接口更重但更接地、可解释。两者代表"潜在接口轻量化 vs 几何化"的路线分歧。
- **vs ViewDreamer（11-19）**：ViewDreamer 解决多相机视角自由的视频世界模型；Ego4Gen 固定自我中心视角但输出显式 4D。前者重视角泛化，后者重几何接口。
- **vs ResWAM（同期）**：ResWAM 学"什么变了"（残差）；Ego4Gen 学完整的几何+运动。残差思路更高效，完整 4D 更通用。
- **vs 传统 Motion Planning**：传统方法用显式状态估计 + 物理模型规划，精度有保证但泛化差；Ego4Gen 用学习到的生成动力学，泛化好但精度无保证。

## 核心技术发现

- 发现1：几何接地的运动 token（点图+场景流联合潜在量）在 OOD 场景优于抽象潜在动作与视频潜在基线。
- 发现2：模态路由 LoRA 能在预训练视频世界模型上增加几何模态而不破坏原能力。
- 发现3：两阶段 FlowInverse 能以极少动作标注把 4D 想象翻译为有效机器人控制。

## 与Spatial AGI的关系

### 直接贡献

定义并验证了 Spatial AGI 中"想象-行动接口"的一种具体形态：几何接地的 4D 潜在量。这是连接世界模型与具身控制的关键接口标准候选。

### 技术启发

- 生成式 4D（而非重建式 4D）是空间智能中更可扩展的路线——它兼容互联网视频数据的规模；
- 几何监督可以伪标签化、自动化，不必依赖 3D 传感器；
- 接口设计比模型规模更重要：接口决定了世界模型的想象能否被控制系统消费。

### 应用场景

操作前预演验证、遥操作数据增广、导航轨迹预演、仿真数据引擎、少样本新任务学习。

## 个人思考

### 最令人兴奋的发现

"几何接地运动 token 在 OOD 下优于视频潜在量"这一结果，实质上回答了 11-21 那篇 "World Models Favor Learned Priors over Visual Evidence" 的质疑：当你强迫世界模型的想象以显式几何为载体时，模型的"语义先验脑补"就被几何结构约束住了，泛化随之改善。**接口的几何接地是对抗先验作弊的可操作手段**——这是本篇对世界模型可靠性争论的直接贡献。

### 潜在局限

生成式 4D 的"物理性"问题。想象出来的场景流在统计上合理，但可能违反物理守恒或接触力学。长期看需要在生成过程中注入物理约束（可微物理引擎、守恒损失），或者像 MoRE（今日第3篇）那样按物理 regime 分专家建模。纯统计的 4D 想象永远只能到"合理"，到不了"必然"。

### 与本周期研究的关联

- 与 11-20 zSight、11-23 CoT-WAM、11-21 Point Dynamics 构成"潜在世界-动作接口"系列的最新节点：接口从抽象 latent（zSight）→ plan latent（CoT-WAM）→ 点动力学（Point Dynamics）→ 几何运动 token（本篇），越来越几何化；
- 与 StereoVLM（今日第1篇）形成感知-想象闭环：几何接地的现在（视差）+ 几何接地的未来（场景流）= 完整的时空几何链。

- 骨干：Cosmos3-Nano（预训练视频世界模型）

- 适配方法：模态路由 LoRA + 非对称注意力

## 总结

### 核心发现总结

Ego4Gen 证明了从单张自我中心图像联合生成几何一致的 4D 未来（外观+结构+运动）是可行的，且其几何运动潜在量可以直接经轻量逆动力学翻译为机器人动作，为"世界模型 → 具身控制"提供了接地且可泛化的接口。

### 对Spatial AGI的意义

Spatial AGI 的核心循环是"感知 → 想象 → 行动"，Ego4Gen 打通了想象与行动之间的接口，并证明这个接口可以被几何接地。它标志着世界模型研究从"生成漂亮的未来视频"进入"生成可控制的未来几何"的阶段。

## 深度展开：为什么世界-动作接口是本周的关键词

### 接口问题的历史脉络

机器人世界模型两年来的演化可以概括为接口的持续升级：

1. **像素接口**（2024-2025）：世界模型生成未来视频，策略从视频帧提取信息。问题：像素→控制的翻译需要额外感知模块，误差链长；
2. **抽象潜在接口**（2025-2026）：DINO/SigLIP 式语义潜变量作为世界状态。问题：语义潜变量丢失几何细节，无法支撑精确操作；
3. **几何潜在接口**（2026，本周）：点动力学（Point Dynamics, 11-21）、几何运动 token（Ego4Gen, 本篇）、控制中心时空推理（LaST1.0, 11-18）——接口本身携带 3D 结构与运动，可直接消费为控制信号。

Ego4Gen 处于第 3 阶段的前沿。它的"运动 token"本质上是把场景流的稀疏化/分词版本，既有几何保证（可解码回 3D），又足够紧凑（可被 transformer 策略消费）。这个双重身份——几何的潜力 + 潜在的效率——正是"接口"设计的精髓。

### 时间对齐三模态的技术难点

联合生成 RGB + 点图 + 场景流并保持时间对齐，难点在于三个模态的一致性约束：

- **外观-结构对齐**：点图的每一点必须落在对应 RGB 帧的语义位置上；
- **结构-运动对齐**：场景流向量必须把 t 帧点图的点映射到 t+1 帧点图的对应点（即流是点图的传输场）；
- **时间因果性**：三点演化必须满足连续性，不能跳变。

非对称注意力的设计暗示作者选择了"外观主导、几何锚定"的生成顺序：RGB 帧由预训练骨干生成（能力最强），点图与流以 RGB 为条件路由生成（锚定结构）。这个设计的隐忧是：几何可能过度跟随外观的"语义合理性"而非"物理必然性"——这正是第 3 部分要批判的物理性问题。

### MotionCrafter 伪标签的信任边界

伪标签管线的信任边界应该按场景类型划分：

| 场景类型 | 伪标签可靠度 | 原因 |
|----------|------------|------|
| 刚性大物体、显著纹理 | 高 | 立体/时序对应清晰 |
| 小物体、远距离 | 中 | 深度分辨率不足 |
| 透明/反光物体 | 低 | 对应失败 |
| 接触瞬间、形变过程 | 低 | 快速运动模糊 + 拓扑变化 |
| 遮挡边界 | 低 | 半遮挡歧义 |

操作任务的关键时刻（抓取接触、插入对位）恰恰落在低可靠区。缓解方案：接触区用触觉数据校准伪标签、或按可靠度加权训练损失——但摘要未提及，这是复现时的自由度也是风险点。

### FlowInverse 两阶段的信息流解读

两阶段设计的信息流是精心分层的：

- **阶段一（无动作视频）**：学的是"世界会怎么变"的统计——潜变量 ↔ 视觉变化的双射。这一步的泛化性来自海量视频的多样性；
- **阶段二（少量动作数据）**：学的是"我的身体如何引起这些变化"——潜变量 ↔ 关节空间的映射。这一步只需要机器人自身的运动学知识，数据需求小。

这实际上是把世界模型与本体表示解耦了：想象（阶段一）与具身（阶段二）通过潜变量桥接。这个结构对新机器人形态特别友好——换一具身体只需重训阶段二，世界模型与潜变量空间可以完全复用。这是"身体无关的想象能力"的工程雏形。

## 深度展开：OOD 泛化结果的深层含义

### 为什么几何潜在量 OOD 更强

对比三类接口在 OOD 下的行为：

- **视频潜在量**：编码了外观纹理与光照风格，这些是域相关的，换域即失效；
- **抽象动作潜在量**：编码了动作-外观的联合统计，同样域敏感；
- **几何运动 token**：编码的是"什么东西在 3D 中如何移动"，运动模式（推、抓、倒）是跨域不变的任务本质。

几何接地在这里的作用等价于领域泛化中的"不变特征学习"：把表示空间约束在因果不变量（3D 运动）上，剥离域相关变量（外观风格）。这再次呼应了 StereoVLM 的视差监督发现——**把监督/表示落在不变量坐标空间，是空间智能泛化的通用配方**。

### 闭环策略评估的隐含信息

摘要报告闭环评估"展示了 4D 潜在量翻译为控制的有效性"但未给具体数字。合理的推断：

- 闭环成功依赖滚动生成的误差不爆炸：单步想象误差 × T 步累积；
- 几何接口的优势在闭环中应更明显（几何误差可被下一帧观测校正，语义漂移则不可校正）；
- 预演-校正循环（MPC 式）可能是推荐的部署形态，而非开环执行整段想象动作。

## 深度展开：与物理约束路线的张力

### 统计想象 vs 物理必然

Ego4Gen 的 4D 未来是条件采样的产物，其"正确性"是统计意义的：与训练分布中的相似场景一致。失败模式举例：

1. **推倒的多米诺**：想象可能停在"手接触骨牌"而无后续连锁——训练视频里连锁后续稀少；
2. **倒水**：流体细节最难伪标签化，想象的水流可能"凝固"或穿透容器；
3. **软体形变**：布料/绳结的形变统计最复杂，MotionCrafter 类方法在此最弱。

对比路线：MoRE（本日第3篇）用物理 regime 专家显式建模刚体/可形变/抓取动力学，物理归纳偏置更强但需要仿真数据训练。两条路线的融合方向清晰可预见：**生成式骨架 + 物理 expert 路由**——Ego4Gen 的模态路由 LoRA 结构天然可以扩展为物理路由（每个 expert 对应一种物理 regime 的 LoRA）。

### 数据引擎的正循环可能

Ego4Gen 反过来可以成为数据引擎：用它的 4D 想象生成大量候选场景，用真实机器人执行子样本并对比想象与现实，现实-想象偏差（imagination gap）既是模型改进信号，也是"哪些场景统计想象不可靠"的探测器。这个"想象-执行-校准"闭环是 Spatial AGI 自我改进的雏形，与 Embodied-Harness（11-20 搜索结果中的递归自我改进）理念呼应。

1. **物理路由扩展**：把模态路由 LoRA 扩展为物理 regime 路由，融合 MoRE 思想，让生成骨架按场景动力学类型激活不同物理专家；

## 深度展开：批判性审视

### 单图条件的现实边界

单张自我中心图像丢失了大量决策关键信息：

- 物体质量/摩擦/刚度（决定力的效果）；
- 遮挡区域内容（决定抓取可行性）；
- 容器内部状态（决定倾倒结果）。

文本提示可以部分补偿（"倒满杯子的水"），但大量物理属性无法语言化。务实判断：Ego4Gen 更适合作为**短程预演器**（几秒内、接触前）而非全程规划器。接触后阶段应交由 MoRE 类物理模型或真实闭环控制接管。

### 与本周 StereoVLM 的互补验证

StereoVLM 的干预实验证明感知需要几何接地；Ego4Gen 的 OOD 结果证明想象需要几何接地。两篇独立论文在感知端与预测端得出同一结论——几何接地是空间智能可靠性的必要条件。这种跨论文一致性提升了结论的可信度，也预示"几何接地"将成为 2027 年 Spatial AGI 的设计共识。

## 深度展开：系统架构推演

### 完整推理管线的时间与算力预算

假设部署形态为"每 N 步重新想象"的滚动预演：

```
感知采样 (StereoVLM 式)          ~50ms
4D 未来生成 (Cosmos3-Nano, T步)   ~200-500ms (单步采样)
FlowInverse 动作翻译              ~10ms
动作执行 N 步                     ~N×50-100ms
```

生成式 4D 预演的算力成本显著高于前馈策略，因此现实部署大概率是"低成本前馈策略 + 高成本想象纠偏"的双系统：正常情况走策略，遇到不确定性（检测到 OOD 或低置信度）触发想象预演。这与 CauSyncVLA（11-19）的异步双系统设计在思想上一致——快系统执行、慢系统想象。

### 运动 token 的可能形式化

虽然论文未公开 token 化细节，合理推测的方案：

1. **体素化分词**：把场景流投影到 3D 体素网格，每体素一个运动向量，量化为 token 词表；
2. **锚点采样**：选取稀疏锚点（类似 3DGS anchor），编码局部流场；
3. **潜变量直通**：直接把生成骨干的中间 patch 潜变量视为运动 token，FlowInverse 消费原始潜变量。

方案 3 最省事但牺牲显式性；方案 1/2 保持可解码性。FlowInverse 名字中的"Flow"暗示其输入与场景流直接相关，倾向方案 1/2。

### 训练数据配方推测

- 视频预训练（继承 Cosmos3）：互联网视频 + 机器人视频混合；
- 几何适配（MotionCrafter 伪标签）：需要带深度/相机位姿估计的动态视频子集；
- 动作对齐（阶段二）：少规模遥操作数据（估计数百-数千轨迹量级）。

这个配方的要点是三层数据的规模比可能达到 10^6 : 10^4 : 10^2，动作标注数据被压缩到金字塔尖——这是对机器人数据稀缺问题的结构性回应。

## 深度展开：对 Spatial AGI 分层架构的意义

### 想象层的标准化候选

把 Spatial AGI 分层为感知层/想象层/行动层，本篇贡献在想象层：

- **感知层**（StereoVLM, CoSphere-SLAM）：建立当前状态的空间表示；
- **想象层**（Ego4Gen, MoRE, Pros4D）：从状态表示出发模拟未来；
- **行动层**（FlowInverse, WEVO, CauSyncVLA）：把想象筛选出的方案翻译为控制。

Ego4Gen 提出的接口可以成为想象层与行动层之间的**标准化协议**：任何想象模型只要输出几何接地的运动 token，任何行动策略只要消费这种 token，模块即可互换。这种协议化思维——而不是端到端一体化——可能是 Spatial AGI 工程化落地的关键路径，正如 HTTP 之于互联网。

### 与评估层的接口

SpatialScout-V2（今日第4篇）式的评估可以扩展到想象层评估：不只评估"模型对现在的理解"（IoU 定位），还评估"模型对未来的想象"——想象 4D 与真实 4D 的几何/运动误差（可用点图/流一致性指标）。一个统一的"空间能力协议"应该在感知、想象、行动三层各有可测指标，本篇的输出形式（可解码的三模态）天然可测。

## 深度展开：失败案例推演库

构建可预见的失败案例分类，供后续研究对照：

**F1 语义合理但物理不可能**
- 现象：想象中物体穿模、悬浮、违反守恒；
- 根因：统计生成无物理约束；
- 检测：物理校验器（穿透检测、能量守恒检查）；
- 缓解：MoRE 式物理专家路由。

**F2 接触时刻想象崩坏**
- 现象：抓取/插入瞬间几何与运动估计发散；
- 根因：伪标签在此类时刻最不可靠；
- 检测：接触预测器 + 该时段想象置信度降权；
- 缓解：触觉条件化、真实闭环接管。

**F3 遮挡区域幻觉**
- 现象：物体背面/被遮挡区域想象出不存在的内容；
- 根因：单目视角信息缺失；
- 检测：可见性掩码，只在可见区域评估想象；
- 缓解：多视角观测条件（结合主动探索，SpatialScout-V2 思想）。

**F4 长时程漂移**
- 现象：滚动想象超过 5-10 步后场景退化；
- 根因：误差累积 + 训练时序长度限制；
- 检测：滚动重生成的一致性度量；
- 缓解：关键帧锚定、世界状态记忆（MomentMem 思想）。

**F5 语言-几何错位**
- 现象：文本指令未正确改变想象走向（如"轻轻放"却生成快速放下）；
- 根因：语言条件对几何模态的影响通路弱（非对称注意力可能削弱了它）；
- 检测：指令消融测试；
- 缓解：语言-运动对齐的偏好优化。

## 深度展开：给研究者的实践建议

1. **复现优先级**：先验证 FlowInverse 两阶段的有效性（最便宜、最反直觉的环节），再考虑 4D 生成的完整复现；
2. **伪标签质检管线**：MotionCrafter 输出需要配套可靠度评估（光度一致性、时序一致性过滤），不要盲信；
3. **消融必做项**：几何 token vs 抽象 token 的 OOD 对比是本篇核心主张，任何衍生工作都应保留此消融；
4. **部署形态**：按双系统（快策略+慢想象）设计，想象作为纠偏资源而非每步必经路径；
5. **评估协议**：采用三层评估（感知 IoU / 想象几何误差 / 闭环成功率），对齐 SpatialScout-V2 + 本篇的评估接口。
