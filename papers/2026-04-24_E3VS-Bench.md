# E3VS-Bench: A Benchmark for Viewpoint-Dependent Active Perception in 3D Gaussian Splatting Scenes

**ArXiv:** 2604.17969 | **Date:** 2026-04-20 | **Authors:** Koya Sakamoto, Taiki Miyanishi, Daichi Azuma, Shuhei Kurita, Shu Morikuni, Naoya Chiba, Motoaki Kawanabe, Yusuke Iwasawa, Yutaka Matsuo (UTokyo, NII, Osaka Univ, ATR)

**Tags:** #ActivePerception #3DGaussianSplatting #Benchmark #EmbodiedQA #SpatialIntelligence #VLM

## 一句话总结

E3VS-Bench 是一个基于 3DGS 的具身 3D 视觉搜索基准，要求 Agent 在 5-DoF 视角控制下主动探索 99 个高保真场景来回答 2014 个视角依赖问题，揭示了当前 VLM 在主动感知和视角规划方面与人类的巨大差距。

## 核心贡献

1. **新任务定义：Embodied 3D Visual Search (E3VS)** — 超越传统 EQA 的 2D 平面导航，要求 Agent 在 5-DoF（xyz + yaw/pitch）空间中主动控制视角获取任务相关证据
2. **高质量基准构建：** 99 个 3DGS 场景 + 2014 个 episode，利用 3DGS 的照片级真实感保留 mesh 无法呈现的细粒度视觉信息（文字、品牌标志）
3. **严格过滤流水线：** 通过 VLM-as-Judge 框架过滤掉可从先验知识或初始视角回答的问题，确保真正需要主动探索
4. **六类问题分类：** Object Search (OS), Object State (OST), Object Attribute (OA), Context-Guided Search (CGS), Spatial Reasoning (SR), Counting (CNT)

## 方法细节

### 场景构建
- 基于 SceneSplat++ (ScanNet++ 场景的 3DGS 重建)
- 3DGS 相比 mesh 保留关键视觉细节（小文字、微妙属性），这对视角依赖推理至关重要

### Episode 定义
- 每个 episode = (scene, question, initial_viewpoint)
- 初始视角对准目标物体但可能被遮挡
- Agent 每步收到 512×512 egocentric RGB，选择离散动作（平移 0.25m / 旋转 30°）
- 最多 25 步

### 数据生成流水线
1. 场景选择 → 2. VLM 生成 QA → 3. 人工过滤无效 QA → 4. 标注可回答视角 → 5. 过滤无需探索的 episode
- 使用 GPT-5.1 做可回答性过滤（blind + start view 都能回答的去除）
- 人工标注约 1120 小时

### 评估
- **正确性：** VLM-as-Judge (GPT-5.1)，1-5 分，与人类评估 Spearman ρ=0.54
- **效率：** 平均步数
- **安全性：** 碰撞率

### 关键发现
- **VQA at Goal ≈ 3.58 (Gemini)**，VQA at Start ≈ 2.14 → 初始视角远远不够
- **Birdview 效果最差 (~1.5)**，证明俯视图无法替代视角探索
- **SR 任务中 Gemini 3.0 Pro 的 E3VS 得分 ≈ VQA at Goal**，说明空间推理的视角控制能力在进步
- **CNT 最难**：需要跨 5-DoF 轨迹累积证据，所有模型接近 random
- OA 高度视角敏感：需要主动探索物体发现信息在哪
- 更多帧 → 更少步数、更少碰撞，但不显著提高得分
- Thinking 对 GPT-5.1 有帮助，对 Gemini 3.0 Flash 影响不大

## 与空间智能的关系

**直接核心相关。** E3VS-Bench 测试的是空间智能的核心能力：
1. **视角规划：** 理解从哪个角度能看到什么信息
2. **遮挡推理：** 知道需要移动来绕过遮挡
3. **空间关系推理：** 理解物体的三维空间布局
4. **主动探索：** 有目的地选择信息增益最大的视角

这个 benchmark 精准地测量了 VLM 从"被动看图"到"主动探索3D空间"的能力差距。

## 启发与思考

1. **3DGS > Mesh for embodied benchmark：** 传统 mesh 重建丢失的纹理细节恰恰是视角依赖推理的关键，3DGS 开辟了新的 benchmark 构建范式
2. **5-DoF vs 2-DoF 的质变：** 传统 EQA 只有平面导航，5-DoF 带来了真正的 3D 理解需求，move_up 是最频繁动作说明垂直维度的信息至关重要
3. **人类 vs 模型差距巨大：** 即使最好的模型在 CNT 上也接近 random，说明 VLM 的 3D 计数能力极弱
4. **思考未必有用：** thinking 对不同模型效果不一致，说明当前 thinking 可能不是在做空间推理
5. **Benchmark 设计的可借鉴性：** VLM-as-Judge + 严格过滤流水线是高质量 embodied benchmark 的标准范式

## 局限性

- 仅室内场景（ScanNet++）
- 问题主要面向小物体属性识别，缺少大尺度空间导航
- 使用离散动作空间而非连续控制
- 依赖特定 VLM (GPT-5.1) 做过滤，可能引入偏差
