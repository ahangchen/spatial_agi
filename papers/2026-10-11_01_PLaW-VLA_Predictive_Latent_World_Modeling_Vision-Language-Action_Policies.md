## 0. 一句话总结

PLaW-VLA 在预训练的预测导向表征空间（V-JEPA 2 latent space）中预测任务相关的未来状态，并通过结构化因果注意力将预测的未来潜变量直接条件化动作生成，从而以约 1/19 的推理延迟达到与生成式世界-动作模型相当的性能。

## 核心问题

### Q1: 核心算法原理是什么？

**问题**: 这篇文章的核心算法原理是什么？请详细描述：核心思想和动机、主要技术方法、算法流程和关键步骤、输入输出。

**分析**:

#### 1. 核心思想和动机

长时程（long-horizon）机器人操作要求 VLA 模型不仅理解当前场景，还要跟踪任务在连续交互中的演化。在部分可观测性和执行扰动下，仅靠当前观测不足以推断底层任务状态。因此有效的长时程控制需要：

- 从观测历史建模时间上下文（temporal context）
- 预判未来状态演化，为动作生成提供"预测性上下文"（predictive context）

现有将预测能力引入 VLA 的方法存在一个关键问题：**预测目标是什么、以及如何用预测结果条件化动作生成**。主流方法（视觉重建/生成式世界模型）要求模型同时预测任务动态和外观变化，而后者往往与控制无关。这带来两个代价：

1. **预测负担加重**：模型必须花费容量去建模控制无关的视觉细节（纹理、光照、背景）；
2. **误差传播**：当预测的未来直接条件化策略时，外观预测的误差会污染动作生成。

PLaW-VLA 的核心洞察是：**在预训练的预测导向表征空间（V-JEPA 2）中预测任务相关的未来潜状态，跳过低层视觉重建**。这样：

- 预测目标天然聚焦于状态转移和交互动态（V-JEPA 2 的训练目标就是预测性表征学习）
- 预测维度大幅压缩，使轻量级潜世界模型 + 并行未来预测成为可能

#### 2. 主要技术方法：三专家 Mixture-of-Transformers 架构

PLaW-VLA 将 VLA 生成分解为三个因果有序的组件，其联合分布被分解为：

```
p_θ(a_≥t, ẑ_>t, φ_t | o_≤t, c) = p_φ(φ_t | o_t, c) · p_z(ẑ_>t | o_≤t, φ_t) · p_a(a_≥t | φ_t, z_{t-Ho:t}, ẑ_>t)
                                     └── VLM ──┘   └────── LWM ──────┘   └──────── Action Model ────────┘
```

三个专家（expert）：

**(a) Vision-Language Expert（语义接地）**
- 基于 PaliGemma 实例化
- 输入：多视角观测 o_t + 语言指令 c
- 输出：上下文嵌入 φ_t（任务相关的语义表征），为下游潜预测和动作生成提供接地的语义上下文

**(b) Latent World Model Expert（预测潜建模）**
- 观测历史 o_{t-Ho:t} 经冻结的预训练编码器 E（V-JEPA 2）映射为潜状态 z_{t-Ho:t}
- 引入 K 个可学习的未来查询（future queries）s_{1:K}，每个查询对应一个未来预测步
- 未来查询同时关注历史潜轨迹和 VLM 语义嵌入 φ_t，通过预测器 F_z 联合预测未来潜状态：

```
z_{t-Ho:t} = E(o_{t-Ho:t})
ẑ_{t+1:t+K} = F_z(s_{1:K}, z_{t-Ho:t}, φ_t)
```

关键点：**未来预测是并行的**（所有 K 步一次性预测），而非自回归滚动，这直接带来推理延迟的大幅下降。

**(c) Action Expert（连续动作生成）**
- 以 φ_t、历史潜变量 z_{t-Ho:t}、预测未来潜变量 ẑ_>t 为条件
- 解码时间上延展的连续动作序列（action chunks）
- 采用 π0 风格的 flow-matching 目标

**(d) 结构化因果跨专家注意力（Causal Cross-Expert Attention）**

三个专家之间的信息流由结构化因果注意力调节：
- 信息流向：语义接地 → 潜预测 → 动作解码
- 防止未来信息泄漏（future leakage）
- 减少跨专家干扰（cross-expert interference）
- 使用 Mixture-of-Transformers：各专家有独立参数，通过注意力机制选择性交互

#### 3. 训练目标

**潜预测目标（LWM）**：

```
L_wm(D) = E_{(o_{t-Ho:t+K}, c) ~ D} [ (1/K) Σ_{i=1}^{K} ||ẑ_{t+i} - sg(z_{t+i})||² ]
```

- 预测的未来潜状态与冻结 V-JEPA 2 编码器从未来真实观测提取的目标潜状态对齐
- 目标潜变量施加 stop-gradient（sg），避免预测器训练破坏编码器表征结构

**动作生成目标（Flow Matching）**：

```
L_FM(D) = E [ ||π_θ(φ_t, z_{t-Ho:t}, ẑ_{t+1:t+K}, a^τ_{t:t+Ha-1}, τ) - (ε - a_{t:t+Ha-1})||² ]
```

- 遵循 π0，对连续动作块使用 flow-matching
- 插值样本 a^τ = τε + (1-τ)a，τ ~ Beta(1.5, 1)

**联合训练与预测分支随机丢弃**：

```
L_joint = L_FM(D; C_m) + m·λ_wm·L_wm(D)
C_m = (z_{t-Ho:t}, ẑ_{t+1:t+K})  if m=1, else ∅
m ~ Bernoulli(1-α)
```

这是一个非常巧妙的设计：每个 batch 以概率 α 随机丢弃预测分支。作用：

1. **防止过依赖**：避免动作专家对预测上下文过度依赖，保证在预测质量差时策略仍然鲁棒
2. **保留无预测回退能力**：m=0 时策略退化为普通 VLA，仍正常优化
3. 类似 classifier-free guidance 的训练技巧在 VLA 预测建模中的迁移应用

#### 4. 三阶段视频到机器人训练流水线

- **Stage I**：在无动作标注的人/机器人视频上预训练潜世界模型，学习在冻结编码器表征空间中预测视觉动态（规模化利用通用视频数据）
- **Stage II**：引入动作标注的机器人轨迹，联合优化未来状态预测与动作生成，将预测动态与动作相关行为对齐
- **Stage III**：在目标任务和机器人本体上做任务/本体自适应

这一范式使大规模视频中学到的预测知识可复用于机器人策略学习，提供从通用视觉动态到任务特定控制的可扩展路径。

#### 5. 输入输出

- **输入**：多视角图像序列历史 o_{t-Ho:t}、语言指令 c
- **中间**：语义嵌入 φ_t、历史潜状态 z、预测未来潜状态 ẑ_{t+1:t+K}
- **输出**：连续动作块 a_{t:t+Ha-1}（末端执行器/关节控制序列）

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**分析**:

#### 1. 如何理解和表示空间

PLaW-VLA 对空间的表示采取了一种"功能主义"立场：

- 空间不是像素级的几何重建，而是**在预测性潜空间中的状态演化轨迹**
- V-JEPA 2 表征空间经过大规模视频的自监督预测训练，已隐式编码了物体持久性、运动学、空间接触等结构化空间知识
- 任务语义 φ_t 与空间潜状态的结合意味着：空间表征是"任务条件化"的——同一个房间，对"倒水"和"叠衣服"任务而言，相关的空间结构不同

这与 Spatial AGI 的核心问题直接相关：**空间理解不需要显式几何才是空间理解**。潜空间预测器可以视为一种隐式的空间-动态模型（implicit spatial-dynamic model）。

#### 2. 如何处理空间关系

- **时间维度的空间关系**：通过观测历史潜轨迹 z_{t-Ho:t} 编码空间状态的时间演化，物体位置关系的变化被压缩进潜序列
- **未来空间的想象**：K 个未来查询本质上是"空间想象"（spatial imagination）——在不执行动作的情况下推演世界将如何演化
- **语义-空间绑定**：结构化注意力强制语义先经过接地再进入预测，保证空间预测是"关于任务所指对象"的预测

#### 3. 对 Spatial AGI 的启发

1. **预测导向表征 > 重建导向表征**：Spatial AGI 的世界模型或许同样应放弃像素级重建的执念，在 JEPA 式预测空间中做空间推演。这与 LeCun 的世界模型路线一脉相承，本文给出了在 VLA 控制环路上的实证支持
2. **空间想象的效率**：1/19 推理延迟说明潜空间空间推演可以做到实时化，这对需要"在脑内模拟多个候选动作后果"的 Spatial AGI 架构至关重要——只有潜空间想象足够快，基于想象做规划才可行
3. **预测上下文作为动作条件**：Spatial AGI 的行动模块可以显式消费"预期的未来空间状态"，形成 感知→想象→行动 的闭环，而非 感知→行动 的反射弧
4. **随机丢弃预测分支**：Spatial AGI 系统在空间预测不可靠时应优雅退化到反应式策略，这种鲁棒性设计值得借鉴
5. **视频预训练 → 机器人控制的迁移路径**：Stage I 无动作视频预训练表明空间动态知识可以从被动观看中获得，这是 Spatial AGI 数据规模化的重要依据

#### 4. 可以应用的 Spatial AGI 场景

- **家庭机器人长时程任务**：多步骤家务（收拾厨房），需要跟踪任务进度并预测干预后果
- **可变形物体操作**：项目主页提到包括可变形物体任务，绳子/布料的潜空间动态预测
- **空间问答与规划结合**：潜未来状态可解码为空间关系的预测（"如果我把杯子推下去，它会落在哪里"）
- **驾驶/导航**：同类架构可预测交通参与者未来状态作为规划条件
- **人机协作**：预测人类动作的未来潜状态，实现预判式协作

### Q3: 主要创新点和局限性是什么？

**分析**:

#### 1. 主要创新点

1. **预测目标空间的选择**：首个在冻结 V-JEPA 2 表征空间中做未来预测、并直接条件化动作生成的 VLA。与 FLARE（辅助监督）、VLA-JEPA（潜动作表征）、JEPA-VLA（特征融合）形成清晰的谱系差异——PLaW-VLA 是"预测的未来直接作为策略条件"
2. **三专家 MoT + 结构化因果注意力**：将 VLM / 世界模型 / 动作模型解耦又耦合，信息流因果化，避免未来泄漏与专家干扰
3. **并行未来预测**：K 步未来一次性预测，避开自回归世界模型的开销
4. **预测分支随机丢弃（predictive dropout）**：训练技巧层面防止策略过依赖预测，兼顾鲁棒性
5. **效率-性能权衡的实证**：约 1/19 生成式世界-动作模型的推理延迟、相当的性能，说明"潜空间预测"路线在工程上是可行的

#### 2. 主要局限性

1. **潜空间的可解释性缺失**：预测的 ẑ 无法直接转化为几何/空间关系陈述，难以做符号化空间推理或安全验证
2. **依赖 V-JEPA 2 表征质量**：编码器冻结意味着预测空间的表达上限受限于 V-JEPA 2 的训练分布；对极端域外场景（强反射、透明物体、流体）表征可能失真
3. **潜预测误差仍会传播**：虽然避免了外观误差，但动态预测误差依然直接进入动作条件，长时程误差累积未充分讨论
4. **预测视野 K 固定**：任务时长差异大时，固定步数预测的适用性存疑
5. **仿真为主 + 部分真机**：LIBERO/RoboTwin 是仿真基准，真机泛化性的证据相对有限

#### 3. 与相关工作的对比

| 方法 | 预测目标 | 与策略关系 | 相对劣势 |
|------|---------|-----------|---------|
| 生成式世界-动作模型（Motus等） | 未来视频/图像 | 联合生成 | 延迟高、预测外观负担重 |
| FLARE | 未来观测嵌入 | 辅助监督 | 预测不直接条件化动作 |
| VLA-JEPA | 未来 V-JEPA 特征 | 潜动作表征 | 非显式未来状态条件 |
| JEPA-VLA | V-JEPA 视觉特征 | 特征融合进 VLA | 无未来预测 |
| **PLaW-VLA** | **未来 V-JEPA 潜状态** | **直接条件化动作生成** | 可解释性弱 |

**优势**：在"预测什么"（预测导向潜空间）和"如何用"（直接条件化）两个维度上都做了正确选择，实验上同时改善长时程性能（RoboTwin Hard +11.8pp）和分布偏移泛化（LIBERO-Plus zero-shot +1.77pp）。
**劣势**：相比显式3D世界模型（如3DGS世界模型），缺乏几何可编辑性和空间查询能力；相比端到端生成模型，缺少生成细腻未来场景用于人工审查的能力。

## 核心技术发现

- **发现1**：在预测导向表征空间中预测未来，可绕过控制无关的视觉细节建模，预测负担大幅降低
- **发现2**：结构化因果跨专家注意力可以在统一架构内安全地组合 VLM、世界模型和动作模型，无需共享全部参数
- **发现3**：预测分支随机丢弃（α 调节）是防止策略过依赖预测上下文的有效正则化手段
- **发现4**：并行潜未来预测 + flow-matching 动作解码的组合，使世界模型增强的 VLA 首次达到接近实时推理的延迟水平
- **发现5**：无动作视频预训练（Stage I）到机器人控制（Stage II）的迁移有效，验证了通用视频作为空间动态知识来源的价值

## 与 Spatial AGI 的关系

### 直接贡献
提供了一个实证样例：VLA 可以通过内嵌的潜空间世界模型获得"空间想象能力"，且想象的成本足够低（1/19 延迟）可以嵌入实时控制回路。

### 技术启发
- Spatial AGI 的"心理模拟"模块不必是生成式的——JEPA 式潜空间推演在效率和任务相关性上更优
- 语义接地（φ_t）与空间预测的分离-协作架构，可作为 Spatial AGI 分层架构中"概念层"与"空间动态层"的交互范式

### 应用场景
长时程家庭操作、可变形物体操作、预判式人机协作、空间想象驱动的规划与问答。

## 个人思考

### 最令人兴奋的发现

最令人兴奋的是**效率数字**：约 1/19 的推理延迟意味着"每一步动作前先在脑内模拟未来"不再是奢侈品。如果每步控制只需数十毫秒的潜空间推演，那么基于想象的模型预测控制（imagination-based MPC）在通用机器人上就变得现实。这可能是从"反应式 VLA"到"思考式 VLA"的转折点之一。

另一个细节——预测分支随机丢弃——看似小技巧，实则回答了一个深刻问题：**智能体应该多信任自己的想象？** 答案是：训练时保持怀疑（随机忽略想象），推理时充分利用。这种"信任校准"思想对 Spatial AGI 的元认知设计很有启发。

### 潜在局限

潜空间的黑盒性是最大的隐忧。Spatial AGI 若要被部署在人类环境中，其"想象"需要可审计——当机器人预演了一个危险的未来却没有执行，我们需要知道它想象了什么。纯潜向量难以满足这一点。未来方向或许是：潜空间预测 + 轻量级潜→几何/语言解码器做监控。

此外，V-JEPA 2 表征空间是"别人家的空间"。真正的 Spatial AGI 或许需要自组织演化自己的空间表征，而不是永久冻结在某个通用视频编码器上。

### 与昨日研究的关联

昨天精读的 DreamTrue（Action-Faithful Robot World Model with Counterfactual Post-Training）从"反事实后训练"角度提升世界模型的动作忠实性，强调世界模型必须真实反映动作后果；今天 PLaW-VLA 则从"预测什么空间"（预测导向潜空间 vs 像素空间）和"怎么用预测"（条件化动作）角度切入。两者共同指向一个趋势：**世界模型正在从"视频生成器"转变为"策略的内嵌预测器官"**——评价标准从视觉保真度转向控制有用性（action-faithfulness、task-relevance、latency）。结合昨天 Slot3R 的集合关联空间记忆与今天论文2（Spatial Memory Intelligence）的主题，本周文献强烈暗示 Spatial AGI 的世界模型设计正在沿"记忆-预测-行动"三轴分化与整合。

## 关键数据

- **架构**: PaliGemma VLM expert + MoT 三专家 + 冻结 V-JEPA 2 编码器 + flow-matching 动作专家
- **训练**: 三阶段（视频预训练 → 机器人轨迹联合训练 → 任务/本体自适应），预测分支丢弃概率 α
- **LIBERO**: 平均成功率 97.4%（超过 π0.5 骨干 +0.5pp），LIBERO-Long 提升最明显
- **LIBERO-Plus (zero-shot)**: 任务加权成功率 72.7%，比重建导向潜预测高 +1.77pp
- **RoboTwin Hard Horizon III**: 比反应式策略（π0.5）+11.8pp
- **推理延迟**: 约 1/19 生成式世界-动作建模延迟

## 总结

### 核心发现总结
PLaW-VLA 证明了"预测什么"与"如何用预测"是世界模型增强 VLA 的两个正交设计轴，并在两个轴上都给出了优雅答案：在预测导向潜空间预测任务相关未来、以结构化因果注意力直接条件化动作。结果是长时程性能、分布偏移泛化和推理效率的三赢。

### 对 Spatial AGI 的意义
这篇论文为 Spatial AGI 的"空间想象"模块提供了一张可实现的工程蓝图：空间想象不必生成像素，只需在正确选择的表征空间中并行推演任务相关演化；想象结果通过注意力机制流入行动模块；并且智能体应当被训练得对自身想象保持适度怀疑。感知—想象—行动闭环的每一环都开始有了可复用的组件设计。

## 扩展分析：逐模块深度拆解

### A. 问题形式化的深层含义

PLaW-VLA 的分布分解不是简单的架构描述，而是一种关于"控制中什么信息是必要的"的理论立场：

```
p(a, ẑ, φ | o, c) = p(φ | o, c) × p(ẑ | o, φ) × p(a | φ, z_hist, ẑ)
```

逐项解读：

1. `p(φ | o_t, c)` —— **语义接地只看当前观测**。作者认为任务语义是瞬时可判定的，无需历史。这隐含假设当前帧足够判断"在做什么任务"。
2. `p(ẑ | o_≤t, φ)` —— **未来预测需要完整历史 + 任务语义**。状态演化是历史的函数，且"演化什么"由任务决定。这是全架构信息密度最高的一步。
3. `p(a | φ, z_hist, ẑ)` —— **动作同时消费语义、历史动态和未来想象**。动作是三路信息的汇聚点。

这种分解的政治学意味在于：世界模型被显式地置于感知与行动之间的"缓冲带"，成为策略的中间推理层。对比端到端 VLA（感知直接映射到动作），这是从 System 1 到 System 1.5 的演进——还没有完整的规划循环，但已经有了"预演"。

### B. V-JEPA 2 表征空间为什么是正确的预测目标？

选择预测目标空间的三个准则（从本文可以提炼）：

1. **预测性（predictive）**：该空间本身是为"预测未来特征"训练的，其几何结构天然对齐状态转移，而非对齐像素统计。V-JEPA 2 用自回归特征预测目标训练，空间中相近 = 动态上相似。
2. **任务可控过滤性**：预测器以 φ_t 为条件，可以从潜状态中"读出"任务相关分量。V-JEPA 2 表征较抽象，恰好滤除了纹理级别的控制无关细节。
3. **可获取性**：目标潜变量只需对真实未来帧做一次前向编码（训练时），推理时完全不需要解码——预测监督信号便宜。

对比：若以像素为预测目标，模型必须解一个病态问题——未来像素受光照、遮挡、相机抖动等大量与动作无关的随机性影响；潜空间预测把这些 nuisance 交给了编码器去抽象掉。

### C. 结构化因果注意力的信息流分析

用 token 类型重述注意力掩码设计（P=上下文, H=历史潜, F=未来查询, A=动作查询）：

- P（VLM 输出）→ 可被 H、F、A 注意：语义是全局上下文
- H → 可被 F、A 注意：历史动态流向预测和动作
- F（预测的未来）→ 只可被 A 注意：未来不能泄漏回历史/语义（否则会退化成用"答案"拟合"问题"）
- A → 不向任何其他组提供 key/value：动作是终点

这实质上是一个 DAG 上的注意力分解。工程意义：三专家可以部分并行——VLM 编码和 LWM 历史编码可并行，只有预测→动作是串行的。这解释了低延迟的来源之一。

### D. 训练三阶段的知识流

Stage I（视频预训练）：
- 数据：无动作标注的人/机器人视频
- 学到：视觉动态的先验（物体如何移动、手如何影响物体）
- 关键：只有 L_wm 激活，动作专家闲置。世界模型从"旁观者视角"学习因果动态

Stage II（机器人轨迹联合训练）：
- 数据：动作标注的机器人演示
- 学到：预测动态与动作后果的对齐；动作专家从预测上下文中提取控制信息
- 关键：预测分支随机丢弃在这里发挥作用——策略学会在"有想象"与"无想象"两种模式间鲁棒切换

Stage III（任务/本体自适应）：
- 小数据微调到具体任务与机器人
- 相当于把"通用的想象能力"落到"具体的身体"上

这条路线与 LLM 的预训练-微调范式同构，暗示机器人学习正在复制大模型的数据规模化剧本，只是"下一 token 预测"换成了"下一潜状态预测"。

### E. 实验结果的细读

1. **LIBERO 平均 97.4%**：绝对值已近饱和，+0.5pp 的意义在于说明加入世界模型不损害常规性能（无负迁移）。
2. **LIBERO-Long 提升最明显**：长时程正是预测上下文应有的用武之地——任务进度需要历史+未来推演来跟踪。结果与设计动机自洽。
3. **LIBERO-Plus zero-shot 72.7%（+1.77pp）**：分布偏移下的泛化提升说明预测的潜未来提供了超越当前帧的"世界观"，帮助策略抵御扰动。幅度虽小但方向一致。
4. **RoboTwin Hard Horizon III +11.8pp**：这是最亮眼数字。Hard + 长视野是最需要预测的组合，验证了核心假设。
5. **1/19 延迟**：对比对象是生成式世界-动作模型（视频生成类）。若对比自回归潜世界模型，差距会缩小，但并行预测依然占优。

### F. 方法谱系定位图

```
预测目标空间轴:
  像素/视频 ←————————————→ 抽象潜表征
  [生成式WM, Motus]      [PLaW-VLA, VLA-JEPA]

预测与策略的耦合轴:
  仅辅助监督 ←——————————→ 直接条件化动作

```

PLaW-VLA 在三个轴上都选了"右端"，是一篇立场鲜明的论文——它押注抽象、深度耦合、并行，并用实验为这一组合辩护。

### 符号表

| 符号 | 含义 |
|------|------|
| c | 语言指令 |
| o_{t-Ho:t} | 观测历史（多视角图像序列） |
| φ_t | VLM 输出的任务语义表征 |
| z_{t-Ho:t} | 由冻结编码器 E 提取的历史潜状态 |
| ẑ_{t+1:t+K} | LWM 预测的 K 步未来潜状态 |
| s_{1:K} | K 个可学习未来查询 |
| F_z | 潜世界模型预测器 |

| τ | flow-matching 插值系数 ~ Beta(1.5,1) |
| α | 预测分支丢弃率 |
| λ_wm | 潜预测损失权重 |
| sg(·) | stop-gradient |
| m ~ Bernoulli(1-α) | 预测分支使用指示子 |

### 公式索引

1. **联合分解（Eq.1）**: p(a, ẑ, φ | o, c) = p_φ(φ|o,c) · p_z(ẑ|o,φ) · p_a(a|φ, z, ẑ)
2. **潜预测（Eq.2）**: ẑ_{t+1:t+K} = F_z(s_{1:K}, z_{t-Ho:t}, φ_t)
3. **L_wm（Eq.3）**: 预测潜与 V-JEPA 2 目标潜的 MSE，stop-gradient 目标
4. **L_FM（Eq.4）**: flow matching 向量场回归，条件含 φ、z、ẑ
5. **L_joint（Eq.5）**: L_FM + m·λ_wm·L_wm，分支随机丢弃

### 训练-推理不对称性

- 训练时：目标潜来自真实未来帧的编码（teacher forcing 式监督）
- 推理时：预测潜完全由模型自产，无任何未来信息；动作专家消费的是"纯想象"
- 这种不对称是所有世界模型的核心张力：训练分布中预测误差有界，推理时误差自累积。本文通过并行（非滚动）预测规避了自累积问题——代价是只能想象固定 K 步，无法做超长时程推演。

## 附录 K：批判性问题的自问自答

**Q: 并行预测 K 步是否假设了未来与历史之间的马尔可夫性？**
A: 是的，隐式地。F_z 是从 (历史, 语义) 到 K 步未来的一次性映射，不做中间状态滚动。对短视野动态足够，但分支化未来（不同动作导致不同未来）无法表达——它预测的是"当前行为模式延续下的未来"，而非条件于候选动作的未来。这是它与传统 MPC 世界模型的本质区别：想象是被动观测性的，不是干预性的（observational vs interventional）。若要支持"如果我这样做会怎样"，需要把候选动作编码进查询——这是明确的后续工作空间。

**Q: 随机丢弃会不会让 LWM 训练不充分？**
A: L_wm 在 m=1 时才激活，有效训练量打折。但 Stage I 全量预训练弥补了这一点——丢弃只在 Stage II/III 联合阶段引入。设计上是自洽的。

**Q: 为什么用 MSE 而不是 V-JEPA 官方的损失形式（如平滑L1/对比）？**
A: 冻结目标空间下 MSE 足够且稳定；V-JEPA 原始训练的 EMA-target/掩码技巧在这里不需要，因为这是监督回归而非自监督。

**Q: 该方法对观测频率敏感吗？**
A: K 步未来对应固定的物理时间跨度取决于数据帧率。跨本体/跨帧率部署时，潜时间尺度需要重校准，文中未深入讨论。
