# VGGRPO: World-Consistent Video Generation with 4D Latent Reward

**arXiv**: 2603.26599  
**Date**: 2026-03-27  
**Category**: Video Generation / Geometry  
**Tags**: #VideoGeneration #WorldConsistency #GRPO #4D

---

## TL;DR

VGGRPO 提出了一种**潜在空间几何引导**的视频后训练框架，通过构建 Latent Geometry Model (LGM) 直接从扩散潜变量提取 4D 几何，避免 RGB 解码开销，使用两种互补奖励（相机运动平滑度 + 几何重投影一致性）实现世界一致性视频生成。

---

## 核心问题

大规模视频扩散模型的视觉质量惊艳，但**几何一致性差**：
- 几何漂移
- 相机轨迹不稳定
- 场景结构不一致

### 现有方法的局限

| 范式 | 方法 | 问题 |
|------|------|------|
| **架构扩展** | 添加几何模块 | 破坏预训练泛化能力 |
| **RGB对齐** | Epipolar-DPO | 需重复VAE解码，仅限静态场景 |

---

## 核心创新

### 1. Latent Geometry Model (LGM)

**目标**：从潜在空间直接提取几何，避免 RGB 解码

```
视频潜变量 z → Stitching Layer → 几何基础模型后层 → 几何预测
                    (Sψ)
```

**构造方式**：
$$\hat{\Phi}_\psi = \Phi_{\hat{\ell}+1:L} \circ S_\psi$$

其中 $\Phi$ 是预训练几何模型（如 VGGT、Any4D），$S_\psi$ 是学习到的连接层。

**对齐训练**：
$$\mathcal{L}_{align} = \sum_j \lambda_j \|\hat{\Phi}_{\psi,j}(\mathcal{E}(x)) - \Phi_j(x)\|_1$$

### 2. 潜空间 GRPO

**Group Relative Policy Optimization** 在潜空间执行：

$$\mathcal{J}_{GRPO}(\theta) = \frac{1}{K}\sum_{k=1}^K \frac{1}{T}\sum_{t=0}^{T-1} [\min(\rho_t^k A^k, clip_\varepsilon(\rho_t^k) A^k) - \beta D_{KL}]$$

**关键**：无需 RGB 解码，奖励直接从潜变量计算

### 3. 两种几何奖励

#### 相机运动平滑度奖励

$$e_{trans}(z_0) = \frac{1}{T-2}\sum_{i=2}^{T-1} \frac{\|a_i\|_2}{\|v_i\|_2 + \|v_{i-1}\|_2}$$

- $v_i = c_{i+1} - c_i$（速度）
- $a_i = v_i - v_{i-1}$（加速度）
- 平滑轨迹 → $e_{trans} \approx 0$

同理定义**旋转平滑度** $e_{rot}$

#### 几何重投影一致性奖励

$$e_{reproj}(z_0) = \frac{1}{N_{pairs}}\sum_{(i,j)} \|\pi_j(P_i^{(j)}) - p_j^{(i)}\|_2$$

- $P_i^{(j)}$：第 $i$ 帧点云投影到第 $j$ 帧
- $\pi_j$：投影函数
- **跨视角几何一致性**

**总奖励**：
$$r = w_1(1 - e_{trans}) + w_2(1 - e_{rot}) + w_3(1 - e_{reproj})$$

## 技术细节

### 支持 4D 动态场景

当 LGM 使用 Any4D 等 4D 几何模型时：
$$\{C_i, D_i, P_i, F_i\}_{i=1}^N = \hat{\Phi}_\psi(z)$$

- $F_i$：场景流（scene flow）
- 分离静态/动态组件

### 训练流程

```
1. 构造 LGM（stitching layer 训练）
2. GRPO 采样：K 个视频样本/提示
3. LGM 提取几何 → 计算奖励
4. 策略更新（潜空间，无 RGB 解码）
5. 重复 2-4
```

## 实验

### Benchmark

| 方法 | Static | Dynamic | 整体质量 |
|------|--------|---------|----------|
| Baseline | 0.72 | 0.68 | 0.70 |
| Epipolar-DPO | 0.81 | 0.70 | 0.75 |
| **VGGRPO** | **0.89** | **0.82** | **0.85** |

### 效率对比

| 方法 | 训练时间/epoch | GPU 内存 |
|------|----------------|----------|
| RGB-based | 8h | 80GB |
| **VGGRPO** | **2.5h** | **40GB** |

**节省 3x 训练时间**，无需 RGB 解码
