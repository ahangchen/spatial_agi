## 0. 一句话总结

用 3DGS 重建真实机器人工作区，在机器人坐标系内合成"腕相机视角 + 平滑到达轨迹"的大规模 VLA 训练数据，
避免完整数字孪生和物理仿真，使 π0.5 仅用腕相机图像就达到 80% 精确到达成功率，
远超 150 条遥操作示范的 58.7%，而人工采集时间少于 10 分钟。

## 核心问题

### Q1: 核心算法原理是什么？

**问题**: 这篇文章的核心算法原理是什么？请详细描述：1) 核心思想和动机，2) 主要技术方法，3) 算法流程和关键步骤，4) 输入输出。

**分析**:

#### 1. 核心思想和动机

- **痛点一：VLA 数据瓶颈**。VLA 模型（RT-2、OpenVLA、π0、π0.5 等）的效果强依赖大规模、
  高质量、视觉-语言-状态-动作四者对齐的示范数据。真实机器人数据主要靠遥操作采集：
  慢、贵、噪声大（操作员会走错再修正，策略会把"误操作+修正"一起学进去），
  且相机采集与动作执行之间的延迟造成 observation-action 错位，
  这对"精确到达（pre-contact precise reaching）"是致命的。
- **痛点二：数字孪生难建**。电子废品拆解（e-waste disassembly）场景里主板元件
  细小、反光、机械结构复杂，物体级 mesh 重建、材质建模、接触仿真都极难，
  完整数字孪生成本高且 sim-to-real gap 大。
- **痛点三：相机配置**。外部固定相机需要稳定放置和标定；腕相机（wrist camera）
  视角随末端执行器移动，不依赖外部布置，但视野窄、持续变化，策略需要
  更多样的对齐数据才能学会可靠修正——数据需求反而更大。
- **核心思想**：只做"接触前到达"这一段，用 3DGS 作为免 mesh 的照片级工作区
  表征，在机器人坐标系下采样可行起始位姿、渲染腕相机观测、配对平滑到达
  轨迹，直接生成 VLA 微调数据；再配一个指令条件的到达验证器（reach verifier）
  决定何时停止并移交下游抓取控制器。
- **关键洞察**：接触前阶段不需要物理仿真（没有接触、没有动力学），
  需要的只是"真实感的腕相机观测 + 机器人可执行的动作标签"。
  3DGS 恰好提供前者，机器人运动学恰好提供后者。

#### 2. 主要技术方法

整体是三阶段 real-to-sim-to-real 流水线：

1. **真实场景重建（Real-Scene Reconstruction）**
   - 腕相机 + 手眼标定（hand–eye calibration）建立相机系与末端执行器系的
     度量关系：T_CB^(i) = T_EB^(i) · T_CE。
   - 用深度平面校验（point-to-plane 残差 e_i = |n·x_i + d| / ||n||）验证标定的
     垂直方向精度，因为精确到达对法向/进近方向误差最敏感。
   - 用腕相机视频重建 3DGS 场景，保留线缆、密集元件、反光件和杂乱背景，
     完全不需要物体级 mesh 和接触模型。论文用对比实验说明：
     同一采集下 mesh 渲染有明显几何/外观伪影，直接污染策略输入；
     3DGS 能沿新机器人轨迹合成几何一致的新视角观测。
   - 录制少量朝向目标的短到达视频，提取目标附近的 key poses。

2. **机器人对齐的 3DGS 数据生成（Robot-Aligned Data Generation）**
   - **机器人系场景对齐**：3DGS 场景初始在 SfM 坐标系，用 SfM 相机中心与
     机器人运动学相机中心的对应点，加权求解相似变换
     min Σ w_i ||sR·c_i^G + t − c_i^B||²，权重偏向目标附近的 anchor 帧，
     提高交互区域局部对齐精度。
   - **可行起始位姿采样**：候选位姿须同时满足：位置在安全工作区 Ω_safe 内、
     IK 残差 < ε_max、关节在限位内、操作度
     m(q) = sqrt(det(J_p J_pᵀ)) > m_min（远离奇异位形）。
     这保证生成的观测-动作对物理可执行，而不只是视觉上合理。
   - **轨迹渲染与动作标注**：从采样起点 → 预接近位姿 → 目标 key pose，
     用 cubic smoothstep h(u)=3u²−2u³ 做时间插值（端点零速度，避免分段
     跳变）；每个中间末端位姿转成腕相机位姿从对齐后的 3DGS 渲染；
     同一条轨迹按不同策略后端转换动作表示——关节空间策略（π0.5/OpenPI）
     用 a_q = q_{t+1} − q_t（经 IK），位姿空间策略（OpenVLA-OFT）用
     相对末端运动 a_x = ρ((T_E,t^B)⁻¹ T_E,t+1^B)。
   - 数据生成 worker 并行加载同一 3DGS 场景，每个进程 <1GB 显存；
     故意不做任何 domain randomization——多样性全部来自采样的机器人位姿
     及其视角一致的轨迹。

3. **策略学习与部署**
   - 行为克隆：min_θ Σ L_BC(π_θ(I_t, ℓ, s_t), a_t)，
     样本 = (腕相机图像 I_t, 目标指令 ℓ, 机器人状态 s_t, 动作 a_t)。
   - 部署安全：预测动作缩放并裁剪
     q_cmd = clip(q + clip(α·Δq̂, ±δ_max), q⁻, q⁺)。
   - **粗到细 action chunking**：随 rollout 推进逐步缩短每 query 执行的
     chunk 长度（H_{k+1} ≤ H_k）——开头快、接近目标时视觉反馈更频繁。

4. **指令条件到达验证器（Instruction-Conditioned Reach Verifier）**
   - 独立于 VLA 骨干单独训练，输入 (I_t, ℓ, s_t)，输出到目标的笛卡尔
     距离估计 d̂_t = V(I_t, ℓ, s_t)，Smooth-L1 回归监督。
   - 结构：视觉/指令/状态三个编码器；指令通过两种机制调制视觉特征：
     FiLM（语言相关的特征调制）+ 语言引导的空间注意力（强调指令相关图像区域）。
   - **状态掩码**：训练时以 0.5 概率把状态编码置零，防止策略走捷径
     （固定工作台下"末端高度≈接近程度"是虚假相关），换取对状态偏差的鲁棒性。
   - 部署：d̂_t < 0.65cm 记为高置信到达，需连续 3 次高置信预测才终止
     （抗瞬态误报），可选几何检查后把控制权交给下游抓取模块。

5. **下游抓取执行**
   - 验证器确认后，直接用当前末端位姿作为抓取位姿（无额外物体位姿估计），
     平行爪以 70N 力闭合，执行固定的 lift–transfer–place 序列
     （五阶时间缩放 + 四元数插值 + 关节阻抗控制）。
   - 下游控制器全实验固定不变，用来客观验证 VLA+verifier 产出的交互位姿
     是否"抓取就绪（manipulation-ready）"。

#### 3. 算法流程和关键步骤

```
[阶段一：采集与标定]
  腕相机扫描工作区 → 手眼标定 → 深度平面校验
  → 录目标 key pose 短视频
        ↓
[阶段二：3DGS 重建与对齐]
  3DGS 重建 → SfM 系→机器人系加权相似变换对齐（目标帧高权重）
        ↓
[阶段三：数据生成]
  循环：
    采样候选起始位姿 → 安全区/IK/限位/操作度四重过滤
    → smoothstep 平滑轨迹（起点→预接近→key pose）
    → 逐帧渲染腕相机视图 + 生成动作标签（关节空间或位姿空间）
        ↓
[阶段四：VLA 微调]
  行为克隆微调 π0.5 / OpenVLA-OFT
        ↓
[阶段五：闭环部署]
  腕相机闭环推理（动作缩放裁剪 + 粗到细 chunking）
  → reach verifier 判停（<0.65cm 连续3次）
  → 固定抓取控制器完成 lift-transfer-place
```

#### 4. 输入输出

- **数据生成阶段输入**：腕相机扫描视频、手眼标定结果、少量目标 key poses、
  目标任务指令、期望数据规模。
- **数据生成阶段输出**：N 条（腕相机图像序列 + 语言指令 + 机器人状态 +
  平滑到达动作）的 VLA 训练样本。
- **部署阶段输入**：实时腕相机图像 + 目标指令。
- **部署阶段输出**：连续到达动作流 + 停止信号（交互位姿），交接给下游抓取。

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**分析**:

#### 1. 如何理解和表示空间

- 论文的空间表示是"**双坐标系统一**"：3DGS 场景（SfM 视觉空间）与机器人
  基座系（运动学度量空间）通过加权相似变换精确对齐。这本质上是把
  **感知空间**和**行动空间**绑到同一度量框架——Spatial AGI 的一个基本命题：
  智能体对空间的内部表征必须能直接映射到可执行的物理动作。
- 3DGS 在这里被定位为"观测模型"而非"几何模型"：它的价值不在几何精度，
  而在能沿任意新视角合成视觉上可信的观测。这提示 Spatial AGI 的空间
  表示应该是**可渲染、可查询视角的生成式表征**，而不是静态 mesh。
- 加权对齐（目标附近 anchor 帧高权重）体现"任务相关区域精度优先"的
  空间表示思想：均匀精度的空间表征既不必要也不经济，交互区域局部
  精度才是关键。

#### 2. 如何处理空间关系

- **各向异性容差**：螺丝（进近方向高精度）、GPU（薄、需对准爪开口、
  纵向容差大）、RAM（长轴容差大、宽度方向严）。verifier 和任务设计
  都显式利用目标相关几何语义。Spatial AGI 需要理解"空间精度需求随
  交互语义变化"这一点，而不是用统一阈值。
- **空间到动作的映射链**：视觉观测 → 语言指定目标 → 空间定位 →
  运动学可行轨迹 → 反馈修正。语言在此不是描述空间，而是**选择空间
  中的注意力区域和精度准则**（FiLM + 空间注意力）。
- **从无上下文恢复**：初始腕相机完全看不到主板时，策略仍能靠探索性
  运动让工作区进入视野再定位（1500 条数据下 17/30 粗到达、8/30 精确
  到达）。这是"主动感知"式空间行为的雏形。

#### 3. 对 Spatial AGI 的启发

- **数据引擎范式**：Spatial AGI 的训练需要海量"视角-动作对齐"的空间
  经验。本文证明：一个真实场景的 3DGS 表征 + 运动学可行性过滤 +
  平滑轨迹生成，就能把 <10 分钟的人工采集放大成 1500 条结构化示范。
  这套"重建-对齐-采样-渲染"数据引擎可推广到任何具身空间任务。
- **表示的功能性**：不需要完整的物理数字孪生，只需覆盖策略实际需要的
  观测分布。Spatial AGI 的世界表征也应该是"按需保真"：交互区域高保真、
  背景低保真。
- **语言作为空间调制器**：verifier 的消融显示去掉指令条件后，状态
  扰动下停机精度从 48.1% 掉到 22.8%——语言条件不仅提供语义，还
  在状态不可靠时提供冗余的空间线索。这对多模态空间智能的架构设计
  （语言-视觉-本体感知三路冗余）有直接指导意义。
- **防捷径设计**：状态掩码暴露了具身学习中的普遍陷阱——模型倾向利用
  本体感知捷径而非真实空间理解。Spatial AGI 训练需要系统性的
  反捷径机制（输入掩码、扰动评测）。

#### 4. 可以应用的 Spatial AGI 场景

- **通用机器人技能数据工厂**：把"到达"换成插孔、拧动、按压等参数化
  技能，同一流水线批量生成多技能 VLA 数据。
- **空间接地基准构建**：在 3DGS 场景中程序化生成"指令→空间位姿→
  正/负样本"，可构建带精确几何真值的空间推理评测集。
- **Sim-free 策略评估**：渲染 + 几何对齐可离线评估策略在目标区域
  附近的位姿分布，作为真机测试前的筛选器。
- **人形/多臂平台**：只要能标定末端-相机关系并对齐 3DGS，即可跨
  具身形态复用（延续昨天 CL4D"跨具身 4D 预训练"的思路）。

### Q3: 主要创新点和局限性是什么？

**分析**:

#### 1. 主要创新点

1. **免 mesh、免物理仿真的 3DGS 数据引擎**：与 SplatSim（需物理仿真）、
   RoboGSim（需 mesh 数字孪生）、Real2Render2Real（需物体扫描 mesh）相比，
   唯一同时做到无物理仿真、无物体 mesh、无 GPU 仿真器依赖的方案
   （论文 Table I）。 SETUP 成本大幅降低。
2. **机器人对齐的视图合成**：不是自由视角渲染，而是每个合成视角都
   来自标定机器人系中的可行末端位姿，保证"视觉合理 ⇔ 物理可执行"。
3. **指令条件到达验证器 + 状态掩码**：把"何时停"从策略中解耦为独立
   可靠模块，并系统性处理了本体感知捷径问题（消融非常漂亮：无掩码
   时干净输入 MAE 0.44cm 更好，但高度偏置 2cm 后精度直接归零）。
4. **粗到细 action chunking**：利用 chunk 长度单调递减实现先快后准，
   简单且可迁移到其他 VLA 部署。
5. **实证结果有力**：1500 条生成轨迹（<10 分钟人工）→ π0.5 三目标平均
   精确到达 80.0%，显著超过 150 条遥操作（90-200 分钟人工）的 58.7%，
   且遥操作基线还多用了侧视图相机。

#### 2. 主要局限性

1. **静态场景假设**：真实部署时主板被物理挪动后性能靠"中等场景变化"
   兜底，但场景大幅变化（新物体、遮挡）无法处理；3DGS 无法更新。
2. **只覆盖接触前**：接触后的操作交给固定控制器，接触密集、可变形
   物体、需要力反馈的阶段完全不适用本流水线。
3. **单视角窄视野**：腕相机无全局上下文，无上下文起步时精确到达
   只有 8/30；可以考虑外部粗定位 + 腕相机精修的层次方案。
4. **起始数据规模敏感**：300 条轨迹在 π0.5 上几乎全部失败
   （螺丝精确到达 0/25），到 900 条才起飞，说明生成数据仍需相当规模，
   "少样本"优势是相对遥操作而言。
5. **无碰撞感知规划**：轨迹生成刻意不用 RRT 等规划器，只靠 smoothstep
   插值，密集场景中轨迹可能与障碍干涉（GPU 目标靠近目标时腕旋转
   偶发碰撞）。
6. **单一工作台单一机器人**：只在 Franka FR3 + 主板拆解验证，
   跨场景/跨具身泛化未验证。

#### 3. 与其他相关工作的对比

| 方法 | 3DGS | 物理仿真 | 物体mesh | GPU仿真器 | 定位 |
|---|---|---|---|---|---|
| SplatSim | ✓ | ✓ | × | ✓ | 全操作学习 |
| RoboGSim | ✓ | ✓ | ✓ | ✓ | Real2Sim2Real 仿真器+策略评估 |
| Real2Render2Real | ✓ | × | ✓ | ✓ | 物体扫描+单示范生成数据 |
| **PrecisionReach-GS** | ✓ | × | × | × | 腕相机 VLA 到达数据引擎 |

- 相比 X-SIM（人类视频重建仿真再蒸馏），本文不需要动作示范视频，
  动作标签纯由运动学生成，监督更干净。
- 相比传统视觉伺服（visual servoing），本文不需要检测目标特征和手工
  设计像空间控制律，直接学语言条件策略。
- 相比昨天分析的 DepthWorld（深度世界模型）和 Robot-Aligned 类工作，
  本文代表"轻量化数据引擎"路线：不追求世界模型的预测能力，
  只追求监督数据的规模与对齐质量。

## 核心技术发现

- 发现1：接触前到达阶段不需要物理仿真——3DGS 渲染 + 运动学标签即可
  产生超越遥操作的 VLA 微调效果（80.0% vs 58.7%）。
- 发现2：mesh 渲染的伪影会直接污染策略输入；3DGS 的外观保真对
  腕相机策略是功能性需求，不只是美观问题。
- 发现3：reach verifier 的状态掩码揭示精度-鲁棒性权衡：干净输入
  MAE 0.44→0.64cm 的代价换来状态偏置下 0%→48% 的存活率。
- 发现4：轨迹平滑度本身是有效的监督信号：smoothstep 换 linear timing
  使精确成功率 58.7%→50.7%。
- 发现5：生成数据规模存在相变：300 条完全失败、900 条可用、1500 条
  超越遥操作基线。

## 与Spatial AGI的关系

### 直接贡献

提供了一个可复制的"真实场景→空间对齐→大规模视觉-动作对齐数据"
引擎，是 Spatial AGI 数据基础设施的具体实例：把 3DGS 从"渲染工具"
升级为"具身空间经验的生成器"。

### 技术启发

- 空间表征按需保真（交互区高精度加权对齐）。
- 语言作为空间注意力与精度准则的调制器。
- 防捷径（状态掩码）应成为具身空间学习的标准配置。

### 应用场景

- 机器人技能数据工厂、空间接地基准、sim-free 策略预筛、
  多具身迁移预训练。

最有趣的是 **state masking 的消融结果**：不掩码状态，模型干净输入下
MAE 更低（0.44 vs 0.64cm），但末端高度偏 -2cm 后停机精度从 100% 崩到
0%。这几乎是"具身版 Goodhart 定律"的完美演示——当本体感知存在捷径时，
模型一定走捷径，且捷径在分布偏移下最脆弱。这也解释了为什么很多
VLA 工作室在真机评测和实验室评测之间性能差距巨大。对 Spatial AGI 的
启示：**评测必须包含主动的输入扰动**，否则测到的空间能力可能是
伪相关的记忆。

另一个亮点是数据规模的相变行为（300→900→1500）。生成数据的优势
不是"少而精"而是"多而对齐"：遥操作示范里混着修正噪声，每条的信息
密度低；生成轨迹干净且 observation-action 严格同步，规模化后监督
质量优势爆发。

### 潜在局限

- 静态 3DGS 是最大软肋。真实家庭/工业环境里物体天天动，每次重扫
  重建不现实。自然的下一步是把 3DGS 数据引擎与可更新的场景表征
  （昨天 SG²SLAM 类的在线 SLAM、或物体级场景图）结合：背景用
  静态 3DGS，交互物体用可插拔的物体高斯/mesh。
- 数据引擎只生成"成功示范"，没有失败恢复数据。策略的鲁棒性
  （尤其 no-context 恢复 8/30）天花板受限。可以在生成轨迹时故意
  注入扰动+恢复段，合成"扰动-恢复"课程。

### 与昨日研究的关联

- 昨天 (10-29) 精读的 **SG²SLAM** 提供在线几何一致的空间建图，
  可以作为本文静态 3DGS 的动态升级：SLAM 输出的 3DGS 地图替代
  一次性重建，使数据引擎适应场景变化。
- **SpatioLM**（10-29）讨论 VLM 的通用空间能力，本文则是 VLA 在
  精细空间动作上的落地——两者共同指向"空间理解→空间动作"的
  闭环，而 reach verifier 相当于给动作加了一个可验证的空间
  groundings。
- **Robot-Aligned** 的加权对齐思想与昨天 WorldSimProbe 对仿真器
  忠实度诊断的关切呼应：空间仿真/渲染不必全局忠实，但必须在与
  任务相关的局部度量上可验证。

## 关键数据

- 平台：Franka FR3 + 腕装 RealSense D435i；目标：Screw / GPU / RAM。
- 数据成本：150 条遥操作需 90-200 分钟人工；1500 条生成轨迹 <10 分钟
  人工采集，单 worker <1GB 显存，可并行。
- 主结果（π0.5，精确到达 /25 trials，主板被挪动后的新位置）：
  - Screw：Teleop150 12 → GS900 14 → GS1500 21
  - GPU：Teleop150 14 → GS900 14 → GS1500 19
  - RAM：Teleop150 18 → GS900 16 → GS1500 20
  - 平均：GS1500 = 80.0% vs Teleop150 = 58.7%（且 teleop 多一个侧相机）
- OpenVLA-OFT 同趋势但整体更低（GS1500 精确到达约 10-12/25）。
- 初始视角鲁棒性（GS1500，30 trials）：全上下文 29、有限上下文 27、
  无上下文粗 17 / 精 8。
- 控制实验：腕-only teleop 58.7→53.3%；linear timing 58.7→50.7%。
- 组件消融（900 条）：去 verifier 精确 58.7→45.3%；去 keyframe 加权
  粗 93.3→74.7%。
- Verifier：整体 MAE 0.64cm、近目标 MAE 0.10cm、停机精度 99.8%；
  状态偏置 -2cm：full 48.1% vs 无 state masking 0% vs 无指令条件 22.8%。
- 渲染保真：SSIM 0.682、Correlation 0.843、MSE similarity 0.979。

## 总结

### 核心发现总结

PrecisionReach-GS 证明了"3DGS 视觉真实感 + 机器人运动学精确性"的
组合可以在完全不需要物理仿真和物体 mesh 的情况下，为精细空间动作
（精确到达）生成超越人工遥操作质量的 VLA 训练数据。数据成本降低
一个数量级以上，配合指令条件验证器实现可靠部署。

### 对 Spatial AGI 的意义

这是 Spatial AGI 数据基础设施的重要拼图：空间智能的训练不一定要
依赖完整世界模型或物理仿真器，"感知表征（3DGS）× 行动空间（运动学）
的严格对齐"就能产生高价值空间经验。加上防捷径机制和对语言条件的
依赖，本文给出的工程模式（对齐、采样、渲染、验证、防捷径）可以
直接作为 Spatial AGI 数据引擎的参考架构。

### 数据生成细节补充

- **相似变换对齐的权重设计**：权重 w_i 不是均匀的，而是把目标组件附近的
  key frame anchor 权重调高。因为到达任务只关心目标交互区周围的局部
  度量精度，全场景均匀对齐会稀释交互区的精度预算。
- **操作度过滤的物理含义**：m(q) = sqrt(det(J_p J_pᵀ)) 度量末端在笛卡尔
  空间各方向的运动能力体积。接近奇异位形时某些方向修正需要极大关节
  速度，策略学到这种轨迹会在真机上震荡——所以奇异位形附近的生成数据
  必须剔除。
- **cubic smoothstep 的选择**：h(u)=3u²−2u³ 在 u=0,1 处一阶导为零，
  保证分段轨迹拼接处速度连续，避免 linear timing 的加速度突变。
  消融显示仅此一项就差 8 个点（58.7→50.7）。
- **动作表示双轨制**：同一轨迹同时可导出关节空间增量（π0.5/OpenPI 用
  IK）和相对位姿增量（OpenVLA-OFT 用 ρ 变换），数据引擎与策略后端解耦。
- **无 domain randomization 的勇气**：传统 sim-to-real 依赖外观随机化
  弥合 gap；本文因为渲染本来就来自真实捕获，外观 gap 天然小，
  多样性全部来自位姿采样——这是 3DGS 相比程序化仿真的根本优势。

### 部署细节补充

- 动作缩放 α 与最大关节增量 δ_max 双重裁剪，任何策略输出都无法导致
  超限运动。
- 粗到细 chunking（H_{k+1} ≤ H_k）：接近目标时每步视觉反馈占比提高，
  相当于控制频率随距离自适应增加——一种隐式的"距离-分辨率"耦合。
- 停机持久性规则（连续 3 次高置信）：单帧误报率 p 下连续 3 帧误报
  概率 p³，显著抑制过早停机；代价是轻微过冲风险，由几何检查兜底。
- 交接设计哲学：下游抓取控制器故意保持固定且非学习，使得所有实验
  中"精确到达成功"的定义客观可比——这是一个很好的实验卫生实践。

### 实验协议细节补充

- 评测时主板被**物理重新摆放**，与 3DGS 重建时的位置不同——测试
  中等场景变化而非固定位姿回放。这是比多数 sim2real 论文更诚实的协议。
- 指标定义：coarse reach（到达目标邻域）与 precise reach（到达后执行
  固定抓取-搬运成功才算）分离，后者直接绑定操纵可用性。
- 容差各向异性在协议中的体现：GPU/RAM 沿长轴允差较大（爪宽额外
  提供裕量），进近方向所有目标都严格。

## 关键公式索引

1. 手眼链式相机位姿：T_CB = T_EB · T_CE
2. 平面校验残差：e_i = |n·x_i + d| / ||n||
3. 加权相似变换对齐：min Σ w_i ||sR c_i^G + t − c_i^B||²，R∈SO(3), s>0
4. 操作度：m(q) = sqrt(det(J_p J_pᵀ))
5. Smoothstep 插值：h(u) = 3u² − 2u³
6. 关节动作：q_t = IK(T_E,t), a_q = q_{t+1} − q_t
7. 位姿动作：a_x = ρ((T_E,t)⁻¹ T_E,t+1)
8. 行为克隆：min_θ Σ L_BC(π_θ(I_t, ℓ, s_t), a_t)
9. 安全执行：q_cmd = clip(q + clip(αΔq̂, ±δ_max), q⁻, q⁺)
10. Chunk 单调递减：H_{k+1} ≤ H_k
11. 距离估计：d̂_t = V(I_t, ℓ, s_t)，Smooth-L1 监督
12. 停机条件：d̂_t < 0.65cm 连续 3 次
