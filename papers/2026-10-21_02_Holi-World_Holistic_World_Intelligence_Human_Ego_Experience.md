# Holi-World: Building Holistic World Intelligence from Human-Ego Experience

**发表日期**: 2026-10-19

---

## 一句话总结

Holi-World 提出一个从人类自我中心（ego）经验流自动构建"世界记录"的完整生态：用 Foundry 流水线把 ~100 个野外场景的立体 RGB+IMU 录像自动转化为持久 3D 物体 + 动态 4D 轨迹 + 约 8 万条有根据（grounded）QA，训练出 4B 的时空推理模型 HOLIWORLD-VL-4B（在自建 Bench 上 F1 78.02%，超过零样本 27B 模型），并以独立人工标注的 HOLIWORLD-Bench 形成双重验证闭环。

## 核心问题

### Q1: 这篇文章的核心算法原理是什么？

#### 1. 核心思想和动机

- **核心信念**：人类自我中心经验（egocentric experience）是学习"世界如何组织、如何因交互而变化"的丰富基础。
- **规模化障碍**：要把不断增长的录像变成学习资源，需要把**场景结构、物体语义、交互历史**跨视角、跨时间连接起来，同时**摆脱昂贵的人工标注**。
- **与相邻工作的差异**：
  - 与纯 3D 场景理解（ScanNet 类）：Holi-World 额外建模动态物体与其随时间的状态演化。
  - 与纯世界模型（视频预测）：Holi-World 不预测像素未来，而是构建**结构化、可追溯的世界状态**。
  - 与人类视频世界模型（同日的 Ropedia W0，同一团队）：W0 学"预测"，Holi-World 学"记录与理解"——两篇构成"经验 → 世界智能"生态的预测面与理解面。
- **生态化主张**：单一模型/数据集不够，需要连接"采集硬件 → 自动标注引擎 → 数据集 → 模型 → 独立评测"的五件套，并配两条验证回路（标注质量验证 + 学习效果验证）。

#### 2. 主要技术方法

**(a) 硬件层：Ego Capture Device**

- 立体 RGB + IMU 的自我中心采集设备，可在野外（in the wild）使用。
- 两种采集模式：
  - **Mapping walks（建图行走）**：走一圈记录房间结构。
  - **Interaction sessions（交互会话）**：记录手部操作过程。

**(b) Foundry 流水线：自动写"世界记录"**

四阶段：

1. **Shared prep（共享准备）**：
   - VI-SLAM 估计相机位姿
   - DA3 估计深度
   - 3DGS 重建高斯场景
   - VLM 提供语义线索，决定每个物体走静态还是动态分支
2. **Static perception（静态感知）→ 持久 3D 物体**：
   - 双目 2D 检测提升（lift）：示例房间左右目合计 1,684 个 box
   - 关联 + TR3D 合并：降到 30
   - 点支撑过滤（point-support filter）：降到 22
   - VLM 检查：✓17 正确 / ✎4 修正 / ✕1 删除 → 最终 **21 个静态 3D 物体**
   - 设计逻辑："两个检测器 + 一个 VLM 审查员"的多级收敛
3. **Dynamic perception（动态感知）→ 4D 物体轨迹**：
   - 交互 grounding → 身份关联 → SAM mask 跟踪 → 3D 反投影 → 每帧 OBB（定向包围盒）→ 4D 轨迹
   - 关键性质："**同一个杯子，即使离开视野也保持同一个 ID**"——身份持久性
4. **Unified world state（统一世界状态）**：
   - 输出统一坐标系下的：物体 ID、3D box、轨迹、支持证据（evidence，可溯源到具体帧）
   - 示例：一个办公室场景 = 880 个相机位姿 + 95 个静态物体 + A→B 运动轨迹

**(c) Holi-World-Data：四级有根据的监督**

| 层级 | 内容 | 规模 |
|------|------|------|
| 1 原始数据 | 场景 / ego 视频 | ~100 / 444 |
| 2 几何 | 3DGS 场景 / RGB 帧 / 深度图 / 相机位姿 | ~100 / 1,322K × 3 |
| 3 语义 | 2D box / 静态 3D box / 动态 4D 轨迹 | ~90K / 2,466 / 2,095 |
| 4 空间智能 | 3D grounding / caption / 静态 QA / 动态 QA | ~4K / ~80K / 13,647 / 64,409 |

- 共 **30 种 QA 类型**，覆盖静态建图、轨迹、caption，**包含难负例（hard negatives）**。
- 每条 QA 都能回溯到背后的物体、时间与帧（"every example links back"）——grounded 的本义。
- QA 示例：Q "What is behind the bed?" A "The curtain."（依据：静态 3D box + 相机位姿）

**(d) 模型：HOLIWORLD-VL-4B**

- 4B 参数的视觉-语言模型，在 Holi-World-Data 上训练。
- 任务：空间-时间推理（3D grounding、静态/动态 QA、数值问题）。

**(e) 评测：HOLIWORLD-Bench（独立人工标注）**

- 对 held-out 录像做独立人工标注。
- 双重用途：(1) 验证 Foundry 自动标注质量；(2) 评估学习到的空间/时间理解。
- 外部验证集：ScanNet、ScanNet++、Aria Digital Twin (ADT)、EgoDynamic4D。

#### 3. 算法流程和关键步骤

```
立体RGB+IMU ego录像（mapping walk / interaction session）
  → VI-SLAM 位姿 + DA3 深度 + 3DGS 场景 + VLM 语义路由
  → [静态分支] 双目2D检测 → TR3D关联合并 → 点支撑过滤 → VLM审查 → 持久3D物体
  → [动态分支] 交互grounding → ID关联 → SAM跟踪 → 3D反投影 → 每帧OBB → 4D轨迹
  → 统一世界状态（ID/box/轨迹/证据帧）
  → 30类QA模板自动生成（含难负例）
  → 训练 Holi-World-VL-4B
  → HOLIWORLD-Bench（独立人工标注）双回路验证
```

#### 4. 输入输出

- **Foundry 输入**：立体 RGB + IMU 的自我中心视频流。
- **Foundry 输出**：统一世界坐标系下的世界记录（持久 3D 物体、动态 4D 轨迹、语义、证据帧）。
- **Holi-World-VL-4B 输入**：ego 视频/多视角观测 + 问题（空间或时间性质）。
- **输出**：3D grounding 结果、QA 答案（开放/是否/选择/数值）。

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

#### 1. 如何理解和表示空间

- **空间 = 静态骨架 + 动态状态机**：
  - 静态物体构成空间的持久结构（"有什么、在哪里"）；
  - 动态物体携带随时间变化的状态（"什么在动、何时何地何状态"）。
- **表示选择**：显式 3D box（静态）+ 每帧 OBB 轨迹（动态）+ 3DGS 场景（连续外观），是一种**符号-几何混合**的世界状态，介于纯神经隐式与纯符号场景图之间。
- **可溯源设计**：每条语义/QA 都带证据帧，空间知识不是凭空的，而是锚定在观测上——这是对"空间幻觉"问题的工程化回答。

#### 2. 如何处理空间关系

- **跨视角统一**：所有物体统一到一个世界坐标系（VI-SLAM + 3DGS），跨视角、跨时间的物体身份一致性问题被显式解决（静态：多视角关联合并；动态：身份关联 + 跟踪）。
- **空间关系 QA 化**：把"什么在什么后面/旁边/里面"这类关系变成可自动生成、可验证的 QA 对（含难负例），空间关系从隐式感知变成可训练、可评测的能力项。
- **时间维度**：4D 轨迹 + 交互历史让"空间关系"扩展为"时空关系"——如"A 被移动到 B 处"这类动态事件。

#### 3. 对 Spatial AGI 的启发

1. **数据飞轮的自动化是空间智能的关键路径**：Foundry 证明可以不用人工标注，把 ego 视频流自动变成 8 万级 grounded QA——空间智能的数据瓶颈可以用"感知流水线 + VLM 审查"打开。
2. **理解面与预测面分开建**：同一团队（Ropedia）同时做了 W0（预测）与 Holi-World（理解），暗示空间智能需要"世界记录器 + 世界模拟器"双引擎：记录器提供结构化真相，模拟器在其上学习动力学。
3. **4B 有据训练胜过 27B 零样本**：F1 78.02% vs 43.67%（Qwen 27B 零样本）——空间推理能力主要来自**有根据的数据**而非模型规模，这是 Spatial AGI 的"数据 > 参数"证据。
4. **难负例的价值**：30 类 QA 中刻意加入难负例，直接对抗 VLM 的语言先验幻觉——空间智能训练必须包含"看起来对但错"的对照样本。
5. **双验证回路方法论**：自动标注的质量用人工 holdout 验证，模型能力用独立 bench 验证——空间智能系统的可信度需要这种审计式设计。

#### 4. 可以应用的 Spatial AGI 场景

- **家庭/办公机器人的持久世界模型**：机器人边走边构建并维护带 ID 的物体地图，跨天、跨视角保持一致。
- **具身 QA / 任务规划前置**：回答"杯子在哪""床后面是什么""遥控器被移到哪了"。
- **AR 助手**： ego 设备实时构建世界记录，支撑空间问答与物体记忆。
- **仿真场景资产自动生成**：Foundry 输出可直接作为仿真的场景初始状态（物体位姿 + 轨迹脚本）。
- **数据引擎授权**：Foundry 可以为其他空间智能模型批量生产训练数据。

### Q3: 基于前面的分析，这个方法的主要创新点和局限性是什么？

#### 1. 主要创新点

1. **端到端自动化的"世界记录"引擎**：从原始 ego 视频到 grounded QA 全程无人工标注，这在 4D 级别（静态 3D + 动态 4D + 语义 + 交互历史）是首个完整闭环。
2. **静态/动态双分支 + VLM 路由**：物体级地决定走持久 3D 分支还是 4D 轨迹分支，两级感知互补盲区。
3. **身份持久性**：物体离开视野后 ID 保持——解决 4D 理解中最实际也最易被忽视的问题。
4. **四级有据数据组织**：raw → geometry → semantics → spatial intelligence，每条监督可溯源到帧级证据。
5. **独立人工 Bench 双回路**：HOLIWORLD-Bench 同时审计标注质量与模型能力，方法论上的闭环设计。
6. **小模型逆袭**：4B 有据训练在自建 Bench（78.02 F1）与 EgoDynamic4D（66.39）上全面超过 27B 零样本。

#### 2. 主要局限性

1. **场景规模有限**：~100 个自采场景、444 条视频，QA 的多样性受模板与场景束缚，泛化到完全不同环境（户外、工业）未验证。
2. **静态感知在困难场景仍弱**：ScanNet++ AP25 仅 0.30、自建 Bench AP25 仅 0.24——绝对数值不高，杂乱/小物体场景的 3D 检测仍是瓶颈。
3. **依赖前置工具链质量**：VI-SLAM/DA3/3DGS/TR3D/SAM 任一环节退化都会级联污染世界记录；论文未系统分析误差传播。
4. **动态感知的交互假设**：动态分支依赖"交互 grounding"启动，未直接被交互的物体运动（如风吹、他人移动物体）可能漏检。
5. **QA 模板化**：自动生成的 30 类 QA 覆盖面可度量但语言多样性有限，可能带来模板过拟合。
6. **无动作条件预测**：世界状态是"记录"而非"模拟"，不能回答"如果我这样做会发生什么"——需与 W0 类预测模型互补。

#### 3. 与其他相关工作的对比

| 方法 | 类型 | 静态3D检测 | 动态4D跟踪 | QA数据 | 人工标注需求 |
|------|------|-----------|-----------|--------|--------------|
| SpatialLM / LLaVA-3D / SceneScript | 模型式结构输出 | 弱 | 无 | 无 | 高（训练标注） |
| Map-Det3D | 建图检测 | 中 | 无 | 无 | 中 |
| M3-Spatial / LangSplat | 3DGS 语言场 | 弱 | 无 | 无 | 中 |
| Boxer / Holi-Spatial | 空间流水线框架 | 中 | 弱 | 部分 | 中 |
| IT3DEgo / EgoSeg3D | ego 3D 跟踪 | — | 中（需GT初始化） | 无 | 高 |
| **Holi-World** | 全自动生态 | **0.68 AP25 (ScanNet)** | **54.31 HOTA (ADT)** | **~80K grounded** | **≈0** |

- **优势**：唯一同时做到"无人工标注 + 静态 SOTA + 动态 SOTA + grounded QA 数据 + 独立 Bench"的工作；基线在测试时还能拿 GT 帮助（GT 初始化/类别查询），Foundry 什么都不用仍然领先。
- **劣势**：场景规模与领域覆盖小于 ScanNet++ 级公共语料；无动作条件预测能力；模板化 QA 的天花板。

## 核心技术发现

- **发现 1**：多级收敛的静态感知（1,684 个 2D box → 关联合并 30 → 点支撑过滤 22 → VLM 审查 21）证明"多检测器 + VLM 审查员"比单一大模型更可靠。
- **发现 2**：ADT20 上 HOTA 54.31% vs 使用 GT 首帧初始化的 IT3DEgo 36.00%（+18.31）——纯自动 pipeline 打败用 GT 作弊的基线。
- **发现 3**：4B 有据训练模型 Token F1 78.02% vs Qwen 27B 零样本 43.67%（+61.67% 相对提升）；数值题 81.84% vs 66.13%。
- **发现 4**：ScanNet AP50 0.55 是最强基线 Map-Det3D（0.12）的 4.6 倍。
- **发现 5**：消融显示各模块互补盲区：image lift 管小物体、point cloud 管大范围、VLM 管正确标签、label continuity 管稳定 ID、SAM masks 管平滑轨迹。

## 与Spatial AGI的关系

### 直接贡献
- 给出空间智能数据自动化的完整范式：**感知工具链 + VLM 审查 + 模板化 QA + 独立审计**。
- 提供 ~80K grounded QA 数据集与独立人工 Bench，可直接服务社区。

### 技术启发
- 空间智能的"世界状态"应当是**结构化、有 ID、可溯源**的，而非纯隐式向量。
- "记录世界"与"模拟世界"是空间智能的两个正交引擎，应当分工建设。

### 应用场景
- 机器人持久物体记忆、AR 空间问答、仿真资产生成、空间数据引擎。

## 个人思考

### 最令人兴奋的发现
- "4B 打败 27B"不只是效率故事，而是路线宣言：**空间智能的能力来自世界记录的质量，而非语言模型的先验**。Qwen 4B 数值题只有 10.80%，同一个 4B 底子换成 Holi-World 数据训练后 16.33→（Bench 数值 81.84%），数据带来的跃迁接近 8 倍——grounded 数据就是空间智能的"教科书"。
- 身份持久性（"同一个杯子离开视野还是同一个杯子"）看似朴素，实则是空间认知的基石能力——人类婴儿在 4-9 个月习得物体恒常性，Holi-World 把它工程化了。

### 潜在局限
- 自动标注的"VLM 审查"环节继承了 VLM 自身的偏见：审查员看错，世界记录就错，且错误会被 QA 模板放大成系统性训练偏差。独立 Bench 能测量但不能阻止这种偏差进入训练。
- 100 个场景的生态验证了方法，但离"人类经验的连续流"还差几个数量级；真正的考验是在数千场景、跨城市、跨文化环境上的标注质量稳定性。

### 与昨日研究的关联
- 与同日精读的 Ropedia W0（同一团队）构成镜像：W0 = 人类经验 → **预测世界**；Holi-World = 人类经验 → **记录世界**。两者合起来是"经验 → 世界智能"的完整拼图。可以预见下一个版本会把 Foundry 的世界状态作为 W0 的结构化条件——那将是"记录驱动模拟"的合流。
- 与昨日 GeoThinker-F（内生预测性世界表征）相对照：GeoThinker-F 把世界表征内化到模型快速通道，Holi-World 把世界表征外化为显式记录——内隐 vs 外显是空间智能架构的根本分歧，两者最终需要在 Bench 上正面对决。

## 关键数据

- **采集规模**：~100 场景、444 条 ego 视频、1.32M RGB-D 帧（立体 RGB + IMU 设备）。
- **几何资产**：~100 个 3DGS 场景、1,322K 帧/深度/位姿。
- **语义资产**：~90K 2D box、2,466 静态 3D box、2,095 动态 4D 轨迹。
- **QA 资产**：~80K caption、13,647 静态 QA、64,409 动态 QA、~4K 3D grounding、30 种 QA 类型。
- **模型**：HOLIWORLD-VL-4B（4B）。
- **关键成绩**：
  - ScanNet AP25 0.68 / AP50 0.55（最强基线 0.40 / 0.12）
  - ADT20 HOTA 54.31%（IT3DEgo* 36.00%）
  - Bench Token F1 78.02%（Qwen 27B 零样本 43.67%）
  - EgoDynamic4D Token F1 66.39%（Qwen 27B 42.93%）
  - Bench 数值题 81.84%、Y/N 93.52%、MCQ 94.00%

## 总结

### 核心发现总结
Holi-World 证明：用"多感知工具链 + VLM 审查"的自动流水线，可以把野外人类 ego 经验零标注地转化为结构化世界记录（持久 3D 物体 + 动态 4D 轨迹 + 8 万条可溯源 QA），这些有据数据足以让 4B 模型的时空推理击败 27B 零样本模型，且自动标注质量经独立人工 Bench 双重验证。

### 对Spatial AGI的意义
- 它把 Spatial AGI 的瓶颈从"缺标注数据"改写为"缺自动数据引擎"，并交付了第一个完整开源生态（硬件→引擎→数据→模型→Bench）。
- 与预测型世界模型的分工确立后，"世界记录器 + 世界模拟器"双引擎架构很可能成为 Spatial AGI 系统的标准形态。
- 剩余短板（场景规模、误差级联、模板化 QA、无动作预测）清晰标注了下一阶段的改进路线。

## 附录 B：Foundry 单房间案例的启示

论文给出一个真实房间的完整收敛链，值得逐级分析：

```
双目 2D 检测提升（左目 + 右目）   1,684 boxes   ← 2D 检测的冗余与噪声
    ↓ 关联 + TR3D 合并                30        ← 56 倍收敛，跨视角去重
    ↓ 点支撑过滤                      22        ← 去幻觉：没有 3D 点支撑的 box 不可信
    ↓ VLM 审查                  ✓17 ✎4 ✕1      ← 语义级质检：标签修正与删除
    ↓ 最终静态 3D 物体                21
```

**三条工程经验**：
1. **每一级都有明确的失败模式**：2D 层管"看见"，几何合并管"唯一性"，点支撑管"物理存在"，VLM 管"语义正确"——不要指望任何单级解决所有问题。
2. **VLM 是审查员而非生产者**：VLM 只做 ✓/✎/✕ 判断，不负责生成 box——把 LLM 用于验证而非生成是规避幻觉的正确姿势。
3. **收敛比 ≈ 1.2%**（1,684→21）：大规模自动标注系统的设计目标不是"多"，而是高置信的"少"。

办公室统一世界状态示例：880 相机位姿 + 95 静态物体 + A→B 轨迹，全部在同一坐标系——**一个坐标系是所有下游空间推理的前提**。

## 附录 C：方法论深度评析

### C.1 "grounded"的三重含义

1. **几何接地**：每条 QA 可回溯到 3D box / 轨迹 / 相机位姿。
2. **证据接地**：支持证据（evidence）具体到帧，可人工复核。
3. **生成接地**：QA 由世界状态模板生成，不是 LLM 自由发挥——杜绝"编造事实的问答对"。

这与"用 GPT-4 批量造 QA"的偷懒路线形成鲜明对比：模板生成的 QA 语言单调，但**事实零幻觉**；对于空间智能，事实正确性 > 语言多样性。

### C.2 双验证回路的审计学价值

```
回路1（标注质量）：Foundry 自动标注 vs 独立人工 holdout 标注
回路2（学习效果）：VL-4B 表现 vs 独立人工 Bench
```

关键设计：Bench 的录像是 **held-out** 的（未进入 Foundry 数据），人工标注独立进行（不看自动结果）。这使 Bench 同时扮演"考试卷"和"自动标注的抽查审计"双重角色。空间智能系统若要获得信任，这类审计设计不可或缺。

### C.3 与 scaling 叙事的关系

W0（同团队，同日）的叙事是"数据越多预测越好"（对数-线性）；Holi-World 的叙事是"数据越 grounded 推理越强"（4B>27B）。两者合并指向一个更精细的 scaling 观：

> 空间智能的 scaling 变量不只是数据小时数，还有**每条数据的接地密度**（每个样本携带多少可验证的空间结构）。

### C.4 潜在失败场景推演

1. **透明/镜面物体**：3DGS 与深度估计的天敌，Foundry 世界记录会系统性缺失。
2. **高度动态环境**（多人走动、宠物）：VLM 路由的静态/动态判断会摇摆，ID 切换风险高。
3. **重复外观物体**（两把一样的椅子）：外观驱动关联可能合并错误身份。
4. **长间隔重访**（隔天再看同一房间）：物体重排后 ID 如何续接？论文未涉及跨会话身份维持。
5. **非交互动态**（风吹窗帘）：交互 grounding 触发不了，动态分支漏检。

## 附录 H：逐组件技术拆解

### H.1 硬件层：Ego Capture Device

- **传感器配置**：立体 RGB（双目）+ IMU。
- **设计权衡分析**：
  - 为什么不用单目？立体基线提供深度先验，降低 DA3 类单目深度估计的尺度漂移。
  - 为什么必须 IMU？VI-SLAM（视觉-惯性）在快速转身、弱纹理走廊等视觉退化场景下靠 IMU 维持位姿。
  - 为什么 ego 而非多固定相机？ego 视角天然携带"人如何使用空间"的交互信息，这是固定机位没有的。
- **两种采集协议的分工**：mapping walk 保证空间覆盖（结构完整），interaction session 保证动态覆盖（事件完整）——数据采集本身就有任务意识。

### H.2 共享准备层的四个组件

1. **VI-SLAM**：输出相机位姿序列——整个世界的坐标系锚。
2. **DA3（深度基础模型）**：输出稠密深度图——点支撑过滤与 3D 反投影的原料。
3. **3DGS**：高斯场景重建——提供连续外观与可查询的 3D 表示。
4. **VLM 语义路由**：看物体外观与上下文，决定走静态（家具类）还是动态（手持物、被移动物）分支。

**架构洞察**：路由发生在**物体级**而非场景级——同一房间里，沙发走静态分支、水杯走动态分支，互不干扰。

### H.3 动态分支的五步链条

```
交互 grounding（识别"手在碰什么"）
  → 身份关联（跨帧同一物体）
  → SAM mask 跟踪（像素级外观锁定）
  → 3D 反投影（mask → 世界坐标系）
  → 每帧 OBB（带朝向的包围盒 → 4D 轨迹）
```

- **交互 grounding 是启动器**：动态物体通过"被人手触碰"被识别进入跟踪——这是从人类交互先验中借来的启发式。
- **SAM 提供像素级外观锁定**，弥补 box 跟踪在外观相似物体上的混淆。
- **OBB 而非 AABB**：朝向信息对"杯子倒了没有""椅子转向哪边"类推理是必要的。

### H.4 数据集的分层设计哲学

四级组织（raw → geometry → semantics → spatial intelligence）本质是把数据当成**可分层取用的知识库**：

- 训练感知模型 → 取第 2 层（帧+深度+位姿）
- 训练 3D 检测/跟踪 → 取第 3 层
- 训练空间推理 VLM → 取第 4 层
- 审计/验证 → 任意层回溯到 raw

这种"一份采集、多层复用"的设计将单次采集的价值最大化——对比一次只出一类标注的传统数据集，边际效率高得多。

### H.5 QA 类型学（30 类）

覆盖三大族：
- **静态建图族**：存在性、位置、空间关系（后/旁/内）、计数、距离、大小比较……
- **轨迹族**：物体从哪来到哪去、何时移动、移动前后的状态对比……
- **Caption 族**：场景/事件的自由描述。

**难负例的设计模式**（推断）：
- 存在相似 distractor 的位置题（"左边的杯子"vs"右边的杯子"）
- 空间关系反转（A 在 B 后 vs B 在 A 后）
- 时间反转（移动前 vs 移动后的状态提问）
- 计数陷阱（部分遮挡导致的人类直觉误判）

## 附录 I：数字背后的解读

### I.1 为什么 ScanNet++ 领先幅度小？

- ScanNet（合成感强、家具规整）：AP25 0.68，碾压级。
- ScanNet++（真实高质感、物体密集）：AP25 0.30 vs Boxer 0.23。
- 自建 Bench（野外、完全 held-out）：AP25 0.24。

**解读**：自动流水线的优势随场景"野性"增加而衰减，但优势仍在。绝对值 0.24-0.30 提醒我们：**自动 3D 标注的上限还远未达到人工质量**，VLM 审查只能救回部分错误。

### I.2 数值题的双面证据

- Bench 数值 81.84%（同分布）：有据训练后近乎解决。
- EgoDynamic4D 数值 16.33%（跨分布）：泛化失败。

**结论**：空间数值推理（距离/计数/坐标）目前是"有据则明、离据则盲"——grounded 数据教会的是模式而非规则。要让数值能力泛化，可能需要在 QA 中引入程序化计算（symbolic solver in the loop）而非纯学习。

### I.3 Y/N 题 99.67% 的警示

EgoDynamic4D Y/N 准确率 99.67%——接近满分反而可疑，可能存在类别先验捷径（该集 Y/N 分布不均衡）。跨数据集评估中，接近饱和的单项指标应核查标签分布。

## 附录 J：精读问答补充

**Q: Foundry 与 NeRF/3DGS 时代的语义场景图方法（如 ConceptGraphs 类）本质区别？**
A: 三点：(1) 动态物体与交互历史是一等公民，不只是静态场景图加附件；(2) 输出面向训练（QA 模板生成）而非仅面向查询（机器人现问现答）；(3) 有独立人工 Bench 审计标注质量——数据引擎思维 vs 感知系统思维。

**Q: 为什么训练 4B 而不是更大的模型？**
A: 战略性选择：4B 打赢 27B 才能证明"数据价值 > 参数价值"；如果用 27B+ 训练，贡献会归因不清（数据还是参数？）。小模型实验设计让数据贡献可归因。

**Q: 这套生态最大的可迁移资产是什么？**
A: 不是模型（VL-4B 场景特定），而是 **Foundry 的编排配方**（工具链选择、过滤阈值、VLM 审查提示、QA 模板库）与 **Bench 的审计协议**。这两样可以直接搬去任何新环境。

**Q: 与"用世界模型生成合成数据"路线的对比？**
A: 合成数据（生成式）免费但真实性存疑；Foundry 数据（感知式）真实但受采集成本约束。两者互补：Foundry 提供真实骨架，世界模型可在其上外推合成变体（新视角、新光照、新物体状态）。合流点是自然的后续方向。

## 附录 K：对 Spatial AGI 路线图的影响评估

1. **短期（6 个月）**：Foundry 类自动标注会被各大机器人/AR 团队复制，空间 QA 数据集将快速通胀——先发的 Bench 审计协议成为稀缺品。
2. **中期（1-2 年）**："记录器+模拟器"双引擎合流：世界记录成为世界模型的结构化条件与评测底座。
3. **长期**：如果 ego 采集设备（智能眼镜）普及，Holi-World 式流水线将成为"个人空间记忆"的基础设施——每个人的环境都有一个带 ID 的持久世界记录。

风险项：隐私（世界记录 = 可查询的个人空间数据库）、安全（记录被篡改将污染下游决策）、数据主权。
