## 0. 一句话总结

Demiurge 用一个"演化中的 4D 点云记忆"把孤立的视频重渲染串成自回归循环——每条新轨迹的生成都以全部历史几何与外观为条件，生成后再蒸馏回记忆——从而把单目视频扩展成一个跨轨迹一致、可导航、可直接优化成 3DGS 的 4D 世界。

## 核心问题

### Q1: 核心算法原理是什么？

**问题**: 这篇文章的核心算法原理是什么？

**分析**:

#### 1. 核心思想和动机

- **问题背景**: 视频扩散模型已经能从单目视频合成任意目标轨迹的新视角视频（generative video rerendering），支撑世界建模、具身智能和机器人仿真。但现有方法把每条相机轨迹当作独立任务：轨迹 A 的生成不知道轨迹 B 的存在，跨轨迹的几何、外观、动态互不约束。
- **后果**: 生成的一堆"孤立 2D 视频"无法拼成一个全局自洽的时空格（spatiotemporal lattice），也就无法形成可导航（navigable）的 4D 世界——机器人从轨迹 A 走到轨迹 B 时，会发现两次"看到"的世界对不上。
- **核心思想**: 把视频重渲染改造成**自回归过程**，维护一个演化的 4D 点云记忆 M_i 作为持久世界状态：
  - 每步沿目标轨迹 C^i 渲染记忆 → 得到条件 → 生成新视角视频 + 深度；
  - 把新生成的内容反投影、融合回记忆 → M_i；
  - 用 M_i 引导下一条轨迹。
  - 即 generate–recover–update 循环。

#### 2. 主要技术方法（四大组件）

**组件 1: Memory-guided Appearance Video Diffusion（记忆引导的外观视频扩散）**

- 沿目标轨迹 C^i 用 dual-stream warping 渲染记忆 M_{i-1}，得到部分 RGB 视频 V~、部分深度 D~、可见性掩码 M~；
- **噪声监控器（noise monitor，非学习、轻量）**: 点云渲染在遮挡边界处会产生空洞和不稳定投影，若不处理会随自回归迭代累积。对每像素判定三种不可靠情况：
  - 深度无效（D < τ_0）；
  - 深度梯度过大（||∇D|| > τ_g）；
  - 3×3 邻域局部深度方差过大（Var > τ_v）；
  - 输出异常掩码 O，并在所有条件上统一失效这些像素：V̄ = (1−O)⊙V~ 等；
- 外观扩散模型 F_app 以清洗后的三路条件 + 噪声 latent 拼接去噪，生成 V^i：保留记忆支持的可靠内容，用生成先验重绘不可靠与新增区域。

**组件 2: Memory-consistent Video Depth Completion（记忆一致的视频深度补全）**

- **问题**: 把生成的 RGB 视频反投影回记忆需要稠密深度。现成单目视频深度估计器有两大毛病：
  - 尺度歧义（scale ambiguity）——深度是相对的，与缓存中的度量几何对不上；
  - 即使在已观测区域也可能与缓存几何不一致，直接反投影会在记忆中引入错位表面和几何断裂。
- **方案**: 训练一个深度补全模型，以记忆渲染的部分深度 D~ 作为引导：
  - 已观测区域：锚定（anchor）到缓存的度量几何；
  - 新暴露区域：补全出与整体尺度/结构一致的深度；
  - 输出时序连贯的稠密深度 D^i，可安全反投影回点云并融合。

**组件 3: Memory-aware Dual-stream Warping（记忆感知双流 warp）**

- 关键洞察：记忆更新策略需要在"稳定性"与"覆盖度"之间权衡，于是维护**两份点云**：
  - **选择性更新点云（selectively updated）**: 只融合高置信内容 → 提供**高保真外观引导**，防止累积色彩漂移（cumulative color drift）；
  - **稠密更新点云（densely updated）**: 尽量融合一切 → 提供**可靠的遮挡线索**，标识哪些区域是"确定看不见的"；
- 依据两流之间的**深度差异（depth discrepancy）**融合：外观流优先（保留稳定视觉内容），在深度差异大的新暴露区域让位给生成。
- 效果：抑制几何伪影 + 阻断自回归迭代的色彩漂移。

**组件 4: Geometry-aware Video Refinement（几何感知视频精修，可选）**

- 利用时序一致的目标视角深度图 + 部分 RGB 渲染，衰减细微纹理闪烁和噪声，提升最终输出的感知质量与时序一致性。

#### 3. 算法流程和关键步骤

```
输入: 单目视频 V^0 + 相机轨迹 C^0 + N 条目标轨迹 {C^i}
  ↓
[初始化] 单目深度估计 → 反投影 → 初始 4D 记忆 M^0
  ↓
[自回归循环 i = 1..N]
  1. Dual-stream warp: R_dual(M^{i-1}, C^i) → (V~, D~, M~)
  2. 噪声监控: 深度无效/梯度大/方差大的像素 → 异常掩码 O
  3. 条件清洗: (V̄, D̄, M̄) = (1−O) ⊙ (V~, D~, M~)
  4. 外观扩散: V^i = F_app(V̄, D̄, M̄)   ← 生成新视角视频
  5. 深度补全: D^i = 补全模型(V^i, D̄)    ← 锚定已观测区，补全新区域
  6. 记忆更新: V^i, D^i 反投影 → 融合 → M^i
  7. (可选) 几何感知精修 V^i
  ↓
输出: N 条轨迹的几何一致视频 + 统一的 4D 世界（可直接优化为 3DGS/4DGS）
```

#### 4. 输入输出

- **输入**: 一段单目视频 + 其相机轨迹（+ 深度估计器初始化），以及若干目标相机轨迹。
- **输出**:
  - 每条目标轨迹的新视角视频（光度真实、时序连贯）；
  - 全局一致的 4D 点云世界状态（时空格）；
  - 可直接优化成高质量 3DGS（伪影极少）的场景表示。

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**分析**:

#### 1. 如何理解和表示空间

- **4D 点云记忆 = 显式世界状态**: Demiurge 把"世界"具体化为一个随时间演化的 4D 点云缓存 M_i = {P_{i,t}}，按视频时间帧 t 组织。空间不是 latent，是可渲染、可反投影、可增补的显式几何。
- **记忆的可信度分层**: 双流设计（选择性更新 vs 稠密更新）隐含了一个深刻观点——**空间记忆必须带置信度**：哪些内容是"确证的"（高保真流），哪些是"占位的"（稠密流）。这比单一的 3DGS 记忆（如 Holi-Spatial 360）更细粒度。
- **"探索即记忆增长"**: 世界通过一条条轨迹的访问而长大——空间认知是一个主动、渐进的积累过程，而不是一次性快照。

#### 2. 如何处理空间关系

- **跨轨迹一致性作为一等目标**: 论文的核心贡献就是让"从轨迹 A 看到的世界"和"从轨迹 B 看到的世界"是同一个世界。这本质上是空间关系中的**同一性约束**（identical-scene constraint）。
- **遮挡的显式建模**: 遮挡线索来自稠密流，可见性掩码显式告知生成模型"哪里没见过、需要想象"。空间推理中最难的 occlusion reasoning 在这里被工程化为掩码 + 条件清洗。
- **大视差与零重叠**: 支持 180° 旋转、与输入视角零重叠的重渲染——意味着记忆+生成可以处理"从未从该方向看过"的视角，这是空间外推能力（spatial extrapolation）的直接测试。

#### 3. 对 Spatial AGI 的启发

- **自回归世界构建范式**: "生成→恢复几何→更新记忆"的循环是一个通用的空间认知循环（perceive→consolidate→recall），可推广为 Spatial AGI 的操作语义：任何新观测都必须经过"与记忆一致性检查"后才能写入世界模型。
- **几何锚定防止幻觉漂移**: 与 Holi-Spatial 360 的结论殊途同归——纯生成会产生漂移（color drift、spatial drift），显式几何记忆是防腐剂。Demiurge 的双流记忆进一步给出了"记忆分层置信度"的具体机制。
- **对世界模型的架构启示**: 与把历史压缩进 latent memory 的视频世界模型（sliding-window / hierarchical latent memory）相比，Demiurge 证明显式 4D 几何记忆在大视差长程任务上更稳。这对 Spatial AGI 的记忆架构选型是重要证据。
- **Sim 后端能力**: 输出可直接优化为 3DGS → 可作为机器人仿真的场景来源，"一段视频 → 可导航世界"的通路打通了 real-to-sim 的最低成本路径。

#### 4. 可以应用的 Spatial AGI 场景

- **机器人仿真与训练**: 拍一段视频 → 得到可任意视角导航的 4D 环境 → 生成大量训练轨迹数据。
- **具身探索规划**: agent 在真实环境中移动时持续构建 4D 记忆，支持"回到没带相机的地方"（memory-based re-observation）。
- **VR/自由视点视频**: 单目视频转自由视角沉浸内容。
- **世界模型评测**: 大视差零重叠重渲染可作为空间外推能力的 stress test。
- **影视/内容预演**: 虚拟运镜，先在 4D 世界里"试拍"。

### Q3: 主要创新点和局限性是什么？

**分析**:

#### 1. 主要创新点

1. **从轨迹级到世界级的范式转变**: 首批把视频重渲染组织为"共享 4D 记忆上的自回归过程"的工作，输出从孤立视频升级为全局一致的时空格。
2. **双流记忆 warp**: 用选择性更新流保保真、稠密更新流保遮挡线索、深度差异做融合裁决——优雅地解决了"记忆稳定性 vs 覆盖度"的矛盾，并直接阻断累积色彩漂移。
3. **记忆一致的深度补全**: 不信任单目深度的尺度，用缓存度量几何做锚，只对未观测区补全——把"几何回写"这个最容易污染记忆的环节变成安全的。
4. **免学习的噪声监控**: 用深度有效性/梯度/方差三个阈值检测点云渲染的不可靠像素，简单但有效地防止退化条件进入生成循环。
5. **三大能力实证**: 时空格构建、180° 零重叠大视差重渲染、输出可直接优化为高质量 3DGS——每一条都是先前方法做不到的。

#### 2. 主要局限性

1. **动态语义有限**: 虽然记忆按时间帧组织（4D），但"动态"主要指沿输入视频时间轴的场景演化；对新的、未发生过的动态事件（新物体交互、物理过程）没有生成能力，不是物理世界模型。
2. **误差仍会累积**: 自回归 + 记忆回写结构决定了早期几何错误会被后续轨迹继承；深度补全锚定机制减缓但不消除。长时间、多轨迹后记忆质量如何衰减，论文未给出定量边界。
3. **依赖输入视频质量**: 初始记忆来自单目深度估计，输入视频的深度质量直接决定世界地基；深度估计失败的材质（透明、反光）会成为永久性记忆缺陷。
4. **显式点云的规模问题**: 4D 点云按帧存几何+外观，长视频、多轨迹下内存和渲染成本线性/超线性增长，没有提到压缩或稀疏化策略。
5. **无语义层**: 记忆只有几何+外观（RGB 点云），没有物体实例、可供性、物理属性——距离"可交互世界"还缺语义与物理两层。

#### 3. 与其他相关工作的对比

| 维度 | Plücker/位姿条件生成 | ViewCrafter/GEN3C | FlexWorld/Voyager | PlenopticDreamer | **Demiurge** |
|---|---|---|---|---|---|
| 一致性范围 | 单轨迹内 | 单轨迹 | 增量 3D 场景 | top-k 视频检索 | **全部轨迹统一 4D 记忆** |
| 记忆形式 | 无 | 部分点云 | RGB-D 缓存 | 视频-相机对库 | **4D 点云（几何+外观+时序）** |
| 动态场景 | 弱 | 弱 | 静态为主 | 支持 | **沿时间帧组织** |
| 上下文瓶颈 | N/A | N/A | 场景表示 | 固定 top-k | **无固定容量瓶颈** |
| 大视差 | 漂移严重 | 中 | 受限 | 依赖检索 | **180° 零重叠可用** |
| 3DGS 可优化性 | 差 | 中 | 好 | 中 | **好（伪影极少）** |

- **vs PlenopticDreamer（最近邻）**: PD 把历史视频-相机对存库、按 3D FOV 重叠检索 top-k，超过 k 条轨迹就得丢弃细节；Demiurge 把所有轨迹融合进统一点云记忆，无固定容量瓶颈，一致性不依赖检索质量。
- **vs latent-memory 长视频生成**: 外观/特征空间记忆缺显式几何接地，大相机运动下空间漂移；Demiurge 的显式 4D 记忆是几何级的。
- **优势**: 一致性最强、可优化性最好、支持动态时间轴。
- **劣势**: 计算链路更长（warp+生成+补全+融合+精修），显存开销大，端到端训练复杂度高。

## 核心技术发现

- **发现1**: 跨轨迹不一致的根源是"每条轨迹独立生成、不保留任何东西"——解法不是更强的生成器，而是显式共享记忆 + 自回归组织。
- **发现2**: 记忆回写链条中，深度尺度歧义是最危险的污染源；"已观测区锚定缓存几何、未观测区才允许补全"的策略能让回写安全化。
- **发现3**: 双流（保真流 + 覆盖流）记忆配合深度差异融合，可以同时获得高保真引导与可靠遮挡线索，并阻断自回归色彩漂移。
- **发现4**: 点云渲染的不可靠像素可以用三个免学习指标（深度无效、梯度大、局部方差大）可靠检测，统一失效即可防止退化条件污染生成。
- **发现5**: 几何一致的生成输出可以直接优化出高质量 3DGS——"生成视频 → 3D 表示"的通道在伪影受控时是实用的。

## 与Spatial AGI的关系

### 直接贡献

- 提供了"单视频 → 可导航 4D 世界"的完整系统，是 Spatial AGI 数据与仿真基础设施的 real-to-sim 入口。
- 证明显式 4D 几何记忆是大视差长程一致性的正确基座。

### 技术启发

- **generate–recover–update 循环** = 空间认知的操作化定义：感知（生成）、巩固（几何恢复）、记忆（融合回写）。
- **记忆置信度分层**（双流）应成为所有空间记忆系统的标配设计。
- **条件清洗**（噪声监控）提示：给生成模型喂记忆时，宁缺勿错。

### 应用场景

机器人 real-to-sim、具身探索记忆、自由视点视频、空间外推评测、虚拟运镜。

## 个人思考

### 最令人兴奋的发现

1. **"记忆即世界"的工程化**。Demiurge 里，世界状态不是抽象概念，而是一个可以渲染、可以回写、可以带着置信度分层的数据结构。这正是 Spatial AGI 需要的"世界模型"的最小可行形态——先有可导航，再谈可交互，最后谈可预测。
2. **双流记忆是个漂亮的设计模式**。任何持久记忆系统都面临"写入激进（覆盖广但脏）vs 写入保守（干净但盲区大）"的两难，Demiurge 用两份记忆 + 运行时融合优雅化解。这个模式在数据库（WAL vs 主存）、RL（target network）里都有影子，搬到空间记忆领域非常自然。
3. **180° 零重叠重渲染**是对"空间想象力"最硬核的测试：不看任何该方向的观测，纯凭记忆中其他方向的证据 + 生成先验推断背面。这与人类闭眼想象房间背面的认知任务同构。

### 潜在局限

1. **它其实是一个"渲染器"而非"世界模型"**: 世界内容完全来自输入视频，Demiurge 只负责从新视角"重放"；它不能预测"如果我推倒这个杯子会发生什么"。称之为 world 应该打引号——是 viewable world，不是 interactive/predictive world。
2. **自回归记忆的熵增问题**: 每次回写都是一次有损压缩 + 有偏插值，几十条轨迹后记忆可能漂向"生成先验的平均场景"。需要周期性的观测重校准机制（类似 SLAM 的回环检测）。
3. **4D 记忆的工程重量**: 按帧存点云的方式对长时序不友好，未来需要场景图/3DGS 化的 4D 记忆（每帧只是视角变化 + 物体状态位）。

### 与今日其他论文的关联

- **与 Holi-Spatial 360 构成完美对照**: 一个几何优先（先锚定再生成，静态多房间），一个记忆优先的生成式扩展（先生成再锚定回记忆，单视频 4D）。两者都认同"几何记忆约束生成"，但方向相反：Holi 是"从观测到生成"，Demiurge 是"从生成到观测"。
- **与 Splat2Act 呼应**: Demiurge 输出可直接优化为 3DGS，而 Splat2Act 恰好消费真实场景 3DGS 来个性化 VLA——"视频→4D世界→3DGS→机器人策略适配"的链条初见雏形。
- **回应 Physical AI 综述**: 综述强调世界模型需要"预测"能力，Demiurge 提供的是"重建/重渲染"能力——两者互补，缺一不可。

## 关键数据

- **输入**: 单目视频（T 帧）+ 轨迹 + N 条目标轨迹
- **记忆结构**: M_i = {P_{i,t}}，按帧组织的彩色 4D 点云
- **四大组件**: F_app（外观扩散）、深度补全模型、双流 warp R_dual、几何感知精修
- **噪声监控阈值**: τ_0（深度无效）、τ_g（梯度）、τ_v（3×3 局部方差）
- **三大能力**: 稠密多视角时空格 / 180° 零重叠大视差 / 直接优化为高质量 3DGS

## 总结

### 核心发现总结

Demiurge 把视频重渲染从"孤立轨迹的独立生成"重构为"共享 4D 点云记忆上的自回归过程"，通过外观扩散 + 记忆一致深度补全 + 双流 warp + 几何感知精修四件套，实现了跨轨迹一致、可导航、可优化为 3DGS 的 4D 世界构建，并在大视差极端场景下保持稳定。

### 对Spatial AGI的意义

- 它给出了空间认知循环（生成-恢复-更新）的工程模板，以及记忆置信度分层（双流）这一可复用设计模式。
- 它划清了一类世界模型的边界：能"从新视角重放"不等于能"预测与交互"——这为 Spatial AGI 的能力分级提供了一个清晰参照点。

## 附录A：深度技术剖析

### A1. 自回归世界的误差传播分析

Demiurge 的信息流是：M_{i-1} → 条件 → 生成 V^i → 深度补全 D^i → 回写 M_i。误差可能在四处进入：

1. 条件渲染误差（点云空洞、不稳定投影）→ 已由噪声监控拦截；
2. 生成误差（幻觉内容）→ 部分被"保留记忆支持的内容"约束，新暴露区无法约束；
3. 深度补全误差（尺度/结构不一致）→ 已观测区被锚定消除，新区只有先验兜底；
4. 融合误差（回写时错位）→ 依赖深度补全质量。

关键观察：**只有新暴露区域是不可控误差入口**，且一旦写回就成了"事实"，后续轨迹无法分辨它是生成的还是观测的。改进方向是给记忆点携带"来源标签"（observed vs generated）与不确定度，融合时加权，评测时用 observed 区校准。

### A2. 双流 warp 的融合判据

融合依据两流深度差异（depth discrepancy）：

- 深度差异小 → 两流一致，用保真流外观（稳定）；
- 深度差异大 → 该像素处于新暴露/不稳定区，降低外观流权重，留给生成模型想象。

这个设计实际上实现了一个空间版本的"已知/未知"二分，且判据是纯几何的（免学习）。代价是阈值敏感：深度噪声大的区域可能被误判为新暴露区，导致不必要的外观重绘（引入生成噪声）。

### A3. 为什么深度补全不直接用现成单目模型 + 尺度对齐？

尺度对齐（如按中位数对齐）只能修全局尺度，修不了**局部结构不一致**：单目深度在已观测区域可能把墙"估弯"了，与缓存点云形成双层面。Demiurge 的补全模型以部分渲染深度为直接条件，本质上是一个"以已知深度为边界条件的深度 inpainting"，输出被约束为与已知几何连续，因此反投影后不会出现双层面。

### A4. 与 SLAM 的深层同构

Demiurge 的循环与现代 SLAM（尤其稠密 SLAM）惊人地同构：

| SLAM | Demiurge |
|---|---|
| 帧间跟踪（几何） | 深度补全 + 回写 |
| 地图（点云/TSDF） | 4D 点云记忆 |
| 回环检测 | （缺失！） |
| 关键帧 | 选择性更新流 |
| 新区域探索 | 新轨迹生成 |

最大的缺失是**回环**：SLAM 靠回环检测修正累积漂移，Demiurge 目前只能靠锚定缓解。把"重访已观测视角"作为自回归中的校准步骤（compare & repair）是一个自然的改进方向。

### A5. "4D"的成色

记忆按视频帧组织 P_{i,t}，即每个时间戳一套点云。但这更像"多份 3D 快照的堆叠"而非紧凑 4D 表示（如 4DGS、场景流场）。真正的时间维度智能（物体持续运动的外推、动态事件的因果理解）没有被表示所支持。称其为"沿时间可导航的多 3D 世界"更准确。

## 附录B：实验与结果解读

### B1. 评测维度

- **感知质量**: 新视角视频的真实感（FID/FVD 类指标 + 人评）；
- **几何精度**: 深度/几何与真值的偏差；
- **跨轨迹一致性**: 同一区域在不同轨迹生成结果中的一致程度（本文的核心指标）；
- **大视差鲁棒性**: 大角度旋转、零重叠条件下的成功率；
- **3DGS 可优化性**: 生成结果直接优化 3DGS 后的渲染质量与伪影水平。

### B2. 结论要点

- 在感知、几何、跨轨迹一致性三方面均达 SOTA；
- 180° 零重叠旋转下仍能产出可用结果（先前方法在此条件下基本崩溃）；
- 3DGS 直接优化伪影极少，验证了"几何一致的生成可以作为 3D 监督"。

### B3. 计算画像

每条轨迹需要：双流渲染 + 扩散去噪（多步）+ 深度补全 + 点云融合（+ 可选精修）。N 条轨迹总成本 ≈ N × 单轨迹成本，无摊销；对比 PlenopticDreamer 的检索式（推理便宜、但一致性受限于检索），Demiurge 是"贵但一致"。

## 附录D：常见问题（FAQ）

### D1. 和直接训一个 camera-controlled video model 有什么本质区别？

本质区别是**状态外置**。纯生成模型的世界状态在权重+上下文窗口里，随生成长度衰减；Demiurge 把状态外置为显式 4D 记忆，生成只负责"填充增量"。这与人脑的坐标系记忆（海马体 place cell 提供空间框架，想象负责填充细节）结构上相似。

### D2. 记忆会无限膨胀吗？

会。按帧存点云是 O(T × N) 增长。实际使用需要稀疏化（关键帧选择）、压缩（点云→3DGS）、或语义层级化（物体级替换点级）。这是该范式走向长程应用的最大工程障碍。

### D3. 能处理人走动的视频吗？

输入视频中的动态会被记忆沿时间帧保留（4D 组织的意义所在），沿原始时间轴重放没问题；但让 agent 在"另一时刻"导航时，动态内容如何安置（冻结？继续运动？）是未明确讨论的语义问题。

### D4. 为什么叫 Demiurge？

Demiurge（德穆革）是柏拉图哲学中塑造世界的工匠神——从已有质料（输入视频）锻造出有序世界（可导航 4D 世界）。名字准确：它不无中生有，而是整理与扩展。

## 附录E：术语表

- **Video Rerendering**: 从已有视频沿新相机轨迹合成新视角视频。
- **4D Point-Cloud Memory**: 按时间帧组织的彩色点云集合，作为持久世界状态。
- **Autoregressive Rerendering**: 逐轨迹生成并把结果融合进记忆以条件化后续生成的过程。
- **Dual-stream Warping**: 保真流（选择性更新）与覆盖流（稠密更新）并行渲染并按深度差异融合的策略。
- **Depth Completion**: 以部分已知深度为条件补全稠密深度，本文版本锚定缓存度量几何。
- **Scale Ambiguity**: 单目深度只有相对尺度，与度量几何存在全局/局部不一致。
- **Noise Monitor**: 基于深度有效性/梯度/方差的免学习不可靠像素检测器。
- **Color Drift**: 自回归生成中颜色/色调逐迭代偏移的累积误差现象。
- **Spatiotemporal Lattice**: 多视角多时间观测构成的全局一致网格结构。
- **Plücker Ray Map**: 用普吕克光线嵌入表示相机位姿的视频生成条件方式。

## 附录G：批判性审视清单

### G1. 可复现性评估

- **有利因素**: 组件化清晰（四个模块可分别消融）；依赖的基础模型（视频扩散、单目深度）多为开源；项目页承诺公开。
- **风险因素**: 四模型级联的训练配置复杂；4D 记忆的工程实现细节（融合拓扑、内存管理）论文篇幅有限；评测跨轨迹一致性的协议较新，第三方复现打分口径可能不一致。
- **综合判断**: 研究复现中偏难，工程复刻难。

### G2. 失效场景推演

1. **输入视频深度失败**（玻璃幕墙、镜面、水面）: 初始记忆在失败材质处永久错误，后续所有轨迹继承该缺陷并可能放大成结构性伪影；
2. **重复 visit 的自吞噬**: 多条轨迹反复覆盖同一区域时，生成内容反复回写，记忆可能逐渐偏离观测向先验均值漂移——缺少"观测权威性高于生成权威性"的机制；
3. **光照变化**: 不同轨迹如果目标光照不同（时间推移），记忆中的外观与新轨迹条件的光照需求冲突，双流融合按深度判据无法处理光度不一致；
4. **大规模场景**: 点云内存随场景尺度平方级增长（遮挡区也要存），室外街道级场景可能不可行。

### G3. 与端到端统一模型的哲学对照

Demiurge 是"系统 2 式"的：显式状态、显式更新、模块分工。与"一个 video foundation model 吃下一切"的端到端路线相比，它的优势是可审计（每一步可检查记忆里到底存了什么）、可修正（发现错可直接改记忆）；劣势是链路长、延迟高、端到端性能上限受各模块短板制约。未来若 video foundation model 原生出"持久世界状态"能力（如内置 memory token 的 3D 接地），本方法的四件套可能被压缩为"记忆接口 + 生成器"两层。

### G4. 安全与滥用评估

单视频→可导航世界的成熟意味着：一段偷拍视频即可重建他人家居的可漫游副本。隐私风险等级高于静态 3DGS 重建（有导航性=有窥视性）。部署时应绑定授权水印与场景用途限制。这是该技术路线商业化前必须回答的伦理题。

## 附录I：实验补遗与阅读笔记

### I1. 与 ViewCrafter 系的逐项对比笔记

- ViewCrafter/GEN3C 用部分点云渲染做条件，但点云只来自输入视频、不随生成增长——本质是"一次性记忆"；
- FlexWorld/Voyager 会增量扩场景，但缺少置信度分层与时间维度；
- Demiurge = 增量 + 置信度 + 时序 + 防漂移融合，四项全占，这是 SOTA 的来源。

### I2. 消融直觉（基于方法设计反推）

- 去掉噪声监控 → 点云渲染的破碎条件进入扩散模型 → 生成放大破碎 → 记忆劣化（论文 Fig.4a 展示的问题）；
- 去掉深度锚定 → 尺度漂移逐轨迹累积 → 记忆出现双层面几何（Fig.4b）；
- 去掉双流（只用稠密流）→ 色彩漂移累积（自回归视频生成的经典病）；
- 去掉精修 → 可用但闪烁。

### I3. 值得做的 follow-up（个人研究建议清单）

1. 来源标签记忆：每个点带 observed/generated 标签 + 不确定度，融合加权，重访时校准；
2. 记忆压缩：点云 → 场景图/物体级 3DGS，把"帧堆叠"变成"物体状态机"；
3. 回环校准：检测重访视角，强制用记忆重渲染并与原观测对比，触发记忆修复；
4. 物理层接入：在记忆上叠加刚体/流体先验，把 L2 世界推向 L3 可交互；
5. 与 VLA 的闭环：用 Demiurge 世界做策略评估器（零真实风险的大视差导航测试）。

## 附录L：方法卡片（Method Card）

- **任务**: 单目视频 → 跨轨迹一致的可导航 4D 世界
- **输入**: 视频 V^0 + 轨迹 C^0 + N 条目标轨迹

- **循环**: generate (F_app) → recover (depth completion) → update (back-project & fuse)
- **关键机制**: 深度锚定（已观测区）、条件失效（噪声监控）、深度差异融合（双流）
- **适用边界**: 输入视频可深度估计、场景以静态为主、目标轨迹在记忆可达范围内
- **失效模式**: 镜面/透明材质、光照变化、记忆漂移（无回环）、内存膨胀
