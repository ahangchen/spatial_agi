# VEGA: Visual Encoder Grounding Alignment for Spatially-Aware Vision-Language-Action Models

**日期**: 2026-05-13
**arXiv**: https://arxiv.org/abs/2605.10485
**机构**: 北京大学, 北京人形机器人创新中心
**作者**: Hao Wang, Xiaobao Wei, Jingyang He, Chengyu Bai, Chun-Kai Fan, Jiajun Cao, Jintao Chen, Ying Li, Shanyu Rong, Ming Lu, Xiaozhu Ju, Jian Tang, Shanghang Zhang

## 摘要

VEGA提出了一种简洁有效的框架，直接将VLA模型的视觉编码器输出与3D感知特征（DINOv2-FiT3D）对齐。关键创新在于在视觉编码器输出层面进行对齐（而非LLM层），在语言语义纠缠之前注入空间感知。对齐通过轻量级projector实现，推理时丢弃，不引入额外计算开销。

## Q1: 核心算法原理

### 1.1 核心思想和动机

VLA模型的视觉backbone主要在2D图像数据上预训练，缺乏3D几何监督，导致空间感知能力不足。现有的隐式空间接地方法存在两个问题：
1. 依赖经验性的层搜索（empirical layer search）来确定对齐位置
2. 在LLM层面的视觉token上进行对齐，此时空间结构已与语言语义纠缠

VEGA的核心洞察：**在视觉编码器输出层面直接对齐**，在任何语言纠缠发生之前就注入空间感知。

### 1.2 主要技术方法

**空间教师模型**: DINOv2-FiT3D
- FiT3D是一个两阶段框架，通过多视角一致的3D Gaussian Splatting监督，将3D空间感知注入DINOv2
- 第一阶段：训练3DGS表示，每个高斯配备低维特征向量
- 第二阶段：将渲染的3D感知特征作为监督目标微调2D基础模型

**对齐框架**:
- 学生：VLA视觉backbone中的DINOv2编码器（倒数第二层输出）
- 教师：冻结的DINOv2-FiT3D编码器（最后一层输出）
- 轻量级projector：LayerNorm + 两层MLP + GELU激活
- 损失：余弦距离 + 动作预测损失的加权组合

### 1.3 算法流程

1. 从输入图像I提取特征：
   - 学生特征：F_DINO = ε^{DINO}_{L-2}(I) （倒数第二层）
   - 教师特征：F_FiT3D = ε^{FiT3D}_{L-1}(I) （最后一层）
2. 投影：F̂_DINO = φ(F_DINO)
3. 对齐损失：L_align = (1/N) Σ (1 - cos(F̂_i^DINO, F_i^FiT3D))
4. 总损失：L_VEGA = L_action + λ * L_align（λ=0.1）
5. 推理时丢弃projector和教师编码器

### 1.4 输入输出

- 输入：多视角图像 + 语言指令
- 输出：机器人动作序列
- 对齐目标：DINOv2-FiT3D的patch级特征

## Q2: 与Spatial AGI的关系

### 2.1 空间理解与表示

VEGA通过DINOv2-FiT3D将3DGS的多视角一致几何信息蒸馏到视觉编码器中，使VLA模型的视觉表征具备3D空间感知能力。这不是直接使用3DGS作为世界模型，而是将3DGS的几何先验作为教师信号注入2D视觉编码器。

### 2.2 空间关系处理

- 多视角一致性：通过3DGS渲染的特征天然具有多视角一致性
- 对象边界：PCA可视化显示FiT3D特征产生更清晰的对象边界
- 空间配置：编码深度、相对位置和视角变化信息

### 2.3 对Spatial AGI的启发

1. **间接空间注入**：不需要显式的3D传感器或标注，通过特征对齐即可注入空间感知
2. **零推理开销**：空间信息在训练时注入，推理时无额外计算成本
3. **几何-语义分离**：在语言纠缠之前对齐，保持几何可解释性
4. **可扩展性**：作为通用框架，适用于任何使用DINOv2视觉编码器的VLA模型

### 2.4 Spatial AGI应用场景

- 精细操作任务（需要精确空间定位）
- 遮挡推理和多视角理解
- 视角变化下的鲁棒操作
- 零样本迁移到新环境

## Q3: 创新点与局限性

### 创新点

1. **视觉编码器级对齐**：首次提出在视觉编码器输出层面直接对齐（而非LLM层），在语言纠缠前注入空间感知
2. **FiT3D教师选择**：使用DINOv2-FiT3D而非VGGT作为教师，架构兼容性更好
3. **极简设计**：仅需一个轻量级projector和余弦损失，无需复杂架构修改
4. **零推理开销**：projector在推理时丢弃
5. **显著性能提升**：RoboTwin 2.0上平均67.5%（Easy）/ 30.7%（Hard），SOTA

### 实验结果

- RoboTwin 2.0 Easy: 67.5%（比OFT+SF高3.3%）
- RoboTwin 2.0 Hard: 30.7%（比OFT+SF高2.9%）
- 训练效率：10k步达到基线60k步的性能
- 数据效率：25%数据下仍比基线高10%
- 真实世界ALOHA：4个任务上持续提升

### 局限性

1. **依赖FiT3D教师**：教师质量直接影响对齐效果，需要高质量的多视角3DGS训练数据
2. **仅适用于DINOv2架构**：对于使用不同视觉编码器的VLA模型（如SigLIP-only），需要适配
3. **对齐层选择**：虽然避免了经验性层搜索，但选择倒数第二层仍是一个设计决策
4. **仅隐式空间**：不直接提供深度图或3D坐标等显式空间信息
5. **评估规模**：仿真评估仅在6个任务上，真实世界仅4个任务

### 与相关工作比较

| 方法 | 对齐位置 | 需要额外传感器 | 推理开销 | 几何可解释性 |
|------|---------|--------------|---------|-------------|
| Explicit (Depth) | 输入 | 是 | 高 | 高 |
| Spatial Forcing | LLM中间层 | 否 | 低 | 低 |
| ROCKET | LLM隐藏状态 | 否 | 低 | 低 |
| **VEGA** | **视觉编码器输出** | **否** | **零** | **高** |

## 个人评价

VEGA是一个优雅且实用的方法。核心洞察——在语言纠缠之前对齐视觉特征——简单但深刻。实验设计严谨，从特征可视化、训练效率、数据效率到消融实验，全面验证了方法有效性。特别值得注意的是λ=0.1的消融结果：过强的对齐监督（0.2）反而损害性能，说明空间信息注入需要与任务学习平衡。这暗示Spatial AGI中的空间感知和任务执行是两个需要协调的目标。

**评分**: 9/10（方法简洁、洞察深刻、实验全面）
