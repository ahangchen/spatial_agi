## 0. 一句话总结

TTL-SR 提出一个几何感知的测试时学习（Test-Time Learning）框架：利用几何一致性约束构造的辅助查询与自适应触发的伪标签，仅用无标注测试数据在线更新 VLM 参数，显著提升定量空间推理（距离/方向）在分布偏移下的鲁棒性。

---

## 1. 研究背景与动机

### 1.1 定量空间推理：VLM 空间智能的硬骨头

定量空间推理要求 VLM 从**单张 2D 图像 + 自然语言问题**推断 3D 空间中的：

- **距离**："桌上的杯子离盒子有多远？"
- **方向关系**："椅子在桌子的哪个方向？"

与定性的"左/右"判断不同，定量推理要求模型内化**相机几何、透视投影与尺度估计**——从 2D 投影反解 3D 度量。

### 1.2 两大痛点

1. **3D 监督昂贵**：定量标注需要深度传感器或人工度量，数据规模受限；
2. **分布偏移下脆弱**：新物体配置、新场景类型、换一种问法（rephrased query），模型预测就变得不一致甚至自相矛盾——同一对物体的两次提问给出冲突的距离排序。

**本质诊断**：模型学到的表示与底层几何**未对齐（misalignment）**——它在拟合数据集中的表面模式，而非投影几何本身。

### 1.3 为什么选测试时学习（Test-Time Learning）？

- 目标域无标注是常态（新机器人场景、新室内环境）；
- 重新收集 3D 标注成本不可接受；
- 测试数据虽然无标签，但**几何本身提供了免费的监督信号**——这是 TTL-SR 的核心洞察。

## 2. 核心方法

### 2.1 框架概览（三步）

```
Test Image + Query
   ↓
① 几何耦合辅助查询生成（Geometrically Coupled Auxiliary Queries）
   ↓
② 自适应几何触发 + 可靠预测过滤 → 结构化 token 级伪标签
   ↓
③ 几何感知多目标损失 → 仅用测试数据更新参数
```

### 2.2 几何耦合辅助查询

对原始查询 Q（如"A 到 B 的距离"），自动生成与同一几何事实耦合的辅助查询：

- **反向查询**："B 到 A 的距离？"（答案必须对称）
- **序数查询**："A 离相机比 B 近吗？"（与距离数值一致）
- **方向查询**："B 在 A 的什么方向？"（与相对位置一致）

这些查询的答案**必须相互一致**，因为它们由同一个 3D 几何事实决定。一致性约束把"无标注测试样本"变成"自带约束的自监督样本"。

### 2.3 自适应几何触发（Adaptive Geometric Triggering）

并非所有测试样本都值得学习：

- 用模型自身对辅助查询族的预测**一致性**作为置信度信号；
- 只有一致性达标（预测彼此不矛盾）的样本才进入伪标签构造；
- 避免把模型的幻觉当监督信号放大（防止 confirmation bias 的自我强化）。

### 2.4 结构化 token 级伪标签

- 空间推理的答案通常是短结构化输出（数字 + 单位 / 方向词）；
- 伪标签在 token 级别构造：对高置信 token 直接采用，对不确定 token 用几何约束推断了候选集合约束其分布；
- 相比序列级伪标签，减少错误传播。

### 2.5 几何感知多目标损失

联合优化：

1. 主查询的伪标签交叉熵；
2. 辅助查询间的一致性损失（对称性/序数/方向约束）；
3. 参数正则项（防止灾难性遗忘源域知识）。

## 3. 实验结果

- **Q-Spatial-ScanNet** 数据集上：
  - Qwen3-VL-4B-Instruct：**+6.47%** 准确率；
  - SpatialRGPT-VILA-1.5-8B：**+9.41%** 准确率；
- 均为**纯测试时适应**，不接触任何目标域标注、不修改训练数据；
- ACM MM 2026 接收，方法与两个主流开源 VLM 即插即用。

## 4. 三个核心问题

### 4.1 Q1: 核心算法/技术方案是什么？

几何一致性作为免费监督 + 置信度门控的自训练：

1. 用查询变换生成几何耦合的辅助查询族；
2. 用预测一致性作为可靠性过滤器（adaptive triggering）；
3. token 级伪标签 + 多目标损失做测试时参数更新。

**与 TTA（test-time adaptation）经典方法的关系**：经典 TTA 用熵最小化或自监督旋转预测等通用信号；TTL-SR 的信号是**领域特有的几何公理**（距离对称性、序数单调性、方向一致性），信号更强、更不易退化为平凡解。

### 4.2 Q2: 与 Spatial AGI 的关系是什么？

1. **几何对齐是空间智能的核心命题**：TTL-SR 直接攻击"表示-几何 misalignment"，与 Spatial AGI 追求的"内在 3D 理解"同源；
2. **无标注自适应 = 部署可行性**：真实机器人场景永远存在 domain gap，能在部署时用无标注数据自我校准空间能力的模型才有实用价值——与今天的 SyncWorld 形成"动力学层校准 vs 语义层校准"的对偶；
3. **一致性作为空间理解的试金石**：一个真正理解 3D 几何的模型应该在任何等价问法下给出一致答案。TTL-SR 把这一哲学变成可优化的损失；
4. **为空间基准提供新评测维度**：除了 accuracy，还应报告"几何一致性率"（等价查询族的答案一致比例）。

### 4.3 Q3: 创新点与局限是什么？

**创新点**：
1. 首个针对定量空间推理的几何感知测试时学习框架；
2. 几何公理 → 自监督信号的系统化转换（对称/序数/方向三族约束）；
3. 自适应触发机制防止不可靠伪标签污染；
4. token 级伪标签贴合空间答案的结构化特性。

**局限**：
1. 依赖模型已有"够用"的几何能力——初始一致性太差的样本被全部过滤，最需要改进的场景（大幅偏移）反而学不到；
2. 辅助查询族是人工设计的，覆盖的几何公理有限（未含遮挡推理、多物体传递性 A<B, B<C ⇒ A<C 等）；
3. 每个新域需要在线更新参数，有计算与灾难性遗忘成本；参数更新 vs prompt/上下文适应的权衡未讨论；
4. 评测集中于室内 ScanNet 系，室外/大尺度空间（街景、航拍）的度量分布不同，未验证；
5. 答案离散化（bucketed distance）设定下有效，连续回归式空间输出未覆盖。

## 5. 与相关工作的对比

| 工作 | 适应信号 | 需要标注? | 更新方式 |
|---|---|---|---|
| 标准空间微调 | 3D 标注 | 是 | 离线训练 |
| SpatialVLM/RGPT 蒸馏 | 大模型生成标注 | 间接 | 离线训练 |
| Prompt/CoT 空间推理 | 无参数更新 | 否 | 推理时 |
| TTL-SR | 几何一致性公理 | 否 | 测试时参数更新 |

与今日 SyncWorld 的对偶关系尤其值得记录：

- **SyncWorld**：用校准回合在**上下文**中适配"动作→像素"的动力学映射；
- **TTL-SR**：用几何一致性在**参数**中适配"像素→度量"的语义映射；
- 两者共同指向一个趋势：**Spatial AGI 的泛化正在从"更多训练数据"转向"更聪明的适应协议"**。

## 6. 个人思考与启发

### 6.1 几何是空间智能领域"免费的标签"

物理世界受几何公理约束，等价查询必然等价回答——这是任何数据集都不需要标注就自带的监督。TTL-SR 只是挖了三族最简单的公理；完整版应该是"几何公理驱动的自训练体系"：传递性、遮挡单调性、透视交叉比不变性……空间推理可能是 TTA 最有结构性红利的领域。

### 6.2 一致性应该成为一等评测指标

今天的空间基准（Q-Spatial、SpatialRGPT-Bench 等）几乎都报单次问答准确率。但如果模型对"A 比 B 近"与"A 比 B 远"给出矛盾答案，两个各对一半的模型与一个全错的模型在准确率上可能无法区分。建议后续 Spatial AGI 评测体系中加入 Consistency-under-equivalence 指标。

### 6.3 测试时学习 vs 上下文学习的分岔

SyncWorld 选择上下文（不更新参数，零遗忘风险），TTL-SR 选择参数更新（效果强但有遗忘风险）。一个自然的综合：把几何一致性约束蒸馏成"空间校准 prompt / 轻量 adapter"，在上下文与参数之间找中间态。
