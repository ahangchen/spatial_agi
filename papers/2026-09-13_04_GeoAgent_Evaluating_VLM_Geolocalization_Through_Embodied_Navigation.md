## 一句话总结

GeoAgent 把"视觉地理定位"从静态单图分类改造成**具身导航任务**：VLM agent 在 1200 个可导航的 Google Street View 环境（100 个城市、发达/发展中地区分层）中通过 9 种工具调用主动探索（移动/旋转），在 8 步动作预算内迭代修正地理猜测——揭示出 VLM"确认强、纠错弱"的序列推理缺陷、50-103% 的发达地区偏差，以及目标导向探索相对随机游走 466-1079 km 的距离优势。

## 核心问题

### Q1: 这篇文章的核心算法原理是什么？

#### 1. 核心思想和动机

**(a) 任务背景**

视觉地理定位在灾难响应（GPS 元数据被剥离/伪造时定位地面照片）、OSINT 事实核查、自主导航、位置隐私研究中有重要应用。现有评测几乎全是**静态单图**任务（PIGEON 的分类、GeoReasoner/GLOBE/Geo-R1 的 VLM 推理、IMAGEO-Bench/FairLocator 的偏差评测），GAMa 用视频但仍是被动观察。

**(b) 核心论点**

被动推理测的是**识别**，不是**不确定性下的推理**。人类玩家玩 GeoGuessr 的方式是主动探索环境——走到下一个街角看路牌、转向看建筑风格、寻找信息增益最大的视角。Embodied navigation 让 agent 通过移动/旋转主动最大化信息增益，才是对任务的忠实重建。

**(c) 三个研究问题**

- RQ1：主动探索能否提升定位精度？提升是否依赖于初始假设的正确性？
- RQ2：前沿 VLM 是否存在发达/发展中地区的系统性地理偏差？
- RQ3：不同架构的探索策略有何差异？动作效率与任务性能相关吗？

#### 2. 主要技术方法

**(a) 任务形式化**

- **Round**：一个出生点的一次完整评测实例；
- **Action**：一个完整 agent 回合 = 渲染视口截图 → 模型调用返回结构化 JSON（含工具调用）→ 执行；
- **动作预算**：8 步（原则性选择：附录 B 显示平均 Haversine 距离在第 5 步后平台化甚至退化；无限预算不提升性能反而放大确认偏误、推高 API 成本）；
- **GUESS**：终止动作，消耗一个动作名额；预算耗尽强制以当前最佳猜测终止。整个设定是"猜测修正过程"（guess refinement procedure）。

**(b) 环境与数据**

- 可导航网页界面（模拟 OpenGuessr，基于 Google Street View），9 种工具调用（移动、旋转、GUESS 等，Table 2）；
- 数据构造：按 UNCTAD 发达/发展中分类 + 年游客量分层（Tier 1=纽约/巴黎，Tier 5=Butare 卢旺达/Imphal 印度）选 100 城市；每城市在已知坐标 2 英里半径内随机采样 100 个经纬度对（Google Geocoding API），剔除无 Street View 的坐标，最终保留 **1200 样本**；
- 随机化采样点保证任务抗"模式匹配/训练数据背诵"，强制细粒度地理推理。

**(c) 评测指标**

1. **地理空间距离**：预测与真值的大圆（Haversine）距离，同时报告均值与中位数（分布被灾难性失败严重偏斜）；
2. **改进率**：improvement_k = (1 - d_k/d_1) × 100，量化从初始猜测到第 k 步的改善；按最终城市猜测正确/错误分层分析；
3. **TF-IDF 词汇分析**：按国家拼接全部观察+推理文本（unigram+bigram，去停用词，max_df=0.95），提取各国特征词汇，分析模型的视觉线索词汇与跨模态词汇重叠。

**(d) 基线体系（设计精巧）**

- **4-view / 8-view 静态基线**：把 0°/90°/180°/270°（+前进一格后再一圈）拼接成单图直接推理；
- **Random Baseline**：均匀随机经纬度，零动作，仅作下界；
- **Random Walk**：同样 8 步预算、同样看到所有渲染视口、同样产出最终猜测，但动作完全随机——**固定视觉覆盖与推理预算，剥离目标导向动作选择的贡献**；
- **Unlimited-step agent**：去掉 8 步上限，测试预算效应；
- **人类参考点**：6 名志愿者（GeoGuessr 新手-中级）在分层子集上完成 380 轮（人均中位距离 1720-3751 km，方差大）。

**(e) 被测模型**

Gemma 3 27B、Llama 4 Scout 109B、Claude Haiku 4.5、Gemini 3.0 Flash、GPT-5 Mini（temperature 0.3）+ 专用空间推理模型 Geo-R1 7B（RTX 5070 Ti 本地）。

#### 3. 算法流程和关键步骤

```
spawn 于随机 Street View 点
  ↓
循环 ≤ 8 步 {
  渲染当前视口截图
  VLM 调用 → 结构化 JSON: 观察 + 推理 + 工具调用(MOVE/ROTATE/…)
  执行工具调用（更新视角/位置）
}
  ↓
GUESS(经纬度) 或预算耗尽强制猜测
  ↓
计算 Haversine 距离 + 分层分析（正误 / 发展程度 / Tier）
```

#### 4. 输入输出

- **输入**：Street View 视口截图序列 + 9 工具接口；
- **输出**：逐步的观察/推理轨迹 + 最终经纬度猜测；评测输出 Haversine 距离、分层精度、行为统计、TF-IDF 词汇。

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

#### 1. 如何理解和表示空间

GeoAgent 对空间智能的贡献是把"空间理解"重新定义为**主动信息获取过程**：

- 传统评测中，空间理解 = 给定视图推断空间属性（识别范式）；
- GeoAgent 中，空间理解 = 在不确定下**选择收集哪些空间证据**（决策范式）。移动和旋转不是导航目标，而是**信息增益动作**——agent 的空间表征必须动态整合多视角证据并维护一个可修正的地理假设。

这揭示空间智能的一个深层结构：**空间认知 = 假设 + 证据获取策略 + 贝叶式更新**。VLM 们的失败模式（初始假设错误后无法修正）恰好发生在第三环——它们擅长生成假设（大洲/国家级正确率 52-89%），但缺乏用新证据做假设空间重排序的能力。

另一个精妙处：任务的环境是**真实世界**（Street View），其空间线索（植被、 driving side、路牌语言、电线杆形状、trams、gingko 树）是 web 语料的投影。这使评测同时测出"模型的世界知识分布"——发达地区偏差本质是训练数据的空间分布偏差，而非感知能力差异（作者排除了图像质量因素）。

#### 2. 如何处理空间关系

- **视角-内容依赖关系**：路牌、店铺名等"last-mile"线索只在特定视角/位置可见——空间关系（我在哪→看向哪→能看见什么）决定信息可得性。Random Walk 对照干净地证明：同样的视觉信息预算下，**选择看哪里**贡献了 466-1079 km 的距离优势。
- **地理空间的层级结构**：大洲→国家→城市→街道的定位精度梯度（GPT-5 Mini: 88.6%→81.2%→34.5%）表明 VLM 的空间知识是分层组织的，宏观线索（气候、植被、行驶方向）支撑高层定位，市政基础设施/本地商业招牌/地区建筑变体支撑低层定位——后者显著薄弱。
- **探索-假设耦合**：行动序列与假设演化交织。Llama 4 Scout 的病态行为（7.55 步中 6.14 步是原地旋转）展示了空间搜索策略的失败模式——信息增益最大化的动作（前进到新街区）被低增益动作（原地转圈）替代。

#### 3. 对 Spatial AGI 有什么启发

1. **具身评测范式**：GeoAgent 与 NavArena 共同确立了一个趋势——空间能力评测正在从静态输入走向"环境+动作空间+预算"的具身闭环。任何 Spatial AGI 能力声明都应该在"可以主动看"的条件下重新检验。
2. **确认偏误是空间智能的核心缺陷**：初始假设错误后额外探索几乎无法恢复（初始距离中位数：成功轮 847 km vs 失败轮 2341 km；logistic 回归 β=-0.43, p<0.001）——探索在"精炼合理假设"而非"重新发现"。Spatial AGI 系统需要显式的假设重生成机制（如刻意寻找反驳证据的 falsification 策略），而非更多的同质观察。
3. **动作预算是评测变量**：8 步预算的设计及"无限预算不增益"的发现提示：空间智能的评测必须控制信息获取预算，无限探索的绝对性能无意义。
4. **地理偏差是 Spatial AGI 的公平性问题**：50-103% 的距离偏差（developed vs developing）+ 具体机制（Mozambique 67%、Thailand 54% 高误分类国家在推理链中完全没有国家特定词汇——模型退回通用区域描述符）。空间智能系统的部署（灾难响应恰恰多发生在发展中地区！）必须审计这种偏差。

#### 4. 可以应用的 Spatial AGI 场景

- **空间能力评测基建**：可导航环境+工具调用+预算 的评测模板可推广到任何空间推理任务（室内搜索、巡检、导航）；
- **灾难响应**：GPS 剥离图像的地面定位；
- **OSINT/事实核查**：照片来源地验证；
- **位置隐私审计**：理解模型的定位能力边界以设计防护；
- **agent 探索策略研究**：Random Walk/agentic 差值分析方法可用于任何主动感知任务。

### Q3: 基于前面的分析，这个方法的主要创新点和局限性是什么？

#### 1. 主要创新点

1. **任务范式创新**：首个把地理定位重构为"Street View 具身导航 + 序列推理"的 agentic benchmark，区分"识别"与"不确定性下的推理"。
2. **严谨的因果剥离设计**：Random Walk 基线（同预算同视觉覆盖、仅去掉目标导向动作选择）+ unlimited 预算条件 + 人类参考点，使"探索的贡献"可被因果量化。
3. **数据工程的抗作弊设计**：城市坐标 2 英里内随机采样，抵抗训练数据背诵与模式匹配；发达/发展中 × 5 个可识别性 Tier 的双维度分层，使偏差与难度分析正交。
4. **多维诊断体系**：Haversine（均值+中位数）+ 分层精度（大洲/国家/城市）+ 逐步改进率 + 探索行为统计（动作数/moves/rotations/invalid）+ TF-IDF 推理词汇分析——从行为到语言的多切面诊断。
5. **三项重要发现**： 确认偏误（错误初始假设不可恢复，β=-0.43）； 系统性发达地区偏差（距离差 50-103%，且排除图像质量因素）； 探索行为与架构强相关（GPT-5 Mini 高效 4.94 步 vs Llama 4 Scout 原地打转 6.14 次旋转），而"动作效率与性能相关"。

#### 2. 主要局限性

1. **环境保真度受限**：Google Street View 覆盖不均（发展中地区数据较新但覆盖稀疏）、采样后 10000 坐标只剩 1200 可用（88% 淘汰率），数据本身的空间分布不均衡可能影响结论外推。
2. **8 步预算的原则性但任意**：budget 选择基于 plateau 观察，但"第 5 步后平台化"本身可能是当前模型行为而非任务本性——更强的 agent 或许能从更多步中获益。
3. **人类参考点薄弱**：6 名志愿者、380 轮、方差巨大（1720-3751 km），"VLM 超越人类基线"的声明只对非专家成立。
4. **单一任务域**：结论（确认偏误、偏差、探索策略）在多大程度上推广到其他空间任务（室内导航、操纵）未知。
5. **无干预实验**：观察确认偏误但未测试缓解手段（如强制假设重生成、falsification prompt、多假设并行维护）——诊断强、处方缺。
6. **成本问题**：agentic 评测的 API 成本显著高于静态（附录 G），大规模复评的可持续性存疑。

#### 3. 与其他相关工作的对比

| 工作 | 输入 | 交互 | 发现 |
|---|---|---|---|
| PIGEON (2024) | 静态图 | 无 | geocell 分类 SOTA |
| GeoReasoner / GLOBE / Geo-R1 | 静态图 | 无 | VLM 推理链/局部化评估/RL 空间思维 |
| GAMa (2022) | 视频 | 被动 | 跨视角定位 |
| IMAGEO-Bench / FairLocator | 静态图 | 无 | 地理偏差评测 |
| WebArena / Mind2Web | 网页 DOM | 2D 语义空间 | agent 长程任务 |
| NAVIG / GeoComp | 静态图+工具 | 地图检索等，物理静止 | geo-agent 雏形 |
| **GeoAgent** | **可导航 Street View** | **具身 3D 探索+预算** | 探索增益/确认偏误/地理偏差 |

**优势**：唯一在"可行动、可预算、可归因"设定下评测地理空间智能的工作。
**劣势**：单一任务域，静态基线的拼接视图（4/8 view）可能低估静态方法上限（真正的静态 SOTA 如 PIGEON 系未对比）。

## 核心技术发现

1. **探索有效但条件性**：所有工具调用正常的模型 agentic 优于 random walk 466-1079 km；Gemini 3.0 Flash 城市精度从 4-view 39.5% → agentic 50.1%（相对提升 26.8%）。但探索的价值取决于初始假设质量——初始距离中位数成功轮 847 km vs 失败轮 2341 km。
2. **确认偏误的定量刻画**：错误猜测的轮次中，更多探索几乎不改善（Gemini 3.0 Flash 甚至在第 5 步后指数退化）；无限预算不能恢复（放大确认偏误）。Claude Haiku 4.5 最"镇定"（探索既不增益也不恶化）。
3. **发达地区偏差 50-103%**：所有模型 mean distance 差距显著；Gemini 3.0 Flash 国家精度差 -25.9%；developing 地区探索时 rotation-to-move 比更高（2.1:1 vs 1.4:1）——模型在不确定环境下"原地打转"。
4. **探索策略的架构指纹**：GPT-5 Mini 4.94 步高效完成（move 2.42/rotate 1.51）；Llama 4 Scout 7.55 步但 6.14 是旋转（原地扫描）；Geo-R1 7B 完全失效（87.3% 无效工具调用，从不导航，agentic 反而比 random walk 差 144 km）。
5. **词汇诊断**：模型共享 36.6-52.7% 高频词汇（LLM 特性而非框架 artifact）；正确调用视觉描述符但映射错误结论（东南亚"热带植被/旧基础设施/摩托车流"→错国家）；高误分类国家（Mozambique 67%）推理链中零国家特定词汇。
6. **语义混淆的地理结构**：泰国被误判为越南 23%、反之 18%——错误聚类在视觉相似区域。

## 与 Spatial AGI 的关系

### 直接贡献
建立了"具身化空间能力评测"的新范式与可复用环境，并给出空间智能体三大行为缺陷的定量证据：确认偏误、地理偏差、低效探索策略。

### 技术启发
- 评测设计模板：可导航环境 + 工具调用 + 动作预算 + random-walk 因果对照；
- 假设修正视角：空间推理 = 假设维护 + 证据获取策略，失败常在后者；
- 偏差审计：空间智能系统上线前应做地理/区域分层评测。

### 应用场景
空间能力评测基建、灾难响应定位、OSINT 核查、位置隐私、主动感知策略研究。

## 个人思考

### 最令人兴奋的发现

"确认偏误不可恢复"是我认为全文最重要的发现：VLM 不是"看得不够多"，而是**不会因为新证据放弃旧假设**。logistic 回归那个 β=-0.43 的含义是：探索的价值几乎完全由第一眼判断决定——这与人类认知的 anchoring bias 惊人相似，暗示 VLM 的序列推理在结构上继承了同样的认知缺陷。这给 Spatial AGI 的启示非常具体：与其给 agent 更多步数，不如设计强制假设多样性的机制（并行维护 top-k 假设、专门寻找反驳证据的动作、定期"假设重启"）。另一个精彩细节是高误分类国家"零特定词汇"——失败不是因为看错，而是因为**没有可以描述它的词**，这是训练数据分布的空洞在推理链上的直接投影。

### 潜在局限

Street View 环境的探索动作空间其实很贫乏（前进/旋转），与真实空间探索（蹲下看细节、走近看纹理）相距甚远；8 步上限可能截断了更强探索策略的能力区间。另外 Random Walk 对照虽好，但"同预算随机看"并不是信息论最优的被动基线——一个精心设计的固定全景采样可能比 random walk 强，从而使 agentic 增益的归因略微保守。人类基线的方差过大，"超越人类"的表述需要限定为"超越非专家业余玩家"。

### 与近期研究的关联

- 与 NavArena（今日论文1）同属"具身化空间评测"趋势：NavArena 评测导航策略（几何空间），GeoAgent 评测地理推理（语义-地理空间），共同确立了"环境+动作+预算+闭环"的评测范式；
- 与 SpatialBlock、MV-STRIDE、GraFT 等空间推理基准互补：那些测静态 3D 推理，GeoAgent 测主动 2.5D 探索推理；
- 确认偏误的发现与 MosaicThinker 等推理自校正工作形成呼应——空间与文本推理可能共享同样的自校正缺陷，值得统一研究；
- 发达/发展中偏差延续了 IMAGEO-Bench、FairLocator 的地理公平性线索，并首次在具身设定下确认。

### 批判性思考

论文声明"developing 地区图像质量更高更新，偏差是模型行为 artifact"——论证严谨，但还有第三变量：Street View 的**覆盖密度**（发展中国家的可导航路径稀疏、拍摄频率低）会影响 agent 能探索到的线索总量，这与图像质量不同，且与模型行为无关。若 developing 样本的可探索信息总量更少，部分偏差应归因于环境而非模型。另外，模型们共享 36-53% 词汇这一点被归为"LLM 特定行为"，但它也可能反映所有模型共享相似的预训练语料——"架构指纹"的说法（探索行为差异）与"语料共性"（词汇重叠）之间的张力值得进一步拆解。

## 总结

### 核心发现总结

GeoAgent 把地理定位重构为 Street View 具身导航评测：1200 样本、9 工具、8 步预算、random-walk 因果对照。核心发现：(1) 主动探索显著提升定位精度（距离改善 466-1079 km，城市精度相对提升最高 26.8%），但增益严格依赖初始假设质量（β=-0.43）；(2) VLM 存在 50-103% 的发达地区距离偏差，机制是"缺乏国家特定视觉词汇时退回通用描述符"；(3) 探索策略是架构指纹，从 GPT-5 Mini 的高效移动到 Llama 4 Scout 的原地旋转到 Geo-R1 7B 的完全失效，动作选择质量直接决定成败。

### 对 Spatial AGI 的意义

GeoAgent 确立了空间智能评测的"具身三要素"——可行动环境、动作预算、因果对照——并暴露了当前 VLM 作为空间智能体的两个结构性缺陷：假设固化（确认偏误）与知识空间分布不均（地理偏差）。对 Spatial AGI 而言，下一步不是更大的模型，而是**假设管理机制**（多假设并行、反驳证据搜索）与**知识覆盖审计**（哪些空间区域在模型的世界模型里是空的）。

## 深度扩展分析

### 扩展一：确认偏误的认知科学与机器推理对照

论文的确认偏误发现可以放在更大的认知科学语境中审视：

| 认知现象 | 人类表现 | VLM 表现（本文） |
|---|---|---|
| 锚定效应 | 第一印象主导后续判断 | 初始猜测距离决定最终成败（β=-0.43） |
| 确认偏误 | 搜索支持已有信念的证据 | 探索在错误假设下不改善甚至恶化 |
| 信息茧房 | 只看符合观点的渠道 | 反复确认同一区域（rotations 集中） |
| 过度自信 | 错误时更坚持 | "错误轮次对额外探索不敏感" |

值得注意的是 Claude Haiku 4.5 的"镇定"：探索既不增益也不恶化——一种近似随机游走的行为。这提示一个反直觉的设计假说：**当假设管理机制缺失时，"目标导向"的探索可能比随机探索更危险**（因为会系统性强化错误）。空间智能体或许需要"元认知开关"：判断当前假设可信度，高则定向精炼，低则主动发散（生成竞争假设并寻找区分性证据）。

可操作的修复方向：
1. **多假设维护**：prompt/架构上强制保留 top-3 地理假设，每步观察需评估对每个假设的证据；
2. **区分性动作选择**：选择能最大化"假设间区分度"的观察动作（信息论式的 expected information gain）；
3. **定期假设重启**：每 N 步强制一次"从零重推"，对比新旧结论；
4. **反驳式 prompt**：在工具集中加入"寻找会证伪当前假设的视角"。

### 扩展二：地理偏差的成因分解

论文排除了图像质量因素，但偏差的可能来源仍可分解为：

```
观测偏差 d = d_developed - d_developing (50-103%)
  ├─ [A] 训练语料的空间分布偏差
  │    - 发展中地区街景/照片在 web 语料中占比低
  │    - 本地语言招牌的 OCR/理解弱
  │    - 区域特异性描述符缺失（Mozambique 零词汇证据）
  ├─ [B] 视觉相似性结构
  │    - 热带发展中国家互相混淆（泰↔越 23%/18%）
  │    - 发达国家视觉地标独特性高（巴黎/纽约辨识度天然高）
  ├─ [C] 探索行为交互
  │    - developing 地区 rotation:move = 2.1 vs 1.4
  │    - 不确定 → 原地打转 → 信息增益更低 → 恶性循环
  └─ [D] 环境覆盖密度（论文未充分排除）
       - Street View 在 developing 地区路径稀疏
       - 可探索信息总量可能更少
```

作者排除了 [D] 中的"图像质量"，但未排除"可探索路径长度/线索密度"。严谨的偏差归因需要控制每个样本的"可得信息量"。修复建议：对低资源地区做**针对性数据增强**（country-specific visual-textual pairs，作者亦提出）+ 偏差感知的评测门限（不同地区不同 SLO）。

### 扩展三：评测方法论的贡献细读

GeoAgent 的评测设计有三处值得 Spatial AGI 评测标准化时继承：

1. **Random Walk 因果对照**：在同预算、同视觉输入、同推理容量下剥离"动作选择"的贡献。这个设计可移植到任何主动感知任务（主动物体识别、主动建图）——比较"策略选择的观察序列"与"随机观察序列"的性能差。
2. **动作预算的平台化分析**：先画"性能 vs 步数"曲线，选平台点为预算。这防止"无限预算刷分"与"预算过小测不出差异"两种失真。
3. **行为-语言双通道诊断**：动作统计（moves/rotations/invalid）刻画"怎么做"，TF-IDF 词汇刻画"怎么想"。空间智能评测应同时报两者的指纹。

一个可以补强的设计：**oracle 对照**——给模型"每步最优视角"的专家演示，测模型模仿能力上限；以及**反事实提示**——显式告知模型当前假设错误，观察其重规划能力。这两个对照能进一步分离"策略能力"与"修正能力"。

### 扩展四：模型行为类型学

综合结果可以把被测模型归为四种空间智能体类型：

| 类型 | 模型 | 特征 | 病灶 |
|---|---|---|---|
| 高效定向型 | GPT-5 Mini | 少步、多移动、最强距离精度 | 城市级 last-mile 仍弱 |
| 全面但动摇型 | Gemini 3.0 Flash | 城市精度最高、agentic 增益大 | 错误假设下第5步后崩塌；发达偏差最大 |
| 保守打转型 | Llama 4 Scout / Claude Haiku | 高步数、旋转为主/低效 | 信息增益低；Haiku 甚至低于人类均值 |
| 失效型 | Geo-R1 7B | 87.3% 无效工具调用 | 静态推理能力无法迁移到 agentic 设定 |

最深刻的教训来自 Geo-R1：**静态空间推理的专家 ≠ 空间智能体**。专用 RL 训练的空间思维在需要工具调用与环境交互的设定下完全失效——空间智能的"agent 能力"（接口可靠性、动作空间合规）是独立于"推理能力"的一等技能。这对所有"用静态 benchmark 刷分的空间模型"是当头一棒。

### 扩展五：与 NavArena 评测哲学的对照

两篇今日论文都是具身评测，但设计取舍不同：

| 维度 | NavArena | GeoAgent |
|---|---|---|
| 空间尺度 | 室内/建筑（米级） | 地理（公里-大洲级） |
| 被测能力 | 导航策略执行 | 地理知识+探索推理 |
| 环境来源 | 3DGS 重建资产 | 真实 Street View |
| 动作空间 | SE(2) 导航命令 | 网页工具调用（移动/旋转） |
| 成功判据 | 到达/对准/停止 | 坐标距离 |
| 对照设计 | 多协议终止敏感性 | random-walk 因果剥离 |
| 规模 | 2000+ 场景 / 22.2M 轨迹 | 1200 样本 |
| 领域偏差审计 | 无 | 发达/发展中偏差（核心） |

互补的启示：Spatial AGI 评测的完整矩阵应同时覆盖"米级执行能力"（NavArena 式）与"地球尺度知识推理"（GeoAgent 式），且都应内置偏差审计（NavArena 缺失的一环——其对场景来源（发达地区为主的艺术场景+重建）的偏差同样值得审计）。

### 扩展六：可复用工程要点备忘

- 可导航评测环境的最小组件：渲染视口 + 工具表 + 结构化 JSON 返回 + 预算控制器 + 强制终止机制；
- Random Walk 对照：同预算同输入仅随机化动作，是主动感知评测的标配对照；
- 预算选择：先做步数-性能曲线，取平台点；
- 指标：偏斜分布的距离类指标必须同时报均值与中位数；
- 词汇诊断：TF-IDF（unigram+bigram，max_df=0.95）按类别拼接推理文本，是廉价有效的推理内容审计工具；
- 温度 0.3：agentic 评测中平衡确定性与多样性的常见选择。

## 附录 G：关键公式速记

### G.1 Haversine 大圆距离

```
a = sin²(Δφ/2) + cos(φ₁)·cos(φ₂)·sin²(Δλ/2)
c = 2·arctan2(√a, √(1−a))
d = R·c,  R = 6371 km
```

### G.2 改进率

## 附录 H：结果读数的三点提醒

1. **中位数 vs 均值的巨大裂口**（Gemini：中位 5 km vs 均值 1099 km）说明分布极度双峰——大量"猜对附近"与少量"完全失败"共存。单看任何一项都会误判。
2. **城市精度 14.3-50.1% vs 国家 52.4-81.2%** 的断层就是"last-mile localization"问题的直接量化：宏观线索充足、市政级线索缺失。
3. **Geo-R1 的 87.3% 无效调用率**提醒：任何 agentic 评测必须先检查接口合规性，否则测的是"模型会不会用工具"而不是"空间推理好不好"——两个混淆变量必须解耦。
