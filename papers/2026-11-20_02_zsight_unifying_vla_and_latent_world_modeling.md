# $Z$-sight: Unifying Vision-Language-Action and Latent World Modeling

## 一句话总结

$Z$-sight 是一个统一的机器人基础模型：它让 VLA 策略**在自己 VLM 的原生视觉 token 空间里直接预测未来**（foresight expert 通过 flow matching 去噪未来 spatial tokens），并与连续动作专家（action expert）在 mixture-of-transformers 中**联合去噪**，从而在不引入视频生成器或外部冻结编码器的前提下，把"世界模型"嫁接进策略本体——SIMPLE 81.9%（+9.6），Unitree G1 真机六任务 73.3%（+20.0），每 chunk 仅 110ms。

## 核心问题

### Q1: 核心算法原理是什么？

**问题**: 这篇文章的核心算法原理是什么？请详细描述：1) 核心思想和动机，2) 主要技术方法，3) 算法流程和关键步骤，4) 输入输出。

**分析**:

1. **核心思想和动机**

   当前"让机器人策略拥有世界模型"的三条路线各有缺陷：
   - **VLA 模型**（π0、GR00T 等）：VLM + 连续动作专家，靠互联网级多模态预训练获得语义推理能力，但监督信号只有动作标签，稀疏，对世界动态没有显式建模；
   - **世界动作模型 WAM**（基于视频生成器）：联合预测未来视频+动作，物理动态丰富，但背着庞大的视频扩散骨干，推理昂贵；
   - **潜在空间策略**：避免像素生成，但要么只是把策略内部激活"对齐"到紧凑的未来嵌入（隐式对齐，不生成未来流），要么预测**冻结外部目标编码器**（V-JEPA 2、SigLIP）的特征——未来预测与 VLM 自己的感知空间是解耦的。

   $Z$-sight 的核心主张：**未来应该在策略感知当下的同一个表示空间里被预测**（"predicts the future directly in the visual token space in which its VLM perceives the present"）。这样感知与预测全程对齐，动作专家可以直接"读"正在成形的未来预测，不需要像素解码，也不需要外部教师。

2. **主要技术方法**

   架构是 mixture-of-transformers（MoT），四个流：
   - **VLM 流**: 视觉编码器 E_φ 把观测编码为 P 个 spatial tokens（native representation space），处理指令、本体状态、观测历史，用离散 FAST 动作 token 监督（L_FAST）；
   - **Foresight expert（前瞻专家）**: 通过 flow matching 在 token 空间去噪**未来 spatial tokens**，目标是对同一视觉编码器的 **EMA teacher** 输出（L_view）；
   - **Action expert（动作专家）**: 条件 flow matching 生成连续动作块（L_flow），注意力可以直接访问 foresight 流的预测特征；
   - **因果视频编码器 V_φ**: 按 MEM 方式把单帧编码器扩展为无参数因果时间注意力（每第4个 ViT block 用 causal temporal attention + spatial attention 替换 frame-wise attention），只传最后一帧的 P 个 token 给 VLM（保持单图 token 预算），多相机用可学习的 view-role embedding 区分。

   防坍缩与防遗忘的双保险：
   - **stop-gradient EMA targets**: 未来目标 z+_t = LN(sg[V_φ̄(O+_t)])，EMA teacher 随在线编码器演化但不允许编码器"作弊"式坍缩自己的预测目标（I-JEPA 式）；
   - **梯度阻断**: L_view 的梯度全程不进 VLM；mid-training 阶段专家随机初始化时用完全知识隔热（knowledge insulation），专家只能经 stop-gradient 读 VLM 的 keys/values，VLM 靠自回归 FAST token 适应。

3. **算法流程和关键步骤**

   - **训练三阶段**：
     1. **Pre-training（人类视频）**: 只训 VLM + L_FAST，约 2000 小时自我中心人类视频（EgoDex + EgoVerse）。手部轨迹转到当前帧坐标系（剥离头部运动）、低置信关节掩码、有效性加权时序高斯平滑 FAST token；
     2. **Mid-training（跨本体混合）**: 引入 foresight + action 专家，优化 L_FAST + L_flow + λ_v·L_view，约 2750 小时机器人数据（AgiBot World + Humanoid Everyday）+ 20% 人类数据回放。人类手和人形机器人用 48 维任务空间手部表示，其他机器人用末端位姿，动作相对当前状态表示、块内 padding + 每通道有效性掩码；
     3. **Post-training（目标本体）**: 目标机器人演示上去掉 L_FAST，专注 L_flow + L_view 微调。
   - **联合去噪推理**: FAST token 省略；VLM prefix 编码一次并缓存 KV；foresight 与 action 两个流从纯噪声出发，σ=τ，用 K 个共享 Euler 步**单次前向同时更新两流**（式 7）：动作流走速度场，未来流走 token 去噪——动作生成过程中实时"看到"正在成形的未来。
   - **噪声耦合训练技巧**: 训练时采样 σ = max(τ, u) ≥ τ（u 为随机下限），让动作专家在训练中见识不同不确定度的未来流。

4. **输入输出**

   - **输入**: 语言指令 ℓ、本体感知状态 s_t、多相机观测历史 O_t（经因果视频编码器）；
   - **输出**: 动作块 A_t = (a_t, …, a_{t+H−1})（连续动作，110ms/chunk），内部附带未来 spatial tokens 的潜在预测（不解码为像素）；
   - **训练时的额外监督**: 块内未来观测 O+_t（测试时不可得）作为 L_view 的目标。

**关键结果**: SIMPLE（人形 loco-manipulation）81.9%（最强基线 +9.6）；Unitree G1 六个真机任务 73.3%（+20.0）；LIBERO/RoboTwin 2.0 桌面任务保持竞争力；110ms 每 chunk。

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**问题**: 这篇文章与通用空间智能（Spatial AGI）有什么关系？请分析：1) 如何理解和表示空间，2) 如何处理空间关系，3) 对Spatial AGI有什么启发，4) 可以应用到哪些Spatial AGI场景。

**分析**:

1. **如何理解和表示空间**

   $Z$-sight 的空间表示是 **VLM 原生视觉 token 空间中的 dense spatial tokens**：
   - 每帧观测被编码为 P×D 的 token 矩阵，保留了场景的空间布局（论文强调"This preserves the spatial layout of the scene"）；
   - 未来被表示为"同一编码器将对未来观测产生的 tokens"——空间预测与空间感知共用一套坐标系，这是本文最重要的表示学决策；
   - 因果视频编码器让 token 序列携带时间维度（运动线索），多相机 token 带 view-role——空间 + 时间 + 多视角统一在一个 token 流里。

2. **如何处理空间关系**

   - **感知-预测闭环**: 动作专家在读"正在去噪的未来 tokens"时，等于在推理过程中实时进行空间想象——"如果我执行这组动作，场景会变成什么样"，并据此修正动作；
   - **运动学空间**: 48 维任务空间手部表示、末端位姿相对表示，都是把动作空间规约到任务相关的空间坐标系（剥离头部运动=换到自我中心坐标系）；
   - **跨本体空间对齐**: 不同机器人（单臂/双臂/人形）的动作被统一到共享维度 + 有效性掩码，本质是跨具身的空间动作语法。

3. **对Spatial AGI的启发**

   - **感知与预测必须同空间**: 这是本文对 Spatial AGI 最锋利的一个论点。如果空间预测发生在一个外部冻结编码器（V-JEPA 2）的特征空间里，而感知发生在 VLM 的 token 空间里，两者的"空间"就不是同一个空间——预测无法直接指导感知驱动的行动。Spatial AGI 的空间想象模块应该内生于其感知表示；
   - **潜在空间世界模型的代价-能力折中**: 像素级 WAM 能力最强但昂贵，隐式对齐最廉价但能力弱，$Z$-sight 的"原生空间联合去噪"提供了一个中间点：有生成式的未来流（可被动作读取、可做测试时干预分析），又没有像素解码开销（110ms）。这个折中设计对具身 Spatial AGI 的实时性要求（机器人控制频率）至关重要；
   - **EMA teacher 的共演化目标**: 目标空间随感知能力一起成长，避免了冻结教师造成的表示天花板。长期运行的 Spatial AGI 的空间记忆/预测模块同样需要"目标跟着表征走"的机制；
   - **数据配方的空间意义**: 2000h 人类自我中心视频 → 2750h 跨本体机器人数据 → 目标本体微调，说明空间操作知识可以从人类视频（观察空间中的手如何移动物体）迁移到任意具身形态——空间智能的具身无关性假说的又一证据。

4. **可以应用的Spatial AGI场景**

   - **人形机器人通用操作**（论文的直接场景）：loco-manipulation 需要同时推理全身移动与手部操作的空间后果；
   - **空间想象驱动的规划**: foresight 流的去噪中间态可以做测试时干预（论文用 intervention 验证了未来预测对动作的因果作用），可发展为"在 token 空间 rollout 多个未来再选优"的规划器；
   - **跨具身空间技能库**: 人类视频预训练 + 跨本体 mid-training 的配方可推广为"看人类视频学空间操作"的通用流水线；
   - **世界模型蒸馏**: 原生空间预测可作为大型视频世界模型（WAM）的廉价学生头，让视频世界模型的物理知识以 110ms 的代价进入控制回路。

### Q3: 主要创新点和局限性是什么？

**问题**: 基于前面的分析，这个方法的主要创新点和局限性是什么？与其他相关工作相比有什么优势和劣势？

**分析**:

1. **主要创新点**

   - **原生表示空间中的未来预测**: 第一个把"未来+动作联合生成"完整搬进 VLM 自身视觉 token 空间的统一模型——既不是像素（WAM），也不是外部冻结特征（DreamVLA/VLA-JEPA/UniJEPA），也不是隐式激活对齐；
   - **MoT 双专家联合去噪**: foresight 与 action 专家在共享 Euler 步中同步去噪，动作专家注意力直接读未来流——"边想象边行动"的架构化实现；
   - **防坍缩三件套**: stop-gradient EMA 目标 + L_view 梯度阻断 + 知识隔热，系统性地解决了"在自己空间里预测自己"的自指风险；
   - **匹配架构对照 + 测试时干预**: 论文用严格控制的消融证明共演化原生目标与联合去噪的因果优势，而不只是端到端分数。

2. **主要局限性**

   - **潜在未来不可视化**: 不解码像素意味着人类无法直接检查模型"想象"的未来，调试和可解释性受限；潜在 rollout 的保真度只能间接评测；
   - **预测时域受限**: 未来目标只是动作块内的观测（O+_t），本质是短时程前瞻，不是长时程世界模型；长时程空间推理（"绕到桌子后面会发生什么"）不在能力范围内；
   - **单帧 token 预算约束**: 为保持 VLM 单图 token 预算只传最后一帧 token，历史信息压缩在因果编码器内部，长历史/复杂多相机场景可能损失细节；
   - **数据依赖**: 需要大规模自我中心人类视频 + 高质量机器人演示，post-training 仍需目标本体数据；
   - **桌面对比优势有限**: 在 LIBERO/RoboTwin 上只是"保持竞争力"，说明方法红利集中在动态复杂、需要全身协调的任务（loco-manipulation）。

3. **与其他相关工作的对比**

   - **vs π0/GR00T 等纯 VLA**: 多了 L_view 的稠密未来监督与想象能力，监督信号从稀疏动作标签变为动作+未来双重；代价是架构与训练复杂度；
   - **vs WAM（视频生成基座）**: 推理成本数量级下降（110ms/chunk），但丧失了像素级未来可视化与视频生成器的互联网级视频先验；
   - **vs DreamVLA / VLA-JEPA / UniJEPA（冻结外部目标）**: 目标与感知共演化，避免了双空间解耦；消融证明这一点带来实质增益；
   - **vs Motus / BagelVLA（统一模型带视频专家）**: 不携带视频生成专家，参数与推理预算小得多；
   - **优势场景**: 动态、全身、真实世界（G1 +20.0 的巨大差距说明动态 loco-manipulation 是想象能力的价值区）；
   - **劣势场景**: 静态桌面任务优势不明显；需要人类无法看的潜在未来时可解释性差。

## 核心技术发现

- 发现1: **未来预测所在的空间决定了它对行动的价值**——与 VLM 感知共演化的原生 token 空间优于外部冻结编码器空间（+9.6/+20.0 的来源之一），"感知空间=预测空间"应当成为具身世界模型的设计公理；
- 发现2: **联合去噪实现"边想象边行动"**——动作专家在每一步去噪中都读到最新的未来流，未来预测从"前置条件"变成了"在线上下文"；
- 发现3: **自指预测可以稳定训练**——stop-gradient EMA + 梯度阻断 + 知识隔热三重机制让"用自己预测自己"不坍缩、不遗忘，这是原生空间路线能够成立的工程前提。

## 与Spatial AGI的关系

### 直接贡献

给出了一个"会空间想象的机器人基础模型"的具体实现：空间想象 = 原生 token 空间中的未来去噪，空间行动 = 读取想象结果的连续控制。它把 Spatial AGI 的"感知-想象-行动"闭环压进了 110ms 的控制回路。

### 技术启发

- 空间预测模块应内生于感知表示，外部教师只适合预训练初期；
- 联合去噪的"共生成"思想可推广到其他空间推理任务（如导航中同时去噪未来视图+路径）；
- EMA 共演化目标是长期自主学习的空间智能体的记忆更新机制候选。

### 应用场景

人形 loco-manipulation、空间想象规划器、跨具身技能迁移、视频世界模型的控制端蒸馏。

## 个人思考

### 最令人兴奋的发现

G1 真机 +20.0 这个数字说明了想象能力的真实价值：越是需要全身动态协调的任务，"预演未来"的增益越大。这暗示空间想象能力不是锦上添花，而是动态空间任务的核心瓶颈。另外，"在自己的感知空间里做梦"这个设计有一种优雅的自洽——整个系统只有一套空间坐标系。

### 潜在局限

短时程（块内）前瞻是它的天花板。真正的 Spatial AGI 需要秒级到分钟级的空间预演（绕过障碍、多步操作序列），这需要把块内去噪扩展为自回归的潜在 rollout，而自回归潜在 rollout 会面临误差累积和漂移——这正是潜在空间路线尚未解决的核心难题。

### 与昨日研究的关联

昨天读的 gpwm（生成式粒子世界模型）用显式粒子表示3D运动，dynthinker 统一静态3D与动态4D空间推理；今天是另一极——把动态全部压缩进潜在 tokens。结合昨天第 1 篇 WM^MLLM 的外置状态，三天内"世界状态的三种归宿"（外置像素、显式几何/粒子、原生潜在空间）都出现了，构成了一个完整的设计空间地图。

## 总结

### 核心发现总结

$Z$-sight 证明了"在策略自己的感知空间里预测未来并联合去噪动作"是一条可行且高效的路线：它以 110ms 的代价把世界模型嫁接进 VLA，在人形动态操作上取得决定性优势，并用严格消融把增益归因到"共演化原生目标"与"联合去噪"两个设计决策。

### 对Spatial AGI的意义

它确立了"感知空间=预测空间"的设计公理，并展示了感知-想象-行动闭环在实时控制回路中的工程可行性。其短时程限制也明确指出了下一步：自回归潜在 rollout 与长时程空间预演。

## 扩展分析

### 架构注意力掩码详解

Token 顺序 [VLM | FAST | foresight | action]：
- VLM prefix：因果注意力，看不到任何专家（保持语言模型纯粹性）；
- Foresight 流：看 VLM prefix + 自身（双向）；
- Action 流：看 VLM prefix + foresight 流 + 自身；
- 两个专家都看不到 ground-truth FAST token（防止泄漏）。

这个不对称掩码就是信息流的拓扑图：想象 → 行动单向 feeding，感知 → 想象/行动单向 feeding，没有回边污染感知。

### 三阶段训练的梯度路径表

| 阶段 | 数据 | 损失 | VLM 编码器梯度来源 | 专家状态 |
|------|------|------|------------------|---------|
| Pre-train | 2000h 人类视频 | L_FAST | 仅动作监督 | 未引入 |
| Mid-train | 2750h 机器人+20%人类回放 | L_FAST+L_flow+λ_v·L_view | 仅 L_FAST（L_view 阻断，专家隔热读取） | 随机初始化，知识隔热 |
| Post-train | 目标本体演示 | L_flow+L_view | 同上阻断策略 | 联合微调 |

设计哲学：感知编码器永远不被"未来预测"的梯度触碰，只被"动作正确性"塑造——预测任务负责想象，动作任务负责感知对齐。

### 流匹配细节点评

- 未来流用 x-prediction 参数化 + max(σ, σ_min) 权重下限，避免小噪声区梯度爆炸；
- 当前帧条件路径 W_c 零初始化——先完全依赖 VLM cross-attention，再逐步习得直连条件，类似 ControlNet 的 zero-conv 思想；
- σ=max(τ,u) 的噪声耦合让动作专家见过"模糊的未来"，训练-推理一致（推理时 σ=τ 同步）。

### 数据工程的隐藏功夫

- 手部轨迹转当前帧坐标系：把"头在动"从手部动作 token 中剥离，等于教模型自我中心空间不变性；
- 有效性加权时序高斯平滑：抑制追踪抖动，否则 FAST token 会被噪声淹没；
- 联合专属人形日志经前向运动学转任务空间：统一动作语义；
- 空闲段过滤 + 20% 人类回放：既保鲜预训练先验又补充视觉动态多样性。

这些细节说明 VLA/世界模型竞赛已进入数据工程深水区，架构差距在缩小，数据管线质量成为分水岭。

### 与 WAM 的成本-能力定量直觉

- 像素 WAM：视频扩散骨干，秒级延迟，像素级可解释；
- $Z$-sight：110ms/chunk，潜在 token 可干预但不可视；
- 差距本质：像素解码器被砍掉后，省了 ~99% 的生成分辨率计算，代价是人类可读性。
- 折中思路（未来工作）：只在调试/评测时解码（训练一个轻量 decoder head），运行时保持潜在。

### 测试时干预实验的意义

论文声称用"test-time interventions"证明联合去噪的因果优势。这意味着对 foresight 流做扰动/替换并观察动作变化——建立了"想象→行动"的因果链证据，而不只是相关性。这种实验范式值得 Spatial AGI 领域推广：任何"内部表示帮助行为"的声明都应配干预实验。

1. 潜在 rollout 的自回归扩展：块外未来如何继续预测？误差累积如何度量与抑制？
2. 多相机 view-role embedding 的扩展性：相机数量/位姿变化时是否需要重训？

## 问答式深度复习（自测）

### 问：为什么不用外部冻结编码器（如 V-JEPA 2）做预测目标？
答：外部目标的特征空间与 VLM 感知空间解耦——预测出的未来要经过一次"空间翻译"才能被动作专家使用，且冻结教师设置表示天花板。共演化 EMA 目标保证预测与感知始终在同一坐标系，消融显示这是关键增益来源。

### 问：为什么 L_view 梯度不能进 VLM？
答：z_t 和 z+_t 来自同一编码器家族，若允许梯度回传，编码器可以坍缩表示让预测任务变平凡（representation collapse），同时破坏 VLM 预训练知识。stop-gradient + EMA + 知识隔热三重防护。

### 问：联合去噪时两个流如何同步？
答：σ=τ，K 个共享 Euler 步，每步单次前向同时更新未来 tokens 与动作。动作专家每步都读到最新的未来流——想象和行动在去噪轨迹上逐步互相塑造。

### 问：为什么在桌面任务上优势不大？
答：桌面任务动态简单、观测-动作映射接近反应式，想象未来收益小；loco-manipulation 需要预判全身移动+操作的空间后果，想象能力才是瓶颈——+20.0 集中在 G1 真机印证了这一点。

### 问：本文的数据配方对 Spatial AGI 有何普适启示？
答：人类自我中心视频可以充当空间操作知识的"通用语料"，跨本体机器人数据提供动作语法，目标本体 post-training 完成具身特化——空间智能训练可以是"人类视频先验 + 机器人数据适配"的两段式，具身无关性成立。

## 术语表

- **VLA (Vision-Language-Action)**: 建立在预训练 VLM 上的机器人策略模型，输出动作。
- **WAM (World Action Model)**: 基于视频生成器联合预测未来视频与动作的世界动作模型。
- **Native representation space (原生表示空间)**: VLM 视觉编码器输出的 spatial token 空间，感知与预测共用。
- **Foresight expert (前瞻专家)**: 在 token 空间用流匹配去噪未来 spatial tokens 的 MoT 专家。
- **Action expert (动作专家)**: 用条件流匹配生成连续动作块的 MoT 专家，可读 foresight 流。
- **EMA teacher**: 在线编码器的指数滑动平均副本，提供 stop-gradient 的共演化预测目标。
- **Knowledge insulation (知识隔热)**: 专家仅经 stop-gradient 读取 VLM KV，防止破坏预训练知识。
- **FAST tokens**: 离散化动作 token，用于 VLM 的自回归动作监督。
- **Flow matching**: 学习从噪声到目标的连续变换场的生成范式，本文用于未来 token 与动作双流。
- **Causal video encoder**: 用因果时间注意力扩展单帧编码器（MEM 方式），保留运动线索。
- **Loco-manipulation**: 移动+操作一体化的任务类别（人形机器人核心场景）。
- **Joint denoising (联合去噪)**: 推理时未来 token 与动作在共享 Euler 步中同步去噪。

1. EMA 更新：φ̄ ← μφ̄ + (1−μ)φ

## 深度评述：为什么"原生空间"很重要

### 表示空间的统一性原理

把一个智能体拆成感知（encode now）、想象（predict future）、行动（emit actions）三个模块时，存在一个被长期忽视的架构自由度：**三个模块各自住在哪个表示空间**。

- 经典 WAM：感知在 VLM 空间，想象在视频 latent 空间，行动在动作空间 → 两个跨空间翻译；
- DreamVLA/VLA-JEPA：感知在 VLM 空间，想象在冻结外部空间，行动在动作空间 → 想象与感知永久异构；
- 隐式对齐法：想象只是内部激活回归到紧凑嵌入 → 没有可生成的未来流；
- $Z$-sight：三者通过 EMA 目标锚定在**同一个共演化空间** → 无翻译、无天花板、可干预。

跨空间翻译的隐性代价不仅是计算，更是**语义损耗**：每次投影都可能与空间布局信息失真（外部编码器的 tokens 未必保布局）。$Z$-sight 明确选择"preserves the spatial layout"的原生 tokens，这是它被归入 Spatial AGI 研究的理由。

### 与 Spatial AGI 的空间理解能力映射

| 空间能力 | $Z$-sight 的实现 | 成熟度 |
|---------|----------------|--------|
| 空间感知 | VLM spatial tokens + 多相机 view-role | 高（继承 VLM 预训练） |
| 空间记忆 | 因果视频编码器内的历史压缩 | 中（有限历史） |
| 空间想象 | foresight 流块内去噪 | 中（短时程） |
| 空间行动 | action 流读想象结果 | 高（真机验证） |
| 空间抽象推理 | 未显式处理 | 低 |

可见其强项在感知-行动两端，空间记忆与抽象推理是短板——这恰是 Spatial AGI 议程中需要世界模型之外组件（外置记忆、符号空间推理）补位的地方。

### 训练动力学的直观理解

想象训练中的三个力：
1. 动作任务（L_FAST/L_flow）拉扯编码器朝"有利于控制"的表示走；
2. 预测任务（L_view）通过 EMA 目标拉扯 foresight 专家朝"共演化未来"走；
3. 隔热与阻断保证力 2 不会直接扭曲力 1 的载体（VLM）。

系统的稳定性来自：EMA 的慢时间尺度让目标"缓动"，专家追得上；梯度阻断让两个力作用于不同参数子集。这个"慢目标+隔离梯度"的组合拳对任何自指学习系统（包括未来的自我改进型空间智能体）都有借鉴意义。

### 推理时延预算的现实意义

110ms/chunk ≈ 9Hz 控制频率。人形 loco-manipulation 的常见需求：
- 全身移动规划：1-10Hz 可接受；
- 上肢操作：10-30Hz 理想；
- 高频反射性动作（抗扰）：>50Hz，需要独立低层控制器。

$Z$-sight 的定位是中层策略（mid-level policy），底层仍需关节级伺服。它证明的是"想象可以进入实时策略层"，而非"想象可以接管全部控制"。

### 数据规模的外推

- 人类视频 2000h：远小于互联网视频，但自我中心+手部交互的密度高；
- 机器人数据 2750h：在 2026 年已属大规模（AgiBot World 是主要来源）；
- 数据效率信号：+20.0 的真机增益来自 mid-training 的动态先验而非目标本体数据量，暗示**动态多样性 > 本体数据量**，这是数据采集策略的重要指向。

### 潜在失败模式分析

1. **想象漂移**：长块或高 σ 时 foresight 去噪偏差大，动作专家读到错误的"未来"——错误想象比不想象更危险；
2. **过拟合动态先验**：mid-training 数据的动态分布（桌面+家务）可能不适配野外场景；
3. **多相机失配**：部署时相机位姿/数量与训练不同，view-role embedding 需要重适配；
4. **FAST token 瓶颈**：离散动作监督的粒度限制 VLM 对连续动力学的理解。

### 对"世界模型进入控制回路"的里程碑意义

2025-2026 年世界模型研究的最大张力是"能力 vs 延迟"：视频世界模型能力惊艳但秒级延迟使它只能做离线规划或数据生成。$Z$-sight 给出了第三条路：**把世界模型压缩成策略的原生能力**，让想象以 token 去噪的形式实时发生。如果这条路线成熟，"具身智能体是否拥有世界模型"将不再是架构问题，而是表示学习问题。

### 教师信号的时间尺度分析

EMA decay μ 决定目标的时间常数。μ 太大：目标滞后，预测任务过易（预测一个旧版本自己）；μ 太小：目标抖动，训练不稳。论文未讨论 μ 的调度——一个显然的改进是预训练后期增大 μ（目标趋稳），post-training 减小 μ（快速适配新本体）。这属于未来实验空间。

### 如果只记住三件事

1. 感知空间=预测空间：未来预测应该发生在 VLM 自己的 token 空间，用共演化 EMA 目标锚定；
2. 联合去噪=边想象边行动：动作专家在去噪每一步读未来流，想象是行动的在线上下文而非前置输入；
3. 防坍缩三件套：stop-gradient + EMA + 梯度阻断/知识隔热，是自指预测可训练的工程前提。

## 与其他空间智能评测的适配猜想

- 若在 MBench-A（WM^MLLM 所用）式环境恢复任务上测 $Z$-sight：预计表现一般——它不做持久世界记忆；

## 补遗：三个容易被误读的点

### 误读1："$Z$-sight 是视频世界模型的替代品"
不完全对。它是**控制回路内**的世界建模方案；视频世界模型在数据生成、长时程仿真、可视化验证上仍有不可替代的作用。两者更像"发动机与风洞"的关系。

### 误读2："EMA teacher 就是教师-学生自蒸馏"
有细微差别：teacher 不提供标签，只提供**目标表示**；且全程 stop-gradient，学生不通过 teacher 反传。这更接近 BYOL/I-JEPA 的自监督目标构造，而非蒸馏。

### 误读3："110ms 意味着可以端到端控制人形机器人"
110ms 是 chunk 级决策延迟。真实系统仍需低层关节控制器、安全监控、力控等传统栈。$Z$-sight 解决的是策略层的想象与决策，不是全身控制的全部。

## 结语

$Z$-sight 的价值在于把一个宏大的愿景——"机器人策略应当拥有世界模型"——落成了一个具体、可训练、达到实时的架构选择，并用消融把每个设计决策的因果贡献讲清楚。它未必是终局架构，但它把"原生空间预测"这个选项摆上了桌面，后续工作必须与之比较。
