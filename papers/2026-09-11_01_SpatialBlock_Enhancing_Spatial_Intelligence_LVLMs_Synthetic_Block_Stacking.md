## 论文速览

Large Vision-Language Models (LVLMs) 在各类 2D 视觉任务上表现强劲，但它们从 2D 图像中"心理重建"场景 3D 结构的能力——即空间智能（spatial intelligence）——仍然有限。现有方案依赖真实场景的空间问答数据集，需要稠密几何标注，成本高、耗时、且因依赖外部感知模块（分割/深度估计）而噪声大。

本文受人类认知发展启发，提出通过**结构化积木堆叠任务**学习基础空间技能的新范式，构建了 **SpatialBlock-15k** 合成数据集（15,000 道积木堆叠问题），覆盖三类任务：
1. **3D-to-2D 投影**（预测 3D 结构在某视角下的 2D 外观）
2. **视角变换**（预测 3D 结构在自转/视角变化后的外观）
3. **结构组合**（预测两个 3D 结构组合后的整体结构）

数据集还引入**受控颜色调制**作为视觉线索，模拟人类"锚定物体推理"的认知机制。实验表明，仅用这个全合成、规模紧凑的数据集训练，LVLM（无论直接答题还是推理式预测）都显著超越基线，并能**泛化到真实世界空间任务**。

## 核心问题

### Q1: 核心算法原理是什么？

**问题**: 这篇文章的核心算法原理是什么？

**分析**:

#### 1. 核心思想和动机

论文的出发点是一个惊人的实证观察：**在最基础的积木堆叠问题上，人类接近满分，而最先进的 LVLM（包括顶级闭源模型）表现很差**，甚至出现错误的空间逻辑解读（Fig. 1）。这说明 SOTA LVLM 缺乏最基本的"空间智能"。

作者选择的方向不是"用更多真实场景数据硬灌"，而是回到**人类空间认知发展的源头**：发展心理学研究表明（Levine et al., 2012; Jirout & Newcombe, 2015），人类的基础空间能力正是通过结构化的操作型玩具（尤其是积木游戏）培养的。积木游戏被证明能增强空间整合（spatial integration）和心理模拟（mental simulation）能力。

核心洞察链条：
- LVLM 空间智能差的根源是缺乏"从 2D 投影重建 3D 结构"的基础技能
- 这一基础技能可以被分解为若干原子能力
- 这些原子能力可以在完全合成的、几何精确的积木环境中被系统性地训练
- 基础技能提升后可**迁移**到真实场景的空间推理

这与"用大规模真实场景稠密标注"的路线形成鲜明对比：合成路线**几何标注零噪声、零成本、可无限扩展**。

#### 2. 主要技术方法

**(a) SpatialBlock-15k 数据集设计**

三类任务对应三种原子空间能力（Fig. 2）：

- **空间组合能力（spatial composition）**：从可见配置解构并推断被遮挡的、为支撑结构而必须存在的积木 → Q1 考察
- **心理模拟能力（mental simulation）**：模拟 3D 结构在变换后的结果 → Q2 考察
- **空间整合能力（spatial integration）**：预测多个组件组合后的整体结构 → Q3 考察

三类问题定义：
- **Q1（3D-to-2D projection）**：给定 3D 积木结构，预测从特定观察方向看到的 2D 外观。要求模型内部重建 3D 配置、心理变换到目标视角，并做**深度感知的遮挡推理**（判断哪些积木在最终投影中可见）。
- **Q2（viewpoint transformation）**：给定 3D 结构，预测自转或视角变化后的样子。要求在变换中保持结构一致性——所有组件的相对位置正确，不发生扭曲、消失或意外位移。
- **Q3（structural combination）**：给定两个 3D 结构，预测组合后的结构。要求模拟组件交互、识别接触界面、推断整合后涌现的全局结构。

**(b) 视觉线索扩展（Visual Cue-based Extension）**

单色积木任务迫使模型纯靠几何关系推理。但真实场景中人类是**锚定特定物体、相对它推理关系**的（Land & Hayhoe, 2001）。为此作者引入颜色作为**功能性线索**而非装饰：

- **Q1 + 深度线索**：按距视角的深度分配不同颜色，任务从"匹配轮廓"升级为"用颜色追踪前后关系"，颜色显式编码深度排序。
- **Q2 + 锚定积木**：指定一个不同颜色的锚定积木，它在变换前后保持相同结构角色，迫使模型理解"锚定物相对关系"在变换中的保持。
- **Q3 + 重叠色块**：两个结构的连接位置不使用箭头而用透明区域的重叠色块表示；两结构分别呈现在不同图像中，需要对齐跨图像的同色块位置来预测组合——颜色成为连接两个独立输入的共享参照点。

每类问题（含视觉线索扩展）各 5,000 样本，共 15,000。

**(c) 两种训练策略**

**策略一：直接答案预测（Direct Answer Prediction）**
- 仅用标准交叉熵损失在 ground-truth 答案序列上训练：
  L_ce(θ) = -Σ_i log P(y_i | y_(1:i-1), q, v)
- 目标：培养快速、即时的空间问题求解能力，建立高保真空间求解的基础。

**策略二：推理式预测（Reasoning-based Prediction）**
- 两阶段：LoRA 监督微调初始化 → GRPO 强化学习
- **关键设计决策：放弃传统"冷启动"阶段**。通常 RL 前用更大教师模型合成 CoT 轨迹做冷启动，但作者发现即使是 SOTA 闭源模型在自家数据集上准确率也很低，无法构造可靠的高质量轨迹。因此用 **LoRA**（而非全参微调，后者会损害模型固有的 CoT 推理能力）做轻量对齐，保留模型的思维链能力，为 RL 提供更好的初始化。
- **GRPO 多目标奖励**：R(y,o) = R_acc + R_format + R_len
  - R_acc：从输出中抽取的最终答案是否匹配 ground truth
  - R_format：强制 CoT 结构 + 用 `<answer></answer>` 标签包裹最终答案
  - R_len：响应长度需满足 50 < L < 1024 token（防止过短或过度冗长）
  - 所有组件均为二元奖励（0/1）
- Advantage 计算：组内相对标准化 A_i = (r_i - mean(r)) / std(r)，组大小 G 个候选响应

#### 3. 算法流程和关键步骤

数据构建流程（推断自论文描述）：
1. 程序化生成 3D 积木结构（保证物理可支撑性——被遮挡积木必须有支撑）
2. 对每个结构渲染多视角图像，生成三类问题的图文对
3. 对每类问题生成单色版本和颜色线索版本
4. 自动获得精确 ground truth（合成环境天然零标注噪声）

训练流程（推理式）：
1. LoRA SFT：在 (图像, 问题) → CoT+答案 数据上轻量对齐
2. GRPO：每个问题采样 G 个响应，计算三项二元奖励，组内标准化 advantage，策略梯度更新
3. 在真实场景空间基准上评估泛化

#### 4. 输入输出

- **输入**：积木结构的渲染图像（单色或带颜色线索）+ 文字问题（如"从正面看这个结构是什么样？""旋转后结构如何？""两个结构组合后是什么？"）
- **输出（直接式）**：答案选项/描述
- **输出（推理式）**：思维链推理轨迹 + `<answer>` 标签内的最终答案
- **训练对象**：通用 LVLM（LoRA 适配 + RL）

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**分析**:

#### 1. 如何理解和表示空间

这篇论文对空间智能给出了一个**可分解的能力观**：空间智能不是单一能力，而是可拆解为空间组合（从投影反推结构，含遮挡推理）、心理模拟（变换下的结构保持）、空间整合（组件到整体的涌现）三个原子能力。这个分解非常有价值——它把"空间智能"这个模糊概念变成了**可编程、可评测、可针对性训练**的工程目标。

表示上，积木结构是**体素化的离散 3D 结构**的最简形式，2D 图像是其在视角下的投影。任务本质是在"3D 结构 ↔ 2D 投影"两个表示之间做双向映射与变换，这正是 Spatial AGI 需要的核心表示转换能力。

#### 2. 如何处理空间关系

论文的处理方式有三个层次值得注意：
- **几何优先**：单色任务强制模型只依赖几何关系（相对位置、遮挡、支撑），排除颜色/纹理捷径。
- **锚定推理**：颜色线索扩展模拟人类"锚定物体 → 相对推理"的认知策略，这是从纯几何到真实场景复杂视觉的重要桥梁。锚定积木在变换中的角色保持，本质上训练的是**等变性**——空间关系在视角变换下的不变量。
- **跨输入对齐**：Q3 的重叠色块要求模型在两个独立图像间建立对应（correspondence），这是多视图空间理解的原子操作。

#### 3. 对 Spatial AGI 的启发

- **合成优先的数据战略**：真实场景稠密 3D 标注贵、慢、噪声大；合成环境提供零噪声几何真值且可无限扩展。论文证明了"小而精的合成基础任务数据 > 大而噪的真实标注数据"这一反直觉结论，对整个 Spatial AGI 数据工程是重要信号。
- **基础技能迁移假说成立**：仅在积木这种极端简化域上训练，就能泛化到真实世界空间任务——说明存在**跨域通用的空间基础技能**，且它可以被显式训练。这与儿童发展心理学的结论在 AI 上得到验证。
- **冷启动悖论**：当任务足够难（连教师模型都不会），传统蒸馏冷启动失效，必须依靠保留模型自身推理能力的轻量对齐 + RL。这个洞察对所有"前沿能力训练"场景（教师也不比学生强多少）都有普适意义。
- **课程式原子能力分解**：先训练原子空间技能，再泛化到复杂场景，暗示 Spatial AGI 的训练或许应该走"合成基础技能 → 真实场景适配"的两阶段路线，而非端到端硬灌真实数据。

#### 4. 可以应用的 Spatial AGI 场景

- **机器人操作**：堆积、插装、装配任务的空间结构推理可直接受益于 spatial composition / integration 能力。
- **自动驾驶**：从摄像头 2D 投影重建 3D 道路参与者结构、遮挡推理（被遮挡车辆必须存在）与 Q1 的支撑推理同构。
- **3D 场景重建与补全**：从单视角推断被遮挡几何，正是 spatial composition 的直接应用。
- **导航**：视角变换能力（Q2）对应导航中的自我中心→世界中心坐标转换、回环识别。
- **空间基准设计**：积木范式可扩展为更复杂的合成基准（重力、摩擦、多智能体积木协作），为 Spatial AGI 提供系统化评测。

### Q3: 主要创新点和局限性是什么？

**分析**:

#### 1. 主要创新点

1. **范式创新**：从"真实场景稠密标注"转向"受人类认知发展启发的合成基础任务"，开辟了低成本、零噪声、可扩展的空间智能训练路线。
2. **数据集创新**：SpatialBlock-15k 是首个系统化覆盖 3D-to-2D 投影、视角变换、结构组合三类原子空间能力的合成数据集，且颜色线索设计（深度编码/锚定积木/重叠对应）有清晰的认知科学依据。
3. **训练策略创新**：发现并解决"冷启动悖论"——在教师模型也做不好的任务上，放弃教师蒸馏，用 LoRA 保留推理能力 + GRPO 直接优化，三项目标明确的二元奖励设计简单稳定。
4. **实证贡献**：揭示了 SOTA LVLM（包括顶级闭源模型）在基础积木任务上的惊人短板，为领域提供了一个"照妖镜"式的能力探针。

#### 2. 主要局限性

1. **域间隙依然存在**：积木是体素化的、物体恒定、光照均匀、无纹理的极端简化环境。真实场景的开放词汇、复杂材质、非刚性物体远超此范围。合成→真实的迁移在本论文中有效，但迁移幅度（真实基准上提升的具体量级）需要仔细审视，可能存在"合成任务上大涨、真实任务上小涨"的稀释效应。
2. **任务覆盖有限**：三类任务都是静态结构的感知/变换，不涉及动态（运动、物理）、语义（物体类别、功能）、大规模（房间/城市级空间记忆）等空间智能的重要维度。重力/支撑是唯一的物理约束，未涉及碰撞、摩擦等真实物理。
3. **多选题偏差风险**：从任务形式看（预测 2D 投影外观）很可能以选择题呈现，模型可能学到选项消除策略而非真正的 3D 重建；RL 的 R_acc 也只看最终答案，推理轨迹本身是否真正"空间化"缺乏过程监督。
4. **规模与模型范围**：15k 样本对"基础技能"够用，但是否存在规模天花板（更复杂的结构组合、更深的堆叠层级）未探索；实验的 LVLM 底座范围和 7B 级以下小模型的表现未在摘要中说明。

#### 3. 与其他相关工作的对比

- **vs. 架构路线（深度插件、3D 空间编码器，如 Depth Anything 插件、SpatialEncoder 类）**：架构路线改模型不改数据，需要外部感知模块提供伪 3D 信号；SpatialBlock 不动架构、只改数据与训练，部署零侵入，但天花板受限于底座视觉编码器的 3D 表达能力。
- **vs. 真实场景空间 QA 数据集（SpatialVLM 类、MindCube 等）**：真实数据语义丰富但标注噪声大、成本高；SpatialBlock 零噪声零成本但语义贫乏。两者是互补而非替代关系——理想的训练配方可能是"合成基础技能预训练 + 真实场景语义微调"。
- **vs. 认知地图输出类方法（输出显式 cognitive map）**：认知地图方法让空间推理显式化、可检查；SpatialBlock 的推理藏在 CoT 里，可解释性较弱，但训练更简单、不要求中间表示的格式设计。
- **vs. SpatialEvo（自演化几何环境）**：两者都走合成几何环境路线，SpatialEvo 强调环境自演化扩展难度，SpatialBlock 强调认知发展依据和人类对齐的任务设计。可结合：用 SpatialBlock 的任务分类学 + SpatialEvo 的自演化机制做无限课程。

## 核心技术发现

1. **SOTA LVLM 在基础积木任务上远逊于人类**——空间智能短板存在于最底层，而非仅在高阶推理。
2. **全合成 15k 样本训练即可显著超越基线并泛化到真实场景**——合成基础技能数据的杠杆率极高。
3. **教师模型冷启动在难题上失效**：闭源 SOTA 在积木任务上准确率低，无法产生可靠蒸馏轨迹；LoRA 轻对齐 + GRPO 是更优路径。
4. **颜色作为功能线索（深度编码/锚定/对应）显著提升真实场景泛化**——视觉锚定是人类空间认知策略在 AI 训练中的成功移植。
5. **全参微调损害 CoT 推理能力**，LoRA 在保留推理基础的同时完成领域对齐。

## 与 Spatial AGI 的关系

### 直接贡献
提供了一个可复用的"合成基础空间技能训练"流水线：任务分类学（投影/变换/组合）+ 数据生成 + 两种训练策略，可直接套用到其他合成空间域。

### 技术启发
- Spatial AGI 训练的"原子能力分解 + 合成环境 + RL"三段式可能成为标准配方。
- 冷启动悖论提示：越靠近前沿能力，越要依赖 self-play/RL 而非教师蒸馏。

### 应用场景
机器人装配、驾驶遮挡推理、单视角场景补全、导航视角变换、空间能力评测基准。

## 个人思考

### 最令人兴奋的发现
"积木效应"的 AI 验证：人类靠积木建立空间认知，AI 也是。这暗示空间智能可能存在**普适的发展路径**——从简单合成结构到复杂真实场景，而不是靠堆真实数据一步到位。如果成立，Spatial AGI 的数据战略应该把预算从"标注真实场景"转向"设计合成任务空间"。

### 潜在局限
我最担心的是多选题形式的评测有效性和推理轨迹的"真实性"——模型可能学会言语化的空间推理（说得头头是道但内部并没有 3D 表征）。后续工作应该用探针（probing）检验训练后模型的内部是否真的形成了 3D 结构表征，而不是只看下游准确率。

### 与近日研究的关联
- 呼应 2026-09-10 的 TTL-SR（测试时几何感知学习）：两者都在探索"不靠大规模真实标注提升空间推理"的路线，一个走合成数据训练，一个走测试时学习。
- 呼应 2026-09-08 LightNav-0（激发 VLM 空间智能做通用导航）：LightNav 在应用端激发空间智能，SpatialBlock 在训练端打基础，可能形成"先 SpatialBlock 预训练、再 LightNav 式任务适配"的完整管线。
- 与 SpatialEvo（自演化空间智能环境，4 月分析过）同属合成路线，但 SpatialBlock 的认知科学依据更扎实。

## 关键数据

- **数据集规模**: 15,000 样本（3 任务 × 5k，含视觉线索扩展）
- **训练策略**: 直接 SFT / LoRA SFT + GRPO（奖励：acc + format + len，均二元）
- **对比基线**: 多个开源与闭源 SOTA LVLM（闭源模型在本数据集上准确率低，无法做教师蒸馏）
- **关键结论**: 合成训练 → 真实场景泛化有效；推理式训练优于直接答题

## 总结

### 核心发现总结
SpatialBlock 证明了：受人类认知发展启发的合成积木任务，能以极低成本（15k 全合成样本）系统性提升 LVLM 的基础空间能力，并迁移到真实场景。关键技术包括任务分类学（投影/变换/组合）、功能性颜色线索、LoRA+GRPO 训练（绕过冷启动悖论）。

### 对 Spatial AGI 的意义
这是"合成数据优先"路线在空间智能上的一个高质量实证：空间智能的底层技能可以在简化合成域中被高效、零噪声地训练，然后迁移。对 Spatial AGI 而言，数据战略的重心应从"真实场景标注"部分转向"合成任务空间设计"，同时警惕简化域的能力天花板和多选题评测的捷径风险。

## 附录 A：三类任务逐项深度拆解

### A1. Q1 — 3D-to-2D 投影任务

**任务本质**：正向投影 + 逆向结构推断的复合。

解决该任务的认知步骤分解：
1. 从输入 2D 视图（可能是多视图或单视图+描述）重建完整 3D 体素结构
2. 关键难点：可见投影无法唯一确定 3D 结构——被遮挡的支撑积木必须被推断出来（物理约束：悬空积木不存在）
3. 将内部 3D 表征心理旋转到目标视角
4. 沿视线方向做深度排序，确定每个像素位置最前方的积木（遮挡推理）
5. 输出目标视角的 2D 外观

**考察的能力矩阵**：
- 逆向推断（从效果到原因）：★★★★
- 物理常识（重力/支撑）：★★★
- 心理旋转：★★★★
- 遮挡推理：★★★★★

**颜色线索版本**：按深度着色后，模型可以把"颜色 → 深度层"作为显式索引，将连续的遮挡推理分解为离散的层排序问题。这实际上把一个隐式推理任务部分外化为模式匹配，是"线索辅助推理"的典型设计。

### A2. Q2 — 视角变换任务

**任务本质**：等变预测——给定结构在视角 A 的图像，预测视角 B 下的图像，要求结构本身不变。

失败模式分析（LVLM 常见错误）：
- **组件消失**：变换后某些积木凭空消失（缺乏对象恒常性）
- **意外位移**：相对位置畸变（缺乏刚体变换的不变量理解）
- **镜像混淆**：左右手性问题（手性是 3D 理解的试金石）
- **拓扑破坏**：连接关系改变（缺乏结构图层面的表示）

**颜色线索版本**：锚定积木设计。指定一块独特颜色的积木，要求它在变换前后保持相同的结构角色。这迫使模型：
1. 识别并跟踪特定对象跨视角的身份
2. 以锚定物为参照系描述其他组件的相对位置
3. 理解"结构角色"这一介于几何和语义之间的概念

这正是机器人操作中"抓取目标物体"所需的身份保持能力。

### A3. Q3 — 结构组合任务

**任务本质**：组合合成——两个子结构的接口匹配与全局涌现。

认知步骤：
1. 分别理解两个输入结构的几何和接口（接触面）
2. 在颜色线索版本中，跨图像对齐同色块确定连接方式
3. 模拟组合过程：哪个面接触、整体重心如何、是否稳定
4. 推断组合后的完整结构

**为何组合任务更接近真实场景**：真实场景几乎都是组合式的——家具由部件组合、房间由家具组合、城市由建筑组合。空间整合能力是从"理解单个物体"迈向"理解场景"的桥梁。

## 附录 B：训练方法逐层解析

### B1. 直接答案预测的定位

看似朴素，实则有明确目的：建立"视觉输入 → 空间答案"的直接映射通路，相当于空间技能的"快系统"（System 1）。其价值在于：
- 为推理式训练提供更强的初始化（先学会答对，再学会解释）
- 验证任务本身的可学习性（如果直接 SFT 都学不会，说明任务太难或数据有问题）

### B2. 冷启动悖论的详细分析

传统 RLVR 流程：
``` 
教师模型合成 CoT 轨迹 → 冷启动 SFT → GRPO/RLVR
```

本论文遇到的问题：
- 教师模型（闭源 SOTA）在积木任务上准确率低
- 低质量轨迹的冷启动会引入系统性错误推理模式
- 一旦模型在冷启动阶段学坏了，RL 很难纠正

替代方案：
```
LoRA SFT（保留底座 CoT 能力，仅对齐任务格式）→ GRPO
```

LoRA 的选择有双重理由：
1. 参数高效，避免灾难性遗忘
2. 低秩约束天然限制了过拟合到表面模式，保留预训练推理能力

**普适启示**：当任务处于前沿（教师也不比学生强多少）时，"self-initiated RL"（保留自身能力 + 直接强化正确性信号）优于"teacher distillation"。这与数学/代码 RL 领域的观察一致，但在空间智能上是首次系统验证。

### B3. 奖励设计的工程细节

三项二元奖励的合理性：
- **R_acc（正确性）**：唯一真正反映任务目标的信号，从 `<answer>` 标签中解析最终答案做精确匹配
- **R_format（格式）**：保证推理轨迹存在且结构完整，为可解释性留下空间
- **R_len（长度约束 50 < L < 1024）**：非常实用的防退化设计——过短意味着跳过推理直接猜答案，过长意味着推理失控或重复循环

潜在问题：二元奖励不区分"推理正确但答案错误"与"推理混乱但答案正确"，缺乏过程奖励（PRM）。在积木任务中推理步骤天然可验证（每一步的中间结构都可检查），未来工作可以引入逐步验证的密集奖励。

### B4. GRPO 组内相对优化的适配性

GRPO 无需价值网络，组内基线降低了奖励方差，对二元稀疏奖励尤其友好。在积木任务中：
- 同一问题采样 G 个响应
- 若全对或全错，组内 advantage 为零，梯度为零（无可学习信号）
- 因此任务难度分布很重要——SpatialBlock-15k 的结构复杂度梯度设计（推断）保证了相当比例的问题处于"部分正确"区间，提供持续学习信号

## 附录 E：风险与后续研究方向的批判性清单

1. **评测捷径风险**：选择题形式 + 答案抽取式奖励 → 模型可能学会排除法。建议：开放式生成 + 结构化验证器。
2. **内部表征检验缺失**：下游准确率提升 ≠ 内部形成 3D 表征。建议：线性探针检测中间层是否存在体素/深度可解码信息。
3. **尺度外推**：积木规模（块数、堆叠深度）超出训练分布后性能如何衰减？建议：难度外推曲线实验。
4. **物理真实性**：支撑约束是最简物理，真实场景涉及摩擦、重心、动力学。建议：引入物理引擎验证的合成任务。
5. **语义鸿沟**：积木无语义，真实物体有功能/类别。建议：合成→真实渐进课程（带语义的合成场景）。
6. **跨模态扩展**：文本描述的空间推理（"如果把它转到背面..."）是否同样受益？
7. **与 3D 基础模型结合**：SpatialBlock 训练的 LVLM 能否与 3DGS/NeRF 表征衔接，形成"感知-重建-推理"闭环？
8. **数据自我演化**：结合 SpatialEvo 式自演化，让积木复杂度随模型能力自动爬升，形成无限课程。

## 附录 H：扩展问答（FAQ 式精读补充）

**Q: 为什么选择积木而不是其他合成任务（如迷宫、拼图）？**

A: 积木的独特优势：1) 同时包含 3D 结构和 2D 投影两个天然表示；2) 支撑约束引入最简物理；3) 与人类发展文献直接对接，任务设计有科学依据而非任意选择；4) 组合操作自然定义（堆叠），避免了任意拼合的歧义。迷宫考察拓扑路径规划，拼图考察接合匹配，都不如积木对'结构-投影'双向映射的覆盖全面。

**Q: 直接回答训练和推理式训练的差异说明了什么？**

A: 推理式优于直接式说明空间任务受益于显式推理链——即使推理内容未被过程监督，'先想后答'本身就减少了冲动猜测。同时说明空间智能不只是感知问题，还是推理问题。

**Q: 颜色线索为什么能提升真实场景泛化？**

A: 单色任务学到的是纯几何推理，但真实图像中几何信息被外观噪声淹没。颜色锚定教会模型'在复杂外观中选取参照物'这一元策略，该策略可直接迁移到真实场景的物体锚定。本质上是训练了注意力和参照系选择，而非具体几何。

**Q: 这篇论文的方法与知识蒸馏失败案例有何关系？**

A: 它是'蒸馏上限受教师能力约束'这一普遍原理的空间智能实例。当任务超越教师能力，RL 的探索+正确性信号成为唯一可靠的改进来源。这预示着 Spatial AGI 的前沿能力训练将越来越依赖 self-improvement。

**Q: 如果只有 1k 样本，方法还能work吗？**

A: 未做数据规模消融（已读部分）。但 GRPO 的组内对比特性表明正确率在 10%-90% 区间的问题最有价值。1k 样本若精心控制难度梯度，可能仍有效，但结构多样性下降可能损害泛化。

**Q: 积木任务的'支撑约束'提供了什么独特信号？**

A: 它让被遮挡部分不是任意的而是可推断的——悬空不可能。这使逆向推断成为逻辑演绎而非记忆匹配。这是合成任务设计的精髓：让每个可见配置唯一（或近似唯一）确定隐藏结构。

**Q: 对本仓库后续研究最值得追的 follow-up 是什么？**

A: 1) 探针实验检验内部 3D 表征；2) 物理引擎级合成任务（碰撞/摩擦）；3) 自演化难度课程；4) 与 3D 重建模型（3DGS）的表示衔接。

**Q: 论文的实验底座规模和开源情况如何？**

A: 代码与数据在 GitHub 开源（rsoohyun/SpatialBlock），可复现性好。底座模型细节需读原文，但 LoRA+GRPO 流程对 7B 级开源 LVLM 均适用。
