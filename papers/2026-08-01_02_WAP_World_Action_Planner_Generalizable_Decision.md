## 摘要概述

构建可泛化到多样应用的智能体仍是根本挑战。基于模仿学习的策略虽然在特定训练环境中成功，但往往无法泛化到新场景和新任务。本文提出World Action Planner (WAP)，一个利用VLM推理能力和多任务位姿-图像条件世界模型物理基础的机器人规划系统。该系统使智能体能够提出初始动作计划，并通过优化和搜索迭代改进，基于想象的世界模型推演进行推理。实验证明该方法在组合任务、新布局和零样本泛化场景中显著优于VLA和WAM等端到端策略模型。

## Q1: 核心算法原理

### 1.1 核心思想和动机

WAP的核心洞察是：**端到端模仿学习从根本上受限于训练数据的范围**。具体表现为：

1. **组合泛化失败**: 仅训练了单独的"抓取-放置"原子轨迹的策略，无法在长时程组合任务中导航
2. **过拟合伪模式**: 如果训练数据中抓取总在特定坐标，策略会持续瞄准该位置——即使物体已移动
3. **缺乏因果理解**: E2E模型不具备对物理因果和动态的系统理解

WAP的解决思路是回归经典机器人学的**模型预测规划**范式：用世界模型模拟动作后果，用VLM进行高层推理，通过迭代优化和搜索生成可执行计划。

### 1.2 主要技术方法

#### 核心组件1: 位姿-图像条件世界模型 (Pose-Image Conditioned World Model)

这是WAP的基础设施，区别于以往的世界模型设计：

**以往方法的局限**:
- 低维动作向量 + AdaLN-Zero调制 → 难以泛化到新动作
- 低维动作向量 + 交叉注意力 → 条件信息不够丰富

**WAP的创新**:
1. 通过正向动力学预计算未来机器人关节位置
2. 从对应相机视角渲染关节位置为"位姿骨架图像"（pose skeleton image）
3. 用视频模型的VAE编码位姿图像为token
4. 将位姿token与视频token拼接成统一序列
5. 采用多视角预测（第三人称视角+腕部视角）

**训练方式**: Diffusion forcing + Flow matching目标
- 历史视频token: 独立随机噪声
- 未来视频token: 均匀噪声
- 位姿图像token: 无噪声（作为条件）

#### 核心组件2: World Action Planner规划系统

WAP规划系统包含三个层次的推理：

**层次1: 智能体动作提案 (Agent Action Proposal)**
- VLM生成原始动作序列（MOVE, ROTATE, GRASP, RELEASE）
- VLM从多视角图像识别目标夹爪位置
- 通过三角化将2D像素坐标转换为3D空间坐标
- 低级策略作为控制器执行动作

**层次2: 全局优化 (Global Optimization Guided by Agent Feedback)**
- 用世界模型想象动作轨迹的后果
- VLM评估想象视频的安全性和目标对齐度
- 如有问题，VLM提供高层语义反馈（如"增加高度避开碰撞"）
- 基于反馈更新动作序列

**层次3: 局部搜索 (Local Search with Agent Ranking)**
- 对候选动作进行网格搜索采样
- 用世界模型想象每个候选的结果
- VLM从想象结果中选择最优方案
- 可选：用扩散策略完成精细操作

#### 核心组件3: 策略作为工具 (Policies as Tools)

WAP将现有策略（扩散策略、VLA、WAM）视为模块化工具：
- 分布内任务: 直接使用已有策略
- 分布外场景: 使用完整的模型规划系统
- 这种范式扩展了机器人决策的泛化前沿

### 1.3 算法流程

```
输入: 任务描述ℓ, 初始状态s, 环境env

while not done:
    # 1. 动作提案
    g = VLM.ProposeActions(s, ℓ)
    a = Controller(g, s_proprio)
    
    # 2. 全局优化
    ŝ_next = WorldModel(s, a)
    Δg = VLM.Optimize(ŝ_next, ℓ)
    a = Controller(g + Δg, s_proprio)
    
    # 3. 局部搜索
    candidates = GridSearch(a)
    for each a_i in candidates:
        ŝ_i = WorldModel(s, a_i)
        if use_policy:
            ŝ_i = WorldModel(ŝ_i, Policy(ŝ_i))
    i* = argmax VLM.Rank(ŝ_1, ..., ŝ_N, ℓ)
    
    # 4. 执行
    s, done = env.Step(s, a_{i*})
```

### 1.4 输入输出

- **输入**: 任务描述（自然语言）、初始状态（多视角图像）、环境
- **输出**: 可执行的机器人动作序列
- **中间表示**: 位姿骨架图像、想象的视频rollout

## Q2: 与Spatial AGI的关系

### 2.1 空间理解和表示

WAP对空间的理解建立在**多视角几何 + 想象推理**之上：

1. **多视角空间感知**: 通过第三人称视角和腕部视角的拼接，模型可以推断每个机器人关节的3D相对位置。这种基于多视角的空间感知比单视角或低维动作向量提供了更丰富的空间信息。

2. **位姿-图像空间表示**: 将机器人关节位置渲染为2D骨架图像，然后用VAE编码为token。这是一种独特的空间表示方法——将3D空间信息编码为2D图像格式，利用视频模型强大的视觉理解能力。

3. **想象空间推理**: 世界模型的想象rollout本质上是在进行空间推理——预测动作执行后的空间状态变化。这种"在脑海中模拟"的能力是空间智能的核心。

### 2.2 空间关系处理

1. **VLM空间理解**: VLM识别多视角图像中的目标位置，进行跨视角的3D三角化。这直接处理了2D图像到3D空间坐标的映射。

2. **碰撞检测**: 通过想象rollout，VLM可以检测潜在的空间冲突（如夹爪与障碍物的碰撞），这是空间关系推理的直接应用。

3. **空间反馈优化**: 当VLM发现想象的动作轨迹存在空间问题时（如"夹爪太低"），它提供空间语义反馈来调整动作。

### 2.3 对Spatial AGI的启发

1. **模型规划优于端到端**: WAP的理论分析和实验都证明，基于世界模型的规划在多任务泛化上优于端到端模仿学习。这对Spatial AGI的架构设计有重要启示——应该将空间推理建立在可模拟的世界模型之上，而非端到端策略。

2. **想象作为空间推理工具**: 世界模型的想象能力可以用于空间推理——"如果执行动作A，物体会到哪里？"这种基于想象的空间推理比纯几何推理更灵活。

3. **层次化空间规划**: WAP的三层规划结构（提案→优化→搜索）可以直接应用到空间规划——VLM提出空间目标，世界模型验证空间可行性，搜索找到最优空间路径。

4. **位姿-图像条件的通用性**: 将空间信息（关节位置）编码为图像格式的思想可以推广——任何空间信息都可以渲染为图像，利用视觉模型的强大能力。

5. **策略作为工具**: 将策略视为可替换的模块化工具，为Spatial AGI提供了灵活的系统架构。

### 2.4 可应用的Spatial AGI场景

1. **机器人操作**: WAP已验证在抓取、堆叠、放置等操作任务上的有效性
2. **导航规划**: 想象rollout可以用于导航场景的空间规划
3. **多步空间推理**: 组合任务的规划能力可用于需要多步空间推理的场景
4. **安全约束**: 通过想象检测碰撞和安全风险
5. **零样本迁移**: 模型规划范式天然支持零样本迁移到新环境

## Q3: 创新点和局限性

### 3.1 主要创新点

1. **位姿-图像条件化**: 将机器人动作编码为骨架图像而非低维向量，显著提升了世界模型对动作的控制精度和泛化能力。这是一个简单但非常有效的设计——利用视觉模型已有的强大空间理解能力。

2. **三层规划架构**: 提案→优化→搜索的层次化规划结构优雅地结合了VLM的高层推理和世界模型的物理模拟。每层解决不同层次的问题：VLM提案解决"做什么"，优化解决"怎么做更好"，搜索解决"精确怎么做"。

3. **理论保障**: 提供了理论分析证明模型规划在多任务泛化上优于模仿学习，在表格设置和线性函数近似下都有严格证明。

4. **想象-评估循环**: VLM不仅用于提出动作，还用于评估想象的结果。这种生成-判别双重角色使VLM的能力得到充分利用。

5. **策略即工具**: 将端到端策略视为可替换工具的范式转变，为构建可泛化的Spatial AGI系统提供了正确的架构思路。

### 3.2 局限性

1. **计算开销**: 每个决策步骤需要多次世界模型想象（网格搜索+N个候选），计算开销远大于端到端策略。实时性能可能是问题。

2. **VLM空间精度限制**: 论文承认VLM缺乏绝对度量定位——无法直接从视觉输入精确输出物理坐标。这限制了精细操作能力。

3. **世界模型保真度**: 规划质量完全依赖世界模型的想象精度。如果世界模型对某些物理交互（如接触、摩擦）模拟不准，规划会出错。

4. **动作原语预定义**: MOVE, ROTATE, GRASP, RELEASE等原语是预定义的，限制了系统处理全新动作类型的能力。

5. **单一智能体**: 当前仅考虑单智能体场景。多智能体协作场景下的想象和规划更复杂。

6. **2D→3D转换的依赖**: 三角化需要多视角输入，在单视角或少视角场景下可能受限。

## 理论分析详解

### 表格设置下的泛化优势

考虑多任务上下文MDP M = {M_c, c ∈ C}，其中：
- c是任务上下文
- P是跨任务共享的通用动态
- r_c是任务特定奖励

**模仿学习的局限**:
- 当任务数|C|线性增长于数据预算K时，模仿学习会产生常数级的次优性
- 根本原因：模仿学习需要为每个任务独立学习策略

**模型规划的优势**:
- 可以高效学习通用动态P，一次学习所有任务通用
- 测试时对新上下文c，直接在学到的P上规划
- 样本复杂度不随任务数线性增长

### 线性函数近似下的泛化

在线性近似下：
- 模仿学习需要覆盖所有任务-状态-动作组合
- 模型规划只需学到共享的动态模型
- 理论证明模型规划的泛化误差界更紧

## 对Spatial AGI的深层启示

### 1. 模型规划是正确的范式

WAP证明了一个对Spatial AGI至关重要的观点：**基于世界模型的规划比端到端策略具有根本性的泛化优势**。这意味着Spatial AGI的架构应该：
- 投资于高质量的世界模型（空间模拟器）
- 使用规划而非端到端策略作为核心决策机制
- 将VLM/VLA作为工具而非整体解决方案

### 2. 想象-评估循环的力量

WAP展示了"想象→评估→优化"循环的强大能力：
- 想象: 世界模型模拟动作后果
- 评估: VLM判断结果质量
- 优化: 基于反馈改进

这个循环可以推广到Spatial AGI的各个方面——空间规划、场景理解、物理推理等。

### 3. 空间表示的图像化

位姿骨架图像的成功启示我们：**将空间信息编码为图像格式可以最大化利用视觉模型的能力**。这个原则可以推广：
- 3D空间关系 → BEV图像
- 物体6DoF位姿 → 渲染的3D投影
- 场景图 → 空间布局图

### 4. VLM作为空间推理器而非执行器

WAP正确地将VLM定位为**空间推理器**（提出、评估、反馈）而非**执行器**（直接输出动作）。VLM缺乏度量精度，但擅长语义理解和相对空间判断。这种分工对Spatial AGI的设计很有启发。

class WorldActionPlanner:
    def __init__(self, vlm_agent, world_model, controller, policy=None):
        self.vlm = vlm_agent  # VLM for reasoning
        self.wm = world_model  # Pose-image conditioned world model
        self.controller = controller  # Low-level robot controller
        self.policy = policy  # Optional: diffusion policy for fine-grained
    
    def plan_and_execute(self, task_description, state, env):
        while not done:
            # Step 1: VLM proposes actions
            action_primitives = self.vlm.propose_actions(state, task_description)
            robot_actions = self.controller.translate(action_primitives, state)
            
            # Step 2: Global optimization via imagination
            imagined_future = self.wm.imagine(state, robot_actions)
            feedback = self.vlm.evaluate(imagined_future, task_description)
            optimized_actions = self.controller.adjust(robot_actions, feedback)
            
            # Step 3: Local search with ranking
            candidates = self.grid_search(optimized_actions)
            imagined_results = [self.wm.imagine(state, a) for a in candidates]
            if self.policy:
                for i, result in enumerate(imagined_results):
                    imagined_results[i] = self.wm.imagine(
                        result, self.policy(result)
                    )
            best_idx = self.vlm.rank(imagined_results, task_description)
            
            # Step 4: Execute best action
            state, done = env.step(candidates[best_idx])

## 实验环境详细分析

### 仿真环境

WAP在以下仿真环境中验证：
- **RLBench**: 多视角机器人操作基准
- **CoppeliaSim**: 物理仿真引擎
- **多视角设置**: 第三人称视角 + 腕部视角

### 任务类型

1. **组合长时程任务**:
   - pick-and-place组合（抓取物体A放置到位置B，然后抓取物体C放置到位置D）
   - 子任务衔接是关键挑战
   - WAP通过想象和优化成功处理过渡

2. **空间泛化（新布局）**:
   - 物体位置从训练位置移动到新位置
   - 测试策略是否能追踪移动的物体
   - WAP通过世界模型想象检测到旧坐标无效

3. **零样本场景**:
   - 训练中完全未见的任务和场景
   - 依赖世界模型的通用动态学习
   - 依赖VLM的语义推理能力

4. **精细操作**:
   - 杯子边缘抓取
   - 积木堆叠
   - 需要毫米级精度

### 对比方法

- **VLA (π0等)**: 端到端视觉语言动作模型
- **WAM**: 世界动作模型，视频+动作联合生成
- **Diffusion Policy**: 扩散策略

### 关键定量结果

- 组合任务: WAP >> VLA（VLA在第一个子任务后停滞）
- 新布局: WAP准确追踪物体，VLA瞄准训练坐标
- 零样本: WAP通过模型规划成功执行新任务
- 碰撞检测: WAP通过想象成功避免碰撞

## 技术架构深度解析

### 世界模型训练

**数据收集**:
- 多种机器人的遥操作数据
- 包含多视角视频+关节位姿+动作标签
- 不同任务和场景的多样化轨迹

**Diffusion Forcing训练**:
- 历史帧：独立随机噪声（允许历史不确定性）
- 未来帧：均匀噪声（标准视频扩散）
- 位姿图像：无噪声（作为确定条件）
- 这种设计允许模型从不确定的历史中推断未来

**多视角拼接**:
- 第三人称视角和腕部视角在空间维度拼接
- 每帧同时处理两个视角
- 模型可以从两个视角推断3D空间关系

### VLM Agent设计

VLM在WAP中扮演多重角色：

1. **动作提案器**: 观察场景，提出动作原语序列
2. **位置检测器**: 从多视角图像识别目标位置
3. **安全评估器**: 评估想象rollout的安全性
4. **质量排序器**: 对候选结果排序
5. **反馈生成器**: 提供语义修正建议

这种多重角色设计充分利用了VLM的通用能力。

### 位姿图像渲染细节

1. 通过正向动力学计算关节角度
2. 正运动学得到关节3D位置
3. 从相机视角投影到2D图像平面
4. 绘制骨架连接线
5. 用VAE编码为token

这种渲染是实时的，不会成为瓶颈。

## 与ODEWorld的互补性

值得注意的是，本文的World Action Planner与论文1的ODEWorld有很强的互补性：

| 方面 | ODEWorld | WAP |
|------|----------|-----|
| 时间建模 | 连续(ODE) | 离散(扩散) |
| 动作表示 | 速度场 | 位姿图像 |
| 规划方式 | 潜在积分 | 想象-评估-搜索 |
| 精度来源 | ODE求解器 | VLM+网格搜索 |
| 泛化机制 | 连续时间外推 | 模型规划 |

两者结合可能产生更强大的系统：
- WAP的规划框架 + ODEWorld的连续时间世界模型
- 想象-评估循环 + 连续时间ODE积分
- 位姿-图像条件 + 速度场建模

## 对未来Spatial AGI系统设计的建议

基于WAP的启示，Spatial AGI系统应该：

1. **以世界模型为核心**: 而非以端到端策略为核心
2. **层次化架构**: VLM高层推理 + 世界模型物理模拟 + 低级策略执行
3. **想象-评估循环**: 作为通用推理模式
4. **策略模块化**: 不同策略作为可替换工具
5. **多视角融合**: 从多个视角理解3D空间
6. **安全第一**: 通过想象检测潜在风险
