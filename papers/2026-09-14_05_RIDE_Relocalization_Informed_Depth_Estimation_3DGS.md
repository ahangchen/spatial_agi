## 0. 论文速览

RIDE 的出发点是一个被忽视的观察：**Render–match–PnP 重定位流程中，PnP-RANSAC 筛选保留下来的 2D-3D 对应点，除了算相机位姿之外还携带了免费的金字塔级度量深度信息**——每帧最多 256 个几何验证过的稀疏度量深度锚点（anchors），却被几乎所有重定位管线直接丢弃。RIDE 把这些锚点作为稀疏度量观测，去校准一个冻结的 VDA-S 视频深度先验，从机器人 RGB 流中产出**稠密度量深度**，无需部署额外传感器。

面对锚点稀疏、分布不均、时有时无的现实，RIDE 设计了三层校准结构：

1. **全局尺度校准**：学习锚点可靠性 η + Cauchy 鲁棒加权 + 递归全局尺度记忆（卡尔曼式增益更新）
2. **局部空间校正**：锚点栅格化为 prompt，轻量解码器预测有界的空间 log-scale 残差（±0.3）
3. **光流引导的时序记忆**：SEA-RAFT 双向光流 + 前后向误差置信度，对齐复用历史校准状态（ConvGRU），支持短时锚点断供

**关键成绩**：
- 公开 RGB-D 基准（场景不相交测试）：最高 δ₁、最低 held-out 误差与时间不一致性
- 真实部署：**5 个场景 27 条真实机器人路线**零微调评测，三项稠密深度指标全部第一
- 对比 scale-only 校准基线：精度与时序一致性全面占优

**一句话总结**：重定位的"副产品"（几何验证的稀疏对应）+ 视频深度基础模型的"结构先验"= 免费的稠密度量深度；把定位几何同时服务于位姿恢复与稠密感知。

## 核心问题

### Q1: 核心算法原理

**问题**: 这篇文章的核心算法原理是什么？

**分析**:

#### 1. 核心思想和动机

**问题诊断**：机器人感知需要两样东西——位姿（我在哪）和度量深度（周围几何长什么样）。两者共享同一视觉输入，却通常被分开处理。Render–match–PnP 重定位（以 GS-CPR 为代表的 3DGS 重定位范式）流程：

```
查询图 + 粗位姿 → 3DGS 渲染 RGB+度量深度 → 渲染图/查询图匹配
→ 匹配像素反投影为地图 3D 点 → PnP-RANSAC 过滤 → 6-DoF 位姿
```

管线到此为止，**被 RANSAC 保留的内点对应所编码的度量信息被丢弃了**。

**为什么不用渲染深度直接当稠密深度？** 直觉方案是精修位姿处直接渲染 3DGS 深度图。但它有致命弱点：地图是静态快照——动态物体、新增物体不在地图里；地图几何不完整、渲染伪影会引入错误深度。而 PnP 内点对应是**几何验证过的**（它们就是用来定位成功的那批点），天然对"地图 vs 当前场景"的差异鲁棒。

**方案骨架**：稀疏度量锚点（准但不密）+ 冻结 VDA-S 视频深度先验（密但无绝对尺度）→ 校准融合。挑战在于锚点的三大现实性质：
- 稀疏（≤256/帧）且**分布不均**
- **间歇性**：纹理弱/视角差时锚点可能断供
- 可靠性参差：个别对应可能有噪声

由此推出三个模块的必要性：全局尺度记忆（尺度漂移+断供兜底）、局部空间校正（先验的空间变误差）、时序记忆（跨帧复用校准信息）。

#### 2. 主要技术方法

**度量锚点提取**（Sec III-A）：
- 粗位姿 T̄ 下从度量 3DGS 渲染 I^r_t 与 Z^r_t
- 查询-渲染匹配对 (u, ũ) 经渲染深度反投影为世界系地图点（Eq.1）
- PnP-RANSAC 精修位姿并保留内点集 J_t；每个内点给出查询像素处的深度观测（Eq.2）
- 锚点集 A_t = {(u_i, z_i)}, |A_t| ≤ 256

**先验准备**：冻结 VDA-S 输出相对深度 R_t；用 0.1% 分位数 floor ζ_t 清洗无效值，取倒数得正先验 P_t；同时输出多尺度特征 {F_t^(ℓ)}。锚点处采样先验深度 p_i，计算 log 尺度残差 r_i = log z_i − log p_i。

**学习锚点可靠性**：共享 MLP 编码每个锚点的归一化坐标、log 深度、残差统计、邻域支持、有效性信息；masked mean/max pooling 提供集合级上下文（无序操作，置换不变）；每锚点头输出可靠性 η ∈ [0,1]。

**全局尺度校准**（鲁棒递归滤波）：
- median/MAD 稳健统计 → Cauchy 权重 κ_i 抑制离群 → w_i = η_i·κ_i
- 加权平均得瞬时 log 尺度观测 α_obs（≥8 个有效锚点才有效）
- Global Scale Memory：特征预测小步长漂移（0.05·tanh 限幅），增益网络 K_t ∈ [0,1] 综合锚点支持度、残差离散度、先验统计、光流置信度、innovation 后做卡尔曼式更新 α = α⁻ + K(α_obs − α⁻)
- 观测无效时 K=0，仅靠漂移预测保持状态——**断供兜底**

**局部空间校正**：锚点栅格化为 prompt（加权残差/可靠性/占用/邻域支持/floor mask），紧凑 top-down 解码器融合 log 先验与 VDA 多尺度特征，输出全分辨率空间 log-scale 残差 δ^sp = 0.3·tanh(·)——**有界设计**保证分支只做局部乘性校准，底层结构仍由冻结先验提供。

**光流引导时序记忆**：
- 冻结 SEA-RAFT 双向光流，前后向误差 + 不确定性 → 逐像素置信度 c_t（Eq.13）
- 用当前→前一帧光流把历史隐状态 H_{t-1} warp 对齐到当前帧（Eq.14）
- ConvGRU 融合对齐历史与当前全部上下文，输出有界的时序校正 δ^tmp（门控 g_t·0.3·tanh）
- 光流缺失时置零 warped 历史、保留全局记忆——**优雅降级**

**最终输出**：D_t(u) = P_t(u)·exp(α_global + δ_local)，δ_local = δ^sp + δ^tmp。推断严格因果（只用 t 时刻及以前的信息）。

**训练**：在公开 RGB-D 视频上训练（观测采样自真实深度图，模拟部署时的锚点接口），分阶段监督；部署时直接迁移到真实重定位锚点，**零微调**。

#### 3. 算法流程和关键步骤

```
每帧:
 1. 粗位姿 → 3DGS 渲染 → 匹配 → PnP-RANSAC → 位姿 + ≤256 稀疏度量锚点
 2. 冻结 VDA-S → 相对深度先验 P_t + 多尺度特征
 3. 锚点可靠性 η → Cauchy+η 加权 → 瞬时尺度观测 α_obs
 4. 全局记忆: 漂移预测 + 增益 K 更新全局 log 尺度 α_global
 5. 锚点 prompt 解码 → 有界空间校正 δ^sp
 6. RAFT 光流 warp 历史状态 → ConvGRU → 有界时序校正 δ^tmp
 7. D = P_t · exp(α_global + δ^sp + δ^tmp)
```

#### 4. 输入输出

- **输入**：RGB 流、度量尺度 3DGS 模型、相机内参、粗位姿（来自任意现有定位方法）
- **输出**：稠密度量深度图 D_t（因果、时序一致），附带 6-DoF 位姿（重定位本身）
- **部署要求**：无需 LiDAR/dToF 等额外传感器

### Q2: 与Spatial AGI的关系

**问题**: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**分析**:

#### 1. 如何理解和表示空间

RIDE 的空间表示是**双层的**：

- **地图层**：度量尺度的 3DGS 显式场景模型——持久、可渲染、静态
- **观测层**：当前视角的稠密度量深度——实时、含动态内容

两者的桥接物是稀疏锚点：**对应点是把"地图坐标系"焊接到"当前观测"上的几何铆钉**。这个双层结构正是空间智能系统普遍面临的"先验地图 vs 实时感知"问题的干净解法——用少量高置信对应维持坐标系，用学习先验填充稠密细节。

深度表示本身采用 **log 空间的乘性分解**：D = P·exp(α_global + δ^sp + δ^tmp)——全局尺度/空间变化/时序校正三个正交因子分解，每个因子有独立的物理含义与界。

#### 2. 如何处理空间关系

- **像素-地图对应**：重定位对应本质上是"2D 图像位置 ↔ 3D 世界位置"的关系推断，是空间接地（grounding）的最严格形式——有 RANSAC 几何验证背书
- **跨帧空间关系**：光流 warp 实现像素级空间对齐，把"上一帧哪里校正过"迁移到"这一帧对应位置"——空间关系成为记忆复用的索引结构
- **尺度一致性**：全局尺度记忆保证整个序列的深度共享统一度量基准——空间关系（多远、多大）跨帧可比，这对导航与操作的空间推理是必要条件

#### 3. 对Spatial AGI的启发

1. **"副产物复用"的设计哲学**：重定位管线的中间产物（对应点）免费转化为稠密感知的监督信号。Spatial AGI 系统设计中应系统审计每个模块的副产物——定位的对应点、SLAM 的路标、建图的渲染深度，都可能喂养其他感知任务

2. **几何验证数据 > 原始渲染**：地图渲染深度会被"地图-现实差异"污染，而 RANSAC 内点是几何验证过的。这一原则推广：**空间智能系统中，经一致性检验的稀疏信号往往比未经检验的稠密信号更值得信任**

3. **冻结基础模型 + 有界校准的架构模式**：VDA-S 提供结构、校准网络只学有界的 log-scale 修正（±0.3）——保护基础模型能力的同时注入部署环境的度量约束。与今日 AffordanceVLA 的"结构化中间监督保护 backbone"异曲同工，但手段相反：AffordanceVLA 是监督信号锚定，RIDE 是输出端有界残差

4. **间歇性观测的工程化处理**：可靠性学习 + Cauchy 鲁棒 + 递归记忆 + 优雅降级——这套"观测不可靠时怎么办"的工具箱对一切 Spatial AGI 在野外部署（GPS 掉线、特征缺失、天气干扰）都有参考价值

5. **因果性的部署纪律**：严格因果推断（无未来帧）——与 CST-WM 的因果世界模型、AffordanceVLA 的单向注意力形成呼应：在线空间智能系统全面拥抱因果约束

#### 4. 可以应用的Spatial AGI场景

- **移动机器人导航**：建图一次（3DGS），后续每次进入场景免费获得稠密度量深度用于避障与可通行性分析
- **AR/VR 重定位感知一体化**：重定位同时输出虚拟-现实融合所需的环境深度
- **动态场景监控**：地图层静态 + 观测层动态，差分即变化检测（新增/移动物体）
- **多机器人系统**：共享 3DGS 地图 + 各自 RGB 流 = 各自稠密深度，无传感器硬件差异要求
- **数据采集管线**：既有 3DGS 地图的场景，任意 RGB 视频流都可转化为伪 RGB-D 训练数据

### Q3: 创新点和局限性

**问题**: 基于前面的分析，这个方法的主要创新点和局限性是什么？

**分析**:

#### 1. 主要创新点

1. **重定位副产物的价值发现**：首次系统性地把 render–match–PnP 中被丢弃的 PnP-RANSAC 内点对应转化为稀疏度量深度锚点——连接位姿恢复与稠密深度估计，部署零额外传感器。这是全文最"漂亮"的观察，属于典型的"Everyone overlooked"式贡献

2. **观测质量感知的鲁棒尺度估计**：学习的锚点可靠性（置换不变的集合编码）× Cauchy 鲁棒权重的双重加权，配合 ≥8 锚点的有效性门槛——显式建模"观测本身不可信"这一现实

3. **有界残差校准范式**：全局尺度（递归记忆）+ 空间（0.3·tanh）+ 时序（门控 0.3·tanh）三层有界 log-scale 修正，冻结先验兜底结构——每个校正因子都有明确的物理含义与数值界

4. **光流引导的校准记忆**：用前后向光流误差做置信度的历史状态 warp 复用——时序深度补全文献中少见的"校准信息（而非深度本身）跨帧传递"设计，天然支持锚点断供

5. **部署形态的严谨性**：训练（RGB-D 视频采样观测）与部署（重定位锚点）的域差距靠零微调评测验证；5 场景 27 条真实机器人路线的现场评测在学术工作中少见地扎实

#### 2. 主要局限性

1. **依赖预先构建的度量 3DGS 地图**：整个方法以"地图已存在且度量尺度正确"为前提；动态环境需要地图更新机制（论文未涉及在线建图/地图维护）

2. **初始化依赖**：度量输出在全局尺度首次初始化前无效——冷启动阶段的深度不可用；长时间锚点断供下尺度漂移累积行为未量化

3. **锚点覆盖的结构性盲区**：锚点来自图像匹配，弱纹理区域（白墙）、重复纹理、地图外的动态物体表面天然无锚点——恰恰是渲染深度也不可信的区域，深度质量在这些区域退化为纯先验

4. **单帧 ≤256 锚点的信息量上限**：空间校正解码器要从 ≤256 个稀疏 prompt 插值全分辨率残差，复杂场景的空间变误差可能欠拟合

5. **模块堆叠的延迟与复杂度**：VDA-S + SEA-RAFT 双向 + 匹配 + PnP + 三个校准网络——实时性未报告，机器人端部署的计算预算存疑

6. **动态物体深度无真值约束**：锚点只落在静态地图结构上，动态物体的深度完全依赖先验外推——对避障等安全关键用途需要保守处理

#### 3. 与其他相关工作的对比

| 维度 | 渲染深度直接用 | 传感器深度补全 | 时序补全 (RayFusion/SVDC) | 单帧先验+稀疏 | **RIDE** |
|------|------|------|------|------|------|
| 稀疏观测来源 | — | LiDAR/dToF | 外部稀疏图 | 各式 | **重定位 PnP 内点** |
| 地图-现实差异鲁棒 | ✗ | — | — | — | **✓（几何验证）** |
| 额外传感器 | 无 | 需要 | 需要 | 视方法 | **无** |
| 时序记忆 | — | 多为逐帧 | ✓ | ✗ | **✓（校准级记忆）** |
| 断供处理 | — | — | — | — | **✓（全局记忆兜底）** |
| 基础模型 | — | — | — | ✓ | **✓ 冻结 VDA-S** |

## 核心技术发现

1. Render–match–PnP 重定位的 PnP-RANSAC 内点对应可免费转化为几何验证的稀疏度量深度锚点（≤256/帧）
2. 稀疏锚点 + 冻结视频深度先验 + 三层有界校准（全局/空间/时序）= 零额外传感器的稠密度量深度
3. 学习的锚点可靠性 + Cauchy 权重解决观测质量参差；≥8 锚点门槛保证统计有效性
4. 光流引导的校准状态 warp 复用支持短时锚点断供；全局尺度记忆保证长期尺度一致
5. 公开基准 δ₁ 最高、时序不一致最低；5 场景 27 条真实机器人路线零微调全部指标第一
6. 几何验证的稀疏信号比地图渲染的稠密信号更能抵抗地图-现实差异

## 个人思考

### 最令人兴奋的发现

**"锚点免费"这个观察有一种经济学式的优雅**：重定位管线为了算位姿已经付出了渲染、匹配、RANSAC 的全部成本，稠密深度所需的稀疏度量观测就躺在废料堆里。这类贡献的可复制性强——读完论文任何人都能在自己的 GS-CPR 管线上加十几行代码把锚点吐出来。好的系统研究就是把被浪费的信息变成价值。

**有界校正的设计也值得铭记**：三个校正分支全部限幅（漂移 0.05、空间/时序 0.3·tanh），底层结构永远由冻结先验兜底。这是对"微调破坏基础模型"问题的输出端解法——校正量在数学上就不可能压倒先验。与 AffordanceVLA 的监督端锚定、GraFT 的免训练外挂构成同一问题的三种解法谱系。

**真实评测的诚意**：27 条真实机器人路线、5 个场景、零微调——在 3DGS 重定位文献普遍只在 7-Scenes/12-Scenes 上刷位姿指标号称 SOTA 的背景下，愿意走出实验室测稠密深度的工作非常稀缺。真实的机器人序列意味着动态行人、地面反光、传感器运动模糊，这些才是部署的真实面目。

### 潜在局限

1. **静态地图假设是最大的软肋**：真实家庭/仓库环境天天变。地图过期后锚点仍会指向旧几何——虽然比渲染深度鲁棒（RANSAC 会过滤大部分），但系统性的环境变迁（家具搬动）会静默地降低锚点可用性直至断供，而系统对此没有显式诊断
2. **深度误差不均匀性**：锚点区域准、非锚点区域靠先验——下游（如避障）如果假设深度均匀可靠会踩坑；论文报告整体指标但未按"锚点距离"分层分析误差，这个信息对安全使用很重要
3. **与 SLAM 的关系暧昧**：定位依赖预建地图，本质是"重定位"而非"持续建图"；与 SLAM 系统整合（边定位边更新地图和锚点质量）是显然但未做的下一步

### 与今日研究的关联

- **与 AffordanceVLA 的"锚点"概念遥相呼应**：一个是几何锚点（稀疏度量观测锚定深度先验到地图坐标系），一个是语义锚点（可供性监督锚定 VLM 能力不被动作损失侵蚀）——今天两篇论文都用"少量高置信信号锚定大量低约束预测"的结构，这可能是 Spatial AGI 系统设计的通用模式
- **因果纪律的三连**：CST-WM 的因果世界模型切边、AffordanceVLA 的 UAA 单向注意力、RIDE 的严格因果推断——在线空间智能全面接受"不能用未来"的约束
- **GraFT 的外挂哲学 vs RIDE 的校准哲学**：GraFT 完全不动 MLLM 权重外挂场景图；RIDE 冻结深度基础模型只学有界校准。两者都拒绝大规模微调，都相信"基础模型已懂结构，缺的只是接地的少量信息"
- 与 GraFT 同属 3DGS 生态：GraFT 把 3DGS 提升为场景图供 MLLM 查询，RIDE 把 3DGS 用作定位与深度的几何底座——3DGS 正在从"新视角合成"演化为空间智能的**通用场景容器**

## 总结

### 核心发现总结
RIDE 发现重定位管线中 PnP-RANSAC 保留的对应点携带被浪费的度量深度信息，将其转化为稀疏度量锚点，配合冻结 VDA-S 视频深度先验与三层有界校准（学习可靠性的鲁棒全局尺度记忆、锚点 prompt 空间校正、光流引导时序记忆），在无额外传感器条件下从 RGB 流产出稠密度量深度。公开基准与 27 条真实机器人路线的零微调评测全面领先 scale-only 校准基线。

### 对Spatial AGI的意义
定位与稠密感知不必是两个系统——几何验证的稀疏对应足以把基础模型的深度先验焊接到任意预建地图的度量坐标系上。对 Spatial AGI 的启示：(1) 系统审计每个模块的可复用副产物；(2) "冻结基础模型 + 有界校准"是在基础模型时代注入部署约束的低风险模式；(3) 间歇性观测的鲁棒处理是在野部署的必修课。开放缺口：动态环境下的地图维护、误差空间分布的显式建模、与 SLAM 的在线整合、端侧实时性。

### A1. 核心公式速查

```
锚点提取:  X^w = R̄[Z^r(ũ)K⁻¹ũʰ] + t̄          (渲染像素→地图点)
          z_i = e₃ᵀ(R̂X^w + t̂)                  (内点→深度观测)

先验:      P_t(u) = 1/where(v_t, R_t, ζ_t)       (floor 清洗后取倒)

全局尺度:  w_i = η_i · [1+((r_i−r̄)/γ)²]⁻¹        (可靠性×Cauchy)
          α_obs = Σw_i r_i / Σw_i
          α = α⁻ + K_t(α_obs − α⁻)               (增益更新)

空间校正:  δ^sp = 0.3·tanh(解码器(prompt, log先验, VDA特征))

时序记忆:  c_t = m·exp[−(e_fb/3)²]·exp[−U/5]      (前后向误差置信度)
          H̃_{t−1} = c·m·B(H_{t−1}, u+b_t)       (光流warp)

```

| 因子 | 作用范围 | 界 | 信息来源 | 断供行为 |
|------|---------|-----|---------|---------|

## 附录B: 深度延伸分析

### B1. 锚点的信息论视角

为什么 ≤256 个锚点足以校准整帧深度？关键在于**信息分工**：

- 结构信息（哪近哪远、物体形状）：由 VDA-S 先验免费提供——这是互联网级深度数据训练的成果
- 缺失信息只有**度量尺度的低维流形**：全局尺度是 1 维，空间变化是低频场，时序变化是慢漂移

锚点的信息量只需覆盖这个低维流形，不需要重建场景。这个"先验承担高维、观测只补低维"的分工，是对"基础模型时代小数据能干什么"的精确回答：**小数据足以校准，不足以从头学**。反过来说，如果任务需要的修正超出有界设计（±0.3 log）的范围——例如先验完全错误的场景类型——系统会失效而非报错，使用方需要理解这个保证的边界。

### B2. 与机器人深度感知的生态位分析

机器人获取度量深度的现有选项对比：

| 方案 | 精度 | 成本 | 视野 | RIDE 生态位 |
|------|------|------|------|------------|
| LiDAR | 高 | 高（数千美元） | 有限视角/盲区 | 无需硬件 |
| RGB-D 相机 | 中（距离受限） | 中 | 有限量程 | 无需硬件 |
| dToF (手机级) | 低-中 | 低 | 稀疏 | 互补 |
| 纯学习深度 | — | 零 | 全帧 | 尺度不可靠 |
| **RIDE** | 中-高 | **零增量**（复用定位系统） | 全帧 | 需预建地图 |

RIDE 的本质是把"建图时的一次性投入" amortize 到"部署时的持续深度输出"。对已部署 3DGS 重定位的场景（AR、巡检机器人），这是纯增量收益。

### B3. 失败模式分析

1. **地图过期**：环境大幅改变后锚点数量骤降 → 系统退化为纯先验+陈旧全局尺度，深度"看起来合理"但尺度漂移——最危险的静默失败。缓解思路：把锚点数量/可靠性作为置信度输出给下游
2. **初始化窗口**：尺度未初始化前输出无效；机器人冷启动需依赖重定位成功——定位失败则深度全盘不可用（单点故障）
3. **低纹理长廊**：匹配困难 → 锚点长期 <8 → 靠记忆漂移硬撑；长走廊恰是机器人最常见的退化场景之一
4. **强动态场景**：行人密集时大量匹配落在动态物体上，RANSAC 内点率下降——可靠性网络需在训练中见过此类分布

### B4. 有界校准 vs 监督锚定 vs 免训练外挂：基础模型时代的三种接地策略

今日论文合辑呈现的谱系（值得记入方法论）：

| 策略 | 代表 | 做法 | 适用条件 |
|------|------|------|---------|
| 免训练外挂 | GraFT | 结构化知识注入上下文，不动权重 | 基础模型已具足够能力，缺知识 |
| 监督锚定 | AffordanceVLA | 结构化中间目标作为语义锚，联合训练 | 有大量领域数据，防能力侵蚀 |
| 有界校准 | RIDE | 冻结主干，只学有界输出残差 | 先验结构正确，只差部署域的低维修正 |

三者共同前提：**基础模型包含正确的东西，损坏它的风险大于补足它的收益**。这是 2026 年具身/空间智能的重要共识转向——从"微调一切"到"外科手术式接地"。

### B5. 潜在的后续研究方向

1. 在线地图维护：锚点与新观测的持续融合，3DGS 地图的增量更新（地图层动态化）
2. 锚点置信度传导：向下游任务输出逐像素深度置信图（按锚点距离/可靠性），供安全层使用
3. 与 VIO/SLAM 融合：锚点作为视觉路标进入滑窗优化，双向增强
4. 尺度自诊断：全局记忆的 innovation 方差作为"地图过期警报"
5. 端侧蒸馏：VDA-S+RAFT+校准头的蒸馏部署（实时性前提）
6. 多地图/多楼层：大规模环境的地图检索与锚点切换

### B6. 评测方法论点评

论文的评测设计有两点值得学习：
- **场景不相交**（scene-disjoint）公开基准：排除记忆效应，测的是校准器的泛化而非场景过拟合
- **训练-部署接口对齐**：训练时从 RGB-D 采样稀疏观测模拟锚点，部署时换真锚点且零微调——接口级 domain gap 的诚实检验。很多"深度补全"工作训练用 LiDAR 稀疏模式、部署时分布完全不同，RIDE 的处理更严谨

## 附录C: 方法细节补充

### C1. 全局尺度记忆的滤波器解读

RIDE 的全局尺度更新本质上是一个**自适应增益的标量卡尔曼滤波**：

```
预测步:  α⁻ = α_{t-1} + Δα_drift        (过程模型: 缓慢漂移)
更新步:  α = α⁻ + K_t(α_obs − α⁻)       (观测更新)
增益:    K_t = f(锚点支持度, 可靠性, 残差离散度, 先验统计, 光流置信度, innovation)
```

与标准 KF 的差异：增益不是由协方差递推解析给出，而是由网络从丰富的上下文特征预测——本质是"学习卡尔曼增益"，用数据驱动的灵活性换取解析可解释性。漂移项限幅 0.05·tanh 对应"尺度不会突变"的物理先验。

观测有效性门槛（≥8 个有效锚点）是简单的统计功效保障：低于该数量时加权均值方差过大，宁可不用。

### C2. 锚点可靠性网络的设计考量

- **置换不变性**：masked mean/max pooling 使输出不依赖锚点顺序——对应点集合天然无序
- **特征内容**：归一化坐标（空间位置先验：图像边缘/天空区锚点更不可靠）、log 深度与残差统计（数值一致性）、邻域支持（孤立锚点更可疑）、有效性 flag
- **共享 MLP + per-anchor head**：编码共享保证集合内一致的表示，头部分离允许逐点打分

这个"逐元素质量评估 + 集合上下文"的模式可推广到任何稀疏观测场景（特征匹配质量、雷达回波质量等）。

### C3. 光流选择 SEA-RAFT 的理由推断

- 双向推断输出不确定性 U_t——置信度计算 (Eq.13) 直接需要
- 前后向闭环误差 e_fb 是运动一致性的标准检验：遮挡/出界区域误差大 → 置信度低 → warp 的历史状态被抑制
- 冻结使用：光流只需可靠对齐，无需域适应

### C4. 训练细节补充

- 训练数据：公开 RGB-D 视频；稀疏观测从真值深度图采样，模拟锚点的稀疏/不均/间歇特性（含模拟断供）
- 分阶段训练（staged）：先校准各分支，后联合微调时序部分（依论文 Sec III-C；具体阶段划分见原文）
- 因果约束贯彻训练：所有输入截断至 t 时刻，与部署一致

### C5. 与 3DGS 重定位前沿的关系表

| 方法 | 3DGS 角色 | 输出 | RIDE 的增量 |
|------|----------|------|------------|
| GS-CPR | 渲染+深度源 | 6-DoF 位姿 | 内点 → 度量锚点 |
| GSFeatLoc | 特征高斯 | 位姿 | — |
| STDLoc | 稀疏到稠密特征 | 位姿 | — |
| **RIDE** | 渲染+深度源 | **位姿 + 稠密度量深度** | 感知任务解锁 |

## 附录D: 批判性追问

1. **锚点深度与先验深度的系统偏差**：锚点来自地图（建图时刻），若先验在对应位置给出的相对深度与地图几何形状差异大（如新增家具遮挡墙面），残差 r_i 系统性偏移，全局尺度被拉偏——Cauchy 只能抗离群不能抗系统性偏差。是否应把"残差的空间结构"也纳入漂移预测？
2. **单目先验的尺度分层误差**：VDA-S 的相对深度在不同深度层（近/中/远）的比例误差不同，单一全局 log 尺度是折中；空间校正能否覆盖深度相关的尺度变化取决于锚点的深度分布——远景常缺锚点
3. **评测的基线公平性**：对比方法中"scale-only calibration"是最直接基线，但与其他用传感器稀疏观测的补全方法比较时，锚点质量与 LiDAR 不可同日而语——RIDE 的价值主张是"零增量成本"而非"绝对精度"，阅读时注意不要过度解读指标差距
4. **重复纹理的锚点**：错误匹配若恰好在 RANSAC 一致（对称结构），会成为高置信坏锚点——可靠性网络能否识别这种"几何自洽但语义错误"的对应存疑
