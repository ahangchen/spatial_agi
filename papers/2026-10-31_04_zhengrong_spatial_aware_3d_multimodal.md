## 0. 一句话总结

这是一份扎实的工程复现与适配报告：针对建筑场景度量空间 VQA 数据集，打通了两条端到端微调管线——HiSpatial-3B（RGB + MoGe 单目度量点图分支的全量 SFT，精度 1.73% → 79.89%）与 Qwen3-VL 8B/32B（QLoRA 混合域指令微调，20.74% → 45.27% / 30.79% → 47.60%），并沉淀了数据转换、几何预处理、混合域训练、统一评测的完整工程栈与"输出格式分布是训练域的一部分"等经验教训。

## 核心问题

### Q1: 核心算法原理是什么？

#### 1. 核心思想和动机

VLM 在语义识别、caption、VQA 上已很强，但从单张 2D 图像做**可靠度量 3D 推理**仍很难。目标任务是兼具语义理解与几何敏感度的空间任务：物体计数、建筑高度估计、占地面积比较、成对距离估计、空间排序、相对方向推理等 12 类问题。

本文立场明确：**不是从头训基础模型，而是构建并验证一个面向强开源多模态模型的实用适配栈**。选了两个互补的模型家族做对照实验：

- **HiSpatial-3B**：在输入层显式注入几何（度量点图分支），天然适合定量/关系型空间推理
- **Qwen3-VL 8B/32B**：强通用多模态基线（内含空间与 3D grounding 训练数据），用于检验"纯指令微调能把任务专业化推多远"

双分支设计的方法论价值：**把"几何重建的局限"与"域适配/指令格式/语言推理的局限"分离开来**——两条管线在同一份监督与同一评测接口上跑，差异可归因。

#### 2. 主要技术方法

**（A）HiSpatial 分支（显式几何注入 + 全量 SFT）**

- 理论基础：HiSpatial 把 3D 空间智能形式化为四级层次——基础几何感知 → 物体级空间理解 → 物体间关系理解 → 抽象空间推理（视角采择、多步空间问题）
- 架构：PaliGemma2-3B（SigLIP 视觉编码器 + Gemma 2）骨干；训练与推理时用 MoGe 式单目几何估计器产出**度量尺度点图** P = G(I) ∈ R^{H×W×3}，每像素 3D 坐标
- 表示流：v = E_rgb(I)，s = E_xyz(P)，h = F(v, s, q)，标准 SFT 交叉熵
- 度量尺度点图是关键：目标任务要物理单位的定量推理，affine-invariant 不够
- 数据准备四步：载入场景图+对齐 VQA 记录 → MoGe 产稠密 XYZ 张量 → 图像+几何+对话元数据序列化为 WebDataset → 目标域与通用视觉指令数据混合
- 点图**预计算+序列化**：几何估计与模型优化解耦、省重复预处理、可复现
- 训练配置：从 released checkpoint 起训，per-device bs=4、有效 bs=32、先 1200 步后扩到 3600 步、每 400 步存 checkpoint；训练/推理环境分离
- 复现 sanity check（未达原论文算力但验证管线正确）：CV-Bench-3D 94.17%、CV-Bench Relation 94.77%、Embspatial 73.90%、RoboSpatial 78.05%

**（B）Qwen3-VL 分支（QLoRA 混合域指令微调）**

- 架构背景：视觉编码器 + MLP merger + Qwen3 decoder，交错 MRoPE（时空位置建模）+ DeepStack（多级视觉特征注入语言模型）；预训练配方本身含空间推理与 3D grounding 数据
- 适配：4-bit 量化 + 低秩适配器（y = (Ŵ₀ + αBA)x）；视觉编码器冻结，LoRA 作用于语言侧 transformer 投影（可选启用多模态 connector）——8B/32B 在有限 GPU 上可行
- 数据：同一 VQA 监督转多模态对话格式；1000 场景按 900/100 划分，12 问题类型 → ~10,800 训练 / 1,200 测试实例
- 混合域策略：目标空间指令数据 + 通用多模态指令数据一起训，防窄域过特化

**（C）统一评测层**

- 统一推理接口：sample_id → 图像 → 模型/checkpoint → 归一化 JSON 预测
- 任务感知评分：计数=直接比对；度量问题（高度/距离）=数值解析+相对容差；开放关系答案=语义归一化
- 统一多模型 runner：HiSpatial、Qwen3-VL、LLaVA-3D、SpatialRGPT 消费同一 JSONL 基准

#### 3. 算法流程和关键步骤

HiSpatial 管线：
1. 数据层：原始/风格化 RGB、bbox 叠加图、实例 mask、相机位姿、场景标注 → 对齐的 image-question-answer 记录 + 可复现划分
2. MoGe 预处理：每图 → 度量点图 → WebDataset 序列化
3. 混合域 SFT（目标建筑数据 : LLaVA-NeXT 通用 VQA ≈ 1:1）
4. checkpoint 批量推理 + 自动评测

Qwen3-VL 管线：
1. VQA → 对话指令格式（含 <image> 占位）
2. 4-bit QLoRA：冻结视觉编码器，LoRA 训语言侧
3. 混合域训练
4. 同一评测接口

#### 4. 输入输出

- 输入：建筑场景 RGB（原版/风格化/bbox 高亮变体）+ 空间问题
- 输出：物理单位的定量答案（米制距离/高度）、计数、空间关系描述
- 评测输出：统一 JSON 预测文件 → 任务感知自动评分

### Q2: 与通用空间智能（Spatial AGI）有什么关系？

#### 1. 如何理解和表示空间

本文的空间观是**分层度量主义**：
- 空间智能的四级层次（感知→物体→关系→抽象推理）给出了一张能力地图，Spatial AGI 的训练与评测可以按层诊断
- 度量尺度（metric scale）被反复强调：affine-invariant 几何只能支撑定性关系，物理单位的推理需要度量点图——**空间智能的"量纲"问题被摆到台面**
- 空间知识可以通过两条路径获得：输入层显式注入（几何分支）vs 参数层隐式学习（指令微调激活预训练空间先验）

#### 2. 如何处理空间关系

- 点图把"像素→3D 坐标"的关系前置到输入，模型的关系推理变成在真 3D 坐标上的数值运算
- 12 类问题覆盖空间关系的完整谱系：一元（计数、高度）、二元（距离、占地比较）、序关系（排序）、方向关系（相对方位）
- 评测的相对容差设计承认了空间估计的固有不确定性——空间关系的"正确"是容差内的

#### 3. 对 Spatial AGI 的启发

1. **混合域训练是空间专业化的必要条件**。窄域空间监督会同时教格式与破坏通用能力；混合域（1:1 或 8:2）平衡专业化与保留。这适用于任何 Spatial AGI 的垂直微调。
2. **"输出格式分布是训练域的一部分"**：自由格式与选择题监督朴素混合导致自由格式任务大跌，8:2 混合才恢复——这个发现超出空间领域，是所有指令微调的通用教训。
3. **显式几何 vs 隐式先验的对照方法学**：想给 VLM 加空间能力时，应同时跑"加几何输入"与"纯指令微调"两条线，归因才有依据。结果显示两者互补：HiSpatial 上限更高（79.89% vs 47.60%），Qwen3-VL 通用性更好。
4. **模型规模≠空间推理能力**：32B 混合域后仅 47.60%，远低于 3B+几何分支的 79.89%——在度量空间任务上，正确的表示注入胜过参数堆叠。
5. **工程栈本身是可复用的 Spatial AGI 基础设施**：数据转换、几何预处理、混合训练、统一评测的完整模板。

#### 4. 可以应用的 Spatial AGI 场景

- 建筑测绘/城市空间的 VLM 辅助度量问答
- 无人机/机器人的单目度量空间感知前端
- 空间 VLM 的评测基准建设方法学（任务感知评分器）
- 任何垂直空间领域的适配管线模板（医学影像空间关系、室内布局理解等）

### Q3: 主要创新点和局限性是什么？

#### 1. 主要创新点

1. **双管线对照实验设计**：显式几何注入（HiSpatial）vs 纯指令微调（Qwen3-VL）在同一数据、同一评测上的系统对比，归因清晰
2. **完整的可复现工程栈**：从数据转换到统一多模型评测的端到端闭环，工程完成度高
3. **格式组成效应的实证发现**：自由格式/选择题混合比例显著影响任务表现（8:2 最优），把"答案格式分布"提升为显式的训练域设计维度
4. **迁移性证据**：HiSpatial 在独立收集的风格化 split 上 14.9% → 55.1%，证明学到的是任务结构而非场景记忆
5. **点图预计算序列化**的工程决策：解耦几何估计与训练，提升复现性

#### 2. 主要局限性

1. **单场景类型**：建筑-centric 数据集，室内、自然场景、密集物体场景未验证；几何分支在纹理弱/反射表面的 MoGe 失效场景未测
2. **精度天花板**：最好 79.89%，意味着 ~20% 空间推理仍然错误，且错误类型分析（哪些层级失败）报告未深入
3. **Qwen3-VL 上限存疑**：47.6% 的结果表明纯 QLoRA 对度量空间任务帮助有限——但未尝试给 Qwen3-VL 也加点图输入（组合两策略），对照设计留了缺口
4. **MoGe 依赖**：点图质量上界由单目几何估计决定，估计误差如何传播到答案误差未量化
5. **技术报告性质**：无方法学创新，外部效度（其他数据集/模型族）未知

#### 3. 与相关工作的对比

- **vs HiSpatial 原论文**：本文是其下游适配与工程验证，复现 sanity（CV-Bench-3D 94.17%）表明管线忠实
- **vs SpatialRGPT、LLaVA-3D**：被纳入统一评测的同类空间 VLM，本文贡献评测基础设施而非新模型
- **vs 昨日精读的 SpatioLM（general physical spatial intelligence VLM）**：SpatioLM 走大规模物理空间预训练路线，本文走小数据垂直适配路线——两种资源预算下的现实选择对照

## 核心技术发现

1. **度量点图输入分支带来的增益（+78 个百分点）远大于参数规模（8B→32B 仅 +2.3 个百分点）**——在度量空间推理上，表示 > 规模
2. **混合域采样是防窄域过特化的有效手段**，且最优混合比例与任务格式相关
3. **答案格式分布应作为训练域的显式组成部分**来设计与调控
4. **任务感知评测**（计数直比/度量容差/语义归一化）是空间 VQA 评测的正确粒度
5. 预训练 VLM（Qwen3-VL 含 3D grounding 数据）的隐式空间先验可通过指令微调部分激活，但对定量度量任务远不够

## 个人思考

### 最令人兴奋的发现

最扎眼的数字是"3B+点图 79.89% vs 32B 纯微调 47.60%"。这是对"空间智能靠规模涌现"叙事的一个清醒反例：**空间智能可以被"喂"进去（好的输入表示），而不必完全"长"出来（规模+数据）**。对资源有限的 Spatial AGI 团队，这几乎是一份行动指南：先把几何表示做好，再谈模型规模。

### 潜在局限

这份报告最大的价值是工程诚实（复现数字、失败实验都写），但科学贡献有限。最该做而未做的实验是"Qwen3-VL + 点图输入"的组合臂——如果组合臂显著超过两个单臂，结论会从"两条互补路线"升级为"几何注入与通用先验可叠加"。另外 79.89% 的错误侧写（哪四级层次失败）缺失，限制了它对 Spatial AGI 能力地图的诊断价值。

### 与昨日研究的关联

昨日 SpatioLM 用"通用物理空间智能"的预训练路线把空间能力做进基础模型，本文则示范了没有预训练预算时的下游适配打法。两者合起来回答了 Spatial AGI 的资源-能力权衡谱系：预算大→像 SpatioLM 一样把物理先验预训练进基座；预算小→像本文一样用 MoGe 点图注入+混合域 SFT。而 4 月精读过的 HiSpatial 原论文（当时 Top 论文）在此被下游验证了实用性——好的表示设计会持续产生复利。

## 关键数据

- **HiSpatial 目标域**: 1.73% → 64.69%（1200步）→ 73.90%（2400步）→ **79.89%**（3600步）
- **风格化独立 split**: 14.9% → 55.1%（同 checkpoint 序列）——迁移性证据
- **Qwen3-VL-8B**: 20.74% → 45.27%；**Qwen3-VL-32B**: 30.79% → 47.60%（QLoRA 混合域）
- **复现 sanity**: CV-Bench-3D 94.17% / Relation 94.77% / EmbSpatial 73.90% / RoboSpatial 78.05%
- **数据**: 1000 场景（900/100 划分）、12 问题类型、~10.8k 训练 QA
- **训练配置**: 全量 SFT（bs 32）vs QLoRA 4-bit（冻结视觉编码器）
- **格式混合**: 自由格式:选择题 = 8:2 最优；1:1 朴素混合致自由格式大跌

## 总结

### 核心发现总结

在度量空间 VQA 任务上，显式几何表示注入（度量点图）的收益压倒性地大于模型规模与纯指令微调；混合域训练与格式感知的数据组成是专业化微调成功的关键工程要素。本文以完整的可复现工程栈把这两点做实。

### 对 Spatial AGI 的意义

这是一份 Spatial AGI 的"施工图"级参考：能力分层诊断框架、度量表示注入策略、混合域配方、任务感知评测协议，四件套可直接搬用到任何垂直空间领域。它提醒我们：通往空间智能的路上，表示工程与数据工程至少与模型工程同等重要。
