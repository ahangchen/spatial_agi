# From Pixels to Actions — Towards Native Vision-Language-Action Policies (NEO-VLA)

**发表日期**: 2026-11-04
**arXiv链接**: https://arxiv.org/abs/2611.06918
**PDF链接**: https://arxiv.org/pdf/2611.06918
**HTML版本**: https://arxiv.org/html/2611.06918v1
**模型名**: NEO-VLA

## 论文概览

这篇论文提出一个结构性问题：**VLA 模型的动作策略是否应该继承一个固定的视觉端点（编码器输出），还是应该直接访问骨干网络中持续演化的视觉计算？**

现有 VLA（RT-2、π0、GR00T 等）几乎都用 CLIP/SigLIP/DINOv2 等预训练视觉编码器先把图像压缩成特征，再交给语言骨干与动作模型。这个接口暴露了编码器输出，却隐藏了产生它的整个视觉计算层级。而操作任务恰恰依赖最容易被这个抽象损害的视觉信号：局部几何、边界、深度、细微状态变化。

NEO-VLA 的答案：**encoder-free（结构原生）VLA**。图像经轻量 patch 卷积直接进入骨干 token 空间，与语言全程共同演化；一个 flow-matching 动作专家从骨干的**多个不同深度层**读取缓存的 keys/values 来预测连续动作块。

核心实证发现：
1. 控制变量对比下，原生（encoder-free）架构优于编码器架构；全量微调会缩小但不消除差距；单纯加大规模无法弥补。
2. **动作关键信号往往在最终视觉表示之前就很早就达到峰值**——分层探测（layer-wise probing）与激活干预（激活交换实验）双重证实。
3. 在 LIBERO、LIBERO-plus、RoboTwin 2.0 上，NEO-VLA 取得更强且更鲁棒的控制，尤其在相机扰动与图像噪声等分布偏移下优势明显。

## 核心问题

### Q1: 这篇文章的核心算法原理是什么？

**1) 核心思想和动机**

- 操作任务需要语义理解与细粒度空间推理并存：识别指令所指、推断目标位置、确定夹爪相对运动。语义偏向深层表示，几何细节偏向浅层表示——**动作需要的视觉信息分散在计算层级的不同深度**。
- 固定编码器端点的问题：
  - 视觉处理对 VLA 性能至关重要（Zhang et al. 2026b：视觉模块是主要瓶颈）；
  - 视觉组件对剪枝异常敏感（2026a：视觉编码器/骨干/投影器是最敏感组件）；
  - 动作微调会损害预训练视觉表示（Kachaev et al. 2025）。
- 因此作者重新审视接口本身：让动作预测直接利用骨干内部**演化的**视觉表示，把"视觉读取深度"变成显式的架构选择。

**2) 主要技术方法**

**(a) 结构原生的视觉接口**

- 遵循 NEO 系列的 encoder-free 设计：两级卷积 patch embedder，总步长 32，每 32×32 区域产生一个视觉 token；
- 无预训练视觉编码器、无图像 codebook、无 autoencoder——像素直接进入语言骨干 token 空间；
- Native Rotary Position Embedding：位置分解为（时间, 高, 宽）坐标、解耦旋转频率；图像 token 保留显式 2D 空间坐标，视频沿时间轴推进，统一处理图像/视频/交错序列；
- 模态感知注意力：文本 token 因果注意力，视觉 token 在每个视觉块内双向注意力——支持稠密空间建模，同时视觉与语言表示跨层共同演化。

**(b) 40 层 2B 原生骨干的三阶段训练**

1. 大规模图文预训练建立视觉感知（同时保持语言模型的语言能力）；
2. 中训练深化视觉-语言对齐（captioning、对话、OCR、检测数据）；
3. 高质量多模态交互的指令微调——从多模态感知推进到推理。

**(c) 多模态前缀（multimodal prefix）**

- 上一时刻与当前时刻的多视角图像（每个时间块最多 3 个相机视角，每视角预算最多 88 个视觉 token，保持原生纵横比动态 patch 化，padding 位置从注意力中掩蔽）；
- 每视角带相机身份 token + 投影相机几何（内参、旋转由共享 MLP 编码）+ patch token（单一 patch embedder 跨相机/视角/时间共享）；
- 结构化 prompt：控制频率、机器人具身、夹爪配置、动作参考系、任务指令；
- 机器人本体感知：6 个 token（Arm0/Arm1/身体的上一时刻与当前状态），状态 MLP 联合编码测量值与有效性掩码；缺失组件直接掩蔽，同一 token 接口适配不同机器人配置；
- 所有前缀 token 用（时间、高、宽）三维旋转位置编码联合处理。

**(d) 跨视觉深度的动作读取（action readout across visual depths）——本文最独特的机制**

- 独立、较窄、随机初始化的**动作专家**（action expert）：专家层 j 对骨干层 m_j 缓存的 keys/values 与自己的 action-token KV 做联合注意力；
- 层映射 M=(m_1,…,m_d) 是显式架构选择，四种配置：
  - **first-28**: M=(0..27)，只读早期层；
  - **skip-28**: 40 层中近似均匀采样 28 层；
  - **end-28**: M=(12..39)，只读晚期层；
  - **full-40**: 全部 40 层 + 40 层专家（更高容量设置，单独对待）；
- 前三种用同样的 28 层专家与隐藏宽度，参数量几乎相同，**严格隔离"动作读取深度"这一个变量**。

**(e) 连续动作策略建模**

- 沿 π0 路线：动作专家以 flow-matching 预测连续动作块的统一速度场；
- 动作目标包含双臂块（R^{2×30×2×…}，30 步 horizon）与身体块；三个动作块共享时间 rotary 偏移（0-29），身份嵌入区分语义角色；
- 专家后缀嵌入 = 投影的噪声动作 + flow 时间 τ + 加性的 step/frame/identity 嵌入；
- 全量微调时动作损失同时更新骨干与专家。

**(f) 预训练语料**

9 个公开数据集家族，2,231,583 episodes，9,927 小时机器人数据。

**3) 算法流程和关键步骤**

```
多视角图像（原生纵横比）→ 共享patch embedder（步长32）→ 视觉token
文本指令/结构化prompt + 相机几何MLP + 状态MLP → 语言/状态token
  ↓ 全部进入40层原生骨干（三维RoPE，模态感知注意力）联合演化
  ↓ 各层KV缓存
动作专家（flow-matching）：从所选层映射的KV做交叉注意力
  → 预测双臂+身体的连续动作块速度场
```

**4) 输入输出**

- **输入**：上一时刻+当前多视角图像、结构化语言指令、相机内参/旋转、双臂与身体本体感知状态
- **输出**：连续动作块（双臂 30 步 horizon + 身体），flow-matching 速度场去噪得到
- **架构旋钮**：动作专家读取的骨干层集合 M

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**1) 如何理解和表示空间**

NEO-VLA 对空间的理解体现在"**空间信息分散在表示层级中**"这一核心发现上：细粒度几何（边界、局部形状、相对深度）在浅层最易访问，语义（这是什么物体、什么功能）在深层。原生骨干让这两种空间信息在同一个表示系统中跨层共存、共同演化，而不是在编码器端点被一次性压缩。相机几何（内参/旋转）被显式 token 化注入，说明作者把**相机-场景的空间关系**当作一等输入而非隐式假设。三维 RoPE（时间/高/宽）则把空间结构直接写进位置编码，这是"空间先验内置于架构"的体现。

**2) 如何处理空间关系**

- **视角-场景关系**：每视角相机身份 token + 投影几何 token，多视角信息在前缀中就被关联；
- **像素-语义关系**：视觉与语言 token 全程联合注意力，空间细节与语义在每一层交互而非仅端点拼接；
- **状态-动作关系**：本体感知状态 token 与视觉前缀同场演化，动作专家同时读取两侧；
- **深度-动作关系**：层映射 M 让"动作需要什么深度的空间信息"成为可学习/可搜索的选择——这是对空间信息层级结构的直接利用。

**3) 对 Spatial AGI 的启发**

- **空间智能不应只有单一视觉端点**：任何空间决策系统（不只是操作）都应允许决策模块访问多深度的感知计算。这对导航、场景编辑、空间问答同样成立——空间问答中的计数、相对位置判断也依赖浅层几何。
- **控制变量研究范式**：NEO-VLA 用参数量对齐的层映射对比 + 激活干预实验，把"哪里有动作关键信息"变成可测量的实证问题。Spatial AGI 领域需要更多这种"表示解剖学"研究。
- **Encoder-free 与空间保真**：预训练编码器为语义对齐优化，可能系统性地损失度量级空间信息（尺度、距离、边界）。原生骨干从像素学起的表示可能保留更多度量空间结构——这与"VLM 是否真的理解空间"的怀疑论形成呼应。
- **统一 token 接口适配不同具身**：缺失组件掩蔽的设计让同一模型跨具身部署，是 Spatial AGI 身体通用性的工程模板。

**4) 可以应用的 Spatial AGI 场景**

- 精细操作（需要浅层几何）与语义推理混合的任务；
- 多视角空间感知系统（相机几何显式注入的模板）；
- 空间问答/基准任务的架构改造（多深度读取）；
- 跨具身机器人策略的统一底座；
- 空间表示的诊断工具（层级探测 + 激活干预方法论）。

### Q3: 基于前面的分析，这个方法的主要创新点和局限性是什么？

**1) 主要创新点**

1. **问题层面的创新**：第一次把"动作策略应从哪个深度读取视觉计算"作为显式研究问题，并给出系统性实证答案（早期层对控制至关重要，尤其在骨干冻结时；全量微调后早期+晚期组合最佳）。
2. **架构机制**：可配置层映射的动作专家，让视觉读取深度成为显式架构旋钮，且对比实验严格控制专家容量。
3. **双重证据链**：层映射对比（相关性证据）+ 激活交换干预（因果性证据，早期层激活交换引发更大预测误差）。
4. **原生骨干在控制上的可行性验证**：与 Qwen3-VL-2B、Gemma3-4B 用相同动作专家与训练语料对比，原生骨干 LIBERO 成功率更高，冻结骨干时优势最大。
5. **鲁棒性结论**：LIBERO-plus（视觉/语言/环境分布偏移）与 RoboTwin 2.0 上，多深度读取转化为对相机扰动与图像噪声的实际鲁棒性。

**2) 主要局限性**

1. **归因的混杂变量**：作者自己承认，原生与编码器骨干在预训练数据与容量上有差异，增益不能完全归因于"移除编码器"本身。
2. **patch 分辨率粗**：32×32 步长的单一 token 化对极细粒度接触（插针、线缆操作）可能分辨率不足；每视角 88 token 预算也限制高分辨率输入。
3. **计算成本**：动作专家对多层 KV 做交叉注意力（full-40 需 40 层专家），推理成本高于单端点读取；KV 缓存的多层存储也增加显存。
4. **2B 骨干规模有限**：结论是否随规模（10B+）持续成立未验证——作者提到"规模无法弥补差距"，但那是 2B 范围内的观察。
5. **任务域**：以桌面操作基准为主（LIBERO/RoboTwin），长时程导航、全身移动未覆盖；"早期层信号更重要"的结论在非操作域可能不同。

**3) 与其他相关工作的对比**

| 维度 | NEO-VLA | 编码器VLA（π0/RT-2/GR00T） | 双视觉通路方案（Zhang 2026c） | discrete-token VLA（RT-1/2） |
|------|---------|-----------------------------|------------------------------|------------------------------|
| 视觉接口 | 无编码器，像素直入 | 固定编码器端点 | 双编码器 | 固定编码器 |
| 动作读取深度 | 可配置多层 | 单点 | 单点（两条路） | 单点 |
| 动作表示 | 连续 flow-matching | 连续/离散 | 连续 | 离散 token |
| 空间细节保真 | 高（全程演化） | 受端点压缩 | 部分 | 受端点压缩 |
| 预训练依赖 | 需自训原生骨干 | 复用成熟编码器 | 复用 | 复用 |

**优势**：唯一系统性研究动作读取深度的工作；原生骨干在控制上实证更强更鲁棒。
**劣势**：原生骨干需昂贵的三阶段自训；patch 分辨率粗；规模外推未验证。

## 核心技术发现

- **发现1**：动作关键视觉信号在骨干早期层即达峰值，早于最终语义表示——几何细节是控制的核心货币。
- **发现2**：骨干冻结时只读早期层最好；全量微调后早期+晚期组合最佳——微调使深层表示也能承载控制信息。
- **发现3**：激活交换干预显示早期层激活的跨观测交换引发显著更大误差——因果性证实早期层承载动作关键信息。
- **发现4**：原生（encoder-free）骨干在控制上优于编码器骨干，全量微调缩小但不消除差距，规模无法弥补。
- **发现5**：多深度读取转化为相机扰动/图像噪声下的实际鲁棒性增益。

## 与Spatial AGI的关系

### 直接贡献
证明空间智能的决策模块需要访问完整感知计算层级而非单一端点，并给出可操作的架构机制（层映射动作专家）。

### 技术启发
- 表示层级解剖学方法论（层映射对比+激活干预）适用于一切空间智能架构研究；
- 相机几何显式 token 化、三维 RoPE、具身组件掩蔽等空间先验内置技巧；
- encoder-free 路线对度量空间信息保真的潜在优势。

### 应用场景
精细操作策略、多视角空间感知底座、跨具身统一接口、空间表示诊断。

## 个人思考

### 最令人兴奋的发现
"动作关键信号峰值出现在早期层"这个发现的深层含义：**语义压缩与空间保真存在结构性张力**。视觉编码器为语义任务优化，压缩掉的恰恰是度量级空间细节；而操作恰恰最需要这些细节。这解释了为什么 VLM 在空间基准上普遍挣扎，也暗示 Spatial AGI 可能无法简单复用为语义理解设计的视觉前端。我不禁推测：未来的空间智能骨干可能需要"双梯度流"——语义流走向语义端点、几何流走向动作端点，两条流共享浅层但在深层分化，NEO-VLA 的层映射机制已经是这个方向的雏形。

### 潜在局限
32×32 patch 化是所有 encoder-free 路线的共同软肋——丢掉 ViT 的高分辨率多尺度设计后，细节感知完全依赖骨干自己从粗 token 里学，对精密装配类任务可能不够。另外激活交换实验是在操作域做的，"早期层承载几何"的结论能否外推到需要强语义的空间决策（如"去厨房拿水杯"的导航）存疑——那类任务可能反而是深层更重要。

### 与昨日研究的关联
昨天精读的 AgentVQA（统一 agentic 视觉理解基准）显示视觉理解需要主动的、多步的证据获取；NEO-VLA 则显示动作需要多深度的被动视觉读取。两者从不同侧面攻击同一个问题：单一前向视觉端点不足以支撑空间智能。结合本周 FloMo（运动是低熵动作中介）的观点，一个更完整的图景是：空间智能的视觉接口应当同时输出多深度语义特征（NEO-VLA）、多深度几何特征（本文的浅层读取）与运动结构（FloMo），而非任何单一压缩表示。

## 总结

### 核心发现总结
NEO-VLA 用结构原生的 encoder-free 骨干 + 可配置层映射的 flow-matching 动作专家，证明动作策略应直接访问骨干多深度的视觉计算：动作关键信号峰值在早期层，原生架构优于编码器架构且分布偏移下更鲁棒。

### 对Spatial AGI的意义
空间智能的感知接口必须是分层的、可多深度读取的——单一视觉端点是控制性能的结构性瓶颈。本文与运动接口（FloMo）、世界模型模拟器（PrimeSim）一起，正在拼出空间智能感知-预测-决策的完整架构图。
