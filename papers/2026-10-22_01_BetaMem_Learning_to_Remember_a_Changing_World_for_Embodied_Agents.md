## 一句话总结

BetaMem 把具身智能体的长期记忆做成一个"可写、可查、可忘、可审计"的六层记忆系统（工作/空间/实体/情景/经验/程序），核心创新是**双层写契约**（操作可执行性 + 内容必须有观测来源支撑）：SFT 学会守约的记忆操作，RL 用"重复采样 + 对照原始观测的教师验证"奖励完整准确的记录、惩罚遗漏/失真/无中生有，并通过"失败驱动的策略递归自改进"沿记忆操作因果链做诊断和局部规则修复——用 Qwen3.5-9B 在 M3-Bench-robot 48.08%、LoCoMo 92.08%、OpenEQA EM-EQA 72.6%、EgoLifeQA 62.4%，同尺寸开源模型中最强。

## 核心问题

### Q1: 这篇文章的核心算法原理是什么？

#### 1. 核心思想和动机

- **长时程具身 Agent 的记忆三大病症**（论文动机）：
  1. **时间混乱与记录残缺/失真**（temporal confusion，incomplete or distorted records）——记忆里的"什么时候"和"发生了什么"不可靠；
  2. **固定记忆规则的重复性错误**——写什么、何时忘都是硬编码启发式，环境一变就错，且错误会重复出现；
  3. **存储与检索成本随时间无限增长**——全存式记忆不可持续，必须有代价模型的遗忘。
- **核心立场**：记忆不是"存日志"，而是一个**受契约约束、可自我修复的认知子系统**。写入的每条记忆都应对得起"操作合法性"和"观测证据"双重审计；忘记什么应是在存储/读取预算下的**成本-效用分配决策**。

#### 2. 主要技术方法：六层记忆架构

| 层 | 内容 | 对应 Spatial AGI 的角色 |
|----|------|------------------------|
| Working memory | 当前任务上下文、活跃目标 | 短时空间推理的工作集 |
| Spatial memory | 空间布局、位置、几何关系 | 度量/拓扑空间知识的容器 |
| Entity memory | 物体属性、状态、身份 | "哪个东西在哪、什么状态" |
| Episodic memory | 带时间戳的事件序列 | "什么时候发生了什么" |
| Experiential memory | 交互经验、成功失败教训 | 经验学习与反思的原料 |
| Procedural memory | 技能、操作流程 | "怎么做"的知识 |

- 六层**互链**（linked）：一个事件会同时触达实体（谁）、空间（哪里）、情景（何时）——检索时可沿链接汇聚多源证据。

#### 3. 关键机制一：双层写契约（dual-level write contract）

这是全文最有辨识度的设计：

- **契约维度 A：操作可执行性**——每条记忆操作（写/改/删/链接）必须满足格式与前置条件，例如更新实体状态必须先引用已存在的实体条目；
- **契约维度 B：内容源支撑**（source support）——记忆内容必须能追溯到原始观测（某帧 RGB-D、某段对话），**不允许无中生有**；
- 契约的落地分两段训练：
  1. **SFT**：在符合契约的记忆操作轨迹上做监督微调，让模型先学会"守规矩地写"；
  2. **RL**：重复采样（repeated sampling）+ **教师验证**（teacher verification）——把生成的记忆对照**原始观测**逐一核验，奖励完整、准确的记录，惩罚三类坏行为：**遗漏**（该记的没记）、**失真**（记错了）、**无支撑内容**（编造）。
- 效果数字：记忆生成模型训练后，**契约通过率从 50.9% 升至 86.2%**，同时每条存储动作的输出 token 减少 **47.3%**——守约与效率同向改善。

#### 4. 关键机制二：失败驱动的策略递归自改进

- **沿记忆操作因果链做诊断**（diagnosis along the causal sequence of memory operations）：当任务失败，回溯是哪一次写入/检索/遗忘操作种下了错误种子；
- **局部规则修复**（local rule repairs）：不重训整个模型，而是修掉导致重复错误的记忆规则；
- **独立回放门控**（gated by independent replay）：修复后的规则必须在**独立回放**中验证有效才被采纳——防止"修复"引入新错误或过拟合单次失败。
- 这形成一个"写记忆 → 出错 → 归因到记忆操作 → 修规则 → 回放验证 → 更新策略"的**递归自改进闭环**。

#### 5. 关键机制三：原子化工具与成本-效用遗忘

- 存储、更新、检索、遗忘全部封装为**原子工具**（atomic tools）；
- 每个操作都在**存储预算与读取预算**的约束下做成本-效用分配——遗忘不是"过期就删"，而是"腾出预算换取更高价值的记忆"的显式经济决策；
- 工具化设计还意味着记忆操作可以被审计、被回放、被 RL 信用分配——这是契约可训练的前提。

#### 6. 输入输出

- **输入**：长时程任务流——时间对齐的观测（RGB-D/视频）+ 交互（对话、动作）+ 任务查询；
- **输出**：
  - 运行时：可检索的记忆证据 + 任务答案/导航/操作决策；
  - 系统级：一份全程可追溯、契约合规的记忆库（含演化历史）。

#### 7. 主要结果（摘要数据）

| 基准 | 成绩 | 说明 |
|------|------|------|
| M3-Bench-robot | 48.08% | 机器人记忆理解基准，所列记忆方法中最高 |
| LoCoMo | 92.08% | 长对话记忆 |
| OpenEQA EM-EQA | 72.6% | 具身问答（情景记忆设定） |
| EgoLifeQA | 62.4% | 第一人称生活问答 |
| EMem-Bench（Qwen3-VL-8B-Instruct 评测） | 成功率 38.4%，错误复发率 24.9% | 记忆错误不再复发是核心卖点 |
| 契约通过率 | 50.9% → 86.2% | 契约训练的直接收益 |
| 每存储动作输出 token | −47.3% | 记忆写入更紧凑 |
| 底座 | Qwen3.5-9B（开源） | 同尺寸开源模型中最佳 |

类目分析显示优势集中在：**跨观测信息整合**、**长时程事件回忆**。

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

#### 1. 如何理解和表示空间

- BetaMem 的空间理解是**时间化的空间**：空间条目不是静态地图，而是**带版本、带来源、带时间戳的空间知识**——"杯子在桌上（t=120s，来自第 120 帧观测）→ 杯子进了橱柜（t=340s，来自对话）"。
- 这呼应了空间智能研究里一个正在成形的共识：**真实世界的空间状态是动态的，空间智能 = 空间感知 × 状态维护**。SpatialScout（2026-10-21 精读）测的"out-of-sight 后更新物体状态"正是 BetaMem spatial + entity memory 要解决的问题。
- 六层分离意味着**空间不是孤岛**：空间知识只有与实体（是什么）、情景（何时）、经验（上次找它发生了什么）链接，才能支撑"去把那个杯子拿来"这种复合查询。

#### 2. 如何处理空间关系

- 空间关系的处理被建模为**记忆操作**：建立（首次观测到 A 在 B 上方）、更新（A 被移动）、失效（观测过期）、遗忘（低价值旧空间条目）；
- 契约维度 B 对空间记忆尤其关键：**空间断言必须有观测来源**——这直接打击空间幻觉（模型"脑补"物体位置）；
- 读取预算约束下的检索：空间查询（"X 在哪"）要在有限上下文里挑出最相关的空间/实体/情景证据——这是空间检索的经济学。

#### 3. 对 Spatial AGI 的启发

1. **空间记忆需要"写入质量"训练**。当前大多数空间记忆系统（3DGS 记忆、场景图记忆、语义地图）把写入当作感知流水线的副产品，从不为"写入质量"本身训练模型。BetaMem 证明写契约 + 教师验证可以把契约通过率从 51% 拉到 86%——同样的思路可以直接搬到空间断言的生成上。
2. **错误复发率是被忽视的关键指标**。24.9% 的错误复发率 vs 对照方法——空间智能系统同样存在"同一个位置记错两次"的问题（Holi-World、DialogMem 都报告过状态过期类错误）。失败驱动的规则修复 + 回放门控提供了可复用的修复框架。
3. **遗忘是空间智能的一等公民**。机器人在无限运行中不可能保留全部 3D 观测（3DGS 尤其贵），"存储/读取预算下的成本-效用遗忘"是空间记忆工程化的必答题。
4. **审计性是落地前提**。机器人事故归因需要回答"当时它基于什么记忆做了这个决定"——契约 + 原子工具 + 可回放的演化历史给了空间记忆一个可审计的形态。
5. **记忆生成的 RL 信用分配范式**：把"完整、准确、有据"做成奖励信号，可迁移到空间建图（地图更新质量）、世界模型（预测-观测一致性）等一切"生成内部表示"的模块。

#### 4. 可以应用的 Spatial AGI 场景

- **家庭机器人长期服务**：跨天/跨周维护物体位置与状态（BetaMem 的原始目标场景）；
- **空间问答 Agent**：OpenEQA 类任务中把观测记忆与人类语言记忆（对话）统一检索；
- **世界模型的经验记忆**：把 Experiential memory 接到世界模型上——上次预测错了什么、错因是什么，作为下次预测的上下文；
- **多智能体共享空间记忆**：契约化的写入天然适合多机器人共享地图的"谁能改什么"权限模型。

### Q3: 基于前面的分析，这个方法的主要创新点和局限性是什么？

#### 1. 主要创新点

1. **双层写契约**：第一次把"记忆写入"从自由生成变成受审计的契约行为，且证明契约可被 SFT+RL 显式训练（51%→86%）——这是记忆系统从工程 pipeline 走向"可学习认知模块"的标志性一步。
2. **教师验证 RL**：用原始观测做 ground truth 核验生成记忆，奖励结构（完整/准确/有据 vs 遗漏/失真/编造）直接对齐记忆质量的三个正交维度——比"任务成功"这种稀疏奖励信号密集得多。
3. **失败驱动的递归自改进**：错误沿记忆操作因果链归因 + 局部规则修复 + 独立回放门控——把"自我修正"做成了带防呆的工程流程，而不是笼统的 reflection prompt。
4. **六层互链记忆的完整实现**：工作/空间/实体/情景/经验/程序六层在统一工具接口下互链，比以往单一记忆类型的工作（GSMem 的空间记忆、EmbodiedLGR 的图记忆）覆盖面完整得多。
5. **经济学化的遗忘**：存储/读取预算下的成本-效用分配，让"忘记"成为可优化的决策而非规则触发器。
6. **同尺寸开源 SOTA + 效率收益**：9B 模型 + token 写入减半——记忆系统第一次同时报告质量与成本曲线。

#### 2. 主要局限性

1. **空间表示仍然符号化**。摘要未见显式几何（点云/3DGS/度量地图）——spatial memory 更像语义-拓扑层的空间知识，"杯子在橱柜第二层"到"世界坐标 (x,y,z)"的落地仍需外部几何模块。与 3DGS 式度量空间记忆是互补而非竞争。
2. **教师验证依赖可回放的原始观测**。这要求全程存储原始数据流——与"减少存储成本"的目标存在内在张力；实际部署中"教师"本身可能就是有损压缩。
3. **契约覆盖面未知**。摘要报告契约通过率，但未说明契约规则库多大、规则本身如何演化（规则是人工写的还是也可自改进）。
4. **评测基准的域差异**。LoCoMo 是纯对话记忆，OpenEQA/EgoLifeQA 是视频问答——真正长时程**机器人闭环任务**（记忆错误导致抓取失败→修复→不再犯）的证据主要来自 EMem-Bench 的错误复发率 24.9%，这个绝对值仍然偏高。
5. **递归自改进的稳定性**。失败归因+规则修改的循环长期运行存在漂移风险（修 A 坏 B），回放门控能缓解但不能根除；论文未报告多轮迭代的稳定性曲线。
6. **9B 底座的天花板**。记忆写入质量受底座视觉理解能力制约——复杂的空间场景理解错误会以"忠实记录错误感知"的形式通过契约审计。

#### 3. 与其他相关工作的对比

| 工作 | 记忆形态 | 写入质量训练 | 遗忘 | 空间几何 |
|------|----------|--------------|------|----------|
| GSMem（3DGS 空间记忆） | 度量几何 | ✗ | ✗ | ✓ 强 |
| EmbodiedLGR（图记忆） | 语义图 | ✗ | 部分 | 拓扑 |
| MemoryWAM（世界动作模型记忆） | 潜空间 | ✗ | ✗ | 隐式 |
| DialogMem（同期基准） | 评测对象 | —（评测方） | — | 对象级定位 |
| **BetaMem** | **六层符号互链** | **✓ 契约+SFT+RL** | **✓ 预算化** | 语义/拓扑层 |

- **vs GSMem**：GSMem 解决"空间记忆的几何精度"，BetaMem 解决"记忆内容的可信与自修复"——几何层与语义层的正交互补，合起来才是完整的空间记忆栈。
- **vs DialogMem**（今日精读 02）：DialogMem 诊断出"对话进入记忆但没接到物体条目"的 grounding 瓶颈——BetaMem 的 entity memory + 契约（对话记忆必须链接到实体条目才合规）正是对症的架构答案。
- **vs 各类 reflection/self-correction Agent**：多数 self-correction 是 prompt 层的自由文本反思；BetaMem 的修复是结构化的（因果链归因 + 局部规则 + 回放门控），可验证、可累积。

## 核心技术发现

- **发现 1**：契约通过率 50.9% → 86.2%，同时写入 token −47.3%——"写得更守约"与"写得更省"同向，说明无约束生成里大量 token 是幻觉与冗余。
- **发现 2**：错误复发率（24.9%）作为一等指标登场——记忆系统的价值不在"记了多少"而在"同一个坑不踩第二次"。
- **发现 3**：跨观测整合与长时程回忆是六层记忆的优势类目——印证"分层互链"设计的收益集中在需要多源证据汇聚的任务上。
- **发现 4**：9B 开源底座即可在同尺寸记忆方法中登顶（LoCoMo 92.08%）——记忆质量与底座规模的相关性弱于记忆架构本身的设计。

## 与Spatial AGI的关系

### 直接贡献
- 为空间记忆提供了"写入可信性"的完整训练配方（契约 + 教师验证 RL + 自改进）；
- 提供了空间知识动态维护的六层参考架构，明确 spatial memory 与 entity/episodic 层的接口。

### 技术启发
- 空间断言应有"证据链"：每条"X 在 Y 处"都能回指观测帧——空间幻觉治理的新范式；
- 空间记忆工程化三件套：契约、预算化遗忘、审计回放。

### 应用场景
- 家庭/仓储机器人的长期部署、跨会话空间问答、多机共享记忆的权限与审计。

## 个人思考

### 最令人兴奋的发现
- **"记忆写入可以被 RL 训练"这件事本身**。整个社区都在为"读记忆"（RAG、检索）卷得头破血流，BetaMem 指出写入侧才是脏活累活和真正杠杆：教师验证把无限贵的"记忆质量"变成可采样的密集奖励。这个范式可以平移到空间建图——把"地图更新"当记忆写入训练，用后续观测做教师验证，可能比 SLAM 前端 hand-crafted 的一致性检查更有扩展性。
- **错误复发率**。这是记忆系统的"对外承诺"式指标：用户能感知的不是你记住了多少，而是你是否重犯。EMem-Bench 把它做成基准维度，会改变后续记忆工作的评测文化。

### 潜在局限
- 教师验证 = 观测回放的存储成本与"省 token"的收益之间的总账没有算清楚；真实部署需要增量式/有损的教师。
- 契约是人工规则库的话，长期自改进会撞上"契约本身需要演化"的问题——契约的元学习是下一步。

### 与前日研究的关联
- **与 SpatialScout（10-21/03）**：SpatialScout 发现弱模型"随进度减少观察、凭旧记忆定位"是空间失败的行为信号——BetaMem 的情景记忆 + 观测溯源恰是让"旧记忆"带上新鲜度戳、可被检验的方案。
- **与 Holi-World（10-21/02）**：Holi-World 的 Foundry 是"感知流水线建世界记录"，BetaMem 是"Agent 自主写并守约"——两条路线终将在"谁来写空间记忆"上相遇：流水线写入精度高但无任务上下文，Agent 写入有上下文但需契约约束。
- **与 LAW / ORD-WM（10-20）**：世界模型处理"想象的未来"，BetaMem 处理"记录的过去"——完整的空间智能 Agent 需要"过去（记忆）→ 现在（感知）→ 未来（想象）"三时态的统一管理，BetaMem 的经验记忆层是世界模型错误教训的自然容器。

- 训练：SFT（合规轨迹）→ RL（重复采样 + 教师验证）；自改进（因果链归因 + 局部规则修复 + 独立回放门控）

## 总结

### 核心发现总结
BetaMem 把具身长期记忆重构为一个受契约约束、可训练、可自修复的六层系统：双层写契约 + 教师验证 RL 显著提升写入可信性（86.2% 通过率）与紧凑度（token −47%），失败驱动的规则自改进配合回放门控压低错误复发，预算化的原子工具让遗忘成为经济决策——在四个记忆基准上以 9B 开源底座取得同尺寸最佳。

### 对Spatial AGI的意义
- 空间智能的"记忆侧"第一次有了质量可训练的蓝图：空间断言不是感知流水线的副产品，而是需要契约、验证与自改进的核心认知行为；
- 与几何层空间记忆（3DGS/SLAM）、世界模型（想象）构成"记录-度量-预测"三件套——空间 AGI 的长期落地（家用机器人）取决于这三者的接口质量，而接口的共同语言正是 BetaMem 提出的"契约"。

## 附录 A：六层记忆的空间智能能力栈映射

```
任务: "把我上次修好的那个台灯拿到书房"
S1 任务解析        → working memory 挂载目标
```

BetaMem 的价值主张：这六步的每一步证据都可追溯、契约合规、预算内检索——
传统单层记忆系统在 S3/S5 会断链（事件与空间状态脱钩）。

## 附录 B：契约训练的技术细节推演

**为什么需要 SFT 先行？**
RL 的采样空间需要先收敛到"大体合规"的区域——若初始策略大量违反契约（格式错误、悬空引用），教师验证的奖励信号会过于稀疏。两段式的分工：
- SFT：学"怎么说"（契约语法）；
- RL：学"说什么"（内容质量：完整/准确/有据）。

**重复采样的作用**：同一观测流采样多条记忆轨迹，教师验证给出质量排名——构成组内相对优势（类似 GRPO 的记忆版），降低奖励方差。

**教师验证的三个判据**：
1. 完整性：关键事件是否都覆盖（对照观测时间线）；
2. 准确性：细节是否与观测一致（物体、位置、顺序）；
3. 支撑性：每个断言能否回指观测证据。

## 附录 C：错误复发率 24.9% 的深读

24.9% 意味着约 1/4 的错误类型仍会重演。结合"失败驱动自改进"机制推测：
- 已修复的错误类型（回放验证过的规则修复）复发率低；
- 复发的可能是：(a) 归因失败的错误（找不到因果链上的种子）；(b) 修复规则泛化不足（新情境下规则不触发）；
- 对比意义：比"完全无自改进"的基线显著低（否则不会作为亮点报告），但离"错误免疫"很远——空间智能部署中"同一位置反复记错"正是用户最不能容忍的失败。

### G.1 现有基准谱系与 BetaMem 的位置

| 基准 | 评测面 | BetaMem 成绩 | 域 |
|------|--------|--------------|-----|

**观察**：纯语言域（LoCoMo）接近饱和（92%），具身域（48-72%）仍有巨大空间——
记忆的难点不在存储检索，而在**时空 grounding 与动态维护**。

### G.2 评测指标的三层演进

```
第一代: 检索命中率 / QA 准确率     —— "记住了吗"
第二代: 上下文利用率 / 证据质量    —— "用对了吗"
第三代: 契约通过率 / 错误复发率    —— "写得对吗 / 还犯吗"  ← BetaMem 所在
```

第三代的本质是把评测从"下游表现"推进到"上游质量"——
下游表现受检索器、推理器、任务难度多因素混淆；上游质量直接可归因到记忆模块。

### G.3 对空间智能评测的迁移建议

空间记忆基准（如 VSI-Bench 的记忆子任务）应引入：
1. **断言溯源率**：答案引用的记忆中有多少能回指有效观测；
2. **状态新鲜度误差**：使用过期空间知识的比例；
3. **重复错误率**：跨 episode 的同类错误复发统计；
4. **写入效率**：每单位观测产生的记忆 token / 存储字节。

## 附录 I：教师验证的技术风险剖析

### I.1 教师的系统性盲区

教师 = 原始观测回放。但观测本身有局限：
- **视角盲区**：相机没拍到的地方发生的物理变化，记忆若正确推断（如听到声音推断门开了）反而无法通过"源支撑"验证——契约可能系统性惩罚合理推断；
- **感知噪声**：深度传感器误差导致的位置记录，教师会"确认"错误值——契约保证的是"忠于观测"而非"忠于世界"。

### I.2 缓解方向

1. 推断类记忆单列一类（inferred），用不同验证标准（多源一致性而非单源回指）；
2. 空间数值断言引入不确定度量化（位置 ± σ），契约要求"不确定度诚实"；
3. 与 BetaMem 的 experiential 层联动：教师验证失败的高频模式本身入库，作为感知系统的校准线索。

### I.3 一个隐含的哲学立场

BetaMem 的契约体现"证据主义"记忆观：记忆 = 压缩的观测 + 合法的操作。
与之对立的"构造主义"记忆观（记忆 = 生成式世界模型的重构）认为允许重构、只要有用。
两者的张力恰如 SLAM（度量精确） vs 世界模型（语义想象）——
空间 AGI 的记忆架构大概率是混合体：度量层守契约，语义层允许受控重构。

## 附录 J：与同期空间记忆工作的详细对照

### J.1 vs DialogMem（今日 Paper 02）

DialogMem 的三大瓶颈：对象级接地、正确条目检索、准确定位。
BetaMem 的对应答案：
- 对象级接地 → 契约维度 A 强制对话记忆链接 entity 条目（悬空对话记忆违规）；
- 检索 → 六层互链提供多路检索证据；
- 定位 → spatial memory 版本化 + 新鲜度。
但 BetaMem 未评测对话场景的导航收益——DialogMem 指出的"对话提升 QA 不提升导航"现象在 BetaMem 架构下是否消失，是可直接做的实验。

### J.2 vs GSMem 类几何空间记忆

GSMem：3D 高斯作为空间记忆——几何精确、语义贫瘠、无时间演化机制。
BetaMem：语义丰富、时间演化、几何缺位。
**融合形态预测**：spatial memory 条目挂接 3DGS 锚点（几何验证），
契约同时审计"语义-观测一致"与"几何-重投影一致"——双教师验证。

### J.3 vs MemoryWAM / 世界模型记忆

世界模型记忆是潜空间的、面向预测的；BetaMem 是符号的、面向审计的。
接口点：世界模型的 rollout 失败 → 差异诊断 → 写入 experiential memory →
作为后续 rollout 的检索上下文（检索增强的世界模型）。

## 附录 K：部署视角的成本模型

假设家庭机器人每天 12 小时运行、30 FPS 感知流：
- 原始观测留存：12h × 30fps ≈ 130 万帧/天（教师验证需要）——必须分层留存
  （关键事件全帧、其余关键帧/缩略图）；
- 记忆写入：47.3% 的 token 节省意味着同样预算下近 2× 的记忆密度；
- 读取预算：每次决策可检索的记忆条目有限，预算化遗忘保证高价值条目不被挤出；
- 审计成本：随机回放抽查 ~1% 条目即可维持契约威慑（合规率监测）。

**经济学结论**：契约 + 教师验证的最大开销是存储，而存储是所有 AI 成本中降得最快的——
这个架构的成本曲线是顺周期的。

## 附录 L：精读问答补充

**Q1: 为什么是六层而不是经典的三层（感觉/工作/长期）？**
A: 六层是按**内容生命周期**切分而非时间跨度：空间与实体是"世界状态"类，情景与经验是"历史"类，程序是"技能"类。经典三层把所有长期知识混在一起，无法做差异化契约（空间条目需要位置溯源，程序记忆需要成功统计溯源）。分层契约是关键——统一契约要么太松（空间条目无溯源）要么太严（技能记忆无观测可回指）。

**Q2: 自改进为什么用规则修复而不是继续 RL？**
A: RL 修复慢（需要重新采样训练）且不稳定；错误常常源于个别规则（如"何时覆盖旧位置"）——局部规则修复是 O(1) 的。回放门控弥补了规则修复不经训练的泛化风险。这也解释了为什么错误复发率没有降到 0：规则修复的泛化能力有限。

**Q3: 这套东西对空间建图（SLAM）社区有什么冲击？**
A: SLAM 的回环检测本质是一种"记忆契约"（位姿图一致性），但它是几何单一维度的。BetaMem 暗示下一代空间系统的回环检测将是多维的：几何一致 + 语义一致 + 事件一致（"我确实在 t=120 来过这里"）。写入即建图，建图即记忆。

**Q4: 92.08% 的 LoCoMo 说明什么？**
A: 说明纯对话记忆在 9B 规模已近饱和，记忆研究的主战场明确转向具身/时空域。这也提醒评测者：再用对话基准证明记忆创新，边际信息量已经很低。

## 附录 O：空间记忆 Agent 的一日生命周期（推演）

以 BetaMem 架构运行的家庭机器人典型一天，展示六层记忆与契约的协同：

```
07:30 唤醒
  - working memory 初始化今日任务
  - spatial memory 载入昨晚封存的全屋状态快照（含新鲜度戳）
  - 差异扫描：厨房椅子位置与封存快照不符 → 触发实地验证

09:00 早餐整理
  - 观测到杯子从餐桌移到水槽 → entity 更新 + spatial 更新
  - 契约检查：更新操作引用了实体条目 #47 ✓，附观测帧 #12031 ✓
  - episodic 写入："09:02 清理早餐"

11:00 主人对话
  - 主人说"我把剪刀收进抽屉了" → 对话记忆写入
  - 契约关键点：该对话条目必须链接 entity #12（剪刀）
    并标注证据类型 = 人类证言（可信度 < 直接观测）
  - spatial 层写入"剪刀可能位置：厨房抽屉 B"，置信度标签 = hearsay

15:00 找剪刀任务
  - 检索：entity #12 → spatial 候选（抽屉 B, hearsay）+ 上次直接观测位置（书房, t-3天, stale）
  - 读取预算内选择：优先验证 hearsay 但更新的位置
  - 经验注入：experiential 提示"该主人说'收起来'时常指厨房抽屉"（历史成功模式）

19:00 失败与自改进
  - 抽屉 B 未找到剪刀 → 任务失败触发归因
  - 因果链回溯：写入 → 检索 → 验证，定位到"hersay 位置未做主动验证"规则缺口
  - 规则修复提案："hearsay 空间断言在作为导航目标前需 1 次直接观测确认"
  - 独立回放验证通过 → 规则入库

23:00 封存
  - 预算化遗忘：今日观测流中低价值段（静止监控）降采样留存
  - 高价值片段（剪刀事件）全帧保留（教师验证与审计需要）
  - 契约合规率日报：写入 412 条，通过 389 条（94.4%），失败样本进入修复队列
```

**两个设计要点浮出**：
1. **证据可信度分层**（直接观测 > 人类证言 > 推断）让契约在多源证据下可操作——单一"必须有观测支撑"无法容纳对话输入；
2. **失败驱动的规则演进**让系统行为随主人习惯个性化——记忆系统从"记录工具"变成"可塑的认知策略"。

## 附录 P：Meta 反思——记忆与空间智能的共同演化路线图

综合本周精读（BetaMem、DialogMem、Holi-World、SpatialScout）与上周（LAW、ORD-WM、T2-z），空间智能的记忆侧可以画出一条清晰的演化线：

```
阶段 1（2024-2025）：静态表示
  场景图 / 3DGS / 语义地图 —— "空间是快照"

阶段 2（2026 上半年）：动态状态
  物体状态跟踪 / 变化检测 / 事件时间线 —— "空间是状态机"

阶段 3（2026 下半年，当前）：可信演化
  契约化写入（BetaMem）/ 审计回放 / 预算化遗忘 —— "空间记忆是受治理的认知资产"

阶段 4（可预期）：预测性记忆
  记忆与世界模型双向接口 —— "记忆为想象提供先验，想象为记忆提供待验证假设"
```

Spatial AGI 的终局架构里，"记忆"与"空间"将不再是两个模块，而是同一枚硬币：
**空间记忆 = 带契约治理的世界状态数据库，空间智能 = 在其上的读写与推演能力**。

BetaMem 的真正贡献不在于某个 benchmark 分数，而在于它把"治理"（契约、审计、预算、修复）
这组来自软件工程的概念正式引入了认知架构——这可能是 2026 年具身智能从"能力演示"
走向"可信部署"的分水岭信号之一。
