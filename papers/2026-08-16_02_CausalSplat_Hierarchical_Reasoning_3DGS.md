## 论文一句话总结

CausalSplat 定义了"推理 3D 高斯分割"（Reasoning 3D Gaussian Segmentation）新任务——在 3DGS 场景中根据含隐式意图、多跳逻辑约束的自然语言指令定位并分割目标物体——构建了覆盖常识/空间/可供性/反事实四级推理层级的 Causal-LERF 与 Causal-ScanNet 基准，并提出"语义场构建 + 多模态语义场景图 + 三阶段 VLM 推理"框架，将显式结构感知与隐式逻辑推断解耦，在推理基准上以 47.0%（2D mIoU）和 14.9%（3D mIoU）大幅超越现有 SOTA（23.6% / 5.1%）。

## 核心问题

### Q1: 核心算法原理

**问题**: 这篇文章的核心算法原理是什么？

**分析**:

#### 1. 核心思想和动机

（1）**从"名词查询"到"隐式意图"的能力鸿沟**

3DGS 开放词汇理解（LangSplat、OpenGaussian 等）已经成熟，但它们处理的都是显式名词查询（"蓝毛巾"）。Referring 3DGS（ReferSplat）扩展到含空间关系或属性的描述性语言，但仍依赖显式指代表达。而真实具身交互中用户意图高度隐式且依赖上下文——论文给出经典例子："我刚洗了手，请把水槽旁边、橱柜下方挂着的东西递给我"。解析这种指令需要推断隐式可供性 + 解码 3D 物理空间关系 + 常识与逻辑推理。

（2）**两大技术瓶颈的诊断**

若沿用 R3DGS 范式（给每个 3D Gaussian 分配语义特征、直接与文本特征对齐），推理任务上会遇到：
- **缺乏结构化空间感知**：CLIP 类模型的词袋效应使特征对齐无法编码物体间拓扑结构与相对几何关系，无法解析方向、包含等复杂空间约束
- **缺乏隐式推理**：传统视觉-语言对齐聚焦显式属性，难以捕获隐式因果逻辑与功能描述，无法建立"切牛排的工具"→"刀"的映射

（3）**解耦思想：显式结构感知 vs 隐式逻辑推断**

CausalSplat 的核心设计哲学是把推理过程概念性拆分：
- **场景图负责显式结构感知**：显式建模 3D 高斯场景中物体间的拓扑与空间关系，克服特征场的空间感知局限
- **LLM/VLM 负责隐式逻辑推断**：利用大模型知识与推理能力把隐式查询解析为可执行的结构化意图

#### 2. 主要技术方法

框架由三个模块串联：

**模块一：语义场构建（Semantic Field Construction）**

目标：把多视角 2D 分割掩码提升为 3D 语义特征场，抑制 SAM 掩码的固有边缘噪声。三步：

- **空间加权特征提取**：每个 3D Gaussian 点挂一个语义特征向量 f_i ∈ ℝ^C，通过 3DGS 同款 alpha-blending 可微渲染得到 2D 特征图 F。对 SAM 掩码 M_pos，按像素到掩码几何中心的距离定义空间权重 W_{x,y}（中心权重高、边缘低，下限 ω_min=0.4），加权聚合得到掩码平均语义特征 p（L2 归一化）。

- **对比特征优化**：L_total = L_pos + L_neg。正样本项用空间权重引导目标区域特征向掩码平均特征聚拢（加权的 (1-S)² 损失）；负样本项用 margin（m=0.03）惩罚相似度超限的负样本，并用动态采样策略（随机采样率 r = 正负像素比 + 硬负样本阈值 τ=0.5）解决负样本主导的类不平衡。

- **基于聚类的 3D 实例分配**：收集所有视角的掩码平均特征，用 HDBSCAN 密度聚类把 2D 掩码聚成 3D 实体簇 O_k；每个实体取簇内特征均值为代表特征 C_k；每个 3D Gaussian 点按与各实体代表特征的余弦相似度硬分配到唯一实体 ID。

**模块二：语义场景图构建（Semantic Scene Graph Construction）**

把 3D 实体组织为图 G = (V, E)，节点为实体、边为空间关系：

- **语义节点构建**：每个节点有多模态描述符 M_i = ⟨c_i, b_i, I_i, A_i⟩：
  - c_i ∈ ℝ³：实体高斯点云的空间质心
  - b_i ∈ ℝ³：轴对齐包围盒跨度（max-min）
  - I_i：关联的 2D 分割掩码
  - A_i = {T_i, X_i, F_i}：VLM 分析 2D 掩码提取的结构化属性——内在类别、视觉特征、交互可供性

- **尺度自适应边构建**：开放世界场景尺度剧变，固定距离阈值不可靠。以垂直关系为例，要求：(a) 两实体质心 Z 轴位移与质心距离之比超过阈值（|ΔZ|/d_{i,j} > τ=0.3）；(b) 水平投影距离小于动态容限 D_limit^xy = min(max(0.55·√(b̄x²+b̄y²), 0.08·S_xy), 0.35·S_xy)——下界由两实体包围盒平均跨度决定（适配大物体），上界由全场景水平对角跨度决定（适配场景规模），实现"物体尺寸与场景范围"的双重平衡。

**模块三：场景图多模态推理（Scene Graph-based Multimodal Reasoning）**

用 Qwen3-VL-30B-A3B-Instruct 做三阶段 prompt 推理：
1. **指令解析**：解析指令 Q 语义；若仅描述物体内征特征则直接输出决策；检测到显式空间关系词则触发拓扑推理（动态路由，避免简单查询的冗余搜索错误）
2. **拓扑推理**：在场景图中识别指令描述的锚节点 v_anchor，沿有向边 E 做结构化搜索
3. **决策输出**：整合语义约束与拓扑约束，输出目标节点

#### 3. 算法流程和关键步骤

```
输入: 多视角2D图像 + 自然语言指令Q（隐式意图/多跳逻辑）
  │
  ├─ ① SAM提取各视角2D掩码
  ├─ ② 3DGS语义场渲染（alpha-blending特征splatting）
  ├─ ③ 空间加权 → 掩码平均特征p
  ├─ ④ 对比优化（L_pos聚拢 + L_neg分离 + 动态负采样）
  ├─ ⑤ HDBSCAN聚类 → 3D实体 + 高斯点硬分配
  ├─ ⑥ 场景图构建（多模态节点 + 尺度自适应边）
  ├─ ⑦ VLM三阶段推理（解析→拓扑搜索→决策）
  │
输出: 目标3D实体（高斯点集），可投影为2D/3D分割掩码
```

#### 4. 输入输出

- **输入**：多视角 2D 观测（重建好的 3DGS 场景）+ 含隐式意图或逻辑约束的自然语言指令
- **输出**：目标物体的 3D 分割（高斯点集级别），评估时投影为 2D 像素 mIoU（Causal-LERF）或 3D 点级 mIoU（Causal-ScanNet）
- **关键超参**：ω_min=0.4，对比 margin m=0.03，硬负样本阈值 τ=0.5，垂直边阈值 0.3，全部特征 L2 归一化

### Q2: 与Spatial AGI的关系

**问题**: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**分析**:

#### 1. 如何理解和表示空间

（1）**双层空间表示：连续特征场 + 离散拓扑图**

CausalSplat 的空间表示是分层的：
- **底层**：3D Gaussian 语义特征场——保留连续、细粒度、可渲染的空间信息
- **上层**：语义场景图——离散实体节点 + 空间关系边，是 VLM 可以直接操作的符号化空间结构

这种"连续场 + 离散图"的复合表示正是 Spatial AGI 的核心命题之一：底层保证空间精度与可微性，上层支撑逻辑推理与语言接口。

（2）**几何显式化的三个层次**

- 质心 c_i：物体在全局坐标系中的位置
- 包围盒跨度 b_i：物体的尺度与形状代理
- 自适应关系边：物体间的拓扑（支撑、上下、邻近等）

（3）**多模态节点的语义对齐**

节点属性 A_i = {类别、视觉特征、可供性} 把几何实体与语言语义绑定，使"允许通过的物体"、"放洗漱用品的表面"这类功能性空间描述可以落地到具体几何区域。

#### 2. 如何处理空间关系

- **尺度自适应阈值**：解决 Spatial AGI 的经典难题——同一关系（"在...上方"）在小物体对（茶杯-茶碟）与大物体对（桌子-地板）上需要完全不同的判定尺度。动态容限同时考虑物体尺寸与场景范围，是一个可复用的工程化解法
- **拓扑边搜索**：多跳空间约束（"盘子旁边的包"）通过沿图边的结构化搜索实现，比特征空间中的隐式对齐更可控、可解释
- **空间关系的方向性**：垂直关系要求 ΔZ 占比大 + 水平偏差小，把"上下"这类关系从模糊的语言概念转化为可计算的几何谓词

#### 3. 对Spatial AGI的启发

（1）**四级推理层级是 Spatial AGI 能力评估的系统化框架**

- L1 空间推理：几何关系与拓扑（支撑/包含/遮挡）
- L2 常识推理：先验知识与场景实例对齐（"擦嘴的东西"→餐巾）
- L3 可供性推理：几何结构→功能潜力（"开口朝上的容器可供抓取"）
- L4 预测/反事实推理：物理机制推演（"移走底部红色物体后哪些物体会掉"）

这个从感知到因果的递进框架，可以直接作为 Spatial AGI 系统的能力路线图。特别是 L4 反事实推理是首次被纳入 3D 理解基准——这是从"空间感知"迈向"空间智能"的关键一步。

（2）**"感知-推理解耦"架构对具身系统的普适价值**

把结构化感知（场景图）与逻辑推断（LLM）分离，意味着：
- 感知模块可以独立升级（更好的分割/聚类）
- 推理模块可以独立升级（更强的 LLM，论文用 Qwen3-VL-30B 即插即用）
- 中间表示（场景图）可被下游任务复用（导航、操作、问答）

（3）**现有 SOTA 在推理分割上的惨败揭示了空间智能的真实水位**

Causal-LERF 上最强基线 LUDVIG 只有 23.6%，Causal-ScanNet 上所有方法 ≤5.1%，而 CausalSplat 也只有 14.9%（3D）。**在真实 3D 场景中做隐式意图理解仍然远未解决**——这个基准为 Spatial AGI 划出了清晰的努力空间。

（4）**3DGS 作为 Spatial AGI 的空间记忆载体**

论文隐含一个重要立场：3DGS 不只是渲染工具，而是可承载结构化语义（实例、关系、可供性）的空间记忆。这与近期 Reasmory（3D 重建作为 VLM 显式记忆）、R4DSG（4D 场景图记忆）等工作的趋势一致。

#### 4. 可以应用的Spatial AGI场景

- **具身指令跟随**：机器人听懂"把我刚吃完的薯片袋扔进厨房那个装垃圾的东西里"——需要常识（垃圾）、空间（厨房哪里）、可供性（开口容器）
- **家庭服务机器人的开放词汇操作**：抓取目标的推理定位（本任务的直接延伸）
- **AR/VR 交互**：用户用自然语言指代虚拟/真实混合场景中的物体
- **场景编辑与数字孪生**：反事实推理支持"移走这个柜子后哪些东西需要重新安置"的孪生体编辑
- **安全检查**：反事实层级的"如果支撑物移除会掉落什么"直接可用于工业安全评估
- **自动驾驶可交互区域推理**：可供性推理迁移到驾驶场景（可通行区域、可停靠表面）

### Q3: 创新点和局限性

**问题**: 基于前面的分析，这个方法的主要创新点和局限性是什么？

**分析**:

#### 1. 主要创新点

（1）**任务与基准定义（最大贡献）**

- 首个 3DGS 专用的多级推理分割基准（Causal-LERF 158 指令 + Causal-ScanNet 73 指令，14 个真实室内场景，231 条推理指令）
- 覆盖全部四级推理维度（对比：3DAffordSplat 仅合成场景可供性、REALM 仅常识+有限空间）
- 严格标注质控：4 名专业标注者全票通过才收录，歧义样本剔除
- 指令分布：18.2% 空间 / 48.5% 常识 / 16.0% 可供性 / 17.3% 反事实

（2）**"感知-推理解耦"的系统架构**

场景图作为几何与语义之间的中间表示，让 LLM 在结构化空间上进行推理而非在原始特征上硬算。消融证明：纯文本图 40.1 → 加节点图像反而降到 37.2 → 加拓扑边 40.2 → 完整多模态图 47.0——**视觉与拓扑必须联合建模**。

（3）**三个工程细节的消融验证**

- 空间加权：随机权重 34.9 / 平均池化 35.7 / 空间加权 47.0（+11.3，边缘噪声抑制的价值）
- 动态路由三阶段推理：去掉指令解析 40.5（简单查询冗余搜索致错）、去掉拓扑推理 42.2（复杂空间任务失败）——**推理深度应与查询复杂度匹配**
- 尺度自适应边：解决开放世界尺度剧变下的关系判定

（4）**跨任务泛化**

虽为推理任务设计，在标准 Ref-LERF 指代分割上 36.1 mIoU（超 SOTA ReferSplat 6.9 分）、LERF 开放词汇上点基方法 SOTA（51.3，Figurines 场景 75.3）。

#### 2. 主要局限性

（1）**绝对性能仍然很低**

- Causal-ScanNet 3D mIoU 仅 14.9%——即使大幅超越基线，离实用还很远
- 常识推理指令占 48.5%，比重失衡；四级推理的评估粒度（每级样本量）有限
- 14 场景 / 231 指令的规模较小，统计稳定性存疑

（2）**推理链路依赖 prompt 工程**

- 三阶段推理是手工设计的 prompt 流水线（Qwen3-VL-30B），非端到端学习
- LLM 的指令解析错误会级联传播；对未见类型的隐式意图泛化未验证
- "检测到空间关系词才触发拓扑推理"的路由规则较脆弱（依赖词汇触发）

（3）**静态场景假设**

- 反事实推理（"移走X后什么会掉"）基于静态场景图的几何推断，没有真正的物理模拟（力分布、稳定性分析只是通过 LLM 常识近似）
- 无时序：不处理动态场景或物体状态变化

（4）**2D 掩码质量的上游依赖**

- SAM 掩码噪声虽然被空间加权缓解，但根本依赖仍在；小物体、透明物体、严重遮挡场景未讨论
- HDBSCAN 聚类的超参敏感性、实例过分割/欠分割问题未深入分析

（5）**场景图构建的开放性问题**

- 边类型仅示例了垂直关系，完整的关系类型学（支撑/包含/遮挡的具体判定）细节在正文未完全展开（部分在附录）
- 节点属性的 VLM 标注可能有误（类别/可供性标注错误会直接误导推理）

#### 3. 与其他相关工作的对比

| 维度 | CausalSplat | LUDVIG | REALM | ReferSplat | OpenGaussian |
|------|------------|--------|-------|-----------|--------------|
| 任务 | 四级推理分割 | 3DGS语言理解 | 常识+空间推理 | 指代分割 | 开放词汇 |
| 表示 | 场景图+特征场 | 语言引导特征 | Agent+MLLM | 特征对齐 | 点级特征 |
| Causal-LERF 2D mIoU | **47.0** | 23.6 | 11.4 | 10.0 | 6.3 |
| Causal-ScanNet 3D mIoU | **14.9** | 5.1 | - | - | 2.9 |
| Ref-LERF mIoU | **36.1** | - | - | 29.2 | - |
| LERF-OVS mIoU | 51.3(点基SOTA) | 50.4 | - | 55.4 | 38.4 |

**关键观察**：
- vs REALM：同为"VLM+3DGS"路线，CausalSplat 的场景图结构化程度更高，推理基准上 4 倍领先（47.0 vs 11.4）——**结构化中间表示的价值得到直接验证**
- vs ReferSplat：在指代任务（ReferSplat 的主场）反超 6.9 分——推理框架向下兼容简单任务
- vs LUDVIG：同为结构化路线，CausalSplat 的多模态节点+自适应边更精细，推理任务上翻倍

## 核心技术发现

1. **隐式意图的 3D 定位是现有 SOTA 的盲区**——开放词汇/指代方法在推理基准上崩塌（6-24%），即使推理专用方法 REALM 也只有 11.4%；结构化场景图 + LLM 的组合（47.0%）是目前最有效的路径，但绝对值仍低
2. **SAM 掩码边缘噪声可通过"中心加权 + 对比优化"系统性抑制**——空间加权相对平均池化 +11.3 mIoU，相对随机权重 +12.1 mIoU
3. **视觉节点与拓扑边必须联合建模**——只加图像反而伤害性能（40.1→37.2），完整多模态图才达 47.0，证明场景理解中"属性"与"关系"的协同必要性
4. **推理深度应动态匹配查询复杂度**——指令解析路由（简单查询跳过拓扑搜索）贡献 +6.5 mIoU，避免"过度推理"误差
5. **反事实推理首次进入 3DGS 评测**——"移走X后什么会掉"类指令为 Spatial AGI 的物理理解评估开辟了新维度

## 与Spatial AGI的关系

### 直接贡献

- 提供了 Spatial AGI 推理能力的**四级分层评估框架**（空间→常识→可供性→反事实）
- 提供了**"特征场+场景图"双层空间表示**的完整实现与消融验证
- 提供了真实场景推理分割基准，暴露当前方法的能力边界

### 技术启发

## 个人思考

### 最令人兴奋的发现

（1）**结构化表示对推理的杠杆效应**

REALM（Agent+MLLM 直接推理）11.4% vs CausalSplat（场景图结构化）47.0%，4 倍差距。这是对"结构化中间表示在 Spatial AGI 中的价值"的最直接量化证据。结合昨天 R4DSG（4D 场景图记忆）、Spatial Memory Agent（程序性记忆）的发现，一个趋势清晰浮现：**LLM 的空间推理能力严重依赖喂给它的空间表示的结构化程度**。原始特征场/点云对 LLM 几乎不可用，而实体-关系图可以。

（2）**反事实推理：Spatial AGI 的试金石**

"如果移走底部红色物体，哪些会掉？"——这个问题之所以难，是因为它要求模型不仅理解当前场景的几何，还要理解物理因果结构（支撑关系、重力）。CausalSplat 用 LLM 常识近似这种推理，显然只是第一步。真正的解法可能需要可微物理引擎或物理仿真与场景图的耦合。这条研究线（NewtPhys 4D 物理标注、PhysiFormer 等）与本文在收敛。

（3）**绝对性能的警示**

14.9% 的 3D mIoU 提醒我们：从"能分割名词"到"能理解意图"之间有一个巨大的鸿沟，而这个鸿沟恰恰是具身智能商业化的关键瓶颈（用户不会用"名词+属性"和机器人说话）。

### 潜在局限与批判性思考

（1）**Prompt 流水线的脆弱性**

三阶段推理本质上是把推理逻辑硬编码进 prompt。当指令同时涉及常识+空间+反事实（"把那个如果架子塌了会砸到我的东西挪走"），线性流水线能否处理？路由规则（检测空间词）如何应对隐喻表达？端到端训练的推理分割（类似 LISA 的 [SEG] token 路线）可能是必要的演进。

（2）**规模问题**

14 场景 231 指令的基准在 2026 年显得偏小。常识指令占近一半也反映：反事实/可供性指令的标注成本高。未来需要程序化生成（类似 SpatialEvo 的确定性几何环境）来扩展。

（3）**场景图的语义标注误差传播**

节点属性由 VLM 自动标注（类别/特征/可供性），标注错误的量化与影响未充分讨论。级联误差（分割错→聚类错→属性错→推理错）是这类流水线方法的固有风险。

### 与近期研究的关联

- **与 LEGO（08-13 精读，分层语言高斯）的对比**：LEGO 也做语言-3DGS 的分层理解，但聚焦分层渲染组织；CausalSplat 聚焦推理层级。两者互补：LEGO 的空间分层可以作为 CausalSplat 场景图的底座

- **与 Reasmory（已在库）的一致性**：Reasmory 证明 3D 重建作为 VLM 显式记忆提升空间推理，CausalSplat 是该理念在"推理分割"任务上的具体化，并进一步引入关系边

## 总结

### 核心发现总结

CausalSplat 的核心贡献是**问题定义而非方法突破**：它把 3DGS 理解从"名词查询"推进到"四级推理"（空间/常识/可供性/反事实），并用两个真实场景基准揭示了现有方法的全面溃败（最强基线 ≤23.6%）。方法层面的洞见是"感知-推理解耦"——用多模态场景图（质心+包围盒+类别+特征+可供性的节点 + 尺度自适应关系边）作为几何与逻辑之间的桥梁，让 LLM 在结构化空间上做三阶段推理，推理基准 2 倍于最强基线且向下兼容指代/开放词汇任务。

### 对Spatial AGI的意义

这篇论文把 Spatial AGI 的能力标尺立了起来：四级推理层级（尤其是首次入榜的反事实推理）为整个领域提供了评估坐标系；47.0%/14.9% 的绝对水位说明我们仍处在"空间推理"的早期。架构启示同样重要：**LLM 的空间推理上限由空间表示的结构化程度决定**——特征场+场景图的复合表示、感知与推理的解耦、推理深度的动态路由，这三件事对任何 Spatial AGI 系统设计都有直接参考价值。下一步的显然方向：端到端可训练的推理分割、物理仿真支撑的真反事实推理、更大规模的程序化推理基准。

## 附录A：四级推理层级的完整剖析与示例

### A.1 层级定义与典型查询

| 层级 | 认知要求 | 典型指令 | 失败模式（基线） |
|------|---------|---------|----------------|
| L1 空间推理 | 解析绝对/相对几何关系（距离、尺度）与 3D 拓扑（支撑、包含、遮挡） | "找到桌子下方被遮挡的、支撑着一个盒子的物体" | 2D 投影视角混淆上下关系；无法跨视角验证遮挡 |
| L2 常识推理 | LLM 先验知识与 3D 场景实例对齐，无直接视觉描述 | "我刚吃完油腻的一餐，需要清洁嘴巴"→定位餐巾 | 词袋匹配到无关显著物体（salient distractor） |
| L3 可供性推理 | 基于 3D 几何（凹度、把手宽度）与空间状态推断交互潜力 | "找一个开口朝上、可供机械臂抓取的容器" | 无法将物理结构映射到功能 |
| L4 预测/反事实 | 理解重力、碰撞等物理机制，假想条件下的状态推演 | "如果移走底部的红色物体，哪些物体会掉落？" | 无物理模拟，纯几何/语义方法完全无法处理 |

### A.2 层级间的依赖关系

四层并非完全独立：
- L2-L4 都依赖 L1 的结构化感知（质心/包围盒/关系边是后续推理的输入）
- L4 依赖 L1 的支撑关系边 + L2 的物体物理属性常识 + L3 的稳定性判断
- 评估指标上四层统一为 mIoU，但认知负荷差异巨大——48.5% 的常识指令占比可能高估了整体难度均衡性

### A.3 与其他分层框架的对比

- Spatial-IQ（已在库）：按能力层级解构空间智能，但限于 2D 视觉问答
- Embodied3DBench：低层具身空间智能，无反事实维度
- CausalSplat 的独特性：**唯一将反事实推理纳入 3D 实例级评估的基准**

## 附录B：尺度自适应边构建的数学细节

### B.1 动机

开放世界场景中物体尺度差异可达 2-3 个数量级（茶杯 vs 沙发）。固定距离阈值判定"上下/邻近"关系在小物体上过于宽松、在大物体上过于严苛。

### B.2 双重约束（以垂直关系为例）

**约束1（垂直显著性）**：|ΔZ|/d_{i,j} > τ = 0.3
- ΔZ = z_i - z_j：两实体质心的 Z 轴位移
- d_{i,j}：质心欧氏距离
- 直觉：垂直分量必须占主导，排除斜向远距的误判

**约束2（水平紧凑性）**：水平投影距离 ≤ D_limit^xy

```
D_limit^xy = min( max( 0.55·√(b̄x² + b̄y²),  0.08·S_xy ),  0.35·S_xy )
              └──────────物体尺寸下界──────────┘  └─场景下界─┘  └─场景上界─┘
```

- b̄x, b̄y：两实体包围盒在 x/y 轴的平均跨度 → 下界适配大物体（如桌面上的杯子）
- S_xy：全场景水平对角跨度（由所有实体质心极值计算）→ 0.08·S_xy 保证小物体也有最小容差；0.35·S_xy 防止大场景中过度连接

### B.3 设计启示

这是一个"物体尺度 × 场景尺度"双因素自适应的通用模板，可直接迁移：
- 邻近关系：将垂直约束换成水平距离占比约束
- 包含关系：用包围盒体积比 + 质心距 inside 判定
- 遮挡关系：结合相机位姿与深度排序，渲染验证

## 附录C：失败模式与误差传播分析

### C.1 流水线的四级误差源

```
SAM掩码噪声 → 空间加权缓解（但未消除）
   ↓
HDBSCAN聚类错误 → 实体过分割/欠分割
   ↓
VLM节点属性标注错误 → 类别/可供性误标直接误导推理
   ↓
LLM三阶段推理错误 → 路由失败（未检测到空间词）/ 拓扑搜索路径错误
```

### C.2 定性观察（来自论文图3/图4）

- 常识查询失败模式：基线模型定位到显著但无关的干扰物（如查询"摄像机"时定位到场景中最显眼的电子产品）
- 多跳空间约束失败模式：基线无法区分"目标"与"参照物"（"盘子旁边的包"→把盘子也分割进去，严重过分割）
- 可供性查询失败模式：Dr.Splat 等输出散点噪声或全房间过分割

### C.3 已知风险缓解手段

- 空间加权（+11.3 mIoU）：对抗边缘噪声
- 动态负采样（硬负样本 τ=0.5）：对抗类别不平衡
- 指令解析路由（+6.5 mIoU）：对抗简单查询的过度推理
- 待解：聚类与属性标注的误差量化、置信度传播、多假设推理
