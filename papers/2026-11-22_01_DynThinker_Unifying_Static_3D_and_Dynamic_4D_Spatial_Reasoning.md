## 核心问题

### Q1: 核心算法原理是什么？

**问题**: 这篇文章的核心算法原理是什么？请详细描述：1) 核心思想和动机，2) 主要技术方法，3) 算法流程和关键步骤，4) 输入输出。

**分析**:

#### 1. 核心思想和动机

这篇论文的出发点是一个非常具体的观察：**通用空间智能需要同时具备静态3D理解和动态4D推理能力，但现有模型很难两头兼顾**。

具体来说，作者发现了一个他们称之为"空间-动态干扰"（Spatial-Dynamic Interference）的现象：

- 3D专项后训练（post-training）会削弱预训练模型自带的动态理解能力
- 4D专项模型则往往缺乏扎实的静态3D推理能力

作者用了一个非常聪明的诊断实验来证实这一点：在 Qwen3-VL-8B 和它的 3D 专项版本 GeoThinker 之间做**权重插值**。结果非常清晰——随着插值系数向 GeoThinker 移动：

- VSI-Bench（静态3D基准）分数稳步上升
- VLM4D（动态4D基准）分数持续下降

而且静态性能在中间插值点就开始饱和，动态性能却持续滑落到专项checkpoint。这说明3D专项训练确实在"侵蚀"预训练继承下来的动态能力。

更关键的第二个诊断实验是**参数组敏感性分析**：把3D专项模型的不同参数组分别恢复到预训练值，观察静态/动态性能变化。结果是：

- 干扰在参数组间**高度不均匀**
- **深层MLP（第4层之后）** 对静态-动态平衡尤其敏感
- 恢复这些层的MLP到预训练值能大幅恢复动态性能，但会部分逆转静态3D收益

这个诊断直接催生了两个设计动机：
1. 对敏感参数要"加固保护"，对不敏感参数保留"适应弹性" → D-EMA
2. 光保存还不够，还需要主动注入空间+时间先验来双向增强 → SDF

#### 2. 主要技术方法

DynThinker 由两个互补组件构成：

**（a）空间-动态融合（Spatial-Dynamic Fusion, SDF）**

架构层面：用 VDPM 作为动态几何编码器。VDPM = VGGT骨干 + 时变解码器：

- VGGT编码器特征 → 提供静态空间几何先验
- 时变解码器特征 → 捕捉跨帧的时序动态变化

为降低顺序解码成本，作者采用"密编码、疏解码"策略：对全部 n 帧做编码，但只对时间上排序的子集 K（m ≤ n 帧）做解码，然后通过时间线性插值恢复帧对齐的解码器特征：

```
F_enc = E(I)
F_dec_sparse = D(F_enc[K])
F_dec = LinearInterp_time(F_dec_sparse; K, n)
```

两条特征流都重采样到VLM的视觉token网格（n × L × d），再投影到LLM隐空间。

**重要性门控（Importance Gating）**：在第 j 个交互层，从图像token隐状态 H_j^img 预测两套独立的重要性分数：

```
S_j^s = Sigmoid(MLP_j^s(LN(H_j^img)))   # 空间重要性图
S_j^d = Sigmoid(MLP_j^d(LN(H_j^img)))   # 动态重要性图
```

每个重要性网络是轻量瓶颈MLP，为每个视觉token预测标量权重。

**双流直接相加组合**：与GeoThinker用交叉注意力不同，SDF直接把两条对齐的流加权相加：

```
F_j^fused = W_os(LN(F_enc) ⊙ S_j^s) + W_od(LN(F_dec) ⊙ S_j^d)
```

**残差缩放注入**：通过可学习标量门 g 注入：

```
H_j,out^img = H_j^img + tanh(g) · F_j^fused
```

g 初始化为0，使SDF初始时是恒等映射——训练从"无先验"平滑启动。重要细节：**SDF不向LLM序列添加任何新token**，先验直接注入已有的视觉表示。

**（b）解耦指数移动平均（Decoupled EMA, D-EMA）**

优化层面的能力保护机制。标准EMA对所有参数用统一的平均时间窗，无法区分敏感度。D-EMA按参数组分配不同的平均时间窗：

参数组划分（边界 b=4）：
- **敏感组 G_sens**：第 b 层之后的可训练MLP参数（诊断实验确定的干扰敏感区）
- **基础组 G_base**：其他所有可训练预训练参数（早期MLP、注意力模块、可训练视觉组件）
- **新参数组 G_new**：所有新引入参数（包括SDF）

组级平均公式：

```
θ̄_t^(k) = ρ_k · θ̄_{t-1}^(k) + (1-ρ_k) · θ_t^(k)
```

衰减系数满足 0 < ρ_base ≤ ρ_sens < 1，ρ_new = 0（新参数不做平均）。

**尺度归一化的时间窗**：为了在不同训练时长下保持一致的初始权重贡献，参数化为：

```
λ_k = -N_ref · log(ρ_k)
ρ_k' = exp(-λ_k / N_target)
```

保证 (ρ_k')^N_target = ρ_k^N_ref = e^{-λ_k}，即无论训练多长，初始预训练权重在训练结束时的"残余影响力"恒定。

#### 3. 算法流程和关键步骤

1. **输入**：n帧RGB图像序列 I + 自然语言问题 Q
2. 视觉编码器提取patch特征，s×s相邻patch合并成视觉token（每帧 L 个token）
3. VDPM密编码所有帧、疏解码m帧（论文配置 n=32, m=8），时间插值恢复全部帧的解码器特征
4. 两条几何特征流重采样到视觉token网格，投影到LLM隐空间
5. LLM前向传播中，在选定的中间交互层，SDF用语义隐状态预测重要性图，加权融合两条先验流，残差注入图像token隐状态
6. 后续层继续多模态推理，生成文本回答
7. **训练时**：正常SGD/Adam优化在线参数；D-EMA在150步后启动，每10步更新一次影子参数；训练结束后用整合参数 θ̄_T 推理（架构不变）

#### 4. 输入输出

- **输入**：多帧视频/多视图图像（最多128帧评测）+ 文本问题
- **输出**：文本形式的答案（数值估计、多项选择、路径规划等）
- **隐式输出**：中间层的空间+动态先验融合表示（不外显）

### Q2: 这篇文章与通用空间智能（Spatial AGI）有什么关系？

**问题**: 这篇文章与通用空间智能（Spatial AGI）有什么关系？请分析：1) 如何理解和表示空间，2) 如何处理空间关系，3) 对Spatial AGI有什么启发，4) 可以应用到哪些Spatial AGI场景。

**分析**:

#### 1. 如何理解和表示空间

这篇论文对空间的理有一个重要的二元结构：

- **静态空间**：场景的3D几何结构——物体计数、绝对/相对距离、物体/房间尺寸、相对方向、路线规划（对应VSI-Bench、MMSI-Bench、MindCube、ViewSpatial、SITE、CV-Bench等基准）
- **动态空间**：随时间演化的4D结构——运动轨迹、视角变化、观察者运动与物体运动的解耦（对应VLM4D、DSR-Bench、DSI-Bench）

这个二元结构本身对Spatial AGI就是一个重要提醒：**真实世界的空间智能从来不是静态的**。一个能在房间里数对家具数量的模型，未必能判断"我向左走时桌子相对我是向右移动的"。DynThinker把这种解耦能力（DSI-Bench专门考察观察者运动vs物体运动的区分）纳入统一框架，是在向"空间=几何+时间"的完整定义靠拢。

表示层面，空间知识以三种形式存在：
1. 预训练VLM隐式的2D投影统计（"平面"先验）
2. 几何编码器的显式3D/4D特征（VGGT的点图、VDPM的时变解码）
3. 语义引导下的token级重要性选择（哪里需要几何证据）

#### 2. 如何处理空间关系

处理流程是"语义引导的几何注入"：

- 不让几何模块直接输出答案，而是让VLM的中间语义表示决定**在哪些空间位置、哪些推理上下文中**引入多少静态几何证据、多少动态时序证据
- 重要性门控 S^s、S^d 实现了每个视觉token级别的证据调配
- tanh(g) 的零初始化残差门保证了先验注入是"按需生长"的

另外，D-EMA处理空间关系的方式很特别——它处理的不是输入空间，而是**参数空间中的能力分布**：通过让深层MLP参数在训练过程中保持与预训练状态的时间平均联系，防止静态专项训练覆盖掉动态空间能力的神经基底。

#### 3. 对Spatial AGI的启发

**启发1：能力冲突是真实的，而且可以定位。** 这篇论文最大的方法论贡献是诊断流程：权重插值 + 参数组恢复实验，能把"哪部分网络承载哪种空间能力"定位出来。对Spatial AGI研究来说，这种"能力解剖学"方法可以推广：空间智能的各子能力（度量估计、视角变换、时序推理、物理直觉）很可能分布在不同参数组，多任务空间训练的负迁移可以被诊断和针对性缓解。

**启发2：统一不是平均，而是差异化保护+语义化融合。** D-EMA的思想——对不同敏感度的参数施加不同强度的保守性——本质上是"结构性课程学习"。这暗示Spatial AGI的统一模型不应该对所有能力一视同仁地训练，而应该有一个能力敏感度地图来指导训练策略。

**启发3：几何先验的注入应该是语义条件化的。** 盲目融合所有帧的全部几何特征（计算贵且引入噪声估计器的依赖）不如让语义模型决定何时何地取用几何证据。这与"工具使用"式的空间推理（VLM按需调用3D工具）形成呼应——DynThinker是"内部工具化"：把几何编码器当成可被语义查询的内部证据源。

**启发4：静态与动态的数据配比问题。** 论文的data scaling实验显示，没有D-EMA时，增加4D训练数据会让动态推理越来越差（干扰随规模加剧），有D-EMA则两边都受益。这直接反驳了"数据多了自然统一"的朴素假设。

#### 4. 可以应用的Spatial AGI场景

- **具身导航**：机器人/无人机既要理解静态场景布局（去哪、有什么），又要推理自身运动引起的视角变化（DSI-Bench式解耦）
- **自动驾驶**：静态道路结构 + 动态交通参与者轨迹的联合推理
- **视频问答与监控**：长视频中物体交互的时空推理
- **操作规划**：机械臂需要对静态物体几何和动态运动（包括自身介入后的变化）联合建模
- **AR/VR**：虚实融合中，虚拟内容既要贴合静态几何又要跟随动态场景

### Q3: 主要创新点和局限性是什么？

**问题**: 基于前面的分析，这个方法的主要创新点和局限性是什么？与其他相关工作相比有什么优势和劣势？

**分析**:

#### 1. 主要创新点

1. **首次系统性诊断"空间-动态干扰"**：用权重插值和参数组恢复实验证明3D专项训练侵蚀动态能力，并定位到深层MLP是干扰敏感区。这是一个可复用的分析范式。

2. **D-EMA（解耦指数移动平均）**：把EMA从"全局正则化"升级为"组级能力保护"。三个技术细节值得注意：
   - 组级差异化衰减 ρ_sens ≥ ρ_base
   - 新参数（SDF）排除在平均之外（ρ_new=0）
   - 尺度归一化时间窗，保证不同训练长度下初始权重的残余影响力一致

3. **SDF（空间-动态融合）**：相比GeoThinker的交叉注意力融合，SDF用重要性门控+直接相加，且同时注入静态（编码器）和动态（解码器）两条先验流，语义引导每个token的证据调配。不增加序列长度。

4. **统一模型的SOTA**：单一8B模型在10项指标平均60.5分，超过GPT-5.6 Sol（59.5），同时刷新ReVSI（56.0）、DSR-Bench（67.2）、DSI-Bench（51.2/40.1）开源SOTA。VLM4D从GeoThinker的42.4恢复到60.0，DSR从30.9跃升到67.7——动态能力的"失而复得"是最有说服力的证据。

5. **规模鲁棒性**：D-EMA在数据扩展（1M→2M 4D样本）下保持有效，甚至在专门4D训练下也优于MLLM-4D RFT（66.74 vs 63.1，且用更少SFT样本）。

#### 2. 主要局限性

1. **诊断结论的特异性**：深层MLP敏感这一结论来自Qwen3-VL + GeoThinker这一特定组合，是否泛化到其他骨干/其他专项训练未知。b=4的边界选择靠扫描，缺乏第一性原理解释。

2. **D-EMA的超参依赖**：ρ的设定（0.999834等）需要参考训练调度手工调整，虽然尺度归一化缓解了这个问题，但本质上是超参搜索。

3. **几何编码器仍是外部依赖**：VDPM在推理时需要前向（虽然疏解码省了计算），对遮挡、恶劣视觉条件下的几何估计误差鲁棒性有限；重要性门控学到的是"何时不信任几何"，但训练数据中的几何质量分布决定了这个能力的天花板。

4. **静态3D部分仍有明显短板**：MMSI-Bench只有31.5、MindCube 31.5，与Sensenova-SI（42.5/89.9）等相比在部分静态基准上并不领先——统一模型在单项上仍可能输给极致专项模型。

5. **基准覆盖偏向问答式推理**：没有涉及空间智能的生成侧（场景生成、导航执行），且论文自己声明不宜直接部署到具身/驾驶等安全关键场景。

#### 3. 与其他相关工作的对比

| 方法 | 策略 | 劣势（相对DynThinker） |
|------|------|----------------------|
| GeoThinker | 语义引导中间层融合（仅静态几何，交叉注意力） | 动态能力严重退化（VLM4D 42.4） |
| GeoSR-4D / DSR-GSM | 几何掩码/π³几何，动态偏重 | 静态3D弱（VSI 32.9/33.5） |
| MLLM-4D-RFT | 4D专项SFT+RFT | 静态一般，且需要更多数据 |
| 数据回放（replay） | 混合旧数据 | 需要额外数据、混合配比调参 |
| LoRA | 参数高效 | 限制更新容量，无法解决干扰 |
| WiSE-FT/SWA/EMA | 权重平均 | 全局统一窗口，无组级敏感性 |

优势总结：唯一在统一模型中同时做到静态强、动态强且可规模化的开源方案；诊断-设计闭环的方法论完整。

劣势总结：架构与训练都更复杂（几何编码器+SDF+D-EMA三件套），复现门槛高；在纯静态极致基准上不占优。

## 核心技术发现

1. **空间-动态干扰可定位**：权重插值显示VSI-Bench与VLM4D单调反向变化；参数组恢复实验锁定深层MLP（j>4）为干扰敏感区。
2. **组级EMA即能力保险**：D-EMA在不使用回放数据、不加正则项的情况下，把GeoThinker式训练丢失的动态能力（VLM4D 45.2→53.6 in 4B消融）找回来，同时静态还略有提升。
3. **先验注入零初始化**：tanh(g)从0起步，训练自动决定注入强度，避免了先验噪声破坏预训练表示。
4. **密编码疏解码**：n=32帧编码、m=8帧解码+时间插值，把顺序解码成本从n降到m，几何覆盖不缩水。
5. **干扰随数据规模加剧**：无D-EMA时，4D数据越多动态越差；有D-EMA则静态动态双升——统一性不能靠堆数据，要靠训练机制。

## 个人思考

### 最令人兴奋的发现

"能力解剖学"这套诊断方法可能比D-EMA本身更有长期价值。把插值实验和参数组恢复实验组合起来，就能给网络画出一张"能力-参数"地图。如果这套方法推广到Spatial AGI的更多子能力——度量估计、视角变换、物理因果、导航规划——我们也许能回答一个根本问题：空间智能在大模型里到底是"一种"能力还是"一堆"能力的巧合共存？如果深层MLP真承载了时序-空间的一致性，那这说明预训练阶段视频数据确实教了模型一些真实的4D概念，只是被后来的3D专项SFT覆盖了。反过来，这也提示：预训练才是空间智能的主要来源，后训练更像是在做"能力选择"，选错了就是灾难性遗忘。

### 潜在局限

D-EMA本质上是一种保守策略——它保护的是已有的动态能力，但如果预训练本身动态能力就弱（比如纯图片训练的模型），D-EMA保护的就是弱能力。真正的统一可能需要数据机制（如统一3D-4D联合表征的预训练目标）而不只是训练技巧。另外，SDF依赖VDPM的质量，几何估计在真实糟糕条件下（夜间、运动模糊、纹理缺失）的失败如何被重要性门控察觉，论文没有深入分析——门控是在干净数据上训练的，分布外几何错误的"可信度校准"是个开放问题。

### 与昨日研究的关联

结合近期读到的空间推理工作（如HiSpatial的层级3D理解、SpatialStack的几何-语言融合、Grid Spatial Understanding的网格推理），这个领域正在形成一条清晰的脉络：**从"给VLM喂几何特征"进化到"语义引导下的几何证据调度"**。DynThinker的D-EMA补充了这条脉络缺失的一环——训练动力学层面的能力共存问题。之前读的世界模型论文（fast-slow timescale设计）与D-EMA在思想上遥相呼应：都是在"变化"与"保持"之间做结构化管理，一个在参数空间，一个在表征空间。Spatial AGI的统一理论可能就藏在这些对偶结构里。

DynThinker证明了静态3D与动态4D空间推理可以在单一8B VLM中兼得：诊断定位干扰敏感参数组（深层MLP），D-EMA组级保护预训练动态能力，SDF语义引导注入静态+动态几何先验，最终十项指标平均60.5超越GPT-5.6 Sol。关键洞见是：统一空间智能不能靠数据堆叠，必须显式管理训练过程中的能力干扰。

## 附录A：技术细节深挖

### A.1 空间-动态干扰的诊断实验细节

诊断实验是全文的立论基础，值得单独展开：

**实验一：权重插值（Checkpoint Interpolation）**

```
θ(α) = (1-α)·θ_pretrained + α·θ_specialized,  α ∈ [0, 1]
```

在 Qwen3-VL-8B → GeoThinker Qwen3-VL-8B 的连线上采样多个 α 值，分别在 VSI-Bench（静态）和 VLM4D（动态）上评测。观察到的两条曲线形态：

- VSI-Bench：近似单调上升，且在 α≈0.5 附近出现饱和拐点——静态收益"来得快、到顶早"
- VLM4D：近似单调下降，且在 α→1 时跌至最低——动态损失"持续不断、越专越伤"

这个不对称形态非常重要：它说明静态专项训练的收益机制（拟合数据分布中的空间问答模式）与动态能力的损失机制（预训练表征中的时序一致性被覆盖）是两个不同时间尺度的过程。前者迅速收敛，后者慢性累积损伤。

**实验二：参数组恢复（Parameter-Group Restoration）**

把3D专项模型按模块（attention/MLP）和层级范围分组，逐组把参数恢复到预训练值：

- 恢复前4层的MLP（j≤4）：动态性能几乎不变，静态也几乎不变——早期层是"中性区"
- 恢复第4层之后的MLP（j>4）：动态性能大幅回升，静态3D收益部分回吐——干扰主要来自这里
- 恢复attention模块：影响相对温和

附录H进一步做了MLP边界b的敏感性扫描（H.1）和权重插值的细粒度分析（H.2），验证了b=4的选择不是过拟合单一基准的巧合。

**方法论的普适价值**：这两个实验都不需要重新训练，只需要已有checkpoint，成本极低。任何做"专项后训练"的团队（空间、代码、数学……）都可以复用这套流程来定位"遗忘发生在哪里"。

### A.2 D-EMA的数学结构

D-EMA的核心是一个带组差异化衰减的影子参数系统。把公式(6)(7)(8)串起来看：

对每个预训练参数组 k，维护影子参数 θ̄，初始化为预训练权重 θ_0（这一点很关键——影子的"锚"就是预训练状态，而不是训练初期状态）。衰减 ρ_k 决定了经过 N 步训练后预训练权重的残余影响力：

```
残余影响力 = ρ_k^N = e^{-λ_k}
```

- λ_k 越大 → 残余影响力越小 → 对该组的"保护"越弱
- 敏感组取更大的 ρ（即更小的 λ）→ 预训练权重"活"得更久

尺度归一化（式8）解决了EMA的经典痛点：固定 ρ 在不同训练长度下的实际平均窗差异巨大。通过 λ_k 的重参数化，无论 N_target 是1万步还是10万步，最终 e^{-λ_k} 的初始权重贡献恒定，超参可以跨调度迁移。

**与新参数的解耦**：ρ_new = 0 意味着 SDF 等新模块完全不参与平均——它们从零开始学习，不需要保护任何东西。这个三组设计（敏感/基础/新）把"保护谁、保护多少、不保护谁"表达得非常干净。

**与模型融合的关系**：训练结束时 θ̄_T 实际上是"预训练权重 + 训练轨迹的加权平均"，形式上接近 WiSE-FT 式的插值，但插值系数是通过训练动力学自动学出的、且按参数组差异化——比事后手工插值更优雅。

### A.3 SDF与GeoThinker融合方式的结构差异

| 维度 | GeoThinker | DynThinker SDF |
|------|-----------|----------------|
| 先验来源 | 单一静态几何（VGGT类） | 静态（编码器）+动态（解码器）双流 |
| 融合机制 | 交叉注意力 | 重要性门控 + 逐元素加权 + 直接相加 |
| 注入方式 | 中间层残差注入 | 相同（tanh(g)零初始化残差） |
| 序列代价 | 引入交叉注意力计算 | 不增加token，仅每token两次轻量MLP |
| 语义条件化 | 有（Q-Former式） | 有（每层独立的门控MLP） |

交叉注意力 vs 门控相加的取舍：交叉注意力表达力更强但计算贵、易过拟合；门控相加假设两条先验流与视觉token已空间对齐（由重采样保证），语义模型只需决定"取多少"而非"怎么混合"。从消融看这个简化没有付出精度代价，反而因为参数更少更稳定。

### A.4 训练数据配方分析

2.68M样本的构成体现了"静态:动态:通用"的平衡意识：

- 静态空间：VLM-3R空间指令数据、VSI-590K、MindCube
- 动态4D：13K DSR样本（2000视频，占官方训练集26%）、1M MLLM4D样本（占50%）
- 通用视频：430K（防通用能力崩塌）
- 预训练式数据：SPAR-7M采样、LLaVA-Hound split

值得注意：DSR和MLLM4D都是**评测基准的官方训练集**——这说明动态4D领域的评测集和训练集尚未完全隔离，DynThinker的动态分数（DSR 67.2）部分受益于见过同分布训练数据。这与静态领域（VSI-Bench等）的情况类似但值得保持警惕。

### A.5 推理成本分析

- VDPM：n=32帧密编码 + m=8帧顺序解码 + 线性插值 → 几何成本约为全解码的1/4
- SDF：每个交互层、每个视觉token两次瓶颈MLP + 两次投影 → 相对LLM主体可忽略
- token压缩：开启时平均60.3，关闭60.5 → 动态任务受益于更多token（VLM4D 60.0→62.3），静态略降（VSI 69.3→67.8），实际部署需按场景权衡

## 附录B：与其他Spatial AGI前沿工作的对照

### B.1 与"几何证据调度"脉络的关系

近期一系列工作在探索"VLM如何使用几何证据"：

- GeoThinker：语义引导的中间层融合（静态单流）
- Think-Capture：主动获取任务关键物体的3D几何（工具调用式）
- S-Agent：外部空间工具编排
- SpatialStack：几何-语言层级融合

DynThinker的位置：**内部化的双流证据调度 + 训练机制保护**。它假设几何证据永远可得（内部编码器），用门控决定用量；Think-Capture则假设几何获取有成本，用策略决定是否获取。两条路线分别对应"证据便宜"和"证据昂贵"的场景，未来可能融合为"主动获取+按需注入"。

### B.2 与能力遗忘研究的呼应

语言模型领域的"对齐税"（alignment tax）、专项微调遗忘研究早已观察到类似现象，DynThinker的贡献是把这个问题带入空间智能领域并给出了第一个参数级定位。这个"定位→保护"范式未来可预期的推广：

1. 空间↔物理因果的干扰定位（学物理会不会丢空间？）
2. 空间↔语言的干扰定位（学空间会不会退化对话？）
3. 多智能体空间协调能力的保护（当前尚无基准）

### B.3 对空间基础模型路线图的启示

把近期工作排列起来，可以看到空间智能训练的三个阶段：

1. **阶段一（2024-2025）**：给VLM喂3D数据，牺牲通用性换空间能力
2. **阶段二（2026）**：诊断能力冲突，设计保护机制（D-EMA这类），单模型多能力
3. **阶段三（未来）**：把3D/4D一致性目标内置到预训练，后训练只做对齐——预训练即空间智能

DynThinker是阶段二的代表作，它的诊断实验同时是阶段三合理性的证据：如果动态能力主要来自预训练，那么在预训练阶段就用统一的空间目标训练，会比事后修补高效得多。

## 附录D：逐基准深度解读

### D.1 静态基准表现解读

**ViewSpatial（90.4，全场最高）**：视角依赖的空间关系判断（"物体在我的左边还是右边"）。DynThinker大幅超越GPT-5.6 Sol（49.8），说明动态几何编码器的相机位姿先验对自我中心/他者中心视角切换帮助极大。动态4D训练反哺静态视角推理，是"统一带来正向迁移"的直接证据。

**MindCube（31.5，仍偏低）**：需要跨多视图整合认知地图式推理。所有模型在此都很挣扎（人类94.5），DynThinker与GeoThinker持平，说明当前几何先验注入范式对"认知地图构建"这类高阶组合推理帮助有限——几何特征给的是局部结构，缺的是全局空间记忆与假设检验机制。

**MMSI-Bench（31.5）**：多图像空间智能，同样全场性难题。与专门的多图空间推理模型（Sensenova-SI 42.5）相比仍有差距，印证"统一模型单项不极致"的局限。

**SITE（47.4）与CV-Bench（59.6）**：中规中矩，通用VLM底子决定上限。

### D.2 动态基准表现解读

**VLM4D（62.3）**：从预训练底座60.0恢复并小幅超越，而GeoThinker掉到42.4。D-EMA的"恢复"叙事在数字上完全兑现。VLM4D考察运动轨迹、视角变化、时序连续性——正是预训练视频数据能教的东西。

**DSR-Bench（67.2）**：真实视频上演化的3D关系与多物体交互。从30.9到67.2的跃升远超"恢复"范畴，是SDF动态先验流的主动增益——VDPM解码器的时变特征直接编码了物体间关系的演化。GPT-5.6 Sol仅29.1，人类未报告，这个基准上8B开源模型碾压了前沿闭源模型，侧面说明闭源API模型对动态空间关系仍然严重欠拟合。

**DSI-Bench（51.2/40.1）**：观察者运动与物体运动的解耦。这是动态空间推理中最"认知科学"的能力——自我运动补偿。40.1（group-wise）已接近GPT-5.6 Sol的42.2。DSI-G比DSI-S低约11分，说明按组聚合的严格协议下模型仍有系统性混淆，自我/他者运动归因是下一个攻坚点。

### D.3 数据扩展实验的深层含义

表3(b)在VLM4D Real split上的对比：DynThinker用800K样本达63.82，超过MLLM-4D用2M SFT的59.7和RFT的63.1；全VLM4D上1.5M样本66.74 vs MLLM-4D RFT 61.0。效率优势约2.5倍。

## 附录F：Spatial AGI 研究议程建议

基于本文的发现，提出后续值得探索的方向：

1. **预训练内化3D/4D一致性**：D-EMA保护的是预训练遗产，更彻底的方案是在预训练阶段引入可微几何一致性损失（如点图循环一致性、时序光度约束），让"静态+动态"成为先天能力而非后天补丁。

2. **几何证据的置信度校准**：SDF的门控应学会感知几何编码器的失灵场景（低纹理、运动模糊、强光照变化），可引入不确定性估计（如集成采样、深度方差）作为门控的额外交互项。

3. **能力敏感度地图的自动化**：把参数组恢复实验自动化为训练管道组件——每次专项训练前先跑一轮轻量诊断，自动确定 D-EMA 的分组和衰减配置，消除人工超参搜索。

4. **动态空间推理基准的人类标定**：为DSR/DSI/VLM4D补充人类基线，建立"距离人类水平"的统一度量，避免在饱和基准上空转。

5. **统一模型的空间行动化**：当前止步于问答，下一步是把统一3D/4D推理接到动作空间（导航、操作），验证"理解-行动"闭环中静态动态联合推理的实际价值。
