## Spatial AGI架构决策

### 模块化架构 vs 端到端学习

**决策日期**: 2026-03-12
**来源**: TiPToP论文分析

**决策**: 采用模块化架构而非端到端学习

**理由**:
1. TiPToP证明零数据模块化系统 = 350小时端到端VLA
2. 模块化更高效、更鲁棒、更可解释
3. 预训练VFM的强大泛化能力
4. 计算效率更高（选择性执行）

**影响**:
- 改变整个机器人学习的研究方向
- 从"收集更多数据"转向"设计更好的模块化架构"
- 架构设计 > 数据规模

## Spatial AGI五维突破架构

**决策日期**: 2026-03-12
**来源**: 5篇论文综合分析

**架构设计**: 五边形能力模型

1. **感知模块**（BEACON + ReCoSplat）
   - BEV遮挡推理
   - 实时3D重建
   - 解决"看"的问题

2. **理解模块**（C2FMAE）
   - 层次化跨粒度表示
   - 语义→实例→像素
   - 解决"懂"的问题

3. **规划模块**（TiPToP）
   - 开放词汇规划
   - VFM + TAMP
   - 解决"做"的问题

4. **评估模块**（CourtSI）
   - 度量级基准
   - 厘米级精度
   - 解决"评"的问题

5. **集成模块**（未来）
   - 模块间接口标准化
   - 计算效率优化
   - 跨域泛化

**技术路径**: 感知 → 理解 → 规划 → 评估 → 集成
