1. **触发时机** - 主会话何时应该委派任务

3. **输出** - 完整的输出字段定义 + 示例JSON
4. **工作流程** - ASCII流程图 + 详细步骤
5. **注意事项** - ✅必须做 + ❌禁止做 + ⚠️常见错误
6. **知识参考** - 具体的知识内容（放在最后）

   - ❌ "辅助工具脚本（util/）"
   - ✅ "生成评价指标到 metrics/ 目录"
   - ✅ "生成测试代码到 test/ 目录"

   - ❌ "性能基准测试（engine/benchmark.py）"

## 职责分工总结

### data-engineer (数据工程) - 数据专家
**职责**: 所有数据相关的实现工作
- 数据预处理（格式转换、清洗、标准化）
- Dataset 类实现（`dataset/loader.py`）
- DataLoader 配置和实现（`dataset/dataloader.py`）
- 数据增强流水线（`dataset/transform.py`）
- 采样器实现（`dataset/sampler.py`）
- 数据质量检查（完整性、一致性、分布分析）
- 数据列表生成（`datalist/`）
- 数据预处理脚本（`util/preprocess_data.py`）
- 数据可视化（`util/visualize_data.py`）

**输出**:
- 真实可用的 Dataset 类
- 配置好的 DataLoader
- 数据质量报告
- 数据列表文件

### algorithm-designer (算法设计) - 决策者
**职责**: 算法策略设计和配置
- 设计采样策略（决策用什么采样方法）
- 设计损失函数（选择和配置）
- 配置优化器（选择和调参）
- 定义评估指标（选择和配置）

**输出**:
- 采样策略选择（如"使用 ClassBalancedSampler"）
- 损失函数配置
- 优化器配置
- 评估指标配置

**依赖**: data-engineer 实现采样器代码

### performance-tuner (性能优化) - 分析师
**职责**: 分析瓶颈并提供优化建议
- 分析数据加载瓶颈（GPU 利用率 < 80%）
- 建议优化参数（num_workers, pin_memory）
- 优化训练速度
- 解决 OOM 问题

**输出**:
- 性能瓶颈分析报告
- 优化参数建议（如 "num_workers 建议设为 8"）

**依赖**: data-engineer 根据建议实现 DataLoader 配置

### test-engineer (测试评估) - 验证者
**职责**: 验证数据和模型正确性
- 验证数据加载正确性
- 测试模型性能
- 分析测试结果
- 生成修复建议

**输出**:
- 测试结果报告
- 数据加载验证报告
- 修复建议

**依赖**: data-engineer 提供真实数据集和 Dataset 类
