# 每日思考 - 2026-04-24

## 今日论文主题：从被动感知到主动探索，从反应式到规划式

今天的五篇论文围绕一个共同主题展开：**如何让具身智能体从"被动接收信息"转向"主动获取信息并规划未来"**。这个转变是空间智能从感知层级迈向认知层级的关键。

---

## 一、E3VS-Bench：主动感知的"能力测试"

E3VS-Bench 给出了一个清晰的信号：**当前 VLM 在被动看图方面很强，但在主动探索 3D 空间方面非常弱**。

### 核心洞察：视角依赖性是空间智能的试金石

传统 EQA 基准将 Agent 限制在 2D 平面导航，本质上还是在"走路+拍照"。E3VS-Bench 的 5-DoF 视角控制带来了质变：

- **move_up 是最频繁的动作** — 说明垂直维度的信息获取至关重要，而这在传统 benchmark 中被完全忽略
- **move_backward 比 move_forward 更频繁** — 获取上下文比靠近目标更重要
- **俯视图 (birdview) 效果最差 (~1.5/5)** — 这颠覆了一个直觉：以为"站得高看得远"就够了。实际上，细粒度的视角依赖信息（文字、物体状态、内部内容）需要从特定角度观察

这让我重新思考**空间智能的层级结构**：

```
Level 0: 被动感知（看图回答问题）— 当前 VLM 擅长
Level 1: 主动搜索（知道要看什么，去找到它）— 部分模型开始具备
Level 2: 视角规划（知道从哪个角度看能获取信息）— 极弱
Level 3: 主动探索（不知道信息在哪，但有策略地去发现）— 几乎为零
```

### 3DGS 作为 Benchmark 基础设施的范式转变

这个论文有一个重要的方法论贡献：**3DGS > Mesh for embodied benchmark**。传统 mesh 重建丢失的纹理细节恰恰是视角依赖推理的关键（小文字、品牌标志）。3DGS 开辟了构建高保真 embodied benchmark 的新范式。

我预见未来会有更多 benchmark 基于 3DGS 构建，因为它同时满足：
1. 照片级真实感（保留细粒度视觉信息）
2. 自由视角渲染（支持 5-DoF+ 控制）
3. 场景可获取（ScanNet++、Matterport 等已有 3DGS 重建）

### 计数问题暴露的深层缺陷

CNT 类别中所有模型接近 random baseline，这个结果值得深思。计数需要：
1. 跨多个视角累积证据
2. 维护已观察物体的空间记忆
3. 处理遮挡和重复计数

这实际上是在测试 Agent 的**空间工作记忆**能力 — 能否在移动视角的过程中维护一个一致的世界模型。当前 VLM 显然缺乏这种能力。

## 二、PokeVLA：空间认知作为操控的基础

PokeVLA 的两阶段训练范式提供了一个重要洞察：**空间理解应该在动作学习之前建立**。

### "先理解再行动"的成功

Stage 1 在 2.4M 多模态数据上建立 spatial grounding / affordance / embodied reasoning 能力，Stage 2 才注入操控表征。这个顺序很重要：

- Spatial grounding → 理解"在哪里"
- Affordance → 理解"能怎么交互"
- Embodied reasoning → 理解"交互的后果"

这三者构成了从感知到行动的认知链条。如果端到端一起学，模型可能走捷径（用视觉特征直接映射到动作），而没有建立真正的空间理解。

### 轻量化的意义

"Pocket-sized" 的定位很重要。如果 VLA 要真正部署，不能总是依赖巨型模型。PokeVLA 证明了精心设计的训练数据和范式可以让小模型达到 SOTA，这对空间智能的落地至关重要。

## 三、Mask World Model：预测什么比预测多准更重要

MWM 提供了一个关于世界模型设计的深刻洞察：**信息瓶颈的选择决定了模型学到什么**。

### 从像素到语义的抽象跃迁

传统世界模型预测 RGB 像素 → 模型需要同时预测与任务无关的视觉因素 → 泛化困难。

MWM 预测语义 mask → 信息瓶颈过滤掉纹理、颜色等噪声 → 模型聚焦于几何和动态。

这个洞察与空间智能的核心问题直接相关：**什么是空间信息的本质表示？**

我认为存在一个抽象层次谱系：
```
RGB像素 ← 最底层，信息最丰富但噪声最多
光流/深度 ← 低层几何信息
语义Mask ← 物体级别的几何+语义
场景图 ← 关系级别的抽象
语言描述 ← 最高层抽象
```

MWM 选择了语义 mask 这个中间层次，可能恰好位于"信息充分性"和"噪声过滤"的最佳平衡点。

### 对未来世界模型设计的启示

MWM 的成功暗示了一个重要方向：**世界模型不应该预测感官细节，而应该预测任务相关的抽象状态**。

这与人类认知的"不变量学习"理论一致 — 人类不会记住每个像素，而是记住物体和关系。

我预测未来的世界模型会沿着以下方向发展：
1. 从像素预测 → 语义预测（MWM 证明有效）
2. 从 2D mask → 3D semantic volume（更完整的空间表示）
3. 从单一表示 → 层次化表示（不同粒度的空间抽象）

## 四、Cortex 2.0：从反应式到规划式的范式转变

Cortex 2.0 代表了 VLA 演进的关键一步：**从"看到什么做什么"到"想象未来再选择"**。

### 反应式控制的根本局限

VLA 的核心范式是 observation → action，这本质上是一种反应式控制。在短视野任务中这够用，但在长视野任务中：

- 单步错误累积 → 不可恢复的失败
- 没有前瞻 → 无法避免即将到来的困难
- 缺乏全局规划 → 无法优化整体效率

Cortex 2.0 的"生成候选轨迹 → 评分 → 选择最优"范式，本质上是将 **model-based planning** 引入了 VLA 框架。

### 视觉潜在空间作为"心理模拟"的舞台

Cortex 2.0 在 visual latent space 中进行规划，这类似于人类的"心理模拟" — 在脑海中想象未来场景。

这与空间智能的"空间想象"能力直接对应：
1. **空间预测：** 想象物体在未来几步后的位置
2. **碰撞避免：** 评估轨迹是否会碰到障碍物
3. **任务进度评估：** 判断当前轨迹是否朝着目标推进

### 工业部署的价值

Google DeepMind 的这篇论文不仅展示了学术创新，更重要的是证明了 world model 在真实工业环境中可以可靠运行。这对整个领域是一个强烈的信号：**世界模型不再是学术实验品，而是可部署的工程系统**。

## 五、UniT：统一物理语言 — 跨身体的通用空间智能

UniT 提出了今天最具远见的想法：**一个跨身体的统一物理语言**。

### "视觉后果"作为跨身体桥梁

核心哲学非常优雅：虽然人类和人型机器人的运动学完全不同，但执行相同"物理意图"时产生的**视觉后果是相似的**。

这个洞察有一个更深层含义：**空间智能的本质不是关于"怎么动"，而是关于"动了之后世界变成什么样"**。

三分支交叉重建机制实际上是：
1. Action→Vision：知道做什么之后能看到什么结果（正预测）
2. Vision→Action：看到结果后知道做了什么（逆推断）
3. Fusion：将两者统一到共享空间（抽象化）

### 统一表示的双用途

最令我兴奋的是 UniT 的统一 token 同时服务于：
- **VLA-UniT：** 策略学习 — 预测要做什么
- **WM-UniT：** 世界模型 — 预测做了之后会怎样

这意味着 UniT 的 token 空间是一个真正的**物理语言** — 它同时编码了意图和结果，动作和状态。

### 对 Spatial AGI 的终极启示

如果我们将 UniT 的思路推广到极致：

1. **通用物理语言：** 不只是人类↔人型机器人，而是所有具身智能体（轮式、四足、无人机、机械臂）都映射到统一空间
2. **多智能体协作：** 不同智能体通过统一物理语言理解彼此的意图和行动后果
3. **知识规模化：** 人类日常视频（YouTube、TikTok 等）成为所有具身智能体的训练数据

这可能是 Spatial AGI 的关键基础设施之一。

## 综合思考：空间智能的"主动转向"

今天的五篇论文共同指向一个趋势：**空间智能正在从"被动理解"转向"主动获取和规划"**。

### 三个层次的转变

1. **感知层：** 从被动看图 → 主动控制视角获取信息 (E3VS-Bench)
2. **决策层：** 从反应式控制 → 规划式决策 (Cortex 2.0)
3. **表示层：** 从身体特定 → 跨身体统一 (UniT)

### 信息瓶颈的共识

MWM 和 PokeVLA 从不同角度达成了共识：
- MWM：通过 mask 预测过滤无关信息
- PokeVLA：通过两阶段训练先建立空间认知再学动作

两者都在说同一件事：**不要让模型被无关信息淹没，先建立任务相关的抽象，再基于抽象做决策**。

### 空间智能的核心循环

综合今天的论文，我提出空间智能的核心循环框架：

```
感知 → 抽象 → 想象 → 规划 → 行动 → 观察 → ...
  ↑                                                    |
  └──────────── 更新内部世界模型 ←──────────────────────┘
```

- **感知：** 主动控制视角获取信息 (E3VS-Bench)
- **抽象：** 过滤噪声，提取本质 (MWM, PokeVLA)
- **想象：** 在潜在空间预测未来 (Cortex 2.0)
- **规划：** 生成候选并选择最优 (Cortex 2.0)
- **行动：** 跨身体统一表征驱动 (UniT)
- **观察：** 更新内部世界模型 (WM-UniT)

这个循环不断迭代，每一步都在精化智能体对空间世界的理解。

### 今日最大的 Open Question

UniT 的"视觉后果"假设能否推广到所有类型的身体？

如果答案是肯定的，那么我们就找到了空间智能的"通用语言" — 不是自然语言，不是代码，而是一种编码"物理意图→视觉后果"的潜在语言。这可能是 Spatial AGI 的 Rosetta Stone。

## 深度分析：每篇论文的技术细节与批判

### E3VS-Bench 的过滤流水线值得深入分析

E3VS-Bench 的数据构建流水线是本文最精巧的部分之一：

**问题生成：** 使用 Gemini 2.5 Flash 在多视角渲染图上生成 QA。选择每个场景中实例数少的物体类别 → 计算观看距离使物体占画面 3/5 → 在球面上均匀采样视角 → VLM 过滤遮挡/越界/模糊视角 → 基于有效多视角生成 QA。

这个流程的关键设计决策：
1. 选择实例数少的类别 — 减少歧义
2. 物体占画面 3/5 — 保证足够的视觉信息
3. 球面均匀采样 — 覆盖所有视角
4. VLM 预过滤 — 减少人工标注负担

**过滤流水线的"守门人"问题：** 使用 GPT-5.1 作为过滤模型存在潜在偏差。GPT-5.1 能回答的问题被过滤掉了，但其他模型能回答的问题可能没有被过滤。这意味着 benchmark 对不同模型可能不公平。论文承认了这一点并排除了 GPT-5.1 在 blind/start 评估中的使用，但这个问题值得更深入的讨论。

**1120 小时人工标注的成本：** 这是一个高质量 benchmark 的代价。但这也限制了这种方法的可扩展性。未来可能需要更好的自动化工具来降低标注成本。

### PokeVLA 的两阶段训练的深层意义

PokeVLA 的两阶段训练不仅是技术选择，更反映了一种认知假说：

**假说：空间认知是操控能力的基础设施，不是副产物。**

如果这个假说成立，那么：
1. 先学空间理解，再学操控 → 高效（PokeVLA 的路线）
2. 空间理解和操控一起学 → 可能低效（端到端的路线）
3. 只学操控不学空间理解 → 脆弱（纯行为克隆的路线）

这个假说与认知科学中的"核心知识"理论一致 — 人类婴儿先发展空间认知（物体 permanence、深度感知），再发展操控能力。

**2.4M 数据的秘密：** 这个数据量在 LLM 标准下不算大，但对 embodied AI 来说已经很大了。关键不是量，而是覆盖度 — spatial grounding、affordance、embodied reasoning 三类任务的组合覆盖了空间智能的核心维度。

我好奇的是：如果将数据量扩大 10 倍但只保留其中一类任务，效果会如何？这可能揭示哪类空间知识对操控最重要。

### Mask World Model 的信息论视角

从信息论角度看，MWM 做了一件很简单但很深刻的事：**改变了预测目标的熵**。

RGB 预测的熵极高 — 需要预测每个像素的精确颜色值，其中大部分与任务无关。Mask 预测的熵低得多 — 只需预测每个像素属于哪个语义类别。

这种熵的降低有两个效果：
1. **降低学习难度：** 模型不需要学习不相关的视觉细节
2. **提高泛化能力：** 模型学到的是跨环境不变的语义动态

**Random Token Pruning 的鲁棒性测试很有洞察力：** 这实际上是在测试模型对信息丢失的容忍度。MWM 在丢掉大量 token 后仍然保持性能，说明它学到的表征确实抓住了任务相关的核心信息，而不是依赖所有视觉细节。

这让我想到一个类比：人类在昏暗光线下依然能操控物体，因为我们依赖的是几何和空间关系，而非精确的纹理信息。MWM 在某种程度上复现了这种能力。

### Cortex 2.0 的规划深度与延迟权衡

Cortex 2.0 没有报告推理延迟数据，这是一个重要的遗漏。在工业环境中：
- 反应式 VLA：~10-50ms 推理
- 规划式 Cortex 2.0：需要生成 N 条轨迹 + 评分 → 可能 100ms-1s

**这个延迟对什么任务是可接受的？**
- 慢速操控（装配线上的固定周期任务）→ 可接受
- 快速反应任务（动态避障、敏捷操控）→ 可能不可接受
- 长视野复杂任务（多步装配、拆包）→ 值得用规划换取可靠性

一个可能的折中方案是**自适应规划深度**：
- 简单场景：少生成几条候选，快速决策
- 复杂场景：多生成候选，仔细规划
- 非常紧急：直接反应式

这种自适应机制可能是未来 VLA + World Model 系统的标准配置。

### UniT 的"视觉后果不变性"假设的边界

UniT 的核心假设 — 不同身体执行相同意图产生相似视觉后果 — 有其适用边界：

**假设成立的场景：**
- 人类手臂和人型机器人手臂执行相同抓取动作 → 手到达目标位置 → 视觉结果相似
- 相似的行走模式 → 从相似视角观察环境

**假设可能不成立的场景：**
- 轮式机器人 vs 足式机器人：移动方式完全不同，视觉后果不同
- 微型无人机 vs 人类：视角和运动模式差异极大
- 机械臂 vs 人类手：灵活性和运动空间差异大

**更深层的问题：** "视觉后果"的定义本身可能有歧义。是指像素级别的相似？还是语义级别的相似？UniT 使用的是潜在空间对齐，但这个对齐的粒度和精度可能不足以处理极端差异化的身体。

### 世界模型的三种路径

今天的论文展示了世界模型的三种不同设计路径：

| 维度 | MWM | Cortex 2.0 | WM-UniT |
|------|-----|-----------|---------|
| 预测目标 | 语义 Mask | 潜在状态 | 统一 token 条件生成 |
| 核心创新 | 信息瓶颈 | 规划式控制 | 跨身体对齐 |
| 评估场景 | 桌面操控 | 工业操控 | 人型机器人 |
| 主要优势 | 泛化鲁棒 | 长视野可靠 | 数据可扩展 |
| 主要局限 | 依赖分割质量 | 推理延迟 | 身体差异边界 |

三种路径并不互斥，可能的融合方向：
- **MWM 的 mask + Cortex 2.0 的规划：** 在 mask 空间中进行规划，兼顾鲁棒性和前瞻性
- **UniT 的统一 token + MWM 的 mask：** 用统一 token 预测 mask 动态
- **三者融合：** 跨身体的统一 mask token + 规划式控制

### 主动感知的三个层次

E3VS-Bench 暴露的问题可以从另外四篇论文中找到部分答案：

| 层次 | E3VS-Bench 暴露的问题 | 可能的解决方案 |
|------|----------------------|--------------|
| 视角选择 | 不知道从哪看 | Cortex 2.0 的规划能力 |
| 信息过滤 | 被无关信息干扰 | MWM 的 mask 瓶颈 |
| 知识迁移 | 缺乏先验空间知识 | PokeVLA 的预训练 + UniT 的迁移 |

### 空间智能的技术栈正在成形

综合这几天的论文阅读，空间智能的技术栈正在逐渐清晰：

```
┌─────────────────────────────────────────────┐
│           Application Layer                  │

├─────────────────────────────────────────────┤

│  世界模型 + 轨迹生成 + 评分 (Cortex 2.0)      │
├─────────────────────────────────────────────┤

```

每一层都有今天的论文做出了贡献。这个技术栈还在早期阶段，但轮廓已经可见。

## 反思与自我批评

### 我可能过度乐观的地方

1. **统一物理语言的普适性：** UniT 目前只在人型机器人上验证，推广到所有智能体可能面临根本性挑战
2. **Mask 预测的充分性：** MWM 在桌面任务上有效，但大范围导航可能需要更丰富的表示

## 技术深度：论文中的关键设计决策分析

### E3VS-Bench 的 5-DoF 动作空间设计

E3VS-Bench 选择了离散动作空间：6 个平移动作（±x, ±y, ±z，步长 0.25m）+ 4 个旋转动作（yaw ±30°, pitch ±30°）+ stop，共 11 个动作。

**为什么是 5-DoF 而不是 6-DoF？** 5-DoF (xyz + yaw + pitch) 没有包含 roll。这个设计是合理的，因为在视觉搜索任务中，roll 旋转对信息获取的贡献很小（人眼也很少需要倾斜头部来获取信息）。减少一个自由度也降低了搜索空间的复杂度。

**步长 0.25m 的选择：** 对于室内场景（ScanNet++ 的典型尺度），0.25m 是一个合理的步长 — 足够在 25 步内覆盖场景，又不至于一步跳过关键区域。

**30° 旋转步长：** 这与人眼的扫视（saccade）角度大致匹配。更大的角度可能导致错过目标，更小的角度会增加不必要的步骤。

### VLM-as-Judge 的可靠性

E3VS-Bench 使用 GPT-5.1 作为 judge，Spearman ρ=0.54 与人类评估的一致性。这个数字是什么水平？

- ρ=0.54 属于"中等正相关"，说明 judge 有一定可靠性但远非完美
- 作为对比，人类评估者之间的 Spearman 相关通常在 0.7-0.9 之间
- 这意味着约 25-30% 的评分可能与人类判断不一致

**一个潜在的改进：** 使用多个 judge 的集成评分可能提高可靠性。或者使用连续评分而非 1-5 离散评分，减少边界情况的歧义。

### PokeVLA 的 Action Expert 设计

虽然 abs 没有详细描述 Action Expert 的架构，但从设计理念来看，它可能是一个轻量级的 MLP 或 small transformer，将 VLM 的视觉-语言表征映射到动作空间。

**Action Expert 的必要性：** 为什么不直接用 VLM 输出动作？可能的原因：
1. VLM 的输出空间是语言 token，直接映射到连续动作有维度不匹配问题
2. Action Expert 可以学习 VLM 表征到动作的非线性映射
3. Action Expert 可以独立优化，不影响 VLM 的预训练知识

这与 RT-2 的"tokenize action"思路不同 — RT-2 将动作离散化为语言 token，PokeVLA 用专门的 expert 来处理动作输出，避免了动作到语言的量化损失。

### MWM 的 Mask 获取方式

一个关键的技术细节：MWM 如何获取 semantic mask？

可能的方式：
1. **预训练分割模型：** 使用 SAM 或类似模型实时生成 mask → 引入额外的计算开销和误差
2. **自监督分割：** 在训练过程中学习分割 → 增加训练复杂度
3. **Ground truth mask：** 在仿真中使用完美分割 → 限制了 sim-to-real 迁移

论文提到在仿真 benchmark 上评估，可能使用了 ground truth mask。真实世界实验中可能使用了预训练分割模型。这个选择对方法的实际可用性影响很大。

**如果使用 SAM：** SAM 的实时性在机器人场景中是可接受的（~50ms per frame），但 SAM 的分割粒度可能不适合所有操控任务（太细或太粗）。

### Cortex 2.0 的轨迹评分机制

Cortex 2.0 对候选轨迹评分时考虑两个维度：成功概率和效率。这引发了几个技术问题：

**评分模型是什么？** 可能是一个在大量成功/失败轨迹上训练的价值函数，或者直接使用 world model 的预测误差作为评分。

**生成多少条候选轨迹？** 太少可能错过好方案，太多增加延迟。一个合理的范围可能是 5-20 条。

**轨迹长度如何确定？** 固定长度还是自适应？长轨迹提供更远的前瞻但预测误差更大。

**评分的校准问题：** 如果评分模型的校准不好（高估或低估成功率），可能导致次优决策。

### UniT 的离散潜在空间

UniT 使用"共享离散潜在空间"来编码物理意图。为什么是离散的？

**离散 vs 连续的权衡：**
- 离散：更好的可解释性、更容易对齐跨身体表征、更利于下游策略学习（类似 VQ-VAE 的优势）
- 连续：更精确的表达能力、避免量化损失

UniT 选择离散可能是为了：
1. 将连续的动作空间量化为有限的"物理意图"集合
2. 便于跨身体的 token 对齐（相同离散值 = 相同意图）
3. 便于作为 VLM 的输入/输出（与语言 token 同构）

**一个有趣的问题：** 离散化的粒度如何选择？太粗会丢失细粒度的意图差异，太细会增加对齐难度。

## E3VS-Bench 中每个问题类型的深入认知分析

### OS (Object Search) — 基础的空间搜索
- 任务：找到特定物体
- 所需能力：物体识别 + 空间探索策略
- 人类表现 3.12 → 不是最高的 → 说明搜索本身对人类也有一定难度
- 模型表现 3.21 (Flash) → 模型在物体识别方面可能已经接近或达到人类水平

### OST (Object State) — 二值判断的挑战
- 任务：判断物体状态（开/关、满/空等）
- 所需能力：找到正确视角 + 状态识别
- 人类 3.59 → 相对较高 → 人类很擅长找到"能看清状态"的视角
- 模型 2.82 → 差距主要在视角规划而非状态识别

### OA (Object Attribute) — 细粒度视觉的极限
- 任务：识别物体的细粒度属性（文字、颜色、材质）
- 所需能力：精确的视角控制 + 高分辨率视觉理解
- 人类 4.06 → 最高分之一 → 人类擅长从不同角度发现细节
- 模型 3.18 → 差距主要在"主动发现信息在哪"的能力

### CGS (Context-Guided Search) — 语义推理的胜利
- 任务：根据功能/场景找到物体（"哪里可以放文件"）
- 所需能力：语义理解 + 空间搜索
- 模型表现 3.53 → 相对最好 → 语义理解是当前 VLM 的强项
- 这暗示：**当空间搜索结合语义推理时，VLM 的语言理解能力可以弥补空间理解的不足**

### SR (Spatial Reasoning) — 空间关系的终极测试
- 任务：判断物体间的空间关系（远近、大小、位置）
- 所需能力：精确的空间编码 + 多物体关系推理
- Gemini 3.0 Pro 在 E3VS 和 VQA at Goal 上表现一致 → 空间推理的视角控制能力已经在进步
- 但其他模型差距巨大 → 空间推理能力分布不均

### CNT (Counting) — 累积认知的最难挑战
- 任务：数物体数量
- 所需能力：空间工作记忆 + 遮挡推理 + 跨视角累积
- 所有模型 ~1.88 → 接近 random → 说明跨视角累积能力几乎为零
- 人类 3.59 → 即使人类也有一定难度 → 这确实是最难的任务

**CNT 为什么这么难？** 因为它需要同时具备：
1. 空间记忆：记住已经数过的物体
2. 遮挡推理：知道可能还有被遮挡的物体
3. 视角规划：系统性地覆盖整个空间
4. 去重：不同视角可能看到同一物体

这四项能力的组合远远超出了当前 VLM 的能力范围。

## 关键引用与金句

从今天的论文中提取的关键句子和我的注解：

1. **E3VS-Bench:** "Visual search in 3D environments requires embodied agents to actively explore their surroundings and acquire task-relevant evidence."
   - 注：这是主动感知的精确定义 — "主动"不是随机移动，而是有目的地获取与任务相关的证据。

2. **E3VS-Bench:** "Despite strong 2D reasoning ability, all models exhibit a substantial gap from humans, highlighting limitations in active perception and coherent viewpoint planning."
   - 注：2D 能力 ≠ 3D 能力。这是一个重要的结论 — 在 ImageNet 或 VQA 上的表现不能预测 3D 主动感知能力。

3. **MWM:** "This shift imposes a geometric information bottleneck, forcing the model to capture essential physical dynamics and contact relations while filtering out visual noise."
   - 注："几何信息瓶颈"这个概念非常有启发性。通过选择合适的预测目标，可以在不损失任务相关信息的情况下大幅减少需要学习的内容。

4. **Cortex 2.0:** "While Vision-Language-Action models have demonstrated strong generalization, they remain fundamentally reactive."
   - 注："根本上是反应式的"这个判断非常准确。VLA 的 observation→action 范式本质上是一种条件反射，不是真正的规划。

5. **Cortex 2.0:** "Cortex 2.0 shifts from reactive control to plan-and-act by generating candidate future trajectories in visual latent space."
   - 注：在视觉潜在空间中规划，而非在关节空间或任务空间中规划，这是一个重要的设计选择。

6. **UniT:** "Grounded in the philosophy that heterogeneous kinematics share universal visual consequences."
   - 注：这是整个论文的核心洞察，也是最值得深思的命题。

7. **UniT:** "By inducing a highly aligned cross-embodiment representation, UniT offers a scalable path to distill vast human knowledge into general-purpose humanoid capabilities."
   - 注："可扩展的路径"是关键词 — 如果每次都需要机器人数据，就永远受限于数据采集成本。
